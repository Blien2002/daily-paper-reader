## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现优异，但当标准指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示其根本原因在于架构而非语义理解不足。具体而言，我们证明了当前的VLA模型在内部能够成功保留正确的任务身份。失败实际上源于动态视觉观察与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构瓶颈，我们提出了基于语义重绑定（GSR）的方法，这是一种优雅的干预措施，通过将独立提取的任务语义与原生视觉特征显式融合，从头训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这一有针对性的干预仅使用标准演示即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进的模型推至新的PRIDE得分70.4的记录，在指令生成能力上超越了近期引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，其对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型在机器人操作任务中表现优异，但严重依赖标准化的指令模板。当指令被等价改写（如换一种说法描述相同动作）时，VLA模型的性能会出现灾难性下降，例如 VLA-Adapter、SmolVLA、π0.5 在LIBERO-Para上的成功率跌幅最高可达 67.53%。
- **核心矛盾（关键发现）**：传统观点认为这种脆弱性源于语义理解不足，通常用大规模扩充语言覆盖来缓解。但本文通过探针实验揭示了一个反直觉的事实——**模型内部其实已经正确保留了任务语义**，真正的问题出在架构层面：
  - 模型将动态视觉观测与文本指令联合编码，导致即使语义等价，不同表述在特征空间中也会产生系统性的、可分离的偏移（而非随机噪声）。
  - 下游动作策略对这些细微特征偏移高度敏感，无法将"已保留的正确语义"稳定地翻译为控制指令。
- **核心论点**：这种"语义理解好但用不好"的问题本质上是架构翻译缺陷，靠堆数据来解决是低效的；通过优雅的结构设计即可修复，从而替代暴力数据扩展范式。

## 2. 方法论

### 2.1 诊断方法（用于定位问题根源）

- **语义保持度量（Semantic Retention）**：在相同观测下，计算改写指令产生的动作与正确标准指令动作之间的归一化距离，与错误任务指令动作距离进行对比，定义语义保持率 R = (Δwrong − Δpara) / (Δwrong + Δpara)。R 为正值表示改写指令保留的任务信息仍比错误任务更接近正确任务。
- **Retrieval@1**：检测改写指令生成的动作是否在N个标准指令候选中最接近正确任务的动作，用于评估行为层面的任务身份可分辨性。
- **因果干预验证**：在VLA-Adapter的最后一个Bridge-Attention block前，仅将改写指令对应的语言特征替换为标准指令的特征，保持视觉和状态输入不变，成功率从60%提升至96%。这因果性地证明：任务语义在语言编码器中存活，但下游动作策略无法正确利用它。
- **进一步探明根因**：
  - 将辅助Qwen分支的图像替换为固定图像（主视觉通路仍为真实观测），Paraphrase成功率从46.82%提升到61.58%—证明动态视觉与文本的联合编码放大了改写带来的特征波动；
  - 通过任务不相交交叉验证，估计32个能分离标准指令与改写指令输出的特征方向。删除这些方向显著减小动作差距（0.4361 → 0.2282），而删除随机方向无效（0.4386），证明改写引发的特征偏移是系统性的、可分离的。

### 2.2 GSR（Grounded Semantic Re-binding）方法

- **核心思想**：绕过VLA模型不稳定的"语言-视觉联合编码"路径，使用一个**与当前图像完全无关、仅输入真实任务指令的冻结T5-large编码器**提取纯净稳定的任务语义；随后将其投影并注入模型原生的多模态计算路径中，与视觉场景和机器人状态进行深度融合；最后**完全重新初始化动作专家**从头训练，使其学习将外部语义与视觉、状态映射为正确动作。
- **关键步骤（架构感知的通用指南）**：
  1. 冻结T5-large提取指令的token级语义（不含图像和机器人状态）；
  2. 识别各模型原生架构中"任务信息、视觉场景、机器人状态"三者进行核心多模态融合的计算阶段，将投影后的T5语义注入该阶段；
  3. 评估模型原生语言路径对改写的鲁棒性：
     - 若原生路径脆弱（如VLA-Adapter、SmolVLA），则将其原始文本输入替换为固定中性提示"perform the task"，强制模型完全依赖T5语义；
     - 若原生路径已可靠（如π0.5），则保留真实指令，T5作为补充语义源。
- **不同架构的落地方式**：
  - **VLA-Adapter**：冻结Qwen接收中性提示和真实图像；T5输出投影后作为sidecar K/V源输入到Bridge-Attention策略的每个MLPResNetBlock_Pro中；动作头从随机初始化训练，使用标准L1回归损失。
  - **SmolVLA**：不能采用VLA-Adapter的"旁路侧车"方式（会因缺乏视觉接地而失败）；将T5语义通过8头接地注意力注入SmolVLM原生语言槽位后，继续经过原生多模态计算。
  - **π0.5**：T5语义在PaliGemma的指令token位置（任务掩码范围内）注入，PaliGemma继续接收真实指令，冻结VLM骨干，重初始化300M动作专家，使用原始flow-matching目标训练。
- **ParaVLA（原生解耦架构）**：完全分离视觉与语言处理——冻结T5编码指令、DINOv2编码图像，仅在最终动作专家中融合。0.33B参数，每个控制步仅需DINOv2和动作专家计算（T5对每任务只运行一次并缓存结果），在标准指令和改写指令间实现近乎完美鲁棒性。

### 3.4 辅助实验

- **层间干预实验**：系统性地将改写运行中某一层的内部特征替换为标准运行的特征，测量动作恢复率，揭示VLA-Adapter存在单一瓶颈（最后Bridge-Attention block恢复96.8%），而SmolVLA和π0.5任务语义分布式处理。

## 6. 主要结论与发现

1. **VLA模型对指令改写的脆弱性不是语义理解失败**，而是架构性的"翻译"失败——模型内部保留任务身份，但下游动作策略无法稳定利用。
2. **根因在于联合编码动态视觉与文本**：这产生了系统性、可分离的特征偏移，而非随机的语义损失。
3. **GSR通过在模型原生多模态融合点注入冻结T5的纯净语义、并重初始化动作专家，仅用canonical数据即可显著恢复释义不变性**：VLA-Adapter Full Para从46.82%提升至70.94%（+24.12个百分点，相对提升约51.5%），SmolVLA从4.47%提升至49.12%。
4. **GSR是一种架构感知的通用方法论**，而非固定补丁：不同模型需要不同的注入点和不同的原生语言路径处理策略。
5. **结构设计可以替代数据扩展**：GSR使0.51B的VLA-Adapter在指令跟随能力上媲美大规模预训练的π0.5；π0.5+GSR更达到PRIDE 70.4的最高记录，超越Xiaomi-Robotics-0（69.2）。
6. **原生解耦架构ParaVLA（0.33B）展示了终极鲁棒性**：标准指令与改写指令成功率仅差1个百分点，同时无每步T5推理开销。

## 7. 优点

- **问题定位精准、因果链完整**：不是停留在"效果差→加数据"，而是用探针实验、token干预、特征方向删除、层间替换等多种手段层层锁定真正根因，逻辑严整。
- **方法优雅且高效**：无需任何改写数据，仅使用canonical演示；冻结T5和VLM骨干，只需训练投影层和动作专家，训练成本低。
- **架构感知的通用设计原则**：基于对三种不同架构的深入分析提出指导性框架，而非"一刀切"补丁，可迁移到未来新架构。
- **诊断方法本身具有广泛参考价值**：语义保持率R、Retrieval@1、皮层替换度量（patching）、双路径冲突测试等为VLA可解释性研究提供了工具。
- **统计严谨性**：严格配对控制（固定初始状态、观测、种子、噪声）、McNemar检验、bootstrap置信区间，提升了结论可信度。
- **证明了"轻量模型可通过结构设计媲美大规模模型"**，对资源受限的机器人学习场景具有实际意义。

## 8. 不足与局限

- **π0.5在匹配训练步数下标准指令成功率出现轻微下降**（93.0→91.0），虽加倍训练后恢复至96.0，但说明GSR在大型动作专家上需要更多优化步数，收敛效率问题仍未完全解决。
- **ParaVLA解耦架构存在可扩展性瓶颈**：升级为更大的视觉基础模型（如更大DINO变体）时，无法展现VLM级别的扩展收益。解耦范式与VLM规模红利之间的张力是未来重要挑战。
- **真实机器人评估规模有限**：仅6个任务、单一机械臂平台、5次试验/条件，1Hz控制频率限制；场景多样性（物体材质、光照、遮挡）未覆盖。
- **仅基于LIBERO系列基准**，虽含4,092集较大规模的改写评估，但任务类别集中在桌面操作，未涉及移动操作、长程任务等更复杂场景。
