## 摘要
视觉-语言-动作（VLA）模型的视觉表示在空间精确的机器人操作中仍然不可靠。我们发现，VLA中的视觉编码器也表现出先前在通用视觉Transformer中记录到的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练期间获得的空间感知能力密切相关。随着编码器学习任务相关信息（如物体位置、深度排序和局部几何），有限的全局token容量导致部分信息溢出到低信息量的patch token中。我们提出了AtVLA，这是一个将可学习的注册token插入视觉编码器的框架。仅使用具身数据和原始动作目标进行端到端训练，这些注册token成为具身空间信息的专用载体，而剩余的patch token恢复了干净且空间上忠实的注意力分布，这对于精确的目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位，但无法恢复在低分辨率观察中丢失的几何细节。因此，AtVLA将注意力修正与不确定性门控的局部细化相结合。动作专家对多个动作块进行采样，并根据它们之间的差异估计不确定性；仅对于不确定的预测，动作条件化的注意力展开（attention rollout）识别任务相关区域，该区域被裁剪、以高分辨率重新编码，并附加到缓存的prefix上以生成精确的动作。在LIBERO、SimplerEnv和具有挑战性的单视角真实世界基准上，AtVLA将LIBERO平均成功率从94.2%提升至98.4%，真实世界成功率从46.5%提升至69.0%。在代表性的部署设置下，裁剪在约30%的重新规划步骤中被触发，总计算量仅为基础模型的1.4-1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

### 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过在大规模视觉-语言预训练基础上进行机器人演示数据后训练，实现了跨任务泛化。然而，机器人控制不仅需要语义理解，还需要**空间精确的视觉表征**以支撑目标定位、几何推理和精细接触。
- **核心问题**：VLA 模型的视觉编码器在实际操控中表现出两类关键瓶颈：
  1. **注意力伪影（Attention Artifacts）**：视觉编码器中存在高范数伪影——低信息背景 patch 被用作全局信息“仓库”，挤占了局部空间内容，破坏了密集注意力图，导致模型错误定位目标物体、混淆任务类型。
  2. **低分辨率下几何细节丢失**：即便定位正确，低分辨率观测中目标/接触区域的局部几何细节仍然不足，而腕部相机存在视角敏感性问题。
- **关键发现**：这种注意力伪影与具身后训练密切相关——编码器在学习物体位置、深度关系、实例结构和局部几何等操控相关信息时，有限的全局 token 容量导致信息溢出到 patch token 中，使得有用的具身知识存储在了错误的位置。
- **研究含义**：需要一种既能在**表征层面**矫正注意力伪影，又能在**感知层面**按需补充高分细节的机制，以提升 VLA 模型的空间操作可靠性。

### 2. 方法论

AtVLA 由两个互补机制组成：**寄存器增强视觉编码** 和 **不确定性门控局部精炼**。

#### 2.1 寄存器增强视觉前缀（Register-Enhanced Visual Prefix）

- **核心思想**：在视觉编码器中插入可学习寄存器 token，为其提供专用的全局信息槽，防止背景 patch token 被挪用为高范数信息蓄水池。
- **实现细节**：
  - 在 SigLIP 编码器的 class token 之后插入 Nr=4 个 1152 维可学习寄存器嵌入，输入序列变为 [CLS; r1...rNr; p1...p256]。
  - 视觉编码器输出寄存器特征 Rt 和 patch 特征 Pt；与仅将寄存器作为内部工作区的原始用法不同，AtVLA **保留寄存器输出并通过视觉投影器传给下游策略**，作为多槽全局上下文。
  - 基础多模态前缀为 Cbt = [Π(Rt); Π(Pt); Elang(ℓ); Estate(st)]，完整 16×16 patch 网格仍可用于空间定位。
- **效果**：寄存器成为具身空间信息的专用载体，patch token 恢复干净的注意力分布。

#### 2.2 不确定性门控动作预测（Uncertainty-Gated Action Prediction）

- 基础视觉和语言前缀仅计算一次，并缓存 KV。
- 动作专家从独立高斯初始化中采样 K=4 个动作块：A(k)1:H = ODESolve(vθ, z(k)0 | Cbt)。
- 在平移动作维度和将要实际执行的前 h 个动作上计算不确定性：

  Ut = (1/h|Dtr|) Σj=1..h Σd∈Dtr √[(1/(K−1)) Σk (A(k)jd − Ājd)²]

- 若 Ut ≤ τ（阈值 τ 在留出集上校准），执行均值动作块；若 Ut > τ，触发精炼路径。

#### 2.3 注意力引导的局部精炼（Attention-Guided Local Refinement）

- **注意力展开**：利用动作采样时已产生的注意力矩阵，跨 18 层 joint-attention 层、多个去噪步（{3,6,9}）平均并做残差连接 + RowNorm，通过 rollout 传播得到 16×16 显著图。
- **对比窗口搜索**：在预设窗口集合（边长 {84,112,140} 像素，步长 14）中，选择内部注意力与周围环形区域最具有区分度的窗口（对比性标准可避免过大的全图裁剪和孤立注意力峰的小窗口）。
- **高分辨率重编码**：将选中区域裁剪并缩放至 224×224，用同一编码器编码；丢弃裁剪侧寄存器输出（基础寄存器已汇总全局上下文），仅保留 256 个裁剪 patch 特征。裁剪位置通过 MLP 编码为位置嵌入并加到每个裁剪 token 上，然后**附加到缓存前缀**（无需重算基础图像/语言 KV）。
- **触发频率**：约 30% 的重规划步骤触发裁剪，总计算量约为基础 π0 的 1.4–1.6 倍。

#### 2.4 三阶段训练范式

| 阶段 | 内容 | 步数 |
|------|------|------|
| Stage 0: 寄存器适应 | 仅用基础视图和 Lπ0 目标：先只更新寄存器嵌入（4K 步），再解冻 SigLIP 最后 4 层（16K 步） | 20K |
| Stage 1: Ground-Truth 裁剪对齐 | 使用标注裁剪区域，训练裁剪位置编码器 + LoRA 适配器，视觉编码器冻结 | 10K |
| Stage 2: 联合精炼与推理对齐 | 联合优化动作预测 + 注意力接地损失 Lag；裁剪来源从 ground-truth 线性过渡到自生成的注意力 rollout；裁剪丢弃率线性升至 0.3 | 40K |

- 总目标：L = Lπ0 + λcpLcp + λagLag，λcp=0.1，λag=1.0。
- 使用 rank-32 LoRA 适配器，保持基础 π0 动作表示、归一化和流匹配目标不变。

### 6. 主要结论与发现

1. **注意力伪影可被具身后训练矫正**：仅使用具身数据和动作监督训练寄存器，即可消除高范数伪影，无需额外的视觉预训练或通用视觉监督。混合 ImageNet/CC3M 反而破坏具身能力。
2. **寄存器承载丰富的具身空间信息**：线性探针显示，寄存器特征在物体定位（0.88）、深度（0.87）和表面法线（0.75–0.82）预测上均优于 CLS token 和 pooled patch 特征。移除已学习的寄存器导致 LIBERO 平均下降 4.45 个百分点，证明其不仅抑制伪影，还保留任务相关具身知识。
3. **裁剪不仅帮助精细感知，还支持长时规划**：LIBERO-Long-10 和真实世界长时任务均从裁剪中获益，因为额外视觉上下文支持后续决策。
4. **外部 VLM 裁剪不可靠**：无具身后训练的外部 VLM 裁剪常无法隔离交互关键区域，且不准确的裁剪会扭曲策略输入，突出了具身监督对决策相关视觉接地的重要性。
5. **性能提升显著**：LIBERO 平均成功率从 94.2% 提升至 98.4%，真实世界从 46.5% 提升至 69.0%，计算开销仅增加 1.4–1.6 倍（裁剪触发率约 30%）。

### 7. 优点

- **创新性**：首次将 Vision Transformer 的寄存器 token 引入 VLA 具身策略，并揭示注意力伪影与后训练空间信息获取之间的因果关联。
- **优雅的机制设计**：将“恢复定位能力”与“补充几何细节”解耦——干净的注意力决定看哪里，自适应裁剪恢复所需局部几何，二者互补。
- **效率优先**：不确定性门控使裁剪仅在约 30% 的重规划步骤被触发，且复用已有 KV 缓存，不重算基础前缀；注意力展开复用了动作采样期间已计算的注意力。
- **全程具身监督**：不依赖外部视觉模型、3D 传感器或显式空间监督，仅用动作目标和轻量辅助损失完成端到端训练。
- **严格受控消融**：π0 + Registers 与 π0 + Cropping 两个受控变体能清晰分离各组件贡献，且对裁剪学生训练使用与部署一致的失败处理规则（无 ground-truth 回退），避免训练-测试偏差。
- **渐进式课程训练**：三阶段训练（寄存器适应 → 裁剪对齐 → 联合精炼，其中裁剪源从标注逐步过渡到自生成）有效防止不稳定的特征漂移。

### 8. 不足与局限

- **标注依赖**：训练需要任务相关区域的边界框标注来监督裁剪接地损失 Lag 和 ground-truth 裁剪，增加了数据准备成本。
- **基准覆盖有限**：
  - SimplerEnv 仅测试 Google Robot 套件（3 个任务），且 Open/Close Drawer 中裁剪收益有限（场景大部分被柜体占据，裁剪无法有效解析把手/接触点）。
  - 真实世界基准为自建、单视角设置，未经第三方独立验证。
- **计算开销**：虽然裁剪触发率被控制在约 30%，总推理成本仍为基础方法的 1.4–1.6 倍，且不确定性估计需要额外 3 次动作采样（K=4 中多出 3 次）。
- **超参数敏感**：裁剪触发阈值需要按 embodiment 校准，注册 token 数量需实验调优（过少导致伪影吸收不完整，性能甚至低于基线；4 个恰好饱和）。
- **架构依赖**：注意力 rollout 依赖动作专家的多头注意力结构，方法迁移到非注意力或无此结构的策略可能需要重新设计。
- **单视角深度歧义**：Building Blocks 类任务的隐式 3D 推理虽有改善，但单视角在根本上的深度歧义未被完全消除。
- **训练成本**：70K 梯度更新在 8 块 RTX 6000 Ada 上进行，虽然仅微调局部参数，但完整的后训练流程仍需要相当的资源投入。
