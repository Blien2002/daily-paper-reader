## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观察到的物理交互线索。最近触觉世界动作模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何结构化这些未来以供动作专家有效使用仍未得到充分探索。直接用学习到的世界动作模型研究这个问题是困难的，因为端到端行为纠缠了物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及不可读的未来到动作接口。为了使这一接口可独立研究，我们引入了Oracle视觉-触觉前瞻（OVTF），一个受控框架，从模拟中验证的成功轨迹中提供配对的RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更干净的问题：如果未来是成功的且物理上可执行的，什么表示能让动作专家吸收其益处？在OVTF内，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注其自身的触觉流和相位对齐的未来视觉，并阻止跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问并独立处理每种未来模态。在UniVTAC模拟基准的七项任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性相位对齐的视觉-触觉路由相比完全模态隔离提供了更具可操作性的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

### 研究动机与背景

接触丰富的操控任务（contact-rich manipulation）对机器人控制提出了独特挑战：任务成功往往依赖视觉难以观测的物理交互线索（如接触力、形变、摩擦等）。近年来，触觉世界动作模型（tactile world action models）通过联合建模未来的视觉观测与触觉信号来指导动作生成，试图将“物理交互预判”的能力注入动作策略。

然而，作者指出了一个被现有研究普遍忽视的关键瓶颈：**未来到动作的接口（future-to-action interface）**——即未来信息以何种表征形式、何种路由方式传递给动作专家，决定了这些信息是否真正可被动作策略“消化吸收”。已有的端到端世界动作模型（WAM）评估中，以下四个因素纠缠在一起，导致无法单独判断接口设计的好坏：

1. **物理上无效的视觉未来**：视觉上合理但违反接触力学的未来轨迹
2. **对未来分支信任不足**：预测不稳定，使动作分支学会忽略未来信息
3. **不正确或模态不一致的触觉未来**：触觉预测精度差、与视觉未来时序不匹配
4. **糟糕的未来到动作接口**：未来内容正确但表征形式无法被动作分支有效读取

本文的核心贡献在于**提出了一种变量解耦（variable-disentangling）的研究框架 OVTF**，通过固定未来提供者为成功轨迹（oracle），首次使“未来到动作接口”可以被独立研究。这回答了领域内一个更干净的问题：**如果我们能保证未来信息是成功的、物理可执行的，那么什么样的接口设计才能让动作专家最大化利用这些信息？**

## 二、方法论

### 1. Oracle Visuo-Tactile Foresight (OVTF)

OVTF 通过**固定未来提供者**来隔离接口研究：

- 未来来源不是学习到的预测器，而是从成功的 HDF 演示轨迹中采样得到的配对 RGB 触觉序列
- 每个策略调用时，从当前参考轨迹索引 τ_ref 到最终帧 T-1 之间，均匀采样至多 N=100 帧
- 每个采样帧通过**归一化剩余视野相位**（phase）标记：
  ```
  φ_i = (τ_i - τ_ref) / max(1, T-1-τ_ref),  φ_i ∈ [0,1]
  ```
- 未来提供者只提供视觉图像和左右触觉 RGB 图像，**不提供**未来动作、未来 qpos、物体位姿、仿真器状态、成功标签等额外特权信息

### 2. 编码与预处理

- 当前观测：冻结的 UniVTAC-ACT* 编码器（视觉 + 触觉）处理
- 未来观测：独立的可训练 ResNet-18 编码器，由 UniVTAC-ACT* 权重深拷贝初始化
- 未来提供者输出三个序列：H（视觉）、L（左触觉）、R（右触觉），均 ∈ R^{N×512}
- 每个模态序列经过**门控局部时域残差**（gated local temporal residual）模块：
  ```
  X'_m = X_m + tanh(g_m) · Conv_DW(LN(X_m))
  ```
  其中 g_m 初始化为零，避免训练初期干扰

### 3. Asymmetric Phase-Local Future Memory (AFM)

AFM 是本文提出的核心接口机制，包含 12 个可学习的 512 维槽位：
- 4 个视觉槽位、4 个左触觉槽位、4 个右触觉槽位
- 四个固定相位锚点：C = {0.125, 0.375, 0.625, 0.875}

每个槽位通过联合多头注意力从允许的源序列读取信息，注意力分数包含**高斯相位先验**：
```
score_h,k,i = (q_h,k)ᵀk_h,i / √64 - (φ_i - c_k)² / (2 × 0.18²)
```
即内容注意力仍然可以访问所有有效源位置，但相位不一致的位置会受到软性惩罚。

**AFM 的路由模式（关键创新）**：
```
H ← H
L ← (L, H)
R ← (R, H)
L ↔ R 访问被禁止
```
即：
- 视觉记忆只读取未来视觉
- 每个触觉记忆联合关注自身触觉流 + 相位对齐的未来视觉（单次联合注意力，而非先读触觉再读视觉）
- 左右触觉之间完全阻断

### 4. Modality-Isolated Future Memory (IFM)

IFM 为对比基线，仅移除视觉→触觉的读入边：
```
H ← H
L ← L
R ← R
```
其余设置（未来提供者、相位锚点、记忆预算、训练数据、优化配置）与 AFM 完全一致。

### 5. ACT 集成与训练目标

- 未来槽位乘以零初始化的 tanh 门
- ACT 编码器记忆组织为：`[z₀ + s₁, q, s₂, ..., s₁₂, M_current]`
- 50 个动作查询，输出 50×8 的归一化动作块
- 禁用 CVAE/动作编码器，latent z 始终为零
- 冻结当前观测编码器；训练对象为未来编码器、时序滤波器、槽位读取器、ACT 变换器、动作头
- 优化目标为掩码动作 L1 损失，槽位去相关为 detached 诊断项（不参与反向传播）

## 六、主要结论与发现

### 1. 选择性视觉-触觉路由优于完全模态隔离

AFM Oracle（32.0%）明显优于 IFM（23.7%），差距 8.3 个百分点。由于两者使用相同的 oracle 未来、记忆预算、训练数据和优化配置，唯一差异就是路由模式，因此可归因于**相位对齐的视觉上下文使未来触觉信息对动作生成更具可操作性**。

### 2. 显式接口融合的价值不被下游自注意力取代

一个重要的反直觉发现是：虽然所有模态记忆在后续 ACT 编码器中仍可重新交叉注意力，但**在接口处进行显式非对称融合仍是必要的**，下游自注意力并不能完全弥补隔离接口的信息组织缺陷。

### 3. 策略确实在利用测试期未来内容

AFM Oracle（32.0%）与 AFM Forced-Zero（19.4%）之间的差距（12.6 个百分点）证明：训练时看到 oracle 未来的策略，在评估时确实积极消费未来信息，而非仅仅享受额外模块带来的表征增益。

### 4. 无未来信息时动作路径依然稳健

AFM Zero-Train 达到 20.0%，高于 UniVTAC-ACT* 基线的 14.9%，说明 AFM 所兼容的动作策略路径本身（不依赖未来输入时）也具有竞争力。

### 5. 不同任务对未来信息的依赖程度不同

- Put Shelf 和 Pull Out Key 显示出未来内容带来的最大行为增益
- Insert Tube 中 Oracle 与 Forced-Zero 持平（均为 42%），说明该任务的策略增益主要来自训练阶段的未来信息调节，而非测试期的在线未来输入
- Insert Hole 是唯一 IFM 最高的任务，但所有条件都接近成功率下限（2%-8%），结论意义有限

## 七、优点

### 方法论层面

1. **变量解耦的框架设计**：OVTF 将"未来预测质量"与"未来到动作接口质量"彻底分离，使接口研究不再受预测误差干扰。这是领域内少有的"clean-room"式研究范式。
2. **Oracle 信息的最小化设计**：只提供视觉-触觉图像，不提供未来动作或仿真器内部状态等特权信息，确保了研究的可控性和可推广性。
3. **相位感知的软性对齐**：高斯相位先验而非硬性时间窗，兼顾了时序对齐和内容注意力的灵活性。
4. **非对称路由的生物学启发性**：视觉辅助触觉、阻断左-右触觉交互的设计，回应了"触觉预测需要视觉上下文，但不同触觉流应保持独立性"的合理假设。
5. **完善的对照体系**：Zero-Train、Forced-Zero、IFM、Oracle 四个条件构建了完整的消融链，每一项结论都有对应的对照组支撑。

### 实验层面

1. **多任务覆盖**：7 个任务涵盖不同的接触模式（插入、拿起、放置、拔钥匙、提罐），任务多样性较好。
2. **公平性声明严格**：所有 AFM 系方法共享除检查点和接口路由外的所有配置，包括 rollout 映射、评估器、预处理、时间聚合、成功判定谓词。

### 方法论局限

4. **Oracle 框架本身不可部署**：OVTF 是诊断框架，未来提供者依赖成功的 HDF 演示轨迹。论文未展示如何将接口设计迁移到真实的 learned predictor 条件下——即当未来预测有噪声时，AFM 是否仍然优于 IFM 是未知的。
5. **单一项研究框架**：评估仅基于 UniVTAC 仿真环境，未在真实机器人平台验证；仿真中的触觉传感器和物理引擎与实际触觉存在 sim-to-real 差距。
6. **接口模块与 ACT 策略的耦合**：结论建立在一个具体策略架构（ACT）之上，AFM 接口的普适性是否对 Diffusion Policy、RDT 等其他动作策略成立，尚未验证。

### 潜在偏差风险

7. **初始化偏差**：AFM 系模型从 UniVTAC-ACT* checkpoint 初始化，且未来编码器从该 checkpoint 深拷贝——这意味着 baseline 与实验组共享了部分初始化信息，虽然 Fairness 声明控制了评估差异，但预训练权重的质量可能影响结论外推。
8. **任务选择偏差**：所选 7 个任务整体成功率偏低（baseline 仅 14.9%），高难度任务占多数。AFM 的优势是否在中等/高成功率任务中保持，缺乏验证。
9. **仅报告 2000 步的最终结果**：未提供训练过程曲线，无法确认 2000 步是所有任务上的收敛点，可能低估或高估某些方法的最终潜力。

### 应用限制

10. **接口的时序精细度有限**：每个模态仅使用 4 个相位锚点（12 个总槽位），对长时域（200+ 帧）任务中更细粒度的接触事件表征能力可能不足。
11. **未考虑触觉-触觉的跨流互补性**：左右触觉相互阻断是一个强假设，某些双手协调任务中左右接触信息可能相互需要，但该设计对这类任务可能不是最优的。

---

## 总结

本文通过提出 OVTF 框架，成功将"未来到动作接口"从端到端世界动作模型的混合效应中独立出来，并提出了 AFM 这一非对称相位局部未来记忆机制。实验证据表明：在未来信息保证成功和物理可执行的前提下，**选择性相位对齐的视觉-触觉路由提供比完全模态隔离更可操作的动作接口**；同时，该接口路径在无未来输入时也不弱于基线。研究为世界动作模型的接口设计提供了新的理论视角和实证基础，但 oracle 框架与真实预测器之间的推广性、统计稳健性和跨架构普适性仍需进一步验证。
