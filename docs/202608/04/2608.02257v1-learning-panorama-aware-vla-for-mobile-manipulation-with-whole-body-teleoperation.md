## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作为视觉-语言-动作（VLA）策略带来了两个关键挑战：在数据层面，高效收集高质量全身演示需要同时协调控制移动底盘和机械臂；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为了解决这些挑战，我们开发了一个全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持获取一个包含5.5小时多模态演示的真实世界移动操作数据集。基于该数据集，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于混合Transformer（Mixture-of-Transformers）架构，通过专门的全景编码和融合模块引入全局空间上下文，从而能够将全景观察与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了平均阶段完成率91.3%和端到端成功率73.4%，显著优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 1. 核心问题与整体含义

- **研究动机**：移动操作是具身智能的核心能力，要求机器人在开放世界中协调完成多阶段任务。然而，现有VLA模型向移动双臂机器人迁移时面临两大瓶颈：
  1. **数据收集困难**：移动操作需要操作者同时协调底盘运动、双臂动作和夹爪控制，传统分离式控制界面导致演示质量下降，难以采集高质量的全身协调数据。
  2. **视觉感知局限**：现有VLA模型依赖正面摄像头和腕部摄像头等局部视野，在长时程移动操作中，底盘平移/旋转和机械臂自遮挡常导致目标物体、地标或目标区域超出视野，缺乏机器人中心的全局空间理解。
- **核心思路**：全景成像天然提供360度环绕观测，可建立机器人中心的全局空间上下文；同时通过全身遥操作提升数据采集质量，两者结合构建一个"数据收集—模型学习"的完整框架。

### 2. 方法论

- **整体框架**：包含两部分——全身遥操作数据采集系统 + 全景感知VLA策略（PanoVLA），形成从数据到模型的全链路解决方案。

- **（1）GMR全身遥操作系统**
  - **硬件接口**：操作者佩戴VR头显（6-DoF头部位姿）、双手持控制器（手部位姿+夹爪指令）、腰部+双踝三个人体追踪器，通过稀疏人体运动采集实现自然身体运动驱动。
  - **运动重定向**：将稀疏追踪流实时重建为SMPL人体状态，提取骨盆运动、足部运动和双手位姿，输入GMR（General Motion Retargeting）优化框架，将移动底盘建模为**平面虚拟浮动基座**，与双臂关节联合优化。
  - **优化目标**：`q* = argmin_q (λpos Lpos + λrot Lrot + λbase Lbase + λreg Lreg)`，其中Lpos对齐手部-夹爪位置，Lrot对齐手-末端执行器朝向，Lbase将底盘平面运动与操作者骨盆位移和朝向耦合，Lreg限制关节极限和过度变化。
  - **模式切换策略**：底盘执行采用代价驱动的模式切换——在每个控制周期评估三种运动模式（自旋、阿克曼转向、对角平移）与期望位姿的匹配代价，选择代价最低的模式执行。
  - **动作输出**：最终输出17维全身动作（双臂14维 + 底盘3维），实现自然身体运动对移动基座和双臂的协调控制。

- **（2）PanoVLA模型架构**
  - **基础架构**：基于π0.5的MoT（Mixture-of-Transformers）VLA骨干，在VLM专家和动作专家之间**插入全景专家**，构成三专家架构（VLM专家、全景专家、动作专家）。
  - **全景编码器（Panorama Encoder）**：双鱼眼图像 → 球面重投影（Π_sph）→ 等距柱状投影（ERP）全景图 → 采用**MTPano**全景基础模型提取语义与深度特征（两分支密集特征拼接）→ 轻量级token适配器（自适应平均池化 + MLP）压缩为固定数量的全景token。
  - **全景专家（Panorama Expert）**：通过块级因果注意力掩码，将全景token与VLM专家生成的KV缓存进行联合自注意力，产出任务条件化的全景缓存（Panorama Cache），为动作专家提供全局空间上下文。
  - **动作专家**：基于VLM缓存与全景缓存的组合（`Ct = [Cvlm_t; Cpano_t]`），采用**条件流匹配（Conditional Flow Matching）** 预测连续动作块（32步），训练目标为：
    `L = E[||vact_θ(xτ, τ|Ct) − u(xτ|a)||²]`。

### 3. 实验设计

- **数据集**：使用自建的**全景感知移动操作数据集**，包含4个真实世界任务、800条成功演示轨迹（每任务200条）、约5.5小时、50万同步帧（25Hz采样），同步记录局部RGB（前方+双腕）、顶部360度全景（ERP格式）、本体感觉状态和17维全身动作。
- **任务设定（Benchmark）**：
  - **Move Pen**：将笔放入笔筒，目标位于前/左/右。
  - **Move Block**：将积木移至前方区域，积木位于左/右/双侧。
  - **Open Curtain**：打开两侧窗帘，需左右顺序交互。
  - **Wipe Table**：沿长桌擦拭污渍并将抹布放回原位，空间范围最长。
- **对比方法（3个受控基线）**：
  - **π0.5**：仅使用局部相机，SigLIP编码，无全景。
  - **π0.5 w/ Pano**：将ERP全景图直接作为附加图像输入，用同一个SigLIP编码器处理。
  - **π0.5 w/ Stacked Pano**：将全景重投影为3个互隔120°的透视图合并为拼接图像，再输入原π0.5架构。
  - **PanoVLA（本文模型）**：MTPano全景编码器 + 全景专家。
- **评估协议与指标**：每任务15次闭环真实机器人试验，单次不间断运行（失败阶段不手动重置），报告**阶段完成率（SCR）** 和**端到端成功率（SR）** 两个指标。

### 6. 主要结论与发现

- PanoVLA在四任务上平均SCR达**91.3%**、SR达**73.4%**，较π0.5基线（SCR 58.6%、SR 30.0%）大幅提升，证明**全景空间上下文能有效提升移动操作的空间理解与闭环执行性能**。
- **全景接入方式比是否使用全景更重要**：直接添加ERP图像（π0.5 w/ Pano）虽部分有效但增益不稳定；透视重投影（Stacked Pano）在操控密集阶段有收益但可能破坏跨视角连续性；专用全景编码器+全景专家的设计在全任务上取得一致最优。
- **PanoVLA的优势在多阶段、长时程任务中更明显**（如Wipe Table任务中，基线在最后阶段大幅失败，而PanoVLA保持稳定的全局一致性）。
- 模型设计选择：100M专家规模与MTPano全景编码器均为经验最优。
