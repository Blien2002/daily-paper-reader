## 摘要
世界动作模型通过联合建模动作和未来观测来提升机器人策略学习。然而，仅以任务提示和观测上下文为条件进行未来预测，可能会捕获通用任务进程，而非所执行动作的具体后果。我们提出了SelfWAM，一种基于模态专业化Transformer混合架构的统一自接地世界动作模型，该模型联合预测动作、动作条件下的未来RGB帧以及机器人自遮挡掩码，从而将未来预测接地于机器人可见身体及其动作引发的运动。在联合训练过程中，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持仅基于动作的快速推理路径不变。为了将视频学习聚焦于动作相关的视觉变化，我们使用针对未来机器人自遮挡掩码预测的提示特定目标，这消除了外观细节，并提供了一个其时间演变与条件动作紧密耦合的目标。总之，干净动作条件化和未来自遮挡掩码监督使未来预测更直接地反映执行动作如何改变机器人可见运动及周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生了更具动作敏感性的未来预测，并保持了快速的策略推理，同时提升了策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

## 论文核心问题与研究动机

- **背景**：世界动作模型（WAM）通过联合建模动作和未来观测来提升机器人策略学习，近期如 FastWAM 等工作表明，大部分收益可以在推理时不生成未来视频的情况下实现，仅将未来视频预测作为联合训练目标。
- **核心问题**：现有 WAM（尤其 FastWAM）的未来视频预测仅以当前观测和任务提示为条件，**未利用产生该未来的已执行动作**。这导致辅助目标退化为预测“通用任务进展”，而非区分不同动作的具体视觉后果；同时，RGB 未来预测被物体外观、纹理、光照等与动作弱相关的细节主导，缺乏对机器人自身可见运动的直接监督。
- **研究意义**：面向策略的世界模型不仅要回答“接下来会发生什么”，还要回答“在特定动作下什么会改变、在哪里改变、机器人身体如何介导这些变化”。SelfWAM 旨在将未来预测明确接地于机器人可见身体及其动作引发的运动，实现**自接地的动作条件未来预测**，同时不牺牲部署时的推理效率。

## 方法论

### 1. 总体框架
- 基于**模态专业化混合 Transformer（MoT）**架构，包含两个流：
  - **视频流**（预训练视频扩散主干，WAN2.2-5B）：处理当前观测编码和带噪的未来视频潜在表示。
  - **动作流**（轻量级动作专家，由视频主干参数插值初始化）：处理带噪的未来动作令牌，用于策略推理。
- 两个流通过**混合注意力（mixed attention）**耦合，语言指令和本体感觉特征同时调节两个流。

### 2. 关键设计一：非对称信息流 / 干净动作条件化
- 训练时，为演示动作创建**第二个干净副本**，经相同动作分词器和动作块编码，赋予干净去噪时间步 t=0，时间位置编码与噪声动作令牌对齐。
- 注意力模式设计（核心）：设 O 为当前上下文令牌、Ã 为带噪未来动作令牌、A 为干净动作令牌、Ṽ 为带噪未来视觉令牌，注意力关系为：
  - Q_Ã → {O, Ã}（动作预测不能看到干净动作或未来视觉）
  - Q_Ṽ → {O, Ṽ, A}（未来视觉可看到干净动作，实现动作条件化）
  - Q_A → {O, A}
- 该非对称设计**防止目标泄漏**：策略路径无法从干净动作副本或未来视觉表示中恢复其预测目标；部署时去掉干净动作与未来视觉流后，**推理计算图与纯动作推理完全一致**。
- 可选 rollout 时，可将策略采样或候选动作插入干净动作槽，使视频流变为动作条件世界模型。

### 3. 关键设计二：未来机器人自掩码预测
- 同一视频主干复用两种输出域：**未来 RGB** 和**未来机器人自掩码**，通过不同输出提示词区分，共享相同的时空令牌布局、噪声调度、位置编码和注意力模式。
- 自掩码目标去除了外观和背景变化，直接监督机器人可见身体的运动，其时间演变与条件动作紧密耦合，提供更聚焦的动作特定具身动力学学习信号。
- 自掩码实例**不参与动作监督**，仅为视频主干提供世界模型目标；策略目标只计一次。

### 4. 训练目标
- 使用标准的流匹配目标，总损失：
  - **L = λ_act · L_act + λ_video · L_rgb/mask**
  - 实验设置 λ_act = 1, λ_video = 1，RGB 与自掩码实例采样比 9:1。

### 5. 部署
- 仅执行动作推理路径：编码当前上下文 → 轻量级动作专家迭代去噪动作块（10 步）→ 执行前 24 个动作 → 重规划。干净动作和未来视频令牌不实例化。

## 主要结论

1. **动作条件化显著改善未来预测**：相比观测条件的 FastWAM，SelfWAM 的 LPIPS 从 0.0636 降至 0.0429，FVD-I3D 从 45.92 降至 34.55，PSNR 从 29.24 dB 升至 32.79 dB。
2. **动作敏感性显著增强**：WorldArena 上 Action Following 从 FastWAM 的 0.0000 提升至 SelfWAM 的 0.0184；方向性扰动与连续插值实验均显示 SelfWAM 的未来预测随动作变化而相应移动，而基线几乎不变。
3. **策略性能提升**：RoboTwin 2.0 上 SelfWAM 平均成功率 92.62%，优于 FastWAM 的 91.84% 及所有其他基线；随机化环境下的增益更明显（93.08% vs. 91.86%）；真实机器人 4 个任务平均成功率 95%，优于 FastWAM（85%）和 π0.5（90%）。
4. **推理代价几乎不变**：动作推理延迟仅增加 0.97%，联合动作+视频延迟增加 1.36%，峰值显存无变化。
5. 消融表明：干净动作条件化单独引入时性能略降但影响有限；叠加自掩码监督后全面超越 FastWAM，说明**自掩码提供互补的具身聚焦训练信号**是性能提升的关键。

## 优点

- **问题定义精准且动机充分**：清晰指出 WAM 中“动作未参与未来预测”这一关键缺陷，并系统论证了该缺陷的理论后果。
- **架构设计优雅且工程可取**：非对称注意力在统一架构中实现动作条件化与防泄漏，干净动作条件可通过简单约定复用为 rollout 候选动作输入。
- **自掩码目标新颖且有效**：将机器人自掩码作为第二输出域（非独立专家），去除外观干扰、聚焦具身运动，与 RGB 预测形成互补；该目标同时服务于未来预测和策略学习。
- **训练/部署一致性保障**：部署时计算图与训练时策略路径完全一致，确保训练-推理无偏。
- **实验验证全面，动作敏感性分析深入**：从保真度、敏感性、消融、效率多个维度验证了设计意图。
- **细节设计周到**：如自掩码实例不参与动作监督（避免策略目标重复计数）、RGB/自掩码共享时空布局、动作路径一致性诊断（最大 NRMSE ≈ 1e-5 / 余弦距离 ≈ 6e-11）等。

## 不足与局限

- **真实实验规模有限**：仅 4 个任务、每任务 10 次试验，统计置信度偏低，无法检验任务间差异的显著性。
- **未来预测评估标准不足**：275 条轨迹的保真度评估使用了训练集子集，作者自己也澄清“不应视为留出视频泛化测试”；LPIPS/PSNR 等参考指标不直接反映动作响应正确性。
- **WorldArena 一致性指标的解释力有限**：高一致性可能来自近乎静态的预测，需联合动作敏感性解读。
- **未建模接触/力/遮挡交互**：作者承认 SelfWAM 不显式建模接触力或被遮挡交互，对接触丰富的操作任务覆盖不足。
- **训练成本较高**：64 块 A800 训练约 30 小时，对一般研究团队复现门槛较高；依赖 WAN2.2-5B 大型预训练主干和 RobotSeg 掩码生成，引入额外依赖。
- **潜在偏差风险**：真实机器人掩码由 RobotSeg 自动生成，分割错误可能引入监督噪声；场景随机化下的增益集中于部分任务（如 Open Microwave、Hanging Mug），平均增益可能掩盖任务间的不均衡。
- **消融设计细节有限**：仅报告了两种组件的开关，未深入分析条件化强度、掩码采样比例或自掩码监督的权重对性能的影响。
