## 摘要
视觉-语言-动作（VLA）策略在机器人操作中表现出强大的性能，但仍然容易受到运行时干扰的影响，这些干扰会破坏视觉观察、机器人状态和执行动作之间的时间对齐。我们提出了ActFovea，一个即插即用的防护框架，无需重新训练或修改底层VLA策略即可检测并缓解此类故障。ActFovea利用机器人运动学、本体感觉状态和近期动作来构建动作条件化的中央凹区域，该区域保留接触相关区域和预测运动走廊，同时抑制与任务无关的视觉内容。它通过评估视觉运动和观察新鲜度是否与几何、本体感觉和动作转换保持一致来检测运行时风险。对于可恢复的干扰，ActFovea构建针对特定干扰的候选观察，并在验证由此产生的动作块后接受恢复。当过时或重放的观察使得可靠恢复不可能时，它调用有界的安全失败程序。在多个LIBERO套件中对$\pi_0$进行闭环评估时，ActFovea在局部视觉覆盖下的成功率从49.3\%提高到90.3\%，缩小了与干净性能差距的93.7\%。它还在动作漂移和视觉延迟下分别将成功率提高了7.0和9.8个百分点，同时保持了干净任务性能。在冻结观察重放下，ActFovea在所有试验中都触发了及时的安全失败，没有未受保护的失败。这些结果表明，时空视觉-动作一致性为VLA策略的运行时防护提供了有效基础。

## Abstract
Vision-language-action (VLA) policies achieve strong performance in robotic manipulation but remain vulnerable to runtime disturbances that break the temporal alignment among visual observations, robot states, and executed actions. We introduce ActFovea, a plug-and-play safeguarding framework that detects and mitigates such failures without retraining or modifying the underlying VLA policy. ActFovea uses robot kinematics, proprioceptive states, and recent actions to construct action-conditioned foveated regions that retain contact-relevant areas and predicted motion corridors while suppressing task-irrelevant visual content. It detects runtime risks by evaluating whether visual motion and observation freshness remain consistent with geometric, proprioceptive, and action transitions. For recoverable disturbances, ActFovea constructs disturbance-specific candidate observations and accepts a recovery only after verifying the resulting action chunk. When stale or replayed observations make reliable recovery impossible, it invokes a bounded safe-failure procedure. In closed-loop evaluations of $π_0$ across multiple LIBERO suites, ActFovea increases success under localized visual overlays from 49.3\% to 90.3\%, closing 93.7\% of the gap to clean performance. It further improves success under action drift and visual delay by 7.0 and 9.8 percentage points, respectively, while preserving clean-task performance. Under frozen-observation replay, ActFovea triggers timely safe failure in all trials, with no unprotected failures. These results demonstrate that spatiotemporal visual-action consistency provides an effective basis for runtime safeguarding of VLA policies.

## 二、论文提出的方法论

### 核心思想
ActFovea 不依赖奖励信号、模拟器对象状态、分割标注或扰动先验知识，仅依靠运行时可观测的视觉历史、本体感受状态、动作历史和机器人运动学信息，构建"期望的物理演化"作为参照，再检测实际观测与之的一致性偏离。

### 关键流程与公式

**1. 动作条件化中央凹注视（Action-Conditioned Foveation）**
- 不同于以图像几何中心为基准的传统中央凹，ActFovea 的动态中央凹区域随机器人运动学与动作历史实时移动。其保留区域（preserve mask）由**预测接触中心**（projected contact center）和**预测运动走廊**（projected motion corridor）组成：
  M_vt = Dilate(M^c_v,t ∨ M^Γ_v,t, r_m)  （公式2）
- 对外部背景施加编辑操作（归一化、高斯平滑、色彩灰度混合等）：
  Ĩ_vt = (1 − α B̄_vt) ⊙ I_vt + α B̄_vt ⊙ E(I_vt)  （公式3）
- 该操作保留了接触邻域与运动走廊，同时降低与任务无关背景的敏感度。

**2. 一致性监控与风险估计**
- 综合几何一致性（观测中心与投影接触中心的距离）、动态一致性（预测与观测图像位移的方向和幅度一致性）、时间证据（时间戳健康度、局部运动缺失、滞后估计、全局重放相似性）等多维度分数，形成加权聚合的风险指标：
  R_t = clip(β r̄_t + (1−β) r_t + p_cam_t + p_lag_t + p_cal_t, 0, 1)  （公式4）
- 一个确定性路由器（deterministic router）将证据分类为：时间延迟、动作漂移、不可恢复冻结、一致/未知等状态。
- 局部视觉覆盖（localized overlay）证据需要满足多帧稳定性和多视角一致性才被接受为空间扰动。

**3. 一致性引导的恢复与动作验证**
- 对可恢复扰动，构建候选观测库：原始观测路径避免不必要的修改，中央凹路径使用公式3处理，有限视觉滞后路径则对图像进行基于运动学参照的平移校正。
- 局部覆盖采用基于光流对齐和去混合（deblending）的恢复：
  X̂_vt = clip((P_vt − α̂_vt Q̂_vt) / (1 − α̂_vt), 0, 255)  （公式5）
- 对每个候选观测，让VLA策略产出动作块，并由验证器评分：
  V_k = clip(w^T u_k + b_k, 0, 1)  （公式6）
- 验证器衡量首动作方向、端点方向、动作幅度、平滑度、时域长度、块漂移等，选择兼具高验证分和合适执行模式的候选。

**4. 风险自适应执行与安全失败**
- 两阶段仲裁：一致性监控器决定执行/阻尼/缩短时域/保持，动作验证器决定正常执行/短时域执行/伺服恢复/安全失败，最终合成：
  â_mot_t,i = λ_mon_t λ_ver_t a*_mot_t,i, i < h_t, h_t = min(h_mon_t, h_ver_t)  （公式7）
- 当冻结观测重放被确认（持续陈旧、无可恢复新鲜证据），ActFovea 关闭恢复通道，锁存保持状态，执行有界运动抑制（可能前置一个裁剪的反向动作），实现**有界安全失败**——即快速终止控制而不产生无界运动。

## 六、论文的主要结论与发现

1. **统一防护可行**：基于时空视觉-动作一致性的统一框架，可以在不修改 VLA 策略的前提下同时处理空间视觉覆盖、有限视觉延迟和动作块漂移三类扰动。
2. **可恢复性区分有效**：ActFovea 能够正确区分"可恢复的扰动"（有限延迟、局部覆盖、动作漂移）与"不可恢复的失效"（冻结观测重放），并采取截然不同的应对策略。
3. **量化效果**：
   - 局部视觉覆盖下，成功率从 49.3% 提升到 90.3%，恢复受损性能的 **93.7%**；
   - 动作漂移下，成功率从 83.1% 提升到 90.1%（+7.0 个百分点）；
   - 视觉延迟下，成功率从 76.2% 提升到 86.0%（+9.8 个百分点）；
   - 干净环境下性能保持（93.8% vs. 基线 93.0%）。
4. **有界安全失败有效**：冻结观测重放下，2,000 个测试 episode 全部实现了"及时安全失败"，平均仅执行 2.0 个有界动作步骤（累积运动范数 0.326），无任何未受保护失败。相比之下，无安全失败机制时控制器在检测后仍执行了 259.2 个动作、累积运动范数达 241.98。
5. **组件分工明确**：观测恢复（候选库 + 候选扩展）是空间覆盖恢复的核心；动作验证是时间延迟和动作漂移恢复的核心。单一固定策略（如固定短时域、时间戳保持）无法同时应对多种扰动。

## 七、优点

1. **统一的运行时防护框架**：不针对于某一种特定攻击/扰动，而是基于"一致性"这一共性失效本质构建统一防护，具有较好的通用性。
2. **即插即用、策略冻结**：兼容现有 VLA 模型，不需要训练目标、参数优化或策略内修改，便于迁移到已有部署系统中。
3. **动态中央凹设计合理**：以机器人运动学和动作历史为锚点动态调整保留区域，比固定 ROI 或仅关注接触点的静态方法更能适应任务阶段变化（从接近到抓取到放置）。
4. **区分"恢复"与"安全失败"**：这一区分是部署安全的本质要求——既避免过度保守抑制合法行为，也避免在失去感知基础后盲目恢复。
5. **消融设计细致**：定量厘清了各组件（威胁识别、恢复库、候选扩展、动作验证）在不同扰动下的独立贡献，为后续研究提供清晰指引。

## 八、不足与局限

1. **缺乏真实世界验证**：全部实验均在 LIBERO 模拟环境中完成，合成的扰动模式（如固定光流对齐、checker overlay）与真实物理世界中的传感器噪声、遮挡、光照变化存在差距，难以直接验证在实际机器人部署场景中的有效性。
2. **模型覆盖单一**：仅评估了 π0 一个 VLA 模型，未验证对其他 VLA 架构（如 OpenVLA、RT-2、Octo）的可迁移性。
3. **超参数与阈值依赖**：公式中的权重（w、β）、检测半径（r_c、r_Γ）、编辑强度（α）等多个超参数均为固定实现常量，未提供自动选择方法或敏感性分析，可能影响在异构任务/环境上的泛化性。
4. **计算开销未量化**：ActFovea 涉及光流计算、多候选策略推理（多次调用 VLA）和图像恢复操作，论文未报告推理延迟增加的具体数值，"实时性"存疑。
5. **安全失败机制的边界有限**：论文明确指出"形式化的碰撞避免保证不在此机制范围内"，当前的安全失败仅是运动抑制，尚不能作为完整的安全保证。
6. **扰动类型覆盖有限**：没有验证在语义级、自然语言注入攻击、多扰动耦合叠加等更复杂扰动场景下的表现。
