## 摘要
本文介绍了一种模块化推理框架，将流匹配生成模型与形式化控制屏障函数（CBF）安全保证相结合。与现有方法对模型最终输出应用外部安全过滤器不同，我们的方法修改模型内的流匹配去噪过程，以固有地生成安全轨迹。通过采用平滑的对数-求和-指数聚合屏障，我们在整个动作片段上强制执行安全性。这种聚合屏障确保计算开销增加最小，且不改变模型的语义意图。我们表明，在所提出的框架内，生成的分布与目标分布之间的2-Wasserstein距离保持有界。我们的方法无需特定于安全的数据集或昂贵的模型重新训练，为安全推理提供了通用解决方案。我们在两个机器人操作平台和一个2D导航基准上验证了该方法，确认我们的框架实现了可靠的安全性，且不会降低模型成功率。

## Abstract
This article presents a modular inference framework that integrates Flow Matching generative models with formal Control Barrier Function (CBF) safety guarantees. Unlike existing methods that apply external safety filters to a model's final output, our approach modifies the Flow Matching denoising process within the model to inherently generate safe trajectories. By employing a smooth Log-Sum-Exponential aggregate barrier, we enforce safety over entire action chunks. This aggregate barrier ensures a minimal increase in computational overhead and does not alter the semantic intent of the model. We show that, within the proposed framework, the 2-Wasserstein distance between the generated distribution and the target distribution remains bounded. Our method eliminates the need for safety-specific datasets or costly model retraining, providing a versatile solution for safe inference. We validate the approach on two robotic manipulation platforms and a 2D navigation benchmark, verifying that our framework achieves reliable safety without degrading the success rate of the model.

- **论文意图**：提出一种**内生式（intrinsic）安全推理框架**，在不需要额外安全数据集、不需要重训练的前提下，通过在Flow Matching去噪过程中嵌入CBF约束，使VLA模型生成的整段动作轨迹**内在地满足安全条件**，同时不损害模型的任务成功率和语义意图。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

#### 核心思想
将VLA的流匹配去噪过程视为一个连续时间ODE系统，在去噪过程中施加基于CBF的安全约束（即CBF-QP），使每一次迭代的流方向被“安全地”修正（最小幅度的修正），从而让最终生成的动作块整体满足安全性。

#### 关键技术细节

**(1) 动作块的安全性定义（Definition 2）**
- 动作块 z = [q₁, q₂, …, q_H] 安全当且仅当所有中间状态 q_i 均满足 h(q_i) ≥ 0。
- 直接使用 min 算子会破坏 CBF 的光滑性，因此引入 **Log-Sum-Exponential (LSE) 平滑聚合函数**：

```
h(z̄) = −(1/κ) ln(Σ_{i=t}^{t+H} e^{−κ·h(q_i)})
```

- 理论性质（Theorem 2）：该函数对 min 算子给出**保守下界逼近**，即：
  min h(q_i) − ln(H)/κ ≤ h(z̄) ≤ min h(q_i)
  - κ 控制逼近精度：κ 越大越接近 min，但安全裕度越小。

**(2) 屏障增强流匹配（Barrier-Enhanced Flow Matching）**
- 修改原始流匹配ODE：dψ_s/dτ = v(τ, ψ(z,τ)) + δ_s，其中 δ_s 为最小安全修正项。
- 通过求解以下QP（二次规划）获得 δ_s：

```
δ_s = argmin ½‖δ‖²
s.t. (∂h/∂z)(v_θ(τ,z) + δ) ≥ −α h(z)
```

- 该QP的闭式解为：

```
δ_s = ReLU(−αh(z) − ∇_z h(z)·v_θ(τ,z)) · ∇_z h(z) / ‖∇_z h(z)‖²
```

- 主要优点：
  - 只对不满足 CBF 约束的方向进行修正，最小干预。
  - 不改变模型的语义意图和行为规划能力。

**(3) 分布偏移分析（Theorem 3 & Corollary 1）**
- 基于Benton等人（[27]）的流匹配误差界理论（Assumptions 1–3，即L²逼近误差有界、唯一解存在、局部Lipschitz连续性），证明：
  - 加入安全修正 δ_s 后，生成分布的 2-Wasserstein 距离**仍保持有界**，即不会显著偏离目标分布。
  - 修正后的向量场 v̂_θ = v_θ + δ_s 仍满足 Lipschitz 条件，误差界以常数倍数膨大但有上限。

**(4) 可证明的安全保证（Theorem 4）**
- 设从 τ=0 到 τ=τ_s 期间（未施加滤波阶段）的最坏情况屏障衰减率为 M，则最终生成动作块的屏障值为：
  h(ψ(z, 1.0)) ≥ (h₀ − M·τ_s)·e^{−α(1−τ_s)}
- 只要初始噪声是安全的（h₀ > 0）且 τ_s ≤ h₀/M，就能保证全部去噪过程的安全性。
- 在实践中，减少 τ_s 或增大 α 都能放宽充分条件。

**(5) 速度约束与轨迹平滑**
- 引入稀疏矩阵 D（差分矩阵）构造有限差分关节速度：
  - v_min ≤ D·(z̄ + δ)·Δt ≤ v_max
- 最终QP（式19）包含三项：
  - 最小干预项（½‖δ‖²）
  - 平滑/最小骤变项（λ·‖D(z̄ + (v_θ + δ)Δτ)‖²）
  - 安全约束 + 速度约束

**(6) 屏障函数实例**
- 壁面屏障：h(q) = ⟨n̂, p_ee⟩ − d（防止末端执行器越过平面）
- 球形屏障：h(q) = ‖p_ee − p_center‖² − r²（防止进入球体禁区）
- 均为纯运动学函数，不依赖系统动力学知识，易于实际部署。

#### 推理算法（Algorithm 1）流程概要
1. 输入图像、语言指令、超参数（κ, α, τ_s）；
2. 从Beta分布采样初始噪声；
3. 循环去噪（τ=0→1，步长 Δτ）：
   - 用VLA计算原始流向量 v_θ；
   - 当 τ ≥ τ_s 时：计算 h(q_i)、∇h(q_i)，构建LSE聚合屏障，求解QP获得安全修正 δ_s；
   - 否则 δ_s = 0；
   - 更新动作块：z ← z + (v_θ + δ_s)·Δτ；
4. 输出最终安全动作块。
