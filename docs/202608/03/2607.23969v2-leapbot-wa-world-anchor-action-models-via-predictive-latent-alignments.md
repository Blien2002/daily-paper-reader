## 摘要
世界动作模型（WAMs）已成为具身智能的一种强大范式，但对像素级视频生成的普遍依赖造成了根本性瓶颈。强制模型重建与任务无关的视觉细节会消耗表征能力，并使策略容易受到视觉干扰物的影响。在本文中，我们提出了LeapBot-WA，它通过将联合嵌入预测架构（JEPA）作为世界锚点，为WAMs建立了一种新颖的预测-潜在范式。与传统对视觉合成的依赖不同，LeapBot-WA将世界建模的核心转向预测性语义对齐，直接在潜在基础空间中提取抽象的物理动力学。为了弥合非高斯预测特征与扩散先验之间的模态差距，我们引入了各向同性语义自编码器（ISAE），它将锚点的潜在空间重塑为适合扩散的流形，以防止流形外漂移。此外，我们设计了一种非对称混合Transformer（MoT）架构。在训练期间，锚点扩散Transformer作为特权动力学专家来指导动作扩散Transformer；在推理时，这个重型动力学分支被剪枝，从而实现零开销执行。LeapBot-WA在LIBERO上的预测模型中达到了最先进的性能，并且在无需大规模轨迹预训练的情况下，在RoboTwin 2.0上匹配了顶级生成式WAMs。它还进一步展示了对未见环境的卓越零样本鲁棒性以及成功的真实世界迁移，为可扩展的机器人控制建立了一种高效且稳健的以潜在为中心的范式。代码：https://github.com/LeapWM/leapbot-wa。

## Abstract
World Action Models (WAMs) have emerged as a powerful paradigm for embodied intelligence, yet the prevailing reliance on pixel-level video generation creates a fundamental bottleneck. Forcing models to reconstruct task-irrelevant visual details dissipates representational capacity and renders policies vulnerable to visual distractors. In this paper, we propose LeapBot-WA, which establishes a novel Predictive-Latent paradigm for WAMs by operationalizing the Joint-Embedding Predictive Architecture (JEPA) as a World-Anchor. Departing from the traditional reliance on visual synthesis, LeapBot-WA shifts the core of world modeling to Predictive Semantic Alignment, extracting abstract physical dynamics directly within a latent foundation space. To bridge the modality gap between non-Gaussian predictive features and diffusion priors, we introduce the Isotropic Semantic Autoencoder (ISAE), which reshapes the anchor's latent space into a diffusion-friendly manifold to prevent off-manifold drift. Furthermore, we design an Asymmetric Mixture-of-Transformers (MoT) architecture. During training, an Anchor Diffusion Transformer acts as a privileged dynamics expert to guide the Action Diffusion Transformer; at inference, this heavy dynamics branch is pruned, enabling zero-overhead execution. LeapBot-WA achieves state-of-the-art performance among predictive models on LIBERO and matches top-tier generative WAMs on RoboTwin 2.0 without requiring large-scale trajectory pre-training. It further demonstrates superior zero-shot robustness to unseen environments and successful real-world transfer, establishing a highly efficient and robust latent-centric paradigm for scalable robotic control.   - 机器人操控真正需要的是**抽象的物理动力学知识**（如物体在干预下如何变化），而非重建纹理、阴影、光照等任务无关的视觉细节。
  - 像素级重建浪费大量表征容量，使策略对视觉干扰物高度敏感，难以泛化到新环境。
  - 单纯压缩到潜在空间也不足够——紧凑性不等于语义抽象性，且预测特征（非高斯、高结构化）与扩散模型（需要各向同性先验）之间存在严重分布失配，导致流形外漂移。
  - 现有框架将世界建模与策略执行紧耦合，部署时仍依赖生成分支，导致对视觉干扰和域偏移脆弱。
- **论文的立场**：高质量动作策略**不需要**像素级世界生成。LeapBot-WA 将世界建模的核心从视觉渲染转向**预测性语义对齐**，直接从潜在基础空间中提取抽象物理动力学，建立了高效、鲁棒的"预测-潜在"（Predictive-Latent）范式。

## 2. 论文提出的方法论

### 2.1 总体架构

LeapBot-WA 采用双路径架构，包含两条核心管线：

- **表示管线（Representation Pipeline）**：由 Predictive Anchor（微调后的 JEPA 模型）驱动，从原始观测提取高层语义 token。
- **生成管线（Generative Pipeline）**：由 Asymmetric MoT（非对称混合 Transformer）驱动，在扩散友好潜在空间中进行联合流匹配。

### 2.2 核心组件与关键技术

#### （1）Predictive Anchor（预测锚点）

- 使用大规模预测基础模型 **JEPA**（V-JEPA 2.1）作为 World-Anchor，经 LoRA 域自适应微调，从机器人轨迹中提取抽象物理动力学。
- 特点：无需像素重建，直接将通用物理先验注入控制环路；语义表征关注状态转换而非任务无关外观。

#### （2）Isotropic Semantic Autoencoder（ISAE，各向同性语义自编码器）

- **目的**：弥合非高斯预测特征与扩散先验之间的模态差距，防止联合流匹配时的离流形漂移。
- **结构**：给定语义 token F(v)（来自相机视角 v），编码器预测高斯后验：`μ, log σ² = Enc_φ(F(v))`，解码器重建原始语义 token：`F̂(v) = Dec_ψ(z(v))`。
- **三部分训练目标**：
  - **语义感知重建损失**：`L_rec = ||F̂ − F||₂² + λ_cos · E[1 − cos(F̂, F)]`（同时约束幅度与方向）；
  - **KL 散度正则**：`L_KL = D_KL(q_φ(z|F) ∥ N(0, I))`；
  - **切片各向同性高斯正则（SIGReg）**：`L_iso = R_SIGReg(z)`，显式惩罚聚合潜在分布偏离严格各向同性，防止维度坍缩。
- 总目标：`L_ISAE = L_rec + β·L_KL + λ_iso·L_iso`。

#### （3）View-Aware Residual Conditioning（视角感知残差条件化）

- ISAE 共享权重且无显式相机先验，为保留多视角空间感知能力，在 Anchor DiT 输入端添加可学习视角残差：
  `h^(v) = Proj(Norm(z^(v),t)) + e^(v)_view`，再进行时空位置编码。

#### （4）Intent-Conditioned Dynamics Modeling（意图条件动力学建模）

- Anchor DiT 分支以共享上下文 token c（包含语言指令与本体感觉状态）为条件，**独立于目标动作轨迹 a**。
- 刻意剥夺低层运动指令，防止语义表征坍缩为琐碎控制捷径，迫使模型学习**意图驱动的泛化物理先验**。

#### （5）Asymmetric Latent Dynamics Distillation（非对称潜在动力学蒸馏）

- 训练时语义序列和动作序列在共享扩散时间步 t 独立加噪：`z_t = (1−t)z + tϵ_z`，`a_t = (1−t)a + tϵ_a`。
- 关键设计是**非对称掩码注意力**：`Attn_asym(H)` 中的掩码 M 阻止 Anchor DiT 关注动作 token，而保留 Action DiT 对语义 token 的关注。Anchor DiT 充当"梦想家"（keys/values），Action DiT 充当"逆控制器"（queries）。
- 训练目标：`L_train = λ_a·L_action + λ_s·L_semantic + λ_f·L_future`，其中 `L_future` 为未来语义预测损失（SmoothL1）。

#### （6）零开销推理（Zero-Overhead Inference）

- 推理时完全剪除重型 Anchor DiT 动力学分支，仅从当前观测 o₀ 计算一次语义 token 作为 **专家缓存（Expert Cache）**：`H_s,cache = f_sem(o₀, c)`。
- Action DiT 在去噪过程中持续关注该静态缓存，既保留了语义引导，又实现了零额外开销的实时执行。

### 2.3 三阶段渐进训练范式

1. **Stage I（域自适应语义预训练）**：对 V-JEPA 2.1 编码器进行 LoRA 微调，利用五源机器人视频语料（多视角比例 7:3），保持基础参数冻结，优化时空掩码预测目标。
2. **Stage II（生成式潜在对齐）**：冻结编码器后训练 ISAE，在特征空间中完成（不使用任何像素级解码），将 1664 维非高斯 JEPA 空间映射到 96 维各向同性扩散友好空间。
3. **Stage III（非对称世界-动作联合扩散）**：冻结 V-JEPA 与 ISAE，联合训练语义状态扩散分支和动作策略分支。针对异构动作空间，采用维度特定投影头和源同质批处理策略。

## 7. 优点

- **范式创新**：首次将 JEPA 系统性地用作世界动作模型的世界锚点，真正绕开了像素重建瓶颈，建立了"预测-潜在"新范式。
- **ISAE 设计精巧**：通过 SIGReg 切片各向同性正则显式塑造扩散友好流形，解决了非高斯预测特征与扩散先验之间的根本性模态失配问题。
- **非对称 MoT 架构优雅**：训练时特权专家指导、推理时零开销剪枝的"非对称"设计，实现了世界建模能力与执行效率的兼得。
- **意图条件化设计**：刻意隔离动作轨迹、仅以意图/上下文为条件，防止语义坍缩为控制捷径，迫使模型学习真正泛化的物理先验。
- **训练范式系统化**：三阶段渐进训练（域适应→潜在对齐→联合扩散）有效避免了表示坍缩与模态对齐不稳定。
- **鲁棒性表现突出**：在视觉扰动、随机化和真实世界迁移中表现出色，强有力地支撑了核心论点（不需要像素生成）。
- **效率优势明显**：2.9B 参数、546ms 延迟，兼顾规模与实时性。

## 8. 不足与局限

- **依赖基础模型质量**：整体性能受限于底层 V-JEPA 表征的质量，若基础模型在特定物理场景上先验不足，框架本身无法完全弥补。
- **细粒度物理建模不足**：作者承认无法建模极精细的接触物理和高频触觉交互，这限制了其在精密装配等场景的应用。
- **LIBERO-10 长时程任务仍偏弱**：虽然取得预测类最佳（85.0%），但与像素空间 WAMs（如 ImageWAM 98.4%）相比仍有显著差距。
- **随机化泛化仍存疑**：在 LIBERO-plus 的 Robot 和 Layout 维度上相对较弱，说明对新机器人形态和复杂布局的泛化仍需改进。
