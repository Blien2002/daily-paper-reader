## 摘要
世界动作模型（WAMs）通过联合建模机器人动作和未来视觉动态，已成为一种有前景的范式。然而，它们对像素生成式未来监督的依赖，可能会将动作相关的状态转换与任务无关的视觉内容纠缠在一起，从而限制其在视觉分布偏移下的鲁棒性。我们发现了训练分布幻觉（Training-Distribution Hallucination），这是一种反复出现的现象，即基于视觉偏移观测的未来预测会产生训练域内容的幻觉，而非忠实于当前场景。一项受控的帧三元组诊断进一步表明，与Wan-VAE潜变量相比，DINOv3特征在视觉偏移下保持更稳定，同时能更好地保留任务状态差异。我们并非修正预测的未来，而是提出语义-时序世界动作模型（ST-WAM），通过使用DINOv3作为未来预测和历史检索的共享语义表示，同时保留细粒度的VAE动态，来提高动作鲁棒性。其双空间未来专家（DSFE）联合预测未来的VAE潜变量和DINO特征，而当前锚定意图检索（CAIR）在当前视觉-语言上下文下从近期DINO历史中检索任务相关证据。ST-WAM以端到端方式训练，无需额外的具身预训练或任务特定标注，且在推理时无需显式的未来生成。它在LIBERO上达到98.7%，在RoboTwin 2.0上达到92.8%；更重要的是，与Fast-WAM相比，它将零样本LIBERO-Plus性能提升了21.3个百分点，并将视觉偏移下的真实世界成功率从25.8%提高到61.5%，提高了一倍以上。这些结果表明，语义-时序建模有效补充了像素生成式动态，实现了鲁棒操作。

## Abstract
World Action Models (WAMs) have emerged as a promising paradigm by jointly modeling robot actions and future visual dynamics. However, their reliance on pixel-generative future supervision can entangle action-relevant state transitions with task-irrelevant visual content, limiting robustness under visual distribution shifts. We identify Training-Distribution Hallucination, a recurring phenomenon in which futures conditioned on visually shifted observations hallucinate training-domain content rather than remain faithful to the current scene. A controlled frame-triplet diagnosis further shows that DINOv3 features remain more stable across visual shifts while better preserving task-state distinctions than Wan-VAE latents. Rather than correcting the predicted futures, we propose Semantic-Temporal WAM (ST-WAM) to improve action robustness by using DINOv3 as a shared semantic representation for future prediction and history retrieval while retaining fine-grained VAE dynamics. Its Dual-Space Future Experts (DSFE) jointly predict future VAE latents and DINO features, while Current-Anchored Intent Retrieval (CAIR) retrieves task-relevant evidence from recent DINO history under the current visual-language context. ST-WAM is trained end-to-end without additional embodied pretraining or task-specific annotations, and requires no explicit future generation at inference. It achieves 98.7% on LIBERO and 92.8% on RoboTwin 2.0; more importantly, compared with Fast-WAM, it improves zero-shot LIBERO-Plus performance by 21.3 percentage points and more than doubles real-world success under visual shifts from 25.8% to 61.5%. These results demonstrate that semantic-temporal modeling effectively complements pixel-generative dynamics for robust manipulation.

- **整体含义**：问题关键不在于“WAM 能否预测未来”，而在于“未来应以何种表征方式服务于鲁棒控制”。语义-时序建模可以有效补充像素生成式动态，为视觉分布偏移下的操作任务提供新范式。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
利用 **DINOv3 作为共享语义表征**，在互补的两个时间方向上增强 WAM：
- **前瞻方向**：用 DINOv3 特征作为未来预测目标，监督任务相关的语义状态演化；
- **回溯方向**：用 DINOv3 历史特征作为任务进度证据，辅助当前动作生成。

保留 VAE 细粒度视觉动态，不修改或修正幻觉化的未来视频，而是在端到端 WAM 框架中融合语义与像素两种未来监督。

### 关键模块一：双空间未来专家（Dual-Space Future Experts, DSFE）

- **统一视觉-语义未来建模**：冻结 Wan2.2 VAE 编码视觉潜变量 zᵥ，冻结 DINOv3 编码逐帧语义特征 zₛ，二者共同建模未来状态。
- **三分支 Mixture-of-Transformers（MoT）**：
  - 三个分支：视觉未来 DiT（继承 Wan2.2 视频预训练）、语义未来 DiT、动作 DiT；
  - 每个分支保留独立参数与预测头，层间混合注意力使两个未来空间相互细化，动作分支整合当前双空间证据。
- **结构化跨分支注意力掩码**（非对称）：
  - 干净的当前 VAE/DINO token 可互相交互，但不能读取未来或动作 token；
  - 带噪的未来两个流可互相注意并读取当前锚点，但不能读取动作 token；
  - 动作 token 只能读取当前双流与自身，不能访问未来流；
  - 该设计防止未来目标信息泄漏到动作生成，同时允许推理时丢弃未来分支，保持高效部署。

### 关键模块二：当前锚定意图检索（Current-Anchored Intent Retrieval, CAIR）

- **当前语义查询生成**：用冻结 Qwen3-VL 提取当前观测与语言指令的最终层多模态隐状态 Hₜᵍ；通过一组可学习查询向量（N_I=8）经多头注意力压缩为当前语义 token Uₜ⁰，作为检索锚点。
- **语义历史检索**：用 DINOv3 对短历史 Hₜ（M=4 帧，取自 frame indices t-24、t-16、t-8、t-1）提取稠密 patch 特征，加时间嵌入后构成历史 token 序列 Rₜ；当前语义 token 作为 query，通过 L=2 层交叉注意力选择性检索与当前任务状态相关的历史证据。
- **意图注入**：检索后的 token 经输出投影注入动作专家上下文（C_a = [C_ℓ; P_p(s_t); I_t]），仅影响动作生成，不影响 DSFE 分支的上下文条件。

### 联合流匹配训练目标

- 定义三个分支目标：xᵥ = 未来 VAE 潜变量、xₛ = 未来 DINO 特征、xₐ = 动作块。
- 每个分支采样时间步 τᵣ 和高斯噪声 εᵣ，通过线性插值构造带噪输入：x_{r,τ} = (1-τ)xᵣ + τεᵣ；目标速度 uᵣ = εᵣ - xᵣ。
- 同步两个未来分支的时间步（τᵥ = τₛ = τ_f），动作分支独立采样 τₐ。
- 整体损失：L = λᵥLᵥ + λₛLₛ + λₐLₐ，其中 λ=(1.0, 0.02, 1.0)。
- 推理时退化为纯动作策略：a_{t:t+H-1} ~ π_θ(·|o_t, s_t, ℓ, H_t)，无需显式未来生成。

## 6. 主要结论与发现

1. **训练分布幻觉是视频生成式 WAM 在视觉偏移下的系统性缺陷**：70.6% 的预测案例表现出向训练域内容漂移的幻觉；两个代表性模型（LingBot-VA、Fast-WAM-Joint）均受此影响，导致零样本性能大幅下降。
2. **DINOv3 语义表征优于 VAE 潜变量作为共享表示**：在同状态稳定性上（0.904 vs 0.686 余弦相似度）和跨状态区分性上（95.2% vs 60.0%）均显著更优。
3. **语义-时序建模可有效提升鲁棒性**：ST-WAM 在 LIBERO 上达到 **98.7%**（最佳）、RoboTwin 2.0 平均 **92.77%**（最佳），同时在零样本 LIBERO-Plus 上以 **72.8%** 超过 Fast-WAM 达 **21.3 个百分点**；真实世界视觉偏移下成功率从 Fast-WAM 的 **25.8%** 提升至 **61.5%**，提升超一倍。
4. **VAE 与 DINO 未来表征互补而非可替代**：仅使用 DINO 未来（39.7% LIBERO-Plus）不如仅使用 VAE（51.5%），而双空间联合达到 66.4%，表明 DINO 不能替代 VAE 的细粒度视觉动态，二者缺一不可。
5. **显式语义未来预测是必要的**：即使保留语义 DiT 与混合注意力，但去除未来目标与损失，性能从 72.8% 降至 62.9%，说明未来语义监督本身是关键增益来源。
6. **当前锚定 + DINO 历史的检索方式缺一不可**：无锚定检索（56.5%）、仅 Qwen 当前语义（62.3%）、用 VAE 历史替代 DINO 历史（64.7%）均低于完整模型的 72.8%，且低于 Dual-Space w/o CAIR 的 66.4%，表明不当的历史表示甚至会损害性能。

## 8. 不足与局限

- **训练算力信息缺失**：未报告模型训练的 GPU 数量、型号与总时长，难以评估方法的资源可复制性。
- **真实世界评估范围有限**：仅在单一平台（Agilex Piper 单臂）上验证；未覆盖双臂操作、多机种迁移或非固定标称条件下的数据采集对扰动鲁棒性的影响。
- **视觉偏移类型有限**：真实世界测试集中在背景、光照、物体外观及其复合，未包含相机视角变化、传感器噪声、遮挡或动态场景变化，而 LIBERO-Plus 中相机与噪声扰动恰是 Fast-WAM 表现最差的维度（分别提升 39.0 和 41.8 个百分点），缺乏真实世界的对应验证。
- **对大规模预训练的依赖性未充分讨论**：ST-WAM 虽然无需“具身预训练”，但依赖 Wan2.2-TI2V-5B（视频生成预训练）、Qwen3-VL-4B（VLM）、DINOv3、T5 等多个大型基础模型，这些模型本身的预训练数据与任务领域密切相关，该隐式依赖可能影响结论的普适性。
- **延迟对比不够全面**：仅报告了 Fast-WAM 一个对比对象的推理时间，未给出与 π0 等 VLA 基线或 LaWAM 等方法的效率对比；且 1.24 倍开销的构成（CAIR 还是 DSFE）未做分解。
- **潜在公平性问题**：不同方法在 LIBERO-Plus 的对比中，部分基线使用了不同的微调或适配策略（如 π0-FAST 的 action tokenization、OpenVLA-OFT 的 post-training），虽作者注明“不使用微调”的政策，但基线的预训练数据规模与机器人经验不同，性能差距未必完全归因于方法本身的鲁棒性。
- **未探索超出视觉偏移的泛化**：作者在结论中承认未来工作将扩展至物理动力学变化和本体变化，但当前方法对这类偏移的有效性尚无验证。
