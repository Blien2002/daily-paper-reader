## 摘要
使用视觉-语言-动作（VLA）模型骨干的机器人操作系统通常仅使用一个 VLA 来执行任务。然而，单个 VLA 在不同任务状态和环境中的表现并不理想。我们提出了一种在执行过程中动态组合多个 VLA 策略的框架：逐步动作策略路由（SWAP）。SWAP 将策略路由形式化为离线强化学习问题，学习一个路由评判器，在当前观测下于每个决策步骤选择最合适的策略。SWAP 使机器人能够在线选择新的策略执行，而不是在整个回合中固定使用单一策略。我们在真实世界 DROID 操作任务和 LIBERO 仿真实验上评估了 SWAP。SWAP 相比固定策略执行和路由基线均有提升，真实世界任务成功率绝对提升最高达 33%，同时成功轨迹的机器人动作步长减少 28.3%。

## Abstract
Robot manipulation systems using Vision-Language-Action (VLA) model backbones typically use just one VLA for task execution. However, individual VLAs do not perform well across different task states and environments. We introduce a framework for dynamically composing multiple VLA policies during execution: StepWise Action Policy Routing (SWAP). SWAP formulates policy routing as an offline reinforcement learning problem, learning a routing critic that selects the most appropriate policy at each decision step given the current observation. SWAP enables robots to select new policies to execute online rather than committing to a single policy for the duration of an episode. We evaluate SWAP on both real-world DROID manipulation tasks and LIBERO simulation experiments. SWAP improves over fixed-policy execution and routing baselines, giving absolute improvements in real-world task success up to 33% while reducing successful trajectory robot action step length by 28.3%.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有机器人操控系统通常使用单一 VLA（Vision-Language-Action）策略执行整个任务。然而，单个 VLA 在不同任务状态、环境、执行阶段中表现并不一致：某些策略擅长自由空间运动，某些擅长精细操作或恢复行为。
- **核心问题**：能否在执行过程中**动态组合多个候选 VLA 策略**，而不是始终绑定单一策略？
- **整体含义**：论文提出“策略路由”（policy routing）问题，将策略选择本身视为一个决策问题，并给出一个离线强化学习框架 SWAP，在机器人执行过程中逐步选择最合适的 VLA 策略，以提升任务成功率和执行效率。

## 2. 论文提出的方法论

### 2.1 问题形式化

- 将机器人执行建模为 MDP：\(M=(\mathcal S,\mathcal A,P,r,\gamma)\)。
- 假设存在一个候选策略库 \(\Pi=\{\pi_1,\dots,\pi_K\}\)，每个 \(\pi_k\) 是预训练机器人控制器。
- 目标是学习路由策略 \(\phi(z_t\mid s_t)\)，其中 \(z_t\in\{1,\dots,K\}\) 表示第 \(t\) 步选择的策略索引。
- 实际执行的动作从被选策略采样：\(a_t\sim \pi_{z_t}(\cdot\mid s_t)\)。
- 优化目标为最大化长期回报：
  \[
  \arg\max_{\phi}\mathbb E_{\phi,\Pi}\left[\sum_{t=1}^T \gamma^{t-1}r(s_t,a_t)\right]
  \]

### 2.2 SWAP 核心思想

SWAP 将策略路由形式化为**离线强化学习**问题，学习一个 **routing critic**，根据当前观测估计每个候选策略的长期价值，并在部署时选择价值最高的策略。

- **离线数据集构建**：
  - 从每个候选策略收集成功和失败轨迹。
  - 不进行逐低层控制步路由，而是在 **chunk 级别**路由：每个 chunk 对应底层 VLA 输出的一组连续动作。
  - 每个路由 transition 为 \((o_t,z_t,r_t,o_{t+c},d_t)\)，其中 \(c\) 为 chunk 长度。
  - 奖励为稀疏二元奖励：成功后最终 transition 奖励为 10，失败为 0，中间 transition 奖励为 0。

- **离线评论家学习**：
  - 使用 **IQL（Implicit Q-Learning）** 训练两个 routing critics \(Q_1,Q_2\) 和一个状态价值函数 \(V\)。
  - 损失函数：
    \[
    \mathcal L_Q = \mathbb E_{(o_t,z_t,r_t,o_{t+c},d_t)\sim\mathcal D}
    \left[\sum_{i=1}^2 \left(Q_i(o_t,z_t)-\left(r_t+\gamma(1-d_t)V(o_{t+c})\right)\right)^2\right]
    \]
  - 采用双 Q 网络的最小值来抑制过估计。
  - 直觉：离线 RL 会为与成功结果相关的策略选择赋予更高价值，为失败轨迹中的选择赋予更低价值。

- **Routing Critic 架构**：
  - 使用冻结的 **Qwen2.5-VL-3B** 视觉-语言模型编码当前视觉观测和语言指令，得到 2048 维嵌入。
  - 将该嵌入与可学习的候选策略身份嵌入拼接，输入轻量 MLP 双 Q 网络，输出每个候选策略的标量 Q 值。
  - 同时维护一个价值网络 \(V\) 用于 IQL 训练。

- **测试时策略路由**：
  - 给定当前观测 \(o_t\)，对所有候选策略评估：
    \[
    z_t=\arg\max_z \min(Q_1(o_t,z),Q_2(o_t,z))
    \]
  - 执行被选策略的一个 chunk 动作，然后重复路由过程。

## 3. 实验设计

### 3.1 实验环境与数据集

- **真实世界 DROID 平台**：
  - 使用 Franka Panda 7-DoF 机械臂，多视角 RGB 相机（外部和手腕相机）。
  - 三个任务：
    1. Marker → Bowl（把标记物放入碗中）
    2. Cube → Cup（把方块放入杯子）
    3. Cube on Cloth → Bowl（把布上的方块转移到碗中）
  - 候选策略：Physical Intelligence 的 **π0、π0.5、π0-FAST**。
  - 其中 π0.5 和 π0-FAST 使用公开 DROID checkpoint 零样本；π0 由于零样本效果差，在小量数据上微调。

- **LIBERO 仿真**：
  - 使用 LIBERO-Spatial 子集以及更具挑战性的 LIBERO-Plus Spatial 子集。
  - 候选策略包括 **π0、OpenVLA、OpenVLA-OFT、OpenVLA-OFT no-wrist、OpenVLA-OFT+** 等变体。
  - 在 10 个 LIBERO-Spatial 任务中的 8 个任务上收集数据，保留任务 5 和任务 9 用于评估；同时在 LIBERO-Plus Spatial 上评估泛化能力。

## 6. 论文的主要结论与发现

- SWAP 在真实机器人任务上显著优于固定策略和随机路由：
  - 平均成功率从最优固定策略的 63.3% 提升到 **96.7%**，绝对提升最高达 33%。
  - 成功轨迹的平均动作步数从 269 步降至 **193 步**，减少 **28.3%**。
- 随机路由仅略微超过最优固定策略（66.7% vs 63.3%），说明“切换”本身有一定恢复作用，但 SWAP 的大幅提升主要来自**学习到路由策略**。
- SWAP 能够发现策略的阶段性优势：
  - 早期更多选择 π0-FAST 进行快速自由空间移动；
  - 接近和抓取物体时切换到 π0.5 进行精细操作；
  - 物体掉落或失败后，Q 值下降，SWAP 再次选择 π0.5 进行恢复。
- 在 OOD 干扰物场景中，SWAP 仍保持较高成功率（90% 和 80%），优于最优固定策略（40% 和 30%）。
- 在五策略 LIBERO 实验中，SWAP 达到 62.65% 成功率，远高于随机路由的 2.7%；并能有效忽略性能极差的 OpenVLA-Spatial 策略。
- 在“一个强策略 + 一个弱策略”的场景中，SWAP 能识别并主要使用强策略，不会因弱策略的存在而严重下降。

## 7. 优点

- **新颖的问题设定**：将多 VLA 策略动态组合形式化为策略路由，区别于传统的单一策略训练或 Mixture-of-Experts 联合训练。
- **离线 RL 与黑盒策略兼容**：候选策略保持冻结，仅训练路由 critic，因此可以灵活添加新策略而无需重新训练专家。
- **Chunk 级路由设计**：与 VLA 自身推理节奏一致，避免打断中间动作，不引入额外策略查询成本。
- **使用冻结 VLM 编码器**：利用强大预训练视觉-语言表征，使小规模离线机器人数据也能训练有效路由。
- **实验证据扎实**：在真实机器人和仿真中均验证，并分析了 Q 值、策略选择频率、路径长度等，提供可解释性。
- **泛化性强**：在未见干扰物和仿真 OOD 任务上仍能保持性能。
- **效率提升**：不仅提高成功率，还缩短成功轨迹长度，说明路由选择能减少无效或低效行为。

## 8. 不足与局限

- **候选策略规模有限**：真实世界仅 3 个策略，仿真为 2–5 个策略，尚未探索数十或数百个策略的大规模路由。
- **任务范围有限**：真实世界仅 3 个桌面短程任务，未覆盖长程、移动操作或更复杂任务。
- **奖励信号稀疏**：采用稀疏二元奖励，在长程任务中可能不足以有效训练路由 critic，可能需要中间子任务奖励。
- **未考虑成本**：路由目标只优化任务回报，未考虑推理延迟、计算或金钱成本；多策略在线查询可能带来系统部署负担。
- **OOD 策略质量稳定性**：路由 critic 学到的是训练分布上的策略偏好，若某个策略在训练分布中强但在 OOD 中弱，可能导致次优选择；例如在五策略实验中，π0 在训练分布中最强，但其 OOD 性能下降，限制了 SWAP 的 OOD 表现。
- **实验统计样本较小**：真实世界每个任务仅 10 次评测，缺少置信区间或显著性检验，结论的统计稳健性有待加强。
- **未明确算力细节**：论文未报告 GPU 型号、数量、训练时间，难以评估方法计算成本。
- **策略公平性问题**：真实世界实验中 π0 经过微调而其他策略为零样本，虽然不影响 SWAP 本身逻辑，但在解释单个策略对比时需谨慎。
