## 摘要
长时程组合操作对于真实世界机器人部署日益重要，其中单个任务涉及多个协调的子任务。现有的世界-动作模型（WAM）联合预测短时程视觉未来和动作，但通常缺乏显式的子任务级推理。我们提出视觉目标条件动作推理（ViGAR），一种将操作分解为视觉子目标规划器和子目标执行器的层次化框架。给定当前观测和全局指令，子目标规划器为下一个子任务预测视觉子目标。随后，子目标执行器以预测的子目标为条件，联合生成未来视觉轨迹和动作。两个组件共享预训练的世界模型表示，使任务级规划和动作生成能够受益于共同的物理知识。此外，我们的框架自然支持上下文学习：使用全局目标图像作为上下文，可以在不更新参数的情况下诱导不同的子任务分解和行为。在 RoboTwin Clean2Random 基准上，ViGAR 在 Clean 和 Random 设置下分别达到 82.00% 和 67.02% 的成功率，平均成功率比最强基线高出 12.86 个百分点。在五个组合任务和两个上下文学习任务上的真实机器人实验进一步证实了 ViGAR 的有效性。

## Abstract
Long-horizon compositional manipulation has become increasingly important for real-world robot deployment, where a single task involves multiple coordinated subtasks. Existing world-action models (WAMs) jointly predict short-horizon visual futures and actions, but typically lack explicit subtask-level reasoning. We propose Visual Goal-conditioned Action Reasoning (ViGAR), a hierarchical framework that factorizes manipulation into a visual subgoal planner and a subgoal executor. Given the current observation and global instruction, the subgoal planner predicts a visual subgoal for the next subtask. The subgoal executor then jointly generates future visual trajectories and actions conditioned on the predicted subgoal. Both components share a pretrained world-model representation, enabling task-level planning and action generation to benefit from common physical knowledge. Moreover, our framework naturally supports in-context learning: using a global goal image as context can induce different subtask decompositions and behaviors without parameter updates. On the RoboTwin Clean2Random benchmark, ViGAR achieves 82.00% and 67.02% success rates under the Clean and Random settings, respectively, surpassing the strongest baseline by 12.86 percentage points in average success rate. Real-world robot experiments on five compositional and two in-context learning tasks further confirm the effectiveness of ViGAR.

## 1. 核心问题与整体含义

- **研究背景**：长时程组合式操作任务（例如整理桌面、叠放碗碟）需要机器人连续完成多个协调的子任务，并能在场景、物体、布局变化时保持泛化，而非简单重放训练轨迹。
- **现有世界-动作模型（WAM）的局限**：WAM 通过联合预测短期未来视觉状态和动作，学习物理动作动态，具有较强的跨任务、跨环境泛化能力；但其通常只建模“下一步可能发生什么”，缺乏显式的任务级推理接口，难以组织跨子任务的长程行为。
- **核心问题**：如何在不牺牲 WAM 物理预测和泛化能力的前提下，赋予其显式的子任务级决策能力，并支持部署时通过上下文指定新任务。
- **核心思想**：将组合式操作分解为 **长期未来选择** 与 **短期未来实现** 两个阶段，即先显式预测下一个子目标的视觉图像，再基于该图像联合生成未来视频与动作。由此提出 **ViGAR（Visual Goal-conditioned Action Reasoning）** 框架。

## 2. 方法论

### 2.1 整体框架

ViGAR 由两个共享预训练世界模型表示的核心组件构成：

- **子目标规划器 \(G_\theta\)**：根据当前观测与全局指令，预测下一个子任务的视觉子目标图像。
- **子目标执行器 / 策略 \(\pi_\phi^{WAM}\)**：以预测出的子目标为条件，联合生成未来视觉轨迹与机器人的动作块。

两个组件均从 **Cosmos3-Nano**（16B-A8B 参数的全模态世界模型）初始化，共享物理知识表示。

### 2.2 子目标规划器

- **问题定义**：将子目标规划视为“图像编辑”任务：给定当前帧 \(o_t\) 和全局指令 \(\ell\)，生成目标子目标图像 \(g_i\)。
- **训练监督**：
  - 训练对 \((o_t, \ell, g_i)\) 从子任务分段后的机器人演示中构建；
  - 使用 **流匹配（flow matching）目标**训练，其中条件隐含变量为 \(z_t = \text{VAE}(o_t)\)，目标隐含变量为 \(x_0^g = \text{VAE}(g_i)\)；
  - 采用 **末端执行器 ROI 加权损失**：通过相机投影得到末端执行器附近的二值掩码，并在潜在空间面积池化后对损失进行加权，使监督集中在操作发生区域而非静态背景。
- **子目标前瞻规则（look-ahead rule）**：
  - 在子任务边界处，当前帧 \(o_t\) 可能同时与当前子任务末尾和下一子任务早期视觉相似，容易导致规划器混淆、回退到已完成子任务；
  - 因此将每个子任务最后 \(p\%\) 的帧的训练目标重定向为下一子任务的子目标 \(g_{i+1}\)，保证监督一致。
- **训练目标**：带 ROI 加权的流匹配损失
  \[
  \mathcal{L}_{\text{Plan}} = \mathbb{E}\left[\left\|\sqrt{w_i} \odot \left(G_\theta(x_\tau^g, \tau \mid z_t, \ell) - v_{\text{plan}}\right)\right\|_2^2\right]
  \]
  其中 \(v_{\text{plan}} = \epsilon - x_0^g\)。

### 2.3 子目标引导的世界-动作模型

- 策略 \(\pi_\phi^{WAM}\) 以当前观测 \(o_t\)、本体感觉状态 \(s_t\)、全局指令 \(\ell\)、预测子目标 \(\hat{g}_i\) 和元数据 \(\mu\) 为条件，联合预测未来视觉 \(O_{t+1}\) 和动作块 \(A_{t+1}\)。
- **联合流匹配训练**：对视觉和动作两个模态分别定义流匹配目标 \(v_{vid} = \epsilon_v - x_0^v\)、\(v_{act} = \epsilon_a - x_0^a\)，联合损失为
  \[
  \mathcal{L}_{\text{WAM}} = \mathbb{E}\left[\|\hat{v}_\phi^v - v_{vid}\|_2^2 + \|\hat{v}_\phi^a - v_{act}\|_2^2\right]
  \]
- **子目标注入方式**：
  - 比较了语义路由（视觉编码器 token 进入 reasoner 分支）和几何路由（VAE 编码后的干净潜在变量直接输入 generator 分支）；
  - 实验表明 **几何路由** 在 Clean 和 Random 条件下均更鲁棒，因此 ViGAR 采用几何路由；
  - 为区分子目标潜在变量与其他潜在 token，加入零初始化的可学习嵌入。
- **动作与视频预测设置**：动作块长度 \(H_a = 48\)，视频长度 \(H_v = 48\)，视频下采样率 4。

### 2.4 上下文任务指定（In-Context Learning）

- 将推理期上下文 \(C\) 实例化为 **全局目标图像 \(G\)**：即组合任务完成后应达到的终端世界状态。
- 训练时 \(G\) 是演示轨迹的最后一帧；推理时用户可提供新的全局目标图像，即使该组合未在训练中出现。
- 全局目标图像仅进入子目标规划器：
  \[
  \hat{g}_i \sim G_\theta(\cdot \mid z_t, \ell, G)
  \]
  下游策略 \(\pi_\phi^{WAM}\) 不直接接触 \(G\)，只通过 \(\hat{g}_i\) 间接受影响，因此无需参数更新即可改变子任务分解。

## 6. 主要结论与发现

- **模拟性能**：
  - ViGAR 在 Clean 达到 **82.00%**，Random 达到 **67.02%**，平均 **74.51%**；

  - 子目标前瞻规则和末端执行器 ROI 加权均有效，其中 ROI 加权贡献最大。

## 7. 优点

- **显式的视觉子目标作为任务级推理接口**：将长期任务分解为可预测的视觉目标，比纯文本子任务描述提供更强的空间约束。
- **与预训练世界模型深度结合**：子目标规划器和执行器共享 Cosmos3-Nano 表示，使任务级决策和物理动作生成共享同一物理知识。
- **自然支持上下文学习**：仅改变全局目标图像即可组合未见过的任务，无需参数更新或额外数据收集。
- **实现细节扎实**：提出前瞻规则解决边界混淆，ROI 加权聚焦操作区域，几何路由提高注入鲁棒性，均有消融验证。
- **模拟与真实机器人双重验证**：在 RoboTwin 和五个真实操作任务上均表现优于强基线。

- **高层任务分解与低层执行之间的耦合仍较松**：子目标规划器和执行器虽共享表示，但训练分阶段进行，全局目标图像仅作为规划器输入，执行器不直接感知最终任务约束，在某些需要长程闭环推理的任务中可能出现子目标级联误差。

## 9. 总结

ViGAR 通过将组合式操作分解为“先规划视觉子目标，再以子目标为条件联合生成未来视频与动作”的两阶段框架，在保留预训练世界模型物理常识和泛化能力的同时，引入显式的任务级推理接口。其在 RoboTwin 模拟基准和多个真实机器人组合任务上均取得优于现有 VLA 与 WAM 基线的性能，并展示了通过全局目标图像实现推理期上下文任务指定的能力。主要贡献在于：提出视觉子目标作为长期任务推理的中间表示，设计了子目标前瞻规则与末端执行器 ROI 加权损失以稳定训练，以及验证了几何路由优于语义路由的注入方式。后续工作可进一步引入在线子目标重规划、更丰富的上下文形式（如文本、示例轨迹）以及更大规模的真实机器人评估，以增强模型在复杂、非结构化环境中的鲁棒性和统计可靠性。
