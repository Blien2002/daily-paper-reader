## 摘要
大多数视觉-语言-动作（VLA）模型依赖当前观测，一旦任务相关证据离开视野便会丢失，从而限制了在长时程、依赖记忆的任务上的表现。现有方法引入压缩的历史特征或稀疏视觉关键帧。然而，孤立的快照可能使策略对过去交互中发生了什么变化以及接下来应采取哪个动作感到不确定。为克服这一局限，我们提出 EvoMem-VLA，它通过显式编码并保留历史状态之间观察到的变化来构建状态演化记忆。这些变化表示保留了交互结果的证据，使策略能够超越孤立快照跟踪任务进展。具体来说，我们引入条件增量分词，将有序帧对编码为有方向性的、以源状态为条件的增量令牌，每个令牌与其对应的状态证据相关联。共享的 VLM 骨干支持任务自适应路由：普通长时程任务遵循直接动作路由，而多阶段任务使用子任务路由，该路由生成可执行子任务作为动作生成的额外输入。在每个仿真基准上使用单一联合训练的策略，EvoMem-VLA 在 RMBench 上达到 80.7% 的成功率，在 RoboMME 上达到 82.0%，在跨两种机器人实体的四个真实世界任务中达到 83.8%。这些结果在三个评估设置中均比先前最先进的方法有显著提升。

## Abstract
Most vision-language-action (VLA) models rely on current observations and lose task-relevant evidence once it leaves view, limiting performance on long-horizon, memory-dependent tasks. Existing efforts incorporate compressed historical features or sparse visual keyframes. However, isolated snapshots can leave the policy uncertain about what changed during past interactions and which action should follow. To overcome this limitation, we propose EvoMem-VLA, which constructs state-evolution memory by explicitly encoding and retaining observed changes between historical states. These change representations preserve evidence of interaction outcomes, allowing the policy to track task progress beyond isolated snapshots. Specifically, we introduce conditional delta tokenization to encode ordered frame pairs into directional, source-conditioned delta tokens, each associated with its corresponding state evidence. A shared VLM backbone supports task-adaptive routing: normal long-horizon tasks follow a direct action route, whereas multi-stage tasks use a subtask route that generates an executable subtask as an additional input for action generation. With a single jointly trained policy for each simulation benchmark, EvoMem-VLA achieves success rates of 80.7\% on RMBench, 82.0\% on RoboMME and 83.8\% across four real-world tasks spanning two robot embodiments. These results represent substantial improvements over the previous state of the art in all three evaluation settings.

### 2. 论文提出的方法论

#### 2.1 核心思想

- 构建多尺度状态演化记忆：将初始帧、近期帧、关键帧与“状态变化令牌”按时间顺序组织，使策略既能知道“看到了什么”，也能知道“发生了什么变化”。
- 采用共享 VLM 骨干，支持任务自适应路由：普通长时程任务直接预测动作，多阶段任务先生成可执行子任务，再基于子任务生成动作。

#### 2.2 条件增量分词（Conditional Delta Tokenization）

- 给定有序源-目标图像对 `(I_u, I_v)`，使用冻结的 DINOv3 编码器提取 patch 特征 `f_u, f_v`。
- 成对帧编码器 `g_Δ` 将“目标中未被源解释的信息”压缩为单个方向性、以源为条件的增量令牌：
  - `z_{u→v} = g_Δ(f_u, f_v; q_Δ)`
- 解码器 `h_Δ` 从源特征和增量令牌重构目标特征，训练损失为逐 patch 的 log-cosh 重构损失 `L_Δ`。
- 预训练后，DINOv3 和 `g_Δ` 冻结，解码器丢弃，仅增量令牌被 VLA 使用。
- 该方式学习的是源条件变化，而不是简单的像素差、光流或动作编码。

#### 2.3 状态演化记忆（State-Evolution Memory）

- **多尺度状态证据**：
  - 固定锚点：时间步 `0, t-30, t-15, t` 的观测。
  - 事件状态银行：按时间顺序保留最多 `K` 个关键帧观测 `(κ_i, o_{κ_i})`。
- **与状态关联的变化令牌**：
  - 为每个近期锚点与其 15 步前的观测计算增量令牌，形成三个近期增量组 `d_t^{(1)}, d_t^{(2)}, d_t^{(3)}`。
  - 为每个事件状态与其事件局部滞后帧 `(κ_i - δ_e, κ_i)` 计算事件增量令牌 `d_i^e`。
- 记忆组织为：
  - `M_t = [V_0; d_t^{(3)}; V_{t-30}; d_t^{(2)}; V_{t-15}; d_t^{(1)}; V_t; {d_i^e; V_{κ_i}}]`
- 每个增量令牌紧邻其目标状态，策略不需要推断远处关键帧之间的过渡。
- 近期增量链提供持续变化证据，事件状态-变化对保留离开近期窗口后的早期证据。

#### 2.4 任务自适应路由（Task-Adaptive Routing）

- 对于有多阶段子任务监督的任务，策略先生成可执行子任务 `ŝ_t`，再将其追加到输入上下文进行第二次骨干前向，生成动作：
  - `ŝ_t = Decode_θ(C_t)`
  - `Â_t = Π_{θ,ψ}([C_t; E_ℓ(ŝ_t)])`
- 对于普通长时程任务，直接预测动作：`Â_t = Π_{θ,ψ}(C_t)`。
- 路由方式由任务级配置决定，而非学习复杂度分类器。
- 训练时，多阶段任务使用真实子任务文本；部署时使用生成文本。

#### 2.5 在线关键帧获取与学习

- Keyframe Head 从动作查询状态预测未来 `H` 个偏移的录制概率，超过阈值后调度最高分偏移，到时才提交观测。
- 两阶段优化：
  - 阶段 1：训练增量分词器（DINOv3 冻结）。
  - 阶段 2：冻结变化表示，优化 VLA、动作头、增量投影和 Keyframe Head：
    - `L = L_act + λ_lang L_lang + λ_kf L_kf`
  - `L_act` 为动作回归损失，`L_lang` 为子任务交叉熵，`L_kf` 为关键帧二分类损失。

### 8. 局限性与改进空间

- **变化表示依赖视觉特征空间**：增量分词器基于冻结的 DINOv3 视觉编码器，对需要跨模态信息（如力觉、触觉）的状态变化表达能力有限，可能限制接触密集型任务表现。
- **关键帧调度引入额外延迟**：关键帧获取需要等待未来偏移帧提交后才更新记忆，对于高动态、低延迟的操作场景可能不适用。
- **仿真评测协议不一致**：本文在 RoboMME 上采用 100 episodes/任务，而基线采用 50 episodes/任务，且种子数和检查点数不同，可能导致提升幅度被高估。
- **真实世界任务规模较小**：仅 4 个任务、每任务每实体 10 集，难以充分验证跨场景、跨物体变体的泛化能力。
- **对子任务语言监督的依赖**：多阶段任务的性能增益依赖于子任务文本标注，对于无法获取细粒度语言监督的真实场景，任务自适应路由的优势可能无法发挥。
- **计算与存储开销**：每步需为多个锚点计算增量令牌并维护事件状态银行，可能增加显存占用和推理时延，尤其在长时程部署中需要进一步优化。

### 9. 总体评价

EvoMem-VLA 通过显式编码状态演化信息，为视觉-语言-动作模型引入了更符合人类记忆机制的时间变化表征，在记忆密集型长时程操作任务上取得显著提升，验证了“变化证据”优于“静态快照”的核心假设。工作兼具方法创新性与工程实用性，为后续 VLA 记忆机制设计提供了清晰的研究路径。尽管在跨模态扩展、实时性和评测一致性上仍有改进空间，但整体贡献扎实，实验覆盖较全面，具有较高的学术与应用价值。
