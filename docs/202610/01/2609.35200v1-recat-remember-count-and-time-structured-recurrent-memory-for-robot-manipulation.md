## 摘要
依赖记忆的操作要求机器人利用当前传感器已无法获取的信息来做决策，例如回忆先前的视觉线索、跟踪任务进度、计数重复事件或估计已流逝的时间。我们提出 ReCAT，一种具有结构化循环记忆的语言条件策略。以指令为条件的编码器从当前观测中提取特征。循环记忆通过 Mamba-2 层和一个因果注意力层整合观测流。流匹配 Transformer 解码器在每个块中通过独立的交叉注意力分别读取当前表示和历史表示。ReCAT 在 LIBERO 上达到 95.3% 的平均成功率，在 RMBench 上达到 62.4%，在九项任务中的六项上取得最佳或并列最佳结果。在考察空间回忆、事件计数和间隔计时的三项真实机器人任务中，最佳 ReCAT 变体达到 66.7% 的平均成功率，而最强的短历史基线仅为 8.3%。ReCAT 内部的控制比较表明，观测编码器和逐块记忆条件化对于实现这一性能是必需的。这些比较还表明，为高效序列建模开发的更新规则作为机器人记忆时表现不同：加性更新在计数和计时任务上取得最高的观测成功率，而 delta 规则更新在空间回忆任务上表现最好。项目网站：https://intuitive-robots.github.io/ReCAT

## Abstract
Memory-dependent manipulation requires robots to make decisions using information that is no longer available to their current sensors, such as recalling an earlier visual cue, tracking task progress, counting repeated events, or estimating elapsed time. We present ReCAT, a language-conditioned policy with structured recurrent memory. An instruction-conditioned encoder forms features from the current observation. A recurrent memory integrates the observation stream through Mamba-2 layers and one causal attention layer. A flow-matching Transformer decoder reads the current and the historical representation through separate cross-attention in every block. ReCAT reaches 95.3\% average success on LIBERO and 62.4\% on RMBench, with the best or tied-best result on six of nine tasks. On three real-robot tasks probing spatial recall, event counting, and interval timing, the best ReCAT variant reaches 66.7\% average success, against 8.3\% for the strongest short-history baseline. Controlled comparisons within ReCAT show that the observation encoder and every-block memory conditioning are needed for this performance. They also show that update rules developed for efficient sequence modeling behave differently as robot memory: additive updates have the highest observed success on counting and timing, and delta-rule updates on spatial recall. Project website is at https://intuitive-robots.github.io/ReCAT

# ReCAT 论文深度总结

## 1. 论文核心问题与整体含义

**核心问题**：机器人操作中，很多任务需要依赖“当前传感器已无法获取”的历史信息来做决策。例如：

- **空间回忆**（spatial recall）：物体初始位置已经离开相机视野，但机器人需要回到该位置；
- **事件计数**（event counting）：完成了几次重复动作（如挖了几勺土），视觉上每次动作后画面相似，但后续动作不同；
- **间隔计时**（interval timing）：等待约 30 秒后再执行下一步，等待期间画面几乎不变，必须内部维持时间状态。

这类任务相对于当前观测是 **非马尔可夫的（non-Markovian）**——仅看当前画面无法判断该做什么。

**整体含义**：现有方案分为短观测窗口、记忆银行、全历史循环状态三类。前两者要么记不住长历史、要么注意力成本随历史增长。论文提出 **ReCAT**：一种 **结构化循环记忆** 策略，既保持紧凑的历史表示，又在生成动作时仍能直接看到当前观测。核心主张是：**不仅要有记忆，还必须仔细设计“记忆如何更新”以及“记忆如何与当前观测一起进入动作生成器”**。

## 2. 方法论

### 2.1 总体架构（三部分）

ReCAT 由以下三部分组成：

1. **指令条件化的观测编码器**（instruction-conditioned observation encoder）
2. **循环记忆**（recurrent memory）
3. **流匹配动作解码器**（flow-matching action decoder）

关键设计：同一个特征向量 `z_t` **同时**送入动作解码器（当前观测路径）和循环记忆（历史路径），解码器在每个块中通过**独立的交叉注意力**分别读取二者。

### 2.2 当前观测编码（Current-Observation Encoding）

- 使用 **DynaFLIP**（冻结，LoRA 适配）编码每张相机图像为 16×16 patch 网格；
- 使用 **T5**（冻结，LoRA 适配）编码任务指令；
- 通过语言条件化的**全局查询**和**局部窗口查询**压缩 patch 网格（参考 Compressor-VLA），全局查询保留任务相关上下文，局部查询保留细粒度空间细节；
- 输出每相机 80 个 token，拼接指令 token 和一个 proprioception token；
- 6 层编码器混合这些 token：**5 层 Mamba-2 + 第 4 层双向注意力**；
- 最终读出位置作为帧特征 `z_t ∈ R^768`。

公式（视觉压缩）：
```text
Z_t = CrossAttn( γ(ℓ̄) ⊙ Q + β(ℓ̄), P_t )
```
其中 `ℓ̄` 是指令摘要，`Q` 是学习的全局查询，`γ, β` 是 FiLM 参数。

### 2.3 循环记忆（Recurrent Memory）

- **6 个块、宽度 768**：5 个 Mamba-2 层（无 FFN）+ 第 4 个因果注意力层（带一个 FFN）；
- 状态更新：
  ```text
  (q_t, m_t) = R_φ(z_t, q_{t−1})
  ```
  其中 `q_t = (h_t, C_t)`，`h_t` 为 Mamba-2 层的持久循环状态，`C_t` 为注意力层的 KV 缓存；
- `m_t` 是最后一块归一化后的读出（不是状态本身）；
- 注意力缓存 `C_t` 每步存一个 768 维向量，随 episode 长度线性增长（不存图像或 patch token）；
- 训练时整条轨迹并行扫描，推理时逐步运行；
- **两个可配置属性**：
  1. **容量**：块数 + `d_state`；
  2. **更新规则**：Mamba-2（默认）、Mamba-3、Gated DeltaNet-2（表 I 总结语义差异）：

| 更新规则 | 语义 |
|---|---|
| Mamba-2 | **累加**：相似 cue 再次写入会叠加，重复事件在状态中累积——计数需要 |
| Mamba-3 | **累加 + 旋转**：增加相位演化，提供时间进程信号 |
| GDN-2 | **替换**：相似 cue 覆盖旧内容，重复事件只留下单一痕迹 |

### 2.4 动作生成（Flow-Matching Decoder）

- 预测动作块 `A_t ∈ R^{K×d_a}`，`K=16`；
- 流匹配目标：
  ```text
  L_FM = E[ || v_θ(X_τ, τ; z_t, m_t) − (A_t − X_0) ||²₂ ]
  ```
  其中 `X_τ = (1−τ)X_0 + τA_t`，`X_0` 为高斯噪声；
- **4 个解码器块**，每块依次执行：
  1. 动作 token 自注意力
  2. 对 `z_t`（当前观测）的交叉注意力
  3. 对 `m_t`（记忆）的**独立参数**交叉注意力
  4. FFN
- 流时间 `τ` 通过零初始化 AdaLN 条件化每个块。

### 2.5 训练与推理

- LoRA rank：视觉 16、文本 8；
- 真实机器人策略训练 500 epochs；
- 推理：N=4 Euler 步积分速度场，执行 chunk 前 k=4 个动作后重规划；
- 每个控制步编码器运行、记忆推进；
- 记忆状态和注意力缓存在 episode 间重置。

### 5.2 充分性与公平性评估

**优点**：

- 实验设计层次清晰，RQ1/RQ2/RQ3 三个问题驱动，覆盖效果、组件必要性、更新规则三大维度；
- **阶段级（stage-wise）评估**是突出亮点：不仅报告最终成功率，还分解每阶段到达率，能定位失败发生在“操作阶段”还是“记忆依赖决策阶段”，比只报 final success 信息量大得多；

## 6. 主要结论与发现

1. **ReCAT 在标准操作任务上有竞争力，在记忆依赖任务上优势明显**：
   - LIBERO 平均 95.3%（X-VLA 98.1%，DP 72.4%）；
   - LIBERO-Plus 64.2%（X-VLA 71.4%）；
   - RMBench 平均 62.4%，9 项中 6 项最佳/并列最佳；
   - 真实机器人三任务平均 66.7%，最强短历史基线 X-VLA-H 仅 8.3%（95% CI 不重叠）。

2. **阶段级分析揭示了清晰的失败模式**：
   - 基线能完成早期操作阶段，但在“记忆依赖决策点”失败；
   - X-VLA-H 在 PLANT 中 19/20 能挖至少一勺，但只有 2/20 完成任务，17/20 挖过了头；
   - ReCAT 的失败多数发生在记忆决策点**之前**。

3. **观测编码器和记忆条件化都是必要的**（RQ2）：
   - 全 Transformer 编码器：平均 25.0%（PLANT 上 85%→0%）；
   - 无记忆模块 / 无多模态 token：全部任务 0%；
   - 每块交叉注意力 66.7%，其他条件化方式 8.3%–38.3%；
   - PLANT 是最敏感的任务：每块交叉注意力 85%，其他方式最高仅 10%。

4. **更新规则和容量有任务依赖效应**（RQ3）：
   - **加性更新**（Mamba-2 / Mamba-3）在计数和计时任务上最高（PLANT 85% / 90%，POT TIMER 均 100% 等待正确）；
   - **Delta 规则**（GDN-2）在空间回忆上最高（SPONGE 40%）；
   - 容量：深度 6 优于 2；`d_state=128` 在该扫描中最优。

5. **效率**：ReCAT 推理延迟 59 ms/步，低于 DP-H（110 ms）、GMP（93 ms）和 X-VLA-H（288 ms）；SPARC 平滑度最高。

## 7. 优点

- **设计清晰、动机直观**：将“记忆更新语义”与“记忆-观测融合方式”拆分为两个独立可控维度，这在现有工作中较少见；
- **分离的交叉注意力路径**：当前观测与历史记忆通过独立参数进入解码器每个块，避免二者相互干扰；
- **阶段级评估框架**：能区分“操作失败”与“记忆决策失败”，为诊断提供细粒度依据；
- **更新规则的系统比较**：将 Mamba-2 / Mamba-3 / GDN-2 置于同一架构下比较，并给出可解释的假设（加性→计数，delta→替换/空间回忆），为后续设计提供指导；
- **效率和可部署性**：374M 参数即可在 4060Ti 上以 16.9 Hz 运行，对真实机器人应用友好；
- **基线的公平重训**：对所有基线在真实机器人数据上重训，避免了“论文结果不可比”的常见问题。

## 8. 不足与局限

- **统计功效有限**：真实机器人每任务每配置仅 20 rollouts、单种子，许多消融差异在噪声范围内，结论的可信度受限；
- **任务覆盖窄**：每类记忆需求（空间回忆、计数、计时）只在一个任务上验证；未测试多计数（如“挖三勺”）、多时长（如“等 60 秒”）或任务间泛化；
- **无法区分不同任务时长和条件**：语言指令如何区分不同计数/时间设置未被实验覆盖；
- **记忆模块内部贡献未解耦**：消融实验将循环层和注意力层一起移除，无法知道各子模块的独立贡献；
- **SPONGE 任务表现弱**：空间回忆任务的最佳成功率只有 40%，说明记忆使用与细粒度空间控制之间仍存在明显权衡；
