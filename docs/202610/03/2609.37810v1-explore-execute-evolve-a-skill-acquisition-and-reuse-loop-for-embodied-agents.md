## 摘要
视觉-语言-动作与世界-动作模型已在机器人领域展现出令人印象深刻的能力，但对未见任务的泛化仍具挑战性。近期，通用多模态智能体在零样本机器人任务求解方面表现出巨大潜力。然而，它们往往需要从头开始推理和探索物理世界，导致较高的执行成本。为降低这些成本，我们提出了 RoboSkill，一个通过“探索、执行、进化”循环将技能获取与重用相连接的框架。在该循环中，智能体进行探索以收集任务相关信息，在适应反馈的同时执行任务，并根据执行记录进化其技能库。随后，它重用这些技能来指导下一轮循环中的探索与执行，从而闭合循环。为提高循环效率，我们用触觉反馈补充视觉，以减少物理交互中的不确定性。我们进一步用可重用代码增强文本指导，以减少技能重用时的推理开销。在 LIBERO-10 上，RoboSkill 将四个智能体的首次成功率提高了 12.5--25.0 个百分点，并将平均运行时间降低了 7.6--72.4%。在真实机器人上，它将成功率提高了 8.3 个百分点，并将成功试验的平均运行时间降低了至少 14.4%。

## Abstract
Vision-language-action and world-action models have demonstrated impressive capabilities in robotics, yet generalization to unseen tasks remains challenging. More recently, general-purpose multimodal agents have shown great potential for zero-shot robotic task solving. However, they often incur high execution costs by reasoning and exploring the physical world from scratch. To reduce these costs, we introduce RoboSkill, a framework that connects skill acquisition and reuse through an Explore, Execute, Evolve loop. Within this loop, the agent explores to gather task-relevant information, executes tasks while adapting to feedback, and evolves its skill library based on execution records. It then reuses these skills to guide exploration and execution in the next cycle, closing the loop. To improve loop efficiency, we complement vision with tactile feedback to reduce uncertainty during physical interaction. We further augment textual guidance with reusable code to reduce reasoning overhead during skill reuse. On LIBERO-10, RoboSkill improves first-episode success rates by 12.5--25.0 percentage points and reduces average runtime by 7.6--72.4% across four agents. On real robots, it improves success rates by 8.3 percentage points and reduces average runtime for successful trials by at least 14.4%.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型与世界-动作模型（WAM）在机器人执行上速度快，但对未见任务泛化仍受限；通用多模态智能体虽具备零样本任务求解潜力，却需要从零开始反复感知、试错和恢复，执行成本高。
- **核心问题**：如何避免每次执行都“从零开始”，将已有执行经验沉淀为可复用技能，以降低物理任务中的推理、探索与试错成本。
- **整体含义**：提出 RoboSkill，用“探索（Explore）—执行（Execute）—进化（Evolve）”闭环连接技能获取与重用，并通过触觉反馈与可执行代码提升技能在物理环境中的可迁移性与执行效率。
- **主要定位**：与训练期依赖数据分布的 VLA/WAM 互补，利用通用智能体在部署阶段推理、适应并累积技能；与软件环境中的技能重用方法相比，针对物理交互中的部分观测、场景变化、执行结果不确定等问题做了专门设计。

## 2. 方法论

### 2.1 核心思想：探索—执行—进化闭环

- 智能体接收任务指令、已选技能，并通过 SDK 访问环境。
- 若缺少信息，先求解**探索子任务**以获取任务知识；随后用知识与技能生成并执行代码完成任务；执行结束后回顾会话记录和代码，构建或更新技能；新技能再指导下一轮探索与执行，形成闭环。

### 2.2 探索（Exploration）

- 将“获取执行所需信息”定义为探索子任务，其目标不同于主任务，但服务于主任务。
- 探索子任务也遵循执行—反馈—多轮修正的过程，例如在“奶油奶酪放入篮子”任务中，抓取失败后通过 RGB-D 估计桌高，不确定时下降至接触，得到桌高约 0.446 m。
- **探索知识**保存在当前会话中，包括世界坐标轴方向、桌面高度等；若探索后退出，则由智能体作为自身 reviewer 将记录和代码整合为技能包。

### 2.3 闭环执行（Closed-loop Execution）

- 上下文包括任务指令、机器人控制与感知的 API 规范、探索知识和已选技能包。
- **观测**：以视觉（RGB、深度）为主，补充**触觉反馈**（压力、力/力矩）以获取接触和碰撞的直接证据，降低物理交互不确定性。
- **SDK 式交互**：智能体可自行组合 SDK 调用与数据处理，生成如 `depth_pointcloud.py`、`verify_table_height.py` 等可复用程序，这些程序可进入技能包供后续适配与重用。
- 执行过程中记录交互和已执行代码，作为进化阶段输入。

### 2.4 进化（Evolution）

- **时机**：任务进行中保留发现和执行记录，任务结束、智能体退出后进行一次汇总回顾，避免每个子任务后都 review 带来的开销。
- **技能构成**：
  - 文本指导：任务策略、适用条件、失败教训；
  - 可执行代码：分层组织的可复用程序；
  - 支持记录：失败案例、完整执行轨迹、元数据（技能描述、关键帧）等。
- **技能使用**：新任务中智能体根据元数据选择最多 \(K=3\) 个相关技能包，放入工作区指导后续探索与执行；与规则选择相比，智能体选择在多数模型上提高首次成功率，但并非对所有模型和指标都占优。

## 6. 主要结论与发现

- **整体有效性**：RoboSkill 提升成功率和执行效率。在 LIBERO-10 上，首次成功率提高 12.5–25.0 个百分点，平均运行时间降低 7.6–72.4%；真实机器人上成功率提高 8.3 个百分点，成功试验平均时间至少降低 14.4%。
- **效率收益明显**：即使最终成功率已饱和（如 Astra 100%），首次成功率仍从 72.5% 提升至 97.5%；Opus 的 SR@30m 从 17.5% 提升至 82.5%，平均耗时从 80.9 降至 22.3 分钟。
- **跨任务迁移**：技能不仅能用于原任务，还能为其他任务提供有用指导，尤其是时间效率改善，但首次成功率的提升因智能体而异。
- **跨智能体迁移**：来自不同源智能体的技能均显著提升目标智能体 Kimi K3 的表现；真实机器人中，Astra 技能将 Sol 的 6 个简单任务成功率从 13.3% 提升到 70.0%。
- **技能进化**：进一步成功探索和技能更新可以提升性能，但收益**并非单调**；例如 Opus 第二次更新后 SR@30m 反而从 86.0% 降至 74.0%，平均时间从 19.9 增至 25.3 分钟。
- **设计消融**：
  - 可执行代码通常优于纯文本技能，Sol 首次成功率从 15.0% 提升到 67.5%，但收益因智能体有差异；
  - 触觉输入更有利于执行效率：仿真中 Astra 平均时间从 25.4 降至 15.9 分钟，真实机器人 Remove Test Tube 任务成功率从 80% 提升到 90%、平均成功时间从 33.6 降至 20.0 分钟。

## 7. 优点

- **闭环设计清晰**：将探索、执行、技能进化与重用统一为一个可迭代的框架，能够持续累积经验。

- **触觉反馈引入**：以压力/力/力矩补充视觉，改善接触和碰撞等物理交互信息的获取，仿真和真实实验均验证其对效率的贡献。

- **多智能体泛化**：跨任务、跨智能体迁移实验表明技能具有一定的通用性，不局限于单一模型。

## 8. 不足与局限

- **算力信息缺失**：没有报告 GPU/算力配置，无法评估实际计算成本与可复现资源需求。
