## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出巨大潜力，但使其适应新任务和新领域仍然效率低下：现有方法通常依赖参数调整，带来大量成本，并可能导致对已学任务的灾难性遗忘。为此，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适应形式化为显式的查询-技能记忆调优。Optimus-R 包含：（i）用于技能提取的内联记忆接口。该接口将可学习的记忆令牌插入 VLA 前缀流中，使骨干网络能够在原生动作条件化通路中推导出控制感知的查询与技能表示。（ii）用于技能学习的查询-技能记忆库。它将技能外化为查询原型（用于决定检索什么）和技能值（用于指定如何行动），支持在有限参数更新下实现技能复用与扩展。（iii）用于技能更新的轻量级桥接与适配机制。它通过轻量适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适应、跨域适应和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

# Optimus-R 论文详细总结

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型在通用机器人操作上展现出强大能力，但将其适配到新任务、新物体、新场景和新领域时，主流方法仍然依赖参数更新（如全量微调、LoRA、Adapter）。
- **核心问题**：参数中心化的适应方式使每个新技能都隐式地写入模型权重，导致：
  - 适应成本高；
  - 容易干扰先前已学任务，产生灾难性遗忘；
  - 技能难以显式检索、扩展和复用。
- **整体含义**：论文提出 **Optimus-R**，一个以记忆为中心的 VLA 框架，将机器人适应重新定义为 **显式的查询-技能记忆调优**，而不是反复更新模型参数。其目标是让 VLA 通过显式记忆接口获取、存储、组织和复用技能，从而实现数据高效、抗遗忘的持续学习。

## 2. 论文提出的方法论

- **核心思想**：将技能外置到全局记忆库中，通过内联记忆接口从 VLA 前缀流中提取查询向量和技能向量，再用“查询原型决定检索什么，技能值决定如何行动”的机制支持技能复用与扩展。

### 2.1 内联记忆接口（Inline Memory Interface）

- 将 `m=4` 个可学习记忆令牌拼接到 VLA 输入前缀中，与观察和指令一起输入骨干网络，得到记忆状态 `Mt`。
- 使用两个独立的注意力池化操作从 `Mt` 中分别得到查询表示 `qt` 与技能表示 `st`，实现“检索上下文”与“动作相关技能内容”的分离。
- 训练阶段通过轻量技能解码器 `Ds(st)` 重建未来动作块，使技能空间具备可执行行为的监督。

### 2.2 查询-技能记忆库（Query-Skill Memory Bank）

- 记忆库以解耦键值原型形式存储：`B = {(pq_j, ps_j, n_j, E_j)}`，其中：
  - `pq_j`：查询原型，决定检索什么；
  - `ps_j`：技能原型，决定如何行动；
  - `n_j`：支持计数；
  - `E_j`：用于回放的潜在查询-技能样本子集。
- 记忆库构建过程：
  - 运动感知降采样（motion-aware downsampling），避免静态冗余样本；
  - 归一化进度分层采样，覆盖轨迹不同阶段；
  - 先在查询空间聚类，再对技能方差大的簇进一步划分，形成兼具可检索性与动作一致性的原型。
- 检索时先用线性映射 `Amem` 对齐查询，再计算 top-K 原型（默认 `Kr=2`）的 softmax 相似度权重，聚合技能值 `ps_j` 及其残差 `∆ps_j` 得到检索技能 `ŝt`。

### 2.3 桥接与适配机制（Bridge-and-Adapt）

- **Stage A**：接口预训练。训练记忆令牌、查询/技能编码器、技能解码器、令牌投影器和骨干网络最后若干层；训练损失包含原始 VLA 流匹配损失、查询对比损失和技能重建损失。
- **Stage B**：跨域桥接。在保持已学接口模块和基础原型固定的前提下，更新骨干网络、查询对齐矩阵 `Amem`、温度 `τmem` 和活跃原型残差；可选地使用低秩残差技能适配器 `As(ŝt) = ŝt + U_s V_s^T ŝt` 修正检索技能，初值为零初始化，保证初始不改变检索结果。
- **Stage C**：域内记忆适应。冻结骨干网络和接口模块，仅更新 `Amem`、`τmem`、活跃原型残差和记忆库结构。当新样本查询接近现有原型时更新残差和支持统计；否则进入候选缓冲区，满足支持度和方差条件时才追加新原型。
- Stage B/C 使用统一的适应损失：流匹配损失 + 技能对齐损失 + 残差正则项，其中对齐损失使检索/适配后的技能接近当前编码技能目标，正则项限制原型漂移。

- **数据高效适应**：仅用 30% 训练数据，Optimus-R 在 LIBERO 平均成功率提升 16.5 个百分点；CALVIN 平均完成长度提升 0.42；RoboTwin 2.0 Hard 成功率提升 5.0 个百分点。

- **检索空间可视化**：相似任务在查询空间中共享检索邻域，验证了记忆库对可复用技能的编码能力。
