## 摘要
世界动作模型通过以预测的未来为条件来改进机器人操作，但现有的触觉变体大多继承了视频生成流程，通过迭代去噪重建未来的触觉观测。在部署漂移下，这种预测可能变得不可靠：即使底层接触演化仍可预测，接触位置或力的微小变化也可能大幅改变触觉像素。我们提出了 TacDyn-WAM，一种异构视觉-触觉世界动作模型，它预测隐式触觉动力学，而不是重建未来的触觉观测。该模型学习 TacRep，一个动态感知的触觉目标空间，通过在触觉片段上进行掩码时空预测训练，并用关系结构蒸馏进行正则化。视觉专家和隐式触觉动力学专家在各自的目标空间中预测未来的视觉和触觉表示，并通过联合注意力进行交互；触觉专家在单次前向传播中预测多个时间尺度的未来表示及其变化，只读触觉记忆提供当前触觉状态。在 UniVTAC 上，TacDyn-WAM 仅使用提供的演示即可达到 81.5% 的平均成功率，达到最先进水平，并与在大规模视觉-触觉轨迹上预训练的模型保持竞争力。消融实验证实了触觉通路和 TacRep 相对于像素重建和静态替代方案的优势。在五个真实机器人任务上，TacDyn-WAM 达到 71.0% 的平均成功率，中等规模预训练将其提升至 85.0%，进一步验证了我们的方法。

## Abstract
World action models improve robotic manipulation by conditioning actions on predicted futures, yet existing tactile variants largely inherit video-generation pipelines that reconstruct future tactile observations through iterative denoising. Such prediction can become unreliable under deployment drift: small changes in contact position or force may substantially alter tactile pixels even when the underlying contact evolution remains predictable. We introduce TacDyn-WAM, a heterogeneous visuo-tactile world action model that predicts implicit tactile dynamics rather than reconstructing future tactile observations. It learns TacRep, a dynamics-aware tactile target space trained through masked spatio-temporal prediction on tactile clips and regularized by relational structure distillation. A visual expert and an Implicit Tactile Dynamics Expert predict future visual and tactile representations in separate target spaces while interacting through joint attention; the tactile expert predicts future representations and their changes at multiple horizons in a single forward pass, and a read-only tactile memory supplies the current tactile state. On UniVTAC, TacDyn-WAM achieves an average success rate of 81.5% using only the provided demonstrations, reaching state-of-the-art-level performance and remaining competitive with models pretrained on large-scale visuo-tactile trajectories. Ablations confirm the benefits of both tactile pathways and TacRep over pixel-reconstruction and static alternatives. On five real-robot tasks, TacDyn-WAM reaches 71.0% average success, and modest-scale pretraining raises it to 85.0%, further validating our method.

## 1. 论文的核心问题与整体含义

- **研究背景**：世界动作模型通过预测未来状态来辅助策略学习，在机器人操作中展现出潜力。但现有触觉世界动作模型大多沿用视频生成流程，通过迭代去噪重建未来触觉图像。
- **核心问题**：触觉观测对接触位置、力的微小变化非常敏感，部署时策略一旦偏离演示分布，即使底层接触演化仍然可预测，像素级重构也可能变得不可靠。因此，**“触觉世界模型应该预测什么”**成为关键设计问题。
- **整体含义**：论文主张放弃像素/VAE重建，转而学习**隐式触觉动力学表示**，在动力学感知的目标空间中预测接触演化，从而在部署漂移下保持更稳健的预测，并提升触觉相关操作任务的成功率。

## 2. 论文提出的方法论

### 2.1 总体架构：异构视觉-触觉世界动作模型

- 基于 **InternVLA-A1 3B** 混合专家 Transformer 构建，原有三个专家：
  - Understanding Expert（Qwen3-VL-2B）编码当前视觉与指令；
  - Visual Generation Expert 预测未来视觉隐变量；
  - Action Expert 通过 flow matching 去噪生成 50 步动作块。
- 新增 **Implicit Tactile Dynamics Expert（ITDE）** 作为第四专家，与视觉专家在**不同目标空间**中分别预测未来视觉与触觉表示，并通过**逐层联合注意力**交互。
- 另设**只读 Tactile Understanding Memory**，提供当前触觉状态，仅作为 key/value 暴露给其他专家，不参与 query 更新。

### 2.2 TacRep：动力学感知触觉表示空间

- **训练目标**：不重建未来像素，而是学习能捕捉接触演化的表示。
- **Tactile Dynamics Prediction（TDP）**：
  - 基于 V-JEPA 2.1 的自监督视频学习思路；
  - 将 4 帧触觉片段分组成 tubelet，编码可见 patch，训练轻量 predictor 恢复被 mask 的时空块特征；
  - 目标编码器采用 EMA 更新；
  - 损失为掩码位置上的特征回归误差（式 3）。
- **Relational Structure Distillation（RSD）**：
  - 冻结 DINOv2 ViT-B 作为结构教师；
  - 不对齐特征值，只对齐局部 patch 间的**余弦相似关系**，以保留空间结构且不破坏动力学表示；
  - 损失为局部关系差异的 Smooth L1（式 4）。
- 最终保留 EMA 编码器作为冻结的 TacRep Encoder。

### 2.3 Implicit Tactile Dynamics Expert（ITDE）

- **输入编码**：4 帧触觉片段经冻结 TacRep Encoder 得到 2 个时间特征图，池化到 4×4 后投影，得到每传感器 32 个 context tokens。
- **未来查询**：对每个预测时步 \(h \in \{5,15,25\}\)，添加 16 个可学习 Future Token Queries（4×4 网格）。
- **Dynamics Predictor**：28 层 Transformer，隐藏维度 1024，约 0.4B 参数，单次前向预测多时步表示，无迭代去噪。
- **双 readout 预测**：
  - Future Readout 预测未来触觉表示 \(z_{t+h}\)；
  - Delta Readout 预测变化量 \(\Delta z_{t+h} = z_{t+h} - z_t\)；
  - 每个 readout 用 49 个 7×7 查询对 16 个未来 token 做交叉注意力，再线性映射到 TacRep 维度。
- **损失**：Smooth L1 + **Patch-Adaptive Loss Reweighting**，按 patch 实际变化幅值加权，聚焦于接触扩展、收缩、滑动区域（式 6）。

### 2.4 只读触觉理解记忆

- 使用冻结 **AnyTouch2** 编码当前触觉片段；
- **Compact Attentive Pooler** 将几百个 token 压缩为 10 个：1 个全局 token + 3×3 网格 9 个局部 token；
- 再经两层 Q-Former 跨传感器融合，并以 prefix 为条件；
- 记忆 token 仅作为额外 key/value，不更新，参数开销约 1%。

### 2.5 联合注意力与分阶段训练

- 各专家计算独立 Q/K/V，拼接后通过块级因果联合注意力；
- **四阶段训练**：
  1. **Stage 1**：只训练 TacRep；
  2. **Stage 2**：冻结其他专家，训练 ITDE 与 readouts，进行触觉世界接地；
  3. **Stage 3**：训练 Tactile Understanding Memory 与 Action Expert，实现触觉-动作对齐；
  4. **Stage 4**：打开所有连接，联合优化，总损失为
     \[
     L = L_{\text{act}} + \lambda_{\text{vis}} L_{\text{vis}} + \lambda_{\text{tac}} L_{\text{tac}}
     \]
     其中 \(\lambda_{\text{vis}}=0.01\)，\(\lambda_{\text{tac}}=500\)（仿真）或 300（真实预训练）。

## 7. 优点

- **问题定位清晰**：指出像素重建不适合触觉预测，提出隐式动力学建模这一更有针对性的方向。
- **TacRep 设计有据**：结合 V-JEPA 风格时空预测与 DINOv2 结构蒸馏，既捕捉接触演化又保留空间结构，避免特征值冲突。
- **单次前向多时步预测**：无需迭代去噪，提升推理效率并保持恒定延迟。
- **异构专家 + 只读记忆**：视觉、触觉预测和当前触觉理解分离，联合注意力交互；分阶段训练避免随机初始化模块干扰预训练专家。
- **实验说服力较强**：在大型基准上接近大规模预训练模型，消融清晰，真实机器人验证补充了仿真结果。
