## 摘要
接触丰富的操作要求机器人安排精确接触顺序、保持稳定抓取并施加定向力。强化学习（RL）可以自动习得此类行为，但其性能取决于奖励设计：稀疏奖励会降低学习效率，而稠密奖励难以指定。视觉奖励学习通过从无动作演示中推断奖励来解决这一问题。由于它仅以视觉观测为条件，因此无法捕捉超越视觉目标的奖励。我们提出触觉奖励学习（TaRL），一个从触觉演示中学习奖励的框架。TaRL 以触觉形变图序列作为输入，并从成功和失败的演示中回归任务完成进度。由于 TaRL 捕捉局部机器人-物体交互，它提供了信息丰富的反馈来学习稳固抓取和正确方向的力；同时，它对场景布局变化（如物体位置）具有鲁棒性。我们在仿真中的四个操作任务和真实世界中的两个任务上评估了 TaRL。作为塑形奖励使用时，它大幅提升了样本效率和最终成功率，在仿真中螺母穿线成功率从 34% 提高到 56%，在真实世界中立方体抓取成功率从 37% 提高到 97%。将触觉奖励与视觉奖励结合可进一步提升性能。TaRL 还能跨物体实例泛化：在盒子放置任务上训练后直接部署到罐子放置任务，它显著改善了新任务上的策略学习。项目页面见 https://embodiedai-ntu.github.io/tarl。

## Abstract
Contact-rich manipulation requires robots to sequence precise contacts, maintain stable grasps, and apply directed forces. Reinforcement learning (RL) can acquire such behaviors automatically, but its performance hinges on reward design: sparse rewards reduce the learning efficiency, while dense rewards are hard to specify. Visual reward learning addresses this by inferring rewards from action-free demonstrations. Because it conditions only on visual observations, it fails to capture rewards beyond visual goals. We propose Tactile Reward Learning (TaRL), a framework that learns rewards from tactile demonstrations. TaRL takes a sequence of tactile deformation maps as input, and regresses task-completion progress from both successful and failed demonstrations. Because TaRL captures local robot-object interaction, it provides informative feedback to learn firm grasps and correctly directed forces; meanwhile, it is robust to changes in scene layout such as object position. We evaluate TaRL on four manipulation tasks in simulation and two in the real world. Used as a shaping reward, it substantially improves both sample efficiency and final success rate, raising success on Nut threading from 34% to 56% in simulation and on cube pickup from 37% to 97% in the real world. Combining tactile with visual rewards improves performance further. TaRL also generalizes across object instances: trained on box placement and directly deployed to can placement, it significantly improves policy learning on the new task. Project page is available at https://embodiedai-ntu.github.io/tarl.

- 接触丰富操作要求机器人安排精确接触顺序、保持稳定抓取并施加定向力，但强化学习（RL）的性能高度依赖奖励设计：稀疏奖励效率低，稠密奖励难以人工指定。
- 视觉奖励学习（RLfD 的主流范式）仅以视觉观测为条件，无法捕捉视觉目标之外的物理信息，如抓取是否稳固、接触力方向、接触阶段切换等。
- 触觉传感直接编码局部接触几何、压力、剪切力等信息，因此论文提出 **TaRL（Tactile Reward Learning）**，从触觉演示中学习任务完成进度作为 RL 奖励，以弥补视觉奖励的不足。
- 整体含义：为接触丰富操作提供一种基于触觉的、物理感知的奖励学习新途径，且与视觉奖励学习正交互补。

## 2. 方法论

- **核心思想**：将奖励建模为任务完成进度，并使用触觉形变图序列作为输入，通过回归成功/失败演示中的进度来学习一个稠密、信息丰富的奖励函数。
- **输入模态**：每个时间步 $t$ 获取一对触觉形变图 $o_t^{tac}=(o_{t,1}^{tac}, o_{t,2}^{tac})$，每个形变图为 $\mathbb{R}^{3\times H\times W}$，对应两个手指的 3D 形变信息。
- **模型架构**：
  - 从变长轨迹中均匀采样固定数量 $N=16$ 个时间步，不足则填充最近帧。
  - 每个手指的形变图通过共享的 3 层卷积网络编码为 $c$ 维特征，拼接为 $2c$ 维 token $d$。
  - 使用带因果注意力的 Transformer 处理 token 序列，保证每个输出只依赖当前及历史输入。
  - 每个输出 token 经共享 MLP + sigmoid 得到对应时间步的进度预测，最终触觉奖励为 $\tilde{R}_\theta(o_{1:t}^{tac})=\sigma(\text{MLP}(d_N))$。
- **数据预处理**：对每个序列的所有形变图做逐序列归一化（除以该序列中所有图的最大绝对值，并裁剪最小值 $10^{-6}$），使模型学习相对形变模式而非绝对力大小，提高泛化能力。
- **训练目标**：利用三类样本构建回归损失：
  - 成功演示原始视频：目标为 $t/T$；
  - 失败演示视频：目标为 0；
  - 成功但“倒放”视频（随机拼接前向前缀与反向后缀）：目标为 $(i-t)/T$。
  - 总损失 $L(\theta)$ 为三类样本的均方误差之和。
- **下游 RL 集成**：TaRL 离线预训练后直接作为塑形奖励（shaping reward）与任务奖励和可选的视觉奖励 $\hat{R}_\phi$ 线性组合：
  $$R_{\text{total}}(s_t,a_t,s_{t+1}) = R(s_t,a_t,s_{t+1}) + \alpha \tilde{R}_\theta(o_{1:t}^{tac}) + \beta \hat{R}_\phi(o_{1:t}),$$
  其中 $\alpha,\beta$ 为权重超参数；仿真中使用 PPO，真实世界中使用 IQL。

## 6. 主要结论与发现

- TaRL 作为塑形奖励能显著提升下游 RL 的样本效率和最终成功率，仿真中 nut threading 成功率从 34% 提高到 56%，真实世界 cube pickup 从 37% 提高到 97%。
- TaRL 对 OOD 物体位置具有很强鲁棒性：触觉特征在 ID 和 OOD 位置下分布相似，而视觉特征分布差异显著。
- 视觉奖励在物体接近/定位阶段贡献大，但在接触阶段饱和；触觉奖励在接触阶段持续提供信息，二者互补，结合后进一步提升 RL 效率。
- TaRL 可跨物体实例零样本泛化：在 box placement 上训练，直接用于 can placement，奖励质量仍能区分成功/失败，并提升下游 RL。
- 触觉奖励不能从触觉条件 critic 或手写抓取检测奖励中自然涌现，必须通过从演示中学习获得。

## 7. 优点

- **首次提出从触觉演示学习 RL 奖励**，开辟了与视觉奖励学习正交的新方向。
- **物理感知**：利用 3D 形变图捕捉局部交互，能提供抓取稳定性、力方向等视觉不可见的信息。
- **对场景布局鲁棒**：归一化处理使模型聚焦相对形变模式，对物体位置甚至物体实例具有泛化能力。
- **实验扎实**：覆盖 4 个仿真 + 2 个真实世界任务，对比了视觉奖励、手写触觉奖励、触觉条件策略等多种基线，并进行了消融和互补性分析。
- **简洁有效**：采用 ReWiND 的进度回归框架，未引入复杂设计，作为塑形奖励即可大幅提升性能。
