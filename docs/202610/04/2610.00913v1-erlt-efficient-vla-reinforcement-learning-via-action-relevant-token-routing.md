## 摘要
视觉-语言-动作（VLA）模型为机器人操作提供了强大的行为先验，但将其高效地适配到下游任务仍具挑战性。近期工作通过在线强化学习（RL）适配冻结的 VLA 来应对这一挑战，其样本效率取决于 actor 和 critic 所使用的状态表示的质量。现有方法要么使用独立于 VLA 的视觉编码器，要么通过对 VLA 内部表示进行固定压缩来构建此类表示。这两种设计均未显式提取特定任务下与动作相关的 VLA 特征，而这些特征对下游动作优化和动作价值估计最为有用，因此限制了样本效率。为解决这一局限，我们提出 eRLT，它通过在冻结 VLA 的令牌和层之间路由任务特定的动作相关信息，来构建有效的状态表示。具体而言，学习的路由令牌在多个深度动态聚合视觉-语言特征，而轻量级层路由器将这些摘要组合成一个固定维度的 RL 令牌。该路由模块使用专家演示进行初始化，以捕捉能预测专家动作的特征，随后利用在线交互中的 critic 反馈进行优化，用于动作价值估计。在七个 LIBERO 和 RoboTwin 任务中，与代表性基线相比，eRLT 将平均归一化学习曲线 AUC 提升了最高 23.7%。在 USB 连接器插入和主板排线插入的真实机器人实验中，与最强基线相比，AUC 分别进一步提升了 108.9% 和 46.7%。

## Abstract
Vision-Language-Action (VLA) models provide strong behavioral priors for robotic manipulation, yet efficiently adapting them to downstream tasks remains challenging. Recent work addresses this challenge by adapting frozen VLAs through online reinforcement learning (RL), whose sample efficiency depends on the quality of the state representation used by the actor and critic. Existing methods construct such representations either with VLA-independent visual encoders or through fixed compression of internal VLA representations. Neither design explicitly extracts the task-specific action-relevant VLA features most useful for downstream action refinement and action-value estimation, therefore limiting sample efficiency. To address this limitation, we introduce eRLT, which constructs an effective state representation by routing task-specific action-relevant information across both tokens and layers of the frozen VLA. Specifically, learned routing tokens dynamically aggregate visual-language features at multiple depths, while a lightweight layer router combines these summaries into a fixed-dimensional RL token. The routing module is initialized using expert demonstrations to capture features predictive of expert actions and then refined using critic feedback from online interactions for action-value estimation. Across seven LIBERO and RoboTwin tasks, eRLT improves mean normalized learning-curve AUC by up to 23.7% over representative baselines. Real-robot experiments on USB connector insertion and motherboard ribbon-cable insertion further show AUC improvements of 108.9% and 46.7%, respectively, over the strongest baseline.

## 2. 论文提出的方法论

- **核心思想**：通过“动作相关 token 路由”构建固定维度的 RL token，聚合冻结 VLA 中跨 token、跨层的任务特定动作相关信息。
- **技术细节**：
  - **Token-wise routing**：在输入前缀后附加 K 个可学习路由 token，在单独前向传播中通过冻结 VLM，从选定层提取路由 token 位置的隐藏状态并平均，得到每层摘要 \( u_t^{(i)} \)。
  - **Layer-wise routing**：使用可学习层 logits 经 softmax 归一化得到层权重 \( \alpha \)，将多层摘要加权求和得到 RL token \( z_t = \sum_{i=1}^{m} \alpha_i u_t^{(i)} \)。
  - **两阶段训练**：
    1. **专家动作预测初始化**：利用 VLA SFT 演示数据，通过轻量动作探针 \( g_\omega \) 从 RL token 预测专家动作块，最小化 MSE，使 RL token 保留动作优化所需信息。
    2. **Critic 驱动的在线适应**：在线 RL 阶段，将 critic 的 TD 误差反向传播到路由参数，使 RL token 暴露能解释任务进展差异的线索，优化动作价值估计；actor 更新时 RL token 被 detach。
  - **关键设计**：路由 token 的前向传播与 VLA 动作生成分离，不改变冻结 VLA 的行为；路由参数仅包含路由 token 嵌入和层 logits，参数量极小。

## 6. 论文的主要结论与发现

- **动机证据**：最适用于在线 RL 的 VLA 层和 token 子集因任务而异，固定层或固定 token 无法充分利用内部表示。
- **主实验结果**：在 7 个仿真任务上，eRLT 的平均归一化 AUC 为 0.626，优于 RL T*（0.506）和 DSRL*（0.585）；在 LIBERO 全部四个任务上取得最佳，在 RoboTwin 的六分之七任务上优于 DSRL*（仅 Move Can–Pot 略低于 DSRL*）。
- **真实机器人结果**：USB 插入任务上 eRLT 的 AUC 提升 108.9%，最终窗口成功率从 50% 提升至 90%；排线插入任务上 AUC 提升 46.7%，最终成功率与 RLT 均达 100%。
- **消融发现**：四个组件均对性能有贡献，其中 token-wise routing 作用最大，离线初始化次之；路由 token 数量增加不单调提升性能，K=1 或 2 表现较好，过多 token 增加学习负担。
- **整体结论**：任务特定的动作相关 RL token 能有效提升冻结 VLA 在线 RL 的样本效率和最终可靠性。

## 7. 优点

- **方法创新性强**：首次显式地同时跨 token 和层路由 VLA 内部动作相关信息，而非固定压缩或外部编码器。
- **两阶段训练设计合理**：先利用现有演示做动作预测初始化，再用 critic 反馈在线适应，兼顾动作优化和动作价值估计两个目标。
- **控制变量实验严谨**：所有对比方法在同一 RL 框架内仅改变状态表示，能清晰分离状态表示的贡献。
- **动机实验有说服力**：通过受控实验直接展示层和 token 选择对任务存在依赖，为方法设计提供实证依据。
- **真实机器人验证**：在精密插入任务上展示显著提升，证明方法具备实际部署潜力。

## 8. 不足与局限

- **依赖冻结 VLA 的信息容量**：若 VLA 内部未编码任务相关特征，eRLT 无法弥补。
- **计算与内存开销增加**：多层提取和周期性路由更新相比固定层 RL token 更昂贵。
- **真实实验范围有限**：仅两个插入任务、一个机器人平台，且受人工干预协议影响；运行间变异和干预频率敏感性不足。
- **统计稳健性有限**：仿真任务多用 3 个种子，真实实验未见多种子重复，AUC 百分比提升的稳健性值得进一步验证。
- **评估覆盖面局限**：未在多个 VLA backbone、更多机器人构型或更长时域任务上测试；路由器的跨任务/跨本体迁移能力尚未研究。
- **基线选择可能影响相对提升幅度**：与更强或更近期的方法对比时，相对增益可能不同。
- **真实实验中的人工干预可能引入偏差**：辅助轨迹数量和成功次数与自主策略表现相关，可能影响学习曲线解读。
