## 摘要
机器人策略越来越多地结合语义推理和未来世界预测，然而将这些能力结合起来并不能保证局部预测和动作与任务进度保持一致。我们提出 CogWAM，一种认知引导的世界-动作模型，通过一个持久语义状态在任务推理和世界-动作学习之间建立显式语义接口，该状态存储已完成的任务事件和当前活动子任务。CogWAM 仅在观测表明语义转换时更新该状态，使任务级上下文能够跨多个动作块持续存在。为了将语义上下文与物理预测和控制连接起来，CogWAM 采用以进度为条件的 WORLD 和 ACTION 查询，选择性地提取与任务相关的信息，用于未来世界预测和动作生成。在训练过程中，语义状态为两个分支提供共享的任务进度上下文；而推理时移除未来预测分支，直接根据观测和所维持的状态生成动作。我们进一步引入语义训练策略来改善转换学习和闭环条件化。在无需额外机器人动作预训练的情况下，CogWAM 在 RoboDojo 上取得 15.56 / 11.70% 的 Score/SR，并在 BiCoord 上达到最先进性能，同时真实世界实验展示了闭环双臂操作，与逐步更新相比，语义状态重新生成次数减少了 16.4 次。

## Abstract
Robot policies increasingly incorporate semantic reasoning and future-world prediction, yet combining these capabilities does not guarantee that local predictions and actions remain aligned with task progress. We introduce CogWAM, a cognition-guided world-action model that establishes an explicit semantic interface between task reasoning and world-action learning through a persistent Semantic State, which stores completed task events and the active subtask. CogWAM updates this state only when observations indicate semantic transitions, allowing task-level context to persist across multiple action chunks. To bridge semantic context with physical prediction and control, CogWAM employs progress-conditioned WORLD and ACTION queries that selectively extract task-relevant information for future-world prediction and action generation. During training, the Semantic State provides shared task-progress context for both branches, while inference removes the future-prediction branch and directly generates actions from observations and the maintained state. We further introduce semantic training strategies to improve transition learning and closed-loop conditioning. Without additional robot-action pretraining, CogWAM achieves 15.56 / 11.70 % Score/SR on RoboDojo and state-of-the-art performance on BiCoord, while real-world experiments demonstrate closed-loop dual-arm manipulation with 16.4 fewer Semantic State regenerations than step-wise updating.

- **整体含义**：论文主张在认知语义层面与物理控制层面之间建立一个**显式的、可维护的语义接口**，让任务级“认知”能够以低成本、事件驱动的方式持续指导高频的世界建模与动作生成，从而在语义时间尺度与控制时间尺度之间形成闭环对齐。

## 2. 论文提出的方法论

### 2.1 核心思想：持久语义状态作为显式接口

- CogWAM 的核心是在任务推理与世界-动作学习之间引入一个**持久语义状态（Semantic State）**：
  - `m_t`：已完成任务事件的记忆（memory）
  - `s_t`：当前活动子任务（active subtask）
- 该状态在任务执行过程中被保存并继承，仅在观测到语义转换时才更新，使任务级上下文可以跨多个动作块持续存在。

### 2.2 事件触发的语义状态更新（Event-Driven Semantic Planning）

- 系统通过一个**KEEP / UPDATE 决策机制**控制语义状态的更新时机：
  - 决策 `d_t ∈ {KEEP, UPDATE}` 预测当前所存语义状态是否仍然有效；
  - 当 `d_t = UPDATE` 时，模型才生成记忆增量 `Δm_t` 和更新后的活动子任务 `s_t`；
  - 当 `d_t = KEEP` 时，状态直接沿用，避免重复生成。
- 这种设计将语义时间尺度与控制时间尺度解耦：动作需要高频重规划以保证反应性，但任务语义只在少数阶段转换时演化。
- 决策公式（正文思想）：
  ```
  d_t ∼ p_θ(d_t | O_t, ℓ, S_{t−})
  (Δm_t, s_t) ∼ p_θ(Δm_t, s_t | O_t, ℓ, S_{t−}, d_t=UPDATE)
  S_t = S_{t−}（若 KEEP） 或 S_t = (m_{t−} ⊕ Δm_t, s_t)（若 UPDATE）
  ```

### 2.3 进展条件化的 World-Action 接口

- 在给定语义状态 `S_t` 后，CogWAM 在因果序列中追加两组可学习查询 token：
  - **WORLD queries**：条件于语义状态，提取面向未来世界预测的表征 `H^w_t`；
  - **ACTION queries**：条件于同一语义状态，提取面向动作生成的表征 `H^a_t`。
- 两组查询共享任务语义，但保持目标特化的表征。后续梯度分析（§5.1.1）显示，世界与动作目标在感知层具有正对齐，但到深层读出处对齐衰减，因此需要分离查询。

### 2.4 联合训练与推理

- **世界-动作建模**：采用 Mixture-of-Transformers（MoT）双流结构，以当前 DINO 特征为视觉锚点，世界流预测未来多视角 DINO 潜在特征，动作流生成连续动作块。
- **结构化注意力掩码**：防止动作 token 访问未来潜在特征，避免信息泄漏。
- **联合目标**：
  ```
  L = L_action + λ_world L_world + λ_sem L_sem
  ```
  - `L_action`、`L_world` 均为 flow-matching 速度场损失；
  - `L_sem = L_dec + 1[d⋆=UPDATE] L_gen`，其中 `L_dec` 为 KEEP/UPDATE 决策损失，`L_gen` 为记忆增量与活动子任务的自回归生成损失。
- **训练策略**：
  - **边界感知采样（Boundary-Aware Semantic Sampling）**：过采样 UPDATE 事件及接近转换边界的“hard-KEEP”帧，以应对语义转换稀疏问题；
  - **渐进语义条件化（Progressive Semantic Conditioning）**：训练后期逐步将标注语义状态替换为模型预测状态作为上下文，缓解训练-推理不一致。
- **推理简化**：推理时移除未来预测分支，仅靠观测与维护状态直接生成动作。

## 6. 主要结论与发现

- **显式语义接口带来跨基准一致增益**：
  - RoboDojo 平均 Score/SR：15.56 / 11.70%，较同组 StarVLA-α 提升 9.16 / 8.46 个百分点；
  - BiCoord 平均 SSR/SR：58.0 / 43.8%，优于最强基线 π0.5 达 7.2 / 8.2 个百分点。
- **语义状态对长程任务尤其关键**：消融“无持久语义状态”条件下的策略更易出现子任务漂移、重复已完成阶段和过早转换；N-conditioning 通过降低动作分布的条件熵减少历史相关的状态混淆。
- **更新时机比更新频率更重要**：事件触发策略在性能上优于同步更新与固定低频异步更新；同步更新虽延迟较低但计算开销巨大，而事件触发以 16.4× 更少的语义状态重新生成实现了同样的转换延迟。
- **语义接口具有可迁移性**：将同一接口迁移到 Fast-WAM 后，平均 Score/SR 从 3.48/2.03% 提升至 13.33/9.40%，表明其收益不依赖底层 WAM 架构。
- **世界/动作梯度分析**：两目标在感知层共享基础、在深层逐渐分化，揭示分离 WORLD/ACTION queries 的合理性；外部 head 的 dual-DiT 基线在世界目标回归到共享骨干的信号更弱。

## 7. 优点

- **问题定位清晰，对齐视角新颖**：抓住“局部合理动作未必服务于全局任务进展”这一核心矛盾，将讨论从语义能力、世界预测能力的独立改进提升到接口对齐层面。
- **事件驱动设计兼顾性能与效率**：KEEP/UPDATE 决策在实现低延迟、高频检查的同时，大幅减少了语义状态再生成的计算成本，对真实闭环部署具有直接意义。
- **可迁移性验证充分**：通过 Fast-WAM 接口迁移实验，展示了语义接口具有一定平台通用性。
- **梯度分析提供了机理层面的证据**：通过 GA/MR 指标实际测量 VLM 骨干中世界目标与动作目标的梯度耦合，支持了分离查询的设计，是论文中较有力的分析段落。
- **表述审慎公平**：多次声明归因边界（例如“Interface 整体贡献 vs 组件独立作用”“DINO vs Wan2.2 为配方效率比较而非隔离表征质量”等），较为客观。

## 8. 不足与局限

- **语义状态“只追加、不可修正”**：当前状态仅支持追加新完成事件，一旦语义转换判断错误将被固化，缺少事后修正或回退机制，是后续待解决的关键限制。  
- **部分消融未完全拆解**：如 §5.1.2 自述，MoT → CogWAM 的增益是“VLM 条件化 + 事件触发语义状态”的集成效应，未再隔离二者各自贡献。
- **预测表征与底层模型联合变化**：DINO 特征对比 Wan2.2 视频骨干的实验中，表征形式、模型容量、初始化方式同时变化，无法把增益严格归因于预测表征质量。
- **真实机器人覆盖面有限**：6 个基本任务、4 类分布偏移的样本量不大，且在真实机器人评测中似乎未与其他方法做直接的物理对比，泛化到更广泛场景仍需更多证据。
- **部分分析框架的适用边界受限于既有标注**：语义状态训练依赖离线 GPT-5.6 Sol 标注的阶段边界，边界标注质量对监督效果有潜在影响。
- **推理侧去除了世界分支**：未来预测在部署时被移除，虽然降低了计算负担，但也意味着世界预测能力没有在推理闭环中继续提供显式的前瞻纠正作用。
