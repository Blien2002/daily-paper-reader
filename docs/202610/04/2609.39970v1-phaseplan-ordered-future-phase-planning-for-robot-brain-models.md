## 摘要
机器人脑模型整合视觉、语言和机器人状态，为复杂操控任务生成动作。现有模型大多预测可能跨越多个任务阶段的固定长度动作块。这会掩盖阶段转换并偏向频繁出现的动作模式，从而影响动态环境中的动作时序。我们提出 PhasePlan，一种用于机器人脑模型的有序未来阶段规划方法。该方法根据当前多模态观测预测每个未来动作位置处的任务阶段。由此产生的规划表示对相应动作进行条件化，保持任务进度与动作生成之间的时间对齐。训练首先学习规划器，然后在动作模型适配过程中冻结规划器，以维持稳定的阶段表示。我们在预训练的 π0.5 和 AcrossWAM1.0 机器人脑模型上实例化 PhasePlan。详细的定量评估采用 π0.5 实现。在传送带操控任务上，与原始 π0.5 模型相比，PhasePlan 将离线关节动作误差降低了约 22.5%。它还改善了阶段转换建模和跨阶段动作预测。这些结果证明了有序未来阶段规划对于连续动作生成的价值。

## Abstract
Robot brain models integrate vision, language, and robot state to generate actions for complex manipulation tasks. Most predict fixed-length action chunks that may span multiple task phases. This can obscure phase transitions and favor frequent action patterns, compromising action timing in dynamic environments. We propose \method, an ordered future-phase planning method for robot brain models. From current multimodal observations, it predicts the task phase at each future action position. The resulting planning representations condition the corresponding actions, preserving temporal alignment between task progress and action generation. Training first learns the planner, then freezes it during action-model adaptation to maintain stable phase representations. We instantiate \method on pretrained $π_{0.5}$ and AcrossWAM1.0 robot brain models. Detailed quantitative evaluation uses the $π_{0.5}$ implementation. On conveyor-belt manipulation, \method reduces offline joint-action error by approximately 22.5\% relative to the original $π_{0.5}$ model. It also improves phase-transition modeling and cross-phase action prediction. These results demonstrate the value of ordered future-phase planning for continuous action generation.

## 1. 核心问题与整体含义

- **研究背景**：机器人脑模型（robot brain models）整合视觉、语言与机器人状态，面向复杂操控任务生成动作。典型实现是视觉-语言-动作（VLA）策略，例如 π0、π0.5、OpenVLA 等。
- **核心问题**：现有 VLA 策略大多预测固定长度的动作块（action chunk）。这类动作块可能跨越多个任务阶段，例如“等待 → 抓取 → 释放 → 返回”。同一条动作块内部不同位置可能属于不同阶段，但模型对此缺乏显式建模。
- **问题后果**：
  - 固定长度动作块会**模糊阶段转换位置**，使策略难以精确判断何时从等待切换为动作、从动作切换为释放。
  - 训练时如果某些阶段（如等待、运输）样本频率远高于短促阶段（如释放、阶段转换），动作优化会偏向频繁模式，但实际执行更需要精确的转换时序。
  - 相同平均动作误差的策略，可能具有截然不同的阶段转换时序和闭环行为。
- **整体含义**：需要一种**位置对齐的任务进度表示**，显式描述动作块内部每个未来位置所属任务阶段及其顺序，从而将任务级时间结构与连续动作生成对齐。

## 2. 方法论

### 2.1 核心思想

PhasePlan 在动作块内部引入**有序未来阶段规划**：对每个未来动作位置预测一个任务阶段分布，并用该分布与对应的规划表示条件化该位置的动作生成。这样既能保留阶段类别，也能保留阶段转换发生的位置。

### 2.2 输入与阶段定义

- 在时间步 \(t\)，策略输入为：
  \[
  o_t = (I^{\text{head}}_t,\, I^{\text{wrist}}_t,\, s_t,\, \ell)
  \]
  其中包含头视角 RGB、腕视角 RGB、机器人本体状态和语言指令。
- 策略输出未来动作块：
  \[
  A_t = (a_{t+1}, \dots, a_{t+H}),\quad a_{t+h}\in\mathbb{R}^{d_a}
  \]
  实验中 \(H=16\)。
- 每个未来动作位置有任务阶段标签 \(z_{t+h}\in \mathcal{Z}_\tau\)。传送带任务使用四阶段词汇表：
  \[
  \text{Wait} \rightarrow \text{Act} \rightarrow \text{Release} \rightarrow \text{Return-Home}
  \]
- 阶段标签由 VLX-Seek 物体标注、记录的夹爪状态和任务特定时序规则自动构造。

### 2.3 有序未来阶段规划器

- 引入 \(H\) 个可学习阶段查询 \(u_1,\dots,u_H\)，每个查询对应一个未来动作位置。
- 所有查询共享同一观测上下文 \(X_t=E(o_t)\)，但每个查询保留自身位置身份：
  \[
  Q_{t,h} = P_{\theta_P}(u_h, X_t),\qquad p_{t,h} = \mathrm{softmax}(W_z Q_{t,h}+b_z)
  \]
- \(Q_{t,h}\) 是上下文规划表示，\(p_{t,h}\) 是未来第 \(h\) 个位置的任务阶段分布。
- 规划器使用**独立查询**结构；有序性来自 \(u_h \leftrightarrow z_{t+h} \leftrightarrow a_{t+h}\) 的逐位置对应关系。
- 训练目标为逐位置阶段分类损失：
  \[
  \mathcal{L}_{\text{phase}} = -\frac{1}{|V_t|}\sum_{h\in V_t}\log p_{t,h}[z_{t+h}]
  \]
  该损失同时保留阶段类别和阶段转换的时间位置。

### 2.4 计划条件化动作生成

- 对每个位置，将阶段分布 \(p_{t,h}\) 映射为软阶段嵌入，并与规划表示融合：
  \[
  \bar{e}_{t,h} = E_z^\top p_{t,h},\qquad e_{t,h} = W_Q Q_{t,h} + W_P \bar{e}_{t,h}
  \]
- 轻量网络 \(f_{\theta_M}\) 根据 \(e_{t,h}\) 预测缩放和偏移参数：
  \[
  (\gamma_{t,h}, \beta_{t,h}) = f_{\theta_M}(e_{t,h})
  \]
- 对对应动作 token 进行调制：
  \[
  \tilde{x}_{t,h} = (1+\gamma_{t,h}) \odot \mathrm{RMSNorm}(x_{t,h}) + \beta_{t,h}
  \]
- \(f_{\theta_M}\) 的最终投影层采用零初始化，保证适配初期不改变预训练动作路径行为。
- 每个 \(e_{t,h}\) 只影响对应的 \(x_{t,h}\)，保持计划与动作在整条动作块上的位置对齐。

### 2.5 两阶段训练与推理

- **第一阶段**：只优化 \(\mathcal{L}_{\text{phase}}\)，训练阶段查询和规划器层；动作专家冻结。
- **第二阶段**：冻结已选定的规划器，优化原始 flow-matching 动作目标 \(\mathcal{L}_{\text{flow}}\)，更新动作专家和逐位置调制路径。
- 两阶段分解使规划表示先获得稳定时间语义，再用于指导动作生成。
- 推理流程：
  \[
  o_t \rightarrow (Q_{t,1:H},\, p_{t,1:H}) \rightarrow A_t
  \]
  规划器与条件化路径位于同一 PhasePlan 模型中，部署输入仍为标准 RGB、状态和语言指令。

## 6. 主要结论与发现

- 独立查询规划器在传送带验证集上达到约 **92.5% 的逐位置未来阶段准确率**，阶段转换类型准确率约 **89%**；随预测范围增加，准确率下降平缓。
- 视觉输入对阶段预测非常重要：仅状态

和语言输入的变体准确率明显下降；打乱 RGB 图像顺序也会显著削弱阶段预测性能，说明规划器依赖完整视觉空间信息。动作条件化方面，完整规划特征优于仅阶段 ID 条件化；在动作适配期间冻结规划器能保持规划语义稳定，优于继续更新规划器。使用真值阶段标签的 oracle 上界进一步说明阶段标签质量对性能上限的影响。逆阶段频率加权可以提升手命令准确率，印证类别不平衡对动作学习的影响。框级视觉监督有助于规划器将注意力集中到目标包裹区域。MuJoCo 仿真和物理传送带部署中，PhasePlan 的 Wait→Act→Release→Return-Home 转换更稳定，减少了提前释放、延迟抓取和过渡抖动。在 AcrossWAM1.0 上的定性部署显示该方法可作为插件式改造迁移到其他 VLA 模型。

综上，PhasePlan 通过有序未来阶段规划与位置对齐条件化，在不改变标准观测输入的前提下，增强了动作块内部的任务阶段一致性和转换时序准确性。
