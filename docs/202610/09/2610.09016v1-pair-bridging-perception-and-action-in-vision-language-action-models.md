## 摘要
视觉-语言-动作（VLA）模型将视觉观测和语言指令映射为连续机器人动作。该任务需要从描述场景和指令的表示过渡到支持动作生成的表示。许多连续动作 VLA 使这一过渡保持隐式，并主要通过最终动作预测损失进行监督。我们提出 PAIR，一个学习这两个空间之间共享感知-动作表示的框架。在训练期间，掩码动作自编码器将专家动作块编码为与时间范围对齐的动作潜在令牌。桥接模块从当前视觉-语言表示中提取任务相关特征。PAIR 将这些特征与动作潜在令牌对齐，形成桥接令牌，这些令牌保留任务信息并捕获专家动作的结构。随后，桥接令牌被投影到动作令牌空间，并注入初始动作令牌，为动作专家细化提供动作就绪的起点。在推理时，自编码器被移除，桥接令牌仅从当前观测和指令生成。在 LIBERO、LIBERO-Plus 和 CALVIN ABC-D 上的实验显示，所评估的 OpenVLA-OFT 和 VLA-Adapter 模型获得了提升。在 LIBERO-Plus 上，PAIR 将 VLA-Adapter 的成功率从 59.1% 提高到 64.2%。在 CALVIN 上，它将 VLA-Adapter 的平均完成任务序列长度从 4.42 提高到 4.53。在七个真实世界任务中，PAIR 将 OpenVLA-OFT 的成功率从 51.4% 提高到 65.0%。表示分析表明，桥接令牌在动作专家细化之前保留了任务信息，同时使连续动作信息可访问。这些结果支持共享中间表示作为连续动作 VLA 中感知与动作之间的有用接口。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions to continuous robot actions. This task requires a transition from representations that describe the scene and instruction to representations that support action generation. Many continuous-action VLAs leave this transition implicit and supervise it mainly through the final action-prediction loss. We introduce PAIR, a framework that learns a shared perception-action representation between these two spaces. During training, a Masked Action Autoencoder encodes expert action chunks into horizon-aligned Action Latent Tokens. A Bridge Module extracts task-relevant features from the current visual-language representations. PAIR aligns these features with the Action Latent Tokens to form Bridge Tokens that preserve task information and capture the structure of expert actions. The Bridge Tokens are then projected into the action-token space and injected into the initial Action Tokens, providing an action-ready starting point for Action Expert refinement. At inference, the autoencoder is removed, and the Bridge Tokens are generated only from the current observation and instruction. Experiments on LIBERO, LIBERO-Plus, and CALVIN ABC-D show gains for the evaluated OpenVLA-OFT and VLA-Adapter models. On LIBERO-Plus, PAIR raises VLA-Adapter's success rate from 59.1% to 64.2%. On CALVIN, it increases VLA-Adapter's average completed sequence length from 4.42 to 4.53. Across seven real-world tasks, PAIR raises OpenVLA-OFT's success rate from 51.4% to 65.0%. Representation analyses show that Bridge Tokens retain task information while making continuous-action information accessible before Action Expert refinement. These results support a shared intermediate representation as a useful interface between perception and action in continuous-action VLAs.

## 1. 论文的核心问题与整体含义

- **核心问题**：连续动作视觉-语言-动作（VLA）模型需要将“感知空间”（视觉观测 + 语言指令）转换为“动作空间”（连续控制信号），但二者在语义组织上差异很大：
  - 感知空间描述场景内容、物体关系、任务意图；
  - 动作空间描述具有时间顺序、可执行的机器人控制量。
- **现有局限**：多数连续动作 VLA 将这一“感知—动作表示鸿沟”留给最终动作预测损失隐式学习，缺乏显式的中间表示来组织从任务语义到动作结构的过渡。
- **整体含义**：论文提出并验证了一个假设：可以从配对演示数据中直接学习一个**共享的感知—动作中间表示**，让感知侧提供任务语义、动作侧提供可执行结构，从而提升 VLA 在下游操作、泛化和长程执行中的性能。

## 2. 论文提出的方法论

### 2.1 总体框架

PAIR 的核心是学习**Bridge Tokens（桥接令牌）**，作为感知与动作之间的显式接口。训练分为两个阶段：

1. **第一阶段**：训练 Masked Action Autoencoder（掩码动作自编码器），从专家动作块中学习动作结构。
2. **第二阶段**：冻结该自编码器；Bridge Module 从视觉—语言表示中提取任务特征，并与动作潜在令牌对齐；最后将 Bridge Tokens 注入 Action Expert 的输入端。

### 2.2 Masked Action Autoencoder（动作侧）

- 对专家动作块 \(A \in \mathbb{R}^{H \times d_a}\) 进行**随机掩码**和**高斯噪声扰动**，得到损坏轨迹 \(\tilde{A} = C(A)\)。
- 编码器 \(E_A\) 使用自注意力建模动作时间依赖，输出 **Action Latent Tokens**：
  \[
  \tilde{Z}_A = E_A(\tilde{A}) \in \mathbb{R}^{H \times d_z}
  \]
- 解码器 \(D_A\) 重建干净轨迹 \(\hat{A}_{AE} = D_A(\tilde{Z}_A)\)，使用 \(\ell_1\) 重建损失：
  \[
  \mathcal{L}_{AE} = \frac{1}{H}\sum_{i=1}^{H}\|\hat{a}_{AE,i} - a_i\|_1
  \]
- 第一阶段后冻结自编码器；PAIR 训练时用干净专家动作生成参考令牌 \(Z_A = \text{sg}[E_A(A)]\)。

### 2.3 Bridge Module（感知侧）

- 使用 \(H\) 个可学习查询 \(Q_B = [q_1,\dots,q_H]\)；
- 通过**交叉注意力**从视觉—语言表示 \(H_{VL}\) 中提取任务相关信息，并用**自注意力**协调时间范围：
  \[
  B = G_\phi(Q_B, H_{VL}) \in \mathbb{R}^{H \times d_b}
  \]
- 此时 \(B\) 是紧凑、任务相关、逐时间步对齐的表示，称为 **Bridge Tokens**。

### 2.4 跨空间对齐

- 通过 Alignment Projector \(P_{align}\) 将 Bridge Tokens 与 Action Latent Tokens 逐时间步对齐，使用余弦相似度损失：
  \[
  \mathcal{L}_{align} = \frac{1}{H}\sum_{i=1}^{H}\left[1 - \cos\left(P_{align}(b_i), z_{A,i}\right)\right]
  \]
- 其作用：让感知侧表示的内容按照动作潜在结构组织，形成同时携带任务语义与可执行结构的 Bridge Tokens。

### 2.5 Bridge Injection（桥接注入）

- 将 Bridge Tokens 投影到 Action Token 空间，并用**可学习的门控**调节注入强度：
  \[
  \tilde{X}_A^0 = X_A^0 + \tanh(G_g(B)) \odot P(B)
  \]
- 注入位置在 **Action Expert 的输入端**，使 Action Tokens 从“动作就绪”的中间状态开始细化。

### 2.6 训练与推理

- 第二阶段目标：
  \[
  \mathcal{L}_{PAIR} = \mathcal{L}_{act} + \lambda_{align}\mathcal{L}_{align}
  \]
  其中 \(\mathcal{L}_{act}\) 是原始连续动作预测损失，\(\lambda_{align}=0.1\)。
- **推理时移除 Action Autoencoder**，只使用 Bridge Module 从当前观测和指令生成 Bridge Tokens，再进行 Bridge Injection。

## 6. 论文的主要结论与发现

- **PAIR 能一致提升多个 backbone**：
  - LIBERO：VLA-Adapter 平均成功率从 97.3% 提升到 **98.4%**；
  - LIBERO-Plus：总体成功率从 59.1% 提升到 **64.2%**，七类 OOD 全部提升；
  - CALVIN：OpenVLA-OFT 平均完成序列长度从 4.28 提升到 4.40；VLA-Adapter 从 4.42 提升到 **4.53**；
  - 真实世界：OpenVLA-OFT 平均成功率从 51.4% 提升到 **65.0%**，七个任务全部提升。
- **表示分析支持设计假设**：
  - Bridge Tokens 同时具有高任务解码准确率（87.8%）和高动作簇解码准确率（91.5%）；
  - Bridge Tokens 在进入 Action Expert 前连续动作解码 \(R^2\) 已达 0.878，高于 baseline 最终层 0.844；
  - Bridge Tokens 与 ground-truth 动作几何结构保持高度一致（RSA 0.878、top-10 重叠 80.4%）。
- **关键设计选择**：
  - 早期注入优于端部、中间或全层注入；
  - 动作潜在令牌作为对齐目标优于原始专家动作；
  - 对齐损失与自编码器噪声训练均对性能有正向贡献。

## 7. 优点

- **问题定位清晰**：明确将“感知—动作表示鸿沟”作为核心研究对象，不只是堆模型或数据。
- **方法设计合理且可插拔**：PAIR 不改变原 VLA 主结构，只需 Bridge Module + 训练时 Action AE；推理时无额外动作自编码器，部署代价低。
- **训练与推理解耦**：动作结构只在训练时通过专家动作提供，推理阶段仅依赖当前观测和指令，避免依赖动作编码器。
- **机制验证充分**：通过线性探测、逐层动作解码和几何分析，从表示层面证明 Bridge Tokens 确实在 Action Expert 之前提供了动作相关信息。
- **跨场景与跨 backbone 验证**：在多个模拟基准、真实机器人任务、两个不同 VLA backbone 上均显示提升，泛化证据较强。
- **消融设计细致**：覆盖注入位置、对齐权重、对齐目标、注入强度和噪声训练等关键因素。

## 8. 不足与局限

- **提升幅度在某些基准上较小**：CALVIN 上平均序列长度提升约 0.1–0.13，五任务成功率的提升可能需要更多次运行才能判断是否稳定优于噪声。
- **真实实验规模有限**：仅 7 个任务、每任务 20 次测试，且只在 OpenVLA-OFT 上验证；没有展示 VLA-Adapter 或更大规模真实数据上的 PAIR 效果。
- **未明确报告训练时长和推理开销的定量影响**：虽然推理时移除了 Action AE，但 Bridge Module 仍增加一定计算；论文没有明确墙钟时间或推理延迟。
- **表示分析的数据范围较窄**：主要基于 LIBERO-Spatial 的 500 帧，是否对其他套件、任务或真实场景同样成立尚不清楚。
- **对比公平性存在一定挑战**：与多个外部方法比较时，训练数据、模型规模和调优程度可能存在差异，正文主结果主要依赖与自身 backbone 的比较。
- **应用限制**：PAIR 假设训练数据包含成对的视觉—语言上下文和专家动作块；在缺少专家动作演示或仅依赖视频预训练数据的场景中，其适用性未得到验证。
