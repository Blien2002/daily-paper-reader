## 摘要
视觉-语言-动作（VLA）模型越来越依赖基于扩散或流匹配的动作头来生成连续机器人动作。这些动作头通常以大致均匀的方式处理去噪轨迹。然而，我们观察到，条件化关注点在去噪阶段之间自然转移：早期阶段结合语言指令和视觉观测来建立粗略的动作轨迹，而后期阶段则更侧重于当前视觉观测以实现动作对齐。基于这一见解，我们提出了 StairVLA，一个阶段感知的分层动作生成框架，该框架利用部分去噪的动作作为粗略长时程动作生成与局部细化之间的自然接口。高层 VLA 执行早期去噪，生成可复用的长时程部分去噪动作轨迹，而轻量级细化器以更高频率运行，利用最新观测来细化局部动作块。这种设计分摊了昂贵的高层 VLA 计算，同时保留了频繁的闭环校正。在 LIBERO 上，我们的 GR00T 风格实例将平均成功率从 96.5% 提高到 97.8%，同时将每个动作块的摊销推理延迟从 115.0 ms 降低到 44.2 ms。更广泛地，在两个 VLA 主干、仿真基准和真实机器人任务上，StairVLA 持续降低推理成本，同时保持强大的任务性能。

## Abstract
Vision-language-action (VLA) models increasingly rely on diffusion- or flow-matching-based action heads to generate continuous robot actions. These action heads typically process the denoising trajectory in a largely uniform manner. However, we observe that the conditioning focus naturally shifts across denoising stages: early stages combine language instructions and visual observations to establish a coarse action trajectory, whereas later stages place greater emphasis on current visual observations for action alignment. Based on this insight, we introduce StairVLA, a stage-aware hierarchical action generation framework that uses partially denoised actions as a natural interface between coarse long-horizon action generation and local refinement. A high-level VLA performs early denoising to produce a reusable long-horizon partially denoised action trajectory, while a lightweight refiner operates at a higher frequency to refine local action chunks using the latest observations. This design amortizes expensive high-level VLA computation while preserving frequent closed-loop correction. On LIBERO, our GR00T-style instantiation improves average success from 96.5% to 97.8% while reducing amortized inference latency from 115.0 ms to 44.2 ms per action chunk. More broadly, across two VLA backbones, simulation benchmarks, and real-robot tasks, StairVLA consistently reduces inference cost while maintaining strong task performance.

### 1. 论文的核心问题与整体含义

- **核心问题**：现有基于扩散或流匹配的 VLA（Vision-Language-Action）模型，其动作头在去噪过程中通常以近似均匀的方式融合语言指令、视觉观测和机器人状态。但作者观察到，不同去噪阶段对条件信息的依赖并不相同：早期阶段更依赖语言指令与视觉观测协同生成粗略动作轨迹，后期阶段则更依赖当前视觉观测进行局部对齐与细化。
- **整体含义**：这种“阶段依赖性”表明 VLA 动作生成并非同质的去噪过程，可以被自然地分解为“低频高层任务规划”与“高频低层局部修正”。因此，作者提出 StairVLA，利用部分去噪的动作轨迹作为高低层之间天然的通信接口，以摊销高层大模型推理成本，同时保持闭环响应能力。

### 2. 论文提出的方法论

- **核心思想**：将 VLA 动作生成显式划分为两个阶段：
  - **高层 VLA**：低频执行早期去噪，生成一个长时程、部分去噪的动作轨迹（默认 horizon \(H=32\)），并缓存复用。
  - **低层 Refiner**：高频执行剩余去噪，以最新视觉观测和缓存的部分去噪动作段为输入，输出局部可执行动作块（默认 \(h=5\)）。
- **关键技术细节**：
  - **高层 VLA** 保留原 VLA 架构（如 GR00T 或 π 风格），只在推理时提前终止去噪，输出部分去噪轨迹 \(a_\alpha\)（默认 \(\alpha=0.97\)）。
  - **低层 Refiner** 采用 GR00T 风格 DiT：使用 SigLIP-B/16 视觉编码器处理当前观测，并将高层 VLM 最后层隐状态经自适应平均池化压缩为固定数量 token 作为高层条件；动作侧包含机器人状态 token、可学习未来 token 和当前查询动作块。
  - **训练路径重构**：由于高层输出不一定处于理想去噪路径上，训练时从高层输出 \(a_\alpha\) 反推虚拟原点 \(\epsilon_{\text{ref}} = \frac{a_\alpha - \alpha a_{\text{gt}}}{1-\alpha}\)，并构造细化目标速度 \(v_{\text{ref}} = \frac{a_{\text{gt}} - a_\alpha}{1-\alpha}\)，采样 \(\tau \sim U(\alpha,1)\) 生成中间输入进行训练。
  - **多频率推理**：高层 VLA 每 \(M\) 次低层细化周期调用一次，平均每块动作成本 \(T(M)=T_{\text{ref}} + T_{\text{high}}/M\)；\(M\) 控制效率与新鲜度的权衡。
- **算法流程**：高层从噪声开始流匹配去噪至进度 \(\alpha\) 停止 → 缓存部分去噪轨迹 → 对每个局部窗口，低层 Refiner 结合最新观测和该窗口动作段继续去噪至 \(\tau=1\) → 输出可执行动作块；步骤重复 \(M\) 次后刷新高层轨迹。

### 6. 论文的主要结论与发现

- 阶段依赖性：VLA 动作生成中，早期阶段更侧重语言与视觉的联合条件化，后期阶段更依赖视觉观测进行局部对齐；部分去噪动作本身已编码一定任务结构。
- StairVLA 有效性：在 LIBERO 上，GR00T 风格实例将平均成功率从 96.5% 提升至 97.8%，摊销延迟从 115.0 ms 降至 44.2 ms；π 风格骨干同样取得一致提升。
- 跨任务泛化：在 LIBERO-Plus 上零样本表现与代表性方法相当，监督微调后达到 83.7% 平均成功率；真实机器人上性能与效率同步提升。
- 权衡规律：高层轨迹重用存在有效范围，过长 horizon 导致性能下降，需要自适应刷新机制。

### 7. 优点

- **自然接口设计**：直接使用部分去噪动作作为高低层之间的接口，避免外部设计的子目标、路径点或宏观动作抽象，模块间通信简单直接。
- **效率提升显著**：在保持甚至提升成功率的同时，将延迟降低约 2.6 倍，适合低算力部署场景。
- **跨骨干通用性**：在 GR00T 和 π 两种代表性 VLA 骨干上均验证有效，方法不限于特定架构。
- **实验与分析的深度**：包含阶段依赖注意力、masking、路径重构误差、额外指令条件化等一系列诊断性分析，为理解去噪过程提供洞见。
- **真实机器人验证**：不局限于仿真，在真实机械臂上验证了性能与运动平滑度的改善。

### 8. 不足与局限

- **零样本视觉扰动敏感**：低层 Refiner 主要依赖视觉观测，在相机变化等图像扰动下零样本性能下降明显，需要监督微调才能恢复。
- **长时程复用有限**：延长高层预测 horizon（如 H=48、H=64）并不能无限提升复用范围，过长时间复用会导致高层轨迹与实际状态不一致，性能明显退化。
- **比较基准不完全公平**：不同方法在延迟定义、chunk size、额外监督和硬件平台上的差异导致数值比较不够严格。
- **超参依赖**：训练 / 推理去噪进度、重用 horizon \(M\)、局部 chunk size \(h\) 等需要手动调节，缺乏自适应机制。
- **额外训练成本与复杂性**：需要两阶段训练，且低层 Refiner 需要额外使用 SigLIP 视觉编码器和压缩 token，整体流程比单一 VLA 更复杂。
- **任务场景相对有限**：真实机器人仅测试了 Fruit25 和 PushBlock 两类操纵任务，缺少更复杂的接触丰富或动态环境验证。
