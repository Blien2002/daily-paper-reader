## 摘要
视觉-语言-动作（VLA）模型在机器人操作方面表现出色，但在每个控制步骤处理长 token 序列会带来高昂计算成本，限制实时部署。视觉 token 剪枝提供了一种直接解决方案，因为视觉图像块在输入序列中占主导地位且包含大量冗余。然而，现有方法要么依赖间接的免训练启发式规则（如注意力分数和运动阈值），要么需要对基础 VLA 模型进行昂贵的微调。我们提出 VLA-ACL（动作一致性学习），它在完全冻结基础 VLA 模型的同时，通过动作级监督学习轻量级视觉 token 剪枝策略。训练目标鼓励由剪枝后视觉上下文产生的动作与全上下文教师保持一致，并利用真值动作作为辅助监督。这直接将 token 选择与其对下游控制输出的影响联系起来。在 LIBERO 和真实世界操作任务上的实验表明，VLA-ACL 可剪除高达 87.5% 的视觉 token，同时保持竞争力的性能，计算量最多降低 75%，推理速度提升 1.5 倍。这些结果建立了比现有冻结 VLA 剪枝方法更强的性能-效率权衡，并证明了动作级监督对视觉 token 选择的价值。代码见 https://github.com/du-owen/VLA-ACL。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but incur high computational costs from processing long token sequences at every control step, limiting real-time deployment. Visual token pruning offers a direct solution, as visual patches dominate the input sequence and contain considerable redundancy. Existing approaches, however, either rely on indirect training-free heuristics, such as attention scores and motion thresholds, or require costly fine-tuning of the base VLA model. We introduce VLA-ACL (Action Consistency Learning), which learns a lightweight visual token pruning policy through action-level supervision while keeping the base VLA model entirely frozen. The training objective encourages actions produced from pruned visual contexts to remain consistent with the full-context teacher, with ground-truth actions as auxiliary supervision. This directly ties token selection to its effect on the downstream control output. Experiments on LIBERO and real-world manipulation tasks show that VLA-ACL prunes up to 87.5% of visual tokens while retaining competitive performance, reduces computation by up to 75%, and achieves a 1.5x inference speedup. These results establish a stronger performance-efficiency trade-off than existing frozen-VLA pruning methods and demonstrate the value of action-level supervision for visual token selection. Code is available at https://github.com/du-owen/VLA-ACL.

- **研究背景**：视觉-语言-动作（VLA）模型在机器人操控中表现强大，但每个控制步骤都要处理由视觉 token 主导的长序列，导致计算开销大、延迟高，难以满足实时部署需求。
- **核心问题**：如何在尽量不损失操控性能的前提下，大幅减少 VLA 推理时处理的视觉 token 数量。
- **现有方法不足**：
  - 免训练剪枝方法依赖注意力分数、运动阈值等间接启发式，不能直接反映 token 删除对最终动作的影响，且常需要精细调参或访问模型内部状态。
  - 训练式剪枝方法需要微调整个 VLA 骨干，成本高（可能需要多天、多 GPU），且剪枝器与骨干耦合，灵活性差。
- **本文核心思路**：在完全冻结基础 VLA 模型的前提下，仅训练一个轻量级视觉 token 剪枝策略，通过**动作级监督**直接学习“哪些视觉 token 对最终动作重要”，从而在保持高性能的同时显著降低推理开销。

## 2. 方法论

- **总体框架 VLA-ACL（Action Consistency Learning）**：
  - 冻结原始 VLA 的视觉编码器、语言骨干和动作解码器。
  - 训练一个小型 Transformer 补丁评分网络（patch scorer），对每个视觉 token 打分。
  - 推理时每个相机视角保留得分最高的 K 个 token，进入语言骨干；训练时用可微软剪枝近似硬剪枝，使梯度能够回传。

- **关键组件与技术细节**：
  - **补丁评分网络**：5 层双向 Transformer，输入视觉编码器输出的嵌入，输出每个 token 的 logit 分数。
  - **硬剪枝（推理）**：按分数降序排序，保留 Top-K token，保留原始 RoPE 位置索引以维持空间关系。
  - **软 Top-K 松弛（训练）**：  
    $$s = \text{SoftTopK}(l), \quad s_i = \text{Lap}\Big(\frac{l_i - \theta_K}{\alpha}\Big), \quad \sum_{i=1}^{N_e} s_i = K$$
    其中 $\alpha$ 控制软化程度，训练时从 2.0 余弦退火到 0.1，逐步逼近硬剪枝。
  - **可微门控**：用全黑图像经同一视觉编码器得到黑 patch 嵌入 $b$，按软分数将原始嵌入与黑嵌入混合：  
    $$\tilde{X}_i = X_i \cdot s_i + b_i \cdot \sqrt{1 - s_i^2}$$
    低分 token 被黑 patch 替代，保持替换向量在模型训练分布内。
  - **动作级监督目标**：  
    $$\mathcal{L}_{\text{acl}} = \lambda \|\tilde{a} - a\|_1 + \mu \|\tilde{a} - a_{gt}\|_1$$
    其中 $\tilde{a}$ 为软剪枝后的预测动作，$a$ 为全上下文教师预测，$a_{gt}$ 为真值动作；实验取 $\lambda=\mu=0.5$。
  - **多视角处理**：评分网络联合处理所有视角嵌入，但剪枝和门控按每个视角独立执行，每个视角预算为 K。
  - **训练配置**：仅训练补丁评分网络，AdamW 优化器，学习率 $1\times10^{-4}$，batch size 8，共 5000 步。

## 6. 主要结论与发现

- VLA-ACL 在冻结基础 VLA 的条件下，通过动作一致性学习能够有效选择视觉 token。
- 在 LIBERO 上，K=32 时平均成功率 95.4%（基线 96.8%），计算量降低 75%，推理加速 1.5 倍；K=64 时平均成功率 97.0%（略超基线），计算量降低 65%，加速 1.4 倍。
- 真实世界任务中，K=64 平均成功率 72.5% vs 基线 73.75%，FLOPs 减少超过 50%，加速约 1.5 倍。

- 动作级监督比注意力启发式更直接有效；黑 patch 门控比噪声门控或纯乘法门控更接近硬剪枝行为，训练-部署差距更小。
- 结论：动作一致性是有效的视觉 token 选择学习信号，VLA-ACL 建立了更强的性能-效率 Pareto 前沿。

## 7. 优点

- **无需微调基础 VLA**：保持原始策略模型冻结，训练成本极低（单卡几小时），部署灵活。
- **直接优化下游控制效果**：以动作一致性作为监督信号，使剪枝决策与任务性能强相关。
- **兼容现有加速技术**：不修改注意力内部结构，与 FlashAttention、torch.compile 等兼容。
- **训练-推理一致性**：软 Top-K 退火和黑 patch 门控设计缩小软剪枝与硬剪枝之间的差距。
- **通用性强**：在 OpenVLA-OFT 和 π0.5 两种不同动作解码范式的 VLA 上均有效，且超参数无需骨干特化调整。
