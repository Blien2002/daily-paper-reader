## 摘要
视觉-语言-动作策略依赖大型多模态骨干网络，在每个控制步骤中同时执行感知、语言条件化和动作生成。这种能力很大一部分用于支持开放域语义，而连续机器人操作主要需要观察、动作以及由动作引起的状态转移的紧凑表示。像素级世界模型提供了另一种途径，但预测与控制无关的视觉细节可能带来不必要的开销。我们提出 SLIM（自监督潜在交互模型），一种紧凑的 0.5B 参数潜在交互策略。SLIM 学习以动作为基础的预测潜在表示，既能捕捉以动作为条件的未来转移，也能捕捉解释观察变化的动作。SLIM 通过自监督掩码轨迹预测学习这些表示，将动作重建与未来潜在预测相结合。紧凑的混合 Transformer（MoT）骨干网络对观察潜在变量和动作 token 之间的交互进行建模。所得策略使用流匹配进行训练，以实现语言条件动作生成。在仿真基准和真实世界评估中，SLIM 在参数更少、无需额外具身预训练、推理延迟更低且 GPU 内存占用显著更低的情况下，达到或超越了代表性的大规模 VLA 和世界-动作模型基线。

## Abstract
Vision-language-action policies rely on large multimodal backbones to jointly perform perception, language conditioning, and action generation at every control step. Much of this capacity supports open-domain semantics, whereas continuous robot manipulation primarily requires compact representations of observations, actions, and the transitions induced by actions. Pixel-level world models provide another route, but predicting visual details irrelevant to control can be unnecessarily expensive. We propose SLIM (Self-supervised Latent Interaction Model), a compact 0.5B-parameter latent interaction policy. SLIM learns action-grounded predictive latents that capture both action-conditioned future transitions and the actions that explain observed changes. SLIM learns these representations through self-supervised masked trajectory prediction, combining action reconstruction with future-latent prediction. A compact Mixture-of-Transformers (MoT) backbone models interactions between observation latents and action tokens. The resulting policy is trained with flow matching for language-conditioned action generation. Across simulation benchmarks and real-world evaluation, SLIM matches or exceeds representative large-scale VLA and world-action-model baselines with fewer parameters, no additional embodied pretraining, lower inference latency, and substantially lower GPU memory usage.

- **核心问题**：能否在不依赖大型 VLM 骨干、也不进行像素级未来生成的情况下，学习一种紧凑、高效、以动作为基础的潜在交互表示，用于语言条件机器人操作？
- **整体含义**：机器人连续操作不必然需要开放域 VLM 推理或像素级未来生成；通过在观察潜在空间中显式建模“动作—观测变化”的双向关系，可以用更少的参数、更低的延迟和显存实现有竞争力的操作性能。

## 2. 论文提出的方法论

### 2.1 核心思想

SLIM（Self-supervised Latent Interaction Model）将语言条件、观察状态和动作 chunk 三者解耦：

- 语言指令负责任务条件化；
- 观察 latent 表示当前状态；
- 动作 chunk 表示连续控制轨迹；
- 主控制计算放在紧凑的 Mixture-of-Transformers（MoT）骨干中，对观察 latent 与动作 token 的交互进行建模。

SLIM 的学习目标称为 **action-grounded masked trajectory prediction**，通过自监督掩码轨迹预测，让表示同时满足：

- 动作能够解释观察变化（逆动力学方向）；
- 未来观察 latent 能够由当前观察和动作预测（前向动力学方向）。

### 2.2 表示与模型组件

- 视觉编码器：DINOv2-B/14，将多视角观察映射为若干观察 latent token \(Z_t\)。
- 未来观察 latent：使用同一视觉编码器编码未来观察 \(o_{t+H}\)，并通过 EMA（指数滑动平均）副本生成稳定目标 \(\bar{Z}_{t+H}\)。
- 语言编码器：T5-small，生成语言条件 \(\ell\)。
- MoT 骨干：包含 observation stream 与 action stream 两个交互流，通过共享 joint attention 进行跨流交互，并用 per-stream 语言交叉注意力注入语言条件。
- 未来槽位嵌入：observation stream 中维护可学习的未来槽位 \(M_z\)，用于在预测未来 latent 或部署策略时替代真正的未来观察 latent。
- 动作 token：连续动作 chunk 的嵌入，不使用离散化。

### 2.3 训练阶段

#### Stage 1：掩码轨迹预测

- **动作掩码分支（逆动力学目标）**：
  - 将干净动作 chunk \(A_t\) 替换为流匹配中的噪声版本 \(\tilde{A}_t^\tau\)；
  - 从当前观察 latent \(Z_t\)、未来观察 latent \(Z_{t+H}\)、本体感受状态 \(q_t\) 和语言 \(\ell\) 出发，预测流速度 \(V^\star_t = A_t - \epsilon\)；
  - 损失为 \(L_{\text{IDM}} = \mathbb{E}\left\| v_\theta(\tilde{A}_t^\tau, \tau \mid Z_t, Z_{t+H}, q_t, \ell) - V^\star_t \right\|^2\)。
- **未来 latent 掩码分支（前向动力学目标）**：
  - 将未来观察 latent 位置替换为可学习掩码嵌入 \(M_z\)；
  - 从当前观察 latent 和干净动作 chunk 预测未来观察 latent \(\hat{Z}_{t+H}\)；
  - 与停止梯度的 EMA 目标 \(\bar{Z}_{t+H}\) 做 L1 对齐：
  \[
  L_{\text{FDM}} = \left\| \mathrm{LN}(\hat{Z}_{t+H}) - \mathrm{LN}(\mathrm{sg}(\bar{Z}_{t+H})) \right\|_1
  \]
- 总损失：\(L_{\text{stage1}} = \lambda_{\text{IDM}} L_{\text{IDM}} + \lambda_{\text{FDM}} L_{\text{FDM}}\)，其中 \(\lambda_{\text{IDM}}=0.125\)、\(\lambda_{\text{FDM}}=1\)。

#### Stage 2：流匹配策略训练

- 与推理阶段一致，只使用当前观察 latent、可学习未来槽位 \(M_z\)、本体感受状态、语言和噪声动作 chunk；
- 不提供未来观察 latent，也不显式监督未来预测；
- 通过流匹配目标 \(L_{\text{FM}}\) 训练动作生成。

### 2.4 推理过程

- 观察 latent 和语言上下文固定；
- 策略反复更新 action stream，估计动作速度场；
- 使用 4 步流采样生成动作 chunk；
- 无需显式未来帧生成或未来 latent 条件。
