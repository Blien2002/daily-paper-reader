## 摘要
视觉-语言-动作（VLA）模型通常通过自回归文本坐标或不透明的动作标记来暴露空间定位，这在多模态推理与机器人执行之间造成了脆弱的接口。我们提出 Pointing-VLA，一种基于 Embodied-R1 构建的类型化隐藏状态空间读出机制。几何特定头预测规范化点、物体功能定位（OFG）热图和视觉轨迹，而无需将几何序列化为文本。对于所评估的 Bridge/WidowX 和物理拾放部署，一个显式执行契约将 PICK 分配给源条件化的 OFG，将 PLACE 分配给 Pointing，提供直接与阶段对齐的空间目标。Pointing-VLA 在 Bridge/WidowX 上取得了 SOTA 性能，在启用碰撞的 CuRobo 执行下，在没有 Bridge 特定微调的情况下，在评估的四任务集上平均达到 72.9%。Pointing 和 OFG 在原生和跨数据集评估中表现出互补优势。OFG/接触读出迁移到 NORA-1.5，保持或提高了成功率，同时将记录的控制器时间减少了超过 20 倍；在共享外部套件上，类型化头的速度也比 Embodied-R1 文本解码快 6.68–6.90 倍。当作为 $π_{0.5}$ 动作策略的空间引导集成时，Pointing-VLA 在三种视觉情境下将自主真实机器人成功率从 52.7% 提高到 80.7%。这些结果确立了类型化空间读出作为具身推理与机器人执行之间高效、可检查接口的地位。

## Abstract
Vision-language-action (VLA) models often expose spatial grounding through autoregressive text coordinates or opaque action tokens, creating brittle interfaces between multimodal reasoning and robot execution. We present Pointing-VLA, a typed hidden-state spatial readout built on Embodied-R1. Geometry-specific heads predict normalized points, object-functional grounding (OFG) heatmaps, and visual trajectories without serializing geometry as text. For the evaluated Bridge/WidowX and physical pick-place deployments, an explicit execution contract assigns PICK to source-conditioned OFG and PLACE to Pointing, providing direct stage-aligned spatial targets. Pointing-VLA achieves SOTA performance on Bridge/WidowX, averaging 72.9\% across the evaluated four-task set without Bridge-specific finetuning under collision-enabled CuRobo execution. Pointing and OFG show complementary strengths across native and cross-dataset evaluations. The OFG/contact readout transfers to NORA-1.5, preserving or improving success while reducing recorded controller time by more than 20$\times$; typed heads are also 6.68--6.90$\times$ faster than Embodied-R1 text decoding on a shared external suite. When integrated as spatial guidance for a $π_{0.5}$ action policy, Pointing-VLA raises autonomous real-robot success from 52.7\% to 80.7\% across three visual contexts. These results establish typed spatial readouts as an efficient, inspectable interface between embodied reasoning and robot execution.

## 1. 论文的核心问题与整体含义

- **核心问题**：现有 VLA（视觉-语言-动作）模型通常通过 **自回归文本坐标** 或 **不透明的动作 token** 来暴露空间定位信息，导致多模态推理与机器人执行之间的接口脆弱、低效且不可检查。
- **具体痛点**：
  - 文本坐标生成需要逐 token 拼写数字，推理和解析开销大；
  - 文本生成可能无法产出可解析坐标，或坐标语法正确但空间位置错误；
  - 动作 token 虽然免去解析，但隐藏了空间推理依据，难以审计和调试。
- **整体含义**：论文主张将 **具身空间定位（embodied grounding）视为“类型化接口预测”**，而不是文本坐标生成；即直接输出点、功能区域、视觉轨迹等不同几何类型，而非将其序列化为文本。
- **理论背景**：借鉴神经科学中的“视觉-动作双通路”与“群体读出（population readout）”观点，认为下游执行器应从分布式内部表征中直接解码空间变量，而不是通过表征系统本身序列化输出。
- **核心贡献定位**：提出 Pointing-VLA，在 Embodied-R1 基座上构建轻量级类型化隐藏状态空间读出，并以显式执行契约连接空间目标与机器人执行阶段。

## 2. 论文提出的方法论

### 2.1 总体架构

- Pointing-VLA 基于 **Embodied-R1** 骨干，冻结大部分参数，只训练 **Grounding Adapter**、各几何头和少量 LoRA 参数。
- 系统包含三类几何专用输出头：
  - **Pointing head**：预测归一化图像坐标点；
  - **OFG head（object-functional grounding）**：预测物体功能区域热图；
  - **VTG head（visual trajectory generation）**：预测视觉轨迹/路点序列。
- 几何头直接从共享多模态隐藏状态解码，不经过文本生成与解析。

### 2.2 隐藏状态读出机制

- 设多模态隐藏状态为 \(H_e^{mm} = \{h_e^i\}_{i=1}^N\)，索引 \(e \in \{pt, ofg, vtg\}\)。
- 共享 Grounding Adapter 将序列投影到接地空间，并用专家特定任务条件查询读取：
  \[
  X_e = W_e^h H_e^{mm} + P_e
  \]
  \[
  A_e = \operatorname{softmax}\left(\frac{(Q_e W_e^Q)(X_e W_e^K)^\top}{\sqrt{d}}\right)
  \]
  \[
  G_e = \operatorname{FFN}_e(A_e X_e W_e^V),\quad g_e = \operatorname{Pool}(G_e)
  \]
- 点与 OFG 专家使用 **8 个接地查询**；VTG 专家使用学习的时间查询直接关注完整多模态序列。

### 2.3 Pointing 头

- 使用学习指针查询 \(q_{pt}\) 对接地 token \(G_{pt}\) 做注意力，得到 \(z_{pt}\)。
- 经线性层、LayerNorm、sigmoid 输出归一化坐标 \((\hat{x}, \hat{y}) \in [0,1]^2\)。
- 像素坐标为 \((\hat{u}, \hat{v}) = ((W-1)\hat{x}, (H-1)\hat{y})\)。
- 采用 **point-in-box（PIB）** 或 **point-in-mask（PIM）** 评估。

### 2.4 OFG 头

- 保留视觉塔 2D 特征图 \(F_{vis}\)，用全局接地摘要 \(g_{ofg}\) 通过 FiLM 调制：
  \[
  F'_{ofg} = \gamma(g_{ofg}) \odot F_{vis} + \beta(g_{ofg})
  \]
- 卷积热图解码器输出热图 logits \(\hat{H}_{ofg}\)，取归一化峰值作为功能接触点。
- 支持密集掩码或高斯关键点监督。

### 2.5 VTG 头

- 学习路点查询 \(q_{\tau t}\)（带时间编码），按顺序关注多模态序列，输出 T=8 个归一化图像空间路点。
- 指标为 RMSE、ADE、FDE。

### 2.6 执行契约与坐标转换

- **PICK/PLACE 契约** 固定为：
  - **PICK**：源条件化 OFG 热图峰值；
  - **PLACE**：Pointing 预测的归一化点。
- 查询构造：
  \[
  q_{pick} = T_{pick}(\ell, c_{src}),\quad q_{place} = T_{place}(\ell, c_{goal})
  \]
  其中 \(\ell\) 为指令，\(c_{src}\) 为源物体描述，\(c_{goal}\) 为目标描述。
- 图像空间目标经深度 \(D\)、相机内参 \(K\)、相机到机器人变换 \(T_{r \leftarrow c}\) 转换到机器人坐标系：
  \[
  \tilde{p} = [\hat{u}, \hat{v}, 1]^\top,\quad X_c = D(\hat{u}, \hat{v}) K^{-1} \tilde{p},\quad \bar{X}_r = T_{r \leftarrow c} \bar{X}_c
  \]

### 2.7 训练目标与阶段

- 总损失：
  \[
  \mathcal{L} = \lambda_{pt}\mathcal{L}_{pt} + \lambda_{box}\mathcal{L}_{box} + \lambda_{ofg}\mathcal{L}_{ofg} + \lambda_{vtg}\mathcal{L}_{vtg} + \lambda_{aux}\mathcal{L}_{aux}
  \]
- 点与轨迹用 SmoothL1；OFG 用 MSE（高斯关键点）或类别平衡 BCE（密集掩码）。
- 源条件 OFG 专门化：联合更新 OFG LoRA、共享 Grounding Adapter 主体、OFG 学习查询和热图解码器，使用密集源掩码重建、源-干扰项排序与干扰抑制。
- 最终 Pointing 模型加入 **GRPO 风格组归一化细化**：
  - 以预测点 \(\mu\) 为策略中心，\(\sigma = \exp(s)\)，采样 \(a_i = \operatorname{clip}(\mu + \sigma \epsilon_i, 0, 1)\)；
  - 奖励：在目标框内为 1，否则按距离衰减；
  - 组归一化优势后优化策略，同时加入 SFT 平滑损失、KL 参考损失和 \(\sigma\) 正则。
- 训练分阶段：几何预热 → LoRA 专门化 → 任务继续（只更新所需子集）。

## 6. 核心结论与局限

- **核心结论**：Pointing-VLA 通过将空间定位重构为类型化隐藏状态读出，在保持多模态推理能力的同时，显著提升了空间目标指定的准确性、可解释性和可执行性；固定执行契约（PICK=源条件 OFG，PLACE=Pointing）进一步降低了解析不确定性，并在仿真与真实机器人上证明了可行性。
- **方法优势**：
  - 无需文本坐标解析，避免语法错误和空间歧义；
  - 几何头直接从共享隐藏状态解码，保留分布式表征中的空间信息；
  - 类型化输出（点、功能区域、轨迹）与执行器契约天然对齐，便于审计和调试；
  - 轻量训练（冻结骨干，仅训练 adapter、几何头和 LoRA）降低了迁移成本。
- **主要局限**：
  - 依赖深度和相机标定进行坐标转换，深度噪声可能影响真实抓取精度；
  - 执行契约相对固定，对需要复杂多步推理或工具使用的任务扩展性有限；
  - 真实机器人实验未覆盖移动操作、动态物体和长期任务，泛化能力有待进一步验证；
  - 论文未系统比较与端到端动作 token 模型在计算开销和实时性上的差异。
