## 摘要
我们提出 DreamX-Phi 1.0，一个面向机器人操作的动作条件视频世界模型：给定一帧观测、语言指令以及由末端执行器位姿和夹爪状态构成的指定动作序列，它能够预测未来的观测结果。然而仅凭真实感并不能保证忠实性：一段令人信服的推演仍可能移动错误的手臂或丢失被操作物体。为了保证预测遵循每条手臂的指令路径，我们通过 PRoPE 风格的几何编码将每条手臂的 SE(3) 变换注入注意力，从而保持手臂身份和刚体运动结构。仅靠动作控制无法完全约束场景几何或小型被操作物体的演化。因此，我们增加了一个轻量级深度分支来获取场景级几何信息，并使用 SAM3 掩码与冻结的 V-JEPA 教师来在抓取过程中保持物体一致性。我们进一步通过分布匹配蒸馏，将多步生成器蒸馏为少步学生模型，以实现高效部署。截至撰写本文时，DreamX-Phi 1.0 在 WorldArena 2.0 挑战赛的 Track 1 中获得第一名，并在 Track 2 中获得第二名。我们的模型与代码将公开发布。

## Abstract
We present \textbf{DreamX-Phi 1.0}, an action-conditioned video world model for robotic manipulation that, given an observed frame, a language instruction, and a prescribed action sequence comprising end-effector poses and gripper states, predicts the resulting future observations. Yet realism alone does not guarantee faithfulness: a convincing rollout can still move the wrong arm or lose the manipulated object. To ensure the prediction respects each arm's commanded path, we inject per-arm $\mathrm{SE}(3)$ transformations into attention via \textbf{PRoPE-style geometric encoding}, preserving arm identity and rigid-motion structure. Action control alone does not fully constrain scene geometry or the evolution of small manipulated objects. We therefore add a lightweight \textbf{depth branch} for scene-level geometry and use \textbf{SAM3 masks} with a frozen \textbf{V-JEPA teacher} to maintain object consistency throughout grasping. We further distill the multi-step generator into a few-step student via distribution-matching distillation for efficient deployment. At the time of writing, \model{} achieves first place on Track~1 and second place on Track~2 of the WorldArena~2.0 Challenge. Our model and code will be publicly available.

## 2. 论文提出的方法论

### 2.1 总体框架

- 模型基于 **Wan2.2-TI2V-5B** 视频扩散 Transformer，采用流匹配（flow matching）目标。
- 输入：观测 RGB 帧 \(x_0\)、语言指令 \(c\)、双臂动作轨迹 \(a_{1:T}\)（含末端执行器位姿和夹爪状态）。
- 输出：未来 RGB 视频 \(x_{1:T}\)。
- 框架分三部分：动作条件视频预测、训练监督、少步后训练（图 2）。

### 2.2 动作条件：PRoPE 几何编码

- **目标**：将每臂的 SE(3) 变换显式注入注意力，保留刚体运动结构，而不是将动作压缩为通用 token 或特征调制。
- **动作表示**：
  - 第 \(t\) 帧第 \(k\) 臂由位置 \(p_{kt}\)、旋转矩阵 \(R_{kt}\)（由四元数转换）、夹爪值 \(g_{kt}\) 描述。
  - 将每臂末端执行器帧 \(G_{kt}\) 相对于第 1 臂初始帧 \(G_{11}\) 变换得到 \(\bar{G}_{kt}\)，将所有臂统一到公共参考系。
  - 用全局运动幅度因子 \(s_\gamma\) 归一化平移分量，得到 \(\tilde{G}_{kt}\)，再取逆得到 \(A_{kt} = (\tilde{G}_{kt})^{-1}\)。
  - 时间对齐到 VAE 潜变量帧，得到 \(A \in \mathbb{R}^{2 \times T_{\text{lat}} \times 4 \times 4}\) 和 \(g \in \mathbb{R}^{2 \times T_{\text{lat}}}\)。
- **几何注意力**：
  - 每个 Transformer 块含一个并行注意力分支，使用专属 Q/K/V/O 投影，条件于 \(A\) 和 \(g\)。
  - 将注意力头划分为固定连续组 \(\{H^k\}\)，每组对应一条臂。
  - 对 token \(i\) 在头 \(h \in H^k\) 应用对角块矩阵 \(D_i = I_{d_h/4} \otimes A_{k,n(i)}\)，对 Q、K、V 进行变换：\(Q'_i = D_i^\top Q_i\)，\(K'_i = D_i^{-1} K_i\)，\(V'_i = D_i^{-1} V_i\)，输出再逆变换回原空间。
  - 该机制使 token 对 \((i,j)\) 通过相对运动 \(D_i D_j^{-1}\) 耦合，而非绝对坐标。
- **夹爪与残差**：
  - 夹爪开合是标量，不能表示为 SE(3) 元素；通过 \(b_{kt} = W_g g_{kt} + b_g\) 作为逐臂偏置加到对应注意力组的所有头上。
  - 几何注意力输出与预训练自注意力输出相加（残差连接），且 gripper adapter 和输出投影初始化为零，避免初期干扰预训练先验。

### 2.3 辅助深度监督

- **动机**：RGB 预测目标可能忽略表面排序、物体范围、接触几何等 3D 结构。
- **实现**：
  - 使用 Depth Anything 3 (DA3) 提供深度视频 \(d\)。
  - 将单通道深度图复制为伪 RGB 输入，用冻结的 VAE 编码得到深度潜变量 \(z_d = E(d)\)。
  - 复制 RGB Transformer 的最后 \(M\) 个块形成深度分支（前 \(N-M\) 块共享主干），深度块可从对应 RGB 分支读取 K、V（交叉注意力），但 RGB 分支不读取深度特征。
  - 用专属输出头预测 \(\hat{z}_d\)，损失为潜空间 MSE \(L_{\text{depth}} = \frac{1}{|z_d|} \|\hat{z}_d - z_d\|_2^2\)。
- **特点**：深度分支完全可选，推理时不需要深度输入；训练中强化共享表征的几何结构。

### 2.4 物体中心物理一致性

- **动机**：流匹配 RGB 损失对所有 token 平均，机器人臂和被操作物体只占图像小部分，静态背景会淹没接触局部误差。
- **SAM3 掩码加权 RGB 损失**：
  - 离线用 SAM3 生成被操作物体的二值掩码视频，投影到潜变量网格。
  - token \(i\) 的权重 \(w_i\) 由掩码 \(m_i\) 和超参数 \(\lambda_m > 1\) 决定：\(\tilde{w}_i = 1 + (\lambda_m - 1) m_i\)，再归一化。
  - 最终目标 \(L_{\text{obj rgb}} = \frac{1}{|V|} \sum_{i \in V} w_i \ell_{\text{FM},i}\)，使接触局部误差保持影响力。
- **V-JEPA 对齐**：
  - 用冻结的 V-JEPA 教师约束物体特征在空间和时间上的关系。
  - 选择时序分层采样的掩码教师 token 集合 \(I_b\)，将学生隐藏 token 插值到对应坐标。
  - 不直接匹配特征，而是对齐 Gram 矩阵：\(\ell^{(b)}_{\text{JEPA}} = \frac{1}{M_b^2} \| S_b S_b^\top - Q_b Q_b^\top \|_1\)。
  - 门控条件：掩码 token 数 \(M_b \ge M_{\min}\) 且流匹配噪声 \(\sigma_b \le \sigma_{\max}\) 时才贡献损失。
  - 训练分阶段：先只训练投影器，再逐步放开对视频模型参数的梯度。

### 2.5 少步后训练

- 采用 **DMD2 分布匹配蒸馏** 将多步生成器蒸馏为固定 \(N\) 步学生。
- 条件 \(y = (x_0, a_{1:T}, c)\) 同时提供给教师、学生和伪造分数去噪器。
- 分布匹配 KL 目标：\(L_{\text{DMD}} = \mathbb{E}_{y, \tau} [D_{\text{KL}}(q_{\eta,\tau}(\cdot|y) \| p_{\text{data},\tau}(\cdot|y))]\)。
- 叠加非饱和 GAN 对抗损失 \(L_G^{\text{adv}}\)（生成器）和 \(L_D^{\text{adv}}\)（判别器），总目标 \(L_{\text{DMD student}} = L_{\text{DMD}} + \lambda_{\text{adv}} L_G^{\text{adv}}\)。
- 学生使用与训练一致的固定 \(N\) 步去噪调度，反向模拟中仅对采样步传递梯度。

## 7. 优点

- **结构化动作表征**：使用 PRoPE 将 SE(3) 轨迹显式注入注意力，保留双臂身份和刚体运动结构，比通用 token 调制更忠实于动作。
- **分阶段多模态监督**：深度分支只作为训练辅助，推理时可选，不会增加部署负担；SAM3 掩码加权和 V-JEPA Gram 矩阵匹配针对小物体接触一致性，设计合理。
- **高效部署**：DMD 蒸馏结合对抗训练，将多步扩散模型蒸馏为固定少步学生，提升推理效率。
- **数据多样性**：混合自我中心视频、真实与仿真机器人数据，动作无关预训练与动作条件微调分离，提升视觉先验广泛性。
- **基准表现优秀**：在 WorldArena 2.0 和 1.0 的多个指标上取得领先，尤其是深度准确性和语义对齐。
