## 摘要
视觉-语言-动作（VLA）模型在机器人操作任务中表现优异，但在视觉和环境变化下性能往往会下降。隐式世界建模为提升鲁棒性提供了一种有前景的方法，但现有方法通常独立编码各相机视角，并预测整体场景动态，而未显式建模其几何关系。我们提出 GWM-VLA，一种面向 VLA 学习的几何感知隐式世界建模框架。GWM-VLA 结合了几何感知的多视角状态编码、以全局上下文为条件的目标视角预测，以及由机器人动作监督所约束的共享隐式动作表示。具体而言，VGGT-Ω 在每个时间步联合聚合多视角观测，构建几何感知的多视角状态。隐式世界模型利用多视角聚合后得到的 patch token 和 register token 来预测所选目标视图下一时间步的 patch token，从而保留多视角几何信息，而无需预测完整的多视角状态。我们在实验中使用腕部视角作为目标，以更加强调末端执行器运动和局部夹爪-物体交互。最后，共享的隐式动作表示同时作为隐式世界模型和流匹配动作头的条件，使隐式预测监督与真实机器人动作监督能够共同塑造同一隐式动作表示。在仿真和真实环境中的实验证明了 GWM-VLA 的有效性和鲁棒性。

## Abstract
Vision-Language-Action (VLA) models achieve strong robotic manipulation performance but often degrade under visual and environmental shifts. Latent world modeling offers a promising approach to improving robustness, yet existing methods commonly encode camera views independently and predict holistic scene dynamics without explicitly modeling their geometric relationships. We propose GWM-VLA, a geometry-aware latent world modeling framework for VLA learning. GWM-VLA combines geometry-aware multi-view state encoding, global context-conditioned target-view prediction, and shared latent-action representations grounded by robot-action supervision. Specifically, VGGT-$Ω$ jointly aggregates multi-view observations at each timestep to construct geometry-aware multi-view states. The latent world model predicts the next-step patch tokens of a selected target view using patch and register tokens obtained after multi-view aggregation, thereby retaining multi-view geometric information without predicting the complete multi-view state. We use the wrist view as the target in our experiments, placing greater emphasis on end-effector motion and local gripper-object interactions. Finally, the shared latent-action representations condition both the latent world model and the flow-matching action head, allowing latent-prediction supervision and ground-truth robot-action supervision to jointly shape the same latent-action representations. Experiments across both simulation and real-world environments demonstrate the effectiveness and robustness of GWM-VLA.

- **核心问题**：现有提升鲁棒性的方法中，隐式世界建模（latent world modeling）虽然比显式生成未来图像更紧凑，但普遍存在两个不足：
  - 独立编码每个相机视角，再简单拼接特征，缺少对跨视角几何关系、视觉对应关系和相机相对场景结构的显式建模；
  - 预测对象是整体场景动态，目标不够聚焦，且没有将几何信息作为预测状态来使用。
- **整体含义**：论文旨在让 VLA 策略不仅依赖外观相关性，而是学习“机器人动作如何引起场景状态变化”，并利用多视角几何先验提高在视觉/环境偏移下的鲁棒性。

## 2. 论文提出的方法论

GWM-VLA 的核心思想是：用几何感知的多视角表示作为隐式世界模型的状态，以目标视图为预测对象，并通过共享隐式动作表示将“预测未来状态”和“生成机器人动作”耦合起来。

### 2.1 几何感知多视角状态编码

- 使用冻结的 **VGGT-Ω** 作为多视角几何编码器。
- 在每个时间步，将多视角观测联合输入 VGGT-Ω，得到 **register tokens** 和 **patch tokens**：
  - 论文表述为：$\{R_t, P_t\} = E_\Omega(\{I^t_v\}_{v=1}^V)$。
- 与 VLA-JEPA 的“各视角独立编码后拼接”不同，VGGT-Ω 在同一个时间步内显式聚合所有视角，建模跨视角几何结构。

### 2.2 全局上下文条件的目标视图预测

- 不预测完整多视角状态，而是只预测一个选定目标视图的下一时间步 patch tokens。
- 选择目标视图后，提取对应的 register tokens $r_t$ 和目标视图 patch tokens $p_t$。
- 隐式世界模型 $F_\phi$ 在目标视图 patch tokens、register tokens 和共享隐式动作 tokens 的条件下，预测下一时间步目标视图 patch tokens：
  - $\hat{p}_{1:T} = F_\phi(p_{0:T-1}, r_{0:T-1}, A_{0:T-1})$。
- 即使只预测单个视图，由于 patch/register tokens 来自多视角联合聚合，预测仍保留多视角几何信息。
- **目标视图选择**：论文在实验中使用腕部视图，因为它与末端执行器运动、夹爪-物体局部交互更紧密。
- **时间因果注意力**：同一时间步的 token 可双向交互，但只能关注不晚于当前时间步的 token，保证因果性。
- **训练方式**：采用 teacher forcing，用真实下一时间步的 VGGT-Ω patch tokens 作为监督。
- **预测损失**：使用 $\ell_1$ 损失：
  - $\mathcal{L}_{wm} = \frac{1}{T}\sum_{t=0}^{T-1}\|\hat{p}_{t+1} - p_{t+1}\|_1$。

### 2.3 统一隐式动作表示

- 以 **Qwen3-VL-2B** 作为视觉-语言骨干。
- 在输入当前观测和语言指令后，插入时间步分组的可学习隐式动作 query tokens。
- 这些 query tokens 经 VLM 编码后得到隐式动作序列 $A_{0:T-1}$，每个时间步 $t$ 对应 $K$ 个隐式动作 token。
- 关键设计：$A_{0:T-1}$ **同时**作为隐式世界模型和动作头的条件，而不是像 VLA-JEPA 那样额外引入单独的 embodied-action representation。
- 这样，隐式预测损失和真实机器人动作损失会共同塑造同一组隐式动作表示，使其既编码任务相关动态，又保持可执行性。

### 2.4 条件流匹配动作头与联合训练

- 动作头采用 **conditional flow matching**，用于建模连续机器人动作的多模态分布。
- 条件为共享隐式动作序列 $A_{0:T-1}$ 和当前本体感受状态 $s_0$。
- 给定真实动作块 $u_{0:T-1}$、高斯噪声 $\epsilon$、流时间 $\gamma$，动作损失为：
  - $\mathcal{L}_{action} = \mathbb{E}\left[\|v_\psi(u_\gamma,\gamma|A_{0:T-1},s_0) - (u_{0:T-1}-\epsilon)\|_2^2\right]$。
- **联合目标**：
  - $\mathcal{L} = \mathcal{L}_{action} + \lambda \mathcal{L}_{wm}$。
  - 默认 $\lambda=0.1$；世界模型损失只在训练时使用，推理时不使用。
