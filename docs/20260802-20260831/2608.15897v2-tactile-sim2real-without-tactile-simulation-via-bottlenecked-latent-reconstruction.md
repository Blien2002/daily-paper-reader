## 摘要
机器人传感器设计，尤其是触觉传感器，种类繁多且发展迅速。在仿真中对每种传感器建模需要大量领域专业知识，而计算近似可能降低仿真信号的保真度。我们提出基于瓶颈潜在重建的 Sim2Real 方法（SBLR），该方法完全避免对特定传感器的仿真，具体做法是：(1) 在仿真器原生的预言传感器上训练策略，这种传感器无需对任何特定传感器建模即可轻松构建（例如，我们使用点云和指尖力作为触觉预言）；(2) 在推理时将真实传感器的潜在嵌入与预言传感器的潜在嵌入对齐。策略训练分两个阶段：策略首先从预言传感器潜在表示学习，然后通过瓶颈潜在重建使其适应使用真实传感器而非预言传感器时预期的信息损失。预言传感器与真实传感器之间的对齐利用在仿真和真实世界中收集的非配对随机交互数据，通过在最近邻伪对上训练的基于整流流的变换网络来学习。在三个接触丰富任务上的仿真实验表明，SBLR 达到或接近可直接访问触觉仿真的预言性能。使用 GelSight Mini 和 DIGIT 传感器在插销插入与齿轮啮合任务上的硬件实验证明，无需任何传感器特定建模或校准即可实现 85–97.5% 的零样本成功率，比基于物理的触觉仿真基线高出 7.5–15%。

## Abstract
Robot sensor designs, particularly tactile sensors, are highly diverse and evolve rapidly. Modeling each sensor in simulation demands substantial domain expertise and computational approximations can degrade the fidelity of the simulated signals. We propose Sim2Real via Bottlenecked Latent Reconstruction (SBLR), a framework that avoids sensor-specific simulation entirely by (1) training policies on a simulator-native oracle sensor that is easy to construct without modeling any particular sensor (e.g. we use a point-cloud and finger-tip forces as a tactile oracle), and (2) aligning real sensor latent embeddings to those of the oracle sensor at inference time. Policy training proceeds in two-stage: the policy first learns from the oracle sensor latents, then a bottlenecked latent reconstruction adapts it to the information loss expected when using the real sensor instead of the oracle. The alignment between oracle and real sensor is learned from unpaired random-play data collected in both simulation and the real world, using rectified-flow-based transformation networks trained on nearest-neighbor pseudo-pairs. Simulation experiments on three contact-rich tasks show that SBLR matches or approaches the performance of an oracle with direct access to tactile simulation. Hardware experiments on Peg Insertion and Gear Meshing with GelSight Mini and DIGIT sensors demonstrate 85-97.5% zero-shot success without requiring any sensor-specific modeling or calibration, outperforming a physics-based tactile simulation baseline by 7.5-15%.

## 2. 方法论

### 核心思想
- 不在仿真中建模任何真实触觉传感器，而是使用仿真中容易获得的**预言传感器（oracle sensor）**——点力组合（Point Force Composition, PFC），包含操作物体与指尖的完整点云以及指尖接触力。
- 在推理时，将真实传感器读数映射到预言传感器潜在空间，使仿真训练的策略可以直接部署。
- 通过两阶段 RL 训练，使策略适应真实传感器相对于预言传感器的信息损失。

### 关键技术细节
- **对齐数据构建**：在仿真和真实世界分别采集**非配对随机交互数据**（固定物体姿态，随机触碰），利用本体感觉状态转移 `(q_{t-1}, q_t)` 做最近邻搜索，形成伪配对。相似度定义为欧氏距离加权组合。
- **编码器预训练**：
  - PFC 点云部分使用 Point-MAE 得到全局潜在 `z_x`；力部分用自编码器得到 `z_f`；拼接得到 `z_p = f_pfc(p)`。
  - 真实触觉图像（如 GelSight Mini、DIGIT）使用 MAE 编码为 `z_c = f_c(c)`。
- **整流流变换网络（Rectified Flow, RF）**：
  - 训练双向变换 `f_{p→c}` 和 `f_{c→p}`，用于在 PFC 潜在和触觉潜在之间映射。
  - 训练时使用直线桥 `z_t = (1-t)z_0 + t z_c`，损失为 `L_RF = E[||v_ψ(z_t, t, z_p) - (z_c - z_0)||²]`。
  - 推理时解 ODE `dz_t/dt = v_ψ(z_t, t, z_p)`，生成目标潜在。
- **两阶段策略训练**：
  - **Stage 1**：在仿真中用 PFC 潜在训练 RL 策略 `π_θ(o, z_p)`；对 PFC 添加轻微噪声（位置 0.5 mm、旋转 0.29°、力 0.3 N）以避免过拟合。
  - **Stage 2**：冻结两个 RF 网络，对每个时间步执行 **瓶颈潜在重建**：`ẑ_p = f_{c→p}(f_{p→c}(z_p))`，用重建的潜在训练策略，使其适应真实传感器造成的信息损失和 RF 对齐误差。
- **推理部署**：只使用真实触觉读数 `c`，通过 `a = π_θ(o, f_{c→p}(f_c(c)))` 输出动作。

## 6. 主要结论与发现

- SBLR 在仿真 proxy-real 环境中，三个任务平均成功率达 75.9–87.4%，接近或匹配 Image/PFC Oracle 性能，显著优于 DCP、No Tactile 和 OT 基线。
- 去除 Stage 2 的 Ablation 性能下降，在 Nut Threading 上尤为明显，说明瓶颈潜在重建能有效适应信息差距。
- 硬件实验中，SBLR 在 GelSight Mini 和 DIGIT 上实现 85–97.5% 零样本成功率，超过物理触觉仿真 TacSL 基线 7.5–15 个百分点。
- 该方法无需传感器特定仿真、标定或手工特征，可用于不同触觉传感器之间的快速部署。

## 7. 优点

- **避免传感器特定仿真**：直接用仿真器原生 PFC 作为预言传感器，极大降低建模成本。
- **信息瓶颈设计巧妙**：通过 `PFC → 估计真实触觉 → 重建 PFC` 的双重变换，在训练中显式暴露策略于真实传感器的信息损失。
- **两阶段训练高效**：更换新传感器只需轻量 Stage 2 适应，无需重新训练整个策略，适合大模型（如 VLA）的场景。
- **跨传感器通用性**：框架对传感器模态不敏感，实验证明可适配 GelSight Mini 和 DIGIT。
- **数据采集自动化**：非配对随机交互数据采集无需人工干预，成本低。

## 8. 不足与局限

- **未解决动力学差距**：方法仅处理感知模态差距，仿真到真实的动力学差异仍需传统域随机化等手段。
- **对齐数据覆盖有限**：随机交互可能无法充分覆盖高精度任务（如 Nut Threading）的关键接触模式；作者建议引入人类遥操作改善数据质量。
- **硬件实验任务范围有限**：仅两个 Factory 任务，未覆盖更复杂的多指操作或动态任务。
- **单传感器使用**：硬件实验只用了左手指尖触觉传感器，可能简化了对多指触觉融合的要求。
- **标定与物理仿真基线限制**：TacSL 基线依赖 3D 打印标定球的质量，作者承认 3D 打印误差可能影响对比公平性。
- **缺失算力细节**：论文未汇报计算资源，难以评估训练成本与可复现性。
