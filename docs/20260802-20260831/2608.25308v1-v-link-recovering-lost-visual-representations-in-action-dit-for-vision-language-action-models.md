## 摘要
视觉-语言-动作（VLA）模型通过整合视觉感知、语言理解和连续动作控制，为通用机器人操作提供了一条可扩展的路径。然而，我们揭示了 VLA 架构的一个关键局限：动作专家对 VLM 特征中可用的 3D 几何和 2D 语义信息的访问有限。这种可访问性差距削弱了感知基础，并限制了精细机器人操作上的表现。为了解决这一问题，我们提出了 V-Link，它在视觉-语言（VL）到动作（A）的特征转移过程中显式地恢复视觉表示。具体来说，V-Link 在 VLM 内学习互补的空间查询和语义查询表示，并通过非对称路径将其注入 Action DiT。语义查询补充原始的 VLM 图像 token，而空间查询为基于空间定位的动作生成提供专门的几何条件。在 LIBERO、LIBERO-Plus 和 RoboTwin 2.0 上，我们的 V-Link 相较于基线模型 GR00T N1.6 平均成功率分别提高了 +1.9%、+31.2% 和 +18.8%。在 AGIBOT A3 Ultra 上，V-Link 在两个真实世界人形机器人任务上进一步实现了 +20% 和 +24% 的提升。

## Abstract
Vision-language-action (VLA) models provide a scalable path toward generalist robotic manipulation by integrating visual perception, language understanding, and continuous action control. However, we reveal a critical limitation of VLA architectures: the action expert has limited access to the 3D geometric and 2D semantic information available in VLM features. This accessibility gap weakens perceptual grounding and limits performance on fine-grained robotic manipulation. To address this issue, we propose V-Link, which explicitly recovers visual representations during the vision-language (VL) to action (A) feature transfer. Specifically, V-Link learns complementary Spatial and Semantic Query representations within the VLM and injects them into Action DiT through asymmetric pathways. Semantic Queries complement the original VLM image tokens, whereas Spatial Queries provide dedicated geometric conditioning for spatially grounded action generation. Across LIBERO, LIBERO-Plus, and RoboTwin 2.0, our V-Link improves the average success rate over base model GR00T N1.6 by +1.9%, +31.2%, and +18.8%, respectively. On the AGIBOT A3 Ultra, V-Link further achieves gains of +20% and +24% on two real-world humanoid tasks.

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出 **V-Link**，在 VLM 内部学习**互补的空间查询（Spatial Queries）和语义查询（Semantic Queries）**，并通过**非对称路径**注入 Action DiT。
- 训练时利用深度估计和语义分割的辅助监督来解耦两类表示，推理时移除辅助头，无需额外标注。

### 2.2 关键技术细节

#### （1）VLM 表示解耦
- 在 VLM 输入中引入两组可学习 token：空间查询 \(E_d\) 和语义查询 \(E_s\)，与原始文本 token \(E_t\) 和多视角图像 token \(E_o\) 拼接：
  \[
  E = [E_t; E_o; E_d; E_s]
  \]
- 设计**因果注意力掩码** \(M_q\)，使两组查询独立地关注 VLM 的图像和文本 token，而不干扰原生多模态计算。
- 通过 VLM 前向传播得到最终层输出 \(E'_d\) 和 \(E'_s\)。

- **深度头**：从空间查询 \(E'_d\) 预测多视角稠密深度图 \(\hat{D}\)，采用 softplus 激活保证正值。  
  - 损失：平滑 L1 损失 + 绝对相对损失 + 硬块损失（top-k 困难区域），加权组合。  
- **语义头**：从语义查询 \(E'_s\) 预测 2D 语义分割 logits，使用交叉熵损失 + 软 Dice 损失。

- 先进行 warm-up（仅训练 LoRA、查询和任务头），再联合优化所有可训练组件。推理时移除辅助头。

#### （2）动作 DiT 中的视觉表示恢复
- GR00T N1.6 采用 32 层 AlternateVLDiT，每 4 层一个周期，其中图像交叉注意力层位于 \(l = 4k+2\)。V-Link 仅在这些层注入查询表示。
- 对每个图像交叉注意力层：
  - 状态/动作 token \(H_l\) 作为 query，分别与 VLM 图像 token \(E'_o\) 和语义查询 \(E'_s\) 进行**并行交叉注意力**，得到 \(N_l\) 和 \(S_l\)。
  - 两者拼接后经过融合投影，并通过可学习门控 \(g_l\) 与残差连接得到语义增强特征 \(Z_l\)。
  - \(Z_l\) 再作为 query 与空间查询 \(E'_d\) 进行**空间交叉注意力**，得到几何条件化特征 \(H'_l\)。
  - 最后接 FFN 和残差得到层输出。

- **非对称性**：语义查询与原始 VLM token 并行补充语义，空间查询则作为独立的强制性几何条件分支，迫使 Action DiT 编码深度感知表示。

#### （3）训练目标
\[
\mathcal{L} = \mathcal{L}_{\text{act}} + \lambda_{a1}\mathcal{L}_{\text{depth}} + \lambda_{a2}\mathcal{L}_{\text{seg}}
\]
其中 \(\lambda_{a1}=0.1\)，\(\lambda_{a2}=0.002\)，\(\mathcal{L}_{\text{act}}\) 为流匹配动作损失。

## 6. 论文的主要结论与发现

- **视觉表示可访问性瓶颈确实存在**：GR00T N1.6 的 Action DiT 在深度估计和语义分割上显著差于 VLM 特征，说明最终层转移导致感知信息丢失。
- **V-Link 能有效恢复动作专家中的视觉表示**：诊断实验显示，V-Link Action DiT 的深度估计和分割性能大幅改善，接近或超过 VLM 特征水平。
- **性能提升显著且一致**：
  - LIBERO 平均成功率：GR00T N1.6 97.4% → V-Link 99.3%（+1.9%）。
  - LIBERO-Plus：43.8% → 75.0%（+31.2%），在噪声、语言、光照等转移下提升尤为明显。
  - RoboTwin 2.0：38.0% → 56.8%（+18.8%）。
  - 真实机器人：开机 78% → 98%（+20%），关机 70% → 94%（+24%）。
- **计算开销极小**：推理延迟仅增加 1.58 ms，适合实时机器人控制。
- **空间和语义查询互补**：空间查询对移动/放置类任务增益大，语义查询对接触类任务增益大，两者结合最优。
