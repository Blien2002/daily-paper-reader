## 摘要
机器人传感器设计，尤其是触觉传感器，高度多样且演进迅速。在仿真中对每种传感器建模需要大量领域专业知识，且计算近似可能降低仿真信号的保真度。我们提出通过瓶颈潜在重建实现 Sim2Real（SBLR）框架，该框架完全避免传感器特定的仿真，方法是：(1) 在仿真原生预言传感器上训练策略，该传感器易于构建且无需对任何特定传感器建模（例如我们使用点云和指尖力作为触觉预言），以及 (2) 在推理时将真实传感器的潜在嵌入与预言传感器的潜在嵌入对齐。策略训练分两阶段进行：策略首先从预言传感器潜在表示中学习，然后通过瓶颈潜在重建使其适应使用真实传感器而非预言传感器时预期的信息损失。预言传感器与真实传感器之间的对齐是从仿真和现实世界中收集的非配对随机交互数据中学习的，使用基于最近邻伪配对的整流流变换网络进行训练。在三个接触密集任务上的仿真实验表明，SBLR 达到或接近直接访问触觉仿真的预言性能。在 Peg Insertion 和 Gear Meshing 任务上使用 GelSight Mini 和 DIGIT 传感器的硬件实验表明，无需任何传感器特定建模或校准即可实现 85–97.5% 的零样本成功率，比基于物理的触觉仿真基线高出 7.5–15%。

## Abstract
Robot sensor designs, particularly tactile sensors, are highly diverse and evolve rapidly. Modeling each sensor in simulation demands substantial domain expertise and computational approximations can degrade the fidelity of the simulated signals. We propose Sim2Real via Bottlenecked Latent Reconstruction (SBLR), a framework that avoids sensor-specific simulation entirely by (1) training policies on a simulator-native oracle sensor that is easy to construct without modeling any particular sensor (e.g. we use a point-cloud and finger-tip forces as a tactile oracle), and (2) aligning real sensor latent embeddings to those of the oracle sensor at inference time. Policy training proceeds in two-stage: the policy first learns from the oracle sensor latents, then a bottlenecked latent reconstruction adapts it to the information loss expected when using the real sensor instead of the oracle. The alignment between oracle and real sensor is learned from unpaired random-play data collected in both simulation and the real world, using rectified-flow-based transformation networks trained on nearest-neighbor pseudo-pairs. Simulation experiments on three contact-rich tasks show that SBLR matches or approaches the performance of an oracle with direct access to tactile simulation. Hardware experiments on Peg Insertion and Gear Meshing with GelSight Mini and DIGIT sensors demonstrate 85-97.5% zero-shot success without requiring any sensor-specific modeling or calibration, outperforming a physics-based tactile simulation baseline by 7.5-15%.

## 1. 论文的核心问题与整体含义

- **研究背景**：机器人传感器（尤其是触觉传感器）设计高度多样、更新迅速，不同传感器往往需要各自的物理仿真模型，建模成本高、需要领域专长，且仿真近似会降低信号保真度。
- **核心问题**：如何在不建立任何传感器特定物理仿真的前提下，将在仿真中训练好的接触丰富操作策略零样本迁移到真实世界，并适配不同真实触觉传感器。
- **整体含义**：提出 **SBLR（Sim2Real via Bottlenecked Latent Reconstruction，瓶颈潜在重建 Sim2Real）**，用仿真中天然可得的“oracle 传感器”替代真实传感器建模，通过潜在空间对齐与信息瓶颈训练，实现跨传感器、跨 sim-real 的零样本迁移。

## 2. 论文提出的方法论

- **核心思想**：
  - 仿真阶段使用易于构建的 **oracle 传感器**（本文用 **PFC，Point Force Composition**：物体/指尖完整点云 + 指尖接触力），不需要对任何真实传感器建模。
  - 推理阶段把真实触觉读数编码后映射到 oracle 潜在空间，供策略使用。
  - 通过两阶段 RL 训练，使策略适应真实传感器相对 oracle 的信息损失。

- **关键技术细节**：
  - **对齐数据构造**：在仿真与真实世界固定同一物体，自动采集随机接触数据；利用本体感觉转移 \( (q_{t-1}, q_t) \) 做最近邻，形成非配对数据的“伪配对”。
  - **编码器预训练**：
    - PFC 点云使用 Point-MAE，力分量使用自编码器，得到 oracle 潜在 \( z_p \)；
    - 真实触觉图像使用 MAE，得到真实潜在 \( z_c \)。
  - **Rectified Flow 变换网络**：训练 \( f_{p\to c} \) 和 \( f_{c\to p} \)，以建模 oracle 潜在与真实潜在之间的多模态映射。
    - 流训练：\( z_t = (1-t)z_0 + t z_c \)，损失 \( \mathcal{L}_{RF} = \mathbb{E}\left[ \| v_\psi(z_t, t, z_p) - (z_c - z_0) \|_2^2 \right] \)。
  - **两阶段 RL 训练**：
    - Stage 1：用 oracle PFC 潜在训练基础策略 \( \pi_\theta(o, z_p) \)；
    - Stage 2（瓶颈潜在重建）：将模拟 PFC 潜在先经 \( f_{p\to c} \) 映射到估计真实潜在，再经 \( f_{c\to p} \) 映射回 oracle 潜在：  
      \[
      \hat{z}_p = f_{c\to p}(f_{p\to c}(z_p))
      \]
      策略在重建潜在上继续 RL 训练，从而暴露并适应真实传感器造成的信息损失和变换误差。
  - **推理**：真实触觉读数 \( c \) 经编码器 \( f_c \) 和变换 \( f_{c\to p} \) 得到重建 oracle 潜在，输入策略：  
    \[
    a = \pi_\theta(o, f_{c\to p}(f_c(c)))
    \]

## 7. 优点

- **免传感器建模**：彻底绕开传感器特定物理仿真，降低触觉 Sim2Real 门槛。
- **跨传感器适应**：同一套框架可适配 GelSight Mini 和 DIGIT 等不同触觉传感器，无需为新传感器重训完整策略。
- **非配对数据训练对齐**：仅用自动采集的随机交互数据，不需人工标注配对或专家演示，硬件数据成本低。
- **信息瓶颈设计**：通过 \( f_{p\to c} \to f_{c\to p} \) 双重变换，使训练分布接近推理分布，策略显式适应信息损失。
- **轻量第二阶段**：新传感器部署只需轻量 Stage 2 RL，不必重训大型策略模型，适合大模型/VLA 快速适配。

## 8. 不足与局限

- **未解决动力学差距**：方法只处理传感器模态差距，sim-real 的动力学差距仍需其他手段（如域随机化）缓解。
- **任务与传感器覆盖有限**：硬件实验仅 Peg Insertion 和 Gear Meshing，传感器仅 GelSight Mini 和 DIGIT；更多任务和传感器类型（如非视觉触觉）未验证。
- **对齐数据依赖固定物体**：数据收集时物体固定，泛化到不同物体或物体位姿变化较大的场景可能受限。
- **伪配对误差**：最近邻配对基于本体感觉，不能保证接触状态完全对应，可能引入对齐噪声。
- **物理仿真基线公平性**：TacSL 的校准精度受实验条件影响，可能低估物理仿真方法的潜力。
- **算力细节缺失**：未报告训练资源，难以评估实际计算开销。
- **高精度任务覆盖不足**：文中指出随机交互对齐数据对 Nut Threading 等高精度任务覆盖不够，可能需要遥操作等更高质量数据。
