## 摘要
视觉-语言-动作（VLA）模型的实际部署常常受制于效率与性能之间的权衡、跨具身泛化能力以及执行平滑性。我们提出了 NebulaVLA，这是一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化。为了弥合异构机器人之间的语义差距，我们引入了 GESTURE-7，一种统一的、以语言为基础的动作表示。此外，我们的 Guide Action 算法通过基于掩码的平滑性约束来强化运动学连续性。综合评估表明，NebulaVLA 显著优于同步基线方法，在 LIBERO-Plus 上实现了 85.5% 的平均成功率，并将动作生成速度提升了约 2.7 倍。这种异步设计为实际机器人提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义

- **背景与动机**：视觉-语言-动作（VLA）模型正推动机器人操作从模块化流水线走向端到端学习，但实际部署仍面临三大瓶颈：
  - **效率与性能权衡**：单体同步架构下，统一时间分辨率难以同时满足低频语义推理与高频电机控制的需求。
  - **跨具身泛化困难**：将连续运动学映射到离散 token 需要庞大词汇表和大规模演示数据，异构机器人之间动作语义难以统一。
  - **执行平滑性问题**：异步实时推理与动作块生成之间存在时间不匹配，容易导致机械抖动和执行不连续。
- **整体含义**：NebulaVLA 以“快慢认知”范式（System 2 慢思考 + System 1 快反应）为基础，通过双频异步架构、统一动作表示和生成内平滑约束，系统性地缓解上述瓶颈，为实际机器人部署提供更高效、更平滑、更易跨平台迁移的 VLA 方案。

## 2. 论文提出的方法论

- **异构双频架构**：
  - **System 2（约 10 Hz）**：采用 Qwen3-VL 作为视觉-语言骨干，处理自然语言指令和稀疏视觉输入，输出高层抽象动作指导。
  - **System 1（约 20 Hz）**：基于 Diffusion Transformer（DiT），利用 Q-Former 压缩 System 2 的指导信息，并结合高频视觉输入与动作历史，经去噪过程生成最终执行动作。
  - 两者异步解耦，原生支持分布式部署，降低交互延迟并提高硬件吞吐。
- **GESTURE-7 统一动作表示**：
  - 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`。
  - 位置以厘米整数表示，姿态以整数角度表示，`gesture` 为自然语言关键词（如 `grasp`、`push`、`release`）。
  - 不同具身（如灵巧手、平行夹爪）执行相同动作时共享同一关键词，从而统一跨平台动作语义，并天然支持语言条件强化学习。
- **三阶段训练流程**：
  - **Stage 1（System 2 监督微调）**：包含姿态回归、关键点回归、2D 路径点预测、3D 轨迹预测和思维链（CoT）生成五类任务，建立空间感知与轨迹预测能力。
  - **Stage 2（System 2 强化学习）**：基于 GRPO 对 System 2 进行强化学习，奖励函数由 GESTURE-7 距离、关键点定位奖励、路径点奖励、轨迹奖励和格式奖励组成。
  - **Stage 3（System 1 监督微调）**：联合优化 System 2 与 System 1，冻结视觉编码器；使用掩码扩散损失，仅监督新生成的动作区域。
- **Guide Action 机制**：
  - 受图像外绘（Image Outpainting）启发，将上一动作块中尚未执行的轨迹锚点作为条件，指导下一块动作生成。
  - 扩散去噪过程中通过二进制掩码 `M` 强制保留已知动作区域，仅在新区域生成，公式为：
    - `A_{t-1}^{full} = M ⊙ A_{t-1}^{prior} + (1 - M) ⊙ A_{t-1}^{noisy}`
  - 训练时 guide action 点数在 0 到 3 之间随机采样，以适应实际推理延迟变化；损失函数仅作用于掩码为 0 的新生成区域。
