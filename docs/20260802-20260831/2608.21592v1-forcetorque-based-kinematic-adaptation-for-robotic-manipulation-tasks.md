## 摘要
接触密集型机器人操作需要对机器人关节与其感知的任务特征之间的运动学关系进行精确建模。这种关系很少被精确已知：它会随着机器人拿起和更换的每个工具而变化，有时几乎在接触模式改变时瞬时变化——尤其是对于多指手，它们在并非精确规定的点上建立和断开接触，例如全手抓取。本文提出一种自适应方案，仅使用关节角度传感和腕部安装的力/扭矩传感器在线估计该关系，不对工具末端进行任何外部感知测量。我们推导出一个可证明稳定的运动学更新律，仅根据力/扭矩反馈即可辨识未知工具的运动学，并证明了刚性情形以及以柔顺控制器为内环的情形的稳定性。我们表明，辨识仅限于运动所激励的方向——因此，例如，在刚性插入推压下工具长度不可观测，而柔顺回路的被动屈服会部分激励该长度；并且对于二阶导纳，柔顺性保证在连续时间内无条件成立。我们还将控制与估计的联合问题表述为二次规划（QP）：该表述能精确给出更新律的预测项，但具有启发意义的是，它无法复现跟踪自适应项。我们在轴孔插入仿真中验证了该方案。这项工作是某一研究计划的第一步，该计划旨在将操作学习分解为任务策略（可独立于机器人学习，例如通过强化学习）和自适应运动学组件（在线适应当前使用的特定机器人、手或工具）。

## Abstract
Contact-rich robotic manipulation requires an accurate model of the kinematic relationship between a robot's joints and the task features it senses. This relationship is rarely known exactly: it changes with each tool the robot picks up and shifts, sometimes almost instantaneously, as contact modes change --- especially for multi-fingered hands that make and break contact at points that are not exactly prescribed, as in full-hand grasping. This paper develops an adaptive scheme that estimates that relationship online, using only joint-angle sensing and a wrist-mounted force/torque sensor, with no exteroceptive measurement of the tool tip. We derive a provably stable kinematic update law that identifies the kinematics of an unknown tool from force/torque feedback alone, and prove stability of both the rigid case and the case with a compliance controller as an inner loop. We show that identification is confined to the directions the motion excites --- so that, for example, a tool's length is unobservable under a rigid insertion push, while a compliant loop's passive yielding partially excites it; and that with a second-order admittance the compliant certificate holds unconditionally in continuous time. We also pose the combined control and estimation problem as a Quadratic Program (QP): the formulation yields the prediction term of the update law exactly but, instructively, cannot reproduce the tracking adaptation term. We validate the scheme in simulation on a peg-in-hole insertion. This work is the first step in a research program aimed at factoring manipulation learning into a task policy which can be learned in isolation of the robot, for instance by reinforcement learning, and an adaptive kinematic component that adapts online to the particular robot, hand, or tool in use.

## 2. 论文提出的方法论

- **基础控制律**：采用 Jacobian 转置控制  
  \(\tau = \hat{J}^T(q) F\)，其中 \(F = -\nabla_s V(s)\) 是任务空间虚拟力，\(V(s)\) 为值函数（如跟踪误差二次型），\(\hat{J}\) 是 Jacobian 估计。

- **核心自适应更新律（复合律）**：  
  \[
  \dot{\hat{\theta}} = -\Gamma Y^T(q) F \dot{q}^T + \kappa(t) \Gamma Y^T(q) \varepsilon \dot{q}^T
  \]
  - 第一项为**跟踪项**，由跟踪误差驱动。
  - 第二项为**预测项**，由预测误差 \(\varepsilon = \dot{s}_{\text{meas}} - \hat{J}\dot{q}\) 驱动。
  - \(\Gamma\) 为常数增益矩阵；\(\kappa(t)\) 为归一化 LMS 增益，可时变且不破坏稳定性。

- **关键理论发现：仅跟踪律在调节任务下会“自我熄灭”**  
  在调节（目标恒定）场景下，仅使用跟踪项会导致 \(\hat{J}\) 沿误差力方向发生秩一收缩，命令 \(\dot{q} = \hat{J}^T F\) 指数衰减至零，而误差 \(e\) 未必收敛。预测项通过将 \(\hat{J}\) 锚定到实测运动学，阻止这种退化。

- **力/扭矩传感器情景下的运动学因子化**：  
  \(\hat{J}(q,\hat{\ell}) = S \, Ad(\hat{\ell}) \, J_{arm}(q)\)  
  其中 \(J_{arm}\) 为已知机械臂 Jacobian，\(Ad(\hat{\ell})\) 为腕部到工具末端的伴随变换（未知偏移 \(\ell\)），\(S\) 为已知传感器映射。预测误差由力/扭矩残差构建，无需测量或微分工具末端位置。

- **刚性情形稳定性**：  
  Lyapunov 函数 \(V_{aug} = V(s) + \frac{1}{2} \mathrm{tr}(\tilde{\ell}^T \Gamma^{-1} \tilde{\ell})\)  
  沿闭环轨迹得到  
  \[
  \dot{V}_{aug} \le -\|\dot{q}\|^2 + \frac{\kappa}{4}\|b\|^2
  \]
  其中 \(b\) 为力/扭矩预测误差中的偏置项。若无偏置（\(b=0\)），则 \(\dot{V}_{aug} \le 0\)。

- **柔顺（导纳）内环情形**：  
  引入二阶导纳  
  \[
  M \ddot{q} + (I+\beta)\dot{q} = \hat{J}^T F - J_{arm}^T w
  \]
  其中 \(w\) 为腕部力/扭矩，\(M \succ 0\) 为虚拟惯性，\(\beta \succeq 0\) 为阻尼。通过加入动能和接触弹性能存储，证明  
  \[
  \dot{V}_{tot} \le -\|\dot{q}\|^2 + \frac{\kappa}{4}\|b\|^2
  \]
  连续时间内无条件成立。实际离散采样下还需满足虚拟质量下界 \(M \succeq M_{\min}(K_c, T)\)。

- **QP 视角**：  
  将联合控制与估计问题表述为 QP。QP 可精确得到控制律（Jacobian 转置/伪逆）和预测项（正则化最小二乘解，归一化 LMS 增益有明确解释），但无法得到正确符号的跟踪自适应项。正确的跟踪项符号只能由 Lyapunov 分析确定。

## 6. 论文的主要结论与发现

- **力/扭矩反馈足以在线辨识未知工具运动学**：无需视觉测量工具末端，即可完成接触丰富操作（轴孔插入）。
- **跟踪自适应项在调节任务下存在结构性问题**：仅跟踪驱动的自适应律会使 Jacobian 估计收缩至奇异，命令自我熄灭；预测项是稳定完成任务所必需的。
- **辨识局限于运动激励方向**：刚性插入推压下工具长度不可观测，但柔顺回路的被动屈服能部分激发该方向，扩大可观测子空间。
- **二阶导纳内环下稳定性无条件成立**：柔顺闭环与接触环境形成功率连续互联，接触耦合项精确抵消；仅有阻尼耗散和偏置残留。
- **QP 无法得到跟踪自适应项的正确符号**：瞬时优化要么忽略自适应，要么选择不稳定方向；稳定性来自跨样本的 Lyapunov 分析，说明 QP 不能替代稳定性证明。
