## 摘要
多臂协作正在成为具身操作中的核心能力。最近的视觉-语言-动作（VLA）模型集成了感知、语言和控制，但大多数将语言表示为单一全局指令，并未提供显式机制来分配和组合针对各个手臂的行为。这种设计限制了向训练期间未见过的协作模式的迁移。我们提出 MA-VLA，一个通过原子动作分配实现多臂协作的统一框架。MA-VLA 将合作行为分解为中层原子提示，并将其分配给各个手臂，从而支持显式子目标设定和跨任务的组合复用。为了减少对固定执行角色的依赖，我们引入了 Arm Shuffle，即在训练时对每个手臂的观测、状态和分配的原子提示进行排列。这种排列强制实现与角色无关的指令遵循，并支持重新组合成未见过的协调模式，我们称之为多臂组合泛化。我们还构建了一个基准，其中测试时的协作模式在训练集中不存在。在仿真和真实世界评估中，先前最先进的 VLA 在这些未见过的协作下大多失败，而 MA-VLA 始终成功。这些结果表明，结构化的、按手臂的原子动作分配为多臂具身系统中的可扩展泛化提供了一条实用路径。代码、模型和数据可在 https://github.com/zhangzaibin/future-robots 获取。

## Abstract
Multi-arm collaboration is becoming a core capability in embodied manipulation. Recent vision-language-action (VLA) models integrate perception, language, and control, but most represent language as a single global instruction and do not provide an explicit mechanism for assigning and composing arm-specific behaviors. This design limits transfer to collaboration patterns that differ from those observed during training. We present MA-VLA, a unified framework for multi-arm collaboration via atomic action assignment. MA-VLA decomposes cooperative behavior into mid-level atomic prompts and allocates them to individual arms, enabling explicit subgoal specification and compositional reuse across tasks. To reduce reliance on fixed execution roles, we introduce Arm Shuffle, a training-time permutation of the observation, state, and assigned atomic prompts for each arm. This permutation enforces role-agnostic instruction following and supports recomposition into unseen coordination patterns, which we term multi-arm compositional generalization. We also construct a benchmark in which test-time collaboration patterns are absent in training set. Across simulation and real-world evaluations, prior state-of-the-art VLAs largely fail under these unseen collaborations, while MA-VLA consistently succeeds. These results indicate that structured, per-arm atomic action assignment offers a practical route to scalable generalization in multi-arm embodied systems. Code, models, and data are available at https://github.com/zhangzaibin/future-robots

## 2. 方法论：核心思想与技术细节

MA-VLA 是一个统一框架，包含两个主要组件：**VLM 规划器**和 **VLA 执行器**，并配合两种训练时正则化策略。

- **原子动作（Atomic Actions）**
  - 定义一个有限的原子动作库 `U = {u1, ..., uK}`，如抓取、抬起、对齐、放置等。
  - 多臂任务执行过程可表示为一系列带手臂标记的原子动作：
    `P = ((i1, u_k1), ..., (iT, u_kT))`。
  - 组合泛化设定：训练集与测试集共享相同原子动作库，但测试时协作结构（手臂角色分配、时序同步等）是新的、训练时未出现的。

- **VLM 规划器（VLM-based Planner）**
  - 使用一个视觉语言模型（文中提到使用 GPT-4.1）将高层指令 `l` 分解为 `T` 个阶段的原子提示：
    `(p1, ..., pT)`，其中每个阶段 `pt = (p1_t, ..., pN_t)`，`p_i_t ∈ A` 表示第 `i` 个手臂在阶段 `t` 的原子提示。
  - 规划器不进行微调，只输出规范化的语言提示，将“谁在何时做什么”显式化。
  - 原子提示模板集合 `A` 是预先定义、可复现的，规划器输出会被规范到有效模板。

- **VLA 执行器（VLA Executor）**
  - 在每个时刻 `t`，将所有手臂的原子提示拼接为统一指令字符串：
    `u_t = Arm0: p0_t, Arm1: p1_t, ..., ArmN: pN_t`。
  - 执行器输入包括：
    - 多视角视觉观测 `I_t`（全局视角 + 每臂腕部视角）；
    - 所有手臂的拼接本体状态 `s_t = [s1_t, ..., sN_t]`；
    - 统一指令 `u_t`。
  - 输出所有手臂的连续控制动作向量 `[a1_t, ..., aN_t]`。
  - 底层采用基于 **π0** 的流匹配（flow matching）公式：训练时预测去噪向量场，从噪声隐动作恢复到真实动作；采用多投影头将共享隐表示分解为各手臂动作头。

- **训练策略**
  - **Arm Shuffle（手臂随机重排）**：以概率 `p_shuffle` 在训练时随机排列手臂的状态、视图、提示和动作的对应关系。这迫使模型不能把行为绑定到固定手臂索引，从而学习角色无关的指令跟随。
  - **View Dropout（视角随机丢弃）**：以概率 `p_drop` 随机屏蔽部分相机视图，提高多视角推理的鲁棒性。
  - **训练目标**：统一的动作级行为克隆损失，不因使用 Arm Shuffle 和 View Dropout 而改变：
    `L_t(θ) = E[(O_t, l, A_t) ~ D] [Σ_i ℓ(π_θ(Ĩ_t, s_i_t, p_i_t), a_i_t)]`
    其中 `Ĩ_t` 等表示可能经过随机扰动后的输入。

## 3. 实验设计：数据集、基准与对比方法

- **仿真基准**
  - **RoboFactory**：多臂协作操作任务，包含 2–4 臂任务，强调协调与并行执行。具体任务如 Lift Barrier、Place Food、Two Arms Stack Cube、Pass Shoe、Three Arms Stack Cube、Camera Alignment、Long Pipeline Delivery、Take Photo。
  - **RoboTwin 2.0（Hard）**：双机械臂协作基准，包含更强视觉干扰（额外干扰物、背景变化、光照变化）。任务如 Place Dual Shoes、Handover Block、Stack Bowls Two、Grab Roller、Place Object (Cabinet)、Place Bread (Skillet)、Stamp Seal。

- **真实世界平台**
  - **SO101**：双机械臂系统，共 12 个自由度（每臂 6 自由度），配备 1 个全局 RGB 相机和每臂 1 个腕部相机，30 Hz。
  - 任务包括 **Stack Bowls、Place Cubes、Pass Toys、Stack Cubes**，每个任务同时评估域内（ID）和组合式域外（OOD）设置。

- **评估协议**
  - **域内协作（In-domain Collaboration）**：测试与训练相同任务分布，但加入随机扰动（物体姿态偏移、相机视角变化、环境变化）。
  - **域外组合泛化（Out-of-domain Compositional Generalization）**：测试未见的协作结构，如新的堆叠顺序、不同的传递策略、反向堆叠或角色交换等。
  - 仿真中每个配置评估 100 次 rollout，报告平均成功率；真实机器人每任务 20 次试验。

- **对比方法**
  - 行为克隆/扩散类：**ACT、Diffusion Policy (DP)、DP3**。
  - VLA 类：**Pi0-FAST、Pi0**。
  - 现有单臂方法通过适配输入输出接口在多臂 RoboFactory 上重新训练，使用相同的演示数据和匹配的训练预算。
  - 还对比了“独立每臂模型”基线（Separate Model）：每个手臂训练一个独立 VLA，测试时并行运行。

## 6. 主要结论与发现

- **原子动作分解提升域内协作**：与直接使用单一高层指令相比，按手臂分配原子提示能更好地消除手臂职责歧义，且手臂数量越多提升越明显。
- **Arm Shuffle 是实现组合泛化的关键**：仅加入原子动作而缺少 Arm Shuffle 时，域外任务成功率接近 0%；加入 Arm Shuffle 后出现非零成功率并显著提升，表明角色无关指令遵循对重组未见协作模式至关重要。
- **View Dropout 进一步增强鲁棒性**：在域外场景中可进一步提升成功率，且对域内性能只有轻微影响。
- **MA-VLA 优于现有 SOTA**：在 RoboFactory 和 RoboTwin 2.0 上均超过 Pi0、Pi0-FAST 等基线；在基线完全失败的域外任务中，MA-VLA 能取得非零成功。
- **独立每臂模型存在协调缺陷**：虽然单臂能跟随自身原子指令，但无法在多臂协作的未见任务中有效协调，且带来随臂数线性增加的推理开销。

## 7. 优点

- **显式分工界面**：通过原子提示实现“谁在何时做什么”的可解释表示，比单一全局指令更适合多臂协调。
- **角色无关训练**：Arm Shuffle 简单而有效，能打破固定手臂身份依赖，提升组合泛化能力。
- **统一模型，避免多模型开销**：所有手臂在单个前向传播中联合推理，与独立模型相比部署更简洁、更易扩展。
- **跨仿真和真实验证**：在两个仿真基准和一个真实双机械臂平台上均进行验证，结果一致支持方法的有效性。
- **充分的消融与参数分析**：对组件、shuffle 概率、独立模型等进行了细致实验，为结论提供了扎实支撑。
- **复现性**：论文提供代码、模型和数据链接，有助于后续复现与扩展。

## 8. 不足与局限

- **真实世界数据规模有限**：每个真机任务仅 50 条演示、20 次评估试验，成功率指标可能受偶然因素影响，真实环境的泛化性仍需要更大规模验证。
- **域外成功率整体偏低**：虽然相比基线有所提升，但多数未见协作任务成功率仍只有 9%–28%，距离实用还有较大差距。
- **依赖手工定义的原子行动库与解析器**：训练中的原子提示由基于规则的解析器生成，原子模板集合有限，可能限制对新任务的开放程度。
- **超参数需手工调节**：不同域外任务需要单独设置 Arm Shuffle 和 View Dropout 的概率，实际部署时可能需要额外调参。
- **VLM 规划器未微调**：规划器使用 GPT-4.1 生成原子提示，其质量依赖外部大模型，且模板规范过程可能存在错误传播；同时引入了外部 API 依赖和额外推理成本。
- **仅基于 π0 骨干**：方法在单个 VLA 骨干上验证，其对其他 VLA 架构的适用性尚未探索。
- **未与专门的多臂 RL 方法（如 RoboBallet）比较**：基线主要来自 BC/扩散和通用 VLA，缺乏与多臂强化学习方法的直接对比，结论的“优于现有 SOTA”范围有限。
