## 摘要
长程机器人操作要求机器人既能可靠执行单个技能，又能在长期任务中连贯地编排这些技能。大多数分层视觉-语言-动作（VLA）模型通过一次前向传播做出每一项此类决策，没有机制为困难或关键的选择分配额外计算。我们提出 τ₀-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算将高层子任务生成形式化为计算可扩展的推理问题。在每个推理步骤中，高层策略利用执行记忆生成子任务，并在需要时先搜索备选方案，再确定输出。随后，低层策略在多种机器人本体上执行所生成的子任务。该策略通过多模态协同训练在 40,115 小时的异构真实世界数据上进行训练。在域内与分布偏移场景下，分配额外测试时计算可显著提升下一子任务预测准确率，并且这些提升转化为长程机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 1. 论文的核心问题与整体含义

- **研究背景**：长程机器人操作（如清洁房间、做饭、泡茶）要求机器人不仅可靠执行单一技能，还要在长时间跨度内连贯地编排子任务序列。
- **核心问题**：大多数分层视觉-语言-动作（VLA）模型在每一步高层决策时仅使用一次前向传播，缺乏机制为困难或关键选择分配额外计算；错误的子任务选择无法通过更精确的运动控制来弥补。
- **整体含义**：将高层子任务生成重新表述为**计算可扩展的推理问题**，通过世界模型引导的测试时计算（test-time computation, TTC），在决策前评估候选子任务的物理后果，从而提升长程任务的可靠性与成功率。

## 2. 论文提出的方法论

- **系统结构**：τ₀-VLA 由高层策略（high-level policy）和低层策略（low-level policy）两级组成。
  - **高层策略**：由四个模型构成：
    - 提案模型 \(P\)：更新执行记忆并生成候选子任务；
    - 世界模型 \(W\)：预测给定候选子任务执行后的终端头相机 RGB 图像；
    - 价值模型 \(V\)：根据任务指令、候选子任务和预测图像输出标量质量分数；
    - 反射模型 \(F\)：基于束搜索保留的分支摘要和真实观察上下文生成最终子任务。
  - **低层策略**：基于 Qwen3.5-2B 视觉-语言骨干 + Mixture-of-Transformers (MoT) 动作专家，使用条件流匹配（flow matching）生成动作块。
- **关键流程**：
  1. 提案模型 \(P\) 输入上下文 \(h_t = (\ell, M_{t-1}, z^\star_{t-1}, o_t)\)，输出更新后的执行记忆 \(M_t\) 和直接提案 \(z^{\text{dir}}_t\)。
  2. 根据提案 token 的置信度统计（平均生成概率和 logit 边际）计算路由决策 \(g_t\)；若 \(g_t=0\)，直接采用 \(z^{\text{dir}}_t\)；若 \(g_t=1\)，触发测试时计算。
  3. **测试时搜索（beam search）**：从根分支开始，对每个保留分支调用提案模型 \(N\) 次生成候选子任务，世界模型预测每个候选的终端图像，价值模型评分；将子分支追加到路径并累计分数，全局保留 top-\(B\) 分支，递归扩展至深度 \(D\)。
  4. **反射生成**：反射模型 \(F\) 结合真实观察对齐上下文 \(\bar{h}_t\) 和保留分支摘要 \(C_t\)，生成最终子任务 \(z^\star_t\)。
  5. 低层策略以 \(z^\star_t\) 为语言命令，结合多视角观测、本体感受状态和控制元数据生成动作块执行；执行后的真实观察在下一推理步骤融入执行记忆，形成闭环。
- **统一动作空间**：使用 40 维状态/动作向量，涵盖末端执行器位姿、夹爪、腰部、平面基座速度和双臂关节角；采用掩码流匹配（masked flow matching）处理不同本体的通道差异。
- **训练细节**：
  - 低层策略三阶段训练：知识隔离协同训练 → 端到端协同训练 → 任务特定适配；
  - 高层策略从机器人预训练 VLM（Qwen3.5-9B）微调；世界模型初始化自 Step1X-Edit；执行记忆通过自动扰动（滞后、超前、错误等）训练自我纠正；价值模型采用多选 VQA 形式训练；反射模型以 ground-truth 下一子任务为自回归目标。

## 6. 论文的主要结论与发现

- 在长程任务上，**分层系统（带执行记忆）显著优于直接执行基线**：平均 SR 从 27.5% 提升至 45.0%，平均进度从 80.10% 提升至 87.85%；尤其在需要状态跟踪的任务（如番茄炒蛋的加盐）上优势明显。
- **测试时计算（TTC）能进一步提升闭环成功率**：例如 Make Milk Tea SR 从 5/10→7/10、Book Organization 从 6/10→9/10、Clean Room 从 5/10→7/10；开环预测准确率在 OOD 设置下从 Plan Once 的 50.0% 提升至 TTC 的 74.0%。

- **跨本体执行**：τ₀-VLA 低层策略在 Collect Laundry 和 Tidy Makeup Table 上总体优于或接近最佳基线，验证了统一动作空间的有效性。

## 7. 优点

- **创新性地将测试时计算引入高层子任务生成**：通过世界模型预测物理后果、价值模型评分、束搜索和反射模型，实现“先评估、后执行”，不同于传统的单步前向决策。
- **执行记忆可纠正且训练无需额外标注**：通过自动扰动记忆合成训练对，增强对滞后、超前和错误记忆的鲁棒性。
- **统一 40 维动作空间 + 掩码流匹配**：支持固定基座、移动全身和双臂协调，跨多种机器人本体部署。
- **实验设计覆盖开环与闭环、多任务多本体、分布偏移**，并定量展示计算成本与准确率关系，分析较全面。
- **分层与低层解耦**：低层策略保持统一控制接口，高层推理升级不影响底层执行，工程实用性较强。
