## 摘要
我们提出了FabriVLA，一种面向精确多任务操控的轻量级视觉-语言-动作模型。FabriVLA将InternVL3.5视觉-语言骨干网络与一个流匹配动作头相结合，该动作头具有跨动作令牌的门控自注意力机制以及浅层VLM层融合，以丰富空间上下文。该模型通过从预训练的VLM和随机初始化的动作头进行单阶段联合优化来训练。在涵盖50种不同操控任务的Meta-World MT50基准上，FabriVLA达到了90.0%的层级平均成功率，表明基于1B规模VLM构建的紧凑型VLA可以在不依赖数十亿参数VLA骨干网络的情况下实现强劲性能。

## Abstract
We present FabriVLA, a lightweight Vision-Language-Action model for Precise Multi-Task Manipulation. FabriVLA combines an InternVL3.5 vision-language backbone with a flow-matching action head featuring gated self-attention across action tokens and shallow VLM layer fusion for enriched spatial context. The model is trained via single stage joint optimization from a pretrained VLM and randomly initialized action head. On the Meta-World MT50 benchmark spanning 50 diverse manipulation tasks, FabriVLA achieves a tier-average success rate of 90.0%, demonstrating that a compact VLA built on a 1B scale VLM can achieve strong performance without relying on multi billion parameter VLA backbones.

# FabriVLA：面向精确多任务操控的轻量级视觉-语言-动作模型 — 详细总结

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型是通用机器人操控的主流范式，通过预训练的视觉-语言模型将语言指令与视觉观察对齐，生成可执行的动作序列。然而，现有的大规模VLA模型（如π0、RT-2）需要数十亿参数，计算成本高、推理延迟大，难以满足实时机器人控制需求。
- **核心问题**：**如何在保持高操控精度的前提下，构建轻量级VLA模型？** 具体目标是设计一个参数规模在1B左右的紧凑模型，使其在复杂多任务操控场景（如Meta-World MT50的50个任务）中达到与超大模型相当甚至更优的性能。
- **研究意义**：为低成本、低延迟的机器人操控系统提供可行方案，推动VLA模型在实际机器人部署中的实用化。

## 2. 方法论：核心思想与技术细节

### 2.1 整体架构

FabriVLA由三部分组成：
1. **InternVL3.5-1B视觉-语言骨干**（保留14层Transformer）
2. **状态编码器与动作编码器**
3. **流匹配动作头**（包含门控自注意力、浅层VLM融合）

### 2.2 关键技术

- **门控自注意力（Gated Self-Attention）**：在动作头的Transformer块中，引入一个可学习门控参数g，初始化为0。训练时门控逐渐打开，允许动作令牌之间建立依赖关系，建模50步预测时域内的时序结构。初始化时门控关闭，行为等同于仅含交叉注意力的Transformer，确保优化平滑。
- **浅层VLM层融合（Shallow VLM Layer Fusion）**：将VLM第6层（浅层，保留空间细节）的token序列与第14层（深层，语义信息）的token序列沿特征维度拼接，通过一个可学习线性投影（2048→1024）融合，初始化投影矩阵为[I|0]，保证初始功能等同深层仅用。该机制提供更丰富的空间上下文，提升精确操控（如物体定位、接触操作）。
- **流匹配（Flow Matching）训练**：
  - 从均匀噪声ϵ~U([-1,1]^50×24)与真实动作a之间做线性插值：x_t = (1-t)ϵ + t a
  - t从Beta(2,2)分布采样，集中在0.5附近
  - 目标函数：最小化预测速度v_θ与真实速度(a-ϵ)的MSE
  - 推理时：从纯噪声出发，通过欧拉积分（50步）生成动作
- **状态与动作编码**：机器人状态（24维，含末端位姿、夹爪状态、物体位置）通过两层MLP编码为1024维token；动作令牌通过共享MLP编码并添加水平位置编码（50×1024）。

### 2.3 训练流程

- **单阶段联合优化**：整个模型（VLM骨干+动作头）从开始一起训练，所有参数解冻。
- **优化器**：AdamW，学习率2e-5，线性预热1000步，余弦衰减，梯度裁剪1.0，权重衰减1e-4。
- **数据增强**：随机裁剪、旋转、颜色抖动。
- **数据**：Evo-1公开的Meta-World演示数据集，每个任务50条轨迹，共2500条轨迹。

3. **门控自注意力有效**：是动作头中最重要的组件，显著提升了跨步依赖建模能力。
