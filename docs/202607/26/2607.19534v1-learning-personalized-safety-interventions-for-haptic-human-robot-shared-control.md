## 摘要
触觉反馈为在人机共享控制中传达安全意图提供了隐式通道。现有的触觉引导系统通常采用预定义的干预策略，无法适应个体用户或应用场景的多样化安全偏好。为解决这一限制，我们提出了一种从触觉中学习（LfH）框架，该框架从稀疏演示中学习用户偏好的安全干预，消除了手动试错设计的需要。我们的框架基于一个可微的基于控制屏障函数（CBF）的优化层，该层自动调整底层安全参数以匹配演示的触觉响应。用户无需直接调整控制器参数，而是教系统在遥操作期间如何进行干预。由此产生的触觉引导反映了演示的干预偏好，同时保留了触觉共享控制的直观交互。仿真和硬件实验表明，所提出的框架能够从稀疏的用户输入中学习个性化的安全干预，并减少生成的触觉反馈与演示偏好之间的不匹配。

## Abstract
Haptic feedback provides an implicit channel for communicating safety intentions during human-robot shared control. Existing haptic guidance systems typically employ predefined intervention strategies that cannot accommodate the diverse safety preferences of individual users or application scenarios. To address this limitation, we propose a Learning from Haptics (LfH) framework that learns user-preferred safety interventions from sparse demonstrations, eliminating the need for manual trial-and-error design. Our framework is built on a differentiable Control Barrier Function (CBF)-based optimization layer that automatically adjusts the underlying safety parameters to match the demonstrated haptic responses. Instead of tuning controller parameters directly, users teach the system how they expect it to intervene during teleoperation. The resulting haptic guidance reflects the demonstrated intervention preferences while preserving the intuitive interaction of haptic shared control. Simulation and hardware experiments demonstrate that the proposed framework can learn personalized safety interventions from sparse user input and reduce the mismatch between the generated haptic feedback and the demonstrated preferences.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：触觉共享控制（Haptic Shared Control）通过力反馈向操作者隐式传达安全意图，常用于无人机/机器人遥操作。近年来，控制屏障函数（CBF）被用于生成安全干预力反馈，其行为由CBF响应参数（增益 k1, k2）决定。
- **问题**：现有触觉引导系统使用预定义的固定干预策略，无法适应不同用户或应用场景的个性化安全偏好。手动调整CBF参数困难且依赖经验，因为参数到触觉反馈的映射是隐式的（通过CBF-QP求解），小改变可能导致非直观行为。
- **研究动机**：开发一种学习框架，让用户通过稀疏演示指定其偏好的干预强度，系统自动学习CBF响应参数，从而生成个性化的安全干预，同时保留原有共享控制结构和操作者控制权。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：提出“从触觉学习”（Learning from Haptics, LfH）框架，分为三阶段：初始遥操作记录 → 回放式偏好演示与学习 → 部署个性化参数。框架将CBF-QP嵌入可微优化层，通过反向传播优化响应参数。
- **关键技术细节**：
    - **系统建模**：无人机为双积分器动力学（加速度控制）。CBF采用指数CBF公式，使用线性K类函数：α1(h)=k1h, α2(˙h)=k2˙h。力反馈定义为 F_cbf = k_f (u_cbf - u_ref)，其中u_cbf来自CBF-QP求解，u_ref根据用户速度指令计算。
    - **偏好演示**：用户回顾记录的遥操作录像（FPV），在稀疏时间点只修改力的大小（方向保持不变），得到缩放因子ρ。通过高斯过程回归（GP）将稀疏演示插值为连续期望力轨迹F_wish。GP先验均值为1（偏好无修改区域恢复默认），核为RBF。
    - **学习问题**：将CBF约束分组（每组对应语义类别或障碍物），每组拥有独立的响应增益Θ = {k1_s, k2_s}。学习目标是最小化生成力与期望力之间的均方误差，并加入正则项防止过度偏离初始参数。
    - **反向传播**：CBF-QP视为可微优化层，通过KTT条件推导灵敏度，利用CVXPYLayers和PyTorch计算梯度并更新参数。
    - **约束构建**：基于FPV感知的语义约束（从语义标签、深度计算屏障函数）或基于SDF的约束（从运动捕捉系统构建），均提供所需的h, ∂h, ∂²h以满足CBF。

## 6. 主要结论与发现

- 提出的LfH框架能够从稀疏用户演示中学习个性化CBF响应增益，使生成的触觉力更接近用户偏好（仿真中MSE降低23.1%相对于Nominal CBF）。
- 语义分组的学习（Top-K）优于全局统一增益（Global DiffQP），表明不同语义类别需要不同的干预强度。
- GP权重加权策略效果不如语义加权或统一加权，可能因为过度聚焦于编辑点附近样本而忽略整体分布。
- 硬件实验成功部署，实现障碍物依赖的个性化干预（增强某障碍、抑制另一障碍）。
- 框架兼容不同CBF约束构造（感知式与SDF式），具有通用性。

## 7. 优点

- **无需手动调参**：用户通过稀疏演示（仅修改力大小）即可个性化，降低了专家知识门槛。
- **保留共享控制结构**：学习过程不改变CBF-QP框架和操作者控制权，生成的干预仍保持隐式通信。
- **可微优化集成**：将CBF-QP作为可微层，利用反向传播高效学习，避免端到端策略学习所需大量数据。
- **支持多种安全表示**：框架与特定障碍表示解耦，可集成FPV语义约束、SDF等。
- **回放界面设计合理**：结合视觉和触觉回放，用户可直观评估并调整。

## 8. 不足与局限

- **实验规模小**：仅一条仿真轨迹、一个硬件演示，缺乏多用户、多环境、多任务的广泛验证，可能无法代表真实应用泛化性。
- **偏好仅限幅度调整**：用户只能修改力的大小，不能改动方向或时机，限制了个性化的灵活性。
- **依赖预定义语义分组**：分组质量影响学习效果；若语义类别划分不当，学习可能无效。
- **GP先验假设**：未演示区域默认返回初始参数，可能并非用户真实意图。
- **剩余误差**：由于参数共享，无法完美匹配帧级偏好变化，存在残余不匹配。
- **缺乏用户研究**：未评估演示工作负载、满意度、学习曲线等主观指标。
- **硬件实验不可复现**：手动遥操作导致轨迹不可重复，限制了定量比较的可信度。
