## 摘要
视觉-语言-动作（VLA）模型已展现出在具身人工智能中的巨大潜力，但其在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）提高了效率，但将VLA模型视为全精度工作负载，留下了大量内存和计算冗余未被利用。在本文中，我们提出了VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态来加速VLA推理。我们首先引入MotionVQ，一种运动感知向量量化方案，根据机器人的执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。然后，我们提出了一种基于码本索引表示的合并质心向量化GEMM范式，通过空间聚合和时间质心复用来消除冗余乘法。为了实现这些优化，我们设计了一种加速器，有效支持动态精度选择和质心复用计算。实验结果表明，与A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM相比，VQVLA分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度下降可忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心洞察

**洞察一（执行状态与量化敏感性）：**
- 通过分析机器人运动行为，发现**运动幅度与空间邻近性强相关**：当运动幅度小（≤0.8）时，机械臂靠近目标物体（距离≤0.16），处于**执行状态（Execution State）**，需要精细调整，对量化误差高度敏感；当运动幅度大（>0.8）时，机械臂远离物体，处于**过渡状态（Transition State）**，运动约束少，对扰动更鲁棒。
- 通过向两种状态分别注入噪声的实验验证：相同噪声水平下，过渡态的成功率始终高于执行态，证明过渡态对量化误差的容忍度更高。

**洞察二（质心访问的极度不平衡）：**
- 对VQ量化后的质心访问频率进行可视化分析，发现**部分质心（热质心）被频繁访问**（最高访问234次），而另一些则很少被访问（最低10次），存在明显的质心局部性（Centroid Locality）。

### 2.2 MotionVQ：运动感知向量量化算法

- **离线准备：** 预先训练两套精度配置——高精度配置 VQ[256, 2, 256]（平均比特宽约4.125bit，包含256个质心）和低精度配置 VQ[128, 2, 64]（平均比特宽约3.125bit，包含64个质心）。
- **状态预测：** 计算运动幅度 \(D = \sqrt{A_x^2 + A_y^2 + A_z^2}\)（从上一次VLA推理输出的3D动作获得），与阈值 \(T_d\) 比较：\(D \leq T_d\) 判定为执行态（使用高精度），\(D > T_d\) 判定为过渡态（使用低精度）。
- **动态精度适配：** 根据预测状态动态选择对应码本和索引矩阵，在保持成功率的同时减少内存读取。

### 2.3 合并质心向量化GEMM（Merged-Centroid Vectorized GEMM）

该范式直接操作码本-索引表示，**跳过去量化步骤**，利用质心重复性消除冗余乘法。

**空间合并（Spatial Merging）：**

- **原理：** 利用**同一列内**重复出现的质心（空间级热质心）。当多个权重向量映射到同一质心时，根据乘法分配律，可先累加对应输入再做一次乘法：
  \[
  \sum (I_i \times \text{Centroid}) \rightarrow (\sum I_i) \times \text{Centroid}
  \]
- **实现：** 离线构建每列权重组的**空间质心位置表**（记录质心ID与对应的权重向量ID），将仅出现一次或零次的条目丢弃，对重复条目将输入先累加再乘。

**时间复用（Temporal Reusing）：**

- **原理：** 利用**跨列之间**重复出现的质心（时间级热质心），跳过与相同质心和相同输入相乘的冗余乘法，直接复用缓存结果。
- **实现：** 离线通过Top-k选择确定最频繁访问的热质心；运行时使用结果缓存维护 (tag, data) 条目（tag为质心ID和权重向量ID的元组），计算时先查缓存，命中则直接复用缓存结果，未命中则正常计算。

### 2.4 VQVLA加速器架构

- **状态预测器（State Predictor）：** 由运动幅度计算单元（3个乘法器+1个加法器）和阈值比较器组成，开销极低。
- **索引处理引擎（Index Processing Engine）：** 由多个索引处理单元（IPU）组成，并行扫描索引矩阵的列，生成空间/时间质心位置表。根据Cnt（映射到同一质心的权重向量数）划分：Cnt>1 → 空间表；Cnt=1 → 时间表。
- **空间合并PE阵列：** 24×256个PE，集成**三段流水加法树**（3个周期内可完成1个8输入归约、2个4输入归约和4个2输入归约，共产生7个部分和），每个PE集成3个乘法器。
- **时间复用PE阵列：** 24×256个PE，集成1.5MB结果缓存和缓存初始化单元，每个PE含2个乘法器。

## 6. 论文的主要结论与发现

1. **算法层面（MotionVQ）：** 相比基线（全精度），平均任务成功率仅下降 **2.5%**（可接受范围）；内存访问平均减少 **79.4%**；乘法运算平均减少 **54.8%**（不同任务差异明显：OpenVLA/LIBERO-Object达71.4%，RDT/ManiSkill-StackCube仅52.2%）。
2. **硬件层面（VQVLA架构）：**
   - 相比A100 GPU（GPU-A100）：**6.5×**加速；相比LUT-DLA：**1.9×**；相比CodeGEMM：**3.3×**；相比ShiftAddLLM：**4.3×**。
   - 相比Dadu-Corki：**2.8×** 每动作延迟提升；与Dadu-Corki组合（VQVLA-Corki）后提升达 **6.0×**。
   - PE利用率 **90.6%**（高于LUT-DLA的73.3%）。
   - 能耗相比GPU降低 **75.5×**（总功耗仅为A100的6.4%）。
3. **关键发现：** GPU-VQVLA相比GPU-A100有45.2%的性能损失，说明合并质心GEMM算法的索引遍历、不规则逻辑处理等操作在GPU上**难以高效映射**，**专用硬件支持是必要的**。
4. **消融归因：** 状态感知动态加载减少3.8×内存访问延迟；空间合并PE阵列减少1.5×延迟；时间复用PE阵列减少1.6×延迟。

## 7. 优点

1. **洞察新颖且具学科交叉价值：** 将**机器人运动学行为（运动幅度）与量化精度选择**建立关联，跳出传统量化方法静态、与系统状态无关的范式。
2. **算法-硬件协同设计完整闭环：** 从观察到洞察 → 算法设计（MotionVQ+合并质心GEMM）→ 硬件架构实现 → 周期级仿真+流片前综合验证，形成完整方法论。
3. **双重冗余挖掘：** 同时利用**空间维度**（列内质心重复）和**时间维度**（跨列质心重复）的质心局部性，实现乘法减少54.8%，思路清晰且可推广。

6. **与现有方案正交：** 明确与Dadu-Corki可组合（6.0×），展示了集成到现有系统的兼容性。
7. **实验对比全面：** 同时对比通用GPU、VLA专用加速器、VQ加速器、GPU量化加速方法，覆盖充分。

## 8. 不足与局限

1. **GPU部署性能不佳：** GPU-VQVLA相比GPU-A100反而损失45.2%性能，说明VQVLA的效益高度依赖专用硬件，对现有GPU用户不具备直接可用性。
2. **未在真实机器人上部署验证：** 实验全部基于仿真环境（LIBERO、ManiSkill），未在物理机器人上验证。仿真与真实世界的差距（感知噪声、执行误差）可能影响MotionVQ的阈值有效性。
3. **权衡依赖单一阈值：** 过渡态/执行态的二元划分依赖T_d=0.8经验阈值，不同任务/模型可能存在差异，论文仅用10%校准数据验证，泛化性证据有限。
4. **硬件开销较大：** 总面积为51.15mm²（7nm等效），其中索引处理引擎27.93mm²、结果缓存15.93mm²占比较大，在资源受限的边缘机器人设备上部署可能受限（论文提及可裁剪但未量化裁剪后性能损失）。
5. **精度损失存在任务间差异：** 平均成功率下降2.5%，但不同任务的下降幅度可能不均（论文仅给出平均，未逐任务详细报告方差）。
6. **基线对比细节不足：** 对CodeGEMM和ShiftAddLLM的对比未说明是否启用了Tensor Core优化，可能影响公平性。
7. **未讨论泛化到非VLA场景：** 合并质心GEMM利用了VLA中Transformer backbone的权重结构，该范式是否适用于其他模型（如纯LLM或ViT）缺乏讨论。
8. **理论分析深度有限：** 对乘法消除的理论上界、码本大小与质心复用率之间的解析关系缺乏数学建模，更多依赖实验观察。
