## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法引起了越来越多的关注。虽然这些模型是有效的动作预测器，但将它们部署为机器人智能体会暴露出关键缺陷：缺乏故障恢复机制、长时程执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块单独解决这些局限性，然而所需要的是一种通用框架，能够系统性地将预训练的VLA转化为机器人智能体。我们提出了RoboBRIDGE，这是一种模块化框架，通过五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）提供编排层，以从现成组件（包括预训练VLA）组合出稳健的机器人智能体。Monitor将快速故障检测与分层恢复相结合，在错误级联之前予以纠正。当环境偏离当前计划时，Planner触发重新规划，同时Perceptor异步更新场景理解，避免执行停滞。在Controller内部，原始技能微调将操作分解为具有专用LoRA适配器的域不变原始动作，从而降低使用VLA时对域偏移的敏感性。在LIBERO、RoboCasa以及跨越多个机器人平台和VLA骨干的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人智能体并非仅通过扩展动作预测器来实现，而是通过在它们周围进行结构化编排来实现。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

### 2. 论文提出的方法论

**核心思想**：RoboBRIDGE是一个模块化、策略无关（policy-agnostic）的编排框架，将任何动作生成策略封装为稳健的机器人智能体，无需重新训练或修改基础模型。

**框架组成（五个协调模块）**：
- **Perceptor（感知器）**：将原始传感观测转换为以物体为中心的场景状态（物体身份、3D位姿、语义属性等）。
- **Planner（规划器）**：接收场景状态和语言指令，将任务分解为有序的原始技能序列。
- **Controller（控制器）**：动作生成策略的插槽位置，可由VLA模型、经典IK控制器或脚本化程序担任。
- **Robot Interface（机器人接口）**：抽象机器人特定的API、时序、安全限制和坐标变换，使上层逻辑可跨平台复用。
- **Monitor（监控器）**：闭环验证执行结果，检测失败时触发分层恢复。

**三大核心机制**：

**(a) 两阶段监控与失败恢复**
- **阶段一（轻量级成功检查）**：使用视觉语言模型周期性地对当前观测与计划上下文进行二元成功判断，采用约束输出格式抑制冗长推理，保证低延迟、不阻塞控制循环（约5Hz）。
- **阶段二（失败诊断与恢复）**：仅当高置信度失败时调用，推断失败原因并选择恢复目标。恢复策略分四个层级，按重新计算范围递增：
  1. **重试（retry）**：重新执行当前原语。
  2. **重新生成（regenerate）**：保留当前计划和感知状态，重新生成轨迹。
  3. **重新规划（replan）**：基于最新异步感知进行重新规划。
  4. **重新感知（re-perceive）**：强制完整重新感知后再规划（感知状态不可靠时）。

**(b) 异步感知与发散触发的反应式规划**
- 采用生产者-消费者架构，感知线程持续更新线程安全缓冲区中的最新检测结果。
- 每个原语执行完毕后，计算当前计划所用感知状态与最新感知状态之间的发散度：
  - Δ(ōₐ, ō_b) = maxᵢ ‖p_a⁽ⁱ⁾ − p_b⁽ⁱ⁾‖₂ + λ·|Oₐ △ O_b|（三维位置位移 + 物体出现/消失的集合差异加权项）。
- 当发散度超过阈值τ时，保留高层动作序列（如PICK→PLACE），仅基于最新感知重新生成当前和后续的原始技能，避免冗余的高层推理并使用更新后的空间参数。

**(c) 原始技能微调（Primitive Skill Fine-tuning）**
- 将操作分解为域不变原始技能集合P = {MOVE, GRIP, ROTATE, ...}。
- 每个原语配备专用LoRA适配器，附加在冻结的VLA骨干网络上：f_{θ+Δθₖ}: (i, s_t, p_t) → aₜ⁽ᵏ⁾。
- **控制器切换机制**：采用两级解析器，存在对应适配器时选用之，否则回退到所有注册适配器的均值。
- **动作生成与执行**：预测7自由度增量动作 aₜ = (δx, δϕ, g)，通过笛卡尔速度指令或IK逆运动学解算（IK失败时回退速度指令）执行，实现跨不同运动学接口的机器人部署。

### 6. 论文的主要结论与发现

1. **框架提升的一致有效性**：无论使用哪种VLA骨干，RoboBRIDGE均能一致提升任务成功率（LIBERO上平均从35.5%提高至39.7%；RoboCasa上GR00T-N1.5从4.2%提高至9.8%，排除PnP任务后从6.2%提高至14.7%），证实其模型无关的通用性。
2. **两阶段监控是关键增益来源**：无监控时各LLM骨干性能差异很小（1.8%-8.0%），启用监控后差异显著（最强+8.1p.p.），说明规划质量单独不足以弥合VLA与可靠智能体之间的差距，失败诊断需要LLM具备足够的推理能力。
3. **LoRA微调+框架组合的高效性**：LoRA微调搭配RoboBRIDGE达到27.1%，接近全量微调单独部署的31.9%，但参数更新量大幅减少；全量微调叠加框架可达40.0%，说明框架对强控制器同样有增益。
4. **外部编排优于模型内部纠错**：CycleVLA（模型内部子任务回溯+自纠错）在框架外仅达7.5%，远低于RoboBRIDGE提供的结构化外部编排效果。
5. **策略无关设计得到验证**：经典IK控制器在框架内也能达到22.1%的成功率，证明了框架的「控制器插槽」设计可容纳非学习型策略。
6. **两大主导失败模式**：感知错误（遮挡/相似物体导致的错误识别或定位）和不可恢复的操作失败（接触丰富场景中环境状态不可逆改变），指向未来需要更强的感知鲁棒性和显式验证/确认机制。

### 7. 优点

- **通用性与模块化设计**：框架策略无关，可包装任意动作生成策略（VLA、经典控制等），五模块解耦设计清晰，具有强可扩展性。
- **类比LLM智能体演进路径的洞见**：从LLM社区的成功经验出发，将问题重新定义为「编排」而非「模型规模」，视角新颖且具有理论说服力。
- **两阶段监控的分层恢复策略**：轻量检查+重诊断的分离设计合理控制延迟，四级恢复策略（重试→重生成→重规划→重感知）按代价递增，体现工程上的务实考量。
- **异步感知架构**：将感知从执行中解耦，通过线程安全缓冲区隐藏感知延迟，以发散度度量触发反应式重规划，避免执行停滞，设计巧妙。
- **原始技能微调+LoRA适配器的域不变设计**：将操作分解为域不变原语（MOVE、GRIP），降低跨本体、跨环境的域迁移敏感性，参数效率显著优于全量微调。
- **实验覆盖较广**：多仿真基准（LIBERO、RoboCasa）+多VLA骨干（3种）+多机器人平台（2种）+多LLM骨干（6种）+多控制器类型（4种），验证层次丰富。

- **实验统计力度有限**：每个任务仅约17次rollout（以5.9%为最小粒度），样本量小且未报告方差和置信区间，部分改进幅度在统计上可能不显著。
- **RoboCasa得分绝对水平较低**：即便有框架帮助，多数任务成功率仍处于个位数到15%左右的较低区间，距离可靠部署尚有显著差距。
- **真实世界评测系统性不足**：仅展示案例轨迹截图（训练环境和未见环境各一组），缺乏多轮重复实验的成功率统计，难以量化框架在真实场景中的增益幅度。

- **原始技能词汇量有限**：当前覆盖单臂桌面行为，对接触丰富操作、可变形物体、双臂任务需要更丰富的原语和状态表示。
