## 摘要
世界动作模型（WAM）通过基于视频的世界建模作为机器人动作学习的密集监督，为视觉-语言-动作（VLA）策略提供了一种有前景的替代方案。现有的WAM擅长物理基础的执行，但通常缺乏基于VLM的VLA中用于分解粗略指令的显式语言级规划接口。当家庭任务涉及复杂的多步骤目标时，这种分解变得重要，因为粗略的用户命令需要转换为一系列精细的可执行子任务。同时，该领域仍然缺乏VLA和WAM执行能力的公平真实机器人比较，因为现有系统通常在数据、机器人本体和任务协议上有所不同。为了解决分解差距以及对受控WAM-VLA比较的需求，我们提出了DSWAM，一种用于精细机器人操作的双系统世界动作基础模型。DSWAM保留系统1的WAM执行器作为默认控制路径，并可选地在任务分解有用时激活系统2的视觉-语言子任务规划器。规划器从短期视觉历史和全局任务提示中预测可执行的子任务，而WAM执行器为每个指令或子任务执行具有世界感知的动作生成。执行器通过动作预测和视频联合训练进行训练，但推理直接预测动作块，无需显式的未来视频生成。为了使该执行路径在实际机器人上实用，我们进一步集成了TensorRT加速、异步执行和实时分块（RTC），使策略查询不会阻塞机器人控制。为了与VLA策略进行公平的真实机器人比较，我们在DeMaVLA真实世界可变形操作设置下构建和评估DSWAM，采用匹配的机器人平台、预训练数据、后训练数据和评估标准。

## Abstract
World Action Models (WAMs) provide a promising alternative to Vision-Language-Action (VLA) policies by using video-based world modeling as dense supervision for robot action learning. Existing WAMs excel at physically grounded execution, but typically lack the explicit language-level planning interface in VLM-based VLAs for decomposing coarse instructions. Such decomposition becomes important when household tasks involve complex multi-step goals, where coarse user commands need to be converted into sequences of fine-grained executable subtasks. Meanwhile, the field still lacks a fair real-robot comparison between VLA and WAM execution capabilities, since existing systems often differ in data, robot embodiments, and task protocols. To address both the decomposition gap and the need for a controlled WAM-VLA comparison, we introduce DSWAM, a Dual-System World Action Foundation Model for fine-grained robot manipulation. DSWAM keeps a System 1 WAM executor as the default control path and optionally activates a System 2 vision-language subtask planner only when task decomposition is useful. The planner predicts executable subtasks from short-term visual history and a global task prompt, while the WAM executor performs world-aware action generation for each instruction or subtask. The executor is trained with action prediction and video co-training, but inference directly predicts action chunks without explicit future video generation. To make this execution path practical on real robots, we further integrate TensorRT acceleration, asynchronous execution, and real-time chunking (RTC) so that policy queries do not block robot control. To provide a fair real-robot comparison with VLA policies, we build and evaluate DSWAM under the DeMaVLA real-world deformable manipulation setting with matched robot platform, pretraining data, post-training data, and evaluation criteria.

- **核心问题**：现有世界动作模型（WAM）虽然擅长物理基础的执行，但缺乏显式的语言级规划接口，难以将粗略的用户指令（如“整理桌子上的物品”）分解为一系列精细的可执行子任务。同时，该领域缺少在机器人本体、数据、任务协议完全一致的条件下对 WAM 与 VLA 策略进行公平的实机对比。
- **整体含义**：家庭机器人操作任务往往涉及多步骤目标，需要“任务分解”与“物理执行”的解耦。本文提出一种双系统框架 DSWAM，系统 1 是高效的 WAM 执行器（负责世界感知的动作生成），系统 2 是可选的视觉-语言子任务规划器（仅在需要分解时激活）。该设计既保留了 WAM 在接触丰富的物理操作中的优势，又弥补了语言级任务组织的不足，并通过在 DeMaVLA 协议下的公平对比，证明了 WAM 风格执行策略相对 VLA 的能力优势。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：采用双系统架构，将语义任务分解与物理执行解耦。
  - **System 1（WAM 执行器）**：默认的控制路径，基于预训练的视频模型（Wan2.2-TI2V-5B）和动作专家，以多视角 RGB 图像、语言指令/子任务、本体感觉为输入，直接预测连续动作块（action chunk）。训练时使用动作预测与视频联合训练（flow matching 损失），推理时无需显式的未来视频生成。
  - **System 2（视觉-语言子任务规划器）**：可选的模块，基于 Rynnbrain4B 风格的视觉-语言模型。给定全局任务提示和短期视觉历史（最近 5 帧，采样率 1 Hz），预测下一个可执行的子任务指令。训练数据通过预训练的视觉-语言标注器对机器人轨迹视频进行子任务分割，并设计“转换感知”标签（子任务内部、非终止子任务最后窗口输出下一子任务、终止子任务输出 done）。规划器仅在需要分解的指令下激活。
- **关键技术细节**：
  - **动作执行**：使用条件流匹配（Conditional Flow Matching）预测连续动作块，适合双机械臂操控。
  - **视频联合训练**：在训练时，除了动作损失，还加入未来视觉 token 的预测损失，提供世界建模的密集监督；但动作分支不能使用未来视觉 token 作为特权信息。
  - **高效部署**：
    - 推理时直接预测动作块，避免未来视频生成带来的延迟。
    - TensorRT 加速：将视觉上下文编码和动作去噪拆分为两个引擎，BF16 路径下推理延迟从 198.2 ms 降至 73.8 ms（2.69 倍加速）。
    - 异步执行与实时分块（RTC）：策略查询与机器人控制循环解耦，不阻塞低频控制。
  - **系统 2 与系统 1 耦合**：每隔 2 秒，WAM 执行器向规划器发送最近 5 帧，规划器返回当前子任务；若规划器未激活，则直接使用原始指令。

## 3. 实验设计：使用数据集/场景、基准、对比方法

- **RoboTwin 2.0 仿真基准**：包含 50 个双臂操作任务，分为固定初始配置（clean）和随机化场景布局（randomized）两种设置。
- **DeMaVLA 真实世界折叠基准**：使用 ALOHA 风格双臂平台，评估 4 种衣物折叠任务（衬衫、裙子、裤子、毛巾），每类包含两个物理实例（一个简单、一个困难），各 10 次试验，共 20 次/类。全程覆盖“从篮子中取出→摊平→折叠”的完整流程。
- **System 2 排序任务**：真实世界桌面排序，指令“整理桌子上的物品”，分解为“拿起玩具车放进盒子”和“拿起面包放在盘子上”。

- DSWAM 在仿真 RoboTwin 2.0 上达到 clean 92.38%、randomized 91.90% 的平均成功率，优于所有对比方法（包括 VLA 和 WAM 基线）。

## 7. 优点

- **架构设计巧妙**：双系统解耦了语义规划与物理执行，系统 1 作为默认路径，系统 2 按需激活，避免了不必要的规划开销，同时保留了 WAM 在接触操作中的优势。
- **公平对比**：在 DeMaVLA 协议下，首次实现了 WAM 与 VLA 在相同平台、数据、任务和评估标准下的实机对比，证据有力。

- **训练机制**：视频联合训练提供世界建模监督，但动作分支不依赖未来信息，保证了训练与推理一致性。
- **仿真与实物实验全面**：覆盖 50 个仿真任务和 4 类衣物折叠，结果可靠。
