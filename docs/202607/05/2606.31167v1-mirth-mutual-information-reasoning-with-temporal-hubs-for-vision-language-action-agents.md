## 摘要
VLA模型已成为将网络规模数据的语义知识迁移到物理机器人控制的强大范式。然而，当前单帧架构存在内在局限性：忽略历史动态的时间短视、高级指令与低级电机命令之间的推理差距，以及自回归标量解码导致的推理效率低下。在这项工作中，我们提出MIRTH，一个统一框架以解决这些挑战。MIRTH通过三个关键创新增强预训练VLA主干：（1）双尺度时间记忆枢纽，将长期场景演变和短期运动趋势压缩为紧凑嵌入；（2）通过互信息目标优化的潜在推理令牌，刻画出语义规划空间以对齐多模态上下文与动作轨迹；（3）并行动作解码方案，用向量级预测替代自回归生成以最大化控制吞吐量。在LIBERO模拟基准和真实世界LeRobot平台上的广泛评估表明，MIRTH实现了最先进的性能，并展现出涌现的错误恢复能力。代码和收集的数据集发布在http://github.com/kiva12138/mirth。

## Abstract
VLA models have emerged as a powerful paradigm for transferring semantic knowledge from web-scale data to physical robotic control. However, current single-frame architectures suffer from intrinsic limitations: temporal myopia that discards historical dynamics, reasoning gaps between high-level instructions and low-level motor commands, and inference inefficiency due to autoregressive scalar decoding. In this work, we propose MIRTH, a unified framework designed to address these challenges. MIRTH augments a pretrained VLA backbone with three key innovations: (1) dual-scale temporal memory hubs that compress long-term scene evolution and short-term motion trends into compact embeddings; (2) latent reasoning tokens optimized via a mutual-information objective carving out a semantic plan space to align multimodal context with action trajectories; and (3) a parallel action decoding scheme that replaces autoregressive generation with vector-wise prediction to maximize control throughput. Extensive evaluations on the LIBERO simulation benchmark and a real-world LeRobot platform demonstrate that MIRTH achieves state-of-the-art performance and exhibiting emergent error recovery capabilities. The codes and collected datasets are released at http://github.com/kiva12138/mirth.

# 论文详细总结：MIRTH

## 1. 核心问题与整体含义（研究动机和背景）

当前视觉-语言-动作（VLA）模型（如 OpenVLA、RT-2）存在三个关键局限性：
- **时间短视（Temporal Myopia）**：仅依赖单帧观测，忽略历史动态，导致在物体被遮挡或状态变化时失败。
- **推理鸿沟**：高维语言指令与低维电机命令之间缺乏有效的中间表示，直接映射缺乏可解释性和规划能力。
- **推理效率低下**：自回归逐标量解码连续动作，产生长序列 token，延迟高，难以满足实时控制需求。

MIRTH 旨在统一框架内同时解决以上问题，使 VLA 模型具备历史感知、潜在语义推理和高吞吐量执行能力。

## 2. 方法论：核心思想与关键技术

MIRTH 基于预训练的单帧 VLA 主干（如 OpenVLA），引入三个主要创新模块：

### 2.1 双尺度时间记忆枢纽
- **工作空间记忆（长期）**：通过 K 个指数移动平均（EMA）以不同衰减率压缩长期场景布局，并融合运动速度和方差的统计量。每个时间步输出固定长度的特征图，不随历史长度增加。
- **短时记忆枢纽**：维护最近 w 帧的队列，通过时间注意力（含 recency bias）加权求和，捕捉短期运动动态。
- **融合与注入**：通过可学习门控融合两个记忆，然后以“前缀（prefix）”或“注入（infusion）”方式整合到当前帧的表示中。前缀方式将记忆展平作为额外 token 拼接到输入序列，注入方式直接调制当前帧的 patch 嵌入。

### 2.2 潜在推理令牌与互信息优化
- 在语言主干输入序列中插入一组可学习的**推理令牌**，位于感知/指令 token 与动作 token 之间。
- 从语言模型输出中分别提取推理表示 \(z_R\)、动作表示 \(z_A\)、上下文表示 \(z_X\)，通过 InfoNCE 损失最大化推理表示与动作、上下文之间的互信息：
  - \( \mathcal{L}_{ra} \)：拉近推理与动作
  - \( \mathcal{L}_{rx} \)：拉近推理与上下文
- 共训练目标：\( \mathcal{L} = \mathcal{L}_{l1} + \lambda_{mi} \mathcal{L}_{MI} \)，其中 \(\mathcal{L}_{l1}\) 是动作回归的 ℓ1 损失。

### 2.3 并行动作解码
- 用单个 token 表示一个完整动作向量（所有自由度），而非每个自由度一个 token。
- 对动作 token 的隐状态进行全局投影（全局向量解码），并行输出整个动作块，消除自回归链。

### 整体流程
每个时间步，编码当前帧和 proprioception，更新记忆 hub，构造输入序列，通过语言模型一次前向传播得到所有推理和动作 token，并行解码动作块。记忆 hub 的增量更新使得推理高效。

## 6. 主要结论与发现

- **性能领先**：MIRTH 在 LIBERO 平均成功率 98.1%，超越 OpenVLA-OFT（97.1%）和 OpenVLA（76.5%）。在 LeRobot 真实环境中同样最佳。
- **时间记忆有效**：去除长期或短期记忆 hub 均导致性能下降（分别 -1.3%、-0.9%），同时去除则下降 2.1%。线性探测显示 MIRTH 能捕捉运动速度和状态，优于单帧模型。
- **推理令牌提升语义对齐**：去除 MI 损失或推理令牌分别使成功率下降 0.8%、1.4%。t-SNE 可视化显示推理令牌按任务语义形成簇。
- **并行动作解码提升效率**：前缀方式获得更高成功率（95.3%），但注入方式吞吐量更高（70 Hz vs 64.4 Hz）。全局向量解码收敛更快。
- **涌现错误恢复能力**：MIRTH 完整模型的错误恢复率为 12.1%，远高于 OpenVLA（5.2%）和去除推理令牌的变体（8.7%），表明推理令牌有助于检测并纠正失败。

## 7. 优点

1. **创新性**：将时间记忆、潜在互信息推理和并行动作解码有机整合，统一解决 VLA 三大瓶颈。
2. **效率优先**：记忆 hub 固定长度、并行动作解码，在保持语言模型语义丰富性的同时实现高吞吐（60+ Hz），适合实时控制。
3. **无需文本标注**：潜在推理令牌通过互信息优化，避免收集中间文字监督，解决标注稀疏和语言歧义问题。
4. **模块消融清晰**：每个组件贡献均被量化验证，设计决策有依据。
5. **开放平台验证**：使用开源 LIBERO 模拟器和 LeRobot 真实平台，可复现性强，并公开代码和数据集。

## 8. 不足与局限

1. **可解释性差**：潜在推理令牌优化信息流通而非人类可读，难以 debug 或审计内部决策逻辑。
