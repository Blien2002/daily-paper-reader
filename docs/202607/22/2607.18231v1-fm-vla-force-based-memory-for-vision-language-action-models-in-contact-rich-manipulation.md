## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展现出令人印象深刻的泛化能力，而最近的记忆增强型VLA模型通过以过去的图像或语言摘要为条件，放宽了马尔可夫假设。基于视觉的记忆方法通过以采样的过去图像帧为条件来解决这一问题，但计算成本高，并且当事态事件在视觉上模糊时（例如多次按下按钮时动作幅度很小），这些方法存在根本性局限。我们提出了FM-VLA，一种具有基于力觉记忆的VLA模型，能够对非马尔可夫、接触丰富的操作进行时间上下文推理。我们使用通过力时间序列重建预训练的变分自编码器（VAE）将力历史编码为紧凑的力记忆令牌。通过将力潜在表示和短期状态历史作为额外的条件令牌投射到动作专家模块，我们使VLA能够利用积累的接触事件历史来指导操作。我们在三个依赖记忆的任务上评估了FM-VLA，包括寻找隐藏块、按下按钮和擦盘子指定次数。我们的轻量级力记忆在最小推理开销下实现了超过80%的成功率，显著优于基线方法。项目页面：https://qft-333.github.io/FM-VLA-Page/

## Abstract
Vision-language-action (VLA) models have achieved impressive generalization in robotic manipulation, and recent memory-augmented VLAs have relaxed the Markovian assumption by conditioning on past images or language summaries. Vision-based memory approaches address this by conditioning on sampled past image frames, but they are computationally expensive and fundamentally limited when temporal events are visually ambiguous, e.g., pushing a button multiple times with small movements. We propose FM-VLA, a VLA model with force-based memory, enabling temporal context reasoning for non-Markovian, contact-rich manipulation. We encode force histories into compact force memory tokens with a variational autoencoder (VAE) pretrained with force time series reconstruction. By projecting force latent representations and short state history as additional conditioning tokens to the action expert module, we enable VLAs to leverage accumulated contact event history to guide manipulation. We evaluate FM-VLA on three memory-dependent tasks, including finding a hidden block, pressing a button, and wiping a dish for a specific number of times. Our lightweight force memory achieves over 80% success rate with minimal inference overhead, significantly outperforming baseline approaches. Project page: https://qft-333.github.io/FM-VLA-Page/

# FM-VLA 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有视觉-语言-动作（VLA）模型大多基于马尔可夫假设（仅依赖当前观察），在处理需要长程时序上下文的任务（如计数、追踪交互进度、部分可观察状态推理）时表现不佳。
- **背景**：虽然已有工作引入视觉记忆（如MemoryVLA、MEM），但视觉记忆在视觉变化微小或存在严重遮挡的情况下（例如多次按压行程极小的按钮）计算开销大且信息模糊。相比之下，力/力矩信号能直接、明确地反映接触事件，但此前的工作（如TA-VLA、ForceVLA）只将力用于短时条件，未作为长期记忆。
- **整体含义**：本文首次提出将力信号作为长期记忆源，构建力记忆增强的VLA模型（FM-VLA），使非马尔可夫、接触丰富操作任务中的时序推理成为可能。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将机器人在整个episode中积累的力/力矩历史（来自腕部六维力传感器）通过变分自编码器（VAE）压缩为少量紧凑的力记忆令牌（force memory tokens），再结合短窗关节状态历史令牌，共同作为动作专家模块的额外条件输入，使策略能够感知累积的接触事件。

### 关键技术细节
1. **数据预处理**：
   - 力信号：一阶指数移动平均（EMA，α=0.3）降噪；训练时在力历史前随机填充高斯噪声前缀（最多10秒），防止模型利用时间长度作弊；推理时禁用填充。
   - 关节状态：取最近0.9秒（10帧，步长3）的关节位置+夹爪状态（维度ds=16），展平后用零初始化的线性层映射为单个状态令牌。

2. **力记忆编码器（Force-VAE）**：
   - 采用Perceiver-IO架构：输入MLP + 傅里叶位置编码（32波段）→ 2层交叉注意力（8个可学习潜在查询令牌，维度96）→ 10层潜在自注意力 → 输出后验参数 (μ, log σ²)。
   - 解码器类似，重建力序列。
   - 损失函数：掩蔽重建误差 + 带自由位（free-bits）的KL正则化（β=1e-3，λ=0.5 nats）。
   - 预训练阶段：联合所有任务数据，采用反向频率采样，训练100k步，批次大小512（8×GPU）。

3. **记忆令牌注入**：
   - 推理时仅使用VAE编码器输出的后验均值μ（8个令牌），通过零初始化的线性层投影到动作专家隐藏维度dh，与短状态令牌一起追加到动作专家序列末尾（保持噪声动作令牌的RoPE位置不变）。

4. **VLA微调（Stage 2）**：
   - 冻结力编码器，启用评估模式（不加重参数化噪声）。
   - 采用整流流（Rectified Flow）损失：预测噪声-干净动作的差值。
   - 联合微调VLM、动作专家、短状态投影器、力潜在投影器。
   - 超参数：峰值学习率5e-5，50k步，全局批次32，图像dropout p=0.4。

## 3. 实验设计

- **机器人平台**：AgiBot G1双臂人形机器人，每个腕部配备6轴力/力矩传感器（100Hz），三个RGB摄像头（头部、左右腕）。
- **任务套件**：

  3. **擦碗（Wipe）**：用海绵擦碗内部N次（N∈{1,2,3}），视觉变化小。

- FM-VLA在三个任务上平均成功率83.3%，显著优于无记忆π0.5（27.8%）、TA-VLA（22.2%）和视觉记忆π-MEM（53.7%）。
