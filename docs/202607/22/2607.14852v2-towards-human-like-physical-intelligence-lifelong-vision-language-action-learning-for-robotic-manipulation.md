## 摘要
类似于人类顺序学习新任务的自然能力，配备视觉-语言-动作（VLA）模型的机器人在开放世界环境中部署时应具备终身学习能力以学习新任务。然而，最近提出的大多数终身学习模型旨在有效学习当前任务（可塑性）或保持对先前任务的高精度（稳定性），而在机器人操作模型中，可塑性-稳定性权衡仍未得到充分解决。为了应对这一基本挑战，我们提出了一种面向机器人操作的缓存高效终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度适应机制缓解了可塑性-稳定性权衡，同时通过缓存高效的重放策略实现了低成本的机器人部署。更具体地说，我们提出了一种双时间尺度LoRA门控模块，将VLA适应分解为两条轻量级路径：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些路径通过任务感知门进行集成，从而能够显式控制可塑性-稳定性权衡。在技能重放阶段，提出了一种缓存高效的随机重放策略，以在不存储完整轨迹的情况下保留更平衡的保留信号。最后，实验表明，LifelongVLA优于现有基线，展示了高效的技能扩展、对所学操作行为的稳健保留，以及在xArm机器人上实际部署时减少对重新训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

- **整体背景**：VLA模型（如RT-2、π0等）在语言条件机器人操作中取得了显著进展，但它们的持续学习能力不足。现有的持续学习方法（如经验回放、参数隔离）在VLA大模型中效果有限，且存在计算开销大、存储成本高的问题。

## 2. 论文提出的方法论

### 核心思想
提出 **LifelongVLA** 框架，通过两种机制解决塑性-稳定性权衡：
- **双时间尺度LoRA门控**：将VLA适配分解为短期（塑性）和长期（稳定）两条LoRA路径，由任务感知门控动态组合。
- **缓存高效随机重放**：仅存储少量紧凑的冻结前缀令牌和状态-动作监督，在重放时重新采样扩散变量并重新计算后缀，减少存储和计算开销。

### 关键技术细节
1. **双时间尺度LoRA门控（Dual-Timescale LoRA Gating）**：
   - 对每个适配层，定义短期更新 \(\Delta W_{sh,t}\) 和长期更新 \(\Delta W_{lg,t}\)，均为低秩LoRA矩阵。
   - 短期路径仅由当前任务损失 \(L_{new}\) 更新，实现快速学习；长期路径由重放损失 \(L_{rep}\) 和蒸馏损失 \(L_{dist}\) 更新，且学习率更小，实现稳定巩固。
   - 任务感知门控 \(\alpha_t^\ell(c)\) 基于冻结前缀特征计算，输出范围[0,1]，控制两条路径的权重组合：\(\Delta \tilde{W}_t^\ell(c) = (1-\alpha_t^\ell)\Delta W_{sh,t} + \alpha_t^\ell \Delta W_{lg,t}\)。
   - 门控避免循环依赖（门控上下文来自冻结特征），只需单次前向推理。

2. **缓存高效随机重放（Cache-Efficient Stochastic Replay）**：
   - 对每个新任务，随机选择少量样本（缓存配额 \(c_t=50\)），仅存储**停止梯度前缀令牌**和紧凑的**状态-动作对**，不存储原始图像、语言令牌或完整轨迹。
   - 重放时，为每个缓存样本重新采样扩散变量（时间步 \(\tau'\) 和噪声 \(\epsilon'\)），用当前模型重新计算后缀令牌，产生多个随机重放实例。
   - 使用掩码分离当前样本和重放样本的损失，并加入蒸馏损失（教师为上一任务快照），确保平衡的保留信号。

### 公式/算法流程（文字说明）
- 输入：当前任务数据集 \(\mathcal{S}_t\)，缓存缓冲区 \(\mathcal{B}_{t-1}\)。
- 训练步骤：
  1. 当前样本：正常前向传播，计算 \(L_{new}\)（去噪损失）。
  2. 重放样本：从缓存中采样，重新采样扩散变量，计算 \(L_{rep}\) 和 \(L_{dist}\)（教师输出与当前输出之间的L2距离）。
  3. 总损失：\(L_t = L_{new} + \lambda L_{rep} + \beta L_{dist}\)。
  4. 更新：短期路径用\(L_{new}\)梯度更新，长期路径用\(L_{rep}+L_{dist}\)梯度更新（学习率\(\eta_{lg} < \eta_{sh}\)）。
