## 摘要
动作令牌化将连续的机器人动作块映射为离散令牌，并已成为现代视觉运动策略的重要接口。现有方法要么依赖产生过长令牌序列的分析离散化方法，要么缺乏结构的学习型潜在令牌化器，限制了它们与下游策略的兼容性。在这项工作中，我们确定了动作令牌化的三个期望——高压缩、完全可解码和有序令牌空间——并引入有序动作令牌化（OAT），这是一种满足所有三个条件的学习型动作令牌化器。OAT使用带寄存器、有限标量量化和顺序诱导训练机制的Transformer将动作块离散化为有序令牌序列。通过训练每个令牌前缀解码为有效的动作块，OAT将粗略控制信息放在早期令牌中，并使用后续令牌细化残差细节，从而在推理成本与动作保真度之间实现任意时刻的权衡。我们在两种主要的动作令牌使用场景中验证了OAT：用于控制的自回归策略生成令牌，以及使用令牌损失来塑造流动动作专家所消耗的视觉-语言模型上下文的令牌协同训练策略。在三种策略骨干和跨越五个模拟基准及真实世界设置的超过60个任务中，OAT始终提供强大的策略性能，同时在推理时提供显著更大的灵活性。

## Abstract
Action tokenization maps continuous robot action chunks to discrete tokens and has become an important interface for modern visuomotor policies. Existing approaches either rely on analytical discretization methods that produce prohibitively long token sequences or learned latent tokenizers that lack structure, limiting their compatibility with downstream policies. In this work, we identify three desiderata for action tokenization - high compression, total decodability, and an ordered token space - and introduce Ordered Action Tokenization (OAT), a learned action tokenizer that satisfies all three. OAT discretizes action chunks into an ordered sequence of tokens using a transformer with registers, finite scalar quantization, and ordering-inducing training mechanisms. By training each token prefix to decode into a valid action chunk, OAT places coarse control information in early tokens and uses later tokens to refine residual detail, yielding an anytime tradeoff between inference cost and action fidelity. We validate OAT in two prevailing uses of action tokens: autoregressive policies that generate tokens for control, and token co-training policies that use token losses to shape the vision-language model context consumed by a flow-based action expert. Across three policy backbones and more than 60 tasks spanning five simulation benchmarks and real-world settings, OAT consistently delivers strong policy performance while offering significantly greater flexibility at inference time.

### 1. 核心问题与整体含义（研究动机和背景）
- **研究动机**：在视觉运动策略（visuomotor policy）中，动作令牌化（action tokenization）是将连续机器人动作块映射为离散令牌的关键接口。现有方法要么产生过长的令牌序列（如逐维分箱Bin），要么缺乏可预测的有序结构（如学习型潜在令牌化器QueST、ACodec），难以同时满足策略学习对**高压缩**、**完全可解码**和**有序令牌空间**的需求。作者认为，好的动作令牌应当紧凑、任意采样均可解码为有效动作，且包含由粗到精的层级信息。
- **整体含义**：提出有序动作令牌化（Ordered Action Tokenization, OAT），同时满足上述三个需求，并验证其在两种主流策略范式（自回归策略、令牌协同训练策略）中的有效性，从而为视觉运动策略提供更灵活、高效的令牌化接口。

### 2. 方法论：核心思想、关键技术细节与算法流程
- **核心思想**：OAT将连续动作块编码为有序的离散令牌序列。通过**嵌套前缀训练**（nested dropout）和**寄存器自注意力掩码**设计，强制早期令牌携带粗粒度控制信息，后续令牌逐步细化残差细节，从而实现任意前缀均可解码为有效动作块。
- **关键技术细节**：
  - **编码器-量化器-解码器结构**：编码器使用带可学习寄存器（registers）的Transformer，将动作块压缩为寄存器状态；采用**有限标量量化（FSQ）** 将每个寄存器状态离散化为令牌；解码器是交叉注意力Transformer，从令牌序列重建动作块。
  - **有序前缀训练**：训练时随机采样预算集合K（如{1,2,4,8,16}），仅保留前K个令牌，后缀替换为可学习的掩码标记（MASK），强制解码器从不同前缀重建完整动作块。该机制使早期令牌承受更大生存权重，自然形成粗到精的信息分配。
  - **寄存器自注意力掩码**：提供两种变体 —— **令牌级有序（OAT_sing）**采用因果掩码，支持逐令牌自回归生成；**幂次分组有序（OAT_pow2）**采用块因果掩码，同一预算组内寄存器无相互依赖，支持块级并行生成。
- **与策略的接口**：
  - **自回归策略**：通过**块级自回归（BAR）** 框架统一逐令牌、固定块、一次性并行等生成模式。训练时，每个生成阶段仅依赖已生成前缀和掩码，不访问当前块的真实令牌。推理时，根据负载和延迟需求灵活选择生成策略。
  - **令牌协同训练策略**：视觉-语言模型（VLM）在教师强制下预测令牌序列（由冻结的OAT生成），令牌交叉熵损失监督VLM；同时，流匹配专家（flow-matching expert）从VLM的图像、语言、状态前缀的分离键/值缓存中生成连续动作，不更新VLM。OAT的第一个令牌直接对应完整动作块的摘要，为VLM提供类似计划的监督目标。
