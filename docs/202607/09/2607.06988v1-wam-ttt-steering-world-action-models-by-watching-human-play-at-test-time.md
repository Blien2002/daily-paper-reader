## 摘要
引导机器人基础模型（RFM）适应新的任务变体或用户偏好行为仍然具有挑战性，通常需要额外的机器人演示、特定任务的微调或长上下文条件。我们提出WAM-TTT，一种从原始人类视频中引导世界动作模型的测试时训练框架。WAM-TTT不将人类视频视为要模仿的轨迹，而是通过自监督视频预测将其吸收到冻结的WAM内部的轻量级自适应记忆中。为使这种记忆对控制有用，我们引入了一个元训练阶段，该阶段使用配对的人机数据和键值记忆重建目标来将人类演示与机器人行为对齐。在测试时，仅需未标记的人类视频即可适应记忆，而预训练的WAM保持冻结。这实现了无需机器人动作、人类侧标注或特定任务微调的高效且可重用的引导，同时保留了基础模型的泛化能力。大量实验表明，WAM-TTT在各种操作任务和泛化设置中始终优于基于上下文人类视频条件的基线。

## Abstract
Steering robot foundation models (RFMs) toward new task variants or user-preferred behaviors remains challenging, often requiring additional robot demonstrations, task-specific fine-tuning, or long-context conditioning. We present WAM-TTT, a test-time training framework for steering world action models from raw human videos. Rather than treating human videos as trajectories to imitate, WAM-TTT absorbs them into a lightweight adaptive memory inside a frozen WAM through self-supervised video prediction. To make this memory useful for control, we introduce a meta-training stage that aligns human demonstrations with robot behaviors using paired human-robot data and a key--value memory reconstruction objective. At test time, only unlabeled human videos are required to adapt the memory, while the pretrained WAM remains frozen. This enables efficient and reusable steering without robot actions, human-side annotations, or task-specific fine-tuning, while preserving the generalization ability of the foundation model. Extensive experiments show that WAM-TTT consistently outperforms in-context human-video conditioning baselines across diverse manipulation tasks and generalization settings.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将人类视频视为一种隐式的行为信号，而不是需要直接模仿的轨迹。通过自监督视频预测将人类视频中的时序模式吸收到一个轻量级的自适应记忆（adaptive memory）中，该记忆模块嵌入在冻结的世界-动作模型（World-Action Model, WAM）内部。然后利用元训练阶段对齐人类和机器人的行为空间，使得测试时仅需输入未标注的人类视频即可快速调整记忆，从而引导WAM产生符合人类偏好的动作。

- **关键技术细节**：
  1. **基础模型**：采用预训练的**世界动作模型（WAM）**，该模型能够同时预测未来世界状态和动作。在WAM-TTT中，WAM的权重在整个过程中保持冻结。
  2. **轻量级自适应记忆**：设计为一种键值（Key-Value）记忆结构，嵌入在WAM内部的特定层级。记忆的更新通过自监督视频预测损失（预测下一帧图像）进行，输入仅为人类视频帧序列。
  3. **元训练阶段（Meta-Training）**：使用**配对的人机数据**（同一任务下人类演示和机器人执行的数据对）进行训练。目标是优化记忆的读取机制，使得从人类视频编码的键（key）能够检索出对机器人控制有用的值（value）。采用**键值记忆重建损失（key-value memory reconstruction objective）**：给定人类视频，更新记忆；然后让WAM基于该记忆进行动作预测，通过对比机器人真实动作和预测动作的差异来反向传播，仅更新记忆模块的参数（WAM冻结）。
  4. **测试时适应（Test-Time Training, TTT）**：当面对新的任务变体或用户偏好时，仅提供一小段（例如几秒）未标记的人类玩耍视频。模型使用这些视频的自监督预测损失快速更新记忆（约几十步梯度下降），然后冻结记忆，即可用于后续机器人的动作生成。整个过程无需机器人动作标签，无需人类标注（如动作标签、属性标注），也无需重新微调WAM。
  5. **可重用性**：由于记忆是轻量且与WAM松耦合，不同的偏好可以独立存储在多个记忆模块中，在部署时根据需要切换，实现可重用的引导。
