## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大潜力，但现有大多数模型依赖于2D视觉-语言主干，缺乏对目标对象的细粒度3D理解，尤其是在遮挡、姿态变化、尺度变化和精确空间交互的情况下。我们提出了一种基于π₀的面向对象的3D表示对齐框架，使用冻结的SAM3D作为3D教师，在训练期间提供目标对象的3D先验。具体来说，我们使用目标识别模型定位任务相关对象，生成对应的对象掩码，并利用SAM3D提取密集的对象级3D表示，这些表示与π₀的中间视觉特征进行对齐。这使得策略能够内化目标对象的3D信息，同时保留原始的RGB-语言到动作推理流程，在测试时无需深度图、点云、掩码、SAM3D或额外的3D模块。仿真实验显示了一致的改进，在LIBERO上达到99.1%，在CALVIN上平均长度为4.11。真实世界实验进一步表明，我们的方法在需要机器人跨多个子任务关注不同目标对象的长视野操作场景中特别有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：现有的视觉-语言-动作（VLA）模型大多基于2D RGB图像和语言骨干，缺乏对目标物体的细粒度3D理解。在面临遮挡、姿态变化、尺度变化、物体杂乱和精确空间交互（如放置、插入）时，2D表示难以捕获物体的形状、位姿和空间布局，导致操作性能受限。
- **背景**：尽管已有研究尝试通过显式3D输入（深度图、点云）或隐式空间监督来增强VLA模型，但这些方法往往需要修改输入输出接口，或仅关注全局场景级空间表示，并未聚焦于**目标物体级别的3D先验**。同时，2D视觉接地方法（如裁剪区域、边界框）仍限于2D空间，无法提供物体3D形状或布局先验。
- **核心目标**：在不改变原始RGB-语言到动作推理流程（即推理时不需深度、点云、掩码或额外3D模块）的前提下，将面向物体的3D知识注入VLA模型。

## 2. 方法论

### 核心思想
- 构建**SAM3D-VLA**框架，基于π₀架构。使用**冻结的SAM3D作为3D教师**，在训练时将目标物体的3D特征（形状、表面结构、空间布局）对齐到π₀中间视觉特征，使得模型内化3D先验。
- 推理阶段完全保持原始π₀流程：仅需RGB图像和语言指令，无需任何3D模块或掩码。

### 关键技术细节
1. **子任务分解与物体定位**：对于长视野任务，利用LLM（如GPT-4o）将高级指令分解为子任务，每个子任务关联一个目标物体。使用**Grounding DINO**或**YOLO**进行开放词汇目标检测，再用**SAM2**生成物体掩码。
2. **SAM3D特征提取**：将多视角图像和对应物体掩码输入冻结的SAM3D，提取密集物体级3D特征（每个token维度为DT）。对多视角批次进行展平处理。
3. **空间重采样**：将SAM3D token序列reshape为2D特征网格，通过双线性插值调整到π₀视觉token的分辨率（HS×WS），使得教师特征与学生视觉token在空间上对齐。
4. **特征对齐损失**：
   - 学生侧：从π₀的Gemma中间层提取视觉特征St，通过线性投影层Pϕ映射到SAM3D特征空间得到\hat{T}_t。
   - 教师侧：获得对齐后的教师特征\bar{T}_t。
   - 利用物体掩码构建token级掩码mt，只对目标物体区域的token计算对齐损失。
   - 损失函数：**掩码归一化MSE**（对特征进行ℓ2归一化后计算MSE），鼓励方向对齐。
5. **总损失**：L = L_action（π₀标准流匹配动作损失） + α L_align，α控制3D监督强度。
6. **冻结表示探测实验**：训练后冻结VLA骨干，仅训练一个轻量MLP探针，从中间特征预测SAM3D目标，用于验证对齐效果。
