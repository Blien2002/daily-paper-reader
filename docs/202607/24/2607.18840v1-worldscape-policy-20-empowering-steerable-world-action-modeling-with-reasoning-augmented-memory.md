## 摘要
世界动作模型（WAMs）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了一种有前景的范式。然而，现有的WAMs受限于有限的时间上下文、粗略的回合级语言监督以及主要基于文本的条件设定，这阻碍了任务进度跟踪和细粒度语言-视频-动作对齐，同时限制了视觉上下文推理和跨实体迁移。在本文中，我们引入了WorldScape Policy 2.0，一种具有推理增强型长短期记忆的可控WAM。其因果短期视觉记忆提供最近的观测作为DiT预填充，以保留局部交互动态；而其长短期事件记忆将历史VLM输出组织成全局历史、局部活跃和事件边界表示，用于进度感知的检索。检索到的历史信息增强了感知和自回归生成的规划令牌，为自主规划提供隐式的子目标条件；语义强制进一步将事件级指令语义转移到这个潜在规划路径中。为了建立细粒度的多模态可控性，我们构建了ManipEvent-5M，这是一个基于事件的具身预训练数据集，包含近500万个事件段，并配有对齐的动作轨迹、回合级任务指令、段级子任务描述、目标图像和视频演示。这些设计为从高层指令进行自主规划和从细粒度文本、目标图像或视频上下文提示进行可控执行提供了统一接口。在仿真和真实世界平台上的实验表明，该方法在长程自主规划、细粒度指令跟随和上下文自适应方面具有优越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

## 1. 核心问题与研究背景（动机）

- **现有世界动作模型（WAMs）的三大局限**：
  - **时间上下文不足**：多数模型仅依赖当前观测或短历史窗口，无法感知任务进度，导致在不同阶段视觉相似的场景下难以确定正确下一步动作。
  - **粗粒度语言-视频-动作对齐**：同一回合的不同片段共享相同的任务级指令，缺乏细粒度子任务监督，模型易依赖视觉捷径而非真正理解事件级意图。
  - **单一交互接口**：通常仅支持文本控制，无法利用目标图像、演示视频等更自然的多模态提示，限制了视觉推理和跨本体迁移能力。

- **本文目标**：构建一个可控的WAM，同时具备：
  - 进度感知的长程记忆（事件级语义记忆 + 帧级视觉记忆）
  - 细粒度多模态可控性（文本、目标图像、视频演示）
  - 统一的自主规划与显式指令遵循接口

## 2. 方法论：核心思想与关键技术

### 2.1 总体框架
- **WorldScape Policy 2.0**：结合**推理增强的长短期记忆**，将长期事件记忆与短期视觉记忆耦合，通过**隐式潜在子目标推理**实现自主规划。
- **统一动作表示**：每个动作表示为相对于动作块第一帧的增量位置、6D连续旋转表示和绝对夹爪指令。
- **三阶段训练**：事件级多模态预训练 → 记忆增强中间训练（引入语义强制）→ 下游任务微调。

### 2.2 推理增强的长短期记忆
- **短期视觉记忆（Short-Term Visual Memory）**：
  - 维护最近观测的VAE潜在作为DiT的因果预填充，保留局部交互动态。
- **长短期事件记忆（Long Short-Term Event Memory）**：
  - VLM分支处理历史块，构建三种视图：
    - **全局历史（Global-History）**：完整轨迹摘要。
    - **局部活跃（Local-Active）**：最近完成的若干块。
    - **事件边界（Event-Boundary）**：通过语义变化检测选出的关键过渡块。
  - 通过交叉注意力和门控机制将检索到的记忆增强当前推理潜在。
- **语义强制（Semantic Forcing）**：
  - 将细粒度子任务描述的T5嵌入作为训练目标，对齐自主规划潜在，使得模型在推理时能够隐式推断子目标。

### 2.3 多模态条件控制
- 不同模态输入按模式选择：
  - **细粒度文本**：T5嵌入直接注入DiT交叉注意力。
  - **高层指令**：VLM联合观测和事件记忆生成推理潜在作为条件。
  - **目标图像/视频演示**：持久VAE潜在作为因果预填充。
- 实现从高层指令自主规划、子任务文本直接控制、目标图像/视频上下文适应等**统一接口**。

### 2.4 ManipEvent-5M 数据集
- 聚合人类中心视频、机器人演示、模拟数据等来源，构建约**500万个事件段**。
- 每段包含：对齐的动作轨迹、回合级任务指令、段级细粒度描述、目标图像、视频演示。
- 采用四阶段层次化标注：两阶段语义分割 + 层次帧采样 + 具身提示约束 + 多视图冲突解决。

## 5. 优点

- **创新性**：明确区分事件级语义记忆与帧级视觉记忆，通过语义强制首次将显式子目标监督进入WAM潜在规划空间。
- **高质量数据集**：ManipEvent-5M提供大规模、细粒度、多模态对齐的具身数据，支持多种交互模式。
- **统一接口**：单一模型同时支持自主规划、显式指令控制、目标图像/演示视频适应，拓展了WAM的实用性。
- **实验覆盖全面**：既覆盖标准仿真benchmark（50任务），又包括真实的长时间+复杂推理+跨本体迁移任务，且进行了详细的消融。

## 6. 不足与局限

- **计算资源不透明**：未披露GPU型号/数量/总训练时间，难以评估方法部署成本。
- **真实实验规模有限**：每任务仅20 trials，部分任务（如Block Stacking）成功率波动可能较大；仅一个真实平台，泛化性待验证。

- **语义强制简化为余弦对齐**：仅用池化后的向量进行对齐，可能丢失细粒度语义信息。
- **事件边界检测依赖VLM输出变化**：可能受VLM自身噪声影响，缺乏人工验证。
- **应对长尾或未见任务的能力**：实验仅覆盖50个仿真任务和5个真实任务，更复杂、开放场景效果未知。
- **缺少跨本体适应性定量指标**：虽然展示了跨本体转移成功，但仅一项积木任务，缺乏多本体、多视角系统对比。

## 7. 总结

WorldScape Policy 2.0通过推理增强的长短期记忆和事件级多模态数据，将WAM从短程预测推进到可控长程规划。在仿真和真实实验中均取得领先性能，验证了事件级记忆与语义强制在提升操控鲁棒性和可控性方面的有效性。然而，算力需求高、真实评估规模有限等局限仍需后续工作进一步解决。
