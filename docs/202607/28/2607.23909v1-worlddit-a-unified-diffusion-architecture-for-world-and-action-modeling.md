## 摘要
许多最新的机器人策略通过使用大型预训练视觉语言模型（VLM）作为动作骨干来追求更强的控制能力。我们提出了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，无需大型预训练VLM动作骨干即可实现强劲性能。在训练过程中，单个扩散Transformer生成连续动作块，并预测未来相机帧中的归一化RGB图像块目标。在四个LIBERO模拟套件中，WorldDiT位于所报告的针对总模型参数和平均成功率（在报告所有四个套件的方法中）的帕累托前沿上。这些结果为未来的扩展研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 使用**单个共享的扩散Transformer（DiT）骨干**，同时完成两个任务：
  - 生成**连续动作块**（7步）。
  - 预测**来自未来相机帧的归一化RGB图像块**（作为辅助训练目标）。
- 推理时仅使用动作路径，视觉预测头被移除，保持纯粹的策略部署。

### 关键技术细节
1. **输入编码**：
   - 使用冻结的MAE图像编码器（通过共享Perceiver Resampler）、冻结的CLIP文本编码器、可训练的机器人状态编码器。
   - 多模态token构造：包括语言指令、过去三个时间步的视觉观测（主相机+腕部相机）、机器人状态。
2. **训练过程**：
   - 窗口大小 \(N=10\)：前3步为观测上下文（\(C=3\)），后7步为动作目标（\(H=7\)）。
   - 额外预测第 \(i+H\) 帧（即第10帧）的归一化RGB图像块：每帧分为16×16 patch，保留64个均匀间隔的patch（来自主相机和腕部相机各64个，共128个768维向量）。
   - 使用**流匹配（flow matching）** 目标：对动作和RGB patch分别加噪，预测从噪声到干净数据的直线速度场。
   - 总损失：\(L_{\text{total}} = w_{\text{action}} L_{\text{action}}^{\text{flow}} + w_{\text{rgb}} L_{\text{rgb}}^{\text{flow}}\)，权重分别为0.1和0.001。
3. **推理过程**：
   - 仅基于观测上下文，从高斯噪声初始化动作，通过20步欧拉积分得到7步动作块。
   - 执行前3个动作，滑动窗口并重新规划（receding-horizon control），并应用动作时序集成（temporal ensembling）。

  - **不使用大型预训练VLM动作骨干的**（如DreamVLA, FlowVLA, Diffusion Policy等），参数量较小。

## 6. 论文的主要结论与发现

- WorldDiT以**399M总参数**在四个LIBERO套件上取得**平均成功率94.9%**（Spatial 98.0%, Object 97.0%, Goal 92.8%, Long 91.8%）。
- 在报告的24种方法中，WorldDiT位于**参数量-平均成功率帕累托前沿**上：所有成功率高于它的方法都使用更多参数，所有参数量相近或更少的方法成功率更低。
- 结论：**统一的世界-动作建模（联合动作生成与未来视觉预测）可以在不使用大VLM骨干的情况下达到竞争性能**，为后续扩展提供了紧凑的基线。
