## 摘要
视觉-语言-动作策略是通用机器人控制的有前景的基础，但长时程的类人移动操作要求机器人将任务对象视为跨移动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态与用于判断动作是否实现预期物理关系的状态可能不同。我们提出了可持久对象令牌化（POT），该方法从RGB-D观测中维护带角色索引的3D对象记录，并将其转换为用于全身动作专家的对象令牌。实例化为POT-VLA，相同的对象记录既用于条件动作生成，又支持几何谓词检查，从而形成一个闭环执行系统，其中对象状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功提升至71/80。在一个外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上取得了44/50成功，而Being-0论文报告的成功为37/50。最大的提升出现在需要维持3D关系的任务上，这表明以对象为中心的持久状态是可验证类人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 2. 论文提出的方法论

### 核心思想
- 提出**持久对象令牌化**，从RGB-D观测中维护**角色索引的3D对象记录**，将记录序列化为**持久3D对象令牌**，供全身动作专家使用。
- 同一对象记录同时用于**条件动作生成**和**几何谓词检查**，形成“保持–执行–观测–验证–恢复”的闭环。

### 关键技术细节
1. **角色索引对象记忆**：
   - 给定语言指令和当前观测，通过VLM规划器或任务文件获得带类型的子任务计划，每个子任务定义角色、查询、成功谓词、恢复处理等。
   - 利用SAM3（或在线/缓存得到的掩码）结合深度图像和相机位姿，在机器人基座坐标系中构建角色索引的对象记录，包含类别、3D质心、尺寸、可见性、置信度、关系特征（如物体-容器距离、支持高度、末端-物体偏移、目标-目的地位移、对齐、包含等）。

2. **持久3D对象令牌**：
   - 将对象记录转换为固定大小的特征张量，默认8个槽位，每个槽位33维特征。槽位角色包括TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER等，未使用的槽位标记为PADDING并掩码。
   - 特征包括可见性、置信度、2D框、3D质心、3D范围、可选朝向、关系特征。所有度量在机器人基座坐标系中归一化。
   - 持久性体现在：任务实体绑定到角色槽位，每次执行块后刷新度量证据；若物体被遮挡或低置信度，槽位仍保留但标记为不确定。

3. **对象令牌条件化VLA执行**：
   - 动作专家采用GR00T-N1.7，保持相同骨干网络、本体和运行时，但在动作头前插入持久3D对象令牌。
   - 对象令牌投影器将令牌嵌入到DiT隐藏维度，与状态令牌、动作令牌组成序列，视觉-语言编码器特征通过交叉注意力引入。
   - 支持协调导航、到达、抓取、搬运、放置、交接等全身动作。
   - 训练时使用带对象令牌边车数据的演示，动作损失更新对象令牌分支；推理时每个短视界块后刷新感知。

4. **谓词级验证与恢复**：
   - 几何谓词监督器读取与动作策略相同的角色索引对象记忆，检查子任务准备条件（前置谓词）和完成条件（目标谓词）。涵盖包含、支持、末端-目标接近、目标-目的地位移、双手机器人分配、交接距离等。
   - 每个谓词包含类型、对象记录参数、比较操作符、阈值和稳定窗口。根据计算的标量证据，返回状态：in_progress、done、blocked、failed、uncertain。低置信度或稳定性不足触发重新观测或重新接地。
   - 根据状态和诊断（如缺少可见性、抓取失败、放置错误等），选择继续、重试、重新观测、重新接地或重新规划。局部恢复刷新或重新接地对象记录，任务级重新规划接收紧凑反馈。

## 3. 实验设计

### 数据集 / 场景
- 真实世界任务，在**Unitree G1**人形机器人上执行，配备Dex3-1灵巧手和头戴RGB-D相机，在杂乱的办公室环境中进行。
- 8个任务族：手推车运输与放置、薯片盒放入灰色篮子、两个球放入篮子、叠三个杯子、衣物放入洗衣篮、抽屉/托盘放置并关闭、桌面分拣、短程饮料交接。每个任务族10次试验。

### Benchmark
- **主要对比**：直接基线（相同GR00T-N1.7动作专家、相同本体和运行时，但禁用持久对象记录、对象令牌和几何谓词监督）。
- **外部参考**：与Being-0论文对齐的服务任务套件（5个任务：取瓶子、送篮子、抓瓶子、放篮子、放咖啡），使用Being-0论文报告的37/50成功率，POT-VLA自行运行得到44/50。
- **消融实验**：选择4个稳态发散较大的任务（两球放置、叠杯、抽屉/托盘、桌面分拣），对比：
  - 直接基线（无令牌无验证器）：15/40
  - 仅验证器（直接动作+谓词检查+局部恢复）：22/40
  - 仅POT令牌（条件化令牌但无谓词验证）：31/40
  - 完整POT-VLA：34/40
- **泛化测试**：在4种对象状态偏移下各10次试验（新物体实例、布局偏移、干扰物、执行中途扰动），对比直接基线与POT-VLA。

### 评价标准
- 只有在最终几何谓词在预定超时和重试预算内、在所需稳定窗口内保持满足，且无人干预才视为成功。

## 6. 主要结论与发现

- POT-VLA在8个真实世界任务族上取得了**71/80成功**，直接基线仅39/80，提升显著。
- 在外部Being-0对齐任务上，POT-VLA获得44/50，高于Being-0报告的37/50。
- **最大的提升出现在需要维持3D关系的任务上**（如叠杯子、两球放置、衣物运输、抽屉/托盘交互），这些任务中对象状态发散最严重。

- 消融显示：**对象令牌条件化提供了最大增益**（从15/40提升至31/40），谓词验证提供了额外增益（从31/40提升至34/40），两者协作效果最佳。

- **结论：持久对象中心状态（持久3D对象令牌）是一种对可验证人形VLA执行有用的抽象，能够有效减少状态发散，提升长期任务成功率。**

## 7. 优点

- **创新性**：首次在类人VLA中引入**共享对象记忆**作为动作条件和验证的共同基础，解决了状态发散这一关键问题。
- **实用性**：方法不依赖仿真器、物理引擎或学习动力学模型，完全基于测量（RGB-D接地），可直接部署至真实机器人。
- **设计完整**：包含对象记忆构建、令牌化、动作头插入、几何谓词验证、恢复机制，形成完整闭环。
- **实验严谨**：通过消融和泛化实验分离各组件贡献，对比了外部已发表系统，验证了方法的有效性。
- **可解释性**：对象令牌提供显式角色和3D几何信息，谓词验证输出具体诊断（如“抓取失败”、“放置位置超出目标区域”），便于理解和调试。

## 8. 不足与局限

- **依赖感知质量**：POT受限于SAM3掩码质量、RGB-D深度可靠性、相机标定误差。低质量感知会导致对象记录不准确，进而影响动作和验证。
- **动作专家覆盖有限**：当前基于GR00T-N1.7的全身动作头可能无法处理所有灵巧操作场景（如复杂手指姿态、柔软变形物体），且演示数据可能偏少。
- **视野受限**：当前仅使用头戴单视图RGB-D，受遮挡和视野限制。未来需扩展至主动多视角记忆。
- **未考虑社会交互**：未处理人类交接中的意图识别、手部姿态自适应等，仅依赖简单距离谓词。
- **实验规模有限**：每任务10次试验，未进行大规模跨场景随机化测试；统计显著性未报告。Being-0对比非本地复现，可能存在环境/任务差异。
- **未给出算力信息**：缺乏训练时间和资源消耗的细节，不利于复现评估。
- **泛化至新任务**：方法依赖于预定义的子任务角色和谓词，若遇到完全新颖的任务结构可能需要额外手动定义。
