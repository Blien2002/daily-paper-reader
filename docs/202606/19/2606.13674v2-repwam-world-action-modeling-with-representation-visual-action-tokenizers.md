## 摘要
本文提出了RepWAM，一种基于表征视觉-动作分词器的以表征为中心的世界动作模型。现有世界动作模型通常继承自预训练视频生成模型中面向重建的视频分词器。尽管这些分词器保留了视觉保真度，但仅靠像素重建对于学习连接未来预测与机器人控制的指令遵循动态提供有限指导。为解决这一问题，我们探索了一种语义视觉-动作潜空间，用于以表征为中心的世界动作建模。具体而言，我们训练了一个表征视觉-动作分词器，将视觉输入映射为对齐的视觉和潜动作标记。然后，我们预训练世界动作模型以联合建模未来视觉状态以及连接它们的潜动作（在语言指令下），随后适应真实机器人轨迹以实现闭环操控。在真实世界操控任务和仿真基准上的实验表明，RepWAM在多种操控场景中展现出强劲性能，而消融实验凸显了语义视觉-动作分词相对于面向重建替代方案的价值。这些结果确立了表征视觉-动作分词作为世界动作模型的一个有前景的基础，并向通用型机器人策略迈出了一步。代码和权重将在https://github.com/wdrink/RepWAM上提供。

## Abstract
This work presents RepWAM, a representation-centric world action model (WAM) built on representation visual-action tokenizers. Existing WAMs typically inherit reconstruction-oriented video tokenizers from pretrained video generation models. Although these tokenizers preserve visual fidelity, pixel reconstruction alone provides limited guidance for learning instruction-following dynamics that connect future prediction with robot control. To address this, we explore a semantic visual-action latent space for representation-centric world action modeling. Specifically, we train a representation visual-action tokenizer that maps visual inputs into aligned visual and latent action tokens. We then pretrain our WAM to jointly model future visual states and the latent actions that connect them under language instructions, followed by adaptation to real robot trajectories for closed-loop manipulation. Experiments on real-world manipulation tasks and simulation benchmarks show that RepWAM delivers strong performance across diverse manipulation settings, while ablations highlight the value of semantic visual-action tokenization over reconstruction-oriented alternatives. These results establish representation visual-action tokenization as a promising foundation for world action models and a step toward generalist robot policies. Code and weights will be available at https://github.com/wdrink/RepWAM.

- **整体含义**：本文提出**RepWAM**，一种以**表征为中心**的世界动作模型。核心思路是构建**语义视觉-动作潜空间**：通过将视觉潜空间与冻结视觉基础模型（Perception Encoder）对齐，获得富含语义的视觉标记；再在此空间内学习**潜动作标记**，使每个潜动作成为语义视觉状态间的可转移变换。最终在该统一潜空间上预训练世界动作模型，并适应真实机器人轨迹。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 设计**表征视觉-动作分词器（RepViTok）**：包含视觉分词和潜动作分词两个阶段。
- 基于RepViTok，训练**因果扩散Transformer**进行世界动作建模（联合预测视觉状态和潜动作），再通过“两阶段”训练适应具体机器人动作。

### 关键技术细节
#### 视觉分词器（Visual Tokenizer）
- 架构：ViT自编码器。初始帧采用16×16 patches，后续帧采用4×16×16 tubelets（时×高×宽）。编码器堆叠注意力块，含时序因果掩码和全空间注意力。
- 训练损失：
  - 重建损失：L1 + 感知损失 + 对抗损失。
  - **特征对齐损失**：  
    \[
    \mathcal{L}_{\text{align}} = \| W_{\text{align}} z - \mathrm{avg}(G(o)) \|_2^2
    \]
    其中 \(G\) 为冻结的视觉基础模型（Perception Encoder），\(\mathrm{avg}\) 为时域平均池化，\(W_{\text{align}}\) 为线性投影层。该损失拉近视觉潜与语义特征，使潜空间富含语义。
- 总目标：\(\mathcal{L}_{\text{vis}} = \mathcal{L}_{\text{rec}} + \lambda_{\text{align}}\mathcal{L}_{\text{align}}\)。

#### 潜动作分词器（Latent Action Tokenizer, LAT）
- 冻结视觉分词器，训练耦合的IDM \(q_\phi\) 和FDM \(f_\psi\)。
- 对连续潜帧 \(z_t, z_{t+1}\)：
  - IDM压缩变换为潜动作 \(\ell_t \in \mathbb{R}^{d_\ell}\)（\(d_\ell \ll d_v\)）。
  - FDM根据 \(z_t, \ell_t\) 生成传输矩阵 \(K_t \in \mathbb{R}^{L\times L}\) 和残差 \(\delta_t \in \mathbb{R}^{L\times d_v}\)，实现：
    \[
    \hat{z}_{t+1} = K_t z_t + \delta_t
    \]
    其中 \(K_t\) 充当语义令牌空间中的软传输算子，类似光流；\(\delta_t\) 捕获残余变化。
- 训练损失：
  - 前向预测损失 \(\mathcal{L}_{\text{fwd}} = \sum \|\hat{z}_{t+1} - z_{t+1}\|_2^2\)
  - 反向一致性损失 \(\mathcal{L}_{\text{cons}} = \sum \|\hat{z}_t - z_t\|_2^2\)（对逆序对执行相同操作）

#### 因果世界动作模型
- 将语言指令编码为条件令牌，与初始视觉上下文 \(z_1\) 和分块序列结合。
- 每块包含视觉潜和潜动作，采用**块因果掩码**，块内视觉与动作标记共享注意力权重但使用模态特定的FFN。
- 使用**条件流匹配（Flow Matching）** 目标：  
  \[
  \mathcal{L}_{\text{FM}} = \mathbb{E}\left[ \|F^v_\theta - \dot{x}^v_\alpha\|_2^2 + \lambda_a \|F^a_\theta - \dot{x}^a_\alpha\|_2^2 \right]
  \]
  其中 \(v, a\) 分别指视觉和潜动作分量。
- 训练策略：**两阶段**——先预训练（使用潜动作标签），再适配机器人真实动作（使用原始机器人动作标签）。

## 6. 主要结论与发现
1. **语义视觉-动作分词显著优于重建导向分词**：RepViTok在gFVD、PSNR、SSIM、OLS及真实成功率上全面超越WAN2.2 VAE和ViTok。例如，在RoobTwin 2.0上将平均成功率从78.0/76.0提升至86.6/83.1。
2. **两阶段训练（潜动作预训练→机器人动作适应）优于联合预测或无潜动作**：在AgiBot上两阶段将gFVD降至48.23/58.83，OLS提升至19.87/16.98，真实PickFruit成功率从30%升至50%。
3. **潜动作在语义空间中更易转移**：RepViTok的潜动作比LAPA产生更集中、更可控的响应，且IDM损失更低，说明其更适合作为中间表示。
4. **语义对齐降低对视频CFG的依赖**：RepWAM在视频CFG=1.0时取得最佳平均成功率（89.3/88.4），而Lingbot-VA需要更大CFG，表明RepViTok的语言对齐潜空间已提供足够条件信号。
5. **重建质量保持竞争力**：RepViTok在ImageNet和UCF101上的重建指标与WAN2.2 VAE相当或更好，说明语义对齐以微小的保真度代价换取了大量语义增益。

## 7. 优点
- **创新性**：首次明确将世界动作模型的核心瓶颈定位为**表征设计**，并提出统一语义视觉-动作潜空间的方案，而非仅仅继承生成模型的分词器。
- **方法优雅**：通过特征对齐损失将视觉潜拉向语义空间，再利用IDM/FDM在该空间内诱导潜动作，使动作与视觉状态在语义层面一致，逻辑清晰。
- **实验扎实**：同时包含真实机器人（有限但可控）和大规模仿真（RoboTwin 2.0 50任务），消融实验涵盖词器设计、训练策略、转移性等多个角度，结论具有说服力。
- **可解释性**：潜动作的可视化表明其聚焦于操控相关的物体位移和交互，比LAPA更清晰；CFG分析表明模型对超参数更鲁棒。
- **实用性**：两阶段训练范式（潜动作预训练+机器人动作适应）为利用大规模无动作视频进行世界模型预训练提供了可行路径，有利于扩展至互联网视频。

## 8. 不足与局限
- **实验覆盖范围有限**：真实世界仅3个任务（虽然涵盖不同难度），且每任务仅50条演示和10次rollout，统计稳定性可能不足。需要更多任务、更多本体、更广泛条件验证。
- **与最强基线的差距**：在RoboTwin 2.0上，5B版本的RepWAM（89.3/88.4）仍低于使用WAN预训练的Lingbot-VA（92.9/91.6）。论文解释为无预训练所致，但说明单纯从头训练难以匹敌大规模视频生成预训练的收益。
- **算力依赖**：5B模型需要128块H20 GPU，对资源要求高；未提及训练时长，未知实际可重复性。
- **缺少对失败案例的分析**：论文仅展示了成功轨迹，未分析失败模式（如哪个环节出错、是否受传感器噪声影响等），不利于深入理解模型边界。
- **潜在偏差风险**：真实任务演示为同环境获取，缺乏领域泛化测试（如不同光照、背景、物品种类）。仿真RoboTwin虽有域随机化，但仍是模拟环境。
- **应用限制**：潜动作维度仅4，虽然利于压缩，但可能不足以编码复杂操作中的细微变化；另外，当前依赖语言指令，未探索无指令或隐式目标设置。
