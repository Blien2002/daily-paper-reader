## 摘要
可泛化的机器人操作不仅需要对未见场景进行任务级推理，还需要将视觉计划可靠地转化为具体具身的执行。为了弥合这一差距，我们提出了VICX（视频生成与上下文执行），一种解耦的闭环操作框架。在VICX中，冻结的视频生成模型产生视觉-语言条件下的高层视觉计划，而视频到轨迹的上下文操作网络（V2T-ICON）作为任务无关的接口，将这些计划转化为可执行的机器人状态轨迹。为了提高执行泛化能力，V2T-ICON基于分割提取的仅机械臂帧观测，并使用检索的图像-状态对作为上下文提示，从而在推理时无需参数更新即可实现鲁棒且可泛化的视觉到状态映射。在Meta-World上的实验表明，VICX支持跨任务泛化、闭环自我修正和跨具身迁移，展示了任务语义和机器人执行的双重泛化能力。项目网页请见：https://scaling-group.github.io/vicx/。

## Abstract
Generalizable robot manipulation requires not only task-level reasoning over unseen scenes, but also reliable grounding of visual plans into embodiment-specific execution. To bridge this gap, we propose VICX (Video generation and In-Context eXecution), a decoupled closed-loop manipulation framework. In VICX, a frozen video generation model produces vision-language-conditioned high-level visual plans, while a Video-to-Trajectory In-Context Operator Network (V2T-ICON) serves as the task-agnostic interface that grounds these plans into executable robot-state trajectories. To improve execution generalization, V2T-ICON operates on segmentation-extracted arm-only frame observations and uses retrieved image-state pairs as in-context prompts, allowing a robust and generalizable visual-to-state mapping at inference time without parameter updates. Experiments on Meta-World show that VICX supports cross-task generalization, closed-loop self-correction, and cross-embodiment transfer, demonstrating dual generalization across both task semantics and robot execution. The project webpage can be found here: https://scaling-group.github.io/vicx/.

- **背景**：VICX（Video generation and In-Context eXecution）旨在**弥合这一鸿沟**，通过解耦框架实现**任务语义与机器人执行的双重泛化**，无需参数更新。

## 2. 提出的方法论
### 核心思想
- **解耦两阶段**：
  1. **高层视觉规划**：冻结视频生成模型（如Wan 2.7）根据当前观测和语言指令生成未来视频（像素级计划）。
  2. **低层状态执行**：V2T-ICON（Video-to-Trajectory In-Context Operator Network）将生成的视频转化为机器人状态轨迹，并由低层控制器跟踪。

### 关键技术细节
- **V2T-ICON设计**：
  - **任务无关性**：基于**仅机械臂的帧观测**（通过SAM3分割提取），避免场景和物体的干扰。
  - **上下文操作学习**：借鉴ICON（In-Context Operator Network）思想，从训练池中检索与查询帧视觉相似的图像-状态对作为**上下文提示**，在推理时动态校准像素到状态的映射，无需参数微调。
  - **网络架构**：
    - **参考注意力**：逐帧比较查询臂部外观与检索的图像-状态参考，产生帧级潜变量。
    - **时间注意力**：跨帧传播信息以消除单帧歧义、增强时间一致性。
    - **迭代精炼**：多轮交替参考注意力和时间注意力，逐步从粗到细预测轨迹。
- **损失函数**：包含状态MSE损失、轨迹平滑损失（二阶差分）、速度一致性损失三个项。

### 算法流程（文字说明）
- 循环执行：①视频生成模型根据当前观测和任务提示生成短视视频；②对视频帧进行臂部分割；③每帧从训练池检索前N个相似图像-状态对；④V2T-ICON利用这些上下文信息预测状态轨迹；⑤低层控制器执行轨迹；⑥执行后观测反馈给视频模型，进入下一轮闭环规划，直至成功或达到最大次数。

## 6. 主要结论与发现
- VICX在9个任务上平均成功率**72.2%**，显著优于π0.5-Scratch（20.6%）、π0.5-Finetune（26.1%）、AVDC（55.0%）。
- **跨本体泛化**：在橙色臂和场景变化下成功率仍达**57.2%**（无上下文时45.0%）。
- **上下文提示的作用**：使用5个检索参考将成功率从62.8%提升至72.2%（标准环境）和从45.0%提升至57.2%（跨本体），并减少平均规划次数。
- **闭环自我修正**：视频生成模型展现出类似推理的能力，在初始失败后能规划出全新的抓取策略（如抓住抽屉边缘而非把手），无需手工编码故障恢复逻辑。
- **零样本迁移**：在自定义DIY任务中，5上下文设置下成功率达20%（无上下文15%），表明非平凡泛化能力。

## 7. 优点
- **解耦架构**：视觉规划与执行分离，两者可独立利用互联网预训练模型（视频生成）和有限机器人数据（V2T-ICON），降低对大规模机器人数据的依赖。
- **执行泛化强**：V2T-ICON通过臂部分割和上下文检索，实现任务无关和跨本体映射，无需任何微调。
- **闭环鲁棒性**：通过实时反馈和重规划，有效缓解生成视频的误差累积和外部干扰。
- **训练效率高**：仅用3个源任务、1.4K episodes即可泛化至9个任务和不同本体。

## 8. 不足与局限
- **不适用于高频动作输出**：视频生成→轨迹翻译→低层跟踪的串行流水线延迟高，更适合短时重规划而非密集反应式控制。
- **视频生成为主要瓶颈**：作者指出视频生成模型是最大延迟来源，未来需集成更轻量的因果/流式视频模型。
- **单视图限制**：仅依赖单目视觉，缺乏深度或力觉信息，难以执行毫米级精密操作（如插入或力控接触）。
- **实验仅限仿真**：所有评估在Meta-World模拟器中进行，未在真实机器人系统上测试，可能导致sim-to-real gap未被评估。
- **部分任务效果差**：如button-press（20%）、faucet-close（25%）成功率较低，说明对特定接触模式仍不够鲁棒。
