## 摘要
世界行动模型（WAMs）通过将未来预测作为额外训练目标来扩展机器人策略学习，鼓励策略在其表示中编码与任务相关的时间结构。当前的WAMs通常依赖于大规模生成式架构，导致训练成本高、推理延迟大，难以作为高效的闭环策略部署。我们提出了Light-WAM，一种轻量级的世界行动模型，用于高效的机器人操作。具体而言，它采用紧凑的视频骨干网络，并在降采样的潜在空间中进行未来视频监督，降低了视频协同训练的成本，同时保留了其对表示学习的益处。在动作预测方面，Light-WAM引入了StateFusionActionExpert，该模块从多个骨干层读取适应后的状态，通过可学习查询池化进行融合，并在单个前向传递中直接预测动作块。这种设计为视频骨干表示与机器人动作之间提供了高效的接口，避免了繁重的生成式动作专家。实验表明，Light-WAM在LIBERO上保持了强劲的性能，在RoboTwin 2.0上实现了可用的多任务性能，同时仅使用0.44B可训练参数。此外，它实现了72.03ms的推理延迟，峰值GPU内存为4.1GiB，并提高了训练吞吐量。

## Abstract
World Action Models (WAMs) extend robot policy learning by incorporating future prediction as an additional training objective, encouraging the policy to encode task-relevant temporal structure in its representations. Current WAMs often rely on large-scale generative architectures that incur high training costs and inference latency, making them difficult to deploy as efficient closed-loop policies. We propose Light-WAM, a lightweight World Action Model for efficient robot manipulation. Specifically, it is built with a compact video backbone and performs future-video supervision in a downsampled latent space, reducing the cost of video co-training while retaining its benefits for representation learning. For action prediction, Light-WAM introduces the StateFusionActionExpert, which reads adapted states from multiple backbone layers, fuses them through learned-query pooling, and directly predicts action chunks in a single forward pass. This design provides an efficient interface between video backbone representations and robot actions, avoiding the need for heavy generative action experts. Experiments demonstrate that Light-WAM maintains strong performance on LIBERO and achieves usable multi-task performance on RoboTwin 2.0, while using only 0.44B trainable parameters. It also achieves 72.03ms inference latency with 4.1GiB peak GPU memory and improved training throughput.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 使用紧凑的视频骨干（Wan2.1-T2V-1.3B）并保持其冻结，仅训练轻量适配模块。
- 未来视频监督在**降采样的潜在空间**中进行（2×空间下采样），减少训练时的 token 成本。
- 仅使用当前观测进行动作预测，无需测试时未来视频生成本身，也没有大型生成式动作专家。
- 引入 **StateFusionActionExpert**（状态融合动作专家），从视频骨干的多个选定层读取适配后的状态，通过可学习查询池化（learned-query pooling）压缩为固定宽度的状态，然后直接预测动作块（action chunks），一次前向传播即可。

### 关键技术细节
- **视频骨干适配**：使用 Wan2.1-T2V-1.3B，冻结原始权重。通过 LoRA 适配所有注意力/前馈投影，并在稀疏深度（层 {8, 16, 24}）插入轻量 WAM 适配器（瓶颈 MLP）。适配后的状态从这些层提取，供动作解码器使用。
- **高效潜在视频协同训练**：视频监督在降采样潜在空间中进行：将 VAE 编码得到的潜在视频 `z_vid` 先进行空间下采样 `D(·)`，然后进行流匹配训练（flow matching），损失函数为 `L_video = || G_θ(¯z_t, t, C) - u_t ||^2`。当前观测的 latent `z_act` 保持原始分辨率。
- **StateFusionActionExpert**：对于每个选定层 ℓ，使用 `N_q=16` 个可学习查询通过多头注意力（MHA）压缩视频 token 为 `P_ℓ`，然后平均和层归一化得到 `s_ℓ`。各层状态经线性投影后拼接并通过一个残差 MLP `ϕ_fuse` 融合为 `h`。动作解码：为每个时间步 k 使用步嵌入（step embedding `e_k`）加到 `h` 上，然后通过 `ϕ_out` 预测动作 `a_k`。动作损失采用加权回归损失 `L_action`。
- 总损失 `L = L_video + λ L_action`（实验中 λ 隐含为 1 或通过调参设定，文中未明确 λ 具体值，但从算法伪代码可见两者直接相加）。

### 算法流程（文字说明）
- 训练时：输入观测序列、动作块、语言指令、本体状态 → 构建视频（三个摄像头），子采样帧 → VAE 编码得到 latent → 视频分支：空间下采样后加噪，预测流目标；动作分支：使用当前帧原始分辨率 latent，运行适配骨干，收集选定层状态，通过 StateFusionActionExpert 预测动作块 → 联合优化视频损失和动作损失。
- 推理时：输入当前观测、语言、本体 → VAE 编码当前帧 → 运行一次适配骨干，收集选定层状态 → StateFusionActionExpert 预测动作块 → 执行动作。

## 6. 主要结论与发现

1. **性能**：Light-WAM 在 LIBERO 上达到 97.2% 平均成功率，在无体感预训练方法中排名第一（整体第三），与更大的 WAM 基线相当。
2. **多任务能力**：在 RoboTwin 2.0 上实现 76.4% 平均成功率，虽低于 Fast-WAM（91.9%）等大型模型，但仍优于 π0（62.2%）和 X-VLA（72.9%），且达到可用水平。
3. **效率**：相比 Fast-WAM，可训练参数减少 13.7 倍（6.02B → 0.44B），训练吞吐量提升 4.25 倍（0.49 → 2.08 steps/s），推理延迟降低至 72.03ms（Fast-WAM 404.62ms），峰值 GPU 内存降至 4.1GiB。
4. **消融结论**：
   - 2× 潜在下采样可大幅降低训练成本，性能损失微小（从 99.0% → 98.2%）。
   - 3 层适配器（{8,16,24}）足够，5 层无明显提升。
   - 查询数量从 16 降至 8 导致成功率下降（98.2% → 95.4%），说明查询瓶颈需要足够容量。
5. **未来视频预测**：在降采样潜在空间学习到的预测仍能捕获主要运动，提供有用时间监督，但质量不如原始分辨率。

## 7. 优点（方法或实验设计亮点）

- **设计优雅**：通过“降采样的视频监督 + 直接动作解码”大幅简化 WAM 流程，无需测试时视频生成，也无需迭代式动作专家。
- **状态融合动作专家**通过多层级查询池化从不同粒度提取视觉信息，计算高效且能保留操作相关细节。
- **训练效率高**：缓存 latent、下采样训练 token，使得 0.44B 训练参数即可获得竞争力结果。
- **推理极低延迟**（72ms）和低显存（4.1GiB），适合实时闭环控制。
- **实验对比充分**：标注体感预训练情况，区分了 VLA 和 WAM 类别，并在多个基准上验证。
- **开源代码**：提供 GitHub 仓库，有利于复现和后续研究。

## 8. 不足与局限

- **多任务性能差距**：在更具挑战的 RoboTwin 2.0 上，Light-WAM 与 Fast-WAM、LingBot-VA 等大型 WAM 仍有显著差距（76.4% vs 91.9%），说明模型容量和体感预训练在复杂场景中仍然重要。
- **泛化能力未充分测试**：未在 LIBERO-Plus（加入对抗干扰和视觉变化）等鲁棒性基准上评估，模型对光照、视角变化等泛化能力未知。
- **消融不够全面**：消融仅在 LIBERO-Spatial 进行，未在其他套件或 RoboTwin 2.0 上验证下采样、适配器层数等选择的通用性。
- **视频预测质量受限**：由于在下采样潜在空间进行监督，预测帧较为模糊，可能丢失细节，虽然不影响当前动作预测能力，但未来若需要更高质量的视频预测，则需提升分辨率。
- **真实世界评估规模小**：仅 3 个任务，每个 50 演示，且仅与 π0.5 对比，缺乏更多基线或长时任务验证。
- **潜在偏差**：基线对比中，部分基线（如 π0.5）使用了不同的训练数据或体感预训练，性能差异可能不完全由架构决定；另外，RoboTwin 2.0 的随机化设置下 Light-WAM 表现一致（76.3% 与 76.4%），说明对随机化鲁棒，但未分析失败类型。
- **应用限制**：依赖于 Wan2.1 视频骨干，未来若骨干更新或 VAE 预算不同，可能需要重新适配；当前设计主要针对单帧观测，未探索多帧历史的影响。
