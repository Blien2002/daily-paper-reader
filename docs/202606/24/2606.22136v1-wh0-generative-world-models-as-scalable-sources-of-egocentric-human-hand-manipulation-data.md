## 摘要
扩展灵巧操作能力需要对物体、场景和任务进行泛化，然而现有数据源在规模与场景/具身对齐之间面临权衡：遥操作数据与机器人部署对齐良好但收集成本高；仿真具有可扩展性但受限于模拟-真实差距；真实自我中心视频可有效扩展，但与机器人部署仍存在偏差。我们提出Wh0框架，利用生成式视频世界模型作为自我中心人类手部操作数据的可扩展且可控来源，以解锁预训练灵巧VLA模型的操作能力。基于语言、物体和场景的约束，Wh0使用生成式世界模型生成WM-H——一个包含5万条自我中心人-物交互视频的数据集。随后，Wh0通过手部运动重建和视觉编辑将生成的视频转换为机器人可训练的监督信号。与有限真实机器人数据联合训练后，WM-H使预训练VLA模型适应灵巧操作部署。在18个现实世界灵巧操作任务中，与仅在机器人数据上训练的模型相比，Wh0将未见任务的零样本成功率从8.3%提升至38.9%。消融实验进一步表明，可扩展生成与场景/具身对齐是性能提升的关键驱动因素。视频和开源代码见项目网站：https://chenyt31.github.io/wh0.github.io/。

## Abstract
Scaling dexterous manipulation requires generalization across objects, scenes, and tasks, yet existing data sources face a trade-off between scale and scene/embodiment alignment: teleoperation data is well aligned with robot deployment but expensive to collect; simulation is scalable but limited by the sim-to-real gap; and real egocentric videos scale effectively but remain misaligned with robot deployment. We propose Wh0, a framework that uses generative video world models as scalable and controllable sources of egocentric human-hand manipulation data to unlock the manipulation capabilities of pretrained dexterous VLA models. Conditioned on language, objects, and scenes, Wh0 uses a generative world model to produce WM-H, a 50k-episode dataset of egocentric human-object interaction videos. Wh0 then converts the generated videos into robot-trainable supervision through hand motion reconstruction and visual editing. Co-trained with a limited amount of real robot data, WM-H adapts pretrained VLA models to dexterous manipulation deployment. Across 18 real-world dexterous manipulation tasks, compared with a model post-trained only on robot data, Wh0 improves zero-shot success on unseen tasks from 8.3% to 38.9%. Ablation studies further show that scalable generation and scene/embodiment alignment are key drivers of performance gains. Videos and open-source code can be found on our project website: https://chenyt31.github.io/wh0.github.io/.

## 2. 方法论
- **核心思想**：将视频世界模型作为“数据生成引擎”，通过可扩展的生成（而非人工采集）获得大规模、对齐部署的自我中心操作数据，并利用这些数据与少量真实遥操作数据联合微调 VLA 策略。
- **WM-H 数据集构建**（50k 条，每段 81 帧）：
  1. **指令生成**：双智能体系统（LLM + 平衡采样器）持续发现物体名词与属性形容词，优先采样低频词，结构化构造指令（如“pick the {adj} {noun}”），确保名词和形容词的 h-index 分别达到 201 和 117。
  2. **场景与具身对齐的视频合成**：
      - (a) 拍摄机器人部署视角的背景图像（含人手作为尺度锚点），用 Qwen-Image-Edit 将目标物体插入指定区域。
      - (b) 用 Wan-I2V-A14B（LightX2V LoRA 加速，4 步推理）以编辑后的图像为起始帧，生成自我中心人–手操作视频，并用 Qwen3-VL 补充动态描述。
      - (c) 用 Qwen-Image-Edit 将视频中的人手替换为真实的机械手（保持姿态、位置、物体运动不变），实现具身对齐。
  3. **手部运动提取**：使用 HaWoR 重建每帧 MANO 参数（手腕姿态 + 15-DoF 关节旋转），结合 MegaSAM 追踪相机轨迹。
- **策略学习**（VITRA 风格 VLA）：
  - **架构**：PaliGemma 视觉语言编码器（输入当前观测、语言指令、视场标记），提取认知特征，条件化扩散动作解码器（DiT-B，预测 16 步未来动作）。
  - **动作空间**：MANO 参数空间（手腕平移/旋转 + 关节旋转），维度 102。机器人动作通过重定向映射到 MANO 并沿用人类视频预计算的正则化参数。
  - **训练策略**：从 VITRA 预训练权重初始化（在 Ego4D、Epic-Kitchens、EgoExo4D、Something-Something-V2 上预训练），然后联合微调：每批 28% 遥操作（400 条）、68% WM-H（50k）、4% 具身对齐后的 WM-H。冻结视觉编码器，更新其余骨干和扩散解码器（学习率 1e-5，权重衰减 0.1，batch size 256，最多 40k 步）。

- **对比方法**：
  - π0.5：机器人数据预训练 + 遥操作微调。

  - VITRA Real Version：人类视频预训练 + 遥操作 + 真实自我中心视频（HOI4D）联合微调。

## 6. 主要结论与发现
- **性能提升显著**：Wh0 将零样本成功率从 8.3%（仅遥操作微调）提升至 38.9%，提升 4.7 倍；超越使用真实自我中心视频的 VITRA Real Version（21.4%）。
- **关键因素**：场景对齐、具身对齐、数据规模是性能提升的主要驱动因素。移除任一对齐或减少数据量均导致成功率下降。
- **解锁预训练先验**：人类视频预训练是 Wh0 有效的前提（无预训练则几乎零成功率）；WM-H 帮助激活和校准预训练中获得的操作先验，而非从零学习灵巧技能。

## 7. 优点
- **创新数据源**：将生成式世界模型作为可控、可扩展的训练数据生成器，突破人工采集瓶颈，同时通过场景/具身对齐缩小与部署的差距。
- **方法设计巧妙**：双智能体指令生成确保语义多样性；图像编辑实现场景和具身对齐（保持动作语义）；联合训练策略（重采样火箭数据 + WM-H）稳定提供具身信号。
- **验证充分**：在真实机器人上评估，多任务、多场景，消融全面，用户研究支持生成质量。
- **开源**：项目网站提供视频和代码，促进复现。

## 8. 不足与局限
- **视频生成质量受限**：生成器可能产生物理不合理的交互、意外物体或长时不一致；手–物遮挡降低手指重建精度，引入噪声监督。
- **人–机器人形态不匹配**：机械手尺寸较大，可能在执行中意外干扰物体。
- **依赖强预训练**：无人类视频预训练骨干时 WM-H 几乎无益，说明它补充而非替代大规模预训练。
- **任务范围有限**：仅覆盖单臂抓取放置，未验证双臂、工具使用、长时程任务。
- **通用性待验证**：仅在 Unitree G1 + Inspire 手这一种硬件上评估，结论的跨平台泛化性未知。
- **偏差风险**：生成的指令和场景基于有限的模板和物体库，可能偏离真实分布的多样性。用户研究中评估者可能未完全排除主观偏好。
