## 摘要
现实世界中的鲁棒机器人操作不仅需要理解当前观察，还需要记忆和动力学建模。世界动作模型（WAM）通过联合建模视觉前瞻和基于当前及历史观察的动作来具备这些能力，使其成为机器人操作的一种有前景的范式。然而，现有的WAM面临着根本性的权衡：具有高效推理的方法通常仅以最近观察的有界窗口为条件，因此在非马尔可夫环境中表现不佳；而保留长历史的方法则会在时间和空间成本上随序列长度大幅增长。为了解决这一挑战，我们引入了MemoryWAM，一种具有高效持久记忆的世界动作模型。MemoryWAM采用混合记忆设计，结合了近期帧、事件边界锚点帧以及总结长期历史的紧凑要点标记。定制的注意力机制能够检索详细的短期上下文和压缩的长期上下文，支持依赖记忆的决策制定，同时降低推理延迟和GPU内存使用。在模拟和现实世界中的长时域、依赖记忆的操作任务中，MemoryWAM在保持良好计算效率的同时，超越了强视觉-语言-动作（VLA）和WAM基线模型。

## Abstract
Robust robotic manipulation in the real world requires not only an understanding of the current observation, but also memory and dynamics modeling. World action models (WAMs) possess these capabilities by jointly modeling visual foresight and actions conditioned on both current and historical observations, making them a promising paradigm for robotic manipulation. However, existing WAMs face a fundamental trade-off: methods with efficient inference typically condition only on a bounded window of recent observations and therefore struggle in non-Markovian environments, whereas methods that preserve long histories incur time and space costs that grow substantially with sequence length. To address this challenge, we introduce MemoryWAM, a world action model with efficient persistent memory. MemoryWAM uses a hybrid memory design that combines recent frames, event-boundary anchor frames, and compact gist tokens that summarize long-range history. A tailored attention mechanism enables retrieval of both detailed short-term context and compressed long-term context, supporting memory-dependent decision-making with reduced inference latency and GPU memory usage. Across long-horizon, memory-dependent manipulation tasks in both simulation and the real world, MemoryWAM outperforms strong vision-language-action (VLA) and WAM baselines while maintaining favorable computational efficiency.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：现有世界动作模型（WAM）面临长时记忆与推理效率的根本权衡。基于滑动窗口的模型（如Cosmos Policy、FastWAM）推理高效，但只保留近期观测，在非马尔可夫（non-Markovian）环境中失败（关键信息超出窗口）；基于完整历史KV缓存的模型（如LingBot-VA、DreamZero）保留所有帧，但推理延迟和GPU内存随轨迹长度线性增长，难以部署到实际机器人。
- **研究动机**：人类记忆是混合系统——短时记忆用于即时控制（容量有限）、事件边界记忆（任务起始状态特别显著）、长期记忆存储抽象要点而非精确细节。受此启发，希望设计一种同时保留长程上下文又保持计算高效的WAM。
- **整体含义**：MemoryWAM首次将混合持久记忆机制引入WAM，使机器人能够在长时域、依赖记忆的操控任务中高效决策，兼顾性能与实时性。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
构建混合记忆缓存，包含三类上下文：
- **短时记忆（Short-term Memory）**：最近 \(N_{\text{recent}}\) 帧的完整视觉token（滑动窗口），提供高保真局部上下文用于即时控制。
- **事件边界记忆（Event-boundary Memory）**：任务起始的少量锚点帧（\(N_{\text{init}}\) 帧），保留初始场景配置（如指令相关的完整视觉token）。
- **要点记忆（Gist Memory）**：每帧附加 \(M\) 个可学习要点token（\(M \ll L\)，\(L\) 为每帧视觉token数），压缩长程历史。后续视频/动作token不直接访问历史帧，而是访问其要点token，从而实现高效持久记忆。

### 关键技术细节
- **架构**：采用混合Transformer（MoT）架构，包含视频DiT（基于Wan2.2-TI2V-5B）和动作DiT（镜像视频DiT但隐层维度缩小）。视频DiT提取动力学感知特征并维护KV缓存；动作DiT通过去噪动作token并交叉注意力于视频缓存来预测动作块。
  - 训练时使用视频预测作为动力学监督；推理时不生成视频，仅更新缓存。
- **注意力计算**：
  - 视频DiT：自注意力（历史帧+当前帧）+ 交叉注意力（动作查询与视频缓存）。
  - 动作DiT：交叉注意力于混合视频缓存（\(C_{\text{short}} \cup C_{\text{anchor}} \cup C_{\text{gist}}\)）。
- **压缩比**：每个视频帧 \(L=120\) 个latent token，使用 \(M=8\) 个要点token，压缩比 \(d = L/M = 15\)，使得长程缓存大小从 \(O(NL)\) 降至 \(O(NM) = O(NL/d)\)，时间和空间复杂度从 \(O(N)\) 降至 \(O(N/d)\)。
- **训练**：使用连续流匹配（flow-matching），1000步训练时间步。每帧构建自回归序列（清洁/噪声视频token交错+对应动作块），应用混合记忆注意力mask。对清洁条件latent进行线性混合噪声增强（Self Forcing）。
- **推理**：每个动作块（16步）执行后，从环境中采样4个可见帧，VAE编码后更新缓存（锚点帧保留、滑动窗口更新旧帧、所有历史帧要点token永不丢弃）。

### 公式流程（文字说明）
1. 观测 \(o_t\) → VAE编码为视频latent \(z_t\)。
2. 视频DiT更新KV缓存：\(C_t^v = \Phi_v(z_t, l; C_{<t})\)。
3. 动作DiT使用混合缓存预测动作块：\(a_{t:t+h-1} = \Phi_a(x_a^\tau, l; C_{\text{short}} \cup C_{\text{anchor}} \cup C_{\text{gist}})\)，其中 \(x_a^\tau\) 为扩散时间步 \(\tau\) 的噪声动作。
