## 摘要
视觉-语言-动作模型（VLA）在许多机器人操作任务上取得了最先进的性能，但在分布外场景下仍可能表现出不可预测的行为。因此，运行时失败检测对于VLA在实际中的安全部署至关重要。然而，现有的任务失败检测器需要计算昂贵的动作采样，依赖于限制其对VLA适用性的架构假设，或需要访问失败轨迹。我们提出VLA-FAIL，一种轻量级且广泛适用的VLA失败检测框架，它结合了两种新颖的失败检测器，最小化额外开销，且无需失败数据。第一种，最后一层马氏距离（LLMD），通过测量最后一层特征中每个token相对于训练数据的偏差来检测分布外状态。第二种，动作块一致性（ACC），利用滚动时域控制引起的时间重叠，在连续动作块变得不一致时检测失败。为了捕捉检测准确性与检测延迟之间的权衡，我们引入AUCPDT，一种独立于阈值的指标，同时评估精确率、召回率和检测时间。通过大量的真实世界和仿真实验，我们证明LLMD和ACC捕捉互补的失败模式，其组合能够在不同任务中实现可靠且早期的失败检测，通常显著优于更昂贵的基线方法。

## Abstract
Vision-language-action models (VLAs) achieve state-of-the-art performance on many robotic manipulation tasks, yet they can still behave unpredictably in out-of-distribution scenarios. Runtime failure detection is therefore essential for the safe real-world deployment of VLAs. However, existing task failure detectors require computationally expensive action sampling, are based on architectural assumptions that limit their applicability to VLAs, or need access to failure rollouts. We propose VLA-FAIL, a lightweight and broadly applicable failure detection framework for VLAs that combines two novel failure detectors with minimal overhead, without requiring failure data. The first, last-layer Mahalanobis distance (LLMD), detects out-of-distribution states by measuring token-wise deviations in last-layer features relative to the training data. The second, action chunk consistency (ACC), exploits the temporal overlap induced by receding-horizon control and detects failures when consecutive action chunks become inconsistent. To capture the trade-off between detection accuracy and detection latency, we introduce AUCPDT, a threshold-independent metric that jointly evaluates precision, recall, and detection time. Through extensive real-world and simulation experiments, we demonstrate that LLMD and ACC capture complementary failure modes whose combination enables reliable and early failure detection across diverse tasks, frequently outperforming significantly more expensive baseline methods.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：视觉-语言-动作模型（VLA）在机器人操作任务上表现优异，但在**分布外（OOD）场景**下仍会表现出不可预测的失败行为。为了安全部署，需要在运行时**早期检测任务失败**，以便触发人工干预或安全回退。
- **现有方法的不足**：
  - 监督式失败检测需要大量**失败轨迹数据**，收集成本高且存在安全风险。
  - 基于新颖性的检测不够充分：OOD状态不一定导致失败，而某些失败可能由内部动作生成不一致引起，不含视觉异常。
  - 已有的运行时检测器要么需要**昂贵多次采样**（如ACE、Diff），要么依赖特定架构假设（如需访问扩散损失），要么需要外部感知或VLM推理，**实时性差**且计算开销大。
- **本文目标**：设计一个**轻量、通用、无需失败数据**的运行时失败检测框架，适用于主流VLA架构，且**计算开销极小**，可实现实时闭环控制。

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架：VLA-FAIL

- 组合两个互补的检测信号：
  - **LLMD（Last-Layer Mahalanobis Distance）**：检测内部特征漂移。
  - **ACC（Action Chunk Consistency）**：检测动作计划不一致。
- 任一检测器超过阈值即触发失败报警：`F_FAIL(t) := (s_t^ACC ≥ τ_ACC) ∨ (s_t^LLMD ≥ τ_LLMD)`。
- 阈值通过**恒定共形预测**在校准数据集上确定。

### 2.2 LLMD：最后一层逐Token马氏距离

- **原理**：利用VLA特征提取器最后一层的输出，度量当前观测的特征相对于训练数据分布的偏离程度。
- **关键技巧**：
  - 针对**流匹配模型**，噪声动作在`t=0`时服从标准正态分布，因此**固定一个噪声向量**`a*_0`，消除噪声引入的特征变化。
  - 计算**逐token的均值和协方差**（每个token位置独立统计），增强检测能力。
  - 训练后单次预处理，计算训练集所有样本的`f*(o)`，得到均值`μ_s`和正则化协方差`Σ_s^λ`。
  - 运行时计算`max_s (f*(o_t)_s - μ_s)^T (Σ_s^λ)^{-1} (f*(o_t)_s - μ_s)`。
- **计算代价**：仅需一次模型前向传播，且可与动作采样并行。

### 2.3 ACC：动作块一致性

- **原理**：在滚动时域控制中，连续两个动作块的重叠部分（前缀与后缀）应保持一致；若不一致持续存在，则表明计划不稳定，可能失败。
- **计算**：
  - 速度归一化：用动作维度的平均速度`v_t^d`归一化差异（防止静止时噪声放大）。
  - 未平滑得分：`ˆs_t^ACC = (1/D) * (1/(H-R)) * Σ_d (1/v_t^d) * Σ_i |a_{t-1, R+i, d} - a_{t, i, d}|`。
  - 指数移动平均平滑（`α=0.9`）得到最终` s_t^ACC`。
- **优势**：仅需**单个动作样本**，实时友好；速度归一化提高鲁棒性。

### 2.4 新评价指标：AUCPDT

- **问题**：传统AUCPR只关注分类准确性，不区分早期/晚期检测。简单平均检测时间也不公平（过早报警可能精确率低）。
- **定义**：PVT为失败检测时间（未检测到则为1），计算每个阈值下的精度和PDT，保留Pareto最优点，计算精度-PDT曲线下的面积。越低表示越早检测且精度越高。

## 3. 实验设计

### 3.1 数据集/场景

- **真实世界任务（6个）**：
  - Blocks（堆叠小积木，高精度）、Drawer（打开抽屉放置红色方块，长周期）、Cups（任意杯套叠，多模态）、Kitchen（玩具厨房多步操作，长周期）、Stack T（T形物体竖直堆叠，高精度）、Mixer（语言条件打开混合器放置指定颜色杯子）。
  - 每个任务约80次 rollout，含分布内和分布外（OOD）初始布局。
- **仿真任务（LIBERO-Plus）**：
  - 包含四个子套件：Object、Spatial、Goal、10。每个套件测试不同泛化能力（物体身份、空间布局、目标、长周期技能）。共数千次 rollout。

### 3.2 对比方法

- **ACE**（FIPER）：动作分布熵，需32个动作样本。
- **Diff**（模仿Diff-Dagger）：流匹配损失，需32个样本。
- **STAC**：两个连续动作分布之间的MMD散度，需32个样本。
- **LLMD**（单独）、**ACC**（单独）以及**FAIL**（组合）。
- 所有基线在**回放**上评估（因其计算开销大，无法实时运行）；VLA-FAIL可实时运行。

### 3.3 评价指标

- **AUCPR**（阈值无关精度-召回面积）。
- **AUCPDT**（本文提出，联合精度和检测延迟）。
- 以及阈值依赖指标（Precision、Recall、F1、WACC等，见附录C）。

## 6. 论文的主要结论与发现

- **LLMD与ACC互补**：ACC在机器人动作剧烈/抖动时效果好；LLMD在策略陷入循环或输出默认动作时效果好。两者组合（FAIL）在几乎所有任务中表现可靠。
- **VLA-FAIL性能超越高成本基线**：
  - 在真实世界任务上，FAIL的AUCPR和AUCPDT常为前三，甚至最优。
  - 在LIBERO-Plus上，FAIL的检测性能与ACE/Diff相当或更好，且延迟更低。
- **早期检测优势**：LLMD通常比ACC和其他基线更早检测失败，组合后可平衡精度与延迟。
- **AUCPDT指标有效区分检测时机**：相同AUCPR下，AUCPDT能揭示检测速度差异。

## 7. 优点

1. **轻量高效**：仅需单次模型前向或已有动作块数据，计算开销可忽略，适合实时闭环。
2. **无需失败数据**：仅需成功可演示数据预处理，避免昂贵的安全风险数据收集。
3. **架构通用**：适用于流匹配、扩散、离散VLA，不依赖特定架构假设。
4. **互补信号**：特征漂移和动作不一致互补，覆盖多数失败模式。
5. **新评价指标AUCPDT**：合理权衡精度与检测延迟，避免早期或晚期检测的偏差。
6. **实验扎实**：真实世界+大规模模拟验证，消融充分，统计严谨。

## 8. 不足与局限

1. **LLMD需要原始微调数据**进行预处理（计算特征统计），数据不可得时无法使用。
2. **ACC依赖滚动时域控制的重叠**：若执行完全开环动作（无重叠），ACC失效；重叠越小性能下降（但仍保留部分检测能力）。
3. **无法检测所有失败模式**：如策略自信地停止或忽略语言指令（特征和动作均一致），此时需结合VLM语义检测。
4. **模拟实验仅单次种子**（因计算成本高），可能引入随机偏差；但结果趋势与真实世界一致。
5. **阈值设定较简单**：恒定共形预测，未针对变长任务优化（虽作者已解释原因）。
6. **未在非常大规模、多机器人场景下验证**：真实世界任务有限（6个），泛化性需进一步测试。
