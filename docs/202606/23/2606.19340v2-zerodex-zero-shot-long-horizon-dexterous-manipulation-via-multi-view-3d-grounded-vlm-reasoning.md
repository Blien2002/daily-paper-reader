## 摘要
我们提出ZeroDex，一个用于长时域灵巧操作的零样本框架，它通过标定后的多视图RGB图像将语言指令转化为可执行的3D任务规划。我们的系统无需训练端到端策略，而是使用视觉语言模型（VLM）生成参考帧任务基础点和原始级2D关键点，然后通过多视图融合将其提升到3D空间。这种提升结合了视图级VLM基础的三角测量与参考视图射线投票，后者沿语义相机射线搜索邻近视图中几何一致的候选点。生成的3D关键点既支持拾取放置也支持工具使用：对于工具使用，我们检索与推断技能类别对应的以对象为中心的原子动作，并将其存储的6D工具轨迹对齐到场景；对于灵巧执行，我们将提升后的抓取关键点扩展为任务条件化的抓取可行区域，并通过臂手运动生成器生成可行的抓取-运动对。真实世界实验表明，与单视图RGB-D基础和微调VLA基线相比，3D基础精度和执行可靠性均有提升。我们进一步通过闭环状态验证和重新规划展示了长时域操作，实现了对新场景中未见物体和工具使用任务的零样本执行。

## Abstract
We present ZeroDex, a zero-shot framework for long-horizon dexterous manipulation that grounds language instructions into executable 3D task plans from calibrated multi-view RGB images. Rather than training an end-to-end policy, our system uses a vision-language model (VLM) to produce reference-frame task grounding and primitive-level 2D keypoints, then lifts them into 3D via multi-view fusion. This lifting combines triangulation of view-wise VLM groundings with reference-view ray voting, which searches along a semantic camera ray for geometrically consistent candidates across neighboring views. The resulting 3D keypoints support both pick-and-place and tool-use: for tool-use, we retrieve an object-centric atomic action corresponding to the inferred skill category and align its stored 6D tool trajectory to the scene; for dexterous execution, we expand the lifted grasp keypoint into a task-conditioned grasp affordance region and generate feasible grasp-motion pairs with an arm-hand motion generator. Real-world experiments show improved 3D grounding accuracy and execution reliability over single-view RGB-D grounding and fine-tuned VLA baselines. We further demonstrate long-horizon manipulation through closed-loop status verification and replan, enabling zero-shot execution on unseen objects and tool-use tasks in novel scenes.

- **核心问题**：灵巧操作（dexterous manipulation）需要精确的3D空间理解（抓取点、放置位置、工具运动轨迹），现有方法主要依赖端到端学习（如VLA模型）或人类示教重定位。这些方法存在以下瓶颈：

## 2. 论文提出的方法论

### 核心思想
- 将语言指令分解为原子操作序列（ grasp → waypoint → release/hold ），利用多视图VLM基础生成2D关键点，并通过**三角测量**与**参考视图射线投票**相结合的方法稳健地提升为3D世界坐标。
- 对工具使用任务，引入**“原子动作包”（Bag of Atomic Actions）**，即预存储的以工具为中心的6D运动轨迹库，通过场景关键点对齐来适配新场景。
- 对灵巧抓取，将3D抓取关键点扩展为**任务条件化的抓取可行区域**，并利用两种抓取生成器（圆柱模板与优化式），再通过逆运动学与碰撞筛选得到可行臂手运动。

### 关键技术细节

1. **参考帧语义基础**（Section 3.1）：
   - 给定多视图图像集合 \(I\) 和指令 \(l\)，VLM \(\Phi\) 选择参考视图 \(r\)，推断操作模式 \(z\)（pick 或 tool），并预测模式特定基础元组 \(g_z\)。
   - 对于拾取放置，\(g_{pick}\) 包含目标物体和2D目标像素。
   - 对于工具使用，\(g_{tool}\) 额外包含工具物体、技能类别和目标物体。
   - 然后生成原始序列 \(Q_r = \{(m_t, P_t^r)\}_{t=1}^T\)，其中 \(P_t^r\) 包含2D关键点及其语义描述。

2. **多视图融合3D提升**（Section 3.2）：
   - 对于每个2D关键点 \(p_{t,j}^r\)，在所有视图上查询VLM得到视图级2D基础 \(p_{t,j}^v\)。
   - **三角测量**：对每对视图 \((a,b)\) 计算候选3D点 \(X_{t,j}^{a,b}\)，统计重投影误差满足阈值 \(\epsilon_{tri}\) 的视图数作为共识得分。取得分最高的候选作为 \(X_{tri}\)。
   - **参考视图射线投票**：沿参考视图相机射线采样 \(N_\delta\) 个深度候选，投影到非参考视图并加上编号标记，让VLM选择最匹配语义描述的编号，统计投票得分得到 \(X_{vote}\)。
   - 最终融合：若三角测量最高得分超过阈值 \(\tau_{tri}\)，则采用 \(X_{tri}\)，否则回退到 \(X_{vote}\)。
   - 关键点集 \(X\) 转换到世界坐标系。

3. **以对象为中心的原子动作对齐**（Section 3.3）：
   - 原子动作定义为 \(A = (c, \mathcal{T}, X_s, X_e)\)，其中 \(c\) 是技能类别，\(\mathcal{T}\) 是6D工具轨迹，\(X_s, X_e\) 是存储的起点和终点锚点。
   - 测试时，根据推断的技能类别 \(c\) 检索对应动作，利用场景中的 \(X_{app}\) 和 \(X_{term}\) 计算刚体变换 \(T_{align}\)，将存储轨迹对齐到当前场景得到 \(\hat{\mathcal{T}}\)。

4. **灵巧抓取与运动生成**（Section 3.4）：
   - 将3D抓取关键点投影回各视图，查询VLM预测2D抓取边界框，提升为3D可行区域 \(R_{aff}\)（通过多视图包含分数阈值 \(\tau\)）。
   - 两种抓取生成器：
     - 圆柱模板采样器：用于手柄状物体，初始化手掌位姿并优化手指闭合。
     - 基于优化的生成器（改进自BODex）：加入可行区域引导的接触损失 \(L_{aff} = w_{dist}L_{dist} + w_{dir}L_{dir}\)。
   - 碰撞感知位置精化：对放置/终点关键点在局部垂直网格中搜索最近无碰撞位置。
   - 对每个抓取候选，用现成臂手运动生成器 [54] 求解运动轨迹，选择物理可行的 \((T_{robot}, \eta)\) 执行。

5. **长时域闭环执行**（Appendix C.1）：
   - 包装单步管道，VLM每步执行后根据新观测生成状态更新（continue / retry / replan / done），允许最多4次重试。

## 6. 主要结论与发现

- **多视图融合显著提升3D基础精度**：在抓取点定位误差（\(L_{grasp}\)）上，单视图RGB-D基线为16.43cm，ZeroDex（2/3/5视图）降至约4.6cm；应用动作点误差（\(L_{apply}\)）也从2.72cm降至1.35-1.94cm。碰撞误差在多视图方法上也有所改善（细化后最低）。
- **零样本成功率优于微调VLA**：在“扔垃圾”和“扫帚清扫”上，GR00T和Being-HO微调后全部0/5失败，而ZeroDex分别实现10/10和8/10成功。
- **闭环重规划支持长时域**：在整理物体任务中，6次试验中有4次完全成功（66.7%），烹饪任务3次中1次成功（33.3%）。失败主要来自运动规划问题，而非3D基础。
- **模块化设计有效**：无需任何训练或任务特定调整，即可泛化到新物体和新工具（如扫帚）。

## 7. 优点

- **真正零样本**：无需训练数据或微调，开箱即用，泛化到未见物体和场景。
- **多视图3D提升鲁棒**：结合几何三角测量和语义射线投票，在遮挡和部分可见情况下仍能产生一致3D基础。
- **支持工具使用**：通过在原子动作库中存储6D工具轨迹并执行场景对齐，实现了多样化工具行为（倒水、扫帚、锤击等）。
- **灵巧抓取质量高**：通过任务条件化的可行区域引导抓取生成，结合碰撞感知路径细化，生成物理可行的臂手运动。
- **闭环可重规划**：通过VLM状态验证和失败重试，提升了长时域任务的鲁棒性。

## 8. 不足与局限

- **依赖2D VLM推理可靠性**：系统性能上限取决于底层VLM的任务分解、语义理解和空间推理准确性。即使多视图融合可以缓解部分2D误差，但严重错误仍会传播。
- **运动规划器可能导致失败**：使用了现成臂手运动生成器（如cuRobo），在关节极限、碰撞检测超时或抓取不稳定时仍会失败，增加推理到执行延迟。
- **不支持手内操作**：当前框架聚焦于对象级操作和简单工具使用，无法执行手指内旋转、操作剪刀、按压工具按钮等灵巧的手内在操作。
- **实验规模有限**：真实世界试验次数较少，缺乏统计显著分析；且仅测试了桌面固定环境，未评估动态或复杂户外场景。
- **计算效率未讨论**：多视图VLM推理（需要多次调用大模型）的延迟和计算成本未被量化，影响了实际部署可行性。
- **原子动作库依赖预定义**：需要离线构建工具使用动作库，对新工具可能需手动添加，限制了全自动泛化。
