## 摘要
视觉-语言-动作模型在机器人操作中展现了巨大潜力，但原始语言主要用于指定任务意图，而非在高速底层执行过程中反复处理。受这种分离的启发，我们提出了一种受小脑-丘脑启发的视觉-动作模型（CT-VAM），用于高效的任务条件视觉运动控制。CT-VAM 作为一个紧凑的局部执行策略，能够从双视角视觉观察、本体感觉和轻量级任务条件中预测动作块，从而实现一种实用的云-边缘范式：高层语义推理可由大模型处理，而快速闭环控制则在本地硬件上运行。为了有效融合异构输入，CT-VAM 引入了 TARS（丘脑动作路由流），一种流分离的条件注意力解码器，可独立路由动作、视觉和任务流，从而防止密集的感知标记压倒紧凑的任务相关条件。仅凭借 6800 万参数，CT-VAM 在 LIBERO 任务上的成功率可与规模大得多的 VLA 模型媲美，同时降低了推理延迟。结合用于异步执行块的流一致修复，CT-VAM 支持高频控制，并在资源受限的机器人平台上展示了鲁棒的现实部署能力。

## Abstract
Vision-language-action models have shown strong promise for robot manipulation, yet raw language is primarily needed to specify task intent rather than to be repeatedly processed during high-frequency low-level execution. Motivated by this separation, we propose a cerebello-thalamic-inspired vision-action model (CT-VAM) for efficient task-conditioned visuomotor control. CT-VAM acts as a compact local execution policy that predicts action chunks from dualview visual observations, proprioception, and a lightweight task condition, potentially enabling a practical cloud-edge paradigm in which high-level semantic reasoning can be handled by large models while fast closed-loop control runs on local hardware. To fuse heterogeneous inputs effectively, CT-VAM introduces TARS (Thalamic Action Routing Stream), a stream-separated conditional attention decoder that independently routes action, visual and task streams, preventing dense sensory tokens from overwhelming compact task-relevant conditions. With only 68M parameters, CT-VAM achieves LIBERO success rates competitive with substantially larger VLA models, while reducing inference latency. Together with flow-consistent inpainting for asynchronous chunk execution, CT-VAM supports high-frequency control and demonstrates robust realworld deployment on resource-constrained robotic platforms.

- **核心问题**：现有视觉-语言-动作（VLA）模型在机器人低层控制中，每个控制周期都反复处理原始语言指令，导致推理延迟高、计算开销大，难以部署到资源受限的边缘设备（如Jetson Orin NX）。然而，语言指令主要在任务开始或切换时用于指定意图，高频执行阶段主要依赖视觉和本体感觉反馈。因此，将语言处理与低层执行解耦，使用紧凑的任务条件代替反复的语言推理，是提升效率的关键。
- **整体含义**：受生物小脑-丘脑通路中“高层意图指导”与“快速传感器运动执行”分离的启发，论文提出CT-VAM模型，将高层语义理解（可由大模型在云端完成）与低层视觉运动控制（在本地边缘设备上快速闭环执行）解耦。该模型仅68M参数，在LIBERO基准上达到与大规模VLA模型竞争的成功率，同时显著降低推理延迟，支持高频实时控制，验证了云-边协同范式的可行性。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将原始语言指令转化为紧凑的任务条件（文中采用one-hot任务标识符），低层策略仅依赖视觉史、本体感觉史和该任务条件生成动作块，避免反复处理语言。
- 提出**TARS（Thalamic Action Routing Stream）**：一种流分离的条件注意力解码器，独立路由并门控动作流、视觉流、本体感觉流和任务流，防止密集的视觉标记淹没紧凑的任务条件。
- 提出**FCI（Flow-Consistent Inpainting）**：异步执行动作块时，通过约束重叠区域遵循与训练相同的噪声-数据线性插值路径，保证相邻块边界的连续性，同时保持解码器输入分布一致。

### 2.2 关键技术细节
- **输入**：双视角RGB图像（第三视角 + 腕部视角）历史、本体感觉历史、任务one-hot标识符。
- **视觉编码**：冻结的DINOv3-S+ ViT骨干，输出层级的视觉记忆（patch tokens），通过腕部查询交叉注意力融合双视角。
- **动作解码器**：基于Transformer的整流流（rectified flow）模型，预测动作块（chunk length H=8）的速率场（velocity field）。
- **TARS结构**：在每个解码器层，动作令牌（从噪声动作嵌入）同时关注四个流：
  - 自流（当前动作令牌）
  - 动作查询流（可学习的查询令牌，从DINOv3的register tokens初始化）
  - 密集流（视觉patch + 本体感觉编码）
  - 任务流（单一任务token）
  每个流独立进行LayerNorm和Softmax，再通过可学习门控聚合，避免长序列流（如视觉patch）主导。
- **整流流训练**：采用带掩码的均方误差损失，预测速率场。推理时使用固定步数（NFE=8）的欧拉积分。
- **FCI**：采样固定噪声ϵ_ov，在每步流积分后，将新块的前K_ov个动作约束为 (1-τ)ϵ_ov + τY_ov（Y_ov为当前块剩余动作），保证最终边界一致且中间状态在分布内。

### 2.3 公式与算法流程（文字说明）
- **条件互信息形式化**：定义∆t = I(A_t; L | G, O_t)衡量语言经任务条件G后对动作的剩余信息，当G充分时∆t≈0，验证了解耦的合理性。
- **整流流训练**：对专家动作块A，采样τ~Beta(2,2)，噪声ϵ~U[-1,1]；构造A_τ = (1-τ)ϵ + τA；目标速率v* = A-ϵ；预测v_θ(A_τ, τ, C)。损失为元素级均方误差。
- **TARS更新**：对于每个解码器层ℓ，动作查询Q^ℓ_a，从各流计算key/value，独立Softmax得到A^b，门控聚合：ˆX^ℓ = X^ℓ + Σ_b γ^b A^b W_o。
- **FCI流程**：同步生成第一个块并执行；启动异步推理，在剩余K_ov动作期间生成下一块；每一流步后，强制新块前K_ov位置为流一致内插值；其余位置自由更新。
