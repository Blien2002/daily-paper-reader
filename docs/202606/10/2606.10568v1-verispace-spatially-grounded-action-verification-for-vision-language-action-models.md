## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展现出巨大潜力，但其测试时的可靠性仍受限于单次动作预测，即使微小的动作误差也可能导致抓取失败、碰撞或任务进度错误。一个自然的替代方案是为VLA系统配备测试时验证功能，允许在执行前提出并评估多个候选动作。然而，可靠的动作验证具有挑战性，因为不仅需要区分候选动作之间细微的几何差异，还需要评估动作是否朝着任务目标取得有意义的进展。我们提出了VeriSpace，一种用于VLA系统测试时动作选择的3D感知动作验证器。VeriSpace通过两个关键组件评估候选动作：双路径3D注入场景编码，构建同时保留视觉语义和显式3D几何的场景表示；以及空间基元动作推理，通过推理任务相关的空间关系、几何有效性和预期的目标进展来评估每个动作。这些组件共同使得在细微但影响结果的候选动作之间进行更可靠的区分成为可能，同时与现有VLA策略完全兼容。在公共基准测试和真实世界机器人操作任务上的实验表明，VeriSpace在底层VLA策略和先前基于验证的方法上均持续提高了决策可靠性，在分布内和分布外设置中均取得了显著提升。

## Abstract
Vision-language-action (VLA) models have shown strong promise for robotic manipulation, but their reliability at test time remains limited by one-shot action prediction, where even small action errors can cause grasp failure, collision, or incorrect task progression. A natural alternative is to equip VLA systems with test-time verification, allowing multiple candidate actions to be proposed and evaluated before execution. However, reliable action verification is challenging because it requires not only distinguishing subtle geometric differences between candidate actions, but also assessing whether an action makes meaningful progress toward the task goal. We present VeriSpace, a 3D-aware action verifier for test-time action selection in VLA systems. VeriSpace evaluates candidate actions through two key components: Dual-Path 3D-Injected Scene Encoding, which constructs a scene representation that jointly preserves visual semantics and explicit 3D geometry, and Spatially-Grounded Action Reasoning, which evaluates each action by reasoning over task-relevant spatial relations, geometric validity, and expected goal progress. Together, these components enable more reliable discrimination between subtle yet outcome-critical action candidates while remaining fully compatible with existing VLA policies. Experiments on public benchmarks and real-world robotic manipulation tasks show that VeriSpace consistently improves decision reliability over both underlying VLA policies and prior verification-based methods, yielding substantial gains in both in-distribution and out-of-distribution settings.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：视觉-语言-动作模型（VLA）在机器人操作中展现潜力，但通常采用“一次预测即执行”的范式，即使微小的动作误差（如位置偏移、朝向偏差）也会导致抓取失败、碰撞或任务无法推进。这类模型缺乏测试时的自我纠正机制，在场景模糊、操作几何复杂或存在多个可行动作时尤为脆弱。
- **研究动机**：引入测试时验证（test-time verification）——先由VLA策略采样多个候选动作，再通过专门的验证器评估并选择最优动作执行。但可靠的动作验证面临双重挑战：
    - **动作空间推理**：候选动作在2D图像上可能极其相似，但3D空间中的微小差异决定成败，需要感知3D几何结构。
    - **目标进度评估**：动作是否有意义取决于当前任务阶段，需判断动作是否使场景向目标状态靠近，不能仅靠直接打分。
- **整体含义**：提出一种3D感知的动作验证器VeriSpace，通过显式建模场景几何和结构化空间推理，使VLA系统在测试时能够进行更可靠的决策，提升机器人操作的安全性和成功率，且与现有VLA策略即插即用。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
VeriSpace是一个基于VLM的3D感知验证器。在每个时间步，从冻结的VLA策略中采样k个候选动作（6D位姿+夹爪动作），VeriSpace对每个动作输入当前RGB-D观测、任务指令和动作，输出质量分数。最终选择分数最高的动作执行。验证过程包含结构化链式推理，以区分细微但关键的动作差异。

### 2.2 关键技术细节

#### 双路径3D注入场景编码（Dual-Path 3D-Injected Scene Encoding）
- **3D几何构建**：利用相机内外参将RGB-D图像反投影为3D坐标图（P∈R^{H×W×3}），通过正弦编码+可学习MLP得到几何嵌入P'。
- **双路径分词**：
    - **3D几何令牌（X_geo）**：将几何嵌入投影到VLM令牌空间，提供显式几何表示。
    - **空间增强视觉令牌（X_vis）**：用CLIP编码RGB提取视觉令牌，并与几何嵌入逐元素相加，保留语义同时注入3D信息。
- **几何引导的局部聚合（Geometry-Guided Local Aggregation, GLA）**：对X_vis进行最远点采样（FPS）选出种子令牌，在3D球形邻域内（半径r）聚合邻居特征，使用可学习空间核g(·)加权。使令牌能捕获对象表面、边缘、缝隙等局部3D结构。

#### 空间基元动作推理（Spatially-Grounded Action Reasoning）
VeriSpace对每个候选动作执行三步链式推理：
1. **动作空间推理**：识别任务相关实体（操作对象、目标对象、机器人末端），分析其相对位置、朝向、接触/间隙，判断几何有效性。
2. **目标进度评估**：分两步——(2.1) 行动前评估：描述当前状态与目标状态的关系；(2.2) 行动后评估：推断执行动作后的预期场景过渡，比较是否更接近目标。
3. **验证分数估计**：整合上述推理结果，通过轻量MLP（Reward Expert）映射为标量分数。

#### 学习目标
- **动作评估损失 L_a**：Bradley-Terry偏好对损失，鼓励验证器给更优动作更高分数。
- **推理损失 L_CoT**：交叉熵损失监督生成的链式推理序列。
- 总损失：L = λ_a L_a + λ_CoT L_CoT。

### 2.3 算法流程（文字描述）
每个时间步：
1. 给定当前观测（静态RGB-D、手腕RGB可选）、机器人状态、任务指令。
2. VLA策略以温度τ采样k个候选动作。
3. 对每个候选动作，VeriSpace构建3D几何和空间增强令牌，连接指令令牌和动作令牌。
4. VLM骨干网络进行三步结构推理，输出推理文本和最终标量分数。
5. 选择分数最高的动作执行。

## 6. 主要结论与发现

1. **大幅提升成功率**：VeriSpace在所有设置中一致改进VLA决策可靠性。

3. **各组件均重要**：3D输入、双路径编码、GLA、空间推理缺一不可。尤其是空间推理模块的加入带来+6.5pp（SimperEnv）和+5.0pp（真实世界）提升。
