## 摘要
现代视觉-语言-动作（VLA）模型通常无法泛化到新的设置，例如改变的摄像头视角或机器人形态，因为这些模型通常仅基于当前观测和语言指令进行条件化。通过忽略底层系统配置作为一个变量，这些模型隐含地假设了训练中遇到的固定执行上下文，导致任何新环境都需要数据密集型的微调。在这项工作中，我们提出了上下文世界建模（ICWM），这是一个将系统辨识视为上下文适应问题的框架。ICWM使机器人策略能够从自我生成的、任务无关交互的短历史中自主推断关键系统变量。与传统的使用示范来指定执行什么任务的上下文学习不同，ICWM利用上下文窗口来理解系统如何运作。通过在任务执行前处理这些交互，模型隐含地捕获了当前系统的世界动态，从而无需参数更新即可适应新配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新型摄像头视角下显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

## 1. 核心问题与整体含义（研究动机与背景）

现代视觉-语言-动作（VLA）模型在机器人控制中通常仅基于当前观察和语言指令来预测动作，**忽略了底层系统配置**（如摄像头视角、机器人形态等）。这导致模型在部署时若遇到与训练时不同的配置（例如新的摄像头角度或机械臂长度变化），性能会剧烈下降，需要耗费大量数据进行重新微调。作者将此问题定义为**系统辨识缺失**——策略无法在测试时获取当前系统的配置信息。受人类通过随机探索快速建立控制映射的启发，论文提出将系统辨识转化为**上下文适应问题**，使VLA模型通过自生成的任务无关交互历史隐式推断系统动态，无需参数更新即可适应新环境。

## 2. 方法论：核心思想、关键技术细节与流程

### 核心思想
- **ICWM（In-Context World Modeling）**：利用上下文窗口实现系统辨识（而非传统ICL的行为指定）。模型通过预处理一段短交互历史（随机运动的观察-动作-新观察三元组）来捕获当前系统的因果结构，从而调整后续动作产生。

### 关键技术细节
- **训练阶段**：每个训练样本构建为**任务无关交互片段** + 任务查询。交互片段从不同系统配置下的演示中随机采样，迫使模型从上下文提取动力学信息，隐式学习 `Ψ(T)`（配置推断函数）。
- **推理阶段**：
    1. **主动探测阶段**：机器人执行 `N` 次（默认5次）随机运动（采样安全空间内的随机目标位姿），记录每步的 `(o_s, a, o_e)` 三元组。
    2. **上下文执行阶段**：将交互片段拼接到当前观察和语言指令前，用同一Transformer模型生成动作。由于交互片段的自注意力，模型隐式获得配置信息，无需额外参数或梯度更新。
- **公式化**：`a_t ~ π_θ(a_t | Ψ(T), o_t, l)`，其中 `Ψ(T)` 是由Transformer隐式计算的，与策略共享参数。

### 优势
- 完全无参数更新、无需任务演示、无需奖励信号。
- 探测动作是任务无关的，不干扰初始场景。

- **消融实验**：比较全上下文、移除动作、移除图像、无上下文、错误上下文（180°偏移视角的片段）。

## 6. 主要结论与发现

1. **ICWM显著提升新型摄像头视角下的泛化能力**：在LIBERO OOD视角平均成功率提升13.0%（相对MV基线），在真实机器人上提升71%。
2. **隐式辨识优于显式指定**：ICWM比EXPL（使用真实角度）高出9.5%，表明交互上下文提供了更丰富的动态信息。
3. **长时域任务获益最大**：LIBERO-Long上ICWM领先MV达26.3%，因视角漂移在小误差累积时影响更大，ICWM能持续校正。
4. **泛化能力超越摄像头视角**：对语义场景变化（干扰物、纹理）和机器人形态变化（垫片、连杆长度）均保持稳定优势。
5. **探测策略灵活**：随机、XY-only、Z-only、R-only四种策略均有效，证实效益来自交互格式而非特定运动模式。
6. **实际影响**：解决了VLA模型“数据密集型微调”的痛点，实现了零参数适应的部署。

## 7. 优点

- **创新性**：重新定义VLA泛化为测试时系统辨识问题，将ICL从“行为描述”拓展为“系统理解”，视角新颖。
- **实用性**：无需参数更新、无需任务演示，仅需短暂随机探测（5-6秒），开销可接受（KV缓存可复用，零-shot影响可忽略）。
- **简洁优雅**：通过共享Transformer参数隐式实现世界模型，不增加额外参数或训练目标。
- **全面验证**：从模拟到真实，从视角偏移到形态和语义变化，消融设计严谨，理论补充（命题1）强化了动机。
- **结果显著**：在多个难例上（如135°视角、长时域任务）保持领先，性能提升幅度大。

## 8. 不足与局限

- **探测阶段物理开销**：需要机器人先执行随机运动，虽然只有几秒，但在某些需要即时启动的场景（如快速应急）可能不适用。
- **OOD视角覆盖不全**：某些视角（如135°）对所有方法均困难，表明存在感知极限；ICWM在该视角上优势有限。
- **仅测试了有限泛化维度**：未评估光照变化、动态障碍物、完全不同的任务域（如移动操纵）等。
- **探测动作可能影响初始状态**：虽设计了安全空间，但复杂场景中难以完全避免碰撞或干扰。
- **未与在线适应方法（如元学习、在线微调）系统对比**：文中仅对比了静态基线，缺乏对同样可在测试时自适应的方法（如MAML、RL^2）的公平比较。
- **依赖大量多视角训练数据**：训练数据需覆盖多种配置，对于仅有一个视角的数据场景，ICWM可能无法被有效训练（需上下文多样性）。
- **推理延迟有所增加**：虽然可预计算KV缓存，但首次推理时仍需处理额外上下文token（0.185s vs 0.112s），仅在高实时性场景中需评估。
