## 摘要
机器人领域面临着数据稀缺的基本挑战。与语言或视觉研究不同，机器人操作没有互联网规模的数据集。一个可行的前进方向是利用自我中心的人类数据，这些数据可以更容易、更广泛、更大规模地收集。为此，我们研究了使用$π_{0.5}$模型作为基础，在不同具身形式（配备灵巧五指手的人类和人形机器人）之间进行学习的关键设计选择。我们的结果表明，人类数据使机器人能够在没有相应机器人数据的情况下学习新的任务语义，并将现有技能组合成新的行为。论文网站：https://egopipaper.github.io/

## Abstract
Robotics faces a fundamental challenge of data scarcity. Unlike language or vision research, there is no internet-scale dataset for robotic manipulation. A promising path forward is to leverage egocentric human data, which can be collected more easily, with greater breadth, and at a larger scale. Towards this end, we investigate key design choices for learning across human and humanoid embodiments equipped with dexterous five-finger hands, using the $π_{0.5}$ model as a foundation. Our results show that human data enables robots to learn new task semantics and compose existing skills into novel behaviors without corresponding robot data. ## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 基于预训练VLA模型$π_{0.5}$（flow-matching动作头），通过**联合训练人类自我中心数据**和**人形机器人数据**，在不改变模型参数规模下，实现灵巧双手控制。

### 关键技术细节
- **动作交错（Interleaved Action Sequence）**：
  - 原始$π_{0.5}$动作维度上限为32，而双手共58维。
  - 将左手和右手动作**分布到两个token**中（每token 32维），从而保持预训练投影层不变，但有效动作时间步长减半（$H/2$）。
- **视觉对齐（Skeleton Overlay）**：
  - 在人类和机器人图像上叠加**手指骨架线**，每指独立颜色，按深度排序绘制，使模型明确理解手指对应关系。
- **动作对齐（Robot-Centric Mapping）**：
  - 将人类手关键点（MANO格式20个）转换为**每关节偏移和缩放**，映射到机器人关节空间，避免自我碰撞和不自然姿态。
  - 对Tesollo（20关节）和Inspire（6关节）分别给出映射参数。
- **子任务预测（Subtask Prediction）**：
  - 在VLM部分输出子任务文本（如"pick tomato"），作为中间推理步骤，强制“先思考后行动”。
- **训练策略**：
  - 人类数据无腕部图像，机器人腕部图像以**40%概率dropout**，统一输入模态。
  - 联合训练中人类/机器人数据比例固定为50%（不敏感）。

### 公式说明
- 训练目标为flow-matching模仿学习损失：
  $L = \mathbb{E}_{\tau,\omega} [\|\omega - a_{t:t+H} - f_\theta(a^{\tau,\omega}_{t:t+H}, o_t, \ell_t)\|^2]$
  其中$\tau$为flow时间指数，$\omega$为高斯噪声。

## 6. 主要结论与发现
1. **简单联合训练**即可实现番茄分拣（92%）和包装（90%）的高成功率，但装箱较差（27%）。
2. **子任务预测**是解锁装箱任务的关键（提升至93%），尤其适用于需要逻辑顺序和双手协调的复杂场景。
3. **骨架叠加**对性能提升帮助不大（无明显提升），提示模型可能已具备视觉对应能力。
4. **手型选择**：Inspire手（更接近人手尺寸）在装箱任务中优于Tesollo（成功率67%），可能因形态差异小、状态敏感度低。
5. **腕部相机**对抓取精度至关重要（测试时dropout导致成功率下降）。

## 7. 优点
- **方法创新**：
  - **动作交错**巧妙解决预训练VLA维度限制，无需修改模型结构或从头训练。
  - **机器人中心动作对齐**避免逆运动学不适定问题，适用于高自由度假手。
  - **子任务预测**作为辅助损失，有效提升复杂技能链学习。
- **实验设计**：
  - 任务设计清晰区分三种语义迁移类型，验证了方法在不同认知复杂度下的效果。
  - 消融实验系统，关键组件逐一检验。
- **实际意义**：证明人类数据可补足机器人数据缺失的高级语义，大幅降低机器人任务学习的数据需求。
