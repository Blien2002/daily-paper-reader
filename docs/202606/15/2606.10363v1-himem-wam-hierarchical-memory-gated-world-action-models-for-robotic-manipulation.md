## 摘要
世界动作模型（WAMs）已成为具身智能的一种新的强大范式，学习与动作相关的视觉动态，显著增强了泛化能力和鲁棒性。然而，现有的WAMs在处理长期机器人操作中的任务相关记忆方面仍有困难。为了解决这个问题，我们提出了HiMem-WAM，一种分层记忆门控WAM，它整合了以运动为中心的潜在动作、高层技能潜在变量以及边界触发的记忆更新。具体来说，我们开发了一个分层潜在动作框架，共同学习底层运动和高层技能潜在变量，提供结构化的时间抽象。同时，一个边界感知的记忆门在预测的技能转换处写入紧凑的任务状态，使得因果推断无需在测试时生成未来视频或光流估计。在LIBERO、LIBERO-PLUS、RMBench和真实世界任务上的评估显示，HiMem-WAM在部署扰动下，分层潜在变量提高了鲁棒性，并且记忆模块显著有益于依赖记忆的长期操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **分层潜在动作框架**：将长时程任务分解为两个层次——低层运动潜变量（low-level latent action）和高层技能潜变量（high-level skill latent）。技能潜变量由可变长度分段池化得到，提供结构化时间抽象。
- **记忆门控模块**：只在预测的技能转换边界处写入紧凑任务状态，读门控从外部记忆库检索历史上下文以调节规划器，写门控由边界分数控制。整个推理完全因果，无需未来视频生成或光流估计。

### 关键技术细节（三阶段训练）

#### 阶段I：低层潜在动作分词器学习
- 输入：多视角RGB图像、光流（DPFlow提取）、本体感知、语言指令。
- 设计：变分分词器编码短时上下文（当前与下一帧光流、图像等），输出潜变量 z_l^t。
- 损失：光流重建损失 + 动作对齐损失（若存在动作标签）+ KL散度正则化。
- 输出：冻结分词器，离线提取所有轨迹的低层潜变量序列 Z_l。

#### 阶段II：分层潜在动作预训练（无记忆）
- 技能发现：对低层潜变量序列进行多层次的分块（chunking），通过边界预测器（基于token间相似度）将序列划分为可变长度技能段，经注意力池化得到高层技能潜变量 Z_h。
- 规划器：基于Qwen3-VL-4B-Instruct，输入当前观测、指令、本体感知，预测当前技能潜变量 z_h^t 和边界分数 b̂_t。
- 执行器：将技能潜变量扩展为低层潜变量动作块 Ẑ_l^{t:t+K-1}。
- 损失：MSE（技能+低层潜变量）+ BCE（边界预测）。

#### 阶段III：记忆模块微调
- 记忆读门：从外部记忆库 M_t 检索上下文 c_m^t，通过可学习门控 α_r^t 控制信息注入，得到记忆增强状态 \tilde{x}_t。
- 记忆写门：基于 \tilde{x}_t、预测技能和边界分数，计算写门控 α_w^t，当超过阈值 η 时写入新记忆令牌 γ_t（由当前状态、技能、池化低层潜变量组成）。写门控由真实边界标签监督，并加入 L1稀疏正则。
- 总损失：动作预测损失 + 阶段II各项损失 + 门控损失（BCE + L1稀疏正则）。

### 推理流程
- 仅使用当前观测、本体感知、指令和记忆库，因果执行：读记忆 → 规划器预测技能与边界 → 执行器生成潜动作块 → 动作解码器输出可执行动作 → 写门判断是否写入记忆。
