在本报告中，我们提出了Hy-Embodied-0.5-VLA（简称HyVLA-0.5），一个覆盖完整机器人学习栈的端到端系统：数据收集、模型设计、持续预训练与监督微调、强化学习后训练以及现实世界部署。栈中的每个组件都扮演着独特的角色。

## Abstract
In this report, we present Hy-Embodied-0.5-VLA, abbreviated as HyVLA-0.5, an end-to-end system that spans the full robot learning stack: data collection, model design, continued pre-training and supervised fine-tuning, RL post-training, and real-world deployment. Each component serves a distinct role in this stack.

## 1. 核心问题与整体含义

**研究动机**：现有的视觉-语言-动作（VLA）模型在机器人控制上展现潜力，但将其转化为可部署的通用机器人，需要从数据收集、模型设计、训练到执行的全栈协同设计。当前系统存在三个主要瓶颈：(1) 传统遥操作缺乏自然触觉反馈，依赖SLAM的UMI设备精度不足；(2) 通用VLM骨干未针对机器人控制进行优化，连续动作生成与离散化存在矛盾；(3) 部署时的高频闭环控制与模型推理延迟难以调和。

**整体含义**：本文提出HyVLA-0.5，一个覆盖数据收集、模型架构、持续预训练、监督微调、强化学习后训练以及部署的完整机器人学习栈。它并非孤立模型，而是一个将各组件端到端耦合的系统，旨在降低从数据到实物的转化门槛，为可部署通用机器人提供实践路线。

## 2. 方法论

### 2.1 核心思想
- **端到端联合设计**：数据、模型、训练策略、部署机制相互适配，而非各自独立优化。
- **保持动作接口的形态无关性**：通过delta-chunk（增量末端执行器）动作表示和rel-EE框架，解耦策略学习与具体机器人运动学。
- **失败利用驱动改进**：通过离线RL后训练（FlowPRO）将失败案例直接转化为策略提升信号，无需奖励模型。

### 2.2 关键技术细节

#### a. 数据收集：Hy-UMI-10K
- 定制**指尖贴附式UMI**抓取器（模拟工业夹爪），装有指尖力传感器，操作员手指直接驱动，保留自然触觉。
- 使用**外部光学动作捕捉系统**（而非SLAM）以亚毫米精度追踪6-DOF轨迹，同步RGB-D头戴相机。
- 采集**超1万小时、100万回合**的70余种任务演示数据，涵盖洗衣、厨房、精细操作等6大场景。
- 该数据可直接用于后训练（post-training），无需额外目标机器人数据。

#### b. 模型架构
- **主干**：Hy-Embodied-0.5-MoT（4B参数，Mixture-of-Transformers架构），支持原生分辨率视觉编码和多模态自适应计算。
- **动作专家**：采用**流匹配（Flow Matching）** 预测连续动作块（chunk size H=50），通过双塔路由（VLM塔+动作专家塔）实现跨模态交互，并采用块级因果注意力。
- **紧凑记忆编码器**：在视觉ViT中插入层间因果时序注意力，融合K帧历史（K=6用于SFT），但不增加视觉token数量。
- **动作表示**：使用**delta-chunk**（增量末端执行器位姿 + 归一化夹爪开度），输出维度20（双10维），与具体机器人关节解耦。

#### c. 训练流程
- **阶段1：持续预训练**：在Hy-UMI-10K上训练200K步，batch size 1024，学习率5e-5，仅流匹配损失。K=1（单帧）。
- **阶段2：监督微调（SFT）**：
  - **Track A**（同形态）：在目标机器人遥操作数据上微调（Dobot X-Trainer，4任务各300演示）。
  - **Track B**（跨形态）：仅用UMI演示微调，部署于形态不同机器人（JAKA K1, Astribot S1），不接触目标机器人数据。
  - SFT设置K=6，训练60K步，batch size 32。
- **阶段3：RL后训练——FlowPRO**：
  - **数据管线**：通过“干预-回滚”机制从策略执行中自动收集偏好对（正/负轨迹），再通过平滑插值生成密集逐状态三元组 $(s, a_w, a_l)$。
  - **损失函数**：RPRO损失 = 对比项（偏向 $a_w$） + 邻近正则项（锚定隐含奖励为零） + SFT项。无需奖励模型或价值网络。
  - 迭代3轮，每轮25K步，混合历史偏好对和SFT数据。

#### d. 部署
- **异步推理**：推理线程与执行线程重叠，缓冲区覆盖，隐藏骨干网络延迟。
- **Bézier块拼接**：消除块间不连续，通过三次Bézier曲线保证C1连续，根据机器人加速度限制自适应选择连接点。

## 3. 实验设计

### 3.1 仿真环境
- **RoboTwin 2.0**（50个双手操作任务），采用Aloha-AgileX设置。
- **设置**：每个任务Clean环境（50个演示）和Randomized环境（500个演示），共2.75K回合、600万帧。
- **评估指标**：100次随机rollout平均成功率。

### 3.2 真实机器人任务
- **Track A（同形态）**：Dobot X-Trainer上的4个任务（插瓶、折叠眼镜、摆餐具、拉链笔袋），每任务300个演示。
- **Track B（跨形态）**：
  - JAKA K1：收纳配件（发带），300个UMI演示。
  - Astribot S1：清理桌面，200个UMI演示。
- **额外**：Unitree G1上的力区分任务（通过指尖力感知区分轻重箱子）。

### 3.3 对比方法
- 仿真：π0, π0.5, ABot-M0, Qwen-VLA, LingBot-VLA, starVLA, Motus, JoyAI-RA。
- 真实：与同等参数量的π0、π0.5对比（Track A/B）；后训练对比DAgger和π0.6*。

### 3.4 消融实验

- 同时移除记忆编码器与UMI预训练。

## 6. 主要结论与发现

1. **HyVLA-0.5在仿真RoboTwin 2.0上达到最优**：Clean 90.9%，Randomized 90.1%，超越所有对比方法（最佳竞争对手JoyAI-RA分别为90.5%/89.3%）。
2. **UMI预训练对真实机器人至关重要**：特别是在精密关节（如折叠眼镜、拉链）上显著提升成功率；在跨形态迁移中，不接触目标机器人数据即可获得有效性能。
3. **FlowPRO后训练进一步提升性能**：相比DAgger和π0.6*，在所有四个任务上获得更高成功率和更短完成时间（例如插瓶从93%→99%，时间从27s→16s）。
4. **紧凑记忆编码器（6帧历史）带来一致增益**：仿真中提升约2个百分点。
5. **力感知可行**：通过UMI指尖力传感器数据，Unitree G1能成功区分轻重物体。

## 7. 优点

- **全栈系统性**：不是孤立模型，而是数据→部署的完整闭环，组件间强耦合设计。
- **数据质量高**：亚毫米精度动作标注 + 力模态，可直接用于后训练，减少额外遥操作成本。
- **形态无关动作表示**：delta-chunk和rel-EE框架使策略可在不同平台间零/少接触迁移。
- **RL后训练高效**：FlowPRO免奖励/价值网络，通过失败案例快速迭代，且具有对比梯度抵消特性，可安全混合SFT数据。
- **部署实用化**：异步推理 + C1连续平滑块拼接，适应50Hz伺服速率。
- **开源**：代码、模型、数据集已公开。
