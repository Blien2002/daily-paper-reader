## 摘要
视觉-语言-动作模型在机器人操作中展现出强大潜力，然而原始语言主要用于指定任务意图，而非在高频低级执行过程中重复处理。受这一分离现象的启发，我们提出了一种小脑-丘脑启发的视觉-动作模型（CT-VAM），用于高效的任务条件视觉运动控制。CT-VAM作为一个紧凑的局部执行策略，从双视角视觉观察、本体感觉和轻量级任务条件中预测动作片段，有望实现一种实用的云-边缘范式，其中高级语义推理可由大型模型处理，而快速闭环控制则在本地硬件上运行。为了有效融合异构输入，CT-VAM引入了TARS（丘脑动作路由流），这是一种流分离的条件注意力解码器，可独立路由动作、视觉和任务流，防止密集的感知标记淹没紧凑的任务相关条件。凭借仅68M参数，CT-VAM在LIBERO任务上取得了与规模大得多的VLA模型相当的成功率，同时减少了推理延迟。结合用于异步片段执行的流一致性修补，CT-VAM支持高频控制，并在资源受限的机器人平台上展示了稳健的现实世界部署能力。

## Abstract
Vision-language-action models have shown strong promise for robot manipulation, yet raw language is primarily needed to specify task intent rather than to be repeatedly processed during high-frequency low-level execution. Motivated by this separation, we propose a cerebello-thalamic-inspired vision-action model (CT-VAM) for efficient task-conditioned visuomotor control. CT-VAM acts as a compact local execution policy that predicts action chunks from dualview visual observations, proprioception, and a lightweight task condition, potentially enabling a practical cloud-edge paradigm in which high-level semantic reasoning can be handled by large models while fast closed-loop control runs on local hardware. To fuse heterogeneous inputs effectively, CT-VAM introduces TARS (Thalamic Action Routing Stream), a stream-separated conditional attention decoder that independently routes action, visual and task streams, preventing dense sensory tokens from overwhelming compact task-relevant conditions. With only 68M parameters, CT-VAM achieves LIBERO success rates competitive with substantially larger VLA models, while reducing inference latency. Together with flow-consistent inpainting for asynchronous chunk execution, CT-VAM supports high-frequency control and demonstrates robust realworld deployment on resource-constrained robotic platforms.

*   **研究动机**：受生物系统中“小脑-丘脑”通路分离的启发（高层的意图处理与低层的快速感觉运动执行分离），论文提出应将语言理解（语义接地）与视觉运动控制解耦。语言一旦形成紧凑的任务意图表示后，低层策略就可以仅依赖视觉-本体感觉观测和该紧凑条件进行闭环控制，无需反复解析原始语言。
*   **整体含义**：CT-VAM旨在创建一个紧凑、高效的视觉-动作模型，作为本地执行策略，从而实现一种实用的“云-边缘”范式：大型模型（如VLM）负责高级语义推理并输出轻量级任务条件，而CT-VAM在本地硬件上执行快速闭环视觉运动控制。

## 2. 论文提出的方法论

### 2.1 核心思想
*   将视觉运动执行分解为两个阶段：
    1.  **语义接地**：将原始语言指令 `L` 和初始场景上下文 `X₀` 映射为一个紧凑的、控制充分的意图表示 `G`（例如 one-hot 任务标识符）。该过程仅需执行一次。
    2.  **低层执行**：学习一个策略 `πθ(At | G, Ot)`，其中 `Ot` 是当前的视觉-本体感觉历史。该策略在后续控制步骤中无需再处理原始语言。
*   形式化地，论文定义了“控制充分性”条件：若条件互信息 `I(At; L | G, Ot) ≤ εt`，则 `G` 对于原始指令 `L` 是控制充分的。这意味着给定 `G` 和观测后，原始指令不提供额外的动作相关信息。

### 2.2 关键技术细节
*   **总体架构**：
    *   **视觉编码器**：使用冻结的 DINOv3 骨干网络处理双视角（第三视角和腕部）RGB 观测，提取层级的视觉特征记忆 `Dℓ`。
    *   **本体感觉编码器**：`ϕs` 编码本体感觉历史 `s1:To` 得到 `S`。
    *   **任务编码器**：将 one-hot 任务标识符 `y` 嵌入为任务 token `r`。
    *   **动作解码器**：基于纠正流（Rectified Flow）的 Transformer 解码器。它从噪声动作 `Aτ` 开始，通过多步去噪生成动作块 `a1:H`。
*   **核心模块：TARS（Thalamic Action Routing Stream，丘脑动作路由流）**
    *   在解码器的每一层，TARS 将动作 token 更新为对四个分离的信息流的条件注意力输出：
        *   **自流 (self)**：当前动作 token 自身。
        *   **动作查询流 (aq)**：可学习的动作查询槽（初始化为 DINOv3 的寄存器 token），用于细化动作生成。
        *   **密集流 (dense)**：层级视觉特征 `Dℓ`（包含大量 patch token）和本体感觉 `S`。
        *   **任务流 (task)**：紧凑的任务 token `r`。
    *   **关键创新**：对每个流独立进行注意力计算和 Softmax 归一化（流分离归一化），然后通过可学习的门控 `γ` 聚合。这避免了共享 Softmax 中密集 token 数量多而导致的任务 token 被淹没的问题。
    *   动作查询的初始化：从预训练 DINOv3 的 4 个寄存器 token 投影并扩展得到 32 个可学习查询，提供先验信息。
*   **流一致修补（Flow-Consistent Inpainting, FCI）**：
    *   用于异步块执行。当当前动作块正在执行时，并行推理下一个块。
    *   为确保块间边界平滑，FCI 约束新生成块的前 `Kₒᵥ` 个动作（重叠部分）遵循与训练时相同的线性插值轨迹（从噪声过渡到剩余动作 `Yₒᵥ`），而不是直接硬钳位，从而保证解码器输入保持分布内。
    *   这允许将后续推理延迟隐藏在物理动作执行中，实现高频等效控制（如 20 Hz）。

### 2.3 算法流程（文字说明）
1.  **训练**：
    *   对专家动作块 `A`，采样噪声 `ε` 和流时间 `τ`，构建插值 `Aτ = (1-τ)ε + τA`。
    *   解码器以 `Aτ` 为输入，结合 TARS 提供的条件（视觉、本体感觉、任务、动作查询），预测速度场 `vθ`。
    *   损失函数为预测速度与真实速度 `v⋆ = A - ε` 之间的均方误差。
2.  **推理（带 FCI）**：
    *   第一步：同步生成第一个动作块，开始执行。
    *   后续步骤：当当前块还剩 `Kₒᵥ` 个动作时，启动下一个块的并行推理。
    *   在纠正流积分过程中，新块的前 `Kₒᵥ` 个动作被强制约束在噪声-重叠轨迹上，其余部分自由更新。
    *   生成完成后，新块无缝衔接当前块的尾部。

## 6. 论文的主要结论与发现

1.  **语言分离的有效性**：证实了将语言接入从低层控制回路中分离、仅依赖紧凑任务条件可达到与大型 VLA 模型相当的性能，同时推理延迟显著降低。
2.  **TARS 的有效性**：流分离注意力机制有效防止了密集视觉 token 淹没任务条件，相比无 TARS 的更大规模 FM 变体（FM-L, 758M），CT-VAM（68M）取得了更高的平均成功率（82.1% vs 77.3%）。
3.  **FCI 的实用性**：流一致修补实现了异步块执行，将后续推理延迟隐藏在动作执行内，实际执行频率接近目标控制频率（20 Hz），在 RTX 4080 上等效为完全隐藏。
4.  **边缘部署可行性**：CT-VAM 可在资源受限的 Jetson Orin NX 平台上完全运行，通过 TensorRT 优化后推理延迟降低，实际等效频率接近 20 Hz。
5.  **紧凑模型的高效性**：仅 68M 参数的模型即可在 LIBERO 上达到 82.1% 平均成功率，远超同参数量级方法，接近或超过数十亿参数的 VLA 模型（如 π0 86.0%，但 CT-VAM 在某些子项上更高）。
