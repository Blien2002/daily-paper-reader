## 摘要
长时域机器人操作仍然具有挑战性，因为相似的观察可能出现在不同的执行阶段，而适当的动作取决于先前完成的操作。记忆可以通过使策略从执行历史中推断任务进度来解决这种歧义。然而，现有的记忆增强方法通常要么保留需要压缩的密集历史，要么主要依赖可能丢弃早期任务相关事件的近期上下文。在这项工作中，我们提出KEMO，一种轻量级的即插即用记忆框架，自动选择性地保留与任务相关状态变化相关的关键帧，用于VLA策略。KEMO结合机器人运动学和视觉过滤来检测事件，将选定的关键帧编码为紧凑的时间顺序记忆令牌，并通过交叉注意力和门控残差融合与当前视觉特征集成，用于VLA训练。检测到的事件还在关键转换附近定义了更高权重的训练样本。我们在各种真实世界双臂操作任务上评估KEMO，任务包含2到6个有评分的子任务，轨迹长度从830步到2846个执行步骤（持续时间从28秒到95秒）。与无记忆基线（例如π0.5）相比，KEMO将整体任务成功率提高了23.6%，阶段完成率提高了34.1%。消融实验表明，事件驱动的关键帧选择优于均匀采样和近期帧保留，而提出的门控融合和关键帧对齐的损失权重提供了互补的增益。

## Abstract
Long-horizon robot manipulation remains challenging because similar observations may occur at different execution stages, while the appropriate action depends on previously completed operations. Memory can address this ambiguity by enabling policies to infer task progress from execution history. However, existing memory-augmented approaches often either retain dense histories that require compression or rely primarily on recent context that may discard earlier task-relevant events. In this work, we propose propose KEMO, a lightweight plug-in memory framework that automatically selectively preserves keyframes associated with task-relevant state changes for VLA policies. KEMO combines robot kinematics with visual filtering to detect events, encodes the selected keyframes as compact temporally ordered memory tokens, and integrates them with current visual features through cross-attention and gated residual fusion for VLA training. The detected events also define higher-weight training samples near critical transitions. We evaluate KEMO on various real-world dual-arm manipulation tasks spanning 2 to 6 scored subtasks, and trajectory length ranging from 830 steps to 2846 execution steps (durations from 28 to 95 seconds). Compared with the memory-free baseline (e.g., $π_{0.5}$), KEMO improves aggregate Task Success Rate by 23.6\% and Stage Completion Rate by 34.1\%. Ablations show that event-driven keyframe selection outperforms uniform sampling and recent-frame retention, while the proposed gated fusion and keyframe-aligned loss weighting provide complementary gains.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：长时域（long-horizon）机器人操作中，不同的执行阶段可能出现视觉上相似的观测，而正确的动作依赖于之前已完成的操作（即阶段模糊性和部分可观测性）。现有 VLA 策略仅依赖当前观测，难以区分这些歧义点。
- **现有方法的不足**：
  - 密集记忆方法（如 MemoryVLA）需要压缩大量冗余历史，导致关键事件在压缩表示中难以区分。
  - 任务分解方法（如 MemER）依赖 VLM 在线推理，引入额外延迟和幻觉传播风险。
- **本文的动机**：提出一种轻量级、即插即用的记忆框架，以事件驱动的关键帧（event keyframes）作为紧凑的历史证据，在不压缩密集历史或依赖在线高级推理的情况下，帮助 VLA 策略解歧。

## 2. 方法论

- **核心思想**：事件关键帧（对应任务相关的状态转换）提供了紧凑、明确的执行历史证据。通过结合机器人运动学线索和视觉变化验证，自动检测这些关键帧，并将其编码为时序记忆 token，通过交叉注意力和门控残差融合注入当前视觉表示，从而预测动作。
- **关键技术细节**：
  - **事件驱动关键帧检测**：
    - **事件显著性分数**：基于滑动窗口内的平均关节空间位移的倒数，捕捉操作减速时刻（如抓取、放置等）。
    - **因果峰值检测**：在显著性序列上识别局部峰值作为候选关键帧。
    - **视觉去重滤波器**：使用冻结的 DINOv2 编码器比较候选帧与上一个已接受关键帧的全局图像嵌入，仅保留场景变化较大的帧（阈值 ϵ）。
    - **不应期**：避免同一转换中重复检测。
  - **关键帧记忆整合**：
    - **编码**：用 SigLIP 编码器提取关键帧的 patch token，再进行 4×4 空间平均池化，每帧压缩为 16 个 token。
    - **记忆库**：存储最多 K 个最近接受的关键帧，不足时用最近帧填充并带二进制遮罩。
    - **时序位置编码**：每个关键帧槽位附加可学习的位置嵌入，以区分阶段顺序。
    - **记忆注入**：以当前帧的 patch token 为查询，关键帧 token 为键值，进行带遮罩的交叉注意力，然后通过门控残差融合（可学习门控，初始化负偏置）与当前表示结合，避免早期干扰。
  - **关键帧一致训练**：在关键帧附近的时间步（窗口半径 δ）赋予更高的损失权重（λ>1），使策略在关键转换处更准确，且这些权重索引与记忆内容来自同一检测事件。
- **公式**：显著性分数 \( S_t = \frac{1}{1 + \bar{\delta}_t} \)；视觉去重相似度；加权损失 \( L = \frac{\sum_t w_t \ell_t}{\sum_t w_t} \)。

## 7. 优点

- **轻量即插即用**：无需修改基础 VLA 架构，仅添加关键帧检测与记忆注入模块，可作为插件增强现有模型。
- **无需任务特定标注**：关键帧检测完全基于运动学和视觉信号，无需人工标注阶段或使用 VLM 在线推理。
- **事件驱动选择**：自动聚焦于任务关键转换，避免密集历史压缩带来的信息丢失。
- **门控融合设计**：初始化为负偏置，保护基础策略在记忆不成熟时的性能，自适应调节记忆贡献。
- **训练-推理一致性**：用于损失加权的关键帧索引与记忆内容来自同一检测器，强化关键转换处的学习。
- **丰富的真实世界实验**：涵盖 6 种不同复杂度的双臂任务，验证了方法的鲁棒性与可迁移性。

## 8. 不足与局限

- **仅在自定义真实场景评估**：未在公开机器人操作基准（如 LIBERO、RLBench、METTDR 等）上测试，外部泛化性未验证。
