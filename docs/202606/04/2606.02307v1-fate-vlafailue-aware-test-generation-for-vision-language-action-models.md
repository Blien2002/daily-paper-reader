## 摘要
视觉-语言-动作（VLA）模型越来越多地被用作通用机器人策略，但它们的评估仍然主要依赖于随机采样任务场景的静态基准测试。在高维具身空间中，故障是稀疏且聚集的，因此静态基准测试可能低估鲁棒性风险。我们将VLA评估重新定义为主动故障发现问题，并提出一种故障感知测试生成方法，该方法将多样性驱动的探索与从观察执行中学习的替代模型相结合。该方法将测试引导向高风险但多样化的场景区域。在四个最先进的VLA模型上，它发现了更多故障（比选定基线高出最多29.7%），同时揭示了更多样化的故障模式。这意味着，例如，对于GR00T-N1.6，成功率从64.4%下降到34.7%。更广泛地说，我们的研究结果呼吁VLA评估的转变：从固定任务集上的被动测量转向适应性、寻求故障的测试生成，以在部署前暴露模型弱点的结构。

## Abstract
Vision-Language-Action (VLA) models are increasingly used as generalist robot policies, yet their evaluation still relies largely on static benchmarks that randomly sample task scenes. In high-dimensional embodied spaces, failures are sparse and clustered, so static benchmarking can underestimate robustness risks. We reframe VLA evaluation as an active failure-discovery problem and propose a failure-aware test-generation approach that combines diversity-driven exploration with surrogate models learned from observed executions. The method steers testing toward high-risk yet diverse scene regions. Across four state-of-the-art VLA models, it uncovers substantially more failures (up to +29.7 % over selected baselines) while revealing more diverse failure modes. This mean that, for instance, in the case of GR00T-N1.6, success rate dropped from 64.4% to 34.7%. More broadly, our findings call for a shift in VLA evaluation: from passive measurement on fixed task suites to adaptive, failure-seeking test generation that exposes the structure of model weaknesses before deployment.

- **研究动机**：作者主张VLA评估应从“被动测量”转向“主动故障发现问题”——不仅关注找到多少故障，还要关注故障的多样性。现有研究（如VLATest）虽然强调了鲁棒性和多样性，但大多依赖预设扰动或随机采样，缺乏对故障区域的学习和自适应引导。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将VLA测试生成建模为**主动故障发现（active failure-discovery）问题**，结合**多样性驱动的探索**（基于自适应随机测试ART）与**代理模型（surrogate model）** 对故障概率的预测，迭代地引导测试生成向**高风险且多样**的场景区域倾斜。

### 关键技术细节

#### 两个混合测试生成算法：

**算法1：Hybrid Sorted Surrogate Assisted FSCS-ART（基于排序的代理辅助FSCS-ART）**
- 基于FSCS-ART（一种距离最大化的自适应随机测试方法），维护已执行场景存档S和标注存档D。
- 初始阶段（无代理模型时）：使用FSCS-ART选择与已执行场景最不相似（欧氏距离最大）的候选场景，促进探索。
- 当D包含两类样本（成功和失败）后：训练决策树或随机森林代理模型。
- 每轮：首先生成k个候选场景，按与S的最小距离排序；然后预先用代理模型扫描排序后的候选，若预测为故障则优先选择该候选；若均未预测为故障，则选择距离最大的候选。
- 每次执行后更新D，并重训练代理模型。

**算法2：Hybrid Adaptive RF-Guided FSCS-ART（自适应随机森林引导的FSCS-ART）**
- 除了D和S，还维护故障场景存档F（存储导致失败的场景）。
- 同样先探索，待数据含两类后进入学习引导阶段。
- 候选生成方式：从故障档案F附近局部采样+全局随机混合生成。
- 对每个候选计算：归一化最小距离（多样性）和RF预测的故障概率。
- 组合得分：`score = α · p_fail + (1-α) · norm_d`，其中α = min(0.85, i/N)为自适应权重，随迭代从探索向利用过渡。
- 选择得分最高的候选执行；若执行结果失败则加入F；每轮重训练RF。

### 代理模型选择
- 决策树（DT）：轻量、可解释，用于硬边界划分。
- 随机森林（RF）：集成学习，提供更平滑的故障概率估计，避免过度聚焦单一故障簇。

### 关键参数
- 候选集大小k（文中未明确数值）；N为总测试场景数（实验中使用200次迭代？）。
- RF超参数：150棵树，最大深度12，最小分裂节点数3。
- DT最大深度8。
- 自适应权重α上限0.85。

## 3. 实验设计

### 场景/数据集
- **环境**：SimplerEnv（基于MuJoCo的仿真环境），用于机器人抓取任务。
- **任务**：仅使用“Pick up（拾取）”任务——机器人需抓取并举起目标物体。该任务简单，但模型表现较好，因此发现故障更具挑战性。
- **物体池**：7种物体（RedBull罐、蓝色塑料瓶、茄子、胡萝卜、苹果、勺子、海绵）。
- **场景参数**：每次选择一个物体，随机放置于x∈[-0.5, -0.05], y∈[0.0, 0.4]的桌面工作区内；可指定朝向（Ω集）。

### 被测试的VLA模型
- OpenVLA-7b、π0、GR00T-N1.6、EO-1（四种最先进VLA模型）。

### 对比基线
- **B1（Random）**：纯随机生成场景。
- **B2（FSCSART）**：仅使用FSCS-ART（无机器学习引导），即距离最大化的多样性驱动方法。
- 本方法变体：FSCSART_DT（仅用DT引导）、Sorting_RF、Sorting_DT、Weighted_RF（对应算法1和算法2的RF/DT版本）。

### 评价指标
1. **Failure Rate (FR)**：失败场景比例。
2. **Trajectory Coverage (TC)**：机器人末端位置覆盖（相对于工作台网格），衡量行为空间多样性。
3. **Trajectory Coverage under Failure (TCF)**：仅统计失败执行中的轨迹覆盖率，反映故障行为多样性。
4. **Failed Object Coverage (FOC)**：至少发生一次故障的物体种类比例。

### 执行设置
- 每种配置重复10次（应对随机性），每次运行200个测试场景。

## 6. 论文的主要结论与发现

1. **本研究方法显著优于基线**：
   - 在EO1上，最佳方法（Sorting_RF）的FR比B1高23.3个百分点，比B2高22.0个百分点。
   - 在GR00T-N1.6上，Sorting_RF的FR达到65.3%，比B1（35.6%）高29.7个百分点，比B2（36.5%）高28.8个百分点（近乎翻倍）。
   - π0上，Weighted_RF的FR达到73.7%，比B1高19.7个百分点。
2. **ART多样性本身贡献微弱**：B1和B2在所有非天花板模型上FR相差仅0.9-1.5个百分点，说明无ML引导的多样性驱动测试无法高效发现故障。
3. **ML引导是性能提升的核心**：将DT或RF嵌入ART后，FR大幅跃升。RF比DT更优，因为RF提供更平滑的故障概率估计，避免过度聚焦单一故障簇，从而同时保持较高的TCF和FOC。
4. **故障区域具有可学习结构**：VLA故障并非随机分布，而是存在可被代理模型学习的模式或区域。
5. **倡导VLA评估范式转变**：从静态基准转向自适应、故障寻求的评估管线，以暴露系统性弱点。

## 7. 优点
