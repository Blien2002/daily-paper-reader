## 摘要
现代视觉-语言-动作（VLA）模型通常无法泛化到新设置，例如改变相机视角或机器人形态，因为它们通常仅以当前观察和语言指令为条件。通过忽略作为变量的底层系统配置，这些模型隐含地假设了训练过程中遇到的固定执行上下文，从而需要对任何新环境进行数据密集型的微调。在这项工作中，我们引入了上下文世界建模（ICWM），这是一个将系统辨识视为上下文自适应问题的框架。ICWM使机器人策略能够从短期历史的自生成、任务无关的交互中自主推断出关键系统变量。与传统的使用示范来指定执行什么任务的上下文学习不同，ICWM利用上下文窗口来理解系统如何运行。通过在任务执行前处理这些交互，模型隐式地捕获了当前系统的世界动态，从而无需更新参数即可适应新配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新相机视角上显著优于标准VLA基线模型。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

- **研究动机**：现代视觉-语言-动作（VLA）模型仅在当前观测和语言指令的条件下预测动作，忽视了系统配置变量（如相机视角、机器人形态、安装偏移等）。这种隐含的固定上下文假设导致模型在部署环境与训练环境不一致时（例如新相机视角或机器人形态改变）性能急剧下降，通常需要数据密集型的场景特定微调，与通用型部署目标相矛盾。
- **核心问题**：作者将这种失败重新定义为 **系统辨识问题**——策略缺乏测试时的系统配置知识 ψ。现有上下文学习方法（ICL）仅将上下文用于行为指定（做什么），而非系统辨识（系统如何运行），且仍依赖用户提供的示范。
- **整体含义**：ICWM 受人类操作员通过随机探索快速建立新控制映射的心理模型启发，提出利用**自生成、任务无关的交互历史**作为上下文，让模型在测试时隐式恢复系统动态，实现无需参数更新的零样本适应。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将系统辨识视为一个上下文自适应问题。在任务执行前，机器人执行一段短序列的随机探索运动，记录视觉-动作-视觉的过渡片段（自探针交互上下文），然后将其预置于 VLA 策略的上下文窗口之前。模型通过标准序列建模自动从这些交互中提取时不变的系统因果结构（如控制映射、相机视角），从而在下游任务中正确解读当前观测。
- **关键技术细节**：
  - **形式化**：标准 VLA 策略 πₜ(at|ot, l) 隐式假设固定 ψ，而理想策略应条件于 ψ：π*ₜ(at|ot,l,ψ)。ICWM 通过上下文函数 Ψ(T) 近似 ψ，新策略为 at∼πₜ(at|ot,l, Ψ(T))，其中 T 为交互上下文。
  - **上下文训练**：从多配置训练数据中随机采样 N 个任务无关交互片段（每个片段形如 (o_start, a, o_end)），预置于每个训练样本前。模型需学习从不同上下文下准确预测动作，从而隐式学习系统动态。损失函数为负对数似然。
  - **测试时主动探测**：部署时，机器人先执行 N 个自生成随机探测动作（目标姿态在工作空间内均匀采样，避开任务相关物体），记录过渡片段。随后在单次前向传播中，Transformer 先处理上下文，再处理任务查询，产生对齐当前配置的动作。
  - **参数共享**：Ψ 与 VLA 主干共享参数，无需引入额外参数或专用世界模型头。
  - **动作表示**：使用 FAST 动作分词器，动作块大小 5；视觉编码器基于 Qwen2.5-VL-3B；上下文使用 N=5 个片段。

## 6. 论文的主要结论与发现

- **ICWM 显著提升 OOD 视角泛化性能**：在 LIBERO 上，OOD 成功率比 Multi-View BC 高 13.0%，比 Explicit Configuration 高 9.5%；真实机器人上，OOD 成功率提升 71%（17% → 29%）。
- **隐式辨识优于显式提供真值角度**：尽管额外提供相机角度，EXP 仍缺乏系统动态理解，ICWM 从交互上下文中获得更全面的校准。
- **长时域任务获益最大**：LIBERO-Long 上 ICWM 比 MV 高 29.9%（seen）和 26.3%（unseen），说明误差累积可被动态校准缓解。
- **上下文必须与当前配置一致**：假上下文（偏移 180° 视角）导致性能低于无上下文，表明模型真实地条件于上下文内容。
- **ICWM 可推广至语义和形态变化**：在干扰物、纹理、UR5e 加装间隔器、WindowX 连杆缩放的实验中均保持稳定优势。
- **学习到的隐式表示可辨识**：t-SNE 显示不同视角下上下文表示紧密聚类且有良好分离性。
- **在上下文训练下的能力是习得的而非突现**：未经过上下文训练的 BC 模型加上交互上下文后性能崩溃（<1%），证明需专门训练。

## 7. 优点

- **无需参数更新或任务示范**：真正零样本适应，仅需短暂的自生成交互（5-6 秒）。
- **方法简洁高效**：不引入额外网络参数或专用世界模型头，复用 VLA 主干 Transformer 的序列建模能力。
- **通用性强**：适用场景广泛——视角变化、语义场景变化、机器人形态变化，均可通过统一探测策略处理。

## 8. 不足与局限

- **某些 OOD 视角效果有限**：如 135° 视角下所有方法成功率很低，ICWM 虽有提升但仍不理想，可能源于该视角固有的物体遮挡或工作空间可见性不足。
- **依赖探测阶段的时间开销**：虽然仅 5-6 秒，但在需要频繁更换配置（如移动机器人）或多任务连续切换时可能累积。
- **探测策略仍需手动指定安全工作空间**：虽然可通过正运动学自动推导，但在非结构化环境中可能受限。
