## 摘要
视觉-语言-动作（VLA）模型已成为具身人工智能的重要范式。然而，现有VLA模型通常假设光照良好且稳定的室内环境，而真实世界的具身操作可能涉及由光照变化引起的退化RGB观测，这给鲁棒的机器人操作带来了关键挑战。为了解决这一问题，我们提出了Event-VLA，一种事件增强的VLA框架，用于在不同光照条件下进行泛化操作。我们将退化可见性下的VLA操作问题形式化为以RGB为中心策略的实用鲁棒性问题，并引入事件流作为一种对光照鲁棒、对运动敏感的补充观测，以提高不同可见度水平下的鲁棒性。具体地，与直接将事件特征合并到全局语义令牌空间中的传统多模态融合不同，Event-VLA通过动作查询路由路径注入事件信息。它使用可学习的动作查询从VLA推理过程中提取任务相关语义，并通过门控交叉注意力选择性聚合事件令牌，以构建事件感知的动作表示。这种设计保留了预训练的RGB-语言语义先验，同时有效利用事件信息进行鲁棒的动作预测。在仿真和真实世界部署中的实验表明，Event-VLA在正常光照下保持强大的操作性能，并在低光照退化及近乎黑暗的真实环境中提高了成功率。

## Abstract
Vision-Language-Action (VLA) models have become an important paradigm of embodied AI. However, existing VLA models typically assume well-lit and stable indoor settings, while real-world embodied manipulation may involve degraded RGB observations caused by illumination shifts, posing critical challenges for robust robotic manipulation. To address this gap, we propose \textbf{Event-VLA}, an event-enhanced VLA framework for generalizable manipulation across varying illumination conditions. We formulate VLA-based manipulation under degraded visibility as a practical robustness problem for RGB-centric policies, and introduce event streams as an illumination-robust, motion-sensitive complementary observation to improve robustness across visibility levels. Specifically, unlike conventional multimodal fusion that directly merges event features into the global semantic token space, Event-VLA injects event information through an action-query routing pathway. It uses learnable action queries to extract task-relevant semantics from the VLA reasoning process, and selectively aggregates event tokens via gated cross-attention to construct event-aware action representations. This design preserves the pretrained RGB-language semantic priors while effectively leveraging event information for robust action prediction. Experiments in simulation and real-world deployment show that Event-VLA maintains strong manipulation performance under normal lighting and improves success rates under low-light degradation and near-dark real-world settings.

## 2. 方法论：核心思想与关键技术细节

**核心思想**：语义上下文应由预训练VLA建模，事件特征应在受控方式下注入动作通路，而非直接合并到全局语义令牌空间。

**技术细节**：

- **PREI（Physical Residual Event Integration）**：将异步事件流转化为紧凑的物理残差图，包含三个通道：
  - 瞬时通道（Instantaneous）：强调近期局部变化（短衰减常数）
  - 显著通道（Salient）：突出局部突出活动（较长衰减常数，局部归一化）
  - 持久通道（Persistent）：保留全窗口累积结构
  公式使用带指数衰减的活动图、平滑和归一化函数。

- **事件编码器与特征蒸馏**：事件编码器将PREI映射为VLA兼容的事件令牌（全局令牌+空间令牌）。通过冻结的视觉教师（DINO分支）进行特征级蒸馏，对齐RGB-事件特征空间（使用N-ImageNet和v2e生成的LIBERO合成对）。

- **动作条件事件接口**：
  1. VLM输入包含RGB、语言、本体感知、动作占位符及可学习查询令牌（公共查询、动作查询、事件查询）。
  2. VLM骨干输出上下文化隐藏状态，事件令牌不送入VLM，而是通过门控交叉注意力与VLM隐藏状态融合。
  3. 门控机制计算融合门Γ，产生融合隐藏状态。
  4. 查询引导路由将融合令牌分为动作相关令牌（路由到动作头）和事件相关令牌（路由到辅助事件头）。
  5. 动作头预测未来动作块；事件头预测未来PREI目标作为辅助正则化。

- **训练目标**：主损失为动作L1损失；辅助损失包括未来PREI重建损失（带内容掩码）和一阶导数一致性损失。总损失为三者加权和。

   - PREI表示紧凑、多时间尺度、物理意义明确，比传统时间表面更优。
   - 门控交叉注意力+查询引导路由实现受控融合，延迟低、效果好。

   - 仿真与真实部署相互印证，真实环境使用真实事件相机。

3. **可复现性与效率**：
   - 使用开源模型（OpenVLA）、公开模拟器（v2e）、公开数据集（LIBERO），便于复现。

## 8. 不足与局限

1. **模拟器偏差**：LIBERO-Cross依赖RGB-to-event模拟器（基于v2e），可能无法完全反映真实事件相机的噪声、触发动态和校准误差。尽管论文进行了一些验证，但仍存在模拟-现实差距的风险。

2. **真实世界评估规模有限**：仅4个任务、3种光照条件、每条件10次试验，统计显著性有限。缺乏多物体、多环境、长时域任务的广泛验证。

3. **适用范围限制**：主要针对光照退化（低光/近暗），未研究其他视觉退化（如运动模糊、遮挡、传感器噪声）下的鲁棒性。这些场景事件相机也可能提供互补信息。

4. **硬件依赖**：需要额外的事件相机硬件与同步系统，增加了部署复杂性、成本和标定难度。

5. **仅限于抓取/操作任务**：未在导航、移动操作等更广泛具身任务上验证。

6. **事件信号稀疏性**：在真实场景中，若目标物体与背景对比度低、相对运动小，事件响应可能不足，导致事件信息无法有效利用（论文真实世界失败案例也反映了这一点）。
