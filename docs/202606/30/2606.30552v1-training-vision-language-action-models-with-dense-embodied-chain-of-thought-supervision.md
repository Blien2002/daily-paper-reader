## 摘要
跨本体迁移在视觉-语言-动作（VLA）模型中仍然具有挑战性，因为不同机器人平台的低层次状态和动作空间从根本上存在差异。我们观察到，操作背后的高层次认知过程，包括场景感知、物体识别、任务规划和子任务分解，在不同本体之间是高度共享的。基于这一观察，我们提出了ZR-0，一个拥有26亿参数的端到端VLA模型，它使用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨本体表示。ZR-0采用双流架构：一个预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而一个基于扩散Transformer的动作专家（系统1）通过流匹配生成连续的动作片段。这两个组件通过交叉注意力耦合，并采用一个注意力掩码，限制动作专家仅关注输入提示特征，从而可以在推理时完全跳过ECoT生成而不损失任何性能。ZR-0在ProcCorpus-60M上进行了预训练，这是一个大规模数据集，包含来自超过40万条轨迹的大约6000万帧（约1000小时），密集的ECoT注释覆盖了96.8%的帧。我们在三个模拟基准上评估了ZR-0，涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和类人（RoboCasa GR-1 Tabletop）本体，以及在xArm平台上的真实世界实验，展示了在所有设置中的强大性能。代码和模型检查点可在https://github.com/RUCKBReasoning/ZR-0获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

## 1. 核心问题与整体含义（研究动机与背景）
- **问题**：跨本体迁移（cross-embodiment transfer）在VLA模型中面临根本性挑战，因为不同机器人平台的底层状态/动作空间（如自由度、控制接口、传感器）存在差异，现有方法（如零填充、归一化、统一维度语义分配）仅停留在格式层面，未能真正实现语义对齐。
- **关键洞察**：虽然底层动作空间是本体特异的，但高层次认知过程（场景感知、物体识别、任务规划、子任务分解）在不同本体间高度共享。**具身思维链（Embodied Chain-of-Thought, ECoT）** 能够以本体无关的方式捕捉这种共享推理，从而作为跨本体表示对齐的桥梁。
- **整体目标**：提出ZR-0模型，通过密集ECoT监督训练VLM，使其学习到可迁移的本体无关表示，再通过动作专家生成具体动作，实现跨本体泛化。

## 2. 方法论：核心思想、关键技术细节
### 2.1 核心思想
- 采用 **System 1 / System 2** 双流架构：
  - **System 2**（预训练VLM，Qwen3-VL-2B）：处理任务指令和图像观测，在训练时生成结构化ECoT序列（场景描述、进度评估、未来计划、待办子任务、目标框、离散动作token），提供密集监督信号。
  - **System 1**（基于Diffusion Transformer的动作专家）：通过流匹配（flow matching）生成连续动作块（chunk size H）。
- 两个系统通过 **交叉注意力** 连接，并设计 **注意力掩码**：限制动作专家只关注VLM的输入提示特征（任务指令+图像），**忽略ECoT token**，从而在推理时可完全跳过ECoT的自动回归生成，不增加延迟。

### 2.2 关键技术细节
- **VLM（System 2）**：从Qwen3-VL-2B-Instruct初始化，输入多视图图像（224×224），输出最后一层隐藏状态作为动作专家的条件特征。
- **动作专家（System 1）**：DiT结构，包含状态编码器、动作编码器、一组DiT块（自注意+3个交叉注意层）、动作解码器。动作和状态token在自注意中双向融合，在交叉注意中以VLM特征为K/V。
- **训练目标**：
  - **ECoT下一token预测损失** \( \mathcal{L}_{\text{ntp}} \)：仅更新VLM参数。
  - **流匹配损失** \( \mathcal{L}_{\text{fm}} \)：预测去噪向量场 \( A_t - \epsilon \)，使用Beta(1.5,1.0)采样时间步 \( \tau \)，梯度同时更新动作专家和VLM。
  - 总损失 \( \mathcal{L} = \mathcal{L}_{\text{ntp}} + \alpha \mathcal{L}_{\text{fm}} \)，预训练时 \( \alpha=5 \)，后训练时 \( \alpha=1 \)。
- **推理**：从高斯噪声初始化动作块，通过前向欧拉积分迭代去噪N步，无需生成ECoT文本。单个A6000 GPU上约90ms/动作块。
- **ECoT组成**：6个组件——场景描述、进度评估、未来计划、待办动作（动词+宾语+介词短语，本体无关）、目标物体边界框、离散动作token（FAST tokenizer）。覆盖96.8%帧。

## 6. 主要结论与发现

## 7. 优点：方法与实验亮点

## 8. 不足与局限
- **预训练数据规模有限**：仅约1000小时，远小于π0（>10k小时）、LingBot-VLA（~20k小时）、Qwen-RoboManip（>30k小时），导致某些稀疏技能（如关门、关抽屉）性能较差。

- **缺乏小样本或零样本跨本体迁移实验**：所有实验均在同一本体上微调后进行泛化，并未直接测试预训练模型在新本体上的零样本迁移。
- **注意力掩码的潜在风险**：推理时完全丢弃ECoT特征，虽然不损失性能，但若ECoT生成内容对构建上下文很重要，这种设计可能限制模型对复杂长尾指令的响应。
