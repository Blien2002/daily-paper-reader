## 摘要
世界动作模型（WAM）已成为具身智能的一种强大的新范式，学习与动作相关的视觉动态，显著提升了泛化性和鲁棒性。然而，现有的WAM在处理长时程机器人操作中的任务相关记忆方面仍然存在困难。为此，我们提出了HiMem-WAM，一种分层记忆门控世界动作模型，它整合了以运动为中心的潜在动作、高级技能潜在变量以及边界触发的记忆更新。具体来说，我们开发了一个分层潜在动作框架，联合学习低级运动和高级技能潜在变量，提供了结构化的时间抽象。同时，一个边界感知记忆门在预测的技能转换处写入紧凑的任务状态，使得无需在测试时生成未来视频或光流估计即可进行因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM的分层潜在变量提高了部署扰动下的鲁棒性，并且记忆模块显著有利于记忆依赖的长时程操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

- **核心问题**：现有的世界动作模型（World Action Models, WAM）虽然通过未来预测或潜在动力学建模提升了机器人操作的泛化性和鲁棒性，但在长时程（long-horizon）操作任务中缺乏任务相关的记忆能力。机器人需要记住被遮挡的子任务状态或部分完成后的适应，而现有方法要么依赖密集的历史聚合（如固定窗口），要么需要测试时的视频生成或光流估计，导致效率低下或因果性不足。
- **背景与动机**：视觉-语言-动作模型（VLA）虽通过大规模预训练取得进展，但其端到端动作预测对部署扰动（如光照变化、视角偏移）鲁棒性差，且难以维持长历程的任务历史。WAM通过学习动作相关的视觉动力学提供了更好的动态先验，但同样面临记忆瓶颈。现有工作如MotuBrain、LingBot-VA等尝试通过统一视频-动作架构或验证驱动自适应执行来增强长程操作，但仍未明确解决低级运动到高级技能的分层抽象以及跨技能边界的显式记忆保留问题。
- **整体含义**：HiMem-WAM通过引入层级潜在动作框架和记忆门控模块，将低级运动原语组织成可复用的技能，并在技能边界处稀疏地写入紧凑任务状态，从而在保持因果推理的前提下提升长时程操作中的记忆跟踪和鲁棒性。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将策略分解为三个层级——高级技能潜在变量（skill latent）、低级潜在动作块（low-level latent action chunk）和具体执行动作，并利用边界感知的记忆门控机制在技能转换时选择性存储任务状态。
- **关键技术细节**：
  - **三阶段训练管道**：
    - **阶段 I：低级潜在动作分词器训练**。使用多视图光流（DPFlow）编码短时上下文，通过变分分词器学习紧凑的潜在动作空间，并可选地利用动作标签进行弱对齐。训练完成后冻结，离线提取所有轨迹的低级潜在序列 Zl。
    - **阶段 II：层级潜在动作预训练**。对 Zl 进行层次化分块，通过边界预测器和注意力池化发现技能边界，得到高级技能潜在序列 Zh 和逐时间步的伪标签（技能目标和边界标签）。然后预训练规划器（使用 Qwen3-VL-4B-Instruct）和执行器，在无记忆条件下预测高级技能和低级潜在块。
    - **阶段 III：记忆门控模块微调**。启用外部记忆库，读门控从记忆中检索上下文以增强状态表示，写门控根据预测的边界分数（αwt > η 时）决定是否写入紧凑记忆令牌。写门控受技能边界标签监督，并加入稀疏正则化。整个策略通过动作预测损失、层级潜在损失、边界损失和门控损失联合微调。
  - **推理流程**：仅使用当前 RGB 观测、本体感觉、语言指令和记忆库。先读取记忆获得增强状态，规划器预测当前技能和边界分数，执行器展开低级潜在块，动作解码器映射到可执行动作，当写门控超过阈值时写入新记忆。完全因果，无需未来视频生成或光流估计。
- **公式推导**（文字说明）：
  - 策略分解为三个条件概率分布的积分：从动作到低级潜在块、从低级潜在块到高级技能、从高级技能到观测/语言/记忆。
  - 低级分词器训练损失包括光流重建损失、动作对齐损失（有标签时）和 KL 散度。
  - 技能发现损失包括下个潜在预测损失、运动语义损失（通过冻结的流解码器）、边界比例损失和段内一致性损失。
  - 阶段 II 预训练损失为技能、潜在块和边界分数的 MSE/BCE。

## 3. 实验设计：数据集/场景、Benchmark、对比方法

- **仿真实验**：
  - **LIBERO**：包含空间、物体、目标和长时程四个子集，评估语言条件操作。

  - **RMBench**：评估记忆依赖操作，分为 M(1)（单次记忆）和 M(n)（多次记忆）两类任务。
- **真实世界实验**：

  - 评估设置：标准（ST，场景干净）和泛化（GE，引入物体位置、干扰物、布局、光照、指令扰动）。
