## 摘要
视觉-语言-动作（VLA）策略已实现显著的单步操作，但它们在每一步依赖于前一步完成结果的关键环节上仍然脆弱。核心问题在于结构性的：短窗口VLA缺乏一个明确的通道来跨子任务边界传递信息，而现有的记忆增强变体要么每帧写入、从演示时间阶段检索，要么在子目标事件触发时执行动作，但没有将明确的子任务间交接传递给动作专家。我们将子目标完成事件识别为跨子任务记忆交接的自然时间单元，并提出了WeaveLA（为视觉-语言-动作策略编织潜在记忆），这是一种跨子任务记忆接口，在冻结的VLA骨干之上，通过查询驱动的注意力池化将每个已完成的段压缩为潜在令牌，并直接将它们路由到下一个子任务的动作生成路径中。这种事件触发、动作侧的设计保留了基础策略的短窗口接口，同时增加了一个轻量级的跨子任务通道。通过在RoboMME上使用π_{0.5}骨干进行分层评估，WeaveLA的增益恰好出现在需要该通道的地方：在难度最高的重复片段（SwingXtimes，N=3）上，成功率从0%提升至47.8%，而单次执行片段保持不变。每集配对分析确认，增益仅限于那些因果结构需要跨子任务信息的任务。

## Abstract
Vision-Language-Action (VLA) policies have achieved remarkable single-step manipulation, yet they remain brittle precisely where each stage depends on what was just completed. The core issue is structural: short-window VLAs lack an explicit channel for rouxting information across sub-task boundaries, and existing memory-augmented variants either write at every frame, retrieve from demonstration-time stages, or fire at sub-goal events without performing an explicit sub-task-to-sub-task hand-off into the action expert. We identify the sub-goal completion event as the natural temporal unit for cross-subtask memory hand-off, and present WeaveLA (Weave Latent memory for Vision-Language-Action policies), a cross-subtask memory interface that, on top of a frozen VLA backbone, compresses each completed segment into latent tokens via query-driven attention pooling and routes them directly into the action-generation path of the next sub-task. This event-triggered, action-side design preserves the base policy's short-window interface while adding a lightweight cross-subtask channel. Through stratified evaluation on RoboMME with a $π_{0.5}$ backbone, WeaveLA's gains land exactly where the channel is needed: on the hardest repetition slice (SwingXtimes, $N{=}3$), success rises from $0\%$ to $47.8\%$, while single-execution episodes remain unchanged. Per-episode paired analysis confirms the gains are confined to tasks whose causal structure requires cross-subtask information.

## 1. 核心问题与整体含义（研究动机和背景）
现有视觉-语言-动作（VLA）策略在**单步操作**上表现优异（如抓取、放置），但在**重复性操作**（如包装、装配、检测）中表现脆弱。其根本原因是：
- 短窗口VLA缺乏显式的**跨子任务信息传递通道**。
- 每一步的正确动作取决于上一步的完成状态（例如，需要知道“已经摆动了几次”才能决定下一步是继续摆动还是按停止按钮）。
- 现有的记忆增强方法要么每帧写入、要么从演示阶段检索，缺乏在**子任务完成事件**时刻进行显式交接的机制。

WeaveLA旨在解决这一结构性缺陷，提供一个轻量、事件驱动的跨子任务记忆接口，在不影响单次操作能力的前提下，显著提升重复性操作的成功率。

## 2. 提出的方法论
### 核心思想
- 将**子目标完成事件**作为记忆写入的自然时间单元。
- 在此事件时，使用**查询驱动的注意力池化**（Query-driven Attention Pooling）将刚完成的子任务段压缩为**固定大小的潜在令牌**（8个令牌，维度2048）。
- 将这些潜在令牌直接注入**下一个子任务的动作生成路径**（动作侧），而非语言提示或视觉上下文，以保证信息不被稀释。

### 关键技术细节
1. **子目标事件触发器**：只在子任务完成时触发写入，不每帧写入。训练时使用模拟器提供的子目标边界；推理时可使用自监督的潜在偏移检测器替代。
2. **查询驱动记忆编织器（Query-driven Memory Weaver）**：
   - 从已完成的段中提取视觉、文本和状态特征，拼接后通过8个可学习查询令牌进行单步注意力池化（Eq.1）：
     \[
     A = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_h}}\right), \quad m_{k-1} = W_{\text{out}}(A V + Q)
     \]
   - 输出固定维度的潜在记忆 \(m_{k-1}\)。
3. **动作侧记忆消费**：在π₀.₅的Gemma动作专家中插入第三个AdaRMS调制模块，使动作生成时能够通过交叉注意力访问记忆令牌，从而影响尺度/偏移参数。
4. **三阶段训练策略**：
   - Stage 0：任务适应（仅动作损失）。
   - Stage 1：记忆预热（K=2多子任务窗口，仅动作损失）。
   - Stage 2：完整训练（K∈{2,3,4}，添加语义对齐和对比损失）。
   - 分阶段训练防止记忆表征塌陷（如`weaver_latent_norm`指标所诊断的）。

### 公式/算法流程（文字说明）
- 主要损失为流匹配动作损失 \( \mathcal{L}_{\text{action}} \) ，辅助损失包括记忆-文本对齐损失 \( \mathcal{L}_{\text{align}} \) 和记忆对比损失 \( \mathcal{L}_{\text{ctr}} \)。

## 6. 主要结论与发现
- **增益精准定位**：WeaveLA的提升仅出现在需要跨子任务信息的任务上（SwingXtimes和StopCube），单次执行（N=1）成功率不变。
- **最强结果**：SwingXtimes N=3从0%提升至47.8%（6-task训练）；16-task训练也从4%升至30%。
- **轻量且即插即用**：仅增加1.4%参数，不改变基础策略的短窗口接口。
- **触发源可替换**：潜在偏移检测器在SwingXtimes上恢复68%的oracle差距（N=3从4%到21.7%），无需外部监督。
- **Q-Former不稳定**：导致超时率高，成功率降至3.5%。
- **真实机器人验证**：PickXtimes N=3从45%提升至70%。

## 7. 优点
- **机制对齐**：增益仅出现在需要跨子任务信息的场景，而非通用能力提升，证明方法针对问题设计。
- **轻量高效**：只训练1.4%参数，事件驱动写入（非每帧），推理成本极低。
- **即插即用**：可叠加在冻结的VLA骨干上，不破坏原策略在其他任务上的能力。
- **训练稳定性**：分阶段训练有效防止记忆表征塌陷，并提供诊断指标。
- **触发源可替代**：自监督潜在偏移检测器可取代oracle边界，提升了实用性。
- **实验全面**：覆盖多种维度的消融和分层分析，统计证据充分。

## 8. 不足与局限
- **Q-Former提取器不稳定**：导致训练失败，无法解释；未来需分析其原因。
- **潜在偏移触发在StopCube上失效**：仅2%（对比oracle 12%），符号计数任务仍需外部边界检测器。
- **未与输入侧优化（如FrameSamp）组合**：可能可进一步提升性能，但尚未实验。
- **真实机器人实验规模小**：仅20个episode/条件，需更大规模验证。
- **依赖训练时的子目标标注**：虽然推理时可替换，但训练仍需模拟器或人工标注。
