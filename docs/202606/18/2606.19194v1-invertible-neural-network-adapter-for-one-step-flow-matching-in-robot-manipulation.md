## 摘要
本文提出了一种通用机器人操作的可逆神经网络适配器，旨在通过单步去噪过程生成基于多模态观测（包括视觉、语言和本体感受输入）的精确高维动作。该适配器基于流匹配公式，将动作生成轨迹有效约束在可逆潜空间内，从而只需一次推理步骤即可实现高效、高质量的灵巧动作合成。与传统的迭代流匹配策略相比，所提框架在保持强动作预测精度和稳定性的同时，大幅降低了推理复杂度。通过在多样化的仿真基准和真实机器人平台上进行广泛实验，评估了所提方法的有效性。在仿真基准上，所提适配器在广泛的操作任务中持续展现出优于或接近最先进的性能。此外，真实世界实验表明，视觉-语言-动作（VLA）模型的推理效率显著提升，平均推理延迟从110毫秒降至61毫秒，同时保持强大的任务性能。

## Abstract
This paper presents an invertible neural network adapter for general robotic manipulation, designed to generate precise high-dimensional actions conditioned on multimodal observations, including visual, linguistic, and proprioceptive inputs, through a one-step denoising process. Built upon a flow-matching formulation, the proposed adapter effectively constrains the action generation trajectory within an invertible latent space, thereby enabling efficient and high-quality dexterous action synthesis with only a single inference step. Compared with conventional iterative flow-matching policies, the proposed framework substantially reduces inference complexity while maintaining strong action prediction accuracy and stability. Extensive experiments are conducted across a diverse set of simulation benchmarks and real-world robotic platforms to evaluate the effectiveness of the proposed method. Across simulation benchmarks, the proposed adapter consistently demonstrates superior or near state-of-the-art performance on a wide range of manipulation tasks. Furthermore, real-world experiments reveal a significant improvement in inference efficiency for vision-language-action (VLA) models, reducing the average inference latency from 110 ms to 61 ms while maintaining strong task performance.

## 1. 核心问题与整体含义（研究动机和背景）

机器人操作任务需要生成可靠的、高维的、灵巧的动作，尤其在非结构化环境中。近年扩散策略和流匹配方法在策略学习中取得成功，但现有流匹配策略在复杂真实操作场景中存在效率、鲁棒性和泛化性的局限：
- 难以准确捕捉多指互动的细粒度动力学；
- 难以维持长序列动作的时间一致性；
- 缺乏整合多模态观测（视觉、语言、本体感受）的机制；
- 传统迭代式去噪（如10步）导致推理延迟高，不适应实时控制。

现有单步生成方法（如ManiFlow、Mean Flow）通过引入辅助损失项近似一步生成，但在部署时可能偏离真实平均速度场，导致鲁棒性和泛化性下降。本文旨在设计一种可逆神经网络适配器，将流匹配的速度场约束在可逆潜空间中，实现既高效（单步）又准确的动作生成。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 利用可逆神经网络（INN）的**双射特性**，将流匹配单步预测的动作映射到一个结构化潜空间，再进行归一化和逆映射，从而在保持信息不丢失的同时修正预测误差。
- 通过潜空间中的归一化操作（映射到球面）约束表示，使学到的速度场更忠实于真实分布。

### 关键技术细节
1. **流匹配基线**：给定噪声样本 \(x_0 \sim \mathcal{N}(0,I)\)、数据样本 \(x_1 \sim D\)、时间 \(t \sim U[0,1]\)，定义插值状态 \(x_t = (1-t)x_0 + t x_1\)，对应的速度为 \(v_t = x_1 - x_0\)。模型 \(v_\theta(x_t, t)\) 通过均方误差训练。
2. **可逆神经网络（INN）**：使用耦合层实现可逆变换——将输入分成两部分，一部分保持不变，另一部分通过函数变换（加性耦合）。逆变换可闭式计算，雅可比行列式为1，易于训练。
3. **适配器流程**（图1）：
   - 给定观测 \(o\)，流匹配模型预测速度 \(v(x_t, t|o)\)，单步去噪得到 \(\hat{x} = x_t + (1-t)v(x_t, t|o)\)。
   - 将 \(\hat{x}\) 送入INN的前向变换得到 \(y = g(\hat{x})\)。
   - 潜空间归一化：\(\tilde{y} = y / \|y\|_2\)。
   - 再通过INN的逆变换得到最终动作：\(x_{\text{pre}} = g^{-1}(\tilde{y})\)。
4. **损失函数**：
   - 适配器损失：同时在数据空间和潜空间优化重建误差，保证前后一致性：
     \[
     L_{\text{adapter}}(\theta) = \mathbb{E}\left[\|x_{\text{pre}}(x_t, t) - x_1\|^2 + \|\tilde{y}(x_t, t) - g(x_1)\|^2\right]
     \]
   - 总损失：\(L(\theta) = L_{\text{adapter}}(\theta) + \alpha L_{\text{FM}}(\theta)\)，其中 \(\alpha>0\) 为平衡超参数。
