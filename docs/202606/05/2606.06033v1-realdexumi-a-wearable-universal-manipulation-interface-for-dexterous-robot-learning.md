## 摘要
学习灵巧操作需要保留精细的手-物体交互的演示，同时在部署时保持可执行性。现有流程要么通过重定向或具身转换损失了可部署的灵巧性，要么依赖于特定机器人的遥操作，这种方式扩展成本高，且通常缺乏直观、接触感知的灵巧数据收集控制。我们提出了RealDexUMI，这是一种基于共享灵巧末端执行器模块构建的可穿戴通用操作接口，集成了轻量级灵巧手、手内视觉和指尖触觉感知。手掌侧同构遥操作手套将人类手指输入映射到机器人手关节指令，实现实时、无重定向、直观且精确的手部控制。共享的手和感知模块产生零间隙的末端执行器数据，在采集和部署之间具有匹配的手内观察、触觉信号、接触和手部动作。跨越八个真实机器人任务，涵盖细粒度、接触密集、长时域和双臂操作，基于RealDexUMI数据训练的模型实现了88.75%的平均成功率，泛化到未见过的初始姿态，并在三种具身上迁移。网站：https://research.beingbeyond.com/realdexumi

## Abstract
Learning dexterous manipulation requires demonstrations that preserve fine hand-object interactions while remaining executable at deployment. Existing pipelines either lose deployable dexterity through retargeting or embodiment conversion, or rely on robot-specific teleoperation that is costly to scale and often lacks intuitive, contact-aware control for dexterous data collection. We present RealDexUMI, a wearable universal manipulation interface built around a shared dexterous end-effector module that integrates a lightweight dexterous hand, in-hand vision, and fingertip tactile sensing. A palm-side isomorphic teleoperation glove maps human finger inputs to robot-hand joint commands, enabling real-time, retargeting-free, intuitive, and precise hand control. The shared hand and sensing modules yield zero-gap end-effector data, with matched in-hand observations, tactile signals, contacts, and hand actions between collection and deployment. Across eight real-robot tasks spanning fine-grained, contact-rich, long-horizon, and bimanual manipulation, policies trained on RealDexUMI data achieve an average success rate of 88.75%, generalize to unseen initial poses, and transfer across three embodiments. ### 2. 论文提出的方法论
- **核心思想**：使用一个可穿戴的通用操作接口，其核心是**共享的灵巧末端执行器模块**（轻量级灵巧手+手内相机+指尖触觉传感器），配合**手掌侧同构遥操作手套**，使人手输入直接映射为机器人手关节命令（无重定向），实现实时、直观、精确的控制。
- **关键技术细节**：
  - **灵巧手模块**：11自由度（每个手指1个主动+1个被动屈曲自由度，拇指额外1个主动外展/内收），6个主动自由度由伺服驱动蜗轮传动，轻质聚碳酸酯外壳，指尖集成压阻式触觉阵列。
  - **同构手套**：6个自由度由绝对磁编码器测量，直接对应灵巧手的6个主动自由度，线性映射；被动自由度机械镜像手的被动屈曲自由度。弹簧复位，初始化校准后即可使用。
  - **数据采集**：记录手内RGB、指尖触觉、手部状态（位置）、手部命令（来自手套）、6DoF追踪器位姿。追踪器位姿仅用于构建手部参考系下的**相对运动标签**，不进入观测。每个时间步的动作标签为：
    ```
    a_{t,k} = [Δp_{t,k}, Δr_{t,k}, u_{t+k}^{hand}]
    ```
    其中 ΔT_{t,k} = T_t^{-1} T_{t+k} 是手部参考系下的相对变换，u_{t+k}^{hand} 是手套采集的可执行手关节命令。
  - **策略接口**：观测 o_t = (I_t ∈ R^{256×256×3}, S_t^{tactile} ∈ R^{5×10×4}, q_t^{hand} ∈ R^6)。动作空间为未来C步的 chunk 预测：Î_t = π_θ(o_t) = {â_{t,1}, ..., â_{t,C}}。
  - **部署**：仅需更改机器人侧的逆运动学（IK）和底层控制器，策略和末端执行器模块不变。预测的相对动作应用到当前机器人手部位姿得到目标位姿。
- **算法流程**：使用 ACT（Action Chunking with Transformers）作为主要策略，扩散策略（Diffusion Policy）作为基线对比。给定观测，预测固定长度动作序列，通过动作分块执行。

### 6. 论文的主要结论与发现
- **主要结论**：RealDexUMI作为可穿戴灵巧操作接口，能够生成可直接部署的高质量演示数据，训练的策略在8项真实任务上平均成功率达到**88.75%**。

  - 采集效率对比显示RealDexUMI在成功率与时间上均优于AVP和Manus手套重定向。

### 8. 不足与局限
