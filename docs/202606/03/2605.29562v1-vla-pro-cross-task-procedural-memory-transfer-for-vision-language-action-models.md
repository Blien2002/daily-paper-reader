## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出巨大潜力，但在泛化到未见任务时仍存在困难，这些任务需要在不同物体、场景和动作模式之间迁移相关经验。本文提出VLA-Pro，这是一个即插即用的框架，旨在通过在训练时存储任务相关的程序记忆并在推理时迁移这些记忆来增强跨任务泛化能力。具体而言，VLA-Pro在训练时将任务特定的LoRA适配器存储为参数化的程序记忆。在推理时，VLA-Pro基于当前多模态上下文检索相关程序记忆，并动态融合这些记忆以生成当前动作片段。在RoboTwin、RLBench和真实世界操作任务上的实验表明，VLA-Pro在多个骨干网络上持续提升了跨任务泛化能力，在仿真中实现了高达207%的相对改进，并将真实世界的成功率从5.8%提升至65.0%。这些结果表明，程序记忆检索与适应为将操作经验迁移到新任务提供了一种有效机制，同时保持了模块化和执行稳定性。

## Abstract
Vision-Language-Action~(VLA) models have shown strong potential for general-purpose robotic manipulation, yet they still struggle to generalize to unseen tasks that necessitate transferring relevant experience across objects, scenes, and action patterns. This paper proposes VLA-Pro, a plug-and-play framework designed to enhance cross-task generalization by storing task-relevant procedural memories at training time and transferring these memories during inference. Specifically, VLA-Pro stores task-specific LoRA adapters as parameterized procedural memories during training. At inference time, VLA-Pro retrieves relevant procedural memories based on the current multi-modal context and dynamically fuses these memories for generating the current action chunk. Experiments on RoboTwin, RLBench, and real-world manipulation tasks show that VLA-Pro consistently improves cross-task generalization across multiple backbones, achieving up to a 207% relative improvement in simulation and increasing real-world success rate from 5.8% to 65.0%. These results suggest that procedural memory retrieval and adaptation provide an effective mechanism for transferring manipulation experience to novel tasks while preserving modularity and execution stability.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究问题**：当前 Vision-Language-Action (VLA) 模型虽然在多种日常和工业操作任务中取得了显著进展，但**跨任务泛化能力严重不足**。它们经常无法适应那些涉及新物体、新场景的未见任务，即使这些任务在语义或物理上与训练任务相似。模型往往过拟合于训练中高频出现的轨迹分布和操作模式，例如默认“抓取直立瓶子”而非“抓取平躺瓶子”。

- **动机来源**：人类具有强大的**程序记忆**（procedural memory）机制，能够隐式地利用过往经验。例如，抓取平躺瓶子时，人类会回忆起抓握类似圆柱形平躺物体（如麦克风、折叠伞）的物理感觉。而且，回忆特定任务记忆可以对抗高频动作的执行偏差。受此启发，论文提出让 VLA 模型具备可检索、可重用的程序记忆。

- **现有方法的不足**：现有提升VLA适应性的方法分为两类：
  - **架构重构**（如AtomicVLA的MoE、MemoryVLA的双流缓存）：依赖于固定的结构先验，无法将程序性经验内化为可检索、可执行的模型参数。
  - **上下文提示**（如X-ICM拼接任务演示文本）：依赖固定先验或上下文条件，未能将程序经验内化为可检索、可执行的模型参数。

- **本文目标**：提出VLA-Pro，一种**即插即用**框架，在训练时存储任务特定LoRA适配器作为参数化程序记忆，在推理时根据当前多模态上下文检索和动态融合这些记忆，从而将相关操作经验迁移到新任务，同时保持模块化和执行稳定性。

## 2. 方法论

### 核心思想
- VLA-Pro 将每个历史任务的经验表示为**程序记忆** `M_i = (D_i, Δθ_i)`，其中:
  - `D_i` 是该任务的结构化程序状态序列（表示执行阶段）。
  - `Δθ_i` 是该任务对应的 LoRA 适配器（参数化经验）。
- 推理时，通过**当前程序状态提取** -> **跨任务记忆检索**（基于动作感知的语义匹配） -> **记忆融合与适配**（参数加权求和），动态注入相关记忆到预训练 VLA 骨干中，生成当前动作块。

### 关键技术细节
1. **程序状态定义**：每个执行阶段被抽象为结构化状态 `z = {a, o, e, p}`:
   - `a`：当前动作类型（如 pick, place, press...）
   - `o`：物体的几何属性（如 cuboid, lying_cylindrical...）
   - `e`：末端执行器朝向（如 vertical, horizontal）
   - `p`：目标交互点（如 front, center, rim...）
   - 自由的 subtask 字段仅用于可读性，不参与相似度计算。

2. **基座 LoRA 准备**：先在所有已见任务上联合训练一个**共享基座适配器** `Δθ_base`，再为每个任务从 `Δθ_base` 微调出任务特定适配器 `Δθ_i`。

3. **当前程序状态提取**：
   - 使用强视觉语言模型（如 Gemini-3-Flash）作为**程序状态提取器**，根据当前观察、完整指令和交互历史（去重）推断当前阶段的结构化状态 `ẑ_t`，输出限定为结构化 JSON 格式。

4. **动作感知程序匹配**：
   - 检索时，对每个已见任务 i，将当前状态 `ẑ_t` 与该任务的状态序列 `D_i` 中的每个状态计算匹配分数，取最大值作为任务级相关性 `s_i`。
   - 匹配采用**动作感知加权**：根据当前动作类型调整 `{a, o, e, p}` 各字段的权重。例如，当动作为 `pick` 时，强调物体几何属性 `o`（权重 0.35）；为 `place` 时强调目标交互点 `p`（权重 0.35）。
   - 使用余弦相似度计算各字段文本嵌入的相似度。

5. **Top-k 检索与融合**：
   - 选出相似度最高的 top-k 个源记忆（索引集 `K_t`）。
   - 将 top-k 相似度经过 Softmax 归一化得到融合权重 `α_j`。
   - 对检索到的 LoRA 适配器进行参数级加权求和：`Δθ_fused_t = Σ_{j∈K_t} α_j Δθ_j`。
   - 将融合适配器动态加载到预训练 VLA 骨干上（临时策略），执行当前动作块后卸载，模型恢复基座状态，然后进入下一阶段。

### 算法流程（简述）
1. **训练阶段**：在已见任务上训练基座 LoRA → 为每个已见任务微调任务特定 LoRA，并提取其程序状态序列，构成记忆库。
2. **推理阶段**（每个动作块）：
   - 提取当前程序状态 `ẑ_t`。
   - 从记忆库中检索 top-k 最相关记忆。
   - 计算融合权重，合并得到 `Δθ_fused_t`。
   - 加载融合适配器到骨干，执行动作块，然后卸载适配器。

## 6. 主要结论与发现

1. **跨任务泛化显著提升**：VLA-Pro 在所有骨干和平台上一致优于基座 LoRA 基线。
   - RoboTwin：X-VLA 平均成功率从 17.0%→30.0%（+76%），RDT 从 11.1%→34.1%（+207%），π0.5 从 40.4%→59.3%（+47%）。
   - RLBench：π0.5 基础上平均成功率从 13.8%→20.9%（+51%），优于 AtomicVLA（14.7%）和 RDT（10.2%）。
   - 真实世界：成功率从 5.8%→65.0%（+59 个百分点）。

2. **程序记忆减少高频执行偏差**：例如 `place_bell_behind` 任务，基线总是倾向于“放在展台上”（高频模式），VLA-Pro 通过检索正确空间记忆达到 100% 成功率。

3. **参数组件互补**：VLM-backbone 适配在零样本泛化强的任务（如 pick up cup）更有效，而动作专家适配在模式相似任务上更有效。两者联合最优。

4. **检索质量与性能正相关**：更好的检索器（Gemini vs Qwen）带来更高成功率；任务相似度越高，收益越大（线性斜率约 16.77）。

5. **Top-k 影响**：k=2 最优（RLBench 上平均 20.9%），过低（k=1）或过高（k=3）都会引入噪声或稀释有用信息。

6. **运行时开销低**：通过缓存嵌入和复用 LoRA，额外延迟较小（Gemini API 调用平均 2.591s，嵌入 0.235s），与动作块生成和执行相比可接受。

## 7. 优点

- **新颖性**：将人的程序记忆机制引入 VLA 模型，首次提出**参数化可检索程序记忆**，不同于以往的架构重设计或上下文提示。
- **即插即用**：与骨干网络解耦，可轻松应用于 π0.5、RDT、X-VLA 等现有模型，无需修改架构。
- **高效模块化**：LoRA 适配器存储和融合开销小，推理时动态加载/卸载，不干扰模型原始能力。
- **结构化状态设计**：动作感知匹配权重根据动作类型动态调整，使检索聚焦于当前子任务最相关的属性，提升匹配精度。
- **充分实验验证**：涵盖仿真和真实世界，多种骨干，多个消融，统计上可靠（30/25/20 次试验），且开源代码和网站，可复现性强。
- **理论到实践的桥接**：不仅提升性能，还提供了分析（如相似度-增益相关性，参数组件角色），增强了理解。

## 8. 不足与局限

- **依赖外部 VLM 性能**：程序状态提取器（Gemini-3-Flash）的质量直接影响检索和整体性能。若观察模糊、历史不完整，可能检索到不相关记忆，注入次优适配器。
- **记忆库规模有限**：当前仅从少量已见任务构建，限制了可复用的经验多样性。如何扩展到更大、更多样化的经验库尚待研究。
- **灵活性不足于人类**：VLA-Pro 主要依赖相似性检索和加权融合，不能像人类那样灵活地抽象、重组和适应跨不同上下文的能力。对需要深度组合推理或创造性适应的全新任务可能表现有限。
- **选择性报告风险**：在 RLBench 中只展示了 9 个非零成功率的零样本任务，其余 14 个可能被忽略，存在选择性报告偏差。
- **实时性考量**：虽然论文宣称额外延迟可接受，但在线推理时仍需调用外部 API（Gemini、文本嵌入），可能影响实时性要求高的场景。
- **真实世界任务数量较少**：仅 6 对训练/测试任务，泛化结论可能受限于场景多样性。
