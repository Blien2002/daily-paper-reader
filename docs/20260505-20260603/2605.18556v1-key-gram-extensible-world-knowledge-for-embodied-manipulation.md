## 摘要
具身控制日益要求模型在推理动态视觉状态的同时，遵循组合性语言指令。然而，当前的视觉-语言-行动策略和世界行动模型通常将语言知识与视觉计算耦合在共享主干或条件路径中，导致模态竞争，并使知识扩展依赖于主干更新。本文提出Key-Gram，一种将语言派生世界知识与视觉状态推理分离的具身控制条件记忆框架。其核心是一个记忆模块，将指令分解为任务特定的关键元组，通过确定性哈希查找检索静态语言先验，并通过上下文感知门控和轻量卷积融合将检索到的条目注入选定隐藏层。这种设计允许主干将主要能力用于视觉推理和行动推理，而可重复使用的指令知识存储于可扩展的外部记忆中。逻辑记忆表可在训练期间方便地分区，并由于其O(1)查找模式，在推理期间高效地放置在主机内存中。在RoboTwin2.0、LIBERO/LIBERO-Plus以及真实世界双臂操作任务中，Key-Gram一致地改进了π₀和π₀.₅主干，在RoboTwin2.0上平均相对增益为29.5%/9.9%，在LIBERO-Plus迁移（无需目标域微调）上为35.8%/4.5%，在真实世界长程任务上为15.4%/8.1%。这些结果表明，外化语言记忆为改进组合性基础、迁移和真实世界操作提供了一种有效且可扩展的机制。

## Abstract
Embodied control increasingly requires models to follow compositional language instructions while reasoning over dynamic visual states. However, current vision-language-action policies and world-action models often couple linguistic knowledge with visual computation in a shared backbone or conditioning pathway, leading to modality competition and making knowledge extension dependent on backbone updates. In this paper, we introduce Key-Gram, a conditional-memory framework that separates language-derived world knowledge from visual-state reasoning for embodied control. At its core is a memory module that decomposes an instruction into task-specific key-grams, retrieves static linguistic priors through deterministic hashed lookup, and injects the retrieved entries into selected hidden layers through context-aware gating and lightweight convolutional fusion. This design allows the backbone to devote its main capacity to visual reasoning and action inference, while reusable instruction knowledge is stored in an extensible external memory. The logical memory table can be conveniently partitioned during training and, due to its $O(1)$ lookup pattern, efficiently placed on host memory during inference. Across RoboTwin2.0, LIBERO/LIBERO-Plus, and real-world dual-arm manipulation, Key-Gram consistently improves both $π_{0}$ and $π_{0.5}$ backbones, with average relative gains of $29.5\%/9.9\%$ on RoboTwin2.0, $35.8\%/4.5\%$ on LIBERO-Plus transfer without target-domain fine-tuning, and $15.4\%/8.1\%$ on real-world long-horizon tasks. These results demonstrate that externalized linguistic memory provides an effective and extensible mechanism for improving compositional grounding, transfer, and real-world manipulation.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题描述**：当前主流的视觉-语言-行动模型（VLA）和世界行动模型（WAM）在处理具身操作时，均将语言知识与视觉推理紧密耦合在共享骨干网络中。这种设计导致以下矛盾：
  - **模态竞争**：简短的语言指令与稠密的视觉Token在共享注意力流中竞争，稀释了指令信号。
  - **知识扩展依赖骨干更新**：新知识（新对象、技能、关系）须重新写入骨干权重，导致适应性差、灾难性遗忘风险高。
- **背景**：现有方法主要有两条路线——①稠密融合（如RT-2、OpenVLA）将语言和视觉嵌入同一Token空间；②条件生成建模（如扩散策略、FiLM类调制）将语言作为条件信号。两者均未从根本上分离可复用世界知识与在线场景推理。
- **论文目标**：提出一种功能解耦的框架，使语言知识通过外部可扩展记忆存储，视觉骨干专注于动态场景推理，从而降低模态竞争、支持模块化知识增长。

## 2. 方法论：核心思想、关键技术细节、流程

- **核心思想**：Key-Gram是一个条件记忆框架，将指令分解为任务特定的“关键元组”（key-grams），通过确定性哈希查找从外部记忆表中检索静态语言先验，并通过上下文感知门控和轻量卷积融合注入到选定的Transformer层，而视觉骨干保持专注于状态预测和行动推理。

- **关键技术细节**：
  - **关键元组提取**：使用外部语言模型或API解析器，将指令分解为固定数量的短语义短语（如“put mug in microwave”、“close microwave door”），每个短语2-4个词。
  - **哈希记忆映射**：每个关键元组通过乘法-XOR哈希映射到多个哈希头（H个）对应的独立子表，索引计算公式：
    ```
    z_i^(ℓ,h) = (⊕_j a_{i,j} × r_j^(ℓ,h)) mod P^(ℓ,h)
    ```
    检索到的嵌入向量按头拼接到一起。
  - **上下文自适应融合**：检索到的记忆向量经过线性投影得到键K_m和值V_m，与视觉隐藏状态H^(ℓ)计算点积门控：
    ```
    A^(ℓ) = σ( H^(ℓ) K_m^⊤ / √d )
    ```
    然后通过轻量长跨度卷积混合所有关键元组信息，得到增量ΔH^(ℓ)，以残差形式加到原始隐藏状态。
  - **预测头**：
    - 视觉推理：从最终层隐藏状态通过交叉注意力提取未来状态潜变量，经上采样匹配VAE潜空间。
    - 行动推理：复用骨干KV缓存作为条件，由一个较小的行动专家执行流匹配去噪生成动作轨迹。
  - **可扩展记忆分配**：
    - 逻辑表由多个物理子表组成，每个关键元组槽和哈希头拥有独立子表。
    - 更长的指令增加槽数量；更复杂的任务分布增加子表行容量或并行子表。
    - 索引是O(1)查找，推理时可放置于CPU内存。

- **算法流程文字说明**：
  1. 输入语言指令和初始视觉观测。
  2. 解析指令得到K个关键元组。
  3. 对每个关键元组，通过确定性哈希在外部记忆表中检索静态嵌入。
  4. 将检索到的记忆向量经线性投影后，与当前层视觉隐藏状态计算门控值，加权融合并通过卷积混合。
  5. 融合结果以残差方式注入到选定的Transformer层（论文采用第1、8、13层）。
  6. 最终层隐藏状态用于预测未来视觉状态潜变量；同时KV缓存条件化行动专家生成动作轨迹。

## 6. 主要结论与发现

- Key-Gram显著改善了组合指令理解、跨分布迁移和真实世界操作能力。
- 在RoboTwin2.0上，π₀-Key-Gram平均相对提升21.9%/29.5%（简单/困难），π₀.5-Key-Gram提升7.6%/9.9%。增益随任务长度增大而增加。
- 在LIBERO-Plus零样本迁移中，π₀-Key-Gram提升35.8%，π₀.5-Key-Gram提升4.5%；微调后继续提升。
- 真实世界长程任务中，装配任务提升最显著（π₀-KG +26.9%，π₀.5-KG +17.1%）。
- 扩展任务中，未见对象组合迁移提升最大（任务3/4分别提升34.6%/41.7%和18.8%/21.2%）。
- 消融表明早期插入（第1层）最有效，后续添加第8层和第13层有边际增益，门控在后续层自动抑制，验证了外部语言先验减少了骨干指令负担。

## 7. 优点

- **功能解耦设计**：首次在VLA中明确分离语言知识检索与视觉场景推理，减少模态竞争。
- **可扩展性**：外部记忆支持指令长度和任务复杂度的灵活扩展，无需重训练骨干；O(1)查找使推理高效。
- **轻量集成**：Key-Gram模块仅插入少量层，参数量小（约8.39M/层），对骨干改动最小。
- **一致性好**：在多个模拟和真实任务上均有稳定增益，尤其擅长组合性迁移和长程任务。

## 8. 不足与局限

- **骨干泛化局限**：仅测试了π₀和π₀.5两种VLA骨干，未验证在更广泛架构（如RT-2、OpenVLA、世界模型）上的有效性。
- **依赖外部解析器**：关键元组提取依赖于外部语言模型或API，其质量会影响下游性能，且未实现端到端学习。
- **真实世界任务规模有限**：真实世界实验仅涉及少数任务和对象组合，缺乏大规模持续学习评估。
- **消融范围不足**：未系统探讨记忆容量、哈希头数、卷积跨度等超参数影响；仅对层放置做了消融。
- **训练成本较高**：全参数训练需8×H200 GPU，约1-1.5天/epoch，对资源要求较高。
- **潜在偏差风险**：仿真环境中的随机化可能未完全覆盖真实场景分布；长尾指令或模糊指令的解析可能不准确。
