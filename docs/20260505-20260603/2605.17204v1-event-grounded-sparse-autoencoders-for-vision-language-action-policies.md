## 摘要
视觉-语言-动作（VLA）策略将语言和视觉输入转化为机器人动作，其隐藏表示直接塑造闭环行为。然而，来自语言和视觉语言模型的机械可解释性工具并不能直接迁移到VLA：输出是机器人动作而非人类可读的标记，且干预措施只能通过昂贵的闭环 rollout 进行测试。我们提出了一种事件导向的可解释性流水线，将SAE特征分析锚定到行为事件而非文本上下文。使用视觉、状态和时间线索在每个任务内对末端执行器关键帧进行聚类，将SAE特征与行为显著事件关联，并通过可选的VLM注释与语义上下文关联。据我们所知，我们的流水线是首批在闭环行为事件中基于SAE的VLA分析之一。在两个仿真架构和一个真实机器人研究中，事件导向排名对OpenVLA产生了最强的因果效应，并迁移到π₀.₅的连续动作块。SAE是稀疏但不完美的干预基础：可用性随架构和干预位置而变化，激进干预揭示了安全性和可解释性的限制。总体而言，事件导向的SAE分析作为行为锚定的VLA可解释性的实用起点，激发了未来在动作对齐坐标之外的SAE特征、更细粒度的闭环评估以及高风险VLA部署的安全干预方面的研究。代码可在\url{https://github.com/xc-j/Event-SAE}获取。

## Abstract
Vision-Language-Action (VLA) policies translate language and visual inputs into robot actions, where their hidden representations directly shape closed-loop behavior. However, mechanistic interpretability tools from language and vision-language models do not transfer cleanly to VLAs: outputs are robot actions rather than human-readable tokens, and interventions can only be tested via expensive closed-loop rollouts. We propose an event-grounded interpretability pipeline that anchors SAE feature analysis to behavioral events rather than text contexts. End-effector keyframes are clustered within each task using visual, state, and temporal cues, linking SAE features to behaviorally salient events and, via optional VLM annotations, to semantic context. To our knowledge, our pipeline is among the first to ground SAE-based VLA analysis in closed-loop behavioral events. Across two simulation architectures and a real-robot study, event-grounded ranking yields the strongest causal effects on OpenVLA and transfers to the continuous action chunks of $π_{0.5}$. SAE is a sparse but imperfect intervention basis: usability varies with architecture and intervention site, and aggressive intervention reveals safety and interpretability limits. Overall, event-grounded SAE analysis emerges as a practical starting point for behavior-anchored VLA interpretability, motivating future work on SAE features beyond action-aligned coordinates, finer-grained closed-loop evaluation, and safe interventions for high-stakes VLA deployments. Code is available at \url{https://github.com/xc-j/Event-SAE}.

# 论文总结：Event-Grounded Sparse Autoencoders for Vision-Language-Action Policies

## 1. 核心问题与整体含义
- **研究动机**：视觉-语言-动作（VLA）模型将语言指令和视觉观察映射为机器人动作，其隐藏表示直接决定闭环行为。然而，语言模型和视觉语言模型中成熟的机械可解释性工具（如logit lens、稀疏自编码器 SAE 特征解码）难以直接迁移到 VLA 上，原因有二：（1）VLA 输出是动作而非人类可读标记，无法通过投影到词汇空间来命名特征；（2）行为验证困难，单步干预的语义效果难以解读，而多步干预需要每一步精确落地。因此，需要一种**行为锚定**的可解释性方法，将特征分析关联到 rollout 中重复出现的行为事件。
- **整体含义**：该工作提出一种**事件导向的 SAE 流水线**，通过自动化提取运动学关键帧、聚类为任务局部事件、对每个存活 SAE 特征进行事件对齐评分，并经闭环干预因果验证，为 VLA 可解释性提供了一种可扩展、行为驱动的实用范式。

## 2. 方法论
### 核心思想
- 利用闭环 rollout 中与 SAE 无关的外部行为信号（末端执行器关键帧）来锚定特征分析，避免依赖语言词汇投影或 SAE 内部统计数据。通过自动关键帧提取、事件聚类、特征评分和闭环干预，实现无需人工标注的 SAE 特征发现与因果验证。

### 关键技术细节
1. **SAE 训练**（第3.1节）：
   - 使用 BatchTopK SAE 架构（替代 L1 惩罚），每流每套件每层训练一个 SAE，作用于残差流激活（不进行 token 平均）。
   - 训练目标：重建损失 + AuxK 辅助损失（复活死亡特征）。
   - 选择层标准：通过钩住 SAE 重建（reconstruction-only hook）后的闭环成功率（Hooked SR）作为保真度指标，只在保持有效成功率的层进行后续分析（OpenVLA 选层31；π₀.₅ 所有测试层均保持 >95% 成功率）。

2. **运动学关键帧提取**（第3.2节）：
   - 采用自动航点提取（AWE）方法，从末端执行器位置轨迹中提取稀疏关键帧，使线性插值误差在预算 η 内。
   - 为每个关键帧构建局部观测包：五帧图像条带、短视频、元数据（任务描述、时间戳等）。

3. **事件聚类**（第3.3节）：
   - 将关键帧包聚类为任务局部事件簇，描述符由视觉嵌入（v）、机器人状态（s，包括末端执行器姿态和夹爪状态）和时间进度标量（p）拼接并 L2 归一化构成，赋予可调权重。
   - 采用凝聚聚类（cosine 距离阈值），保留至少出现在一半 episode 中的簇作为事件单元。
   - 可选：通过 VLM 对示例关键帧包进行短语和阶段标签注释（如 approach、contact、release），用于可视化（图8、9）。

4. **特征排名策略**（第3.4节）：
   - 事件对齐排名：在每个事件窗口内，计算特征激活与三种时间模板（脉冲、阶梯上升、阶梯下降）的最佳匹配投影值，反映时间形状而非基线水平。
   - 窗口均值排名：平均事件窗口激活，忽略时间结构。
   - 任务均值排名：全局平均激活。
   - 随机存活排名：从存活特征中均匀采样（排除前三排名已选），作为下界对照。
   - 每套件按排名选前 K 个特征（OpenVLA 选 K=5，π₀.₅ 选 K=3）进行干预。

5. **干预模式**（第3.5节）：
   - 残差保持潜编辑：对 SAE 编码 z 中目标特征子集 S 进行缩放（α=0 即零去除，0<α<1 削弱，α>1 增强），通过 `x' = x + Dec(z') - Dec(z)` 仅修改 SAE 可解释部分，保留重建误差。
   - 对比：硬零去除（α=0）和软干预（α 连续扫描）。

## 6. 主要结论与发现
1. **事件对齐排名效果最强**：在 OpenVLA 上层（层31），事件对齐排名选出的前 K 特征产生最大成功率下降（ΔSR = -21.2 pp），显著优于随机对照（-1.3 pp），窗口均值和任务均值居中。表明时间形状信息对因果重要性有额外贡献。
2. **架构和层依赖性**：
   - OpenVLA：上层（层31）可保持部分成功率；浅层钩住后成功率归零（重建误差放大）。
   - π₀.₅ PaliGemma 骨干：所有测试层单特征编辑几乎不改变成功率（ΔSR 约 -0.2 至 -2.8 pp），因为动作专家通过 cross-attention KV-cache 读取骨干状态，稀释了单特征影响。
   - π₀.₅ 动作专家：几乎所有排名（包括随机）的前 K 特征零去除都导致成功率崩溃（ΔSR ≈ -96 pp），显示广泛因果敏感性而非事件特异性。
3. **软干预作为可控旋钮**：在 π₀.₅ 动作专家上，α 连续扫描显示成功率为单调转换，但过渡陡峭（类似开关），实际调参需谨慎。
4. **排名重叠分析**：窗口均值与任务均值高度一致（重叠约95%），事件对齐选择几乎不同的特征（OpenVLA 层31仅5%重叠）。
5. **真实机器人**：SAE 特征抑制可测量地改变颜色条件接近行为，效果与层和抑制强度相关。最强者在动作专家层17。但强干预会带来行驶安全风险。
6. **目标/非目标探测**：事件簇选择的特征在目标任务和非目标任务上造成相似成功率下降（表8），表明特征参与共享操作角色而非任务私有回路。
7. **SAE 作为干预基础的局限性**：特征可能多义；在动作专家上随机特征也导致崩溃，说明 SAE 特征并非因子级别干净隔离。

## 7. 优点
- **自动化程度高**：关键帧提取、事件聚类、特征评分全流程自动，无需人工标注每个特征。
- **行为锚定的新颖性**：首次将 SAE 特征分析锚定到闭环 rollouts 中的外部行为事件（而非 SAE 内部统计或词汇投影），提供独立于 SAE 的验证信号。
- **排名策略对比充分**：比较了四种不同假设的排序方法，并提供随机对照作为下界，使结论有支撑。
- **多层级保真度评估**：不仅关注离线重建质量（FVE），更引入 Hooked SR 作为行为保真度核心指标，确保干预层选择合理。
- **干预方法稳健**：残差保持潜编辑避免了解码器向量加法对原生残差流的过度覆盖（见附录K），使干预更为可控。
- **真实机器人验证**：将仿真结论拓展到物理平台，检验了从观测到干预的可迁移性，并强调安全限制。
- **丰富的可视化与诊断**：提供事件-特征热力图（图8）、关键帧包示例（图9）、零去除失败案例（图10-12）等，辅助理解。

## 8. 不足与局限
- **特征共享而非任务特有**：目标/非目标探测显示所选特征在套件内各任务间产生相似影响，且动作专家中随机特征也造成行为崩溃，说明单特征无法隔离特定行为因子，因果归因粒度粗糙。
- **VLM 语义未被利用**：VLM 注释仅用于可视化（热力图、关键帧标签），未融入排名机制或干预评分，语义结构未发挥搜索或验证作用。
- **粗粒度评估指标**：仅用二值成功率度量干预效果，无法捕捉轨迹层面细粒度变化（如延迟、精度、接触力等）。作者也指出需要更细粒度评估。
- **真实机器人实验范围有限**：仅测试单一任务（芯片接近）；仅使用保守弱干预以避免危险行为。硬零去除或强干预的安全边界未深入探索。
- **仿真环境单一**：所有仿真实验仅在 LIBERO 四个套件上，任务规模和多样性有限；未在更多复杂环境（如 Kitchen、CALVIN 等）验证。
- **SAE 保真度与干预可解释性不平衡**：在 π₀.₅ 动作专家上，SAE 重建保真度高（FVE ≥0.96），但事件对齐排名与随机排名无区分度，暗示高重建保真度不保证特征因果特异性。
- **计算资源报告不够详细**：未给出总 GPU 小时数、训练 SAE 的具体时间等，不利于复现能耗评估。
- **缺乏与其他 SAE-on-VLA 工作的直接定量对比**：仅引用 Swann et al. 和 Grant et al.，但未在同一设置下重现其方法并比较排名效果。
