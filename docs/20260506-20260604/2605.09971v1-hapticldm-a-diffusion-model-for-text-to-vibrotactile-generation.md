## 摘要
文本到振动生成将自然语言转换为触觉反馈，使振动效果设计师能够更高效地获得与场景匹配的振动，这在元宇宙、游戏和电影等应用领域具有巨大潜力，可丰富交互场景中的用户体验。该领域的核心挑战在于如何根据文本语义生成准确、一致且完整的振动。近期基于自回归（AR）的方法（例如HapticGen）由于模型固有的顺序特性及数据约束，在充分捕捉全局依赖性方面能力有限。本文提出了HapticLDM，这是首个基于潜在扩散模型（LDMs）的文本到振动生成模型。首先，在数据方面，我们引入了一种强调动态特征的文本处理策略，以构建高质量的数据对，用于细粒度的动态建模。其次，HapticLDM采用全局去噪机制，调节时间包络中的连贯且稳定的变化。此外，我们进行了广泛评估，包括与最先进基线的A/B测试以及涉及30名参与者的用户研究。结果表明，我们的模型增强了真实感和语义对齐。定性反馈进一步表明，HapticLDM简化了触觉设计流程，同时能生成多样、微妙且物理精确的振动。

## Abstract
Text-to-vibration generation converts natural language into haptic feedback, enabling vibration-effect designers to get scenarios-fitted vibrations more efficiently, which shows great potentials in application fields such as metaverse, games, and film to enrich the user experience in interactive scenarios. The core challenge in this field is how to generate accurate, consistent, and complete vibrations according to textual semantics. Very recent autoregressive (AR) approaches (e.g., HapticGen) exhibit limited capacity in fully capturing global dependencies, owing to the inherent sequential nature of their modeling and prevailing data constraints. In this paper, we proposed HapticLDM, the first text-to-vibration generative model built upon Latent Diffusion Models (LDMs). Firstly, with respect to the data, we introduced a text-processing strategy that emphasizes dynamic characteristics to curate high-quality data pairs for fine-grained dynamic modeling. Secondly, HapticLDM incorporates a global denoising mechanism that regulates coherent and stable variations in the temporal envelope. Furthermore, we conduct extensive evaluations, including A/B testing against the state-of-the-art baseline and a user study involving 30 participants. The results demonstrate that our model enhances realism and semantic alignment. Qualitative feedback further indicates that HapticLDM simplifies the haptic design workflow while generating diverse, subtle, and physically precise vibrations.

### 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：文本到振动触觉生成的主要挑战在于如何根据文本语义生成准确、一致且完整的振动信号。现有自回归方法（如 HapticGen）受限于顺序预测机制，难以充分捕获全局时间依赖，导致生成信号重复、语义对齐差，且误差累积。
- **研究背景**：触觉反馈在 VR、游戏、电影等沉浸式体验中不可或缺，但传统手动设计过程复杂、门槛高。近期交叉模态生成研究多依赖音频到触觉转换，缺乏直接从文本生成的能力。HapticGen 首次探索文本到振动生成，但其数据构建存在LLM生成的文本与振动信号不匹配的问题，且自回归模型难以建模全局时间包络。

### 2. 方法论：核心思想、关键技术细节
- **核心思想**：采用潜扩散模型（LDM）进行文本到振动生成，通过全局去噪机制自然适用于振动信号的全局时间包络建模；同时构建高质量、振动导向的文本-振动数据对。
- **关键技术细节**：
  - **数据构建**：
    - 基于 WavCaps 音频数据集，先过滤语音相关样本（从400K降至343K），再通过音频到触觉转换提取振幅包络作为振动信号（8kHz采样率，10秒固定时长）。
    - 触觉导向过滤：利用 Qwen2.5-32B 大语言模型区分四类文本（动作描述、高唤醒情感、抽象概念、低唤醒情感），仅保留动作描述和高唤醒情感（经实验验证更适合振动映射）。
    - 客观改写：将主观、情感性描述改写为中性、振动导向的描述（如“I think it feels like”改写为“It feels like”），并移除HapticCap中的情感注释，仅保留感官和联想描述。最终SFT数据集由过滤后的预训练数据子集（约57k）与HapticCap处理后的数据（约57k）以1:1混合，共114k样本。
  - **模型架构**：基于 Stable Audio 的潜扩散框架，包括：
    - VAE：基于Oobleck主干，输入归一化8kHz、10秒一维振动波形，下采样2048倍至64通道潜空间。复合损失函数：L1损失 + 多分辨率STFT损失 + 对抗损失 + KL散度。
    - 扩散模型：DiT（Diffusion Transformer），文本条件通过T5-base编码器进行交叉注意力。采用v-参数化训练，损失为均方误差。生成的潜变量经VAE解码后，通过振幅有效性检查（丢弃过弱信号）。
  - **训练策略**：四阶段渐进式对齐
    1. VAE适应：在所有振动数据上微调VAE（batch size 20）。
    2. 扩散模型预训练：在预训练数据集（343k样本）上训练（batch size 512），学习通用文本-振动对应关系。
    3. 监督微调（SFT）：在SFT数据集上微调（batch size 512），增强动态对齐。
    4. 直接偏好优化（DPO）：在HapticGen提供的偏好数据集上训练（batch size 128），进一步对齐人类偏好。

### 3. 实验设计：数据集、场景、基准与对比方法
- **数据集**：
  - **预训练数据集**：WavCaps（过滤语音后约343k对），来源于音频到触觉转换。
  - **SFT数据集**：过滤后的预训练数据子集（约57k）+ HapticCap处理后的数据（约57k），共114k。
  - **偏好数据集**：来自HapticGen发布的偏好数据。
- **基准**：HapticGen（基于自回归Transformer的文本到振动生成模型）。
- **实验场景**：
  - **数据质量验证**：从HapticCap和HapticGen中按四类语义各选5个样本，每类形成20组正负样本对，由20名参与者用5点Likert量表评分匹配度。评估不同语义类别数据对振动生成的适用性。

### 6. 主要结论与发现
- **数据方面**：动作描述和高唤醒情感的文本-振动数据对具有更清晰的可识别映射（匹配度评分分别为3.44±1.21和3.23±1.22），且动作描述的正负样本差异最大（1.04），最适合模型训练；抽象概念和低唤醒情感效果差。

### 7. 优点
- **数据创新**：提出触觉导向过滤和客观改写策略，显著提升文本-振动对齐质量，减少LLM带来的语义幻觉。
- **模型创新**：首次将潜扩散模型应用于振动生成，利用全局去噪机制更好地建模时间包络和长期动态结构，避免自回归模型的误差累积和重复问题。
- **渐进式训练策略**：预训练→SFT→DPO，逐步从大规模通用数据过渡到高质量偏好数据，有效提升语义对齐和人类偏好。
- **评估全面**：包含数据质量验证、A/B测试、用户研究和统计检验，定量定性结合。

- **生成质量局限**：难以准确模拟材料特定纹理和复杂物理反馈（如阻尼效应、低频震动）；对细粒度特征（如“3/4拍”“快速强度递减”）不敏感。
