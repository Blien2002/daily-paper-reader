## 摘要
世界动作模型（WAMs）通过联合预测场景演变和机器人动作来增强视觉-语言-动作（VLA）策略，但现有方法通常将预测的世界表示为整体图像、视频标记（tokens）或全局潜变量。当指令涉及特定对象时，动作解码器难以寻址这些表示，特别是在场景偏移的情况下，对象的身份与上下文纠缠在一起。我们提出了 OA-WAM，一种用于鲁棒机器人操作的对象可寻址世界动作模型。OA-WAM 将每一帧分解为 N+1 个槽位（slot）状态，包括一个机器人槽位和 N 个对象槽位。每个槽位包含一个持久的地址向量和一个随时间变化的内容向量，并在块因果序列中与文本、图像、本体感受和过去动作标记融合。世界头预测下一帧的槽位状态，而流匹配动作头在同一次前向传播中解码一个 16 步的连续动作块。通过仅地址键路由跨槽位注意力，并在每个 Transformer 层重置地址切片，强制实现可寻址性，从而在不增加额外标记的情况下，将“操作哪个对象”与“该对象当前是什么”分离开来。OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 上达到了强大的 VLA 和 WAM 基准水平，在最相关的 LIBERO-Plus 几何轴上达到了最先进的性能，并在七轴综合评估中保持竞争力。因果槽位干预测试产生的交换绑定余弦值为 0.87，而整体基准模型最高仅为 0.09。这些结果表明，可寻址的对象状态为场景扰动下的鲁棒世界动作建模提供了一个有效的接口。

## Abstract
World Action Models (WAMs) enhance Vision-Language-Action policies by jointly predicting scene evolution and robot actions, but existing methods usually represent the predicted world as holistic images, video tokens, or global latents. These representations are difficult for an action decoder to address when an instruction refers to a particular object, especially under scene shifts where object identity is entangled with context. We propose OA-WAM, an Object-Addressable World Action Model for robust robot manipulation. OA-WAM decomposes each frame into N+1 slot states, with one robot slot and N object slots. Each slot contains a persistent address vector and a time-varying content vector, and is fused with text, image, proprioception, and past-action tokens in a block-causal sequence. A world head predicts next-frame slot states, while a flow-matching action head decodes a 16-step continuous action chunk in the same forward pass. Addressability is enforced by routing cross-slot attention through address-only keys and resetting the address slice at every transformer layer, separating which object to act on from what that object currently is without adding extra tokens. OA-WAM matches strong VLA and WAM baselines on LIBERO (97.8%) and SimplerEnv (79.3%), reaches state-of-the-art performance on the most relevant LIBERO-Plus geometric axes, and remains competitive on the seven-axis aggregate. A causal slot-intervention test yields a swap-binding cosine of 0.87, versus at most 0.09 for holistic baselines. These results suggest that addressable object states provide an effective interface for robust world-action modeling under scene perturbations.

### 1. 核心问题与整体含义（研究动机和背景）
论文针对现有**视觉-语言-动作（VLA）**模型和**世界动作模型（WAM）**在鲁棒性上的缺陷提出了挑战。现有的模型（如 RT-2, OpenVLA 等）通常将场景视为整体图像或全局潜变量，这导致模型在面对相机视角切换、物体布局改变或背景变化时，容易将目标物体的身份与周围环境上下文纠缠在一起（Entanglement），从而导致动作预测失效。论文的核心动机是引入**对象可寻址性（Object Addressability）**，让机器人能像计算机内存寻址一样，通过稳定的“地址”锁定目标物体，而不受其外观或位置变化的影响。

### 2. 方法论：核心思想与关键技术
OA-WAM 的核心是将世界模型构建为一组可寻址的对象槽位（Slots），并强制在架构层面解耦“身份”与“状态”。

*   **对象槽位标记化（Object-Slot Tokenization）**：
    利用 SAM 3、DINOv3 和 Qwen3-VL 提取场景中的 $N+1$ 个槽位（1个机器人，N个物体）。每个槽位向量由两部分组成：
    *   **地址向量 ($addr_k$)**：基于初始帧特征和语言标签生成，在整个任务过程中保持**冻结**，代表物体的“身份”。
    *   **内容向量 ($cnt_k^t$)**：随时间更新，代表物体的姿态、外观等时变状态。
*   **对象可寻址注意力机制（OA Attention）**：
    在 Transformer 的 32 个层中，强制跨槽位注意力的“键（Key）”投影仅读取 $addr$ 部分。这意味着动作头在决定“关注哪个物体”时，只能依据稳定的身份地址，而不能被波动的环境内容干扰。
*   **地址重置钩子（Address-Reset Hook）**：
    在每一层残差连接后，强制将地址切片重置为初始值，防止身份信息在深层网络中发生漂移。
*   **统一序列与多头输出**：
    模型基于 7B 的 Chameleon 骨干网络，采用块因果序列处理文本、图像 VQ、槽位、本体感受和动作标记。输出端包含：
    *   **世界头（World Head）**：预测下一帧各槽位的状态和姿态。
    *   **动作头（Action Head）**：利用流匹配（Flow-matching）一次性解码 16 步动作块。

### 3. 实验设计
*   **数据集与场景**：
    *   **LIBERO**：标准操作基准，包含 Spatial, Object, Goal, Long 四个子集。
    *   **SimplerEnv (WidowX/Bridge)**：评估模拟到真实的视觉匹配能力。
    *   **LIBERO-Plus**：核心鲁棒性测试，包含相机、机器人初始状态、布局、光照、背景、语言、传感器噪声 7 个扰动维度。
*   **对比方法**：
    *   **VLA 基准**：OpenVLA, $\pi_0$, $\pi_{0.5}$, InternVLA-M1, SpatialVLA 等。
    *   **WAM 基准**：WorldVLA, VLA-JEPA, GE-Act, Cosmos-Policy, F1-VLA 等。

### 5. 实验数量与充分性
实验设计非常充分且具有高度的客观性：
*   **多维度评估**：不仅在标准基准上刷榜，还深入分析了 7 种不同的分布外（OOD）扰动。
*   **消融实验（A1）**：通过关闭地址掩码和重置钩子，证明了鲁棒性增益确实源于“可寻址性”架构，而非单纯依靠强大的感知前端。

### 6. 主要结论与发现
*   **性能领先**：OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 达到 SOTA 或同等水平。
*   **几何鲁棒性极强**：在 LIBERO-Plus 的几何扰动轴（相机、机器人位姿、布局）上显著超过 $\pi_{0.5}$ 等强基准。
*   **成功的解耦**：因果干预显示 OA-WAM 的物体绑定一致性（0.87）远超所有整体式模型（$\le 0.09$）。
*   **鲁棒性来源**：实验证明，将“身份”从“内容”中分离出来是解决场景偏移下动作漂移的关键。

### 7. 优点
*   **架构创新**：通过简单的张量掩码和重置操作实现了强力的归纳偏置，无需增加额外标记或复杂的损失函数。
*   **可解释性与可验证性**：提出的“交换绑定（Swap-binding）”测试为 VLA 模型的内部机理提供了清晰的诊断工具。
*   **系统性强**：整合了最先进的感知模型（SAM 3, DINOv3）与生成式动作头，构建了一个完整的闭环系统。

### 8. 不足与局限
*   **感知瓶颈**：在“传感器噪声”维度表现较差（-17.1%），因为模型高度依赖上游的槽位提取，如果 SAM 3 或 DINOv3 在噪声下失效，策略也会随之崩溃。
*   **计算开销**：感知前端（约 138ms）占据了推理时间的显著比例，对于极高频的实时控制可能存在压力。
*   **模拟器依赖**：验证主要在仿真环境中完成，虽然有 SimplerEnv 的视觉匹配测试，但尚未在真实物理机器人上进行大规模部署验证。
*   **假设限制**：模型假设物体间是弱耦合的，在处理物体间存在复杂物理遮挡或纠缠的场景时可能受限。
