## 摘要
视觉-语言-动作（VLA）模型是有效的机器人动作执行器，但由于长时闭环规划和多样化物理操作的双重负担，它们在长程任务中仍受到限制。因此，我们提出了 VLAs-as-Tools，这是一种将负担分配给负责时间推理的高层视觉语言模型（VLM）智能体和一系列负责多样化局部物理操作的专用 VLA 工具的策略。VLM 处理场景分析、全局规划和恢复，而每个 VLA 工具执行一个有界的子任务。为了在长程任务中紧密耦合智能体规划与 VLA 工具执行，我们引入了一个 VLA 工具族接口，该接口暴露了显式的工具选择和执行中的进度反馈，从而实现了高效的事件触发式智能体重规划，而无需持续的智能体轮询。为了获得能够忠实遵循智能体调用的多样化专用 VLA 工具，我们进一步提出了工具对齐后训练（TAPT），它构建了用于指令遵循的调用对齐训练单元，并采用工具族残差适配器来实现高效的工具专业化。实验表明，VLAs-as-Tools 在 LIBERO-Long 上将 $π_{0.5}$ 的成功率提高了 4.8 个百分点，在 RoboTwin 上提高了 23.1 个百分点，并根据非偏率（Non-biased Rate）衡量，将调用保真度进一步提升了 15.0 个百分点。代码将会发布。

## Abstract
Vision-language-action (VLA) models are effective robot action executors, but they remain limited on long-horizon tasks due to the dual burden of extended closed-loop planning and diverse physical operations. We therefore propose VLAs-as-Tools, a strategy that distributes this burden across a high-level vision language model (VLM) agent for temporal reasoning and a family of specialized VLA tools for diverse local physical operations. The VLM handles scene analysis, global planning, and recovery, while each VLA tool executes a bounded subtask. To tightly couple agent planning with VLA tool execution in long-horizon tasks, we introduce a VLA tool-family interface that exposes explicit tool selection and in-execution progress feedback, enabling efficient event-triggered agent replanning without continuous agent polling. To obtain diverse specialized VLA tools that faithfully follow agent invocations, we further propose Tool-Aligned Post-Training (TAPT), which constructs invocation-aligned training units for instruction following and adopts tool-family residual adapters for efficient tool specialization. Experiments show that VLAs-as-Tools improves the success rate of $π_{0.5}$ by 4.8 points on LIBERO-Long and 23.1 points on RoboTwin, and further enhances invocation fidelity by 15.0 points as measured by Non-biased Rate. *   **核心挑战**：现有的视觉-语言-动作（VLA）模型在处理**长程（Long-horizon）任务**时面临双重压力：既要进行高层的逻辑规划（如步骤分解、错误恢复），又要执行底层的精细物理操作。
*   **现状局限**：端到端 VLA 模型往往容易受到训练数据偏差的影响，缺乏鲁棒的规划能力；而传统的“代码即策略”系统虽然逻辑性强，但依赖的手写机器人 API 表达能力有限。
*   **研究目标**：提出一种“VLAs-as-Tools”策略，将 VLA 重新定义为可被高层智能体调用的“物理工具”，以实现复杂任务的解耦处理。

### 2. 方法论：VLAs-as-Tools 框架
该方法的核心思想是将具身智能体分为“大脑”（高层 VLM 规划器）和“手”（专门化的 VLA 工具族）。

*   **双向智能体-工具接口 (Interface I)**：
    *   **调用消息 (C)**：包含工具族标签（如 grasp, open）和场景对齐指令（如“抓取左侧的壶”）。
    *   **反馈消息 (R)**：工具在执行过程中实时返回“进度信号”（Progress Signal），允许智能体在不频繁轮询图像的情况下，根据进度停滞或异常触发重规划。
*   **工具对齐后训练 (TAPT)**：
    *   **调用对齐训练单元**：将长程演示数据自动切分为有界的子任务片段，并标注对应的工具标签和进度。
    *   **工具族残差适配器 (Tool-family Residual Adapters)**：基于共享的 VLA 主干网络，为每个工具族（如推、拉、旋转）训练轻量级的 LoRA 适配器。这保证了工具的专业性，同时避免了全参数微调导致的语义退化。
    *   **优化目标**：结合了动作克隆（IL）损失和进度预测损失，并在强化学习（RL）阶段使用 GRPO 算法优化子任务的成功率。

### 6. 主要结论与发现
*   **性能提升**：VLAs-as-Tools 显著优于端到端模型，在 RoboTwin 上将 $\pi_{0.5}$ 的成功率提升了 **23.1%**。

### 7. 优点与亮点
*   **架构解耦**：巧妙地解决了长程规划与局部操作的矛盾，使 VLA 能够像数字插件一样被灵活调用。

*   **参数高效**：使用残差适配器在不显著增加参数量（仅增加约 9%）的情况下实现了多工具专业化。

*   **环境限制**：目前的实验主要集中在**模拟环境**（Simulator）中的单臂操纵，尚未在复杂的真实世界物理环境中进行大规模验证。
