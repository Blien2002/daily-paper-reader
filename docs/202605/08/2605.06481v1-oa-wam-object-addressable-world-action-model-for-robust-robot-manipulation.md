## 摘要
世界动作模型（WAMs）通过联合预测场景演变和机器人动作来增强视觉-语言-动作（VLA）策略，但现有方法通常将预测的世界表示为整体图像、视频标记或全局潜变量。当指令涉及特定对象时，动作解码器很难处理这些表示，特别是在场景偏移导致对象身份与上下文纠缠的情况下。我们提出了 OA-WAM，一种用于鲁棒机器人操作的对象可寻址世界动作模型。OA-WAM 将每一帧分解为 N+1 个槽位（slot）状态，包括一个机器人槽位和 N 个对象槽位。每个槽位包含一个持久的地址向量和一个随时间变化的内容向量，并以块因果序列的形式与文本、图像、本体感受和过去动作的标记融合。世界头预测下一帧的槽位状态，而流匹配动作头在同一次前向传播中解码 16 步连续动作块。通过仅地址键路由跨槽位注意力，并在每个 Transformer 层重置地址切片，从而强制实现可寻址性，在不增加额外标记的情况下，将“操作哪个对象”与“该对象当前是什么”分离开来。OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 上达到了强大的 VLA 和 WAM 基准水平，在最相关的 LIBERO-Plus 几何轴上达到了最先进的性能，并在七轴综合评估中保持竞争力。因果槽位干预测试得出的交换绑定余弦值为 0.87，而整体基准模型最高仅为 0.09。这些结果表明，可寻址的对象状态为场景扰动下的鲁棒世界动作建模提供了一个有效的接口。

## Abstract
World Action Models (WAMs) enhance Vision-Language-Action policies by jointly predicting scene evolution and robot actions, but existing methods usually represent the predicted world as holistic images, video tokens, or global latents. These representations are difficult for an action decoder to address when an instruction refers to a particular object, especially under scene shifts where object identity is entangled with context. We propose OA-WAM, an Object-Addressable World Action Model for robust robot manipulation. OA-WAM decomposes each frame into N+1 slot states, with one robot slot and N object slots. Each slot contains a persistent address vector and a time-varying content vector, and is fused with text, image, proprioception, and past-action tokens in a block-causal sequence. A world head predicts next-frame slot states, while a flow-matching action head decodes a 16-step continuous action chunk in the same forward pass. Addressability is enforced by routing cross-slot attention through address-only keys and resetting the address slice at every transformer layer, separating which object to act on from what that object currently is without adding extra tokens. OA-WAM matches strong VLA and WAM baselines on LIBERO (97.8%) and SimplerEnv (79.3%), reaches state-of-the-art performance on the most relevant LIBERO-Plus geometric axes, and remains competitive on the seven-axis aggregate. A causal slot-intervention test yields a swap-binding cosine of 0.87, versus at most 0.09 for holistic baselines. These results suggest that addressable object states provide an effective interface for robust world-action modeling under scene perturbations.

### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉-语言-动作（VLA）模型和世界动作模型（WAM）在处理机器人操作任务时，通常将场景视为整体图像、视频标记流或全局潜变量。这种“整体性”表示存在一个致命缺陷：**缺乏对象可寻址性（Object Addressability）**。
*   **痛点**：当环境发生轻微扰动（如相机视角切换、背景改变、物体位置偏移）时，目标物体的特征容易与周围上下文纠缠，导致模型无法准确“定位”指令中提到的物体，从而引发动作漂移或失败。
*   **核心目标**：构建一个能够将“操作哪个对象（身份地址）”与“该对象当前状态（内容）”在张量层面解耦的模型，从而提升机器人在复杂、多变场景下的操作鲁棒性。

### 2. 论文提出的方法论
OA-WAM 的核心思想是将世界模型构建为一系列可寻址的对象槽位（Slots），并通过架构约束确保动作生成直接挂钩到这些稳定的对象身份上。

*   **对象槽位表示**：每一帧被分解为 $N+1$ 个槽位（1个机器人槽位，$N$个物体槽位）。每个槽位向量 $s_k^t$ 由四部分拼接而成：
    1.  **地址向量 ($addr_k$)**：由语言标签和初始 DINOv3 特征计算，在整个任务过程中保持**冻结**，代表物体身份。
    2.  **内容向量 ($cnt_k^t$)**：随时间变化，捕捉物体的姿态、外观等动态信息。
    3.  **时间编码**与**角色编码**。
*   **关键技术细节（OA 约束）**：
    *   **地址唯一键路由**：在 Transformer 的 32 个层中，跨槽位注意力的 Key 投影被限制为仅读取 $addr$ 子向量。
    *   **残差重置**：在每一层处理后，通过 Forward Hook 将残差流中的地址部分重置为初始值，防止身份信息在深层网络中被上下文污染。
*   **算法流程**：
    *   **感知层**：利用 SAM 3、DINOv3 和 Qwen3-VL 进行物体分割、特征提取和语义解析。
    *   **主干网络**：基于 7B 参数的 Chameleon 风格多模态 Transformer，处理由文本、图像 VQ、本体感受、过去动作和对象槽位组成的块因果序列。
    *   **双头输出**：**世界头**回归预测下一帧的槽位状态（内容和姿态）；**动作头**利用流匹配（Flow-matching）在单次前向传播中解码出 16 步的连续动作块。

### 6. 主要结论与发现
*   **性能领先**：OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 上达到或超过了现有最强基准。
*   **几何鲁棒性极强**：在 LIBERO-Plus 的几何相关轴（相机、机器人初始位姿、布局）上显著优于 $\pi_{0.5}$ 等强力模型，几何平均成功率提升了 4.8%。
*   **机制验证**：实验证明，显式地将世界模型组织为“可寻址的对象状态”是解决 VLA 模型在场景扰动下失效的有效路径。

### 7. 优点
*   **架构创新**：不同于以往仅在输入端做文章，OA-WAM 在 Transformer 内部通过张量切片和 Hook 机制强制实现了对象寻址，具有很强的解释性。
*   **高效预测**：采用流匹配动作头，避免了自回归生成动作时的误差累积，且支持单次前向预测长动作块。
*   **验证严谨**：因果干预实验（Slot-intervention）为模型是否真正理解“目标物体”提供了直接的证据。

### 8. 不足与局限
*   **感知瓶颈**：模型高度依赖上游的分割（SAM 3）和特征提取（DINOv3）。在传感器噪声极大（如运动模糊、遮挡）导致感知失败时，策略性能会随之崩溃（Sensor Noise 轴表现较差）。

*   **假设限制**：目前的干扰一致性损失假设目标与干扰项之间是弱耦合的，在极度拥挤或物体间有复杂物理交互的场景下可能受限。
*   **环境局限**：所有验证均在仿真环境中完成，尚未在真实物理机器人上进行大规模部署验证。
