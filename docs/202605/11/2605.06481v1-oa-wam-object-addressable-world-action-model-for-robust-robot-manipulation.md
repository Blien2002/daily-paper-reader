## 摘要
世界动作模型（WAMs）通过联合预测场景演变和机器人动作来增强视觉-语言-动作（VLA）策略，但现有方法通常将预测的世界表示为整体图像、视频标记（tokens）或全局潜变量。当指令涉及特定对象时，动作解码器很难处理这些表示，特别是在场景偏移导致对象身份与上下文纠缠的情况下。我们提出了 OA-WAM，一种用于鲁棒机器人操作的对象可寻址世界动作模型。OA-WAM 将每一帧分解为 N+1 个槽位（slot）状态，包括一个机器人槽位和 N 个对象槽位。每个槽位包含一个持久的地址向量和一个随时间变化的内容向量，并以块因果序列的形式与文本、图像、本体感受和过去动作的标记融合。世界头（world head）预测下一帧的槽位状态，而流匹配（flow-matching）动作头在同一次前向传播中解码 16 步连续动作块。通过仅地址键（address-only keys）路由跨槽位注意力，并在每个 Transformer 层重置地址切片，从而强制实现可寻址性，在不增加额外标记的情况下，将“操作哪个对象”与“该对象当前是什么”分离开来。OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 上达到了强大的 VLA 和 WAM 基准水平，在最相关的 LIBERO-Plus 几何轴上达到了最先进的性能，并在七轴综合评估中保持竞争力。因果槽位干预测试得出的交换绑定余弦值为 0.87，而整体基准模型最高仅为 0.09。这些结果表明，可寻址的对象状态为场景扰动下的鲁棒世界动作建模提供了一个有效的接口。

## Abstract
World Action Models (WAMs) enhance Vision-Language-Action policies by jointly predicting scene evolution and robot actions, but existing methods usually represent the predicted world as holistic images, video tokens, or global latents. These representations are difficult for an action decoder to address when an instruction refers to a particular object, especially under scene shifts where object identity is entangled with context. We propose OA-WAM, an Object-Addressable World Action Model for robust robot manipulation. OA-WAM decomposes each frame into N+1 slot states, with one robot slot and N object slots. Each slot contains a persistent address vector and a time-varying content vector, and is fused with text, image, proprioception, and past-action tokens in a block-causal sequence. A world head predicts next-frame slot states, while a flow-matching action head decodes a 16-step continuous action chunk in the same forward pass. Addressability is enforced by routing cross-slot attention through address-only keys and resetting the address slice at every transformer layer, separating which object to act on from what that object currently is without adding extra tokens. OA-WAM matches strong VLA and WAM baselines on LIBERO (97.8%) and SimplerEnv (79.3%), reaches state-of-the-art performance on the most relevant LIBERO-Plus geometric axes, and remains competitive on the seven-axis aggregate. A causal slot-intervention test yields a swap-binding cosine of 0.87, versus at most 0.09 for holistic baselines. These results suggest that addressable object states provide an effective interface for robust world-action modeling under scene perturbations.

### 1. 核心问题与整体含义（研究动机和背景）
现有的视觉-语言-动作（VLA）模型和世界动作模型（WAM）在处理机器人操作任务时，通常将场景表示为整体图像、视频标记流或全局潜变量。这种“整体性”表示存在一个致命缺陷：**缺乏对象可寻址性（Object Addressability）**。
当指令要求操作特定物体（如“把红杯子放到绿盘子里”）时，如果场景发生几何偏移（如相机角度变化、物体位置挪动），整体标记会将物体身份与周围环境纠缠在一起，导致动作解码器无法稳定锁定目标，从而引发操作失败。论文的研究动机是构建一种能够将“操作哪个物体”与“物体当前状态”在架构层面解耦的模型，以提升机器人在复杂扰动下的鲁棒性。

### 2. 论文提出的方法论
OA-WAM 的核心思想是将世界模型组织为一组**可寻址的物体槽位（Object Slots）**，并通过架构约束确保动作生成直接挂钩于特定的物体身份。

*   **核心技术细节：**
    *   **槽位分解：** 每一帧被分解为 $N+1$ 个槽位（1个机器人槽位，$N$个物体槽位）。每个槽位向量由两部分组成：**固定地址向量 ($addr_k$)**（在回合开始时由语言标签和初始特征确定，代表“它是谁”）和**时变内容向量 ($content_t^k$)**（每帧更新，代表“它在哪、什么样”）。
    *   **对象可寻址注意力（OA Attention）：** 在 Transformer 的 32 个层中，跨槽位注意力的 **Key 投影仅读取 $addr$ 子向量**。此外，每层都会通过前向钩子（Forward Hook）重置残差流中的地址切片，防止身份信息在层间传递时发生漂移。
    *   **块因果序列（Block-causal Sequence）：** 将文本、图像 VQ、槽位、本体感受和过去动作标记组装成序列，保持帧间因果性，但允许帧内槽位双向注意力。
    *   **双头预测架构：** 
        *   **世界头（World Head）：** 回归预测下一帧各槽位的内容和位姿。
        *   **动作头（Action Head）：** 采用流匹配（Flow-matching）技术，在单次前向传播中解码出 16 步连续动作块。

### 3. 实验设计
*   **数据集与场景：**
    *   **LIBERO：** 包含 Spatial、Object、Goal、Long 四个子集，用于评估分布内（In-distribution）性能。
    *   **SimplerEnv (WidowX)：** 用于评估模拟到真实的视觉匹配能力。
    *   **LIBERO-Plus：** 核心鲁棒性基准，包含相机位姿、机器人初始状态、布局、光照、背景、语言描述、传感器噪声 7 个扰动轴。
*   **对比方法：**
    *   **VLA 基准：** OpenVLA, $\pi_0$, $\pi_{0.5}$, InternVLA-M1, SpatialVLA 等。
    *   **WAM 基准：** WorldVLA, VLA-JEPA, Cosmos-Policy, GE-Act, F1-VLA 等。

### 4. 资源与算力
论文详细记录了三个阶段的训练开销：

*   **Stage I（对齐）：** 使用 8 张 A100，耗时 3-4 天。

### 5. 实验数量与充分性
实验设计非常充分且具有高度的客观性：
*   **多维度评估：** 不仅在标准基准上刷榜，还重点在 7 种不同的 OOD（分布外）扰动下进行了压力测试。
*   **消融实验（A1-A4）：** 严格隔离了“地址掩码”和“地址重置钩子”的作用，证明了鲁棒性增益确实源于 OA 约束而非单纯的感知增强。
*   **因果干预测试：** 创新性地进行了“槽位交换”实验，通过交换两个物体的地址向量观察机器人轨迹是否发生偏移，这是验证模型内部逻辑最直接的手段。

### 6. 主要结论与发现
*   **性能领先：** OA-WAM 在 LIBERO (97.8%) 和 SimplerEnv (79.3%) 上达到或超过了 SOTA 水平。
*   **几何鲁棒性极强：** 在 LIBERO-Plus 的几何轴（相机、机器人状态、布局）上，OA-WAM 的表现显著优于所有整体式模型（几何平均分 84.3%，比 $\pi_{0.5}$ 高出 4.8%）。
*   **机制验证：** 槽位干预测试显示 OA-WAM 的交换绑定余弦值高达 0.87，而传统模型几乎为 0（$\le 0.09$），证明 OA-WAM 真正实现了语言指令与物理对象的结构化绑定。

### 7. 优点
*   **架构创新：** 提出了一种参数高效且物理意义明确的“地址-内容”分离机制，解决了 VLA 模型长期存在的“目标纠缠”问题。
*   **可解释性与可干预性：** 提供了物体级别的干预接口，使得研究者可以观察并操纵模型对特定物体的注意力。
*   **训练策略稳健：** 通过三阶段训练（预训练-对齐-微调），成功将基础多模态模型转化为高性能的机器人策略。

### 8. 不足与局限
*   **感知瓶颈：** 模型高度依赖上游的感知管线（SAM3 + DINOv3）。在“传感器噪声”扰动下，性能下降明显（-17.1%），因为图像质量受损会导致槽位提取失败。
*   **实时性挑战：** 尽管主干网络推理较快，但前端感知（约 138ms）占据了总耗时的大部分，对于极高频的控制任务可能存在压力。
*   **模拟器依赖：** 目前验证主要在仿真环境（SimplerEnv, LIBERO）中完成，尚未展示大规模真机部署的长期稳定性数据。
