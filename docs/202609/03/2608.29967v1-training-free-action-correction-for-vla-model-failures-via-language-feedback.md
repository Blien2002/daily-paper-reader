## Abstract
Vision-Language-Action (VLA) models demonstrate strong semantic understanding yet exhibit systematic failures during deployment. The conditions under which these failures occur, and whether they can be corrected without retraining, remain poorly understood. In this paper, we take steps toward addressing this gap. We present CorrectVLA, a framework that translates task-level natural language corrections into additive action magnitude adjustments without modifying policy weights. A human provides a single task-level correction, applied uniformly across all rollouts without per-episode intervention. In simulation, CorrectVLA recovers execution misalignment failures across both in-distribution and OOD tasks. In real-robot experiments on a UFactory xArm7 under environment shift, CorrectVLA restores near-perfect success where the base policy almost entirely breaks down, generalizing across object locations and identities. Through a taxonomy of failure modes on LIBERO-90, we find that execution misalignment failures, where the policy reaches the correct target but miscalibrates action magnitudes, represent the correctable subset, while other failure modes where semantic comprehension itself breaks down are not amenable to this approach. The approach succeeds when policies possess strategic correctness and fails when fundamental comprehension is absent, establishing a practical operational boundary for inference-time correction.

## 1. 论文的核心问题与整体含义

- **研究背景**：Vision-Language-Action（VLA）模型在语义理解上表现很强，但部署到新环境（光照、相机视角、桌面等变化）时，常出现系统性执行失败，例如动作幅度偏差、抓取过浅、推动过弱等。
- **核心问题**：这些失败在什么条件下发生？能否在不重新训练模型的情况下，只通过推理时干预来纠正？
- **现有方法局限**：
  - 训练时方法需要收集新演示并更新权重，成本高、需 GPU 和专业知识；
  - 测试时引导方法（如 ITPS、FOREWARN）要么需要持续人类指导或采样候选动作，但无法在原始策略输出分布之外生成针对系统性幅度误差的纠正行为。
- **整体含义**：论文提出 CorrectVLA，探索一种免训练、利用任务级自然语言反馈来修正 VLA 动作幅度错误的范式，并界定“哪些失败可被推理时纠正”的操作边界。

## 2. 方法论

- **核心思想**：将人类的语言纠正（如“向下一点，2.0–2.3 秒”）映射为对冻结策略动作输出的**加性幅度调整**，不修改策略权重。
- **关键假设**：
  - 策略具备“战略正确性”（即知道正确目标和方法），失败仅因动作幅度校准错误；
  - 少量稀疏、按维度的幅度修正足以将“差一点成功”的轨迹变为成功；
  - 人类能通过观察完整 rollout 后给出稀疏反馈。
- **三阶段处理流程**：
  - **Phase A：结构化参数提取**。使用 LLM 从自然语言反馈中提取四个结构化参数：动作维度 \(d_k\)（如 x, y, z, gripper）、方向 \(s_k\)（+1/−1）、幅度词 \(m_k\)（slightly/more/much）和时间窗口 \([t_{\text{start},k}, t_{\text{end},k}]\)。
  - **Phase B：幅度量化**。将幅度词映射到数值范围：“slightly”→[0.3, 0.5]，“more”→[0.5, 0.8]，“much”→[0.8, 1.0]；LLM 在该范围内选值并乘以方向，得到带符号幅度 \(w_k \in [-1.0,1.0]\)。
  - **Phase C：时间分布**。使用分段线性包络 \(\phi_k(t)\)，在指定时间窗口内从 0 升至中点峰值再降回 0；窗口外无影响。
- **最终修正公式**：
  - 对于多个反馈 \(f_1,\dots,f_K\)，按维度聚合：\(\delta_d(t)=\sum_{k:d_k=d} w_k \phi_k(t)\)；
  - 修正后的动作：\(a^{\text{corrected}}_{t,d}=a_{t,d}+\delta_d(t)\)。
- **部署特点**：反馈是任务级的一次性纠正，可复用于该任务所有 rollout，无需逐情节人工干预；策略权重全程冻结。

- **对比方法**：

  - **LLM Baseline**：VLM（GPT-5 mini）自主观察失败视频，生成校正参数，无人类输入。
  - **CorrectVLA（本文）**：人类提供任务级语言纠正，经由 Claude Sonnet 4.5 格式化为 JSON。
- **评估协议**：
  - 仿真 in-distribution：40 个任务 × 50 次 trials = 2000 rollouts；
  - 仿真 OOD：LIBERO-90 全部 90 个任务 × 5 次 trials = 450 rollouts；

  - 真实机器人：pick-and-place 任务，三个泛化条件（同物体/环境变化、同物体/位置变化、不同物体/位置变化），共 20 次 trials。

## 6. 主要结论与发现

- **失败分类学**（LIBERO-90 OOD）：识别出四种一致模式：
  - Task Misunderstanding：约 47%–50%，操作了错误物体；
  - Perception Failure：约 22%–25%，目标被完全忽略；
  - Execution Misalignment：约 22%–23%，目标正确但动作幅度失准；
  - Multi-step Planning：约 5%–6%，第一子目标成功、第二子目标放弃。
- **可纠正性边界**：只有 Execution Misalignment 保留战略正确性，适合推理时幅度校正；语义理解类失败无法通过加性动作修正解决。
- **仿真结果**：
  - In-distribution：π0.5 基础成功率 93.0%；CorrectVLA 恢复 46.8% 的失败样本，总体提升至 96.3%。
  - OOD：π0.5 基础成功率 27.1%；CorrectVLA 恢复 10.1% 的失败样本，总体提升至 34.4%。
  - LLM Baseline 在所有设置下恢复率为 0。
- **真实机器人结果**：底座移动后，π0.5 从 95% 跌至 10%；CorrectVLA 用单个任务级纠正将成功率恢复到 95%（19/20），并在同位置、不同位置、不同物体条件下泛化。
- **核心洞见**：策略的高层结构（接近、抓取、搬运）保持完整，只需调整关键时间瓶颈处的幅度即可将失败转为成功；语言反馈恰好能定位这种校准误差。

## 7. 优点

- **训练无关**：无需更新 VLA 权重、不需要新演示或 GPU 训练，极大降低部署适应成本。
- **人类反馈高效**：单次任务级纠正即可在多次 rollout 中复用，无需逐情节人工监督。
- **清晰的操作边界**：通过失败分类学明确哪些错误可被推理时纠正，避免盲目重训练。
- **方法简单可解释**：语言到动作的映射过程透明，修正以加性偏置形式作用于动作维度，易于调试。
- **真实机器人验证**：在显著环境偏移下仍能从几乎完全失败恢复到接近完美，展示实际部署潜力。
- **适用于两种不同架构模型**：失败分类在 OpenVLA-OFT 和 π0.5 上表现一致，说明发现可能具有一般性。

## 8. 不足与局限

- **应用范围受限**：仅能处理 Execution Misalignment，对占多数的语义理解类失败（Task Misunderstanding、Perception Failure）无效。
- **幅度映射粗糙**：预定义的 “slightly/more/much” 数值范围是经验性的，可能不够精确，导致需要多轮人工反馈。
- **任务级纠正假设过强**：默认单一代表性失败能覆盖该任务所有 rollouts；若失败模式在不同 episode 间差异较大，单一纠正可能无法泛化。
- **真实世界证据有限**：真实机器人实验规模小（20 trials）、任务类型单一（pick-and-place），且失败分类学来自仿真，现实分布可能不同。
- **缺少与更强测试时方法的直接比较**：未与 ITPS、FOREWARN 等现有 steering 方法进行统一条件对比；LLM Baseline 的设计也未能完全公平地体现自动纠正潜力。
- **未提供消融与敏感性分析**：例如不同幅度词区间、时间窗口长度、多个反馈叠加方式等对性能的影响没有系统研究。
