## 摘要
从多具身数据集学习大规模视觉-语言-动作（VLA）模型仍然具有挑战性，因为不同末端执行器之间的动作空间存在异构性。尽管潜在动作模型（LAMs）能够从多样化的视频数据中学习与具身无关的动作表示，但现有的基于图像的LAM通常难以捕捉细粒度的末端执行器关节运动，尤其是人类手和灵巧机器人手的手指级几何变化。为了解决这一局限，我们提出GALA，一个几何感知潜在动作建模框架，通过3D末端执行器几何运动增强基于图像的潜在动作。然而，简单地结合点云会得到共享语义有限的细粒度动作表示，妨碍跨具身预训练。为了解决这一问题，我们引入了统一末端执行器运动表示（UEMR），它在保留细粒度运动信息的同时提高潜在动作的跨具身泛化能力。基于UEMR，GALA将捕捉场景级动态的视觉潜在动作与捕捉共享细粒度末端执行器关节运动的几何潜在动作相结合，为来自多具身数据（包括无动作的第一人称人类视频）的VLA预训练提供有效监督。在细粒度运动探测、跨具身检索和下游VLA评估上的实验表明，GALA在建模跨具身可泛化的细粒度运动方面具有有效性，取得了68.3%的RoboCasa-GR1成功率和75.5%的真实世界成功率。代码、附录和演示可在 https://puzhenyuan.github.io/GALA-website/ 获取。

## Abstract
Learning large-scale vision-language-action (VLA) models from multi-embodiment datasets remains challenging due to heterogeneous action spaces across end effectors. Although latent action models (LAMs) can learn embodiment-agnostic action representations from diverse video data, existing image-based LAMs often fail to capture fine-grained end-effector articulation, particularly finger-level geometric changes in human and dexterous robot hands. To address this limitation, we propose GALA, a Geometry-Aware Latent-Action modeling framework that augments image-based latent actions with 3D end-effector geometric motion. However, naively incorporating point clouds yields fine-grained action representations with limited shared semantics, hindering cross-embodiment pretraining. To address this issue, we introduce the Unified End-effector Motion Representation (UEMR), which preserves fine-grained motion information while improving the cross-embodiment generalizability of latent actions. Building upon UEMR, GALA combines visual latent actions that capture scene-level dynamics with geometric latent actions that capture shared fine-grained end-effector articulation, providing effective supervision for VLA pretraining from multi-embodiment data, including action-free ego-centric human videos. Experiments on fine-grained motion probing, cross-embodiment retrieval, and downstream VLA evaluation demonstrate GALA's effectiveness in modeling generalizable fine-grained motions across embodiments, achieving 68.3% RoboCasa-GR1 success rate and 75.5% real-world success rate. Code, appendix, and demos are available at https://puzhenyuan.github.io/GALA-website/.

## 1. 核心问题与整体含义

- **研究背景**：大规模视觉-语言-动作（VLA）模型需要海量操作数据，但机器人演示采集成本高；人类视频是低成本补充，却存在不同末端执行器（人手、灵巧机器人手、平行夹爪）之间动作空间异构的问题。
- **核心问题**：现有基于图像的潜在动作模型（LAM）主要捕捉场景级末端位移，难以表征手指级细微关节运动（尤其是人手和灵巧手），导致跨具身预训练缺乏细粒度动作监督。
- **整体含义**：该工作提出几何感知潜在动作建模，用 3D 末端执行器几何运动增强图像潜在动作，旨在打通“人类视频—异构机器人数据”的共享表示，提升跨具身 VLA 预训练效果。

## 2. 方法论

- **总体框架**：GALA 分为两个阶段：
  1. **几何感知潜在动作学习**：从 RGB 和点云对中联合学习视觉潜在动作与几何潜在动作；
  2. **几何感知 VLA 联合训练**：冻结的潜在动作编码器监督 VLM 的桥接 token，同时共享 DiT 预测各具身原生连续动作。

- **点云生成**：
  - 将末端执行器表示为腕部/根部中心坐标系下的无序点云 \(P^{e,h}_t \in \mathbb{R}^{N \times 3}\)，\(N=1024\)；
  - 人手通过 WiLoR 估计 MANO 网格并采样；机器人通过 URDF/MJCF 前向运动学获取表面采样，统一表达，无需点、关节或网格拓扑对应。

- **视觉与几何动作编码**：
  - 给定起始-目标区间 \((s,g)\)，输入 RGB \((I_s,I_g)\)、语言指令 \(\ell\)、左右手点云对；
  - 使用冻结的 DINOv2 + SigLIP 编码图像，冻结的 Point Transformer V3 编码点云；
  - 共享时空 Transformer 融合特征，输出视觉 token 和几何 token；几何 token 通过共享 EMA-VQ 码本量化为离散潜在动作 \(Q(Z_G)\)。

- **UEMR（统一末端执行器运动表示）**，包含三个核心设计：
  1. **统一双手运动潜在**：一个几何潜在同时表示左右手在区间内的几何转换；单臂数据则将同一点云输入两个分支。解码器以初始几何为条件重构目标几何：
     \[
     \hat{P}^R_g = D_G(P^R_s, Q(Z_G)), \quad \hat{P}^L_g = D_G(P^L_s, Q(Z_G))
     \]
     使用 Chamfer Distance 作为重构损失 \(L_{G\text{-}rec}\)。
  2. **配对一致性几何增强**：对起始-目标点云对施加相同的随机 3D 变换（缩放、旋转、平移），保留相对运动但扰动绝对坐标，降低坐标系捷径。
  3. **双向转换学习**：同时学习 forward \((s \to g)\) 和 backward \((g \to s)\) 的几何转换，共享编码器、码本和解码器，增加时间动态监督。

- **损失函数**（第一阶段）：
  - 每个方向联合优化视觉潜在动作目标（\(L_{I\text{-}rec} + L_{I\text{-}codebook} + \beta L_{I\text{-}commit}\)）和几何目标（\(\lambda_G L_{G\text{-}rec} + \beta\lambda_G L_{G\text{-}commit}\)）；
  - 总损失 \(L_{LAM} = L_{forward} + L_{backward}\)。

- **VLA 联合训练**：
  - 基于 GR00T 架构，VLM 接受当前观测、语言指令和两组可学习桥接 token（\(q^{img}, q^{geo}\)），预测视觉和几何潜在动作 token；
  - 潜在动作预测使用交叉熵损失：\(L_{latent} = CE(k^{img}_t, \hat{k}^{img}_t) + \lambda_{geo} CE(k^{geo}_t, \hat{k}^{geo}_t)\)；
  - 连续动作采用流匹配，共享 DiT 处理 VLM 上下文、状态、噪声动作块和时间步，再接各具身专用动作头 \(h_e\)；
  - 总 VLA 损失：\(L_{VLA} = L_{action} + \lambda_{latent} L_{latent}\)。

## 6. 主要结论与发现

- GALA 在细粒度运动探测中取得最低位置、旋转和手指误差，证明几何潜在表示保留了更丰富的末端执行器关节运动信息；
- 跨具身检索中，GALA 的 R@1、P@5、mAP 均优于 METIS、OPFA、Native Kinematics 等基线，说明 UEMR 学习到了更可迁移的共享运动语义；
- RoboCasa 模拟中，GALA 在仅 GR-1 数据下达到 55.7% 成功率，在多具身联合训练下达到 68.3%，相比 GR-1-only 提升 12.6%，超过其他基线；
- 真实世界任务平均成功率 75.5%，优于 HARP-VLA 4.0 个百分点、π0.5 7.5 个百分点，验证了方法的实际灵巧操作能力；
- 消融显示移除点云或 UEMR 均会导致性能下降，证明几何建模和统一运动表示对跨具身预训练至关重要。

## 7. 优点

- **新颖性**：首次将 3D 末端执行器点云几何运动与图像潜在动作结合，专门解决手指级细粒度动作建模问题；
- **跨具身设计**：UEMR 通过统一双手潜在、配对一致性增强和双向转换学习，有效缓解了点云表示中形态与坐标特异性导致的共享语义不足；
- **不要求统一动作空间**：下游 VLA 保留各具身原生动作空间，仅通过共享 DiT 和专用动作头实现可执行控制，设计实用；
- **利用无动作人类视频**：可以从第一人称人类视频中提取几何监督，降低对标注机器人数据的依赖；
- **实验多维验证**：从表示质量（探测、检索）到策略学习（模拟、真实世界）均进行了评价，证据链较完整。
