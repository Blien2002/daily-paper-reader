## 摘要
感知环境中的物体是自主机器人的基本能力。在黑暗或低光照环境中，外部相机往往无法可靠感知物体的位置与几何形状；当视觉感知不可用时，仅通过触觉完成目标搜索、识别与抓取就成为机器人操作的关键能力。该任务须同时处理容器尺度的空间探索和物体尺度的精细几何感知，这对低自由度的平行夹爪尤其具有挑战性。然而，目前仍缺乏一个统一框架，将容器尺度的空间探索与物体尺度的精细几何感知及抓取连接起来。为应对这一挑战，我们提出了 GLoTouch，一个建立在平行夹爪上的全局到局部触觉感知与操作框架。在全局阶段，夹爪持有一个被动式长探针，将力测量与已知工具几何相结合来定位接触点，并主动估计候选物体的位置、粗略轮廓和高度。在局部阶段，机器人放下探针，利用同一夹爪上的双侧视触觉传感器直接获取局部触觉观测，并将其与给定的目标三维模型进行匹配，无需针对特定物体进行训练。我们在仿真和真实机器人实验中评估了该框架。源代码将开源。

## Abstract
Perceiving objects in the environment is a fundamental capability of autonomous robots. In dark or low-light environments, external cameras often fail to reliably perceive object positions and geometry; when visual sensing is unavailable, completing target search, recognition, and grasping through touch alone becomes a key robot manipulation capability. This task must simultaneously address container-scale spatial exploration and object-scale fine-grained geometric perception, which is particularly challenging for low-degree-of-freedom parallel grippers. However, a unified framework remains lacking for connecting container-scale spatial exploration with object-scale fine-grained geometric perception and grasping. To address this challenge, we present \textbf{GLoTouch}, a global-to-local haptic perception and manipulation framework built on a parallel gripper. In the global stage, the gripper holds a passive long-reach probe, combining force measurements with known tool geometry to localize contacts and actively estimate candidate-object positions, coarse contours, and heights. In the local stage, the robot sets down the probe and uses the bilateral visuotactile sensors on the same gripper to directly acquire local haptic observations, which are matched against a given target 3-D model without object-specific training. We evaluate the framework in both simulation and real-robot experiments. Source code will be open-sourced.

## 2. 论文提出的方法论

### 2.1 系统总体流程
GLoTouch 分为两个阶段：

- **全局阶段（Global Haptic Exploration）**：夹爪夹持一个无传感器、被动式球形末端长探针；通过腕部力/力矩和机器人运动学推断探针末端的环境接触，进行覆盖驱动的搜索，估计候选物体的平面位置、粗略轮廓（圆形/矩形）和高度。
- **局部阶段（Local Haptic Recognition）**：机器人放下探针，用同一夹爪的双侧视触觉传感器对每个候选物体进行多高度、多序列的闭合采集，获取局部深度图和夹爪开度；将结构化触觉观测与给定目标 STL 的有限窗口支撑几何进行匹配，按匹配损失排序，选择最低损失的候选物体进行抓取。

### 2.2 全局探针探索关键技术

- **接触检测与主动回退**：对腕部力/力矩进行零位标定和低通滤波，得到残差 \(\Delta w_t = \mathrm{LPF}(w_t - \bar{w})\)。当沿运动方向的反向力超过软阈值并持续若干周期时，判定法向接触；另有硬阈值触发立即安全停止。检测后立即停止，并沿相反方向回退一段距离，随后开始轮廓跟踪。
- **工具几何感知的接触定位**：
  - 反应方向 \(r_t = \Delta f^B_{t,xy} / \|\Delta f^B_{t,xy}\|_2\)。
  - 物体面向方向 \(d_t = (u_t - r_t)/\|u_t - r_t\|_2\)，其中 \(u_t\) 是命令运动方向。
  - 探针截面 \(P\) 在方向 \(d_t\) 上的支撑距离 \(h_P(d_t) = \max_{p \in P} d_t^T R_{BE,t} p\)。
  - 接触点估计 \(\hat{p}_t = x_{E,t} + h_P(d_t) d_t\)，用于后续轮廓估计。
- **覆盖驱动搜索**：
  - 维护已执行路径样本集合 \(E\)，在容器内均匀采样前沿候选点，若候选点到最近已执行路径样本的距离大于覆盖半径 \(r_{cov}\)，则为未探索前沿。
  - 选择最近未探索前沿生成连续笛卡尔路径进行搜索；无接触路径加入 \(E\)，有接触则切换为局部边界跟踪。
- **轨道-径向探测轮廓估计（Orbit-and-Probe）**：
  - 从当前中心估计出发，移动到安全轨道，按角度增量沿轨道运动，然后径向接近中心，利用已知接近方向获得边界接触点。
  - 对圆形候选物体，用鲁棒软 \(\ell_1\) 圆拟合求解圆心和半径；若圆残差较大，则拟合有向矩形，得到中心、轮廓类别、尺度、平面朝向。
  - 最后从中心上方垂直下降，以相同接触检测估计物体高度；候选记录为 \(C_i = (\hat{c}_i, \hat{H}_i, s_i, \hat{\theta}_i, k_i, q_i)\)。

### 2.3 局部触觉识别关键技术

- **稳定触觉采集与质量评估**：
  - 夹爪在候选物体上方分层闭合，只有在开度达到稳定平台且 TCP 运动较小时才接受该层；记录开度 \(g_{k,h}\)。
  - 对左右触觉深度图进行时间中值滤波，提取接触掩码和足够大的支持斑块；用拟合平面残差定义非平面度 \(\rho_{k}\)，并记录有效斑块比例 \(q_{D,k}\)。
  - 对双向闭合层权重最高，单向闭合层降权，无效层排除。
- **目标条件有限窗口匹配**：
  - 根据全局轮廓选择采集模式：圆形候选在三个独立偏航角采样；矩形候选沿三条平行纵向轨迹采样。
  - 参考开环 TCP 位置和旋转推断动作图，通过坐标 SVD 得到纵向坐标 \(a_k\)；用逻辑函数计算耦合概率 \(p_c\)，衡量三条序列是否共享同一模型位姿。
  - 对目标 STL，给定尺度 \(s\)、相对偏航 \(\theta\) 和触觉窗口 \(W(l,z)\)，预测支撑宽度 \(W_M(l,z;s,\theta)\) 和表面法线离散度 \(d_M\)。
  - 预测开度 \(\hat{y}_{k,h} = W_M(a_k + \delta, z_{k,h}+z_0;s,\theta) + b\)，其中 \(\delta, z_0, b\) 为对齐偏移和开度偏置。
  - 宽度损失 \(G\) 包含绝对、中心化、纵向差分、跨动作残差及覆盖惩罚、偏置惩罚，使用加权 Huber RMS；局部深度损失 \(\mathcal{L}_{depth}\) 比较观测非平面度和模型预测表面信息；另有尺度先验 \(\lambda_s |\log s|\) 和各向异性先验 \(\lambda_{cm} a_M^2 (1-p_c)\)。
  - 最终匹配损失为宽度损失 + 深度损失 + 采集模式一致性损失。

### 2.4 排序与抓取

- 对固定目标 STL，比较所有候选物体的 TouchSet 匹配损失 \(\mathcal{L}_{match}(D_j | M)\)。
- 仅当最佳候选相对第二候选具有足够损失裕度、绝对拟合质量和触觉证据时，才接受决策。
- 抓取中心由局部接触中心修正，矩形方向用全局主轴初始化，夹爪在力限制下闭合并提起选中物体。

## 6. 论文的主要结论与发现

- **统一框架可行性**：GLoTouch 证明，一个低自由度平行夹爪可以通过临时夹持被动探针，同时完成容器尺度力学搜索与物体尺度触觉识别，并保持最终抓取能力。
- **探针接触优于直接夹爪接触**：在标定正方形上，探针介导的轮廓跟踪中心误差为 0.37 mm，接触 RMS 为 0.87 mm，明显优于裸夹爪的 3.15 mm 和 5.08 mm。
- **全局搜索明显优于随机下降**：在 100 个随机布局中，覆盖驱动搜索在 5 m 路径预算下完全发现 5 个物体的布局比例为 55%，而随机下降仅 30%；平均发现数量也更高。
- **局部匹配训练无关但有效**：组件级匹配 Top-1 准确率 90.0%（60 样本），完整匹配损失矩阵中对角线损失明显较低，说明基于有限窗口支撑几何的方法可以区分物体。
- **端到端检索性能**：仿真 84.0%（84/100），真机 76.0%（38/50）；Apple 最容易（真机 100%），Train 最难（真机 50%），主要失败集中在 Train/Truck 混淆和抓取阶段物体倾倒。

## 7. 优点

- **方法简洁且硬件要求低**：仅依赖平行夹爪、腕部力/力矩和双侧视触觉传感器，探针为无传感器被动工具，易于部署和开源复现。
- **“全局-局部”解耦合理**：全局用探针解决长距离接触检测和轮廓估计，局部用视触觉传感器进行精细匹配，最后仍用同一夹爪抓取，流程连贯。
- **无需物体特定训练**：匹配器基于给定 STL 模型和几何预测，泛化到新物体只需输入新网格，避免大量真实机器人数据采集。
- **几何感知接触定位**：结合已知工具几何和力方向估计接触点，并通过实验验证探针方式显著优于裸夹爪。
- **实验设计较客观**：参数冻结、随机布局、严格端到端成功标准、消融对比和仿真/真机双重验证，增强了结果可信度。
- **失败分析诚实**：明确指出 Train/Truck 混淆和物理稳定性问题，并给出匹配矩阵的定量依据。

## 8. 不足与局限

- **假设较强**：要求已知目标 STL 模型、物体顶部可到达、容器支架与机器人配准已知、场景物体数量已知。这些假设在真实未知环境中不一定成立。
- **局部匹配未利用全部触觉信息**：未使用视触觉 RGB 通道，只用了深度和开度；可能限制对纹理、表面细节的区分能力。
- **轮廓模型过于简单**：只支持圆形和矩形两类，对复杂形状或不规则物体可能失效。
- **物体位移问题未完全解决**：虽然局部匹配设计为对重复接触引入的位姿偏移鲁棒，但物体在探针接触或夹持中可能旋转、倾倒，导致观察到改变；真机失败中物理不稳定性是重要原因。
- **实验覆盖范围和统计强度有限**：物体种类少、数量固定为 5，真机每目标仅 10 次；Train 成功率 50% 表明边界情况未被更好处理。没有进行不同物体数量、密集杂乱、不同容器尺寸或更复杂杂波下的实验。
- **未报告算力与时间**：虽然方法不需要训练，但仿真和真机的单次运行时间、实现复杂度、调参成本均未说明，这影响可复现性和实用评估。
- **没有与现有方法的直接定量对比**：相关工作如 TactoFind、STUCCO 等多指手或粒子滤波方法未在相同基准下直接比较，难以判断相对性能提升幅度。
- **决策接受条件的人为设置**：成功率依赖“最佳候选具有足够裕度”的阈值，这些阈值如何选择、对成功率的影响未充分分析。
