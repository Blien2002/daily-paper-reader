## 摘要
视觉-语言-动作模型告诉机器人移动到哪里，但没有告诉它用多大的力去推。接触密集型任务依赖于后一个量——柔顺性，但目前广泛使用的示教接口都没有记录它。障碍在于可辨识性：实际达到的位姿和测量的力无法将操作者意图的平衡位置与其刚度区分开来，因此 VR 控制器、SpaceMouse 和手持夹爪即使在原理上也无法提供柔顺性监督。先前输出柔顺性的策略通过手工指定任务结构、仿真中特权接触状态或专用力与触觉硬件来绕过这一问题。四通道双边遥操作通过将主端机械臂作为意图平衡位置的独立测量，直接消除了这一歧义，使得仅利用机械臂上已有的关节力矩传感即可通过回归辨识每个轴的刚度。这以零标注成本生成了每个时间步、依赖方向的柔顺性标签，我们利用这些标签微调 VLA，使其在输出位姿的同时输出刚度。在 Franka Research 3 擦拭任务中，当指令要求用力擦拭而非正常擦拭时，五个策略中只有我们的策略接触力发生变化（RMS 从 6.4N（正常）到 9.1N（用力），Cohen's d = 0.89，p = 0.023）。

## Abstract
Vision-language-action models tell a robot where to move, but not how hard to push. Contact-rich tasks depend on that second quantity, compliance, yet no widely used demonstration interface records it. The obstacle is identifiability as realized pose and measured force cannot separate the operator's intended equilibrium from their stiffness, so VR controllers, SpaceMouse and handheld grippers cannot supply compliance supervision even in principle. Prior compliance-output policies work around this with hand-specified task structure, privileged simulation contact state, or dedicated force and tactile hardware. Four-channel bilateral teleoperation removes the ambiguity directly by using the leader arm as a separate measurement of the intended equilibrium, making per-axis stiffness identifiable by regression using only the joint-torque sensing already on the manipulator. This yields per-timestep, direction-dependent compliance labels at zero annotation cost, which we use to fine-tune a VLA to emit stiffness alongside pose. # 论文总结：Compliance for Free: Learning Identifiable Impedance via Bilateral Teleoperation

## 1. 论文的核心问题与整体含义

- **核心问题**：视觉-语言-动作（VLA）模型通常只预测机器人“往哪里移动”（位姿轨迹），但接触丰富任务（擦拭、精密插入、装配）还需要控制“用多大力/多柔顺地接触”，即**柔顺性/阻抗**。主流演示接口（VR 控制器、SpaceMouse、手持夹爪、低成本双臂装置等）只记录末端实际位姿和力，无法分离操作者**意图平衡位姿**与**刚度**，因此无法提供柔顺性监督。
- **根本障碍——可辨识性问题**：在阻抗模型中，接触力 \(f = K e + D \dot{e}\)，其中 \(e = x_{eq} - x_f\) 是意图平衡位姿与实际位姿之差。如果只观测 \(x_f\) 和 \(f\)，不观测 \(x_{eq}\)，则任意缩放 \(K\) 和 \(e\) 都能得到同样的力，刚度无法唯一确定。位姿-only 接口记录不到 \(x_{eq}\)，所以即使再多的数据也无法事后恢复 \(K\)。
- **论文整体含义**：利用四通道双边遥操作，把主端机械臂轨迹 \(x_l(t)\) 作为操作者意图平衡位姿 \(x_{eq}(t)\) 的独立测量，从而打破可辨识性歧义；仅用机械臂已有的关节力矩传感，就能以零额外标注成本提取每时间步、方向依赖的刚度标签，并微调 VLA 使其同时输出位姿和刚度。在 Franka Research 3 擦拭任务上，只有该方法能让接触力随“用力擦/正常擦”语言指令变化。

## 2. 论文提出的方法论

### 2.1 核心思想：用双边遥操作解决可辨识性

- 四通道双边遥操作主动耦合主端与从端机械臂：从端跟随操作者手部运动，同时把从端感受到的接触力反馈给操作者。
- 在主从耦合下，主端位姿 \(x_l(t)\) 是独立记录的测量，可直接视为操作者意图平衡位姿 \(x_{eq}(t) := x_l(t)\)。
- 于是位移 \(e(t) = x_l(t) - x_f(t)\) 被直接观测，刚度 \(K(t)\) 和阻尼 \(D(t)\) 可通过回归辨识。

### 2.2 顺应性标签提取流程

1. **接触坐标系定义**：对接触位置做 SVD，取最小奇异值对应右奇异向量作为表面法向 \(\hat n\)；若平面度 \(\sigma_3/\sigma_1 > 0.15\) 则拒绝该拟合。
2. **窗口回归**：对每个轴，在 300 ms 滑动窗口内、1 kHz 控制率下，求解带正则化和箱约束的非线性最小二乘，估计 \(k_i\) 和 \(d_i\)。正则项在 log 空间鼓励接近先验刚度，\(k_i\) 限制在控制器安全范围 \([k_{\min}, k_{\max}]\)，\(d_i \ge 0\)，并采用临界阻尼 \(d_i = 2\sqrt{k_i}\)。
3. **可辨识性掩码**：只保留真正可辨识的标签。掩码条件包括：回归矩阵条件数不能过大、位移幅值高于阈值、力高于该轴噪声底、且处于接触状态。
4. **无传感器力矩估计**：
   - 静态姿态下，残差力矩与未知负载质量及质心呈线性关系，用 15 个静态位姿做最小二乘识别工具自重。
   - 每次会话前在固定自由空间位姿采样并减去常值偏置。
   - 用随机傅里叶特征岭回归在自由空间扫描数据上拟合与位形/速度相关的慢变偏置；每轴独立拟合，输入 \(x = (q, \dot{q}) \in \mathbb{R}^{14}\)，512 个特征。
   - 噪声底 \(\sigma_{f,i}\) 取原始 RMS 与偏置校正后 RMS 的较小者，用于掩码中的信噪比条件。
   - 通过固定零空间姿态和约束工作空间降低配置依赖误差。

### 2.3 策略设计与训练

- **骨干**：SmolVLA（约 450M 参数，来自 LeRobot），冻结预训练视觉-语言模型，仅微调动作专家。
- **输入**：两个 224×224×3 相机流（场景相机 + 腕部相机）、语言指令（如“wipe the left mark firmly”）、500 ms 六维力历史 token（经 1D 卷积编码，在 VLM 后注入，类似 ForceVLA）。
- **输出**：长度 \(H=32\) 的动作块，每步包含 \([x_{eq}(6), \log K(6)]\)，即绝对目标位姿与六轴对数刚度。
- **损失**：位姿用 flow-matching L1 损失；\(\log K\) 用 Huber 损失，只在掩码标记可辨识的时间步上计算。
- **数据增强**：力 dropout（\(p=0.15\)）和随机力偏置注入（±1 N），防止模型忽略低维力输入。
- **训练设置**：单张 NVIDIA L40S；所有策略统一微调 2500 步，batch size 64，AdamW 学习率 \(10^{-4}\)，三随机种子；可训练参数约 99.9M / 总 450.1M。
- **低层控制器**：Franka Research 3 以 1 kHz 运行笛卡尔阻抗控制器；使用时间集成（temporal ensembling，指数衰减权重 \(m=0.05\)）平滑动作块边界；log 空间刚度变化率限制 \(\gamma=3\ \text{s}^{-1}\)；刚度增大由能量罐（\(E_0=1\) J，\(E_{\max}=5\) J）保证无源性。

## 3. 实验设计

- **主任务**：白板擦拭，板面约 45° 倾斜，末端装刚性擦除器。指令网格为 2×2：“wipe the {left, right} mark {normally, firmly}”。每次 rollout 固定 200 个低层步骤（约 43.5 s），策略 30 Hz 动作率、约 10 Hz 重规划；每格 8 次 rollout，3 个种子，共 24 次/策略。
- **对比的五个策略**：
  - **Fixed-K**：固定手调阻抗 \((300,300,300)\ \text{N/m},\ (20,20,20)\ \text{N·m/rad}\)，只输出位姿。
  - **Fitted-K**：用标签分布拟合出的每轴常数阻抗，但旋转轴落到下界，导致失败率高。
  - **Force-In**：ForceVLA 风格，将力作为输入但只输出位姿。
  - **Hybrid**：ForceVLA2 / Force Policy 风格，输出位姿 + \(K\)，但位姿和 \(K\) 使用分开的解码头。
  - **Ours**：输出位姿 + \(\log K\)，且共享 flow-matching 目标。
- **评估指标**：成功率（自动像素差分判定墨水去除 ≥ 50%）、墨水去除百分比、接触力峰值/RMS（估计力矩）、保护停止次数。
- **补充实验**：
  - 指令条件顺应性链：分别测量演示刚度、策略命令刚度、实际接触力在“firmly vs normally”上的差异。
  - 离线顺应性预测基准：从排除力的特征向量预测 \(\log K_i\)，对比常数基线。
  - 刚度正弦探测：验证真实机械臂对命令刚度的追踪。
  - 因果力消融：冻结力历史 token，观察成功率变化。
