## 摘要
视觉-语言-动作（VLA）或世界动作（WAM）模型最近在机器人操作中展示了卓越的性能。在 LIBERO 上，最先进方法已实现近 100% 的成功率，似乎表明这些模型已准备好部署到现实世界。然而，现有基准上近乎完美的性能可能具有误导性：理想条件下的成功并不意味着真实世界的鲁棒性。现有基准主要评估从预定义初始状态完成任务，而真实世界的交互不可避免地涉及失败，例如抓取失败、碰撞和意外的物体移动。因此，机器人不仅必须成功执行任务，还必须识别失败并从中恢复以继续任务。然而，这种能力在很大程度上仍未得到衡量，揭示了基准性能与真实世界可靠性之间的关键差距。为了解决这一差距，我们引入了 LIBERO-Recover 基准，一个用于机器人操作中失败恢复的大规模基准。基于 LIBERO，我们收集了最先进具身模型的真实执行失败，并构建了 1000 多个场景，涵盖四个恢复级别：（1）动作重试，（2）动作适应，（3）物体状态恢复，（4）环境恢复。我们评估四项核心能力：空间理解、物体结构推理、交互理解和拓扑推理。作为具身失败恢复领域的第一个大规模基准，LIBERO-Recover 将评估从“机器人能否成功？”转变为“机器人在失败后能否恢复？”，从而促进鲁棒且可泛化的具身智能体。项目将在 https://liulin815.github.io/LIBERO-Recovery/ 提供。

## Abstract
Vision-Language-Action (VLA) or World Action (WAM) models have recently demonstrated remarkable performance in robotic manipulation. On LIBERO, SOTA method have achieved nearly 100\% success rates, seemingly suggesting that the models are ready for deployment in real world. However, near perfect performance on existing benchmarks can be misleading: success under ideal conditions does not imply real world robustness. Existing benchmarks primarily evaluate task completion from predefined initial states, while real world interactions inevitably involve failures such as failed grasps, collisions, and unintended object movements. A robot must therefore not only execute tasks successfully, but also recognize and recover from failures to continue the task. Yet this capability remains largely unmeasured, revealing a critical gap between benchmark performance and real world reliability. To address this gap, we introduce LIBERO-Recover Benchmark, a large scale benchmark for failure recovery in robotic manipulation. Built upon LIBERO, we collect real execution failures from SOTA embodied models and construct 1,000+ scenarios across four recovery levels: (1) Action Retry, (2) Action Adaptation, (3) Object State Recovery, and (4) Environmental Recovery. We evaluate four core capabilities: spatial understanding, object structure reasoning, interaction understanding, and topological reasoning. As the first large-scale benchmark for embodied failure recovery, LIBERO-Recover shifts evaluation from \emph{Can the robot succeed?''} to \emph{Can the robot recover after failure?''}, promoting robust and generalizable embodied agents. The project will be avaible in \textcolor{blue}{https://liulin815.github.io/LIBERO-Recovery/}.

- **核心问题**：现有基准无法衡量机器人的**失败识别与恢复能力**，导致基准性能与真实世界可靠性之间存在显著差距。
- **整体含义**：论文提出 **LIBERO-Recover**，将评估范式从“机器人能否成功”转向“机器人失败后能否恢复”，推动具身智能体从理想化任务执行走向鲁棒、可恢复的真实交互。

## 2. 论文提出的方法论

- **问题形式化**：
  - 定义任务为目的条件 \(G(s_T, l)=1\)。
  - 失败状态 \(s_f\) 满足目标未达成但任务仍可恢复。
  - 将执行轨迹分解为失败前轨迹与恢复轨迹，恢复策略需从失败状态出发重新规划并完成原目标。
- **失败与普通状态变化的区分**：失败必须同时满足：
  - 由执行动作诱发；
  - 任务相关（目标未达成）；
  - 使原计划失效（直接继续原动作无法完成）；
  - 仍然可恢复。
- **四级失败难度划分**：
  - **L1 动作重试（Action Retry）**：失败后任务配置几乎不变，只需重试失败动作，如重新抓取。
  - **L2 动作适应（Action Adaptation）**：失败造成有限物体配置变化，需根据观测调整动作，而不是盲目重复。
  - **L3 物体状态恢复（Object State Recovery）**：任务相关物体状态被显著破坏，需先恢复物体姿态/状态，再继续原任务。
  - **L4 环境恢复（Environmental Recovery）**：失败影响非直接操作物体，阻塞后续任务，需要拓扑推理识别并恢复环境状态。
- **场景构建流程**：
  - **Stage 1 任务执行**：从 LIBERO 四个任务套件（130 个子任务）出发，用 π0、π0.5、OpenVLA、GR00T、Wan-Policy、Cosmos-Policy 等模型作为失败生成器，记录真实失败轨迹。
  - **Stage 2 失败定位**：使用 Qwen3.5-27B-Instruct 分析执行视频，划分失败前/失败中/失败后阶段，并提取对应仿真状态。
  - **Stage 3 失败表征**：再利用 Qwen3.5-27B-Instruct 判断失败后果与恢复难度等级。
- **数据集规模**：最终得到 **2178 个恢复场景**（摘要概括为 1000+），覆盖 4 个任务类别、130 个子任务、4 个恢复等级与 16 个评估维度；并由 4 名人类遥操作员收集了 **3184 条专家恢复轨迹**。

- **评估指标**：

  - **RC（Recovery Consistency）**：同一任务内不同失败状态下恢复成功率的稳定性。

## 6. 主要结论与发现

- **标准成功不代表失败恢复能力**：所有模型在真实失败场景下性能下降均超过 50%，且标准基准排名与恢复能力排名不一致。
- **模型擅长局部修正，不擅长状态恢复**：L1/L2 表现明显优于 L3/L4，说明现有模型能调整即时动作，但缺乏对物体状态、空间关系和交互依赖的结构化推理。
- **失败导致复合分布偏移**：失败后执行性能持续降低（RD 高达 54%–100%），表明重复失败会陷入越来越陌生的状态。
- **WAM 恢复一致性更高**：世界模型类策略（Cosmos、Wan）的 RC 高于传统 VLA，可能因为其建模了动作条件的状态转移。
- **更小动作块有利于恢复**：动作块越小，反馈越频繁，恢复能力越强。
- **恢复训练难以迁移到标准任务中的自然失败**：混合 LIBERO-Recover 数据可以提升恢复基准成绩，但对标准 LIBERO 成功率提升有限甚至略有下降，存在“失败恢复迁移差距”。
- **时间上下文有所帮助**：提供初始帧作为时间上下文可提高恢复性能，说明模型需要对比当前状态与期望状态。
- **失败状态分布更集中**：恢复数据集中在抓取、放置等关键交互状态附近，而标准演示覆盖更分散。
