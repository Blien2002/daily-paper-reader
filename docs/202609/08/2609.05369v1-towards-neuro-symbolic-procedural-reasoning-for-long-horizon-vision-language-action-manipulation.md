## 摘要
视觉-语言-动作（VLA）模型能够执行短时操控技能，但在需要持久任务状态、依赖感知推理、条件决策和可靠接地的长时程程序中仍然脆弱。我们研究了一种神经符号框架，该框架将学习到的VLA控制与显式任务图和多模态程序记忆相结合。任务图编码动作依赖、有效转移和分支条件，而记忆维护当前活动步骤、已完成动作、文本上下文和任务相关的视觉证据。这些结构共同指导对象选择、目的地接地、子目标分派以及预期状态转移的验证。人类演示通过注视或显著性线索提供额外的空间和时间指导。为了分离它们对策略学习的影响，我们的初步研究绕过了跨视角注视迁移，并直接在机器人视角遥操作视频中标注伪注视。得到的指导被用于VLA微调和推理阶段。我们研究了两个长时程操控领域：工作空间清理和手术器械处理，它们需要有序执行、视觉接地的决策和条件分支。我们评估了正确对象与目的地选择、子任务完成、任务进展、步骤顺序一致性、完整任务成功以及程序性或执行错误。这项工作将结构化符号推理和来自演示的视觉指导定位为实现可靠长时程VLA操控的互补机制。

## Abstract
Vision-language-action (VLA) models can execute short manipulation skills, but remain brittle in long-horizon procedures requiring persistent task state, dependency-aware reasoning, conditional decisions, and reliable grounding. We investigate a neuro-symbolic framework that combines learned VLA control with explicit task graphs and multimodal procedural memory. Task graphs encode action dependencies, valid transitions, and branch conditions, while memory maintains the active step, completed actions, textual context, and task-relevant visual evidence. Together, these structures guide object selection, destination grounding, subgoal dispatch, and verification of expected state transitions. Human demonstrations provide additional spatial and temporal guidance through gaze or saliency cues. To isolate their effect on policy learning, our initial study bypasses cross-view gaze transfer and directly annotates pseudo-gaze in robot-view teleoperation videos. The resulting guidance is used during VLA fine-tuning and inference. We study two long-horizon manipulation domains, workspace clearing and surgical-instrument handling, which require ordered execution, visually grounded decisions, and conditional branching. We evaluate correct-object and destination selection, subtask completion, task progress, step-order consistency, complete-task success, and procedural or execution mistakes. This work positions structured symbolic reasoning and demonstration-derived visual guidance as complementary mechanisms for reliable long-horizon VLA manipulation.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型（如 OpenVLA、π0.5）已经具备较强的短期操控技能，但在长时程任务中仍然脆弱。
- **核心问题**：长时程操控需要：
  - 持久的任务状态跟踪；
  - 依赖感知的推理；
  - 条件分支决策；
  - 可靠的对象与目的地视觉接地；
  - 对人类协作者或其他智能体引发的外部事件做出响应。
- **论文定位**：提出一种神经符号框架，把学习得到的 VLA 控制与显式任务图、多模态程序记忆相结合，并引入来自人类演示的稀疏程序显著性（伪注视）作为视觉引导。
- **整体含义**：结构化符号推理负责“接下来做什么”，稀疏视觉引导负责“当前子目标如何在空间中接地”，二者互补，目标是提升长时程 VLA 操控的可靠性。

## 2. 方法论

- **任务图结构**：
  - 定义有向任务图 \(G=(V,E)\)。
  - 每个节点 \(v_i=(\ell_i,\rho_i,P_{\text{pre},i},P_{\text{succ},i},P_{\text{fail},i},z_i)\) 包含：
    - 指令文本 \(\ell_i\)；
    - 执行者角色 \(\rho_i\)（机器人、人类或其他智能体）；
    - 可视觉检查的前置条件、成功条件、失败条件；
    - 节点状态 \(z_i\)。
  - 依赖关系和前置条件决定节点是否就绪；图决定“下一步可以合法执行什么”。

- **程序记忆**：
  - 采用只追加式记忆 \(M_t=[e_1,\dots,e_t]\)。
  - 记录决策、观察到的状态转移和视觉证据。
  - 人类的已验证动作作为外部事件写入记忆，从而触发后续机器人节点。

- **执行与验证闭环**：
  - 系统同时观察固定全局视图 \(I^b_t\) 和移动手腕视图 \(I^w_t\)。
  - 对机器人节点，子目标条件化低层策略：
    \[
    \hat{A}_t = \pi_\theta(I^b_t, I^w_t, q_t, \ell_i)
    \]
  - 整体流程为：观察 → 接地 → 记忆 → 选择 → 执行 → 验证。

- **稀疏程序显著性**：
  - 在每个受引导子目标的一条代表性基座相机轨迹上，标注随时间变化的点 \(g_t\)，称为伪注视。
  - 使用 DINOv2 特征获得时间描述符和稠密空间对应，迁移到重复演示；
  - 使用金字塔 Lucas–Kanade 光流进行稳定。
  - 提供两种策略接口：
    1. **Prompt-as-input**：在 RGB 图像中渲染一个空心洋红色圆环 \(R(I^b_t,g_t)\)，直接作为视觉提示输入。
    2. **Prompt-as-supervision**：将 \(g_t\) 转换成 token 级目标分布 \(G_t\)，在微调时用 KL 散度对齐动作条件注意力 \(S_t\)：
       \[
       \mathcal{L}_{\text{reg}} = \mathcal{L}_{\text{act}} + \lambda D_{\text{KL}}(G_t \| S_t)
       \]
       正则化后的策略在推理时接收干净图像，不再需要视觉提示。
  - 论文指出，当前这两种接口只能澄清演示中已有的空间关系，尚未实现向任意未见坐标的显式重定向。

## 3. 实验设计

- **实验领域**：
  - 论文摘要中声称研究两个长时程操控领域：工作空间清理和手术器械处理。

  1. **Prompt-finetuned**：用提示训练，但测试时移除预期叠加层；

  3. **Regularization**：注意力正则化训练，测试时输入干净图像。

  - 正确对象选择；

  - 子任务完成；
  - 任务进展；
  - 步骤顺序一致性；
  - 完整任务成功；
  - 程序性错误与执行错误。

- **对比方式**：
  - 没有与其他 VLA 规划方法或传统长时程操作基线进行直接对比；

## 6. 主要结论与发现

- **视觉引导的因果作用**：
  - 在手术器械处理任务中，两种受引导变体均完成全部 75 次试验；
  - 移除预期视觉提示会使模糊容器路由成功率从 10/10 下降到 5/10，并且所有失败都被归因于错误目的地放置。
- **两种引导机制行为上并列，但机制不同**：
  - Visual prompting 在 RGB 中显式提供空间提示；
  - Regularization 使动作条件注意力对齐目标区域，并在推理时不需要提示。
  - Prompting 改善行为的同时，并未产生同样明显的聚合注意力偏移；因此，行为效用和可视注意力对齐可能捕捉的是不同属性。
- **结构化符号与视觉引导互补**：
  - 论文认为任务图和事件记忆可以决定“下一步”，VLA 决定“如何执行”，感知负责将两者连接起来。
  - 该方法被定位为提升长时程 VLA 操控可靠性的互补机制。

## 7. 优点

- **架构设计合理**：
  - 将任务图、事件记忆与 VLA 控制结合，显式处理依赖、条件分支和协作者事件。
  - 闭环包含观察、接地、记忆、选择、执行、验证，结构清晰。
- **双接口视觉引导设计**：
  - 同一显著性信号可以同时以显式 RGB 提示和注意力正则化两种方式使用，为不同部署需求提供选择。
- **隔离伪注视变量**：
  - 通过绕过跨视角注视迁移，直接在机器人视角视频中标注伪注视，减少了外部干扰，便于分析视觉引导对策略学习的独立影响。
- **真实机器人验证**：
  - 在真实机器人上完成 75 次试验，不是纯仿真结果。
- **机制分析**：
  - 不仅比较成功率，还分析了注意力热图与行为改善之间的关系，提供了一定的机理解释。
