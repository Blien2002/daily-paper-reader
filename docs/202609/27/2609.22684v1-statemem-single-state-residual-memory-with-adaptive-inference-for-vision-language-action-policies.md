## 摘要
依赖记忆的机器人操作通常需要后续动作利用先前交互中的信息。现有的视觉-语言-动作（VLA）策略主要依赖当前观测，限制了历史信息的保留。记忆增强的 VLA（如 MemoryVLA）通过外部记忆库解决了这一局限，但需要显式存储和检索。为解决这些局限，我们提出了 StateMem，一种用于 VLA 策略的单状态残差记忆框架，利用预测误差通过低秩残差更新持久记忆令牌，并自适应路由缓存前缀。一个无需训练的控制器在线调整路由阈值，而快速校正则在缓存重用期间补偿过时的前缀特征。我们在 LIBERO、RoboMemArena 和真实世界操作任务上评估了 StateMem。在 LIBERO 上，StateMem 实现了 97.6% 的平均成功率，并将平均 VLM 前缀刷新率相对于全量刷新降低了 20.25%。在 RoboMemArena 的遮挡类别中，StateMem 在单一 VLA 方法中取得了最佳性能，任务成功率（TSR）达到 21.8%，累积成功率（CSR）达到 44.3%。在六个真实世界操作任务中，其平均成功率提高了 21%。

## Abstract
Memory-dependent robotic manipulation often requires later actions to use information from earlier interactions. Existing vision-language-action (VLA) policies primarily rely on current observations, limiting historical information retention. Memory-augmented VLAs, such as MemoryVLA, address this limitation with external memory banks but require explicit storage and retrieval. To address these limitations, we propose StateMem, a single-state residual memory framework for VLA policies that uses prediction error to update a persistent memory token through low-rank residuals and to adaptively route cached prefixes. A training-free controller adjusts the routing threshold online, while fast correction compensates for stale prefix features during cache reuse. We evaluate StateMem on LIBERO, RoboMemArena, and real-world manipulation tasks. On LIBERO, StateMem achieves an average success rate of 97.6% and reduces the average VLM prefix refresh rate by 20.25% relative to full refresh. In the Occlusion category of RoboMemArena, StateMem achieves the best performance among single-VLA methods, reaching 21.8% Task Success Rate (TSR) and 44.3% Cumulative Success Rate (CSR). Across six real-world manipulation tasks, it achieves +21% in average success rate.

## 2. 论文提出的方法论

### 2.1 总体架构

StateMem 在 π0.5 基础上，将策略建模为：

\[
A_t \sim \pi_\theta(\cdot \mid M_{t-1}, o_t, l, q_t)
\]

其中 \(M_{t-1}\) 是当前时刻前累积的持久记忆状态。整体由三部分组成：

1. **单状态残差记忆模块**；
2. **自适应前缀路由与快速校正模块**；
3. **无需训练的在线阈值控制器**。

### 2.2 单状态残差记忆

- 每个 episode 开始时，通过视觉编码器 + SE-bottleneck + 平均池化得到感知特征 \(p_0\)；
- 从图像-语言前缀的 EOS 隐藏状态得到认知特征 \(c_0\)；
- 两者融合并经过 LayerNorm，得到单一记忆 token：

\[
M_0 = \mathrm{LN}(\mathrm{Fusion}([c_0; p_0]))
\]

- 后续每一步，用轻量预测器 \(P_\phi\) 从上一时刻记忆预测当前感知特征：

\[
\hat p_t = P_\phi(M_{t-1})
\]

- 预测误差定义为：

\[
e_t = p_t - \hat p_t
\]

- 误差通过低秩残差映射更新记忆：

\[
\Delta M_t = B A e_t
\]

\[
M_t = \mathrm{LN}(M_{t-1} + \Delta M_t)
\]

其中 \(A \in \mathbb{R}^{r \times d_p}\)、\(B \in \mathbb{R}^{d_m \times r}\) 是低秩矩阵。

- 归一化预测误差：

\[
E_t = \frac{\|e_t\|_2^2 / d_p}{\|p_t\|_2^2 / d_p + \varepsilon}
\]

- 训练目标为：

\[
\mathcal{L}_{policy} = \mathcal{L}_{act} + \lambda_{pred}\mathcal{L}_{pred}
\]

其中 \(\mathcal{L}_{pred}\) 是预测器辅助损失。

### 2.3 自适应前缀路由与快速校正

- 在每次前缀刷新时，缓存 VLM 前缀 KV 以及对应的记忆状态、感知特征和本体感受状态，作为缓存锚点。
- 路由误差使用同一预测器从缓存锚点计算：

\[
E_t^{route} = \mathrm{MSE}\left(p_t - P_\phi(M_{t_a})\right)
\]

- 路由得分：

\[
\rho_t = \frac{E_t^{route}}{\frac{1}{d_p}\|p_t\|_2^2 + \varepsilon}
\]

- 当 \(\rho_t\) 较低时，说明当前感知与缓存状态一致，重用缓存前缀；否则刷新完整 VLM 前缀。
- **快速校正**：缓存前缀重用期间，通过一个轻量适配器补偿陈旧特征。校正上下文为记忆、感知、本体感受变化及连续重用深度：

\[
d_t^{FC} = [M_t; \Delta M_t; p_t; \Delta q_t; \kappa_t]
\]

- 校正分支分别预测时间嵌入和动作 token 嵌入的修正量，并注入到动作后缀前向过程中。
- 训练时通过蒸馏全刷新路径的梯度截断预测来训练快速校正模块，包含局部流预测一致性、末端动作块一致性、速度一致性和“无伤害”项等。

### 2.4 无需训练的在线阈值控制器

- 维护路由得分的运行均值 \(\mu_{t-1}\) 和绝对偏差统计 \(\nu_{t-1}\)。
- 阈值：

\[
\delta_t = \mathrm{clip}(\mu_{t-1} + \gamma \nu_{t-1}, \delta_{min}, C_{t-1})
\]

- 每步用 EMA 更新统计量。
- 周期性执行动作审计：比较缓存前缀路径与全刷新路径在同一动作噪声下的动作差异：

\[
E_t^{audit} = \mathrm{MSE}\left(a_t^{skip}, a_t^{full}\right)
\]

- 根据审计误差与允许上限 \(\beta_{audit}\) 的关系，在线扩展或收缩阈值上限 \(C_t\)，从而决定后续缓存重用还是刷新。

## 3. 实验设计

### 3.1 仿真基准

- **LIBERO**：
  - 基于 Franka 的通用操作基准，包含四个套件：Spatial、Object、Goal、Long。
  - 每个任务使用 50 条专家演示微调，共 50 次随机试验。
- **RoboMemArena**：
  - 专门面向记忆依赖操作的基准，包含 26 个仿真任务，分四类：Transferring、Occlusion、Counting、Sequence。
  - 每个任务使用 100 条专家演示训练，每个任务 50 个独立种子评估。
  - 指标：TSR 和 CSR。

### 3.2 真实世界任务

- 使用 7 自由度 UFACTORY xArm7 机械臂 + 6 自由度 Inspire 多指灵巧手 + 腕部 Orbbec Gemini 360 相机。
- 六个任务：Pick Fruits、Flip Mug、Stack Cups、Press Buttons（通用），Cover & Uncover、Pick & Count（记忆依赖）。
- 通用任务每任务 50 条演示，记忆依赖任务 120–200 条演示。
- 每个任务 20 次独立随机初始状态试验。

### 3.3 对比方法

- **LIBERO 对比**：Diffusion Policy、MDT、Octo、Dita、OpenVLA、TraceVLA、SpatialVLA、SmolVLA、GR00T-N1、π0-FAST、CogACT、π0、π0.5、CronusVLA、MemoryVLA 等。
- **RoboMemArena 对比**：π0.5、HiF-VLA、MemoryVLA、MemER、PrediMem 等。
- **真实世界对比**：π0.5、MemoryVLA（复现版）。

## 6. 论文的主要结论与发现

- **LIBERO 表现**：
  - StateMem 平均成功率达到 **97.6%**，在所有比较方法中最高；

  - 平均成功率 **65%**，较 π0.5 提升 +21%，较 MemoryVLA 提升 +12%；

## 7. 优点

- **方法层面**：
  - 用单一记忆 token 表示任务历史，避免了外部记忆库的显式存储、检索和额外管理；
  - 以预测误差驱动记忆更新，与预测编码理论呼应，具有较强的可解释性；
  - 通过低秩残差更新记忆，计算开销低；
  - 自适应前缀路由和快速校正结合，能在保持性能的同时减少冗余 VLM 前缀计算；
  - 阈值控制器无需训练，部署阶段可在线调整。
- **实验层面**：
  - 同时在通用操作和记忆依赖操作基准上验证；
  - 仿真 + 真实世界结合；
  - 对比基线丰富，包含多种 VLA 和记忆增强方法；
  - 提供消融、效率与记忆保留分析；
  - 提供匿名开源代码，便于复现。
