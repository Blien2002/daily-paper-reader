## 摘要
操作策略必须知道哪些物体重要以及它们在哪里，然而当前机器人基础模型所依赖的预训练主干——从视觉-语言-动作模型（VLA）中的语言到世界-动作模型（WAM）中的视频生成——并不直接要求这种度量空间定位，导致其只能从机器人演示中隐式学习。我们提出定位动作模型（Grounded Action Models，GAM），一种基于三维定位构建的机器人基础模型新范式。GAM 可以使用语言、点或框提示作为条件，这些提示首先被转换为所选物体的统一物体中心表示。该表示捕获目标聚焦的视觉特征和度量物体几何信息，并通过多流 Transformer 与机器人状态历史混合，以预测动作片段。虽然 GAM 可以自主运行，但它们也可以充当低层控制器，由高层规划器利用其多种输入模态进行控制，从而实现长时程和依赖记忆的操作。在 RoboTwin 2.0 上，GAM 在 50 项任务中取得 55.3% 的平均成功率（Spatial Forcing 为 52.0%），其中在场景随机化下为 47.6%（Abot-M0 为 30.4%），而其动作策略仅在干净场景演示上训练。在 LIBERO-PRO 上，它在 16 种扰动设置下取得 61% 的最先进平均成功率（$π_{0.5}$ 为 53%），当目标被重新放置或重新指定时提升最大。在两台真实机器人上，GAM 在双臂 YAM 上视觉偏移条件下保持 17/20 的成功率，而 $π_{0.5}$ 为 4/20；同时，GAM 与 Molmo2 规划器组合在 Franka 上，在长时程和依赖记忆任务中实现了 64.7% 的分布内（ID）和 49.8% 的分布外（OOD）步骤完成率。

## Abstract
Manipulation policies must know which objects matter and where they are, yet the pretrained backbones that current robot foundation models build on, from language in vision-language-action models (VLAs) to video generation in world-action models (WAMs), do not directly require this metric grounding, leaving it to be learned implicitly from robot demonstrations. We propose Grounded Action Models (GAMs), a new paradigm of robot foundation models built with 3D grounding. GAM can be conditioned using language, points, or box prompts, which are first transformed into a shared object-centric representation of the selected objects. This representation captures target-focused visual features and metric object geometry, which is mixed with robot state history through a multi-stream transformer to predict action chunks. Although GAMs can be run autonomously, they can also serve as a low-level controller that a high-level planner controls using its various input modalities, allowing for long-horizon and memory-dependent manipulation. On RoboTwin 2.0, GAM achieves an average success rate of 55.3% across 50 tasks (vs. 52.0% for Spatial Forcing), including 47.6% under scene randomization (vs. 30.4% for Abot-M0), with its action policy trained only on clean-scene demonstrations. On LIBERO-PRO, it achieves a state-of-the-art average success rate of 61% (vs. 53% for $π_{0.5}$) across 16 perturbation settings, with the largest gains when targets are relocated or newly designated. On two real robots, GAM retains 17/20 successes under visual shift on a bimanual YAM versus 4/20 for $π_{0.5}$, while its composition with a Molmo2 planner on a Franka achieves 64.7% ID and 49.8% OOD step completion on long-horizon and memory-dependent tasks.

## 1. 论文的核心问题与整体含义

- **研究背景与问题**：当前机器人基础模型主要建立在语言或视频生成预训练骨干之上：
  - **视觉-语言-动作模型（VLAs）** 依赖语言预训练，擅长语义理解，但不直接要求精确的 3D 定位。
  - **世界-动作模型（WAMs）** 依赖视频生成预训练，擅长时空预测，但关注外观和纹理，不直接暴露操作目标的度量几何。
  - 两类骨干都需要从有限的机器人演示中隐式学习“哪些物体重要、它们在哪里”，当物体移动、背景变化或目标被重新指定时，学到的关联容易失效。
- **整体含义**：论文提出以 **3D grounding（三维定位）** 作为机器人动作学习的基础，构建新的机器人基础模型范式 **GAM（Grounded Action Model）**。其核心假设是：如果预训练骨干本身就能直接输出任务相关物体的显式度量三维信息，则动作策略可以更直接、更鲁棒地学会操作。

## 2. 论文提出的方法论

### 2.1 核心思想

- 用一个**冻结的、可提示的 3D grounding 骨干模型**（本文采用 WildDet3D）将语言、2D 点或 2D 边界框统一解析为目标物体的显式空间表示。
- 动作头只学习“如何操作已定位的物体”，而物体定位与空间理解由预训练骨干提供。
- GAM 既可以自主运行，也可以作为低层控制器，由高层 VLM 规划器通过点提示进行控制。

### 2.2 关键技术细节

#### A. 从提示到检测

- 输入：当前 RGB 图像 $o_t$ 和任务规格 $\ell$（语言、2D 点或 2D 框）。
- 语言输入通过 span-tagging head（基于冻结的 Flan-T5 编码器）抽取目标物体短语，例如 “pick up the sponge and place it in the bowl” 中抽取 *sponge* 和 *bowl*，分别作为 grounding query。
- 每个 query 送到 WildDet3D，输出：
  - 2D 检测框 $u_i$
  - 度量 3D 框 $b_i$
  - 稠密度量深度图 $\hat{D}_t$
  - 视觉骨干特征 $F_t = \text{Enc}_G(o_t)$。

#### B. 从检测到物体中心观察

- **图像 token**：
  - 将 $F_t$ 平均池化到 $16\times16$ 网格。
  - 保留与目标 2D 框重叠超过 30% 或与机器人臂投影轮廓重叠超过 10% 的网格。
  - 机器人轮廓通过 URDF 正运动学和已知相机标定投影获得。
  - 其余单元置零，经线性适配器得到 $G^2$ 个图像 token。
- **检测 token**：
  - 利用深度图反投影生成场景点云，裁剪出略微膨胀的 3D 框内的目标点云，采样 $P=512$ 个点。
  - 点云编码器：共享逐点 MLP + 全局最大池化、全局平均池化、八个象限内最大池化，得到 512 维形状特征 $\phi(P_i)$。
  - 物体描述向量：
    \[
    z_i = \left[ \tilde{u}_i,\ c_i,\ \gamma(c_i),\ \phi(P_i),\ e_i,\ r_i \right]
    \]
    其中 $\tilde{u}_i$ 是归一化 2D 框，$c_i$ 是物体中心，$\gamma(c_i)$ 是中心坐标的傅里叶特征（8 个频率），$e_i$ 是尺寸，$r_i$ 是旋转的 6D 表示。
  - 线性映射到 $M=8$ 个检测 token；未检测到的目标使用可学习的空 token 填充。
- **状态历史 token**：
  - 拼接当前及前几帧关节位置，投影为单个 token。
- **条件融合**：
  - 图像、检测、状态历史 token 加上模态嵌入，经过共享自注意力层融合，得到条件序列 $C \in \mathbb{R}^{L \times d}$，其中 $L = G^2 + M N + 1$。

#### C. 从观察到动作

- **动作头**：MM-DiT（多流 Transformer）12 块，输入四个流：
  - 图像、检测、状态历史三分段来自 $C$
  - 噪声动作块 $A^\tau_t$ 嵌入为 $H$ 个动作 token。
- **语言条件注入**：
  - 语言句子嵌入 $e_s$ 投影后加到时间步嵌入上：
    \[
    h_{\tau,s} = \text{TimeEmbed}(\tau) + W_\ell e_s + b_\ell
    \]
  - 通过 adaptive layer norm 注入每个 Transformer 块。
- **训练目标**：流匹配（flow matching）。
  - 对演示动作块 $A_t$，加噪：
    \[
    A^\tau_t = \tau A_t + (1-\tau)\epsilon,\quad \epsilon\sim\mathcal{N}(0,I)
    \]
  - 模型预测速度 $A_t - \epsilon$，损失：
    \[
    \mathcal{L} = \mathbb{E}_{A_t,\epsilon,\tau}\left[\|v_\theta(A^\tau_t|\tau,C,e_s) - (A_t-\epsilon)\|_2^2\right]
    \]
- 推理时从噪声出发，用 $K$ 个 Euler 步积分生成动作块。

#### D. 部署

- 初始时由 grounding 骨干定位目标物体。
- CoTracker3 对初始检测框内的点进行跟踪，保持跨帧物体关联。
- 每当动作头查询时重建 grounded 观察并预测动作块。
- 长时程/记忆任务中，高层 VLM 规划器可根据当前图像和历史记忆在子任务切换时重新选择目标，通过点提示重新初始化跟踪器。

## 6. 论文的主要结论与发现

- **RoboTwin 2.0**：
  - GAM 平均成功率 55.3%，为所有列示方法最高；在随机化 Hard 设置下达到 47.6%，显著优于最强基线（Abot-M0 的 30.4% 和 Spatial Forcing 的 26.7%）。
  - 仅用干净场景演示训练，仍保持 76% 的干净性能（63.0%→47.6%）。
  - 说明 3D 输入本身（如 DP3）不足以鲁棒，关键是目标中心过滤和显式 grounding。
- **LIBERO-PRO**：
  - GAM 在 16 个扰动设置上平均 0.61，高于 π₀.5 的 0.53。
  - 在 **Pos**（目标移动）和 **Task**（目标重新指定）扰动上大幅领先，证明策略真正 grounding 了指令，而不是回放记忆轨迹。
  - 在 **Obj**（物体尺寸变化）上落后于多数基线，说明策略对抓取位置随尺寸变化的适应性有限。
- **真实机器人**：
  - YAM：ID 下 GAM 和 π₀.5 均为 19/20；视觉偏移下 GAM 保持 17/20，π₀.5 仅 4/20，保留率 89% vs 21%。
  - Franka：GAM+Molmo2 平均 ID 步骤完成率 64.7%，OOD 49.8%，显著优于 π₀.5（42.4% / 24.0%）和 MolmoAct2（35.3% / 17.1%）；注意力图显示 GAM 更集中在目标物体上。
- **消融结论**：
  - 去掉图像掩码、点云裁剪或双流之一都会导致性能大幅下降，说明目标中心过滤和外观/几何互补信息对鲁棒性至关重要。

## 7. 优点

- **新范式**：首次系统地将 promptable 3D grounding 作为机器人动作学习的预训练基础，区别于主流 VLA/WAM。
- **统一多模态接口**：语言、点、框均可作为目标指定方式，便于人类直接控制或与 VLM
