## 摘要
具身规划越来越依赖视觉-语言模型（VLM）将指令和视觉观测转化为可执行的动作序列。然而，流畅的计划并不总是可执行。VLM 可能会引用未被视觉观测到的物体，选择所需可供性不可用的动作，或违反语法和动作约束。我们提出 CLAMP，一个多模态约束锚定框架，将场景证据转化为冻结 VLM 规划器在解码时的约束。CLAMP 利用初始观测将物体引用限制为场景所支持的物体，同时由给定的符号动作模型指定状态转移和目标。在解码过程中，硬掩码消除无效的下一个 token 候选，而基于隐马尔可夫模型（HMM）的世界状态前瞻模块根据动作前提条件和目标可达性，对剩余可行候选的概率进行重新加权。这使得规划器能够保留 VLM 的语言先验，同时防止视觉上不支持、不安全或不可行的候选进入计划。对于未见过的任务和环境，CLAMP 在测试时利用从冻结 VLM 采样的无标签续写来自适应 HMM。在 VLABench、SafeAgentBench 和 TaPA 上的实验表明，场景锚定约束改善了物体锚定和安全性，而大多数剩余失败源于感知错误或约束规范不一致。

## Abstract
Embodied planning increasingly relies on vision-language models (VLMs) to translate instructions and visual observations into executable action sequences. However, fluent plans are not always executable. A VLM may refer to objects that are not visually observed, select actions whose required affordances are unavailable, or violate syntax and action constraints. We introduce CLAMP, a multimodal constraint-grounding framework that turns scene evidence into decoding-time constraints for a frozen VLM planner. CLAMP uses the initial observation to restrict object references to those supported by the scene, while a provided symbolic action model specifies state transitions and goals. During decoding, hard masks eliminate invalid next-token candidates, while a Hidden Markov Model (HMM)-based world-state lookahead module reweights the probabilities of the remaining feasible candidates based on action preconditions and goal reachability. This allows the planner to retain the VLM's language prior while preventing visually unsupported, unsafe, or infeasible candidates from entering the plan. For unseen tasks and environments, CLAMP adapts the HMM at test time using label-free continuations sampled from the frozen VLM. Experiments on VLABench, SafeAgentBench, and TaPA show that scene-grounded constraints improve object grounding and safety, while most remaining failures stem from perception errors or misaligned constraint specifications.

## 1. 论文的核心问题与整体含义

- **研究动机**：具身规划需要将自然语言指令和视觉观测转化为可执行动作序列，但视觉-语言模型（VLM）生成的计划虽然语言流畅，却常常不可执行：
  - 引用当前场景中不可见的物体；
  - 选择前提条件不满足、可供性不可用的动作；
  - 违反动作语法、参数结构或任务约束。
- **现有方法的不足**：
  - 事后验证/修复（post-hoc verification or repair）允许错误决策先发生，再纠正，效率低且可能传播错误；
  - 传统约束解码主要面向语言生成或专用策略输出，难以处理具身规划中**随世界状态演化、且依赖多模态观测**的约束。
- **论文的核心思想**：提出 CLAMP，在**冻结 VLM 规划器**的解码过程中直接施加多模态约束，将场景证据和符号动作模型转化为**硬掩码 + 软前瞻**，在不更新或缩放 VLM 的前提下，提升计划的可执行性、物体接地和安全性。

## 2. 方法论

- **约束定义**：将规划约束分解为三类：
  - **语法约束 \(C_{syn}\)**：动作必须符合任务给定的动作模式 \(γ\)，动作空间为 \(A_γ\)；
  - **可见性约束 \(C_{vis}\)**：动作引用的实体必须属于初始视觉观测 \(o_0\) 支持的实体集合 \(E_{seen}\)；
  - **可达性约束 \(C_{rch}\)**：动作序列必须能在世界状态演化下可执行、在预算 \(K_{max}\) 内到达目标状态。
- **解码时 logits 修改**：对第 \(n\) 步候选 token \(v\)，CLAMP 将原始 VLM 对数概率 \(ℓ_n(v)\) 加上约束项：

  \[
  \tilde{ℓ}_n(v)=ℓ_n(v)+\log m_{syn,n}(v)+\log m_{vis,n}(v)+\log m_{rch,n}(v)+λ G_{rch,n}(v)
  \]

  - \(m_{syn,n}, m_{vis,n}, m_{rch,n} \in \{0,1\}\) 为**硬掩码**，非法候选被赋予 \(-\infty\)；
  - \(G_{rch,n}(v)\) 为**预算感知的未来可达性软分数**，权重 \(λ\ge 0\)。
- **语法与可见性约束实现**：使用 token 级 DFA \(D_{syn}, D_{vis}\)。语法 DFA 从动作模式 \(γ\) 编译，可见性 DFA 从 \(E_{seen}\) 编译；候选 token 只有在其扩展前缀仍可被 DFA 接受时才被保留。
- **可达性约束实现**：
  - 使用动作级 DFA \(D_{rch}=(Z, A_γ, Δ, z_0, F_{rch})\) 表示符号状态转移、目标状态和动作前提条件；
  - 在 token 解码过程中，只有当前 token 前缀可完成且可从当前状态 \(z_t\) 执行的动作才允许通过；
  - **预算感知前瞻**基于 HMM：对每个候选动作及其后继状态，计算在剩余动作预算内到达目标的 HMM 加权对数概率质量 \(R[K,z,h]\)，并通过动作到 token 的投影得到 \(G_{rch,n}(v)\)。
- **HMM 来源与测试时适应**：
  - HMM 最初从冻结 VLM 的续写序列中**自我蒸馏**得到；
  - 测试时只更新 HMM 发射矩阵 \(B\)，冻结初始分布 \(μ\) 和转移矩阵 \(A\)；
  - 适应方式包括：
    - **TTDA**：目标域离线适应；
    - **OTTA**：在线会话适应；
    - **TTBA**：每个实例生成前用少量无标签续写做批适应。
  - HMM 发射矩阵跨 tokenizer 时需要进行目标驱动的重映射（如 Llama-3 → Qwen3-VL）。
- **解码流程**：若预算耗尽仍未达目标状态，或所有候选 token 均被掩码为 \(-\infty\)，则返回 FAIL；否则按修改后的 softmax 分布采样，完成动作后推进世界状态 \(z_{t+1}=Δ(z_t,a_t)\)。

## 6. 主要结论与局限

- **核心结论**：CLAMP 在冻结 VLM 解码过程中注入多模态、符号化约束，能够在不更新 VLM 权重的前提下显著提升计划的可执行性，减少不可见实体引用，降低安全违规，并在 VLABench、SafeAgentBench、TaPA、VirtualHome/EAI、BEHAVIOR 等基准上优于无约束 VLM 基线及部分外部适配方法；硬掩码保证语法/可见性/动作前提条件的合法性，软前瞻增强预算内的目标可达性；HMM 的自我蒸馏与轻量测试时适应使跨域迁移可行。
- **方法贡献**：将具身规划中的语法、可见性和可达性约束统一为 token 级硬掩码与动作级预算感知软分数，实现了 VLM 自由生成与符号约束之间的解耦；HMM 只需发射矩阵 \(B\) 的测试时更新即可适配目标域，避免对 VLM 本身的任何微调。
- **局限与不足**：
  - 语法/可见性约束依赖预先给定或自动提取的动作模式 \(\gamma\) 和实体集合 \(E_{seen}\)，开放世界提取错误可能转化为系统性掩码错误；
  - HMM 的离散状态/动作粒度对连续操纵、长程依赖和部分可观察世界的表达能力有限；
  - 软前瞻权重 \(\lambda\) 需要根据基准或任务人工调节；
  - 测试时适应与 Baum-Welch 更新引入额外每 prompt 延迟，且 vLLM 批处理与 HuggingFace 单 prompt 路径的耗时差异未被单独隔离；
  - 代理指标与真实机器人执行之间仍存在策略有效性差距；
  - 未报告多次随机种子的置信区间，部分小样本诊断任务的统计稳健性有限。
- **未来方向**：可将 CLAMP 扩展到连续动作空间与更丰富的世界状态表示，减少对符号动作模式和实体集合的先验依赖；探索更高效的在线约束编译与 HMM 更新策略，以降低单卡实时部署的延迟；并在更接近真实执行的环境中验证从 VLM 解码到基础设施执行的一致性。
