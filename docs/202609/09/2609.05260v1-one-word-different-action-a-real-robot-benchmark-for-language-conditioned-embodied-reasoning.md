## 摘要
自然语言指令变化会直接改变机器人行为。一个可靠的具身系统应在任务未变时保持动作不变，并在任务本身发生变化时正确更新动作。我们提出了“One Word, Different Action”基准，这是一个构建在物理决策状态和可执行动作之上的真实机器人基准，使用任务保持与任务改变的指令对来联合评估决策不变性与决策敏感性，并进一步在多约束推理和真实 RGB 语义落地条件下进行评估。实验表明，现代模型在单约束指令变化上已接近饱和，但当多个任务约束需要整合为一个可执行决策时，多个模型的性能明显下降。这些结果表明，更突出的剩余挑战已不再只是识别孤立的指令变化，而是可靠地将多个任务要求组合为正确的机器人动作决策。

## Abstract
Natural-language instruction changes can directly alter robot behavior. A reliable embodied system should preserve its action when the task is unchanged and update it correctly when the task itself changes. We introduce One Word, Different Action, a real-robot benchmark built on physical decision states and executable actions, using task-preserving and task-changing instruction pairs to jointly evaluate Decision Invariance and Decision Sensitivity, with further evaluation under multi-constraint reasoning and real-RGB grounding. Experiments show that modern models are near saturation on single-constraint instruction changes, yet several models degrade noticeably when multiple task constraints must be integrated into one executable decision. These results suggest that the more salient remaining challenge is no longer recognizing an isolated instruction change, but reliably composing multiple task requirements into a correct robot action decision.

## 1. 论文的核心问题与整体含义

- **核心问题**：当用户对机器人的自然语言指令发生变化时，机器人应当何时保持动作不变、何时正确更新动作？
  - 同一任务用不同措辞表达时，机器人应保持相同动作（决策不变性，Decision Invariance）。
  - 任务本身因指令变化而改变时，机器人应相应更新动作（决策敏感性，Decision Sensitivity）。

- **研究背景与动机**：
  - 大模型正越来越多地作为机器人高层认知与决策组件，语言到物理执行的距离缩短，语言理解错误会直接影响机器人的实际行为。
  - 现有具身推理基准多关注最终任务成功率，缺乏在**固定物理状态下**对**受控指令变化**如何影响动作决策的诊断。
  - 相关工作如 RoboBench、VLABench、ManipBench、BlockWorld-Repairs、SwitchVLA、CxMP、LIBERO-Para、LIMP 等，分别从不同侧面研究了指令理解、纠错、任务切换、复述鲁棒性和多约束遵循，但缺少一个统一、受控的真实机器人诊断框架。

- **整体含义**：
  - 单独实例准确率不足以区分“过度不变性”和“过度敏感性”；可靠系统必须做到：动作只在任务真正变化时改变。
  - 本文提出基准 **One Word, Different Action**，用任务保持与任务改变的指令对，在同一物理决策状态和同一可执行动作空间上，联合评测决策不变性与决策敏感性，并进一步考察多约束推理与真实 RGB 视觉落地。

## 2. 论文提出的方法论

### 2.1 核心思想

- **固定物理状态，只改变语言任务约束**：
  - 对给定物理决策状态 \(s\)，定义可执行动作空间 \(\mathcal{A}(s)=\{a_1,a_2,\dots,a_N\}\)。
  - 模型根据自然语言指令 \(x\) 产生动作决策 \(\pi(x,s)\)。
  - 每个任务实例都有唯一确定的正确动作 \(a^*(x,s)\)，预测必须**精确匹配**才算正确。

- **任务保持与任务改变的变换**：
  - 任务保持变换 \(x^+\)：\(a^*(x,s)=a^*(x^+,s)\)，应保持动作不变，对应 **Decision Invariance**。
  - 任务改变变换 \(x^-\)：\(a^*(x,s)\neq a^*(x^-,s)\)，应正确改变动作，对应 **Decision Sensitivity**。
  - 定义两种失败模式：
    - **Over-Invariance**：任务已变，但模型错误地保持原动作。
    - **Over-Sensitivity**：任务未变，但模型错误地改变动作。

### 2.2 关键技术与表示

- **确定性可执行决策表示**：
  - 输出不是自由文本，而是有限、可机器校验的可执行表示：目标对象、对象集合、单个动作、动作集合或有序动作序列。
  - 对象/动作集合要求成员完全一致；序列还要求顺序完全一致。
  - 多约束任务要求同时满足所有约束，不允许部分得分。

- **任务类别设计**：
  - 单约束推理分为四类：
    - **动作抑制**：判断某候选动作或对象是否被任务指令禁止。
    - **集合约束**：在候选集合上执行排除或保留操作。
    - **基数约束**：同时推理集合成员与所需动作数量。
    - **时间顺序约束**：决定多个动作的执行顺序。

- **受控任务族构建**：
  - 每个任务族基于同一物理决策锚，固定物理状态与候选动作空间，仅变化语言表达。
  - 每个族包含任务保持变换和任务改变变换，从而支持不变性与敏感性的联合评估。
  - 构建顺序为：**物理决策状态 → 任务约束 → 确定性动作决策 → 自然语言指令**，保证地面真值由物理状态和任务规则决定，而不是从语言后验推断。

- **多约束具身推理**：
  - 形式化为：\(a^*(x,s) \models \bigwedge_{k=1}^{K} C_k\)，即最终动作必须同时满足全部 \(K\) 个约束。
  - 本文具体实现的多约束组合是**基数约束 + 动作抑制约束**的联合，要求模型在满足数量要求的同时排除被禁止的候选动作。

### 2.3 基准结构

- **物理决策锚**：共 85 个，其中 21 个对象中心锚，64 个动作序列锚。
- **规模**：
  - 原子基准：988 个完整任务族，3952 个任务实例。
  - 多约束实例：84 个。
  - 真实 RGB 子集：748 个任务实例，187 个完整任务族，覆盖全部 85 个物理决策锚。
- **数据划分**：按物理决策锚进行划分，同一锚的所有任务族、语言表述和动作决策进入同一 split，防止同一物理状态跨划分重复出现。

### 2.4 评估指标

- **Exact Action-Decision Accuracy**：实例级动作决策完全匹配准确率。
- **Parse Success Rate**：有效机器可读输出比例；解析失败不剔除，仍计入总分母。
- **Pair Success**：同一任务族中所有配对成员均正确。
- **Decision Invariance**：任务保持对的双方均正确且动作一致。
- **Decision Sensitivity**：任务改变对的双方均正确且动作按任务要求更新。
- **Over-Invariance / Over-Sensitivity**：分别统计错误保持与错误改变的比例。
