## 摘要
主流机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超出当前观测的长程记忆。现有记忆机制往往依赖语言摘要、不断增长的视觉窗口或其组合，因此可能丢失细粒度视觉证据，或在历史覆盖范围与执行效率之间面临权衡。我们提出了 MaP-WAM，一个“记忆即计划”框架，将依赖记忆的世界-动作建模分解为基于记忆锚定的规划与计划条件执行，并使用长期多模态情景上下文作为规划时的证据，而非反复让执行器以完整历史为条件。MaP-WAM 将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这些情景记忆转换为紧凑计划，其中包括下一片段级语言计划及相应的视觉引导。世界-动作-进度（WAP）模型在推理时通过联合预测动作块和相应执行进度，在未知时长内执行每个计划，并通过计划-观测对齐校准预测进度，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，而结构化注意力进一步在规划和执行中支持键值缓存。MaP-WAM 在 RMBench 上取得了 83.3% 成功率的最优性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史的增长，执行器推理延迟保持近似恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 论文的核心问题与整体含义

- **研究背景**：机器人操作策略通常假设当前观测或固定短时窗口已足够，即马尔可夫假设。但许多复杂操作任务本质上是非马尔可夫的，决策需要早于当前观测的历史信息，例如物体的初始位置、被遮挡前的颜色、任务阶段等。
- **现有记忆机制的不足**：
  - **语言记忆**：把历史压缩为语言摘要或子任务指令，紧凑、可解释，但可能丢失细粒度视觉/空间证据。
  - **持续更新记忆**：通过可更新的隐状态或记忆库保存上下文，但长时程下早期关键信息可能被压缩或覆盖。
  - **增长窗口记忆**：直接保留观察序列，视觉证据丰富，但固定窗口会截断远期历史，而增长窗口导致推理延迟和 GPU 内存随历史增长，存在覆盖范围与执行效率的权衡。
- **核心思想与整体含义**：提出 **MaP-WAM（Memory-as-Plans）**，一种“记忆即计划”框架：将长时记忆作为**规划时的证据**，而不是**执行时每一步都输入完整历史**。它把记忆转换为紧凑的语言—视觉计划，执行器只需以当前观测和固定计划为条件，从而在保留细粒度视觉记忆的同时实现固定上下文、恒定延迟的高效执行。

## 2. 论文提出的方法论

### 2.1 总体框架：记忆锚定规划 + 计划条件执行

- **记忆表示**：使用结构化的多模态情景上下文 `C<k`，每个已完成片段 `i` 记录为 `C_i = {l_i, G_i}`，其中 `l_i` 是该片段语言指令，`G_i` 是从该片段真实执行轨迹中均匀采样的固定长度稀疏视觉帧序列（默认 N=8）。初始观测记作 `G_0 = f_0`。
- **规划阶段**：从上下文 `C<k` 和全局指令 `l` 预测下一片段计划 `C_k = {l_k, G_k}`：
  - 语言计划 `l_k` 由 VLM 规划器 `π_l^P` 生成，输入为全局指令、已完成片段指令和紧凑关键帧集 `f*`。
  - 视觉计划 `G_k` 由**因果世界模型（CWM）** 生成，条件为长期视觉上下文 `G<k`、语言计划 `l_k` 和全局指令 `l`。
- **执行阶段**：执行器以固定输入 `{G_k, l_k, f_t, s_t, p_t}` 预测短时动作块，不随历史长度增长而扩大上下文。

### 2.2 记忆锚定语言—视觉规划

- 使用 Qwen3.5-4B 作为语言规划器，WAN-2.2-5B 作为视觉规划器主干。
- CWM 采用流匹配目标训练：  
  `L_v^P = L_FM(G_k, (G<k, l_k, l))`，其中条件 `c = (G<k, l_k, l)`，目标 `y = G_k`。
- **因果注意力掩码**：将已完成片段的视觉证据组织为块，采用块因果掩码，使已完成证据只依赖更早的块和全局指令，从而在推理时可作为静态前缀缓存，后续规划阶段复用 KV 状态。

### 2.3 世界-动作-进度（WAP）模型

- **结构**：扩展预训练视频 DiT（基于 WAN-2.2），采用 Mixture-of-Transformers（MoT）架构，包含视频专家、动作专家（约 1.02B 参数）、进度专家（约 207M 参数）。
- **输入**：视觉计划 `G_k`（静态干净前缀）、当前观测 `f_t`（干净状态 token）、当前进度 `p_t`、本体感知状态 `s_t`、语言计划 `l_k`，以及带噪目标 token（未来视觉状态、动作块、进度序列）。
- **输出**：联合预测未来视觉动态、动作块 `a_{t+1:t+h}` 和对应进度序列 `p_{t+1:t+h}`。
- **结构化注意力掩码**：
  - 计划块只关注自身，可作为缓存前缀；状态块关注计划和自身。
  - 动作和进度 token 不能关注未来视觉 token，反之亦然；进度 token 可关注动作 token。
  - 交叉注意力中，所有 token 关注语言计划；动态 token 还关注本体感知和当前进度。
- **训练目标**：对三个分支分别计算流匹配损失，加权求和：  
  `L_E = λ_v L_v^E + λ_a L_a^E + λ_p L_p^E`，默认 `λ_v = λ_a = λ_p = 1.0`。  
  其中每个分支的条件为 `c = (G_k, l_k, f_t, s_t, p_t)`。
- **进度建模的意义**：进度提供显式时间坐标，帮助区分视觉相似但语义不同的状态（如按压前/后）。

### 2.4 闭环规划与执行

- **计划—观测对齐（进度校准）**：部署时没有真实进度标签，所以进度条件由 WAP 自身预测递归更新，易积累误差。利用视觉计划帧具有归一化进度索引的特点，取当前估计进度附近的参考帧，用 RGB 平均绝对像素差与当前观测比较，选最相似帧，将进度条件更新为该帧索引与当前估计的平均值。该方法无训练、轻量。
- **进度门控片段转换**：计算最近若干动作对应预测进度的平均值，当超过阈值 `τ=0.95` 时，判定当前片段完成，终止执行，将真实观测重采样为稀疏视觉上下文 `G_k`，更新情景上下文，触发下一轮规划。
- **KV 缓存**：CWM 已完成证据前缀可缓存；WAP 的视觉计划前缀可预填充并缓存，在执行片段内复用，仅在片段切换时刷新。

## 3. 实验设计

### 3.1 仿真基准实验

- **数据集/场景**：RMBench，一个专为长时记忆依赖操作设计的仿真基准，包含：
  - 5 个 `M(1)` 任务（决策依赖一个任务相关历史观测）：Observe and Pick Up、Rearrange Blocks、Put Back Block、Swap Blocks、Swap T。
  - 4 个 `M(n)` 任务（决策依赖多个任务相关历史观测）：Battery Try、Blocks Ranking Try、Cover Blocks、Press Button。
- **训练/评估协议**：每个任务 50 条专家演示训练，100 次评估 rollout，全局种子 0；语言/视觉规划器多任务训练，WAP 单任务训练（遵循 Mem-0）。
- **对比方法**：DP、π0.5、X-VLA、Mem-0、WLA-0、LingBot-VA。基线结果主要来自 RMBench 已有评估。

### 3.2 真实机器人实验

- **硬件**：7-DoF Franka Research 3 机械臂，第三人称和腕部 RealSense D435i 相机。
- **任务**：
  - **Find Button**：先观察按钮颜色，再被盖子遮挡，随后人类在白色板上给出颜色指令，机器人打开对应盖子。
  - **Press Buttons**：观察白板上两个数字，分别按压左右两个按钮若干次，再按右侧确认按钮。
- **数据与评估**：每任务 50 条轨迹训练，50 次独立试验评估。
- **对比方法**：FastWAM、π0.5、MaP-WAM。

### 3.3 消融与分析实验

- **记忆锚定视觉规划消融**：在 Observe and Pick Up 和 Swap T 上比较完整方法 vs. 移除视觉计划（w/o visual plan）vs. 用当前观测条件的世界模型替代 CWM（w/o visual memory）。
- **进度建模消融**：在 Blocks Ranking Try、Cover Blocks、Press Button 上比较完整方法 vs. 分类替代进度（classification）vs. 移除进度条件（w/o prog. cond.）vs. 移除进度校准（w/o prog. calib.）。
- **推理效率分析**：绘制规划器延迟随历史片段数变化；执行器单块延迟随历史帧数变化，并对比全上下文和计划上下文，观察 OOM 临界点。
