## 摘要
视觉-语言-动作模型（VLA）近年来通过将大语言模型（LLM）的语义理解与流匹配策略的精确控制相结合，变革了机器人操作领域。优势条件化是一种近期技术，它通过在部署数据上训练价值函数，并利用该价值函数训练优势条件化策略，从而迭代改进 VLA。以往工作仅采用简单的、低信息量的成功/失败奖励，导致价值函数只能区分状态在任务中表现出的进展程度，而无法区分不同质量的状态。受对分布外（OOD）检测方法探索的启发，我们提出了基于距离的优势学习（DistAL），该方法通过使用嵌入空间距离作为奖励，产生更具信息量的价值函数，从而获得更高的下游任务成功率。我们在一系列仿真基准以及真实硬件上的灵巧双手操作任务中验证了所提方法。

## Abstract
Vision-language-action models (VLAs) have trans- formed the field of robotic manipulation in recent years by combining the semantic understanding of LLMs with the precise control of flow-matching policies. Advantage conditioning is a recent technique that iteratively improves VLAs by training a value function on deployment data and using this to train an advantage-conditioned policy. Previous works have only applied simple, low-information success/failure rewards, which leave the value function unable to distinguish states of differing quality beyond how far along the task they appear. Motivated by an exploration of out-of-distribution (OOD) detection methods, we introduce Distance-based Advantage Learning (DistAL), which, by using an embedding space distance as a reward, produces a more informative value function and subsequently a higher downstream task success rate. We validate our method on a series of simulation benchmarks and dexterous bi-manual manipulation tasks on real hardware.

### 1. 核心问题与研究动机
- **背景**：视觉-语言-动作模型（VLA）结合大语言模型的语义理解与流匹配策略的精确控制，已显著提升机器人操作能力，但在接触丰富、灵巧操作任务中成功率仍不足，难以实际部署。
- **现有改进路径的局限**：
  - 基于人类干预的方法需要专家遥操作员持续待命，硬件与操作复杂度高。
  - 在线强化学习微调 VLA 存在样本效率低、训练不稳定、计算成本极高的问题。
  - 优势条件化（advantage conditioning）通过离线价值学习利用部署数据，无需人类专家、更稳定，但以往方法仅使用简单的成功/失败二元奖励。
- **关键问题**：二元奖励加上常数每步惩罚，使价值函数仅能根据“估计剩余步数”对状态排序，无法区分视觉上相似但质量不同的状态（如稳定抓取与不稳定抓取）。定制任务奖励又缺乏可扩展性，需要大量调参或人工标注。
- **核心思想**：失败轨迹相对成功参考数据集往往处于分布外（OOD）。本文探索用 OOD 检测方法预测失败，发现基于图像嵌入空间的 k 近邻（kNN）距离最能反映状态质量，于是将其作为稠密奖励，替代稀疏成功/失败奖励，改善优势条件化流程。

### 2. 方法论：Distance-based Advantage Learning (DistAL)
DistAL 是优势条件化流程中的 **drop-in 奖励替换**，策略、价值函数和训练流程保持不变，仅将奖励信号从稀疏二元改为稠密距离奖励。

- **kNN 特征距离奖励**：
  - 使用基础 VLA 的冻结 SigLIP 视觉编码器 \(f: \mathcal{O}\to\mathbb{R}^{d_f}\)，对基础 VLA 训练集 \(D_\text{train}\) 中的所有观测构建嵌入索引 \(I\)。
  - 对部署中遇到的任意观测 \(o\)，计算其到训练分布中 k 近邻的平均欧氏距离：
    \[
    s_k(o)=\frac{1}{k}\sum_{j\in N_k(f(o);I)}\|f(o)-z_j\|_2
    \]
  - 每步奖励定义为负距离：\(r_t=-s_k(o_t)\)，并归一化到 \([-1,0]\)。
  - 该奖励假设“靠近训练分布的状态更好”，但并非普遍成立；因此保留大终端失败惩罚（来自先前工作），确保仅停留在熟悉状态但未完成任务的情节仍获得低回报。
  - k 值对成功率不敏感，最终取 \(k=10\)。

- **价值函数**：
  - 由预训练 Gemma3 270M 语言模型 + 400M SigLIP 视觉编码器组成。
  - 输入与策略观测相同的图像、语言和状态条件，将输出 token 通过 2 层 MLP 头。
  - 不预测连续值，而是预测离散回报分箱上的分类分布，使用交叉熵损失（HL-Gauss 损失未带来额外收益）。
  - 训练目标为经验回报 \(G_t=\sum_{k=0}^{T-t} r_{t+k}\) 的离散回归。

- **优势条件化策略**：
  - 基于微调后的 π0.5 VLA，使用 PaliGemma 3B VLM + 300M 流匹配动作专家。
  - 通过向语言输入末尾追加文本 “Advantage: positive” 或 “Advantage: negative” 注入二元优势标签。
  - 阈值设置使 30% 的标签为正；训练时以概率 \(p\) 丢弃标签为 \(\varnothing\)。
  - 仅微调动作专家并冻结骨干，效果最佳。
  - 推理时使用分类器自由引导（CFG）：
    \[
    \tilde{v}_\theta(a_\tau,\tau,c,y=1)=v_\theta(a_\tau,\tau,c,\varnothing)+w\cdot\big(v_\theta(a_\tau,\tau,c,y=1)-v_\theta(a_\tau,\tau,c,\varnothing)\big)
    \]

- **训练流程**：
  1. 对部署数据每个观测计算 kNN 距离，赋奖励 \(r_t=-s_k(o_t)\)。
  2. 拟合价值函数到经验回报 \(G_t\)，根据优势 \(G_t-V_\phi(o_t)\) 超过阈值 \(\kappa\) 生成标签 \(y_t\)。
  3. 以优势标签微调 VLA，训练时随机丢弃标签，推理时用 CFG 引导。
