## 摘要
在接触密集型操作中，可靠的动作评估需要超越当前观测，考虑未来的视觉和接触后果。现有的噪声空间强化学习能够高效地引导冻结的视觉-语言-动作（VLA）策略，但其评价器在很大程度上忽略了这些后果。我们提出 Imagine-RL，它通过动作条件化的视觉-扭矩想象来增强噪声空间 VLA 的后训练过程。对于每个候选动作块，一个冻结的视觉-扭矩潜在世界模型（VTLWM）自回归地预测紧凑的未来表示，而无需像素重建。当前图像-状态-动作查询关注已观测的历史和预测的未来，而前一窗口的预测残差提供逐 token 的置信度先验，以抑制不可靠的未来 token。通过将当前证据与预测后果相结合，动作评价器能更好地评估候选动作并指导 actor 网络，而 VLA 和 VTLWM 保持冻结。在四个真实机器人任务中，每个任务进行 50 次评估试验，Imagine-RL 仅使用 100 条 RL 轨迹，相较于 DSRL 将平均成功率提高了 23.6%，相较于 VLA 基线提高了 60%。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

# Imagine-RL 论文总结

## 1. 核心问题与研究动机
- 在接触密集型机器人操作中，可靠的策略评估需要预见未来视觉和接触后果，但现有面向 VLA 的噪声空间强化学习方法中，critic 大多只基于当前观测与动作，忽略未来后果。
- 传统 VLA 以视觉为主，对阻力、滑动、卡滞等接触现象难以直接感知；力感知 VLA（如 TA-VLA、ForceVLA）虽引入力矩/力信息，但主要用于动作生成，而非价值估计。
- RL 后训练真实交互成本高，且视觉相似的动作可能导致成功或失败截然不同，需要“想象未来”来区分候选动作。
- 世界模型可以提供前瞻证据，但将“力条件想象”用于 critic 学习的研究尚不充分。Imagine-RL 旨在解决上述不足。

## 2. 方法论
### 2.1 总体框架
- Imagine-RL 是轻量级噪声空间 VLA 后训练方法：冻结 flow-matching VLA 策略，仅训练潜在噪声 actor；冻结视觉–扭矩潜在世界模型 VTLWM，为 critic 提供动作条件化未来特征。
- 动作 critic 使用当前图像–状态–动作表示作为 query，对视觉和扭矩的历史与未来 token 进行交叉注意力检索，并利用前序窗口预测残差计算置信度先验，抑制不可靠未来 token。
- 动作 critic 提供教师值，蒸馏到噪声 critic，再更新噪声 actor；VLA 和 VTLWM 全程冻结，无需微调骨干或做像素级规划。

### 2.2 关键组件与公式/流程
- **潜在噪声 VLA-RL**：
  - 冻结策略 \(\bar{a}_t = \pi_0(o_t, w_t)\)，输出动作块；噪声 actor \(\pi_\theta(w|o)\) 只输出潜噪声。
  - 动作 critic \(Q_a(o,\bar{a};h^{\bar{a}})\) 评估解码动作；噪声 critic \(Q_w(o,w)\) 蒸馏自 \(Q_a(o,\pi_0(o,w))\)。
  - Bellman 目标：\(y_t = r_t + \gamma^{H_q} \frac{1}{n}\sum_{i=1}^n \bar{Q}_{a,i}(o_{t+1}, \bar{a}_{t+1}; h^{\bar{a}'}_{t+1})\)。
- **VTLWM 视觉–扭矩潜在世界模型**：
  - 共享编码器将多视图图像编码为视觉潜变量 \(z_t\)，扭矩/动作归一化后为 \(\hat{\tau}_t\) 和 \(a_t\)；状态 \(x_t=[z_t,\hat{\tau}_t]\)。
  - 固定一步因果预测器，历史长度 \(H=15\)，自回归展开未来 \(H_f=10\) 步。
  - 损失：\(L_{WM}=\text{MSE}(P^z_{1:H},Z_{1:H})+\lambda_\tau \text{SmoothL1}(P^\tau_{1:H},T_{1:H})+\lambda_{sig}L_{SIGReg}\)。
- **残差置信度引导交叉注意力 critic**：
  - 由当前观测+候选动作得到 query \(q_t=f_q(\zeta_t)\)。
  - 世界模型生成与候选动作一致的未来表示；历史、未来、前序预测与残差分别构成特征。
  - 残差计算：\(R^m_{t,j}=X^{m,hist}_{t,j}-P^{m,prev}_{t,j}\)；相对误差 \(\rho^m_{t,j}\)；置信度 \(\alpha^m_{t,j}=\max(\alpha_{\min}, e^{-\beta \rho})\)。
  - 多头交叉注意力中，query-key 点积度量相关性，偏置项对历史 token 为 0、有效未来 token 为 \(\log \alpha\)、无效位置为 \(-\infty\)，从而对不可靠未来施加惩罚。
  - 多模态上下文 \(h^a_t=[c^z_t, c^\tau_t, g^z_t, g^\tau_t]\)，最终 \(Q_a(o_t,a_t;h^a_t)=Q([\zeta_t,h^a_t])\)。
- **算法流程**：初始化 buffer、冻结 VLA 和 VTLWM；循环采样转移 → 更新动作 critic → 更新噪声 critic → 更新噪声 actor。
