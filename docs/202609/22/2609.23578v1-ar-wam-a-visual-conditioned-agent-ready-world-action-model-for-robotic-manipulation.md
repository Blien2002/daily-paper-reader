## 摘要
随着AI智能体能力日益增强，智能体驱动的机器人控制正成为一种引人注目的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口不适合智能体驱动控制：指代歧义、空间不精确、与智能体固有的语言理解冗余，并将意图与执行纠缠在一起。我们提出了AR-WAM，一种视觉条件化、智能体就绪的世界动作模型，用两个互补条件取代语言：一个表示交互对象与位置的视觉定位提示（目标边界框），以及一个规定所要执行的原子技能的可学习操作令牌。我们的紧凑0.5B参数模型采用冻结的预训练视觉编码器且不含语言编码器，在紧凑潜在状态中预测场景演化并解码动作，通过显式、可监督的推理信号揭示策略意图。模型无关的兼容层提供三种原语（检测、执行与查询），使本地VLM或在线智能体API可以直接驱动策略，长期记忆与闭环错误恢复交由智能体侧处理。在RoboTwin 2.0、RMBench和真实Astribot S1双臂平台上，AR-WAM在标准操作任务上与最强基线相当（平均成功率87.2%），在依赖记忆与真实机器人长时程任务上优于它们，成功率分别提升5.9%与36.7%，同时保持最低推理延迟（14.1毫秒）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

## 1. 论文的核心问题与整体含义

- **研究背景**：随着 AI 智能体（agent）能力增强，智能体驱动的机器人控制（agent 作为高层“大脑”、策略模型作为“小脑”）成为重要范式。
- **核心问题**：现有 VLA（视觉-语言-动作）模型和世界动作模型（WAM）几乎都依赖自然语言指令来指定操作任务，但语言条件在智能体驱动控制中存在四大缺陷：
  - **指代歧义**：桌面上多个相似物体时，文本难以唯一指定目标。
  - **冗余**：语言理解本来就是智能体的强项，在策略中重新学习语言理解浪费训练计算。
  - **空间不精确**：文本经过策略自身的语言编码器后，难以实现精确空间引导。
  - **黑盒纠缠**：将理解、规划、记忆和动作生成塞进一个不可解释的模型，失败时无法区分是意图错误还是执行错误。
- **整体含义**：作者主张在智能体时代，策略真正需要的条件信号应该是**视觉空间信号而非语言**；因此提出 AR-WAM，用“视觉定位提示 + 可学习操作令牌”取代语言，构建一个**智能体就绪**的世界动作模型，让智能体负责语言理解、规划、记忆和错误恢复，策略专注动作生成。

## 2. 方法论

### 2.1 总体思想
- AR-WAM 将操作分解为有限原子技能词汇 `S = {pick, place, handover, click, pull, ...}`，每个技能用一个可学习嵌入 `e_s` 表示。
- 每个技能调用配对**视觉提示**：一个归一化图像坐标下的目标边界框 `g = (x1,y1,x2,y2)`，双机械臂任务扩展为两个框。
- 智能体可额外指定两个辅助属性：参与者 `u`（哪只手臂）和风格 `w`（交互方式），分别用可学习嵌入 `e_u, e_w` 表示。
- 智能体决策通过 **AdaLN 条件调制**注入策略；所有交互行为均为学习得到的技能，系统级辅助运动（如回位）由传统轨迹规划处理。

### 2.2 模型架构
- **紧凑 0.5B 参数模型**：由 0.2B 共享 Transformer（推理专家 + 世界动作专家共享）和冻结的 0.3B DINOv3 视觉编码器组成，**不包含语言编码器**。
- **推理专家（Reasoning Expert）**：
  - 使用可学习推理查询令牌 `q_reas` 对观测和任务条件进行探测，生成推理令牌 `q_t`。
  - 轻量推理头将 `q_t` 解码为三个显式、可监督的预测：
    - 框选对象的像素级掩码；
    - 双臂在技能结束时的末端执行器位姿；
    - 当前步骤的任务抽象（如使用哪只手臂、如何抓取和放置）。
  - 推理损失：`L_reas = BCE(掩码) + CE(任务抽象) + ||末端位姿||²`。
- **前视要点提取（Foresight-gist extraction）**：
  - 离线预训练一个前视要点提取器：冻结编码器 E 将两帧 `o_t0, o_t1` 映射为潜在帧，潜在逆动力学模块压缩时间演化为前视要点 `f_t0→t1`；潜在前向动力学模块从当前帧和要点重构未来潜在帧，训练损失为潜在重构损失。
  - 该要点只在训练时作为目标，推理时不使用。

### 2.3 世界动作专家（World Action Expert）
- 与推理专家共享 Transformer，通过流匹配（flow matching）联合去噪三种输出模态：
  - **动作块** `a_{t→t+H-1}`：与演示动作块对齐，使用速度回归损失 `L_act`。
  - **视觉前视预测** `f_{t→t+H-1}`：与离线提取的前视要点对齐，损失 `L_vis`。
  - **语义前视预测** `q_{t+H-1}`：与共享权重的推理骨干从未来观测产生的推理令牌对齐（停止梯度），损失 `L_sem`。
- 采用块注意力掩码，使动作和前瞻分支可以条件化于推理输出而不污染推理路径；推理前向与第一步去噪共享一次前向，其余去噪步骤复用 KV 缓存。

### 2.4 训练目标与数据
- 总损失：`L = L_act + λ_reas L_reas + λ_vis L_vis + λ_sem L_sem`。
- 数据来源：RoboTwin 2.0 和 RMBench 仿真数据，真值物体状态转换为边界框视觉提示。
- **视觉提示增强**：训练时随机抖动框中心、高度和宽度，使策略容忍不精确的智能体输出框。

### 2.5 智能体兼容层与失败恢复
- 智能体建模为“模型 + 框架（harness）”：大（视觉）语言模型 + 系统提示、规则、工具调用、交互历史和闭环。
- 提供三个模型无关原语：
  - `detect(y) → g`：智能体侧将语言查询（如“红色马克杯”）在当前观测中定位为边界框，策略不接触语言。
  - `execute(g, s, u, w) → ξ`：运行策略直到触发事件发生。
  - `query(ξ) → b`：将执行结果打包反馈给智能体。
- **事件触发智能体调用**：不是每步调用，而是由末端位移超阈值、夹爪闭合、夹爪张开、固定时间间隔四类事件触发。
- **长期记忆与错误恢复**：策略保持马尔可夫性，所有长期结构由智能体的历史/记忆承担；失败时智能体重新 `detect` 得到更新框并重新 `execute`，重试有固定预算；策略解码出的意图信号用于诊断失败是意图错误还是执行错误。

## 6. 主要结论与发现

- **视觉提示优于语言条件**：在相同训练下，用视觉提示替换文本指令平均成功率提升 13.0%；在视觉提示基础上加文本反而下降 2.6%，说明空间定位到位后

语言条件反而成为冗余噪声，干扰动作生成。  
- **推理与前瞻解耦有效**：去除推理专家或前视要点均导致成功率明显下降；推理专家提供的显式意图信号（掩码、末端位姿、任务抽象）不仅改善了动作生成质量，还为后续失败诊断提供了可解释依据。  
- **AdaLN 调制优于交叉注意力**：在相同条件下，采用 AdaLN 注入视觉提示与技能令牌比交叉注意力更稳定、成功率更高，说明轻量、低秩的条件注入更适合紧凑型世界动作模型。  
- **长时程记忆任务中智能体-策略分工成功**：在 RMBench 的 M(1) 与 M(n) 分组中，AR-WAM 显著超越 Pi0.5、Fast-WAM、LiLa-WAM 及三个记忆增强基线；策略保持马尔可夫性、由智能体承载长期记忆与重规划的设计，在需要跨步骤记忆和错误恢复的任务中表现出明显优势。  
- **真实机器人可部署性**：在 Astribot S1 双机械臂平台上，AR-WAM 经过少量真实数据微调后，在三个长时程任务上取得优于 Pi0.5 和 LiLa-WAM 的成功率，验证了视觉提示条件与原子技能词汇在 sim-to-real 迁移中的有效性。  
- **效率优势**：由于移除了语言编码器，并复用推理前向与 KV 缓存，AR-WAM 的端到端推理延迟在单张 RTX 4090 上低于同等规模的 VLA 基线；事件触发式智能体调用进一步降低了系统级决策开销。

- **训练开销与可复现性**：未明确报告训练 GPU 数量与时长，削弱了资源评估的完整性；未来工作可补充训练效率与碳足迹分析。

AR-WAM 提出了一个明确且及时的论点：在智能体驱动的机器人控制中，策略模型应接受视觉空间条件而非自然语言，将语言理解、规划与记忆职责归还给上游智能体。该工作通过原子技能词汇、视觉提示、推理专家与前视要点提取，构建了一个紧凑、高效且可解释的世界动作模型，并在仿真和真实机器人上验证了其优越性。其主要贡献在于重新定义了智能体与策略之间的接口，为后续 VLA/WAM 研究提供了新的设计范式；同时，显式推理损失与事件触发调用机制也为可诊断、可恢复的机器人操控系统提供了实用思路。尽管存在任务范围和数据规模上的局限，论文的整体实验设计较为严谨，消融充分，论证逻辑清晰，具有较高的参考价值。
