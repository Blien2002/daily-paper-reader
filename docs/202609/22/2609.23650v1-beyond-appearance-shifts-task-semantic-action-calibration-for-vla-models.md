## 摘要
视觉-语言-动作（VLA）模型在具身操作中取得了较强性能，但仍缺乏在行为稳定性与任务语义敏感性之间取得平衡的明确机制。我们识别出两种互补的失效模式。在任务保持型变化下，任务语义保持不变但场景外观发生变化（如风格、光照、杂乱或指令改写），策略往往出现不必要的动作漂移。相反，在语义破坏型变化下，目标任务物体或约束等关键任务语义发生改变，策略通常无法产生足够不同的行为，而是沿原始轨迹执行。为解决这一问题，我们提出 BAS-VLA，一个构建在冻结基础 VLA 之上的任务语义动作校准框架。BAS-VLA 采用以破坏为中心的校准核心作为默认路径，并引入选择性证据门控保持辅助模块，仅在检测到干扰变化且任务语义保持一致时激活。在 OpenPI-pi0.5 / LIBERO-Object Milk-Swap 基准上，BAS-VLA 在干净条件（98.0%）和语义保持条件（97.5%）下保持高成功率，同时在故意交换目标物体时干净标准成功率降至 0.0%，展示了强大的陈旧任务抑制和任务语义分离能力。在经验证的风格保持变化上，它将成功率从 42% 提升至 70%，且不降低干净性能。这些结果表明，可靠的 VLA 行为需要超越外观鲁棒性，转向显式的任务语义动作校准。

## Abstract
Vision-language-action (VLA) models have achieved strong performance in embodied manipulation, but still lack a clear mechanism to balance behavioral stability with task-semantic sensitivity. We identify two complementary failure modes. Under task-preserving changes, where task semantics remain unchanged but scene appearance varies (e.g., style, illumination, clutter, or paraphrasing), policies often exhibit unnecessary action drift. Conversely, under semantic-breaking changes, where key task semantics such as the target object or constraint are altered, policies frequently fail to produce sufficiently distinct behaviors and instead follow the original trajectory. To address this gap, we propose BAS-VLA, a task-semantic action calibration framework built on top of a frozen base VLA. BAS-VLA adopts a breaking-centered calibration core as the default path, and introduces a selective evidence-gated preserving auxiliary that activates only when nuisance variation is detected while task semantics remain consistent. On the OpenPI-pi0.5 / LIBERO-Object Milk-Swap benchmark, BAS-VLA maintains high success on clean (98.0%) and semantics-preserving conditions (97.5%), while reducing clean-criterion success to 0.0% under deliberate target-object swaps, demonstrating strong stale-task suppression and task-semantic separation. On validated style-preserving shifts, it improves success from 42% to 70% without degrading clean performance. These results highlight that reliable VLA behavior requires moving beyond appearance robustness toward explicit task-semantic action calibration.

- **研究背景与动机**：视觉-语言-动作（VLA）模型在具身操作中表现优异，但可靠性仍不足。现有研究多关注通用外观鲁棒性，却忽视了任务语义层面的行为校准。
- **识别出的两个互补失效模式**：
  - **任务保持型变化（task-preserving changes）**：光照、风格、杂乱、视角或指令改写等仅改变外观/措辞而不改变任务语义，理想行为应保持稳定，但策略常出现不必要的动作漂移（action drift）。
  - **语义破坏型变化（semantic-breaking changes）**：目标物体、目标位置、空间关系、子目标顺序、可执行性等关键语义被改变，策略应显著偏离原轨迹，却往往仍沿原始动作执行，缺乏行为区分度。
- **论文核心主张**：可靠的 VLA 行为不能只依赖外观鲁棒性，而需要显式的**任务语义动作校准**——明确哪些编辑应保持行为不变，哪些应强制产生行为分离。

### 2.2 破坏为中心的校准核心（默认路径）
- **残差形式**：
  \[
  a^{\text{br}}_t = a^{(0)}_t + \lambda\,r_\theta(a^{(0)}_t, z(x))
  \]
  - \(a^{(0)}_t\)：冻结基础策略输出。
  - \(z(x)\)：冻结的指令特征。
  - \(r_\theta\)：轻量残差校准器。
  - \(\lambda>0\)：残差尺度。
- **训练目标**基于匹配的指令三元组 \((x_c, x_u, x_b)\)（干净、语义保持控制、语义破坏）：
  \[
  L_{\text{imit}} = \|a^{\text{br}}(x_c)-a^\star_t\|_2^2 + \|a^{\text{br}}(x_u)-a^\star_t\|_2^2
  \]
  \[
  L_{\text{cons}} = \|a^{\text{br}}(x_c)-a^{\text{br}}(x_u)\|_2^2
  \]
  \[
  L_{\text{sep}} = \max\big(0,\; m - \|a^{\text{br}}(x_b)-a^{\text{br}}(x_c)\|_2 + \|a^{\text{br}}(x_u)-a^{\text{br}}(x_c)\|_2\big)
  \]
  最终目标：\(L_{\text{br}} = L_{\text{imit}} + \lambda_c L_{\text{cons}} + \lambda_s L_{\text{sep}}\)。
- **效果**：语义保持变体被收缩到干净动作附近，语义破坏变体被推开至少间隔 \(m\)。

### 2.3 选择性证据门控保持辅助
- **目的**：仅在检测到干扰变化（如光照）且任务语义保持一致时，提供弱校正，避免不必要漂移。
- **探针视图构造** \(\tilde{o}^{\text{sty}}_t = \phi_{\text{sty}}(o_t)\)：
  - 使用 Grounding DINO 进行文本条件定位，SAM 2 细化掩码，合并任务相关前景掩码，衰减背景中的低层外观线索（颜色、光照、纹理），保留物体身份、布局和任务相关几何。
- **证据门控**：
  \[
  \tau_t = \tau_{\text{phase}}(t,h_t)\; g_{\text{vis}}(v^{\text{mid}}_t,\tilde{v}^{\text{mid}}_t)\; g_{\text{sem}}(v^{\text{late}}_t,\tilde{v}^{\text{late}}_t,x)\; g_{\text{act}}(a^{(0)}_t,a^{\text{sty}}_t)
  \]
  - \(\tau_{\text{phase}}\) 抑制后期干预。
  - \(g_{\text{vis}}\) 衡量冻结中层视觉特征差异。
  - \(g_{\text{sem}}\) 衡量冻结后期视觉特征的语义一致性。
  - \(g_{\text{act}}\) 衡量视觉变化是否已扰动基础动作。
- **弱融合**：
  \[
  a^{\text{pres}}_t = (1-\alpha\tau_t)\,a^{(0)}_t + \alpha\tau_t\,a^{\text{sty}}_t,\quad \alpha\in(0,1)
  \]
  当 \(\tau_t=0\) 时完全退化为基础动作。

### 2.4 部署模式
- **默认模式**：仅使用破坏核心 \(a^{\text{default}}_t = a^{\text{br}}_t\)。
- **保持模式**：仅使用证据门控辅助 \(a^{\text{pres}}_t\)。
- **全组合模式**（用于消融）：\(a^{\text{full}}_t = (1-\alpha\tau_t)a^{\text{br}}_t + \alpha\tau_t a^{\text{sty}}_t\)。

- **报告负面结果**：Butter-Swap 等困难案例、MetaWorld 边界失效、消融中全组合不占优等均有报告，增强了可信度。
- **形式化性质**：附录提供边际、漂移界、门控恒等式等，理论支撑较好。

## 8. 不足与局限

- **保持辅助适用范围有限**：最强证据来自风格变化切片，对光照、噪声、杂乱等外观变化的提升较小或仅部分支持。
- **全组合模式不占优**：在消融中，全组合在语义破坏侧保留 4–5% 旧任务成功，不如默认核心；作者也承认全组合不是首选部署。
- **困难语义破坏案例表现差**：Butter-Swap 旧任务成功率仍高达 56.5%，说明视觉相似物体对的语义混淆未解决。
- **算力与训练细节不完整**：未报告训练时长、总 epoch 数、优化器参数等，复现成本难以估计。
- **范围限制**：论文明确声明不是通用鲁棒性方案，证据集中在受控干预家族和冻结策略适配；跨基准（MetaWorld 等）仅作边界证据。
- **外部策略比较可能不全面**：仅主要 Milk-Swap 一个任务展示对比，其他任务的策略对比未见完整数据。
- **动作级诊断仅作辅助**：任务成功是主要指标，动作空间分离证据非独立评价标准。
