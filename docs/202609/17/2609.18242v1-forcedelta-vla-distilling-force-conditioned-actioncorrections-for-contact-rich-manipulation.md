## 摘要
具有力感知的视觉-语言-动作（VLA）策略能够改善接触丰富操作，但通常将任务级运动与接触依赖调整合并到单一动作预测中。演示并未提供显式标签来将该预测分解为可复用参考动作与校正量。我们提出 ForceDelta-VLA，一种校正蒸馏框架，它利用冻结教师模型的力条件模式与学习到的力无关模式所生成的成对预测来构建显式的力校正目标。另一个延迟校正目标用于处理参考动作不匹配以及参考状态的变化。训练使用异步调度回放，并利用执行期间可用的缓存任务上下文。由此得到的轻量策略利用近期力历史和机器人状态来调整参考动作，能够在参考动作更新之间响应接触变化，而无需重新生成完整动作块。在九个单臂和双臂接触丰富任务中，ForceDelta-VLA 的平均成功率达到 82.2%，而原始 ForceVLA 基线为 54.4%。直接执行我们的 Stage-1 Temporal Teacher 可获得 70.6%。相对于 ForceVLA，完整系统在成功试验中，两个平台上的平均峰值接触力均降低了约 26%。

## Abstract
Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation, but typically combine task-level motion and contact-dependent adjustment in a single action prediction. Demonstrations provide no explicit labels for decomposing that prediction into a reusable reference action and a correction. We present ForceDelta-VLA, a correction-distillation framework that constructs an explicit force-correction target using paired predictions from a frozen teacher's force-conditioned and learned force-agnostic modes. A separate delay-correction target accounts for reference-action mismatch and the change in reference state. Training uses asynchronous schedule replay with the cached task context available during execution. The resulting lightweight policy adjusts the reference actions using recent force history and robot state, responding to contact changes between reference-action updates without regenerating complete action chunks. Across nine single-arm and bimanual contact-rich tasks, ForceDelta-VLA achieves an 82.2% mean success rate, compared with 54.4% for the original ForceVLA baseline. Direct execution of our Stage-1 Temporal Teacher achieves 70.6%. Relative to ForceVLA, the complete system reduces mean peak contact force over successful trials by approximately 26% on both platforms.

## 1. 论文的核心问题与整体含义

- **研究背景**：接触丰富操作（contact-rich manipulation）中，动作需要随着接触状态变化而快速调整。例如 USB 插入时，宏观接近方向可能保持不变，但局部对准必须响应新出现的接触力。
- **现有问题**：力感知视觉-语言-动作（VLA）策略通常将“任务级运动”和“接触依赖调整”合并在同一个动作预测中，无法显式分离。演示数据只提供最终动作，没有标签说明哪一部分是参考运动、哪一部分是接触修正。
- **挑战**：若希望用“慢速参考动作 + 快速接触修正”的异步结构，就必须从演示中构建显式的修正监督目标，否则同一个演示动作可以对应无数种参考与修正的组合。
- **本文目标**：提出 ForceDelta-VLA，在只使用原始演示数据、不依赖奖励或额外在线交互的前提下，通过蒸馏方式学习力校正和延迟校正，使轻量学生策略能够在参考动作更新之间快速响应接触变化。

## 2. 论文提出的方法论

### 2.1 整体架构思想

- 系统将动作分解为：

\[
A_{\text{cmd}} = A_{\text{ref}} + \Delta \hat{A}_{\text{force}} + \Delta \hat{A}_{\text{delay}}
\]

- 其中：
  - \(A_{\text{ref}}\)：由慢速生成式教师预测的参考动作块。
  - \(\Delta \hat{A}_{\text{force}}\)：由快速学生策略预测的力校正量。
  - \(\Delta \hat{A}_{\text{delay}}\)：由快速学生策略预测的延迟校正量，用于补偿参考动作因异步更新产生的不匹配。
- 只有位姿部分被修正，夹爪指令仍来自参考动作。

### 2.2 三阶段训练流程

#### 阶段 1：训练时间力条件教师

- 以 ForceVLA 为主干，替换其瞬时力嵌入为基于 FAVLA 的因果时序卷积网络（TCN），编码 100 ms 的力/扭矩历史：

\[
z_{F_t} = E_F^T(F_t)
\]

- 教师 \(T_\theta\) 接收视觉、语言、机器人状态和力历史，预测 \(H\) 步动作块。
- 训练完成后冻结 \(\theta\)。

#### 阶段 2：学习力无关参考动作模式

- 为区分“力输入不可用”与“实际测得零力”，引入力无关模式：
  - 用可学习 token \(z_\emptyset^F\) 替代力历史输入。
  - 增加 rank-\(\rho\) adapter \((W_{\text{in}}, W_{\text{out}})\) 修改动作专家的位姿输出。
- 用原始的 flow-matching 目标训练 adapter 参数 \(\phi\)，得到力无关参考动作预测：

\[
A^{\text{ref}}_{T,t,1:H} = T^{\text{ref}}_{\theta,\phi}(V_t, L, S_t, z_\emptyset^F; \epsilon)
\]

### 2.3 成对校正目标构造

- 对每个校正时刻 \(t\)，使用最近的参考动作查询 \(k\)。
- 复用参考查询的视觉-语言前缀 \(E_k\) 和 flow 噪声 \(\epsilon_k\)，但更新到当前机器人状态 \(S_t\) 和当前力历史 \(F_t\)，分别计算：
  - 力条件预测 \(A^{\text{cond}}_{T,t|k}\)
  - 力无关预测 \(A^{\text{ref}}_{T,t|k}\)
- **力校正目标**为两者位姿差：

\[
\Delta A^{\text{force}}_{T,t|k,j} = P(A^{\text{cond}}_{T,t|k,j}) - P(A^{\text{ref}}_{T,t|k,j})
\]

- **延迟校正目标**为：

\[
\Delta A^{\text{delay}}_{T,k \to t,j} = P(A^{\text{ref}}_{T,t|k,j}) - P(A^{\text{ref}}_k(t_j)) + \Gamma(S_t, S_k)
\]

- 其中：
  - \(A^{\text{ref}}_k(t_j)\) 是已存储参考动作在时间 \(t_j\) 的插值。
  - \(\Gamma(S_t, S_k)\) 将参考状态变化转换到归一化动作坐标，用于对齐参考状态。

### 2.4 学生校正策略

- 学生输入包括：
  - 缓存任务上下文 token \(Z^{\text{ctx}}_k\)
  - 力历史编码 \(u_{F_t}\)
  - 当前状态 \(S_t\)
  - 插值后的参考动作段 \(A^{\text{ref}}_k(t_{1:K})\)
  - 时序特征 \(\xi_{t,k}\)
- 使用共享注意力模块 \(\Phi\) 和可学习查询 \(q_{\text{corr}}\)。
- 两次前向：
  - 一次包含全部条件，预测 \(\Delta \hat{A}_{\text{force}}\)。
  - 一次屏蔽力 token，预测 \(\Delta \hat{A}_{\text{delay}}\)。
- 两个独立输出头分别预测 \(K=5\) 步校正。
- 训练损失：

\[
L_{\text{distill}} = \sum_{j=1}^{K} w_j \left[ \ell_{\text{pose}}(\Delta \hat{A}^{\text{force}}_{t,j}, \Delta A^{\text{force}}_{T,t|k,j}) + \lambda_{\text{delay}}\,\ell_{\text{pose}}(\Delta \hat{A}^{\text{delay}}_{t,j}, \Delta A^{\text{delay}}_{T,k \to t,j}) \right]
\]

### 2.5 异步执行

- 部署时，教师持续周期性刷新缓存的参考动作。
- 学生以更高频率读取最近完成的参考动作，并输出力/延迟校正。
- 执行器选择最近完成且有效的学生查询，插值参考动作，分别裁剪两种校正后组合为最终命令。
- 学生查询不等待新参考动作完成，因此能够在参考动作生成期间持续响应接触变化。

## 6. 主要结论与发现

- ForceDelta-VLA 在 9 个任务上平均成功率为 **82.2%**，显著高于 ForceVLA 的 **54.4%**，也高于 π0.5、TA-VLA、ImplicitRDP 和直接执行 Temporal Teacher。
- 相比 Temporal Teacher（70.6%），修正策略进一步提升约 **11.7 个百分点**。
- 在 USB Insertion、Plug Insertion、Button Pressing 等接触敏感任务上提升尤其明显。
- 相对 ForceVLA，完整系统在两个平台上的平均峰值接触力约降低 **26%**；相对 Temporal Teacher 也有进一步降低。

- 对未见物体，ForceDelta-VLA 比 Temporal Teacher 成功率提高 **26.7 个百分点**，峰值力降低 8.2 N。
- 消融显示：力校正、延迟校正和异步调度回放均对性能有正向贡献；分离双头优于单合并头；蒸馏教师配对预测优于演示直接构造目标。

## 7. 优点

- **监督信号来源新颖**：仅利用原始演示数据，通过冻结教师的力条件与力无关模式配对预测构造校正目标，无需奖励、无需额外在线交互。
- **架构分离清晰**：慢速参考动作与快速接触修正解耦，允许接触反馈在高频下影响执行而不阻塞参考动作生成。

- **力无关模式设计合理**：区分“缺失力输入”与“零力接触”，避免将二者混淆。
- **轻量高效**：学生策略前向仅 2.43 ms，远低于生成式教师，具备实时部署潜力。
- **实验规模较大**：9 个真实机器人任务、多平台、多基线、消融和泛化测试较完整。
- **实际收益明显**：不仅提升成功率，还显著降低峰值接触力，说明修正策略确实改善接触柔顺性。
