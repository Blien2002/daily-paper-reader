## 摘要
主流机器人策略通常采用马尔可夫形式，但许多复杂的现实世界操作任务本质上是非马尔可夫的，需要超出当前观测的长期记忆。现有记忆机制通常依赖语言摘要、不断增长的视觉窗口或它们的组合，因此可能丢失细粒度视觉证据，或在历史覆盖范围与执行效率之间面临权衡。我们提出 MaP-WAM，一种“记忆即计划”框架，将依赖记忆的世界-动作建模分解为基于记忆锚定的规划与以计划为条件的执行，并使用长期多模态情景上下文作为规划阶段的证据，而不是反复让执行器依赖完整历史。MaP-WAM 将记忆表示为已完成片段的记录，其中包含语言指令和稀疏视觉上下文，并将这些情景记忆转换为紧凑计划，包括下一片段级语言计划和相应的视觉引导。世界-动作-进展（WAP）模型在未知时长内执行每个计划，在推理时联合预测动作块和相应的执行进展，并通过计划-观测对齐来校准预测进展，以实现自适应片段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，同时结构化注意力进一步支持规划与执行中的键值缓存。MaP-WAM 在 RMBench 上取得了 83.3% 成功率的最先进性能，在真实机器人任务上达到 78.0% 成功率，同时在任务历史增长时保持近似恒定的执行器推理延迟。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

- **研究背景与动机**  
  主流机器人策略，尤其是视觉-语言-动作（VLA）模型和世界-动作模型（WAM），大多基于马尔可夫假设，只用当前观测或固定短窗口预测动作。但许多真实操作任务本质上是非马尔可夫的，需要在当前观测之外保留长期历史信息。例如，任务要求记住被遮挡物体的位置、颜色或数量，而这些信息在决策时已不可见。

- **现有方法的局限**  
  现有记忆机制主要有三类：
  - **语言记忆**：将历史压缩为语言摘要或子任务指令，虽然紧凑、可解释，但容易丢失细粒度视觉和空间证据。
  - **持续更新记忆**：维护可更新的潜在状态或记忆库，但长时程下早期证据可能被压缩或覆盖。
  - **增长窗口记忆**：直接扩展观测上下文，保留更丰富的时空证据，但推理延迟和 GPU 显存随历史增长而快速上升，造成历史覆盖与执行效率之间的权衡。

- **论文整体含义**  
  本文提出 **MaP-WAM（Memory-as-Plans）** 框架，核心思想是：长期视觉历史不必在每一步执行时都作为直接输入，而应主要在规划阶段用于生成“记忆锚定计划”。框架将记忆依赖的世界-动作建模分解为 **记忆锚定规划** 与 **计划条件执行**，用长期多模态情景上下文作为规划时证据，生成紧凑的语言-视觉计划，再由执行器以固定上下文长度执行。这样既保留细粒度视觉证据，又避免执行器随历史增长而变得低效。

## 2. 论文提出的方法论

### 2.1 总体分解

- 原始记忆依赖策略建模为：
  \[
  \pi(a_{t+1:t+h} \mid f_{\le t}, s_t, l)
  \]
  其中 \(f_{\le t}\) 为观测历史，\(s_t\) 为本体感受状态，\(l\) 为全局指令。

- MaP-WAM 将其分解为：
  - **规划阶段**：\(\pi_P(C_k \mid C_{<k}, l)\)，根据已完成的片段上下文 \(C_{<k}\) 和全局指令 \(l\)，生成下一个片段级计划 \(C_k\)。
  - **执行阶段**：\(\pi_E(a_{t+1:t+h} \mid C_k, f_t, s_t, l)\)，执行器仅以当前观测 \(f_t\)、机器人状态 \(s_t\)、当前计划 \(C_k\) 和全局指令为条件，预测动作块。其输入不随历史长度增长，因此执行器上下文长度固定。

### 2.2 结构化多模态情景上下文

- 每个已完成片段 \(i\) 记录为 \(C_i = \{l_i, G_i\}\)：
  - \(l_i\)：该片段的语言指令。
  - \(G_i\)：从该片段真实执行轨迹中均匀采样的固定长度稀疏视觉上下文（默认 \(N=8\) 帧）。
- 初始观测单独保存为 \(G_0 = f_0\)。
- 规划第 \(k\) 个片段时，可用的情景上下文为 \(C_{<k} = \{(l_1, G_1), \dots, (l_{k-1}, G_{k-1})\}\)。

### 2.3 记忆锚定语言-视觉规划

- **语言规划器**  
  使用微调的 VLM（Qwen3.5-4B）预测下一片段级语言计划 \(l_k\)。输入包括全局指令 \(l\)、已完成片段指令 \(l_{<k}\)、以及从 \(G_{<k}\) 提取的紧凑关键帧集 \(f^\star\)（初始帧 \(G_0\) 和每个已完成片段的最后一帧）。

- **视觉规划器：因果世界模型（CWM）**  
  CWM 从 WAN-2.2-5B 视频生成模型初始化，以长期视觉上下文 \(G_{<k}\)、语言计划 \(l_k\) 和全局指令 \(l\) 为条件，生成视觉计划 \(G_k\)。训练使用标准 flow-matching 目标：
  \[
  \mathcal{L}_v^P = \mathcal{L}_{FM}(G_k, (G_{<k}, l_k, l))
  \]
  其中条件为 \(c=(G_{<k}, l_k, l)\)，目标为 \(y=G_k\)。

- **因果注意力与缓存**  
  CWM 将 token 组织为片段级块，使用块因果注意力掩码：未来的目标块不能影响已完成证据块。这样已完成证据的 key-value 状态可以预先计算并缓存，在后续规划阶段复用。

### 2.4 世界-动作-进展（WAP）模型

- **动机**  
  计划执行时长未知，由任务需求和随机执行动态决定。WAP 引入“进展”作为一阶模态，与动作联合预测，并作为条件信号反馈，从而提供显式时间坐标，区分视觉相似但语义不同的状态。

- **架构与训练**  
  WAP 在预训练视频 DiT 基础上扩展，采用 Mixture-of-Transformers（MoT）架构，包含：
  - 视频专家（未来视觉动态预测）
  - 动作专家（约 1.02B 参数，隐藏维度 \(d_a=1024\)）
  - 进展专家（约 207M 参数，隐藏维度 \(d_p=256\)）

  给定片段计划 \(C_k = \{l_k, G_k\}\)、当前观测 \(f_t\)、本体状态 \(s_t\)、当前进展 \(p_t\)，WAP 联合预测：
  - 未来视觉潜变量 \(\hat f_{t+1:t+h}\)
  - 动作块 \(\hat a_{t+1:t+h}\)
  - 进展序列 \(\hat p_{t+1:t+h}\)

  训练目标为三个分支的条件 flow-matching 损失加权和：
  \[
  \mathcal{L}_E = \lambda_v \mathcal{L}_v^E + \lambda_a \mathcal{L}_a^E + \lambda_p \mathcal{L}_p^E
  \]
  其中 \(\lambda_v=\lambda_a=\lambda_p=1.0\)。视觉分支可辅助训练，推理时可省略。

- **注意力掩码与缓存**  
  视觉计划作为静态干净前缀，当前观测作为干净状态 token，未来视觉、动作、进展为噪声目标 token。掩码设计使计划前缀不依赖动态 token 和目标 token，因此计划前缀 KV 可缓存并在整个片段执行期间复用。动作与进展 token 不关注未来视觉 token，反之亦然。交叉注意力中，所有 token 关注语言计划，动态 token 还受到本体状态和当前进展的调节。

### 2.5 闭环规划与执行

- **计划-观测对齐校准进展**  
  视觉计划帧按归一化进展索引。在每次预测前，根据当前进展估计检索附近计划帧，用当前观测与这些帧比较（RGB 平均绝对像素差），选择视觉最相似的帧，并将进展条件向该帧的进展值调整。这可以缓解递归进展预测在长时程执行中的误差累积。

- **进度门控片段转换**  
  对最近动作对应的预测进展取平均，若超过阈值 \(\tau=0.95\)，则判定当前片段完成，终止执行，更新情景上下文（用真实执行观测重采样为 \(G_k\)，替换生成的视觉计划），并触发下一轮规划。

- **推理流程**  
  Algorithm 1 总结了推理过程：初始化 \(G_0\)，循环进行语言规划、视觉规划、WAP 计划前缀缓存，然后在片段内反复执行动作块、校准进展、检查完成分数，直到进度超过阈值，再更新上下文并进入下一片段。

## 3. 实验设计

### 3.1 仿真实验：RMBench

- **基准**：RMBench，专门为长时程记忆依赖机器人操作设计的仿真基准。包含 5 个 M(1) 任务（决策依赖单个相关历史观测）和 4 个 M(n) 任务（决策依赖多个相关历史观测）。
- **训练设置**：每个任务使用 50 条官方专家演示训练，100 次评估 rollouts，全局随机种子 0。
- **对比方法**：DP、π0.5、X-VLA、Mem-0、WLA-0、LingBot-VA。
- **主要结果**：MaP-WAM 平均成功率 83.3%，在所有方法中最高。其中 Swap T 和 Press Button 均达 96%，Observe and Pick Up 从最强基线 9% 提升到 19%。

### 3.2 真实机器人实验

- **硬件平台**：7 自由度 Franka Research 3 机械臂，配备一个第三人称和一个腕部 RealSense D435i 相机。
- **任务**：
  - **Find Button**：先观察一组按钮颜色，然后用盖子遮挡；人类在白板上给出颜色指令，机器人需打开对应盖子找到按钮。
  - **Press Buttons**：观察白板上显示的两个数字，按左、中按钮指定次数，最后按右侧确认按钮。
- **训练与评估**：每个任务收集 50 条轨迹训练，50 次独立试验评估。
- **结果**：MaP-WAM 分别达到 88% 和 68% 成功率；基线 FastWAM 和 π0.5 在 Find Button 上仅靠随机选择获得非零成功率，在 Press Buttons 上全部失败。

### 3.3 消融与分析实验

- **视觉规划消融**：在 Observe and Pick Up 和 Swap T 上，比较 MaP-WAM、w/o visual plan（仅语言计划）和 w/o visual memory（用当前观测条件的世界模型替代 CWM）。结果证明记忆锚定视觉规划对保留精细历史证据至关重要。
- **进度建模消融**：在 Blocks Ranking Try、Cover Blocks、Press Button 三个任务上，比较 classification
