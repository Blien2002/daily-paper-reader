## 摘要
基础视觉语言模型（VLM）展现出关于世界的广泛智能，但将这种智能转化为机器人控制仍具挑战性。我们提出 Show-Harness，这是一种具身操控框架，通过一个连接意图与动作的紧凑语义接口，使 VLM 能够“操控”机器人。Show-Harness 暴露了离散的语义动作单元，VLM 可以自然地对其进行推理，而具体机器人本体相关的解释器则确定性地将这些语义动作单元落实为局部机器人动作，使 VLM 直接负责细粒度的物理决策。通过同一接口，Show-Harness 证明了以下两点的可行性：（1）直接解锁闭源前沿 VLM，实现零样本机器人控制；（2）仅用少量 GPU 小时的微调即可适配小规模开源 VLM，用于低成本部署。我们进一步开发了 GUMI（GUI 操控接口），将相同的语义动作空间扩展到基于 GUI 的演示采集，使人类和智能体无需专用遥操作硬件即可跨不同机器人本体“操控”机器人。大量实验表明，配备 Show-Harness 的 VLM 智能体能在任务、机器人本体和环境之间稳健泛化，性能优于代表性的智能体范式和 VLA 范式。这些结果表明，合适的接口可以释放基础 VLM 中可观的具身能力，而无需增加模型容量或进行昂贵的针对具体机器人本体的预训练。

## Abstract
Foundation vision-language models (VLMs) exhibit broad intelligence about the world, yet translating this intelligence into robot control remains challenging. We present Show-Harness, an Embodied Harness that enables VLMs to "play" robots through a compact semantic interface linking intent to action. Show-Harness exposes discrete semantic action units that VLMs can naturally reason over, while embodiment-specific interpreters deterministically ground them into local robot actions, keeping the VLM directly responsible for fine-grained physical decisions. Through the same interface, Show-Harness demonstrates the feasibility of (1) directly unlocking closed-source frontier VLMs for zero-shot robot control, and (2) adapting small-scale open-source VLMs for low-cost deployment with just a few GPU-hours of fine-tuning. We further develop GUMI (GUI Manipulation Interface), which extends the same semantic action space to GUI-based demonstration collection, allowing humans and agents to "play" robots across embodiments without specialized teleoperation hardware. Extensive experiments show that Show-Harness-equipped VLM agents generalize robustly across tasks, embodiments, and environments, outperforming representative agentic and VLA paradigms. These results suggest that the right interface can unlock substantial embodied capability from foundation VLMs, without requiring additional model capacity or costly embodiment-specific pretraining.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：基础视觉–语言模型（VLM）已经具备广泛的世界知识，包括物体识别、空间关系理解和长程任务分解能力，但将这些“数字智能”转化为机器人物理操作仍十分困难。
- **现有方法的不足**：
  - **VLA（视觉–语言–动作）模型**：将 VLM 直接微调为输出机器人本体相关的连续动作。优点是端到端控制，但会破坏 VLM 原有的语义知识，形成不透明的“像素到执行器”映射；且每当任务、环境或本体改变时，通常需要重新采集机器人轨迹并重新训练。
  - **层级式 / 程序化系统**：让 VLM 只输出高层抽象（如子任务调用、控制 API 程序），由下游控制器执行物理动作。优点是保留语义，但物理控制被外部系统中介，VLM 与细粒度物理执行之间的直接联系被削弱。
- **本文核心思想**：机器人控制需要一个 **合适的语义接口**——动作空间既对 VLM 语义上有意义，又足够细粒度以直接控制物理运动。Show-Harness 通过紧凑的离散语义动作单元和确定性解释器，让 VLM 直接负责每一步的物理决策，从而释放基础模型的具身能力，无需额外模型容量或昂贵的本体特定预训练。

## 2. 论文提出的方法论

### 2.1 整体框架

Show-Harness 将 VLM 置于一个“感知–推理–行动–反馈”的闭环中。每个交互步，模型接收多视角图像和本体感受信息，推理下一步动作，输出一个离散语义动作单元；该单元由本体相关解释器确定性转化为机器人运动；执行后产生新观测，再回馈给模型。

- **核心公式（文字描述）**：
  - 当前观测 \(o_t = (I_t, p_t)\)，其中 \(I_t\) 为多视角视觉，\(p_t\) 为本体感受状态。
  - 通过一组可配置的推理插件 \(\Phi_P\) 处理观测和历史，得到推理增强上下文 \(c_t\)。
  - VLM 以 \(c_t\) 为条件选择一个语义动作 \(a_t \in \mathcal{A}\)。
  - 本体相关解释器 \(g_E\) 将 \(a_t\) 确定性映射为机器人控制指令：  
    \[
    s_{t+1} = \Pi_E\big(x_t + \sigma_t R_E d_a,\ \exp(\theta_t [R_E r_a]_\times) Q_t\big)
    \]
    其中 \(x_t\) 和 \(Q_t\) 分别为末端执行器的位置和姿态；\(d_a\) 和 \(r_a\) 编码平移与旋转方向；\(\sigma_t\) 和 \(\theta_t\) 为标定步长；\(R_E\) 将语义方向映射到具体本体的运动坐标系；\(\Pi_E\) 施加工作空间和单步限制。
  - 夹爪动作直接映射为开合指令。

### 2.2 语义动作空间

- **动作词汇**：
  - 平移：`MV_FWD` / `MV_BACK`、`MV_LEFT` / `MV_RIGHT`、`MV_UP` / `MV_DOWN`，每个动作移动一步。
  - 旋转：`ROTATE_CW` / `ROTATE_CCW`，并指定旋转轴（x、y、z）。
  - 夹爪：`GRASP` / `RELEASE`。
  - 结束：`DONE`。
- **设计特性**：
  1. **增量性**：每个动作引起小范围局部变化，使 VLM 可通过连续观察来修正行为。
  2. **可解释且本体无关**：动作是语义符号而非数值目标，低层控制由解释器处理，模型接口跨机器人复用。
  3. **视觉落地**：运动方向相对于当前观测视图定义，便于空间推理直接映射为动作。

### 2.3 本体接地与解释器

- 不同机器人通过不同的低层控制器实现相同的语义单元，例如 Franka 使用阻抗控制跟踪笛卡尔位姿，AgileX 使用逆运动学和关节目标，模拟器执行相应的工作空间命令。
- 安全工作空间和桌面高度等限制在解释器中配置，违规动作在执行前被阻止。
- 适配新本体只需更换解释器，无需重新训练 VLM 或改变语义接口。

### 2.4 具身 Harness 架构

- **感知插件**：
  - **多视图指导**：告诉 VLM 不同相机视角的用途（全局场景理解 vs. 腕部特写精细对齐）。
  - **本体感受**：将机器人状态（夹爪高度、单步位移、接触状态、夹爪开合）转为文本反馈。
- **推理插件**：
  - **子任务规划**：先将任务分解为有序子任务及可视觉验证的完成条件，执行中逐步推进。
  - **情境规划**：对不确定分支延迟决策，待观测信息充足后再选择分支，避免每步重新规划。
  - **动作分块**：当目标较远时，允许 VLM 一次输出多个连续动作开环执行，减少模型查询频率。
  - **自适应步长**：根据目标是否在腕部视野内切换 2 cm 精细步长和 4 cm 粗略步长。
  - **视觉提示**：当口头目标难以在语言中指定时，生成视觉标记突出目标交互区域。
- **行动插件**：
  - **动作历史**：保留最近动作，提供短期记忆并抑制来回振荡。
  - **失败恢复**：自动检测空抓取，重置夹爪状态并回退到相关抓取子任务。

### 2.5 两种控制模式

- **零样本模式（ZS）**：前沿闭源 VLM（默认 Gemini-3.1 Pro）直接使用 harness 控制机器人，无需微调。
- **微调模式（FT）**：小型开源 VLM（默认 Qwen3.5-2B）通过 LoRA 微调学习预测语义动作单元。损失函数为语义动作 token 的交叉熵：
  \[
  L(\theta) = -\sum_{(\ell, o, h, a)\in D} \log \pi_\theta\big(a \mid \Phi_{P_\text{min}}(\ell, o, h)\big)
  \]
  其中 \(P_\text{min}\) 仅保留任务指令、多视角观测和短动作历史，便于受控比较。**不需要专用动作头或特殊 token**，只用 VLM 原生词汇输出语义动作。

### 2.6 GUMI：GUI 操作接口

- 利用离散语义动作空间可直接通过图形界面操作，开发 GUMI。
- 每个语义单元对应一个带标签的控件和键盘按键。
- 人类可通过键盘操作机器人，计算机使用智能体可操作同一 GUI，VLM 智能体可直接预测动作。
- 每一步记录动作前的观测和所选语义动作，形成策略训练对 \((o_t, a_t)\)。
- 同一解释器还可记录对应的低层轨迹，使一条演示同时可训练语义动作策略和连续控制策略。
- 支持单臂/双臂、分步/连续动作块、人机混合收集，无需专用遥操作硬件，且演示可跨本体复用。
