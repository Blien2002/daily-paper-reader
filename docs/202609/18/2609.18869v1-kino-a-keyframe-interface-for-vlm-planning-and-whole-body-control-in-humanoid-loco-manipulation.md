## 摘要
人形机器人移动操作要求机器人在执行协调的全身运动时，解释任务指令和场景语义。我们提出一种分层框架，使用运动关键帧作为视觉语言模型（VLM）规划与强化学习（RL）控制之间的中间表示。每个关键帧指定一个目标全身机器人姿态，并在适用时指定物体姿态。给定语言指令、场景观测和执行反馈，VLM从预定义库中选择连续的任务相关关键帧。所选关键帧被重定向到当前场景，以考虑物体姿态和尺寸。然后，关键帧条件化的全身策略生成关节级动作以达到这些目标。我们引入一种基于显著性的关键帧采样策略，用于低层策略训练，在使用稀疏VLM关键帧时，将端到端任务成功率从44%提高到92%。我们在仿真中和Unitree G1人形机器人上评估了我们的框架，执行物体拾取、运输和放置任务。该系统成功执行单手和双手操作，并泛化到训练参考数据之外的放置位置。

## Abstract
Humanoid loco-manipulation requires robots to interpret task instructions and scene semantics while executing coordinated whole-body motions. We propose a hierarchical framework that uses motion keyframes as an intermediate representation between Vision-Language Model (VLM) planning and Reinforcement Learning (RL) control. Each keyframe specifies a target whole-body robot pose and, when applicable, an object pose. Given a language instruction, scene observations, and execution feedback, the VLM selects successive task-relevant keyframes from a predefined library. The selected keyframes are retargeted to the current scene to account for object poses and dimensions. A keyframe-conditioned whole-body policy then generates joint-level actions to reach these goals. We introduce a saliency-based keyframe sampling strategy for low-level policy training that improves end-to-end task success rate from 44% to 92% when using sparse VLM keyframes. We evaluate our framework on object pickup, transport, and placement tasks in simulation and on a Unitree G1 humanoid. The system successfully performs both one- and two-handed manipulation and generalises to placement locations beyond the training reference data.

## 1. 论文的核心问题与整体含义

- **研究动机**：人形机器人在真实环境中的移动操作（loco-manipulation）需要同时完成高层任务语义理解与低层全身运动控制。现有方法通常将两者割裂：视觉语言模型（VLM）擅长语义推理，但难以直接输出高维、高频的关节控制；强化学习（RL）能实现鲁棒的低层控制，但难以扩展到需要长期规划与多技能切换的任务。
- **核心问题**：如何在 VLM 高层规划与 RL 低层控制之间建立高效、可解释的接口，使机器人能够根据语言指令和场景观测自主完成拾取、运输、放置等长程任务。
- **整体含义**：论文提出以**运动关键帧**作为中间表示，由 VLM 选择任务相关关键帧，再通过关键帧条件化的 RL 策略执行全身动作。该框架解耦了语义推理与运动控制，避免了为 VLA 模型收集大规模机器人专用数据，同时保持了低层策略的鲁棒性与泛化能力。

## 2. 论文提出的方法论

### 2.1 总体框架
- 系统由四部分组成：**VLM 规划器**（高层决策）、**关键帧库**（预定义姿态集）、**场景对齐模块**（重定向与路径规划）、**关键帧条件化 RL 策略**（低层控制）。
- 运行流程：用户给出语言指令 → VLM 结合场景图像和机器人上下文从关键帧库中选择下一关键帧 → 关键帧根据当前物体姿态和尺寸进行重定向 → 重定向后的关键帧作为目标传递给 RL 策略 → 策略生成关节动作驱动机器人 → 机器人静止后再次查询 VLM，循环直至任务完成。

### 2.2 关键帧条件化策略
- 将低层运动执行建模为目标条件 RL 问题。策略输入包括：机器人自身状态（局部线速度、角速度、重力向量、关节位置/速度）、物体状态（局部位置和四元数）、上一动作、以及目标关键帧 `K_t`（目标根位置/朝向、目标关节角、目标物体位姿）。
- 使用**不对称 actor-critic**：actor 仅依赖真实可观测信息；critic 额外获得参考运动状态、目标误差、剩余时间等特权信息，以提升训练稳定性。
- 训练使用 PPO，奖励分为三组：参考轨迹跟踪、关键帧目标到达、正则化（惩罚力矩、动作速率、关节加速度、足部滑动）。为避免不同奖励相互干扰，采用**多 critic 结构**分别估计三组价值函数。
- 动作空间为 29 维目标关节位置，由 PD 控制器跟踪。训练中引入域随机化（摩擦、质量、执行器增益、观测噪声、外部推力等）以缩小 sim-to-real 差距。

### 2.3 显著性关键帧采样
- 训练低层策略时需要从参考运动序列中采样关键帧作为目标。均匀随机采样会过度表示行走等中间帧，而忽视拾取、放置等任务关键阶段。
- 提出**基于显著性的采样方法**：
  - 计算身体关键点加速度的聚合信号 `Γ(t)`，通过低通滤波后取局部最大值，得到初步关键帧候选 `P_Γ`。
  - 对候选帧，估计左右腿的周期性相似度，滤除由正常行走引起的周期性腿部运动关键帧。
  - 利用物体垂直加速度峰值识别物体事件（如抓取、释放），将机器人候选帧与物体事件对齐，并补充遗漏的物体事件关键帧。
  - 最终显著关键帧集为 `{1, T} ∪ P_r ∪ P_new`，其中包含起始帧、结束帧和任务阶段转换帧。
- 该方法确保了训练关键帧分布与 VLM 在推理时选择的关键帧分布接近。

### 2.4 场景对齐与路径规划
- **关键帧重定向**：从库中选择的通用关键帧需要适配实际物体的位置、朝向和尺寸。采用基于物体包围盒的仿射变换（公式 8），将源物体坐标系下的末端执行器和根位置映射到目标物体坐标系，之后用阻尼最小二乘逆运动学求解完整机器人配置，同时约束脚部保持在接地高度。
- **路径规划**：在初始位置与目标位置之间生成中间关键帧序列。使用切线对齐圆弧或 Dubins 路径，限制曲率（最小转弯半径约 0.33 m），贪婪选择中间目标，确保累积航向变化不超过 45°、位移不超过 2 m，以避免训练中未出现的急转弯。

### 2.5 VLM 规划器
- VLM 的输入包括：自然语言任务指令、第三视角场景图像、结构化规划上下文（上一关键帧、是否成功、当前机器人/物体/目标物体位姿、控制器误差）。
- VLM 输出严格约束为 JSON 格式，例如 `{"keyframe": "crouch_to_pick_box", "object_to_manipulate": true, "task_complete": false}`，直接兼容下游模块。
- 采用**事件驱动闭环执行**：仅当机器人和物体均静止且上一目标执行完成后才向 VLM 发起新查询，避免在执行中打断低层策略。VLM 可通过上下文判断失败并重试或选择恢复关键帧。

## 7. 优点

- **接口设计优雅**：关键帧作为语义与运动之间的紧凑表示，避免了 VLA 对大规模机器人数据的依赖，同时比完整参考轨迹更易由 VLM 生成。
- **显著性采样策略**：针对移动操作任务阶段特性，提出基于加速度和物体事件的采样方法，有效提升稀疏目标下的训练效率，且不增加推理成本。
- **场景对齐机制**：关键帧重定向和路径规划使系统能适配不同物体位姿/尺寸和远距离放置目标，增强了泛化能力。
- **闭环 VLM 规划**：事件驱动查询 + 失败恢复，使系统能自主判断任务进度并应对执行失败。
- **硬件验证**：在真实人形机器人上成功部署，证明了 sim-to-real 转移的有效性。
