## 摘要
基于扩散的视觉-语言-动作（VLA）模型在具身任务中表现出色，但其迭代采样带来高昂的计算和内存访问成本，阻碍了在边缘平台上的实时部署。现有加速方法要么需要昂贵的训练（如蒸馏、流匹配），要么通过静态调度的剪枝和缓存降低感知质量，忽视了机器人交互中动态工作负载的变化。本文提出 FASA（Feedback-Aware Sampling Adaptation，反馈感知采样自适应），一种无需训练的运行时框架，将实时多模态反馈作为去噪管线的控制信号：交互驱动的范围适配器根据视觉和夹爪力反馈调节全局采样步数预算，本体感知的步骤适配器在自适应范围内精确定位优化步数。这一协同设计框架使底层硬件架构能够自适应匹配不同执行阶段的工作负载需求。在多个基准上的对比评估表明，推理速度最多可提升 1.45 倍，同时保持有竞争力的成功率，为将重型生成式具身 AI 工作负载部署到资源受限的计算平台提供了一种新的动态运行时架构范式。

## Abstract
Diffusion-based Vision-Language-Action (VLA) models achieve strong performance in embodied tasks, but their iterative sampling imposes heavy computational and memory-access cost, blocking real-time deployment on edge platforms. Existing acceleration methods either require expensive training (e.g., distillation, flow matching) or degrade perception via statically scheduled pruning and caching, ignoring the dynamic workload variance of robotic interactions. This paper presents FASA (Feedback-Aware Sampling Adaptation), a training-free runtime framework that treats real-time multimodal feedback as a control signal for the denoising pipeline: an interaction-driven range adaptor modulates the global sampling-step budget based on visual and gripper-force feedback, and a proprioception-aware step adaptor pinpoints the optimized step within the adapted range. This co-designed framework allows the underlying hardware architecture to adaptively match the workload demands of different execution phases. Comparative evaluations across several benchmarks show that the inference speed can be increased by up to 1.45$\times$ while maintaining competitive success rates, providing a novel dynamic runtime architecture paradigm for deploying heavy generative embodied AI workloads onto resource-constrained computing platforms.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

FASA 的核心思想是**用反馈信号替代固定的去噪步数**，将标准扩散策略中每个执行步的固定 K 步去噪循环，替换为反馈条件化的动态调度。整个框架由两个协同模块组成：

### 2.1 交互驱动的采样范围适配器（Interaction-Driven Sampling Range Adaptation）

- **目标**：根据视觉与夹爪力的实时变化，动态调整全局采样步数范围 `[s_min, s_max]`。
- **关键计算**：
  - 定义力变化分数：`δ_force = -cos(F_t, F_{t-1})`，其中 `F_t` 为当前夹爪力，余弦距离越小表示变化越大。
  - 定义视觉变化分数：`δ_vision = -cos(f_v,t, f_v,t-1)`，其中 `f_v,t` 由 VLA 模型本身的视觉编码器提取，保证反馈与策略表示对齐。
  - 融合为调制因子：`α_t = 0.5·δ_vision + 0.5·δ_force + β`，其中偏置 `β = 1.5` 起线性整流作用，保证稳定阶段调制因子仍为正（最小约 0.5），避免生成崩溃。
- **范围更新规则**：
  - `s_t_min = s_{t-1}_min · α_t`，`s_t_max = s_{t-1}_max · α_t`。
  - 初始满足 `s_0_max = 2·s_0_min`。
  - 实现中对更新后的边界进行指数移动平均平滑并裁剪到有效区间，防止剧烈振荡。
- **效果**：当机器人处于稳定、准静态阶段时，`α_t < 1` 压缩采样步数范围；当交互动态变化时，`α_t > 1` 扩大算力预算。

### 2.2 本体感知的采样步适配器（Proprioception-Aware Sampling Step Adaptation）

- **目标**：在已调整的范围内，根据关节运动状态确定当前执行步应实际采用的最优采样步数。
- **关键计算**：
  - 定义运动学活动度量：`MotionIndex_t = ||q˙_t|| + ||q_t - q_{t-1}||`，其中 `q˙_t` 为瞬时关节速度，`q_t - q_{t-1}` 为实际位置位移。二者来自策略主干已使用的归一化本体感觉状态，因此无量纲且可直接相加。
  - 高 MotionIndex 表示高动态阶段，需要更细的时间分辨率（更多采样步）。
- **步数选择**：
  - 通过非线性门控映射：`s_t_opt = s_t_min + (s_t_max - s_t_min) · σ(MotionIndex_t)`，其中 `σ(·)` 为 sigmoid 函数。
- **协同机制**：范围适配器决定全局预算，步适配器在该预算内进行局部精细调节，共同实现闭环动态计算调度。

### 2.3 框架特性

- **免训练**：不修改模型权重，无需额外训练或蒸馏。
- **轻量级**：每步额外开销仅为一次视觉编码器调用、两次余弦相似度计算和 MotionIndex 范数计算。
- **硬件无关**：模块拦截策略推理循环，本体感觉信号通过标准物理引擎 API 或机器人控制接口即可获取。

## 6. 论文的主要结论与发现

- **性能提升**：FASA 在多个基准上实现最高 **1.45×** 推理加速，同时保持或提高任务成功率：
  - RLBench：平均成功率从 75.96% 提升至 77.48%，加速 **1.40×**。
  - ManiSkill3：DP 成功率从 70.28% 提升至 76.39%，加速 **1.45×**；RDT 从 86.11% 提升至 87.50%，加速 **1.23×**。
  - LIBERO：成功率从 93.0% 提升至 93.5%，加速 **1.23×**，平均去噪步数从 32 降至 19.79。

- **消融实验发现**：仅使用采样范围适配器（无步适配器）虽然能压缩整体计算预算，但在高动态阶段可能因预算不足导致成功率下降；仅使用步适配器（无范围适配器）能在局部根据运动状态调节步数，但缺少全局预算约束，加速效果有限。完整 FASA 通过范围适配器与步适配器的协同，在保持成功率的同时获得最高加速比，验证了两个模块的互补性。
- **动态调度行为可视化**：在 RLBench 的接触丰富任务中，采样步数随执行阶段呈现明显的自适应变化：在自由运动或粗接近阶段，步数显著下降；在抓取、插入等力/视觉变化剧烈的阶段，步数自动上升。这表明 FASA 能够准确识别精度关键阶段，将计算资源集中于最需要的时刻。
- **主要结论**：FASA 证明了实时多模态反馈（视觉、夹爪力、本体感觉）可以作为扩散去噪步数的有效控制信号，在不修改模型权重、不增加训练成本的前提下实现免训练、低开销的动态推理加速。该框架为资源受限的边缘机器人平台部署重型生成式具身 AI 提供了一种新的运行时调度范式。
- **研究意义与展望**：FASA 的提出不仅缓解了扩散 VLA 的实时推理瓶颈，还为后续研究提供了利用任务执行中的动态反馈进行自适应计算分配的新思路。未来方向包括扩展到更多反馈模态（如力矩、触觉阵列）、与量化/剪枝等模型压缩方法结合、以及在真实机器人上进行长期部署验证；同时，与 EfficientVLA、VLA-Cache、DeeR-VLA 等现有免训练加速方法的直接对比也值得进一步补充。
