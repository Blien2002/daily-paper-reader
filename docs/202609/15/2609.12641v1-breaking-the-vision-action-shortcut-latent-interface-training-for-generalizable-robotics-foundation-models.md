## 摘要
机器人基础模型在分布内表现强劲，但在视觉分布偏移下往往性能下降。在学习从预训练视觉表示生成动作时，模型可能会利用与训练分布内演示动作相关的任务无关视觉线索。当这些相关性在分布偏移下发生变化时，此类视觉-动作捷径可能损害泛化能力。缓解这些捷径需要约束视觉信息用于动作生成的方式，同时保留任务相关的空间信息。我们提出潜在接口训练（LIT），一种与框架无关的两阶段策略：首先在没有图像的情况下建立以空间目标为条件的动作先验，然后通过姿态监督的潜在接口约束视觉条件。第一阶段训练动作专家在语言、机器人状态以及每个演示片段的末端SE(3)执行器姿态条件下生成动作块，学习独立于视觉线索的目标导向动作生成。第二阶段引入一个潜在接口，聚合视觉和语义表示，并作为预训练动作专家唯一的视觉条件通路。该接口通过监督重建先前用于第一阶段条件的末端姿态，促使其保留动作生成所需的目标相关空间信息。在四种视觉-语言-动作和世界-动作架构（Pi0.5、MolmoAct2、FAST-WAM和ImageWAM）上，LIT将LIBERO-Plus总体成功率提高了3.87至10.70个百分点，同时保持或提高了LIBERO平均成功率。真实世界评估显示，在未见过的相机配置、光照变化和干扰物条件下，三项任务汇总成功率提高了13.30至16.70个百分点。

## Abstract
Robot foundation models achieve strong in-distribution performance but often degrade under visual distribution shifts. When learning to generate actions from pretrained visual representations, models may exploit task-irrelevant visual cues that correlate with demonstrated actions within the training distribution. Such vision-action shortcuts can undermine generalization when these correlations change under distribution shifts. Mitigating these shortcuts requires constraining how visual information is used for action generation while preserving task-relevant spatial information. We propose Latent Interface Training (LIT), a framework-agnostic two-stage strategy that first establishes a spatial-goal-conditioned action prior without images, then constrains visual conditioning through a pose-supervised latent interface. Stage 1 trains the action expert to generate action chunks conditioned on language, robot state, and each demonstrated chunk's terminal SE(3) end-effector pose, learning goal-directed action generation independently of visual cues. Stage 2 introduces a latent interface that aggregates visual and semantic representations and serves as the pretrained action expert's only visual conditioning pathway. The interface is supervised to reconstruct the terminal pose previously used to condition Stage 1, encouraging it to retain the goal-relevant spatial information needed for action generation. Across four vision-language-action and world-action architectures (Pi0.5, MolmoAct2, FAST-WAM, and ImageWAM), LIT improves overall LIBERO-Plus success by 3.87-10.70 percentage points while preserving or improving average LIBERO success. Real-world evaluations show 13.30-16.70 percentage-point gains in success aggregated across three tasks under unseen camera configurations, lighting variations, and distractors.

- **核心问题**：机器人基础模型（如 VLA 和 WAM）在训练分布内表现优异，但在视觉分布偏移（如相机视角、光照、背景纹理、传感器噪声等变化）下性能显著下降。  
- **根本原因**：模型在学习从预训练视觉表示生成动作时，可能利用与演示动作存在相关性的**任务无关视觉线索**，形成**视觉–动作捷径**。当分布偏移导致这些相关性失效时，模型泛化能力明显受损。  
- **研究意义**：如何在不牺牲任务相关空间信息的前提下，约束视觉信息的使用方式，从而缓解捷径学习、提高模型对视觉扰动的鲁棒性，是机器人基础模型泛化研究中的关键挑战。  
- **整体含义**：论文提出 **Latent Interface Training (LIT)**，通过两阶段训练构建一种“动作先验 + 姿态监督视觉接口”的范式，使视觉条件仅通过一个可监督的潜在接口进入动作专家，从而减少对无关视觉线索的依赖，同时保留目标引导所需的空间信息。

## 2. 论文提出的方法论

LIT 是一种**框架无关（framework-agnostic）** 的两阶段训练策略，适用于具有“预训练骨干 + 动作专家”结构的 VLA 与 WAM 架构。

### 2.1 第一阶段：空间目标条件动作先验（无图像）

- **目标**：在不使用图像输入的情况下，训练动作专家学会根据语言、机器人状态和**末端 SE(3) 姿态目标**生成动作块，建立目标导向的动作先验。  
- **目标定义**：对每个演示动作块，取其终端机器人状态作为目标 \(g_t = [p_{t+H}; r_{t+H}; q_{t+H}] \in \mathbb{R}^8\)，其中 \(p\) 为世界坐标系末端位置，\(r\) 为轴角姿态，\(q\) 为夹爪关节位置。  
- **实现方式**：
  - 冻结预训练骨干，仅输入语言指令 \(l\) 和机器人状态 \(s_t\)，得到每层语义表示 \(H^\text{sem}_{\ell,t}\)。
  - 用可训练三层 MLP 将目标姿态 \(g_t\) 编码为**目标 token** \(G_t\)。
  - 将目标 token 与骨干表示拼接：\(C_{\ell,t} = [H^\text{sem}_{\ell,t}; G_t]\)，并通过各架构原生的条件机制输入对应层的动作专家。
  - 训练目标为原生动作生成损失，例如 Flow Matching 损失：
    \[
    L_{\text{prior}} = \mathbb{E}_{A_t, \tau, \epsilon} \left[ \| \hat{v}^\tau_t - v^\star_t \|^2_2 \right],
    \]
    其中 \(\hat{v}^\tau_t = v_\theta(\tilde{A}^\tau_t, \tau; C_{1:L,t})\)，\(v^\star_t = A_t - \epsilon\)。  
  - 仅更新动作专家参数和 SE(3) 编码器参数，骨干保持冻结。

### 2.2 第二阶段：视觉–动作接口学习

- **目标**：将第一阶段训练好的动作专家作为初始化，引入一个**姿态监督的潜在接口**，作为动作专家唯一的视觉条件通路。  
- **潜在令牌更新机制**：
  - 定义可学习潜在令牌 \(Z_0 \in \mathbb{R}^{K \times d}\)（\(K=100\)），对每个输入从 \(Z_{0,t}=Z_0\) 开始。
  - 在骨干的每个耦合层 \(\ell\) 上，依次执行：
    - 自注意力：\(Z_{\ell,t} = Z_{\ell-1,t} + \text{SA}_{q(\ell)}(Z_{\ell-1,t})\)；
    - 语义交叉注意力：\(\tilde{Z}_{\ell,t} = Z_{\ell,t} + \text{CA}^\text{sem}_{q(\ell)}(Z_{\ell,t}; H^\text{sem}_{\ell,t})\)；
    - 视觉交叉注意力：\(Z_{\ell,t} = \tilde{Z}_{\ell,t} + \text{CA}^\text{vis}_{q(\ell)}(\tilde{Z}_{\ell,t}; H^\text{vis}_{\ell,t})\)。
  - 其中 \(q(\ell) = \lceil \ell/m \rceil\) 表示每隔 \(m\) 层共享接口注意力参数。
- **条件动作专家**：更新后的潜在令牌 \(Z_{1:L,t}\) 通过各架构原生机制条件动作专家，动作损失 \(L_{\text{act}}\) 与第一阶段形式一致但条件变为 \(Z_{1:L,t}\)。  
- **姿态重建监督**：
  - 从最终潜在令牌 \(Z_{L,t}\) 通过 MLP 解码器重建第一阶段使用的终端姿态：
    \[
    \hat{g}_t = D_\omega(Z_{L,t}), \quad L_{\text{pose}} = \|\hat{g}_t - g_t\|^2_2.
    \]
  - 总损失：\(L_{\text{stage2}} = L_{\text{act}} + \lambda_{\text{pose}} L_{\text{pose}}\)，其中 \(\lambda_{\text{pose}}=0.3\)。  
- **第二阶段联合优化**：骨干及其模态编码器、动作专家、潜在令牌与接口注意力模块、MLP 解码器均参与训练。

### 2.3 推理过程

- 推理时，仅保留潜在接口，移除去第一阶段姿态编码器和第二阶段姿态解码器。  
- 策略输入仅为视觉观测、语言指令和机器人状态，动作采样与执行遵循各框架原生流程。

## 3. 实验设计

### 3.1 基准与数据集

- **LIBERO**：40 个任务，涵盖 Spatial、Object、Goal、Long 四个子集；每个任务 50 次 rollout，共 2000 个 episode，用于评估分布内性能。  
- **LIBERO-Plus**：7 种任务保持型扰动（相机视角、传感器噪声、机器人初始状态、语言指令、物体布局、光照条件、背景纹理），共 10,030 个扰动实例；每个实例 1 次 rollout。所有模型仅在原始 LIBERO 演示上训练，不进行适应。  
- **真实世界任务**：3 个操作任务——Keep LEGOs（拆下所有积木放入盒子）、Wipe trash（用簸箕清洁桌面）、Transfer egg（将鸡蛋从平底锅转移到碗中）。每个任务 100 条演示，共 300 条，训练单个多任务策略。在 ID 设置和三种 OOD 视觉条件（光照变化、相机配置变化、干扰物）下评估，每任务 ID 25 次、每任务 OOD 10 次 rollout。

### 3.2 模型与基线

- **四种架构**：  
  - π0.5（VLA，Mixture-of-Transformers 共享自注意力）；  
  - MolmoAct2（VLA，逐层交叉注意力到 VLM 的 KV 缓存）；  
  - FAST-WAM（WAM，训练时未来视频预测，推理仅动作）；  
  - ImageWAM（WAM，推理时保留图像编辑去噪并条件动作专家）。  
- **对比方式**：每个架构的 **LIT 变体** 与 **架构匹配的 baseline**（相同预训练骨干、随机初始化动作专家、相同数据与训练预算）进行对比。  
- **消融与替代设计**：  
  - LIT w/o Stage 1（去掉第一阶段）；  
  - LIT w/o pose supervision（去掉第二阶段姿态重建损失）；  
  - LIT w/ direct visual access（动作专家可直接访问视觉表示）；  
  - LIT w/o Stage 1 & pose supervision（仅潜在令牌聚合）；  
  - LA4VLA-inspired staged training（两阶段训练但第二阶段直接条件视觉表示）；  
  - Baseline w/ pose supervision（在 baseline 上加姿态监督，但不改变视觉条件架构）。

## 6. 论文的主要结论与发现

- **跨架构泛化能力提升**：LIT 在四个 VLA/WAM 架构上均提高了 LIBERO-Plus 总体成功率，增益为 3.87–10.70 个百分点；同时保持或提高了 LIBERO 平均成功率，未出现平均性能下降。  
- **扰动维度效果显著**：在相机视角、传感器噪声、物体布局等扰动下提升尤为明显，例如 π0.5 在 Camera Viewpoints 提升 22.01 个百分点，FAST-WAM 提升 27.43 个百分点。  
- **真实世界有效**：在 MolmoAct2 上，LIT 汇总 ID 成功率从 74.7% 提高到 88.0%，在三种 OOD 条件下分别提升 13.3–16.7 个百分点。  
- **行为机制证据**：  
  - 注意力可视化显示 LIT 对任务相关机器人–物体区域的注意力在扰动下更稳定；  
  - 反事实干预表明 LIT 对任务无关视觉变化更鲁棒，同时对目标指令变化更敏感——与减少视觉–动作捷径一致。  
- **组件重要性**：消融显示 Stage 1 动作先验、姿态监督和受限视觉通路三者均有正向贡献；仅做潜在令牌聚合、两阶段训练或姿态监督均不能完全解释 LIT 的增益。

## 7. 优点

- **框架无关性**：可适配 VLA（自注意力、交叉注意力两种耦合方式）和 WAM（训练时或推理时世界模型）等不同架构，扩展性强。  
- **两阶段设计清晰**：先解耦动作先验学习（无视觉），再引入可监督的视觉接口，逻辑明确、易于实现。  
- **显式空间目标监督**：使用 SE(3) 末端姿态作为连接两个阶段的桥梁，为视觉接口保留了任务所需的空间信息，避免盲目压缩。  
- **实验扎实**：覆盖四个异构模型、仿真+真实世界、多类扰动，消融和反事实分析提供了较完整的证据链。  
- **训练公平**：LIT 与 baseline 的总训练预算一致，排除了“训练更多所以更好”的常见混杂因素。
