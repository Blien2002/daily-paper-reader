## 摘要
视觉目标与动力学预测可为语言条件的机器人策略提供目标结果和动作相关场景变化的表示。我们通过共享轨迹模型将这些预测引入动作生成与选择。Dynin-Robotics 在 Dynin-Omni 上实现该框架，Dynin-Omni 是一种全模态掩码扩散主干，将语言、视觉观测、目标和动作表示为离散 token。通过改变条件与目标范围，同一模型学习动作预测、以动作为条件的下一观测预测、终端目标状态预测以及轨迹到指令重建。这些接口通过目标预测、候选动作评估以及动作与未来状态预测的联合细化支持测试时扩展。我们在来自 48 个 Open X-Embodiment 数据集的约 133 万条轨迹上持续预训练模型，并将其分别适配到下游领域。在两个 VLABench 任务上，机器人预训练在固定第二阶段步骤预算内改善了适配效果，并且在相同耦合解码器下，完整目标混合相比于仅策略后训练提高了偏移指令成功率。将目标引导与动作-下一状态联合去噪相结合，相比仅动作解码进一步提高了偏移指令成功率；其收益取决于预测的组合方式。Dynin-Robotics 在 LIBERO 和零样本 LIBERO-Plus 上取得了有竞争力的性能，并在 Franka Research 3 机器人上跨四种操作条件实现了 78.4% 的平均成功率。优化的块并行实现在所报告的评测设置下，将模型端动作解码加速最高达 29.2 倍。这些结果支持共享轨迹建模作为学习互补机器人目标并在控制过程中组合其预测的通用接口。

## Abstract
Visual goal and dynamics prediction can provide language-conditioned robot policies with both a target outcome and a representation of action-dependent scene changes. We bring these predictions into action generation and selection through a shared trajectory model. Dynin-Robotics implements this formulation on Dynin-Omni, an omnimodal masked-diffusion backbone, representing language, visual observations, goals, and actions as discrete tokens. By varying conditioning and target spans, the same model learns action prediction, action-conditioned next-observation prediction, terminal goal-state prediction, and trajectory-to-instruction reconstruction. These interfaces support test-time scaling through goal prediction, action-candidate evaluation, and joint refinement of action and future-state predictions. We continually pretrain the model on approximately 1.33 million trajectories from 48 Open X-Embodiment datasets and adapt it separately to downstream domains. On two VLABench tasks, robot pretraining improves adaptation within a fixed Stage-2 step budget, and the full objective mixture improves shifted-instruction success over Policy-only post-training under the same coupled decoder. Combining goal guidance with joint action-next-state denoising further improves shifted-instruction success over action-only decoding; the benefit depends on how the predictions are composed. Dynin-Robotics achieves competitive performance on LIBERO and zero-shot LIBERO-Plus, together with a 78.4% average success rate across four manipulation conditions on a Franka Research 3 robot. An optimized block-parallel implementation accelerates model-side action decoding by up to 29.2x relative to the base implementation under the reported profiling setup. These results support shared trajectory modeling as a common interface for learning complementary robot objectives and composing their predictions during control.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：语言条件机器人操作需要同时处理目标识别、物体交互和连续控制。现有的视觉-语言-动作（VLA）模型通常将语言理解、视觉预测和动作生成分开，或以不同架构耦合，难以统一利用“目标结果”和“动作相关的场景变化”这两种互补信息。
- **核心问题**：如何设计一个统一的轨迹模型，使语言、视觉、目标和动作能在同一表示中作为条件或预测目标，并在推理时灵活组合多种预测来改善动作生成。
- **整体含义**：该工作提出“共享轨迹建模”作为通用接口，在单一全模态掩码扩散模型上同时学习动作预测、世界建模、目标状态预测和任务理解，并支持测试时通过目标引导、联合去噪、候选重排等方式扩展推理计算，从而连接任务语义与物理执行。


## 2. 论文提出的方法论

- **总体架构**：Dynin-Robotics 基于 Dynin-Omni，一种全模态掩码扩散主干，将文本、图像/视频、语音以及新增的机器人动作 token 统一到共享序列中，使用双向 Transformer 和统一的分类预测头。
- **离散 token 表示**：
  - 视觉观测和生成图像使用共享 MAGViT-v2 tokenizer；语言使用文本 tokenizer；动作使用固定均匀分箱量化（默认 256 bins，Stage-2 任务可选 16/32/64 bins）。
  - 动作 token 按时间主序排列，连续控制值通过鲁棒归一化、均匀分箱映射到保留的 token ID 区间；去噪后再逆映射回连续动作空间。
  - 可选传感器 token 接口：对力/力矩等连续传感器流同样使用均匀分箱量化，支持将来扩展。
- **统一目标训练**：
  - 四个目标：**Policy**（从状态和指令预测动作块）、**World Modeling**（从状态、指令和动作预测下一视觉观测）、**Goal-State Prediction**（从初始状态和指令预测终端目标状态）、**Task Understanding**（从轨迹帧重建任务指令）。
  - 每个目标通过目标 token 指定可见上下文和掩码目标范围；仅对目标范围施加掩码，条件 token 保持可见。
  - 损失函数为目标位置的交叉熵，带逆掩码概率加权和全目标长度归一化；Stage-1 Policy 目标额外增加归一化动作 bin 的 MAE 辅助损失。
- **两阶段训练**：
  - Stage-1：在 48 个 Open X-Embodiment 数据集上持续预训练，共 27.6k optimizer updates（220.8k micro-steps），使用 AdamW，峰值学习率 2e-5，BF16/TF32，梯度累积 8。
  - Stage-2：针对下游域（LIBERO、VLABench、真实世界任务）分别进行 SFT 适配，使用任务特定的动作归一化统计、bin 数量和元数据条件。
  - 另有在线强化学习阶段（仅训练轻量 remasking 控制器，主干冻结），但论文指出该贡献未在消融中隔离。
- **推理组合**：
  - 支持六种模式：仅动作解码、目标引导策略、动作-世界模型联合去噪、世界模型候选重排、目标引导+联合去噪、目标引导+候选重排。
  - 联合去噪时，在同一个复合掩码中同时迭代重建动作 span 和下一视觉状态 span；候选重排时，使用 World Modeling 能量（参考视觉 token 的负对数似然）加上 Policy 先验进行排序，并采用边际改进接受规则。
- **加速**：置信度驱动的块并行解码，将动作 token 按时间步（BL7）或整块（BL35）分组承诺；结合 dInfer 缓存和 CUDA Graph 重放，减少顺序骨干评估次数。

## 6. 论文的主要结论与发现

- **统一轨迹建模有效**：在共享掩码扩散模型上同时学习 Policy、World Modeling、Task Understanding、Goal-State Prediction，可以学习互补的目标并支持灵活推理组合。
- **机器人持续预训练至关重要**：在固定 70k Stage-2 预算下，从 Dynin-Omni 直接适配仅得 3.26% ID / 0.70% OOD，而经过 220.8k micro-step OXE 预训练后达到 49.61% / 47.28%。
- **完整目标混合优于仅策略训练**：加入 World Modeling、Task Understanding 和 Goal-State Prediction 后，OOD 成功率从 33.88% 提升到 47.28%，ID 从 47.15% 提升到 49.61%，ID-OOD 差距从 13.27 降至 2.33 个百分点。
- **推理组合的收益取决于组成方式**：单独的目标引导或联合去噪并未超越仅动作解码，但将目标引导与联合去噪结合（variant e）可将 ID/OOD 提升至 49.6%/47.3%，超过仅动作（45.8%/41.4%）；目标引导+候选重排（variant f）进一步获得最高 OOD 47.7%。
- **性能表现**：LIBERO 宏平均 98.1%，零样本 LIBERO-Plus 宏平均 73.0%，真实 Franka 平台四条件平均 78.4%；块并行解码最高加速 29.2×（BL35），BL7 下成功损失仅 0.1 个百分点。
- **局限性发现**：World Modeling 的 PSNR/SSIM/LPIPS 低于帧复制；Language 扰动下性能保持较好，但 Camera 和 Robot 扰动下下降明显。


## 7. 优点

- **高度统一的表示**：将语言、视觉、动作和目标状态放入同一离散 token 序列，用一个双向 Transformer 完成多方向预测，架构简洁、接口一致。
- **支持测试时扩展**：提出六种推理组合，能灵活分配额外计算到目标预测、联合去噪和候选评估，为控制性能-推理成本权衡提供系统方案。
- **多目标训练设计**：通过目标 token 和可见/掩码范围切换，不改变主干即可同时学习多个互补任务，避免多专家或额外解码器。
- **高效的离散动作表征**：采用固定均匀分箱，无学习 tokenizer，配合块并行解码和上下文缓存，在保持成功率的同时显著降低模型端延迟。
- **较全面的评估**：同时覆盖模拟基准（LIBERO、LIBERO-Plus）、诊断任务（VLABench）、真实机器人、视觉/动作输出质量以及推理效率。
- **消融与分析深入**：预训练、训练目标、推理组合、动作 bin、辅助损失、解码块长等均进行了控制变量分析，结论具有可解释性。


## 8. 不足与局限
