## 摘要
长时程机器人操作需要记忆，但记忆并不一定要内置于动作策略中。为解决此类任务，当前的智能体系统通常将视觉-语言-动作模型（VLA）与规划器和几何工具结合，有时还使用额外的深度或标定几何信息。这些系统混淆了归因：性能提升可能来自更丰富的观测或替代的运动工具，而失败可能源于策略本身或欠明确的语言接口。我们通过一种刻意受限的设计来分离这一问题：减少工具广度，但提高接口带宽。2AM 让一个多模态智能体成为任务记忆的唯一持有者，并让一个基于 RGB、每个回合无状态的单一动作模型成为任务相关运动的唯一执行者。该智能体将交互历史整理为子任务语言以及可选的二维抓取、放置和移动提示，在不同时间尺度上约束其物理意图。为了教会 VLA 这种可引导性，我们用结构化提示标签增强演示，并在条件 dropout、空间噪声和时间抖动下训练，以容忍智能体输出的不完美。在 LIBERO-Mem 上，在没有深度、在线几何或基于规划器的物体运动情况下，2AM 达到 76.3% 的平均完成率，比最强报告基线 14.8% 提高了 61.5 个百分点，同时获得 63.0% 的宽松成功率和 11.8% 的严格成功率。这些结果表明任务记忆可以保留在智能体端。它们进一步表明，动作模型的能力不仅取决于策略学到了什么，还取决于智能体能够多精确地引导它。

## Abstract
Long-horizon robot manipulation requires memory, but not necessarily inside the action policy. To address such tasks, current agentic systems often combine VLAs with planners and geometric tools, sometimes using additional depth or calibrated geometry. These systems confound attribution: gains may come from richer observations or alternative motor tools, while failures may stem from either the policy or an under-specified language interface. We isolate this question through a deliberately constrained design: less tool breadth, but greater interface bandwidth. 2AM makes a multimodal Agent the sole holder of task memory and a single RGB-based, episodically stateless Action Model the sole executor of task-relevant motion. The Agent compiles interaction history into subtask language and optional 2D grasp, place, and move hints that bind its physical intention at different time scales. To teach this steerability to the VLA, we augment demonstrations with structured hint labels and train under condition dropout, spatial noise, and temporal jitter to tolerate imperfect Agent outputs. On LIBERO-Mem, without depth, online geometry, or planner-based object motion, 2AM reaches 76.3% average completion, a 61.5-point improvement over the strongest reported baseline of 14.8%, together with 63.0% relaxed and 11.8% strict success. These results show that task memory can remain Agent-side. They further show that Action Model capability depends not only on what the policy has learned, but on how precisely the Agent can steer it.

## 2. 论文提出的方法论

### 2.1 核心思想

- **2AM（Agent-side memory + Action Model）**：多模态 Agent 是**任务记忆的唯一持有者**；单一、基于 RGB、**每个回合无状态**的动作模型是**任务相关运动的唯一执行者**。
- Agent 将交互历史编译为**子任务语言 + 可选 2D 提示**，在不同时间尺度上绑定物理意图：
  - **语言**：说明当前语义阶段要做什么行为；
  - **q_grasp**：下一个要抓的物体实例，主要在获取前有效；
  - **q_place**：目标放置位置，在搬运过程中保持有效；
  - **q_move**：未来几步有用的末端执行器位置，作为局部方向提示。
- 2D 提示是**指导而非强制轨迹**：动作模型仍负责接近、接触、搬运、释放和避碰。

### 2.2 公式化定义

- Agent 模型：
  \[
  c_k = AM_{\text{agent}}(g, I_a^k, H_k)
  \]
  其中 \(g\) 是任务指令，\(I_a^k\) 是当前全局 RGB 图像，\(H_k\) 是整合后的历史。
- Action Model：
  \[
  \hat a_{t:t+L-1} = AM_{\text{action}}(I_a^t, I_w^t, s_t, c_k)
  \]
  其中 \(I_w^t\) 是腕部 RGB，\(s_t\) 是机器人状态，\(c_k\) 是来自 Agent 的 steering command；动作模型输出一个长度为 \(L\) 的绝对末端执行器动作块。
- 命令组成：
  \[
  c_k = (\ell_k,\; q^{\text{grasp}}_k,\; q^{\text{place}}_k,\; q^{\text{move}}_k)
  \]
  坐标使用当前 Agent 视角图像、原点在左上、取值范围 \([0,1000]^2\)；缺失字段直接省略，而非用特殊点表示。

### 2.3 训练监督的恢复

- **不依赖模型教师**：从演示数据中恢复 steering 标签：
  - 子任务语言来自演示阶段标签；
  - 可见物体框中心归一化坐标作为抓取/放置目标：
    \[
    q = 1000\left(\frac{x+w/2}{W}, \frac{y+h/2}{H}\right)
    \]
  - 投影末端执行器轨迹作为 move 提示：从未来时间窗口 \(\Delta \sim U\{10,\dots,20\}\) 采样：
    \[
    q^{\text{move}}_t = \text{robot\_xy}_{t+\Delta}
    \]
- 特权注释仅用于构造训练目标，部署时不存在。

### 2.4 面向不完美 Agent 输出的鲁棒训练

- **条件 dropout**：在语义可用字段内独立遮蔽语言、抓取、放置、移动提示，但保证命令非空：
  \[
  m_t \preceq v_t,\quad \|m_t\|_0 \ge 1
  \]
- **空间噪声**：对保留的 2D 点加各向同性高斯噪声并裁剪到有效图像范围：
  \[
  \tilde q = \text{clip}_{[0,1000]^2}(q+\epsilon),\quad \epsilon \sim \mathcal N(0,\sigma^2 I_2)
  \]
- **时间抖动**：未来窗口采样使模型不把固定时间偏移当作 move 点定义。
- 这些机制覆盖三类主要接口错误：**遗漏、定位误差、时间不对齐**。
- 实现：动作模型采用 **Qwen3-VL-4B** 骨干和 **flow-matching Action Expert**；预测 16 步动作块；没有单独的抓取、放置或移动控制器。

### 2.5 闭环执行

- 每个动作块执行后，Agent 重新观察全局 RGB、更新历史，并可能修改子任务或提示；
- 不暴露任何基准状态或学习到的完成预言机；模拟器仅在不再有下一帧观测时终止回合。

## 3. 实验设计

- **基准与场景**：**LIBERO-Mem**，包含 10 个长时程操作任务，类型包括：
  - M：物体运动；
  - S：序列/重复次数；
  - R：物体关系；
  - O：遮挡/占用；
  - 任务从单次升降-返回循环，到重复放置、碗重排、以及根据之前篮子占用情况决定放置位置。
- **对比方法**：
  - 已发布的 **π0、SlotVLA、SlotSSM** 结果（主要为完成率）；
  - **内部复现的 π0**：使用与 2AM 动作模型相同的 Qwen3-VL-4B 骨干、双 RGB 输入、16 步动作块，但不含 2AM 的 grounded steering 接口；
  - **语言-only 消融**：保留相同 Agent、动作模型、观测和动作块长度，但移除所有 2D 提示，仅保留 Agent 生成的子任务语言。
- **评估指标**：
  - **严格成功率（Strict SR）**：完整任务按顺序完成且请求重复次数正确；如果机器人多执行一个循环则失败；
  - **宽松成功率（Relaxed SR）**：达到完整有序目标，忽略之后的多余执行；
  - **完成率（Completion）**：达到的有序子目标比例。

## 6. 论文的主要结论与发现

- **任务记忆可以完全保留在 Agent 侧**：在 RGB-only、无深度、无在线几何、无规划器物体运动条件下，2AM 平均完成率达到 **76.3%**，比最强报告基线 14.8% 高出 **61.5 个百分点**；宽松成功率 **63.0%**，严格成功率 **11.8%**。
- **接口带宽至关重要**：语言-only 消融仅达到 53.72% 完成率、19.42% 宽松成功率；加入 2D 抓取/放置/移动提示后，完成率提升 **22.57 个百分点**，宽松成功率提升 **43.58 个百分点**。
- **严格与宽松指标分离**：2AM 的严格成功率（11.83%）与复现 π0（12.25%）相当甚至略低，说明 **grounded steering 主要改善任务推进，而不是解决“何时精确停止”的语义终止问题**。
- **动作模型能力不仅取决于策略学了什么，还取决于 Agent 引导得有多精确**：Agent 的定位、阶段选择和物体绑定错误会直接进入动作模型接口，无法仅靠鲁棒训练纠正。

## 7. 优点

- **刻意受限的实验设计**：去除深度、在线几何、规划器物体运动等混杂因素，使性能归因更清晰。
- **接口设计合理**：语言 + 独立可选的 2D 抓取、放置、移动提示，既保留 Agent 的高层意图，又不过度限制动作模型的控制几何。
- **鲁棒训练策略**：条件 dropout、空间噪声和时间抖动针对真实部署中 Agent 输出的遗漏、定位误差和时间延迟，增强了系统鲁棒性。
- **从演示恢复监督**：不需要额外的模型教师，避免引入外部标注偏差。
- **对齐基线**：内部复现 π0 而非直接引用已发布低分，增强对比公平性。
- **指标设计**：区分严格、宽松和完成率，更准确地刻画“任务推进”与“精确终止”两个不同瓶颈。

## 8. 不足与局限

- **实验范围有限**：仅在 LIBERO-Mem 单一模拟基准上验证；未扩展到 RMBench、RoboMemArena、RoboMME 等其他记忆相关基准。
- **2D 接口的固有局限**：无法表达隐藏几何、力状态或连续运动历史；对需要精确时序或隐式状态的物理行为可能不足。
- **严格成功率未改善**：2AM 没有解决语义终止问题，精确停止仍是未解决瓶颈。
- **未逐项消融提示贡献**：没有单独评估抓取、放置、移动提示各自的贡献。
- **Agent 骨干比较单一**：只使用 Qwen3.8-27B，未比较更强或更弱的 Agent 模型。
- **缺少真实机器人验证**：仿真结果能否迁移到真实世界尚未证实。
- **训练资源与算力未公开**：难以评估方法在大规模训练中的可行性和成本。
- **任务记忆前提假设**：方法假设当前记忆后果可以通过当前 RGB 中的 2D 提示接地；对无法视觉接地或需要长期不可见状态的任务可能不成立。
