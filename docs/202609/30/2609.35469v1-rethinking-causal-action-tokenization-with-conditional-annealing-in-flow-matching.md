## 摘要
自回归视觉-语言-动作（VLA）模型为机器人学习提供了一条可扩展的路径，然而现有的动作标记器将标记化视为压缩问题，产生的表示在语义上与自回归骨干不一致。我们提出了 CATok，一种因果动作标记器，它将标记化重新定义为一个因果结构化的生成过程。CATok 引入一种条件退火机制，通过逐步退火一个流匹配过程来提取动作标记：每个标记都以所有先前标记为条件，并在特定噪声水平上编码残差重建信号，建立一个由粗到细的因果标记空间，其生成语义与自回归建模在结构上对齐。基于多模态扩散 Transformer（MMDiT）构建的以标记为条件的流匹配解码器，以混合扩散头架构的精度从这些离散标记重建连续动作片段。这种离散瓶颈通过设计强制实现知识隔离，将高层语义推理与低层运动执行清晰分离，无需显式注意力掩码。在三个仿真基准和真实机器人操作任务上的广泛评估表明，CATok 在重建保真度-压缩权衡和推理效率上始终超越现有标记化方法，同时提高 VLA 任务成功率和训练效率，为纯自回归 VLA 系统建立了高性能、可扩展的基础。

## Abstract
Autoregressive Vision-Language-Action (VLA) models offer a scalable path to robot learning, yet existing action tokenizers treat tokenization as a compression problem, producing representations that are semantically misaligned with the autoregressive backbone. We propose CATok, a causal action tokenizer that reframes tokenization as a causally structured generative process. CATok introduces a conditional annealing mechanism that extracts action tokens by progressively annealing a flow-matching process: each token is conditioned on all preceding tokens and encodes the residual reconstruction signal at a specific noise level, establishing a coarse-to-fine causal token space whose generative semantics are structurally aligned with autoregressive modeling. A token-conditioned flow-matching decoder built on Multimodal Diffusion Transformer (MMDiT) reconstructs continuous action chunks from these discrete tokens with the precision of hybrid diffusion-head architectures. This discrete bottleneck enforces knowledge insulation by design, cleanly separating high-level semantic reasoning from low-level motor execution without requiring explicit attention masking. Extensive evaluations across three simulation benchmarks and real-world robotic manipulation tasks demonstrate that CATok consistently surpasses existing tokenization methods in both reconstruction fidelity-compression tradeoff and inference efficiency, while improving VLA task success rate and training efficiency, establishing a high-performance, scalable foundation for purely autoregressive VLA systems.

- **现有方法的局限**：
  - 传统逐维均匀分箱（BIN）产生过长 token 序列，忽略动作维度相关性，且缺乏动作块内部的因果结构。
  - 基于压缩的 FAST 使用 DCT+BPE，但其频率排序与自回归生成方向不一致，可变长输出易导致解码不稳定。
  - 学习型 OAT 通过嵌套 dropout 引入左到右顺序，但 token 位置缺少语义基础，与信息粒度或生成阶段无对应关系。
- **核心问题**：现有动作分词器主要关注“重建什么动作”，却忽视了“动作应该如何生成”，导致 token 表示与自回归骨干的生成语义错位。
- **整体含义**：论文提出将动作分词重新定义为因果结构化的生成过程，使离散 token 的生成顺序与去噪/流匹配的由粗到细的抽象层级对齐，从而弥合分词器与自回归建模之间的语义鸿沟。

## 2. 论文提出的方法论

- **核心思想**：通过条件退火（conditional annealing）将流匹配过程中的时间阶段映射到 token 序列位置，使每个 token 对应一个特定的生成阶段，形成一个由粗到细、因果有序的 token 空间。
- **整体架构（CATok）**：
  1. **双流动作编码器（Dual-Stream Action Encoder）**：
     - 对动作块进行分位数归一化，使用带权重归一化的 2D CNN 提取时空局部相关性，并加入可学习 2D 位置嵌入得到 `E_act`。
     - 同时初始化 `K` 个可学习查询嵌入 `Q(0)`，通过基于 MMDiT 的对称多模态 transformer 进行共注意力交互，最终得到紧凑的查询表示 `Q = (q1,...,qK)`。
  2. **瓶颈向量量化器（Bottleneck Vector Quantizer）**：
     - 采用 ViT-VQGAN 的分解码设计：先用线性瓶颈 `ψ` 将 `q_k` 投影到低维空间，再在码本 `C` 中按欧氏距离最近邻选择离散索引 `c_k`，最后用后投影 `ϕ` 恢复原始维度，得到量化嵌入 `\hat q_k`。
     - 该分解设计解耦码本维度与模型隐藏维度，提高码本利用率。
  3. **带条件退火的流匹配解码器（Flow-Matching Decoder with Conditional Annealing）**：
     - 基于 rectified flow，定义插值路径 `x_t = (1-t)x0 + t x1`（`x0` 为高斯噪声，`x1` 为目标动作块），目标速度为 `x1 - x0`。
     - 关键机制：在时间步 `t`，按 `κ(t) = ⌊tK⌋` 遮蔽前 `κ(t)` 个 token，只保留 `Q_{>κ(t)}` 作为条件输入速度网络。
     - 训练目标：`L_FM = E_{t,x0,x1}[‖ v_θ(x_t, t, Q_{>κ(t)}) - (x1 - x0) ‖_1]`。
     - 该调度迫使早期 token 提供粗粒度全局引导，后期 token 专注于细粒度残差修正，形成离散信息增量。
  4. **训练损失**：
     - 总损失 `L = L_FM + α L_smooth + β L_VQ`。
     - `L_smooth` 为 DCT 域上的频谱损失：`E[‖ DCT(x1 - x0) - DCT(v_θ(...)) ‖_1]`，促进长时程平滑。
     - `L_VQ` 为标准承诺损失：`Σ ‖ ψ(q_i) - sg(\hat q_i) ‖^2`，码本用 EMA 更新并周期重置低使用率条目。
- **推理/去标记化**：给定 token 序列，映射为嵌入 `\hat Q`，通过求解 ODE `x1 = x0 + ∫ v_θ(x_t, t | \tilde Q_t) dt` 恢复连续动作，其中 `\tilde Q_t` 保留最后 `K - κ(t)` 个嵌入。
- **VLA 集成（VLA-CATok）**：将冻结的 CATok 分词器与自回归 VLA 骨干结合，骨干仅以交叉熵损失预测离散 token，解码器冻结，离散 token 作为唯一接口实现知识隔离。

- **下游性能提升**：CATok 在 LIBERO、SimplerEnv、RoboTwin 2.0 三个仿真基准上总体成功率最佳，且在长时程任务上提升显著（如 SimplerEnv 的 StackGreenCubeOnYellowCube 比最强基线高 16.7%）。

- **真实机器人迁移**：在三个真实任务套件上，CATok 比 FAST 一致提升约 20 个百分点。
- **因果有序性验证**：熵分析显示 CATok 正向顺序熵递减、反向顺序熵递升，表明 token 具有方向性预测依赖；t-SNE 和前缀重建显示早期 token 捕获全局结构、后期 token 细化残差。

## 7. 优点

- **新颖的因果建模视角**：将流匹配的去噪阶段与 token 序列位置关联，为动作 token 赋予了明确的生成语义，而非仅仅压缩。
- **方法设计精巧**：条件退火机制简单有效，通过 `κ(t)=⌊tK⌋` 自然地产生由粗到细的因果结构；MMDiT 解码器兼顾了连续控制的精度与自回归训练的兼容性。
- **知识隔离机制**：离散 token 作为 VLM 与动作解码之间的唯一接口，冻结解码器，无需显式注意力掩码即可保护预训练知识。
- **实验全面且分析深入**：不仅报告下游成功率，还从熵、嵌入几何、前缀重建、原生解码器干预等多角度验证了 token 的因果性与生成语义，增强了结论的可信度。
- **训练与推理效率突出**：在保持高成功率的同时显著降低了训练成本和推理延迟，具有实际部署价值。
