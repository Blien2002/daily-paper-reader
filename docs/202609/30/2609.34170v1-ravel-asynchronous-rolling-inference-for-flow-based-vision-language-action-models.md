## 摘要
基于流的视觉-语言-动作（VLA）模型在通用机器人操作中非常有效，但其对计算开销高昂的VLM编码和多步迭代动作生成的依赖带来了显著的延迟瓶颈。由此产生的推理延迟使机器人难以快速响应，尤其是在动态环境中。我们通过RAVEL（实现低延迟控制的滚动异步VLA）这一异步推理框架来解决这一局限，该框架针对VLM骨干网络和动作专家的计算瓶颈进行了处理。为减少多步动作去噪带来的延迟，RAVEL通过在滚动缓冲区中向前传递部分去噪的未来动作，使近期动作在单次去噪步骤后即可执行。为避免被缓慢的VLM编码阻塞，RAVEL将VLM编码与滚动动作生成解耦，使动作专家能够利用最新的可用VLM上下文持续运行，同时轻量级快速观测通路（FOP）直接以当前观测为条件作用于动作专家。在仿真和真实世界的操作任务中，RAVEL始终保持显著更低的响应延迟，同时维持底层VLA的任务能力，从而实现高频且响应迅速的闭环控制。

## Abstract
Flow-based vision-language-action (VLA) models are highly effective for generalist robot manipulation, yet their reliance on computationally expensive VLM encoding and multi-step iterative action generation imposes a significant latency bottleneck. The resulting inference latency makes it difficult for robots to respond quickly, especially in dynamic environments. We address this limitation with RAVEL (Rolling Asynchronous VLA Enabling Low-Latency Control), an asynchronous inference framework that addresses the computational bottlenecks of both the VLM backbone and the action expert. To reduce the delay from multi-step action denoising, RAVEL allows near-term actions to be executed after a single denoising step by carrying partially denoised future actions forward in a rolling buffer. To avoid blocking on slow VLM encoding, RAVEL decouples VLM encoding from rolling action generation, allowing the action expert to operate continuously using the latest available VLM context, while a lightweight Fast Observation Pathway (FOP) directly conditions the action expert on current observations. Across simulated and real-world manipulation tasks, RAVEL consistently achieves substantially lower response latency while maintaining the task capability of the underlying VLA, enabling high-frequency and responsive closed-loop control.

## 论文核心问题与整体含义

- **研究背景**：基于流的视觉-语言-动作（flow-based VLA）模型在通用机器人操作中表现优异，典型代表如 π0.5、X-VLA、DynamicVLA 等。
- **核心问题**：这类模型依赖昂贵的 VLM 编码和多步迭代动作去噪，导致推理延迟较高；在同步推理模式下，机器人会在动作块之间停顿，执行固定动作块也限制了新观测影响控制的频率。
- **整体含义**：论文希望在不牺牲 VLA 任务能力的前提下，大幅降低“观测—动作”响应延迟，使机器人能够进行高频、快速响应的闭环控制，特别是在目标持续运动的动态环境中。

## 论文提出的方法论

- **滚动动作缓冲区（Rolling Action Buffer）**
  - 维护长度为 \(K\) 的未来动作缓冲区，每个槽位对应未来不同执行时刻的动作。
  - 槽位 \(k\) 的流时间步为 \(\tau_k = 1 - k/K\)，即越远的动作噪声越大。
  - 每个控制步只需一次动作专家前向传播：将所有槽位推进一个去噪步长 \(\Delta\tau = 1/K\)，释放第一个已完全去噪的动作，并在末尾追加一个高斯噪声新动作。
  - 因此每个动作在真正执行前会经历 \(K\) 次渐进细化。

- **异步上下文更新与时间偏移条件**
  - 将 VLM 上下文计算与滚动动作生成解耦，动作专家持续使用最新的可用 VLM 上下文，不等待新的 VLM 编码完成。
  - 引入归一化时序偏移 \(\delta_p = p/K\)，其中 \(p = t_a - t_o\) 表示动作执行时刻与 VLM 观测时刻的差值，使动作专家能够根据延迟生成对应未来时刻的动作。

- **快速观测通路（Fast Observation Pathway, FOP）**
  - 采用轻量图像编码器与当前本体状态投影，将当前观测特征 \(z_{t_a} = F(o_{t_a}, s_{t_a})\) 注入动作专家。
  - 注入方式为在部分动作专家层中引入门控交叉注意力适配器。
  - VLM 上下文提供语义与指令信息，FOP 提供最新视觉与本体状态信息，使近期动作能响应新观测。

- **流式对齐训练（Streaming-Aligned Training）**
  - 训练时随机采样观测时刻 \(t_o\) 和时序偏移 \(p\)，以 \(t_a = t_o + p\) 作为动作预测时刻。
  - 使用与推理一致的滚动噪声分布构造训练缓冲区：\(a^{\tau_k}_{t_a+k} = (1-\tau_k)\epsilon_{t_a+k} + \tau_k \hat{a}_{t_a+k}\)。
  - 训练目标为每个槽位的流匹配速度 \( \hat{a}_{t_a+k} - \epsilon_{t_a+k} \)，损失函数为 slot-wise 的 MSE。
  - VLM 骨干网络在训练中保持冻结，仅训练动作专家及相关投影/适配器。

## 论文的主要结论与发现

- **操作能力保持**：在 LIBERO 与 RoboTwin 2.0 上，RAVEL 保持甚至略微提升原始 VLA 的成功率，说明滚动推理不会损害底层操作能力。
- **显著降低延迟**：在单块 RTX 4090 上，首动作延迟相比全量去噪降低约 2.59–2.92 倍。
- **动态任务收益**：在 DOM 上，RAVEL 成功率达到 44.06%，比 CI & LAAS 高 8.56 个百分点；加入 FOP 后进一步提升至 46.94%，并在 Closed-loop Reactivity 达到 62.5%。RAVEL 还取得最短平均完成时间 6.04 秒。
- **真实世界响应优势**：乒乓球回球任务成功率 90%，远高于其他方法（最高 25%）；观察年龄中位数 121.76 ms、P95 132.20 ms，均为最优。
- **运动平滑性**：网球抓取任务中，RAVEL 在 \(E_{HF}\) 和 TCP jerk RMS 上均最低，表明滚动异步执行能减少运动中的高频振荡和突变。
- **训练与时间对齐必要性**：消融显示，仅做噪声对齐不够，必须同时使用平移 horizon 配对与时序偏移条件；真实偏移 \(\delta_0\) 存在最优值 0.3，过小或过大都会降低成功率。

## 优点

- **同时解决两个延迟瓶颈**：不仅减少多步动作去噪的计算量，还通过异步解耦消除了 VLM 编码对动作生成的阻塞。
- **滚动缓冲设计巧妙**：单步去噪即可释放新动作，同时保留未来动作逐步细化，兼顾效率与连续性。
- **FOP 提升观测新鲜度**：轻量观测通路使动作专家无需等待慢速 VLM 即可响应最新场景变化。
- **时序偏移条件提升鲁棒性**：显式建模观测与执行的时间错位，适应动态环境和机器人执行延迟。
- **实验设计相对完整**：覆盖同步/异步仿真、动态基准、真实机器人以及多种消融，证据链条较完整。
- **真实世界验证有说服力**：在乒乓球等高动态任务中取得显著优势，且量化了观察年龄和运动平滑性。

## 不足与局限

- **需要额外的流式对齐训练**：不能直接对现有 VLA 进行零样本滚动推理，必须进行针对性的微调。
- **架构特定性较强**：时序偏移条件和 FOP 需要修改动作专家结构，不同 VLA 的动作专家设计不统一，扩展性受限。
- **目前仅适用于流式 VLA**：框架尚未推广到扩散式或其他非流式 VLA 架构。
- **物理执行延迟仍在**：FOP 提高了观测新鲜度，但动作预测到机器人实际执行之间的滞后仍存在，可能削弱其在真实系统中的收益。
- **真实世界样本量偏小**：每个任务仅 20 次试验，统计结论可能不够稳健。
- **异步对比方法复现偏差**：DOM 中 VLASH、FASTER 等本地复现表现不佳，部分原因是硬件与原始论文不同，可能影响对比的公平性。
