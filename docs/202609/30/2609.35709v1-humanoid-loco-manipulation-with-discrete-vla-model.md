## 摘要
使用离散动作令牌的视觉-语言-动作（VLA）模型已被证明在控制机械臂执行操作任务方面非常有效。然而，对于人形机器人而言，其全身动作空间——包括腿、躯干、手臂和手——维度要高得多且具有异构性，这带来了令牌化、训练和实时推理方面的挑战，而此前的 VLA 模型并未解决这些问题。我们提出了 Holo-M，据我们所知，这是第一个用于人形机器人运动操作的离散 VLA 模型，它通过用动作令牌扩展语言模型的词表，本质性地利用了语言模型。在该模型中，我们设计了一种统一的动作令牌化器，将人形机器人的动作空间分解为四种身体部位特定的令牌化器——末端执行器、身体、手部和运动学——从而能够在差异巨大的形态和数据源上进行训练，包括人形机器人遥操作、第一人称人类视频和仿真。通过用这些动作令牌扩展语言模型的词表，我们避免了使用单独连续动作专家的模型所固有的知识隔离问题。为满足实时控制要求，我们通过分组离散扩散解码来解码每个身体部位的动作令牌，而不是对动作令牌进行自回归。我们在 SIMPLE 人形机器人运动操作基准上进行了大量实验，其中 Holo-M 在通用和专项评估中均取得了最高的成功率，并大幅领先第二名。我们将发布所有代码和模型权重。

## Abstract
Vision-language-action (VLA) models using discrete action tokens have proven effective for controling robotic arms on manipulation tasks. For a humanoid, however, the whole-body action space -- legs, torso, arms, and hands -- is far higher-dimensional and heterogeneous, raising tokenization, training, and real-time inference challenges that the previous VLA models do not address. We present Holo-M, to our knowledge the first discrete VLA model for humanoid loco-manipulation that intrinsically exploits the language model by extending its vocabulary with action tokens. In this model, we devise a unified action tokenizer that decomposes the humanoid action space into four body-part-specific tokenizers -- end-effector, body, hand, and kinematics -- enabling training across drastically different embodiments and data sources, including humanoid teleoperation, ego-centric human video, and simulation. By extending the language model's vocabulary with these action tokens, we avoid the knowledge-insulation problem inherent to the models that use separate continuous action experts. To meet real-time control requirements, we decode each body part's action tokens through grouped discrete diffusion decoding, rather than using autoregression on the action tokens. We have conducted extensive experiments on the SIMPLE humanoid loco-manipulation benchmark, in which Holo-M achieves the highest success rates in both the generalist and specialist evaluations, leading the second best by significant margins. We will release all the code and model weights.

## 1. 核心问题与整体含义

- **研究背景**：现有基于离散动作令牌（discrete action tokens）的视觉-语言-动作（VLA）模型，主要针对**机械臂操作任务**设计，其动作空间维度低、结构单一，容易实现高效令牌化、训练与推理。
- **核心问题**：人形机器人的全身动作空间包含腿、躯干、手臂和灵巧手，**自由度高、异构性强、时间尺度差异大**，直接将机械臂式离散 VLA 方案扩展过来会面临三类困难：
  - **令牌化困难**：单一扁平词表要么过粗、要么过大，难以满足全身控制需求；
  - **训练困难**：单一数据集难以覆盖人体全部自由度，需要融合遥操作、人类视频、仿真等异构来源；
  - **推理实时性困难**：自回归解码令牌序列过长，难以满足全身实时控制。
- **整体含义**：论文提出 **Holo-M**，据作者称是首个面向人形机器人运动操作（loco-manipulation）的**离散 VLA 模型**。它通过**将动作令牌直接纳入语言模型词表**，使动作生成与语言生成共享同一个序列模型，避免了使用独立连续动作专家时的“知识隔离”问题。

## 2. 论文提出的方法论

### 2.1 统一动作令牌化器

- 将人形机器人动作空间分解为四个身体部位组：
  - **末端执行器（EEF）**：腕部与指尖位置、6D 腕部旋转，维度 48；
  - **身体（body）**：身体关节目标，维度 29；
  - **手部（hand）**：手指关节目标，维度 14；
  - **运动学（kinematics）**：基础速度、高度、偏航率指令，维度 5。
- 每个动作块包含 **T = 30 步、30 Hz**（1 秒），固定组顺序为 **EEF → body → hand → kinematics**，总动作维度 96。
- 不同数据来源可以只监督其覆盖的部分身体部位组，缺席组通过 **group-validity mask** 从损失中排除，无需填充伪目标。

### 2.2 FAST-RVQ 动作令牌化

- 对每个动作组，沿时间轴每个维度应用**离散余弦变换（DCT）**，保留前 **N = 2** 个 DCT 低频系数；
- 对剩余时间域残差使用**残差向量量化（RVQ）**，每个组使用 **Q = 4** 个 RVQ 阶段，码本由 k-means 拟合；
- 每个组令牌长度 \(L_g = N D_g + Q = 2D_g + 4\)，最终四组令牌长度分别为 100、62、32、14，总动作令牌序列 **208** 个。
- 相较 FAST 的字节对编码变长令牌，FAST-RVQ 生成固定长度序列，更适合并行掩码解码。

### 2.3 VLM 骨干网络

- 使用 **Qwen3-VL-2B** 作为视觉-语言骨干，视觉编码器冻结，语言骨干针对动作令牌预测进行训练。
- 条件上下文顺序固定为：**图像 → 任务指令 → 设置/形态信息 → 状态**。状态 tokens 由关节角均匀量化到 256 个 bin，仅作为条件，不包含在动作令牌 208 个之内。
- 动作令牌序列结构：
  - `Action: <action_output><action_start> <end_effector_start>[100 tokens]<end_effector_end> ... <action_end>`
- 训练目标：自回归建模 \(p_\theta(y_t | c_t)\)，按组顺序逐令牌预测，缺席组通过 mask 排除。

### 2.4 分组离散扩散解码

- 为解决自回归 208 步推理太慢的问题，采用**分组离散扩散**：
  - 每组作为独立扩散块，**组内并行去掩码（de-masking）**；
  - 组间保持**自回归因果依赖**，即后续组可以条件于已解码的前序组；
  - 使用**置信度去掩码**：每轮预测所有掩码位置，并选择置信度最高的位置去掩码；
  - 训练目标为分组掩码扩散损失，不引入独立扩散模型或动作头。
- 以每组 8 步去掩码为例，四组仅需 **32 个顺序解码步骤**，相比自回归 208 步减少 **6.5×** 解码深度。

### 2.5 训练流水线

- **Stage I：自回归预训练**。联合使用 EgoDex（人类视频）和 Humanoid Everyday（人形机器人遥操作），仅监督有效组。
- **Stage II：人形机器人后训练**。在 SIMPLE 人形训练集上继续自回归训练，对齐目标机器人。
- **Stage III：分组离散扩散微调**。将 Stage II 的检查点转为分组掩码扩散训练，得到 Holo-M 通用策略。
- **Stage IV：任务专项微调**。针对单个目标任务进行微调，得到 Holo-M 专家策略。

## 6. 主要结论与发现

- **Holo-M 通用策略**成功率为 **143/180**，显著高于最强基线 Ψ0（114/180），排名第一；

- 真实世界两个任务中，Tabletop Grasp 成功 10/10，Move Pick 成功 8/10，验证了系统的可部署性。

## 7. 优点

- **方法创新**：首个面向人形全身运动操作的离散 VLA 模型，将动作令牌集成进语言模型词表，避免知识隔离；
- **统一动作令牌化器**：四组身体部位分解有效应对全身动作空间的高维和异构性，支持跨形态、跨数据源训练；
- **FAST-RVQ**：结合 DCT 低频系数与 RVQ 残差量化，得到固定长度令牌，便于并行掩码解码；
- **分组离散扩散**：组内并行、组间自回归，兼顾任务性能与推理实时性；
- **实验充分**：在 SIMPLE 基准上与多种强基线系统比较，覆盖通用、专家、数据扩展、推理延迟和真实世界验证；
- **工程可复现**：明确了与 Ψ0 共用真实机器人栈，只替换策略服务器，性能差异归因清晰；承诺开源代码与权重。

## 8. 不足与局限

- **算力信息缺失**：论文没有报告训练阶段 GPU 型号、数量、训练时长等，复现难度较大。
