## 摘要
难以从视觉直接推断的隐式物体属性（如材料、容器内容物或柔软度）可以通过触觉感知和探索性交互来揭示。然而，由于触觉信号具有瞬态性和稀疏性，提取信息丰富的触觉事件并将其有效融入机器人操作仍然是一个挑战。在本文中，我们提出了一个以物体为中心的上下文感知操作框架，通过触觉探索学习与任务无关的物体表征。一个token学习器从长时程探索中自主选择具有代表性的触觉片段，而与描述性文本嵌入的对比对齐使得潜在空间能够捕捉多种物理物体属性。这些学习到的表征随后被用作语义上下文，以引导以物体为中心的操作策略，并根据物体属性调整策略。实验表明，学习到的表征在已见物体和未见物体上分别实现了93%和84%的属性估计准确率。在三个涉及视觉上模棱两可物体的任务（即多物体重排、倾倒和开箱）上评估，所提出的框架同时改善了目标选择和依赖属性的操作自适应，将所有评估试验汇总的任务成功率在已见物体上从41%提高到92%，在未见物体上从19%提高到67%，相对于没有物体上下文条件化的基线策略。视频和更多结果可在 https://xinyiyxyx.github.io/tactile-object-centric/ 获取。

## Abstract
Implicit object properties that are difficult to directly infer from vision, such as material, container contents, or softness, can be revealed through tactile sensing and exploratory interactions. However, because tactile signals are transient and sparse, extracting informative tactile events and effectively incorporating them into robotic manipulation remains a challenge. In this work, we present an object-centric context-aware manipulation framework that learns task-agnostic object representations through tactile exploration. A token learner autonomously selects representative tactile segments from long-horizon exploration, while contrastive alignment with descriptive text embeddings enables a latent space that captures multiple physical object properties. These learned representations are then used as semantic context to guide object-centric manipulation policies and adapt strategies based on object properties. Experiments show that the learned representations achieve 93% and 84% property estimation accuracy on seen and unseen objects. Evaluated on three tasks involving visually ambiguous objects, i.e. multi-object rearrangement, pouring, and box opening, the proposed framework improves both target selection and property-dependent manipulation adaptation, raising task success, aggregated over all evaluation trials, from 41% to 92% on seen objects and from 19% to 67% on unseen objects over baseline policies without object-context conditioning. Videos and additional results are available at https://xinyiyxyx.github.io/tactile-object-centric/.

## 1. 核心问题与研究动机  
- 视觉难以直接推断物体的隐式物理属性，如材料、容器内容物、柔软度、重量分布等。  
- 触觉感知与探索性交互可以揭示这些属性，但触觉信号具有稀疏、瞬态、事件驱动的特点，有效信息容易被长时程探索序列稀释。  
- 现有工作多将触觉用于短期反馈或属性识别，较少学习可复用的物体级表征并用于下游操作决策。  
- 本文动机：学习任务无关的物体中心触觉表征，并将其作为语义上下文融入操作策略，提升视觉模糊场景下的目标选择与策略自适应能力。

## 2. 方法论  
### 2.1 物体表征学习（任务无关）  
- **探索程序**：对每个物体执行六种预定义探索动作：摆动、摇动、桌面敲击、空腔敲击、挤压、桌面滑动。  
- **多模态记录**：同步记录三路信号——指尖振动触觉（接触麦克风）、6轴末端力/力矩（关节扭矩估计）、末端执行器线速度（编码器）。  
- **信号编码**：  
  - 信号按 0.5 s 窗口、0.25 s 重叠分段。  
  - 振动信号经 STFT 转换为频谱，由 PANN 风格的 CNN 编码为 256 维 token。  
  - 力与速度分别用 MLP 编码为 256 维 token。  
- **Token Learner**：  
  - 可学习评分网络为每个多模态 token 赋予重要性分数。  
  - 前向传播使用 hard top-K 选择 K=18 个最相关 token；反向传播使用 straight-through estimator 和可微 soft mask，使评分网络获得梯度。  
  - 仅由 triplet loss 优化，无额外辅助选择损失。  
- **物体嵌入生成**：选中的 token 按分数降序拼接并投影为 256 维物体嵌入，随后进行 L2 归一化。  
- **语义对齐**：  
  - 使用预训练 SentenceTransformer（all-MiniLM-L6-v2）生成属性描述文本嵌入作为锚点。  
  - 在 content、fill level、material、rigidity 四个属性轴上分别构造三元组，应用 triplet loss 对齐物体嵌入与文本嵌入。  
  - 推断时通过物体嵌入与候选文本嵌入的余弦相似度估计属性。  

### 2.2 上下文感知策略学习  
- 基于 Action Chunking Transformer（ACT）构建策略。  
- **物体上下文**：将学习到的物体表征与物体坐标位置嵌入拼接，形成时不变上下文，以 FiLM 风格条件化策略。  
- **观测处理**：  
  - 使用物体位置嵌入对外部图像 token 进行注意力，得到物体中心视觉嵌入。  
  - 本体感觉特征与腕部相机 token 交互，提取局部视觉特征。  
  - 在线振动触觉观测通过 1.0 s 窗口 STFT 后由 PANN CNN 编码为 token。  
- **动作输出**：7D 关节角 + 1D 夹爪宽度，动作块长度 64。  
- **多物体场景**：先探索每个物体获得表征；策略按物体顺序执行，输出 idle 动作时切换到下一物体。
