## 摘要
视觉-语言预训练和预测性世界建模为机器人策略提供了丰富的语义和动态视觉特征，但它们的原生动作和视觉预测目标可能遗漏关键的物理和任务结构，同时保留与控制无关的视觉冗余。我们将这种视觉丰富性与控制效用之间的不匹配称为动作充分性差距。我们研究是否可以通过引导中间特征保留机器人操作中三种与控制相关的结构来弥合这一差距：控制运动可行性的几何结构、编码与指令相关实体的可供性，以及将指令锚定在任务相关区域的目标。为此，我们提出了GIFT（引导式中间特征训练），一个架构灵活的框架，用于学习中间特征，通过几何对齐、可供性预测和目标区域重建将这些结构转化为训练时的约束。我们在视觉-语言-动作（VLA）策略、直接动作世界-动作模型（WAM）和逆动力学WAM中实例化GIFT，同时保留每个模型的动作表述。在零样本迁移到LIBERO-Plus上，GIFT-VLA、GIFT-WAM-Fast和GIFT-WAM-IDM分别比StarVLA-OFT、Fast-WAM和Fast-WAM-IDM高出4.6、12.6和5.2个百分点，分别达到79.6%、72.6%和87.8%。在RoboCasa上，三个GIFT变体分别达到61.4%、83.6%和82.3%，分别比对应模型高出12.6、9.0和8.4个百分点。这些结果共同确立了学习功能结构化中间特征作为跨模型特定动作表述的可复用原则，尤其在关节物体任务和未见视觉与空间扰动下的高精度真实世界操作中带来了显著增益。项目页面：https://openphoenix-team.github.io/GIFT-pages。

## Abstract
Vision-language pre-training and predictive world modeling provide robot policies with rich semantic and dynamic visual features, but their native action and visual-prediction objectives may omit critical physical and task structure while retaining control-irrelevant visual redundancy. We call this mismatch between visual richness and control utility the action-sufficiency gap. We investigate whether this gap can be bridged by guiding intermediate features to preserve three control-relevant structure in robotic manipulation: geometry governing motion feasibility, affordance encoding instruction-relevant entities, and goals grounding instructions in task-relevant regions. To this end, we present GIFT (Guided Intermediate Feature Training), an architecture-flexible framework for learning intermediate features that translates these structures into training-time constraints through geometry alignment, affordance prediction, and goal-region reconstruction. We instantiate GIFT in a Vision-Language-Action (VLA) policy, a direct-action World-Action Model (WAM), and an inverse-dynamics WAM while retaining each model's action formulation. Under zero-shot transfer to LIBERO-Plus, GIFT-VLA, GIFT-WAM-Fast, and GIFT-WAM-IDM outperform StarVLA-OFT, Fast-WAM, and Fast-WAM-IDM by 4.6, 12.6, and 5.2 points, reaching 79.6%, 72.6%, and 87.8%, respectively. On RoboCasa, the three GIFT variants reach 61.4%, 83.6%, and 82.3%, outperforming their counterparts by 12.6, 9.0, and 8.4 points, respectively. Together, these results establish learning functionally structured intermediate features as a reusable principle across model-specific action formulations, with especially large gains on articulated-object tasks and high-precision real-world manipulation under unseen visual and spatial perturbations. - **整体含义**：论文提出通过**引导中间特征**保留三类在机器人操作中反复出现的控制相关结构——**几何（geometry）**、**可供性（affordance）**、**目标（goal）**——来弥补该差距。其核心主张是：学习“功能结构化”的中间特征是跨不同策略架构、跨不同动作表述的**可复用原则**。

## 2. 论文提出的方法论

### 2.1 核心思想

- GIFT（Guided Intermediate Feature Training）是一个**架构灵活**的框架，将几何对齐、可供性预测和目标区域重建三种结构转化为训练时对中间视觉特征的约束。
- 关键是**不修改模型原有的动作生成接口**，也不把辅助预测作为动作输入；默认采用 **no-injection（不注入）** 设计，辅助目标仅通过训练梯度塑造共享中间特征。

### 2.2 三类结构化监督

#### （1）几何监督（Geometry Guidance）

- 使用**冻结的 VGGT 几何基础模型**作为训练时教师，对学生中间视觉 token 进行特征对齐。
- 学生浅层特征（\(r=6\)）通过 LN-MLP 和标量头分别预测教师特征的**方向**和 **log-scale**。
- 损失由两部分组成：
  - 角度对齐损失 \(L_{ang}\)：对齐学生预测与 VGGT 特征的单位方向；
  - 尺度对齐损失 \(L_{scale}\)：保留教师特征幅值信息。
- 总几何损失：\(L_{geo} = \lambda_{ang}L_{ang} + \lambda_{scale}L_{scale}\)，权重为 \(0.2\) 和 \(0.05\)。
- 几何教师仅用于训练，推理时无需部署。

#### （2）可供性监督（Affordance Guidance）

- 定义**对象-末端执行器交互关系**：实体角色（padding、左右末端执行器、锚点对象、其他相关对象）、锚点坐标系中的实体位姿、关联末端执行器在实体坐标系中的位姿、以及末端执行器闭合状态。
- 每个实体槽位由 20 维向量表示：\(u_{t,k} = [c_{t,k}, \xi_{k|a,t}, \xi_{e(k)|k,t}, f_{t,k}]\)。
- 使用 K 个可学习查询的轻量 decoder 从最终层视觉 token 回归这些交互目标。
- 损失为按有效槽位掩码加权的 **Smooth L1 loss**：
  \[
  L_{aff} = \frac{1}{Q_t}\sum_{k=1}^{K} q_{t,k}\,\mathrm{SL1}(\hat{u}_{t,k}, u_{t,k})
  \]
- 该表示显式耦合指令相关实体与交互所需的末端执行器位姿，降低对全局相机坐标系的依赖。

#### （3）目标监督（Goal Guidance）

- 为每一视角构建**指令相关操作对象的二值目标掩码** \(M_t\)。
- Goal decoder 基于指令和中间视觉 token 预测低分辨率掩码 \(\hat{M}_t\)。
- 损失为二值交叉熵与 soft Dice 损失的加权和：
  \[
  L_{goal} = \lambda_{bce}\,\mathrm{BCE}(\hat{M}_t, M_t) + \lambda_{dice}(1-\mathrm{Dice}(\hat{M}_t, M_t))
  \]

#### （4）总体训练目标

- 对任意策略实例，总目标为：
  \[
  L_{GIFT} = L_{native} + \lambda_{geo}L_{geo} + \lambda_{aff}L_{aff} + \lambda_{goal}L_{goal}
  \]
  其中 \(L_{native}\) 因模型而异。

### 2.3 三种策略实例化

- **GIFT-VLA**：基于 StarVLA-OFT + Qwen3-VL backbone；动作头使用 BridgeAttention，但在 no-injection 模式中将可供性与目标 token 从动作头交叉注意力中屏蔽。
- **GIFT-WAM-Fast**：基于 Fast-WAM；直接动作扩散，动作 token 只关注当前帧视频 token，不关注未来视频 token。
- **GIFT-WAM-IDM**：基于逆动力学 WAM；训练时用干净/损坏未来视频作为动作专家的条件，推理时先去噪未来视频再据其生成动作。
- **可选的注入变体**：若启用注入，则将可供性与目标 decoder 的隐藏特征投影后作为动作条件；默认 no-injection 不使用注入。

## 3. 实验设计

### 3.1 仿真基准

- **LIBERO**：四个任务套件（Spatial、Object、Goal、Long），每套件 10 个语言条件任务，Franka Emika Panda 机械臂；每任务 50 次 rollout。
- **LIBERO-Plus**：七类分布偏移——相机视角、机器人初始位姿、语言指令、光照、背景纹理、传感器噪声、物体布局。模型仅在原始 LIBERO 轨迹上训练，零样本迁移测试。
- **RoboCasa**：Fourier GR1 人形机器人；24 个家庭操作任务（18 个 pick-and-place + 6 个关节物体任务），每任务 1000 条演示；报告关节物体、pick-and-place 和整体成功率。

### 3.2 真实世界实验

- **平台一**：UFACTORY xArm7 单臂 + 两个 Intel RealSense D435 相机（第三方视角、腕部视角）。
- **平台二**：ARX X5 双臂 + 三个 Intel RealSense D405 相机（一个头部、两个腕部）。
- **任务**：
  - Task 1：颜色条件放置；
  - Task 2：层级条件放置；
  - Task 3：关节物体操作（将魔方放入柜子并关门）；
  - Task 4：双臂试管插入。
- 每任务收集 100 条人类遥操作演示，共 400 条；使用 Grounding DINO、SAM2、Orient Anything V2 等工具生成/人工校验 masks 和位姿标签。
- 在原始设置和渐进扰动下各评估 10 次。

### 3.3 对比方法

- 主要匹配基线：**StarVLA-OFT**、**Fast-WAM**、**Fast-WAM-IDM**。
- 还对比了大量 SOTA 方法，包括 OpenVLA、π0、GuidedVLA、Spatial Forcing、CoT-VLA、DreamVLA、DIAL、GAM、Cosmos Policy、ABot-M0 等。

## 6. 论文的主要结论与发现

- **零样本鲁棒性提升显著**：在 LIBERO-Plus 上，GIFT-VLA、GIFT-WAM-Fast、GIFT-WAM-IDM 分别达到 79.6%、72.6%、87.8%，较匹配基线提升 4.6、12.6、5.2 个百分点。
- **跨环境与跨本体提升明显**：在 RoboCasa 上，三个变体达到 61.4%、83.6%、82.3%，较匹配基线提升 12.6、9.0、8.4 个百分点；关节物体任务提升尤其突出（WAM 变体提升超过 20 个百分点）。
- **三种结构化信号互补**：单信号消融显示，任一信号单独使用都能带来提升，组合后效果最佳。
- **不注入优于注入**：no-injection 变体在多数情况下优于 injection 变体，说明结构化中间监督本身已足够，无需将辅助预测作为动作条件。
- **真实世界鲁棒性提升**：GIFT-WAM-IDM 在真实世界任务上的成功率从 52.5% 提升至 87.5%，且在光照、背景、物体姿态扰动下保持较高成功率。
- **表示学习层面的证据**：注意力和结构化预测可视化表明，GIFT 使动作生成过程更一致地聚焦于被操作对象和交互相关区域。

## 7. 优点

- **架构灵活性高**：同一组目标可同时用于 VLA、直接动作 WAM 和逆动力学 WAM，不绑定特定动作头或解码器。
- **推理开销低**：默认 no-injection 设置下，几何教师和辅助 heads 在部署时均不需要执行，没有额外推理成本。
- **结构化监督设计互补性强**：几何描述可行性、可供性描述对象-末端执行器交互、目标描述指令相关区域，三者共同覆盖控制所需关键信息。
- **实验体系较严谨**：使用匹配基线、same-head 控制、单信号消融、注入/不注入消融、注意力和失败案例可视化，证据链较完整。
- **真实世界验证充分**：在单臂、双臂平台上验证，并设计了渐进式、非合成的视觉/空间扰动，较有说服力。

## 8. 不足与局限

- **结构化标签获取成本高**：仿真中依赖特权状态和专家轨迹重放；真实世界中需要 Grounding DINO、SAM2、人工校验、Orient Anything V2 等多步标注流程，难以大规模扩展。
- **训练时需要额外教师模型**：几何监督依赖冻结 VGGT，引入额外存储与计算负担，尽管推理时不需要。
- **极端分布偏移下会失效**：失败案例显示，在严重传感器噪声、大视角变化、复杂背景或大量未见物体时，几何/可供性/目标预测可能不准确，甚至误导动作生成。
- **真实世界实验规模有限**：每任务仅 100 条演示，评估仅 10 次，结果可能存在较大方差

- **损失权重与教师选择缺少系统敏感性分析**：不同骨干网络、任务域下，几何/可供性/目标三项损失的相对权重可能需要重新调整；冻结 VGGT 以外的几何教师是否带来一致收益也未充分验证。
- **结构先验覆盖范围仍然有限**：几何、可供性、目标三类结构主要针对刚体对象的抓取、放置、插入等任务设计，对流体、布料、可变形物体、接触丰富或动态交互等任务是否同样有效尚未验证。
- **真实世界任务多样性较窄**：仅覆盖颜色/层级放置、关节物体操作和双臂插入，缺少长时序、多阶段、动态物理交互等更复杂任务证据。
- **部分对比方法的训练数据与预处理不完全一致**：与 SOTA 方法的比较中，数据规模、语言标注质量、动作表征等因素可能影响绝对增益的解读，结论应主要依据匹配基线之间的对照。

## 9. 总结与评价

GIFT 的核心贡献在于将“视觉丰富性”与“控制充分性”之间的错配显式化为三类互补的结构化中间特征监督——几何、可供性、目标，并通过 no-injection 机制在不增加推理开销的前提下提升策略泛化性。实验证据较扎实：跨 VLA、WAM 两种策略家族，跨 LIBERO、RoboCasa、真实机器人三种环境，均显示出一致的鲁棒性收益；单信号消融、注入/不注入消融和可视化分析也支撑了“结构化中间表示本身即可改善控制”这一判断。

整体上，该工作提供了一条架构无关、可复用的策略表示学习路径，对机器人学习中的特征归纳偏置设计具有较强参考价值。其主要限制在于结构化标签与几何教师获取成本较高，且三类先验结构对任务形态的覆盖仍有边界。未来若能降低标签获取成本、自动发现任务相关结构或扩展到更广泛的本体和接触/力觉模态，GIFT 的落地潜力会进一步增大。
