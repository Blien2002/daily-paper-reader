## 摘要
潜在世界-动作模型通过在特征空间中预测与动作相关的视觉子目标，避免了渲染未来像素。LaWAM 确立了这一范式，但其原始呈现将世界模型、多模态骨干和部署检查点紧密耦合。我们引入了 AcrossWAM1.0，这是对该潜在世界-动作栈的模块化与规模研究。与其将潜在子目标作为一种新算法呈现，我们明确模块边界：策略适配器生成潜在动作和动作生成上下文；保留的潜在世界解码器将预测的转变锚定在当前场景中；流匹配专家生成连续动作块。我们进一步将仅用于训练的教师模型与推理图分离，并提供可验证的部署导出。在 2000 个配对的 LIBERO 回合中，用 Qwen3.5-0.8B 替换 Qwen3-VL-2B 骨干得到 97.45% 的成功率，而 2B 模型为 98.00%（相差 -0.55 个百分点；精确 McNemar p=0.266）。这并不能证明等效性，但满足预设的两百分点保留标准。紧凑的、推理可达的检查点包含 1,472.6M 个唯一参数，比原始 2B 策略少 42.4%，而所有保留的张量都与源检查点逐位相同。此外，通过 MiniCPM-V 适配器冒烟测试检查了跨系列执行；闭环跨系列迁移仍是一个待评估的开放问题。因此，AcrossWAM1.0 为紧凑型潜在世界-动作策略贡献了一个可审计的软件与评估边界，这与 LaWAM 最初的潜在子目标贡献不同。

## Abstract
Latent world-action models avoid rendering future pixels by predicting an action-relevant visual subgoal in feature space. LaWAM established this formulation, but its original presentation left the world model, multimodal backbone, and deployment checkpoint tightly coupled. We introduce AcrossWAM1.0, a modularization and scaling study of this latent world-action stack. Rather than presenting latent subgoals as a new algorithm, we make the module boundary explicit: a policy adapter produces latent-action and action-generation contexts; a retained latent world decoder grounds the predicted transition in the current scene;and a flow-matching expert generates continuous action chunks. We further separate training-only teachers from the inference graph and provide a verifiable deployment export. On 2,000 paired LIBERO episodes, replacing a Qwen3-VL-2B backbone with Qwen3.5-0.8B yields 97.45% success versus 98.00% for the 2B model (a-0.55percentage-point difference; exact McNemarp=0.266). This does not prove equivalence, but it meets a prespecified two-point retention criterion. The compact, inference-reachable checkpoint contains 1,472.6M unique parameters, 42.4% fewer than the original 2B policy, while all retained tensors are bitwise identical to the source checkpoint. Cross-family execution is additionally checked with a MiniCPM-V adapter smoke test; closed-loop cross-family transfer remains an open evaluation. AcrossWAM1.0 therefore contributes an auditable software and evaluation boundary for compact latent world-action policies, distinct from LaWAM's original latent-subgoal contribution.

## 1. 论文核心问题与整体含义

- **研究背景**：机器人操作策略正在从纯 VLA（视觉-语言-动作）向世界-动作模型演进。LaWAM 提出在特征空间中预测潜在视觉子目标，避免渲染未来像素，实现了高效的动力学感知控制。
- **核心问题**：LaWAM 虽然验证了潜在子目标的有效性，但其原始实现将世界模型、多模态骨干和部署检查点紧密耦合，导致难以替换骨干、难以验证部署参数是否被正确移除，也难以审计模块边界。
- **整体含义**：AcrossWAM1.0 不主张新的潜在子目标算法，而是把 LaWAM 的“算法”转化为一个可审计、可缩放、可部署的**软件与评估边界**。论文的核心贡献是系统层面的模块化设计，而不是算法创新。

## 2. 方法论

AcrossWAM1.0 将潜世界-动作计算拆成明确模块，并区分训练专用与推理可达组件。

- **总体概率分解**（式 1）：  
  \(p(a, \hat{h}_{t+\Delta}, z_t \mid o_t, \ell, s_t) = p_\theta(z_t \mid o_t, \ell)\, p_\omega(\hat{h}_{t+\Delta} \mid h_t, z_t)\, p_\eta(a \mid c_\theta, h_t, \hat{h}_{t+\Delta}, s_t)\)  
  其中 \(h_t\) 是冻结 DINOv3 的 patch 特征，\(z_t\) 是潜在动作，\(\hat{h}_{t+\Delta}\) 是潜在视觉子目标，\(a\) 是动作块。
- **Stage 1：学习动作承载的潜在世界模型**
  - 使用冻结 DINOv3 编码器提取当前和未来帧特征。
  - 逆动力学 Q-Former 从两个时间点的特征对中输出 32 维高斯潜在动作 \(z_t\)。
  - 潜在世界解码器 \(D_\omega\) 以当前特征 \(h_t\) 和 \(z_t\) 为条件，通过 AdaLN 调制（式 3-4）预测未来特征 \(\hat{h}_{t+\Delta}\)。
  - 损失包括未来特征 SmoothL1 损失、可选状态位移损失、以及 KL 正则项（式 5）。
- **Stage 2：从语言与视觉预测潜在动作**
  - 骨干网络为 Qwen 系列多模态模型，接收指令、主视图、可选手腕/辅助视图。
  - 查询分为两组：8 个 latent-action queries（推理 transition）和 8 个 flow queries（提供动作专家上下文）。
  - 单查询交叉注意力将 latent-action query 的隐藏状态压缩为预测潜在动作 \(\hat{z}_t\)。
  - 使用蒸馏损失 \(L_\text{distill}\) 对齐预测潜在动作与 Stage 1 教师 \(z_t^*\)；子目标损失 \(L_\text{subgoal}\) 对齐预测未来特征与真实未来特征。
- **流匹配动作专家**
  - 采用条件 DiT 作为动作专家，以骨干上下文和拼接的当前/预测未来视觉 token 为条件。
  - 流匹配通过线性插值 \(a_\tau = (1-\tau)a_0 + \tau a_1\) 构造路径，用向量场回归（式 9）训练网络 \(v_\eta\)。
  - 测试时用 ODE solver 从高斯噪声积分生成动作块，配置为 50 步动作、10 次积分。
- **训练/部署边界**
  - 推理图仅包含骨干、潜在映射器、世界解码器、流匹配专家。
  - 训练专用模块（逆动力学教师、状态接地头、未来帧监督）在部署导出时被移除。
