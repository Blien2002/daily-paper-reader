## 摘要
冻结的视觉-语言-动作（VLA）策略提供了广泛的操控技能，但执行开环动作块而不跟踪任务进度，因此智能体无法可靠地决定是继续、重试还是终止。外部记忆是一种自然的补救方法，然而当将尝试的动作视为已完成进度时可能有害，将局部执行错误转化为持久的任务状态错误。我们提出成就接地记忆（AGM），一种用于冻结 VLA 策略的轻量级闭环框架，将任务表示为具有进度指针的子目标序列，并仅在当前子目标被物理证据验证后才推进该记忆。本体感受交互线索决定何时验证，而来自冻结基础模型、通过单个 2.43M 参数验证头的相干点跟踪和语言条件跨视图比较决定实现了什么。AGM 因此将开环执行转化为执行、验证和进度的闭环，保持策略冻结且无需测试时大模型推理。在 RoboMME Counting 基准上，AGM 在 PickXTimes 和 BinFill 上达到相应水平，平均超过最强记忆增强基线若干分，该框架在物理机器人上取得了同样决定性的提升。因此，可靠的具身记忆更依赖于有纪律的状态更新，而非记忆容量。

## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

- **研究背景**：冻结的视觉-语言-动作（VLA）策略虽具备广泛操控技能，但其执行是开环的，不跟踪任务进度，导致智能体无法可靠判断何时继续、重试或终止。
- **核心问题**：外部记忆是自然补救方案，但若将“尝试过的动作”误当作“已完成的进度”，就会把局部执行失败（如抓取失败、滑落、放置失败）转化为持久任务状态错误。因此，关键问题从“存什么”转变为“何时写入”。

## 2. 论文提出的方法论

## 7. 优点

- **轻量高效**：仅训练 2.43M 参数验证头，外部冻结参数 231M，远低于 4B 微调 VLM 基线。

- **跨骨干泛化**：同一 AGM 配置在不同 VLA 骨干（π0.5、π0）上均取得显著提升，无需重新调参。
- **真实机器人验证**：在物理平台上验证了框架有效性，且通过离线回放验证提前确认控制器逻辑。
- **工程细节完善**：附录提供完整超参数表、事件数据集构成、验证头结构、部署对齐分析等，复现性强。
- **问题洞察深刻**：明确提出并实验证明“尝试≠成就”，纠正了外部记忆设计的常见误区。

## 8. 不足与局限

- **验证词汇受限**：仅支持由抓取或释放事件包围的子目标，无法覆盖推动、滑动、关节物体操作、持续抓取下的工具使用等，对非抓取子目标（如 SwingXTimes、StopCube）无改进。
- **任务结构假设线性**：任务必须展开为有序子目标序列，不支持分支、部分有序或乱序满足的计划；回滚只能到关联抓取，不可逆性由类型标签固定，无法根据场景动态调整。
- **有界拒绝引入未验证写入**：为避免死锁而设置拒绝上限，达到上限时无论验证结果都会推进，可能将活锁失败转化为进度错误；虽然设定较小且阈值宽松，但不能完全消除未验证写入。
- **验证器质量约束**：所有写入依赖验证决策，验证器错误会直接影响任务性能；不可恢复放置的验证判别在辅助评估中较差，虽通过宽松阈值规避但本质仍是妥协。
- **物理评估范围有限**：仅两个任务家族、单一 6 自由度机械臂、单一夹爪几何和立方体物体类别；阈值需在硬件上重新校准，跨平台泛化未验证。
- **算力报告缺失**：未给出训练和推理的具体硬件配置、时间开销，影响资源需求的可评估性。
- **部分对照混杂**：表 10 中全指令无指针控制器使用不同训练设定的模型，与 AGM 和基于尝试控制器的 subgoal 条件模型并非完全同源，削弱了该特定对比的严格性。
- **泛化边界未深入**：虽然展示了 `N=5` 未在演示中的 BinFill 仍可泛化，但未系统研究不同物体、场景布局、光照等变化下的鲁棒性。
