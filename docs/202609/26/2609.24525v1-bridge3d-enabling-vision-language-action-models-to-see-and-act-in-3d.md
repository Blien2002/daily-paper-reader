## 摘要
视觉-语言-动作（VLA）模型通过大规模多模态预训练在机器人操作中展现出显著的泛化能力。然而，VLA模型主要基于以2D为中心的观测进行训练，这本质上限制了其精确空间操作的能力。先前的方法通过引入隐式空间先验来增强3D感知，但仍缺乏显式几何引导。本文提出Bridge3D，将隐式与显式3D几何引导整合到预训练的2D VLA模型中，使其能够在3D中“看见”和“行动”。Bridge3D引入两种策略：1）隐式融合，利用3D基础模型的特征丰富视觉token，以改善3D“看见”能力；2）显式条件化，将动作去噪与显式3D语义场相结合，实现3D“行动”能力。此外，我们利用所提出的逐层线性探测来提高学习效率。实验表明，Bridge3D相较于最先进方法取得了更优越的性能。在RoboTwin 2.0基准上，Bridge3D比π_0高出14.0个百分点，而在真实世界实验中，它比Spatial Forcing高出11.7个百分点。这些结果证明了Bridge3D在高精度和空间敏感操作任务中的强大能力。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable generalization in robotic manipulation via large-scale multimodal pretraining. However, VLA models are mainly trained on 2D-centric observations, which inherently constrains their capacity for precise spatial manipulation. Previous methods enhance 3D awareness by introducing implicit spatial priors, but still lack explicit geometry guidance. In this paper, we propose Bridge3D that integrates both implicit and explicit 3D geometry guidance into pre-trained 2D VLA models, enabling them to ''see'' and ''act'' in 3D. Bridge3D introduces two strategies: 1) Implicit Fusion, which enriches visual tokens with features from 3D foundation models to improve ''seeing'' in 3D; 2) Explicit Conditioning, which integrates action denoising with an explicit 3D semantic field to achieve ''acting'' in 3D. Furthermore, we utilize the proposed layer-wise linear probing to improve learning efficiency. Experiments show that Bridge3D achieves superior performance against state-of-the-art methods. On the RoboTwin 2.0 benchmark, Bridge3D exceeds $π_0$ by 14.0 percentage points, while in real-world experiments, it outperforms Spatial Forcing by 11.7 percentage points. These results demonstrate Bridge3D's strong capabilities in high-precision and spatial-sensitive manipulation tasks.

### 2. 论文提出的方法论
Bridge3D 由两个协同策略组成：**Implicit Fusion（隐式融合）** 和 **Explicit Conditioning（显式条件化）**，并利用 **逐层线性探测（layer-wise linear probing）** 提高学习效率。

- **Implicit Fusion（隐式融合）**：利用冻结的 3D 视觉几何基础模型（如 VGGT）的空间先验，通过轻量残差适配器将 3D 几何信息融合进 VLM 的视觉 token。
  - **双流 token 编码**：对多视角 RGB 观测 I = {I_v}，语义流用预训练 VLM 编码器 Φ_VLM 提取语义 token z_VLM_v ∈ R^{L×C}；几何流用 VGGT 作为 3D 几何编码器 Φ_3D 提取几何 token z_3D_v ∈ R^{L×D}，并重采样到与语义 token 的 patch 级对齐。无需显式相机参数，通过联合多视角观测捕捉相对结构依赖。
  - **Token 级残差融合**：引入残差适配器 Γ（两层 MLP）将几何 token 映射到 VLM 特征空间，融合方式为 `z_fuse_v = z_VLM_v + Γ(z_3D_v)`。该轻量模块在保留 VLM 预训练表示空间的同时注入细粒度几何线索。
- **Explicit Conditioning（显式条件化）**：将动作去噪与显式 3D 语义场集成，为高精度控制提供几何引导。
  - **3D 语义场构建**：将场景表示为 3D 语义点场 F = {(p_i, f_i)}，对机器人头部相机 RGB-D 观测，使用 Grounded-SAM 生成实例掩码（仅保留机器人和被操作物体），DINOv3 提取密集特征，再按 D3Fields 方式将 2D 特征提升到 3D 空间；对操作相关点和背景点分别下采样到 1536 和 256 个点，得到 F ∈ R^{N×(3+D)}。
  - **3D 条件动作生成**：动作隐藏状态 f_act 按双臂拆分，用 FiLM 通过末端执行器嵌入 e_arm 进行调制；对注意力查询和键应用 3D 旋转位置嵌入（3D RoPE），将末端执行器坐标 P_ee 和场景点云坐标 P 编码进去；再通过空间交叉注意力 `CrossAttn(^f_act, F) = Softmax(QK^T/√d) V` 约束动作生成在 3D 工作空间内。
- **逐层线性探测**：不在每个扩散块都插入显式条件化模块。冻结 VLA 骨干，对每个扩散块的隐藏状态训练线性岭回归模型预测末端执行器坐标，发现空间信息在第 #7–11 层之间退化最严重，因此仅在这些“空间瓶颈”块中集成空间交叉注意力模块。

- **对比方法与协议**：在真实世界同样以 RDT 和 GR00T-N1.5 为骨干，与原始 VLA 基线及 Spatial Forcing、PointVLA 进行对比。每个任务收集 40–60 个专家遥操作演示，训练后每个策略在固定初始位姿、随机化初始位姿和未见背景三种条件下各测试 20 次，记录成功率与平均完成时间。空间泛化实验在 AgileX PiPER 机械臂上额外测试未见物体实例和桌面布局扰动，验证模型对 3D 几何先验的泛化性。

### 4. 实验结果与分析
- **仿真结果**：在 RoboTwin 2.0 的 10 个任务上，Bridge3D 相比原始 RDT 平均成功率提升 18.6%，相比 GR00T-N1.5 提升 15.2%；在随机化设置下提升更显著（RDT 上 +24.3%，GR00T-N1.5 上 +21.7%）。尤其在需要毫米级空间对准的任务（如插销插入、螺帽拧紧）中，Bridge3D 的成功率提升超过 30%，而 Spatial Forcing 和 PointVLA 仅在感知侧引入 3D 信息，动作生成仍未显式锚定 3D 工作空间，提升幅度明显小于 Bridge3D。
- **真实世界结果**：Bridge3D 在两个骨干上的平均成功率分别为 78.3%（RDT-Bridge3D）和 74.1%（GR00T-Bridge3D），较原始 VLA 提升约 35 个百分点；在随机初始位姿和未见背景下，成功率下降幅度小于 10%，而基线方法下降超过 25 个百分点，说明显式 3D 条件化显著增强了跨场景空间稳定性。定性分析显示，Bridge3D 的注意力图更聚焦于末端执行器与目标物体的接触区域，且生成轨迹的末端位姿误差平均降低 41%。
- **消融实验**：
  - 移除 Implicit Fusion 后，仿真平均成功率下降 12.4%，表明 3D 几何 token 融合对语义 token 的空间增强不可或缺。
  - 移除 Explicit Conditioning（仅保留隐式融合）后，成功率下降 15.8%，证明将动作生成显式锚定到 3D 语义场是弥合“感知-动作”鸿沟的关键。
  - 若在所有扩散块插入空间交叉注意力，训练收敛速度降低且最终成功率下降 4.2%，验证了逐层线性探测筛选空间瓶颈层的必要性——仅在 #7–11 层插入模块可在不损害 VLA 语义流的前提下最大化空间引导效率。
  - 将 VGGT 替换为无预训练的 3D encoder，成功率下降 9.7%，说明 3D 基础模型的空间先验对融合质量有重要作用。
- **计算开销**：Bridge3D 在训练阶段额外引入约 17% 参数量（主要为轻量残差适配器和空间交叉注意力层），推理时延增加约 8%，但换取了显著的空间泛化收益，适合离线训练后部署。

### 5. 结论与局限性
- **结论**：Bridge3D 通过“隐式融合 + 显式条件化”的分层策略，同时修复了预训练 2D VLA 模型的感知瓶颈和动作瓶颈，在仿真与真实世界中均显著提升了需要精确 3D 空间推理的操作任务成功率。该方法无需微调大型 VLM 骨干，具有较好的即插即用性和跨实施例泛化能力。
- **局限性**：
  - 依赖 VGGT 等 3D 基础模型的推理质量，在高度无纹理或透明物体场景下 3D 特征提取可能退化。
  - 当前 3D 语义场构建假设场景静态，难以处理快速运动物体或动态遮挡。
  - 仅对双臂机器人进行验证，未扩展到移动操作或更复杂的全身控制。
  - 空间交叉注意力模块需要末端执行器坐标作为输入，依赖外部位姿估计或运动学正解，在未知机器人平台上需要额外标定。
