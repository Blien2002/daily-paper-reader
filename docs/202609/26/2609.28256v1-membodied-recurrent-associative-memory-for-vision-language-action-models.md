## 摘要
视觉-语言-动作模型为通用机器人控制提供了坚实基础，然而绝大多数策略并未保留和利用当前观测之外的任务片段级信息。这一局限在依赖历史信息的操作任务中影响显著，这些任务所需的信息仅存在于过去的观测中。在上下文中保留过去观测有助于恢复这些信息，但代价是不断增长、臃肿的上下文和推理延迟。因此，我们提出了 MemBodied，一种固定大小的片段式记忆，包含两个互补组件：联想状态，记录策略调用之间的交互；以及片段锚点，以紧凑表示保存初始场景作为参考。在每次策略调用时，模型以当前输入和记忆组件为条件生成动作，而不是直接使用过去的观测。在五个需要记忆的 RMBench 评估任务中，MemBodied 的平均成功率达到了无状态策略的 7.81 倍、普通循环记忆的 2.98 倍，同时以少 10 倍的额外参数超越最强的记忆增强基线 1.3 倍。在完全可观测的 LIBERO-Long 套件上，它达到了 90.6%，比无状态 π₀ 策略提高了 5.4%。这些结果表明，MemBodied 是扩展策略上下文以处理历史依赖操作的一种实用替代方案。

## Abstract
Vision-Language-Action models provide a strong foundation for general-purpose robot control, yet a vast majority of policies do not preserve and leverage episode-level information beyond the current observation. This limitation is consequential in history-dependent manipulation tasks that depend on information available only in past observations. Retaining past observations in context can aid in recovering this information, but at the significant cost of ever-growing, bloated context and inference latency. We thus introduce MemBodied, a fixed-size episodic memory with two complementary components: an associative state that records interactions across policy calls and an episode anchor that preserves a compact representation of the initial scene as a reference. At each policy call, the model conditions action generation on the current input and the memory components, rather than directly using past observations. Across five evaluated RMBench tasks requiring memory, MemBodied achieves $7.81\times$ the mean success rate of a stateless policy and $2.98\times$ of vanilla recurrent memory, while outperforming the strongest memory-augmented baseline by $1.3\times$ with $10\times$ fewer added parameters. On the fully observable LIBERO-Long suite, it reached 90.6%, a 5.4% improvement over the stateless $π_0$ policy. These findings support MemBodied as a practical alternative to expanding the policy context for history-dependent manipulation.

# 论文总结：MemBodied

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型在机器人控制中表现优异，但大多数策略仅以当前观测和语言指令为条件生成动作，丢弃了历史观测信息。
- **问题本质**：许多操作任务依赖“仅存在于过去观测中”的信息（例如物体初始位置、已尝试过的组合等），当前观测不足以确定正确动作，产生**时间状态混叠**。
- **现有方案的局限**：直接保留完整历史会导致上下文长度、内存和推理成本随片段增长；固定窗口可能丢失关键证据；压缩历史、循环隐状态或记忆库等方法存在上下文膨胀、隐式表征或额外训练目标等问题。
- **本文目标**：提出一种**固定大小**的情景记忆，既能保留交互历史和初始场景信息，又不增加策略上下文长度，且仅通过动作目标端到端训练。

## 2. 方法论

### 2.1 总体框架

- 记忆由两部分组成：**循环联想状态** \(M_t\)（记录跨策略调用的交互）和**片段锚点** \(A\)（固定保存初始场景的紧凑参考）。
- 在策略调用 \(t\)，模型以当前观测 \(I_t\)、机器人状态 \(s_t\)、语言指令 \(\ell\) 和上一时刻记忆 \(E_{t-1}\) 为条件，预测动作块 \(a_t\)。
- 记忆在片段开始时重置，锚点由第一帧构建并在片段内保持不变。

### 2.2 关联记忆机制

- 每个动作网络层 \(l\) 维护一个关联矩阵 \(S^{(l)}_t \in \mathbb{R}^{r \times r}\)（\(r=128\)），大小固定，不随片段增长。
- **写值构建**：将执行动作后的视觉观测编码与动作块聚合拼接，得到转移表示 \(y_t\)，再投影为各层写值 \(v^{(l)}_t\)。
- **门控 delta 规则写更新**：
  - 写键 \(k^{(l)}_t\) 由层输出 \(h^{(l)}_{t,out}\) 经 L2 归一化得到。
  - 保留门 \(\alpha^{(l)}_t\) 和写入门 \(\beta^{(l)}_t\) 由 \([h^{(l)}_{t,out}; y_t]\) 计算。
  - 状态更新为：\(S_t = \mathrm{Diag}(\alpha_t)S_{t-1} + \mathrm{Diag}(\beta_t)(v_t - \mathrm{Diag}(\alpha_t)S_{t-1}k_t)k_t^\top\)，既能保留已有关联，也能修正与新键相关的旧值，避免无差别累积。
- **读操作**：以进入层的状态表示 \(h^{(l)}_{t,in}\) 构造查询 \(q^{(l)}_t\)，读出 \(r^{(l)}_t = S^{(l)}_{t-1} q^{(l)}_t\)。

### 2.3 记忆读出与变体

- 比较了三种将读出向量注入动作网络的方式：
  - **注意力引导（MemBodied-AS）**：将读出投影为对注意力查询和输出的加法修正。
  - **层级记忆（MemBodied-H）**：在门控 delta 状态之上增加一个受遗忘门控制的 LSTM 式慢速循环矩阵。
  - **记忆 token 注入（MemBodied）**：将读出投影后加到专用“记忆 token”上，再参与自注意力，使读出内容作为上下文供动作 token 使用。
- 在 MemBodied 主变体中，记忆 token 每步重新创建，循环状态由关联矩阵承载；读出缩放因子为 \(\alpha_{mem}/r\)，并有标量门控 \(g^{(l)}_t\) 控制贡献。

### 2.4 片段锚点

- 从第一帧观测中提取冻结视觉 token，将每相机的 16×16 patch 池化为 4×4，拼接形成锚点 \(A\)。
- 当前机器人状态通过交叉注意力查询锚点，得到上下文向量 \(c_t\)，投影后重复到整个动作 horizon，并与动作表示融合。
- 锚点不追加原始图像或完整 token 序列，保持前缀长度和注意力掩码不变。

### 2.5 训练流程

- 采用**延迟写入**：先读取 \(M_{t-1}\) 生成动作，执行后获得 \(I_{t+1}\)，再将“动作+视觉后果”写入 \(M_t\)，保证因果性。
- 因此需要**序列级训练**：每个样本包含 N 个观测-动作对，梯度贯穿整个序列，使后续动作损失能优化早期记忆操作；无需单独的记忆预测损失。

- **固定大小记忆**：不随片段长度增长，保持恒定推理成本，避免上下文膨胀。
