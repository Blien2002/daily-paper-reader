## 摘要
大型预训练视觉-语言-动作模型主导着现代机器人操作基准，但仍不清楚多大规模的模型对强语言条件控制是必要的，或者根本不同的控制架构能否在远更小的参数预算下保持竞争力。我们提出 PredVLA，一种语言条件的预测编码策略，其可训练网络参数仅为 68 万，且没有机器人数据预训练；其分层生成式循环动态预测视觉特征和本体感觉，而观测仅通过由感觉预测误差进行的在线推断影响潜在状态。在 LIBERO 上，PredVLA 在三个短时程套件上达到 86.9% 的平均成功率，在包含长时程套件时达到 75.4%。在采用相同冻结前端、演示、动作解码器和评估协议的控制比较中，PredVLA 的平均成功率分别是参数匹配 Transformer 和 LSTM 策略的 3.7 倍和 7.4 倍。预测编码公式还使得观测驱动校正的贡献可直接测量：因为观测仅通过基于预测误差的潜在推断影响循环状态，禁用该推断就产生精确的开环控制条件。总之，这些结果表明，一种亚百万参数的循环生成式策略能够在现代语言条件操作基准上取得强劲表现，同时提供一种明确的由预测误差驱动的在线状态校正机制。

## Abstract
Large pretrained vision-language-action models dominate modern robot-manipulation benchmarks, but it remains unclear how much model scale is necessary for strong language-conditioned control, or whether fundamentally different control architectures can remain competitive at much smaller parameter budgets. We present PredVLA, a language-conditioned predictive-coding policy with only 0.68 million trainable network parameters and no robot-data pretraining, whose hierarchical generative recurrent dynamics predict visual features and proprioception while observations influence latent state only through online inference from the resulting sensory prediction errors. On LIBERO, PredVLA achieves an 86.9% mean success rate across the three short-horizon suites and 75.4% when the long-horizon suite is included. Under a controlled comparison using the same frozen front end, demonstrations, action decoder, and evaluation protocol, PredVLA achieves 3.7x and 7.4x mean success rates of parameter-matched Transformer and LSTM policies, respectively. The predictive-coding formulation also makes the contribution of observation-driven correction directly measurable: because observations influence the recurrent state only through prediction-error-based latent inference, disabling this inference yields an exact open-loop control condition. Together, these results show that a sub-million-parameter recurrent generative policy can achieve strong performance on modern language-conditioned manipulation benchmarks while providing an explicit mechanism for prediction-error-driven online state correction.

## 2. 方法论

PredVLA 的核心是把预测编码引入机器人控制：**观测从不直接输入循环动力学，只通过预测误差的在线推断来修正潜在状态**。

### 2.1 冻结多模态前端

- 语言：使用 pretrained `all-MiniLM-L6-v2` 编码，再经固定 PCA 投影，从 384 维降到 64 维。
- 视觉：两个相机视图（第三人称 agentview、手腕眼-in-hand）分别用冻结的 ImageNet-pretrained ResNet18 编码，每视图 512 → 96 维，拼接为 192 维视觉观测。
- 本体感觉：关节角与夹爪状态，共 9 维，直接使用。
- PCA 基在训练演示上拟合后固定，所有模型共用。

### 2.2 分层循环生成模型

- 可训练控制器由 4 个循环模块组成：共享顶层模块 `T`、视觉分支 `V`、动作分支 `A_top` 和 `A_bottom`。
- 层级结构：`T → V`、`T → A_top → A_bottom`，并带有视觉到动作的瓶颈 `V → A_top`，以及动作到视觉的回传（efference copy）`A → V`。
- 每个模块维护确定性状态 `h_t`、输出 `d_t = tanh(h_t)` 和潜在自由变量 `c_t`。
- 非根模块的**先验**由父模块输出生成：
  `c^l_{p,t} = W_pri^l d_parent_t + b_pri^l`；
  顶层模块的先验由其自身上一时刻输出循环生成。
- 状态更新使用**多时间常数循环动力学**：
  `h^l_t = (1 - 1/τ_l) h^l_{t-1} + 1/τ_l tanh(W_rec d_{t-1} + W_td d_parent_t + U_l c^l_{q,t} + β^l_t + b_l)`。
- 短时程套件的时间常数 `(T,V,A_top,A_bottom) = (16,8,5,2)`；长时程套件为 `(30,14,8,2)`。
- 语言只通过顶层模块的 `W_lang l` 进入，作为 episode 级条件。
- 动作由 5 个高斯混合组件构成的头部输出，执行时取最高权重组件均值。

### 2.3 自由能目标与训练

- 自由能目标由**准确性项 + 复杂性项**组成：
  `E(I) = Σ_{t∈I} [λ_v ε_v(t) + λ_q ε_q(t) + C_t]`。
- 视觉和本体感觉预测误差为逐维 MSE；复杂性项是后验自由变量与先验的二次惩罚。
- 训练时后验自由变量作为可优化参数，与网络权重一起通过 BPTT 联合优化；训练损失额外加入动作负对数似然，但动作项不会出现在测试的自由能中。
- 训练完成后丢弃后验自由变量，只保留网络权重。

### 2.4 测试时误差回归与精确开环

- 测试时冻结网络权重，只更新后验自由变量。
- 在长度为 **W=40** 的滑动时间窗内，进行 `nitr=10` 次 Adam 更新（步长 0.05），每次更新后重新生成确定性状态轨迹。
- **精确开环控制**：设置 `nitr=0` 时，后验等于先验，所有观测都不再影响循环计算，得到无需重训练、不改变语言条件的开环对应策略。
