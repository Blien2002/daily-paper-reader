## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表示进行机器人控制，然而仅仅添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能需要根据先前的执行采取不同的动作。为了解决这一挑战，我们提出了 TemporalFlow-VLA，它通过物理基础的时序监督学习紧凑的执行历史。利用记录的机器人状态、机器人几何结构和标定相机，我们构建机器人-表面时间流作为仅训练目标，并监督两个执行对齐的时间查询，为动作专家提供结构化历史。几何监督路径在部署时不被评估。TemporalFlow-VLA 在 LIBERO 上达到 97.63 ± 0.26% 的平均成功率，其中在 LIBERO Long 上达到 96.60 ± 0.87%，在 12 个 RoboTwin 任务上 Clean/Randomized 成功率分别为 85.5%/84.2%。与先前方法相比，它在更长时域、多阶段操作上表现出最明显的优势。受控历史干预表明，动作预测依赖于历史内容和时间顺序。借助异步特征缓存，时间条件化在服务器端保持单帧级采样延迟，且无需额外的历史编码开销。总体而言，TemporalFlow-VLA 提供了一种紧凑、物理基础的接口，用于利用有序执行历史，而无需在部署时进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

- **研究背景**：视觉-语言-动作（VLA）模型将预训练视觉-语言表示迁移到机器人控制，但许多代表性 VLA 仍主要依据当前 RGB 观测、语言指令和机器人状态生成动作块。

## 2. 论文提出的方法论

### 2.1 总体思路

- TemporalFlow-VLA 在预训练 VLA 策略中引入一条并行时间通路，同时保留原有动作生成路径。
- 基础策略仍从当前 RGB、语言指令、机器人状态和扩散时间步预测动作块；时间通路额外接收来自头部相机的 \(t-15\)、\(t-8\)、\(t\) 三帧观测。
- 对 16 步动作块而言，\(t-15\) 和 \(t-8\) 大致对应上一块的开头和中间时刻。
- 时间通路围绕两个可学习的时间查询 \(Q_8\) 和 \(Q_{15}\) 构建：
  - \(Q_8\) 表示 \(t-8 \to t\) 的近期运动；
  - \(Q_{15}\) 表示 \(t-15 \to t\) 的完整演化，并可进一步利用 \(Q_8\) 的短期摘要。
- 动作 token 只能通过这两个查询获得历史信息，不能直接访问历史图像 patch。

### 2.2 物理接地的机器人-表面时间流

- 目标：监督“机器人运动在 RGB 图像中如何呈现”。
- 对每个时间间隔 \(\rho \in \{8,15\}\)，设 \(s = t-\rho\)。
- 利用关节配置 \(q_\tau\)、连杆到基座的齐次运动学变换、标定的基座到相机外参，以及内参投影，将源时刻机器人可见表面对应的像素点从源图像投影到目标时刻图像。
- 通过机器人自渲染器获得可见机器人像素及其所属连杆，将源图像中的点变换到目标时刻，再投影回目标图像；只有投影在图像内、属于同一连杆且 3D 残差不超过 5 mm 的对应关系才保留。
- 将有效位移归一化到 224×224 图像坐标系，并在非重叠的 14×14 patch 内做掩码算术平均，得到 16×16×2 的流监督目标 \(F_\rho\)。
- 只有当某个 patch 中有效机器人像素占整个 patch 面积的比例 \(c_\rho(k) \ge 0.1\) 时，该 patch 才参与损失计算。
- 该监督路径仅用于训练，部署时不需要运动学渲染器、流重建头或额外传感器。

### 2.3 层次化时间查询与联合注意力

- 可学习 token \(q_8\)、\(q_{15}\) 被追加到标准 \(\pi0.5\) 前缀中，前缀包含当前图像 token、语言 token 和当前机器人状态输入。
- 对历史 patch \(V_{15}\)、\(V_8\) 添加可学习帧身份嵌入。
- 通过有向注意力掩码组织层次结构：
  - \(Q_8\) 只能读取语言 token、\(t-8\) 观测、当前观测和自身；
  - \(Q_{15}\) 还可以读取 \(t-15\) 观测和 \(Q_8\)；
  - 即 \(Q_8 \to Q_{15}\) 单向连接，使 \(Q_{15}\) 能在短期运动摘要基础上整合更长历史。
- 动作 token 在现有联合掩码自注意力中只能通过 \(Q_8\) 和 \(Q_{15}\) 获得历史视觉信息，无法直接读取 \(V_8\)、\(V_{15}\)。
- 每个时间查询对应一个查询条件解码器 \(D_\rho(V_\rho, z_\rho)\)：
  - 查询向量通过 FiLM 方式调制源帧空间特征；
  - 再用逐点两层 MLP 预测流；
  - 两个解码器不共享参数，不使用卷积或上采样。
- 流损失只在有效掩码 \(M_\rho=1\) 的 patch 上计算 Huber 损失。
- 最终训练目标为：
  \[
  L = L_{\text{action}} + \lambda_{\text{temp}} L_{\text{temp}},\quad \lambda_{\text{temp}}=1.0
  \]
  其中 \(L_{\text{temp}} = \frac{1}{2}(L_8^{\text{flow}} + L_{15}^{\text{flow}})\)。

### 2.4 异步历史特征缓存

- 为避免同步编码 \(t-15\)、\(t-8\)、\(t\) 三帧带来的额外视觉前向开销，采用带时间戳的环形缓存：
  - 在机器人执行当前动作块期间，后台进程异步提取并存储历史观测的视觉特征；
  - 重规划时，\(t-15\) 和 \(t-8\) 的特征直接从缓存读取，只有当前帧同步编码。
- 同步延迟从：
  \[
  T_{\text{naive}} = 3T_{\text{vision}} + T_{\text{joint}} + T_{\text{action}}
  \]
  降低为：
  \[
  T_{\text{cache}} \approx T_{\text{vision}} + T_{\text{joint}} + T_{\text{action}}
  \]
- 缓存只移除同步历史图像编码，时间查询仍保留在联合 transformer 中。
- 在 episode 开始时，若所需历史 token 不足，则用最早观测填充并标记无效，直到缓存可用。
