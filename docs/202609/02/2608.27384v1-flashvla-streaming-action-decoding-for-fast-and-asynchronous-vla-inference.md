## 摘要
视觉-语言-动作（VLA）模型在机器人操作中日益展现出前景，但其实际部署仍受高推理延迟和不稳定异步执行的瓶颈制约。这一挑战在基于流匹配的 VLA 模型中尤为突出，因为动作解码需要以 VLM 上下文为条件进行多次迭代步骤。虽然高效推理方法可提高控制频率，异步方法可减少执行空闲时间，现有方法往往难以同时实现低延迟推理和准确、时间一致的异步执行。我们提出 FlashVLA，一个流式动作解码框架，以统一形式应对这两个挑战。FlashVLA 维护一个流式动作缓冲区，其中包含多个处于不同噪声水平的块，并使用逐块因果注意力对其进行解码。这种设计使 FlashVLA 能够在每个推理步骤生成一个可执行动作块。此外，其逐块自回归形式隐式保持动作连续性，无需额外未来状态条件即可实现平滑异步执行。在大量仿真和真实世界实验中，FlashVLA 大幅提升推理速度，同时保持较强任务性能。在实际部署中，它可在单个 GPU 上实现≥30 Hz 的控制频率，并具有平滑的异步推理。

## Abstract
Vision-Language-Action (VLA) models are increasingly promising for robotic manipulation, yet their real-world deployment remains bottlenecked by high inference latency and unstable asynchronous execution. This challenge is particularly pronounced in flow-matching-based VLA models, where action decoding requires multiple iterative steps conditioned on the VLM context. While efficient inference methods improve control frequency and asynchronous methods reduce execution idle time, existing approaches often fail to jointly achieve low-latency inference and accurate, temporally consistent asynchronous execution. We introduce \textbf{FlashVLA}, a streaming action decoding framework that addresses both challenges in a unified formulation. FlashVLA maintains a streaming action buffer with multiple chunks at different noise levels and decodes them using chunk-wise causal attention. This design allows FlashVLA to produce one executable action chunk per inference step. Moreover, its chunk-wise autoregressive formulation implicitly preserves action continuity, enabling smooth asynchronous execution without extra future-state conditioning. Across extensive simulated and real-world experiments, FlashVLA substantially improves inference speed while maintaining strong task performance. It can achieve $\geq$30\,Hz control frequency on a single GPU with smooth asynchronous inference in real-world deployment.

## 1. 论文的核心问题与整体含义

- **核心问题**：视觉-语言-动作（VLA）模型在真实机器人部署中面临两大瓶颈——高推理延迟与异步执行不稳定。
- **背景与动机**：
  - 基于流匹配的 VLA 模型（如 π0.5）动作解码通常需要 10 步顺序去噪，仅动作解码就占单步推理时间的 **75%**。
  - 同步推理会让机器人在每个动作块边界停顿等待；异步推理虽可重叠预测与执行，但从“过期观测”预测动作，导致预测-执行不匹配，且前瞻越长，失配越大。
  - 现有方法往往只解决其中一面：高效推理方法只降低单次前向成本，异步方法需要额外未来状态条件或planned actionconditions，仍未统一实现低延迟与时间一致。
- **整体含义**：FlashVLA 通过一个统一的结构性改变——**联合而非孤立地解码动作块**——同时消除延迟成本与异步失配成本。

## 2. 方法论

### 2.1 核心思想
- 将动作解码从“每个块独立从纯噪声解码”改为“维护一个流式动作缓冲区，其中多个块处于不同噪声水平，联合解码”。
- 灵感来自长视频生成中的流式逐块扩散（streaming chunk-wise diffusion）。

### 2.2 关键技术细节
- **流式缓冲区（Streaming Buffer）**：
  - 缓冲区包含 \(N\) 个动作块，噪声水平单调递增：\(\tau_1 < \tau_2 < \dots < \tau_N\)。
  - 第一个槽位接近干净、即将执行；最后一个槽位是纯噪声、未来执行。
  - 单个前向传播将每个块推进一个去噪步骤；预热后每步弹出一个可执行块。
- **逐块因果注意力（Chunk-wise Causal Attention）**：
  - 后续（噪声更大）的块可以关注前面（更干净）的块，反之则不行。
  - 信息沿时间向前流动，但不沿噪声反向传播。
  - 这样，未来块在解码时隐式条件于即将执行轨迹，无需显式未来状态预测器或动作条件模块。
- **三个运行时性质**：
  1. **摊销去噪**：每个块仍经过全部 \(N\) 个噪声水平，但 \(N\) 次前向分摊到 \(N\) 个不同推理步骤，单步动作解码延迟最高降低约 **20×**。
  2. **隐式异步条件**：未来块关注近执行块，异步连续性成为解码器的结构属性。
  3. **块级记忆**：高时间步块关注所有更早的块，形成最近精炼块的短历史，对长时程任务尤其有利。
- **推理流程**：
  - **冷启动**：缓冲区为空时，先运行 \(N-1\) 步填充，期间执行安全默认动作（保持静止）；该开销在整个回合中摊销。
  - **稳态流式**：每步推进所有块、弹出最干净块执行、剩余块前移、末尾追加新纯噪声块（见论文 Algorithm 1）。
- **系统级优化**：CUDA Graph 编译、线性层打包、PyTorch max-autotune，进一步消除内核启动开销。

### 2.3 训练方法：多缓冲联合微调（Multi-Buffer Joint Fine-tuning）
- 预训练 VLA 只见过孤立去噪，未见过部分填充缓冲区和因果注意力。
- **挑战**：单一观测对应 \(N\) 种不同缓冲配置（从 1 个真实块到 \(N\) 个真实块）。
- **解决方案**：
  - 将全部 \(N\) 种缓冲配置打包进一个训练样本，共享同一观测编码，注意力掩码隔离不同缓冲。
  - 训练目标为标准流匹配损失之和（论文公式 3）：
    \[
    L_{joint} = \sum_{j=1}^{N}\sum_{i=1}^{j} \mathbb{E}_{\tau_i,z_i}\left[ \left\| v_\theta(x^{(i)}_{\tau_i},\tau_i \mid o_t, B_t^{(j)}) - (z_i - a^{(i)}) \right\|_2^2 \right]
    \]
  - 覆盖冷启动与稳态行为。
- **架构改动**：用 FiLM 增强动作专家中的多级时间步条件；必要时重新初始化动作专家的归一化层以稳定微调。
