## 摘要
在语言中推理使基础模型能够在困难问题上花费更多测试时计算，例如需要分解、约束跟踪和预测未来后果的问题。这种机制能否改善机器人操作仍不清楚，其中长时程任务需要跟踪部分进展、推理物体关系、从错误中恢复，并引导有噪声的低层策略。在本文中，我们研究是否可以训练视觉语言模型（VLM）直接以自然语言进行推理，以引导低层操作策略。我们引入了 $R^3$，一种简单的后训练方案，可将现成的 VLM 转变为机器人推理器：它首先在专家生成的推理轨迹上对 VLM 进行中期训练，以初始化所需的推理风格，然后利用离线动作数据进行基于单步评分准则的强化学习来改进推理器。与以往主要使用结构化轨迹作为辅助监督的机器人推理方法不同，$R^3$ 训练自由形式的语言推理，为动作生成测试时引导。我们在 Language Table 和模拟双臂杂货打包这两个受控测试平台上实例化 $R^3$，用于研究机器人推理和长时程操作。$R^3$ 改善了在未见任务上的探索和泛化能力，并在两个基准上显著优于仅指令模仿学习基线。我们的分析表明，自由形式语言推理可以作为引导低层策略的测试时计算机制。项目主页见 https://robotic-reasoner.github.io/。

## Abstract
Reasoning in language allows foundation models to spend more test-time compute on hard problems, such as those requiring decomposition, constraint tracking, and prediction of future consequences. Whether this mechanism can improve robotic manipulation remains unclear, where long-horizon tasks require tracking partial progress, reasoning about object relations, recovering from mistakes, and steering noisy low-level policies. In this paper, we study whether VLMs can be trained to reason directly in natural language to guide low-level manipulation policies. We introduce $R^3$, a simple post-training recipe that turns off-the-shelf VLMs into robotic reasoners: it first mid-trains a VLM on expert-generated reasoning traces to initialize the desired reasoning style, then improves the reasoner with single-step rubric-based RL from offline action data. Unlike prior robotic reasoning methods that mostly use structured traces as auxiliary supervision, $R^3$ trains free-form language reasoning to produce test-time guidance for action. We instantiate $R^3$ on Language Table and simulated bimanual grocery packing, two controlled testbeds for studying robotic reasoning and long-horizon manipulation. $R^3$ improves exploration and generalization across unseen tasks and significantly outperforms instruction-only imitation learning baselines on both benchmarks. Our analyses suggest that free-form language reasoning can function as a test-time compute mechanism for steering low-level policies. Our project page is available at https://robotic-reasoner.github.io/.

- **核心问题**：能否训练视觉语言模型（VLM）直接以自然语言进行推理，为低层机器人操作策略生成测试时引导，从而提升长时程任务中的探索、泛化与错误恢复能力。
- **整体含义**：论文提出一个两阶段后训练方案 $R^3$，将现成 VLM 转化为“机器人推理器”：高层 VLM 生成自由形式推理和短时程指令，低层固定策略执行动作。该框架将专家动作数据转化为推理监督信号，避免昂贵的在线机器人 rollout。

## 2. 论文提出的方法论

### 2.1 整体架构
- 采用分层控制结构：
  - 高层 VLM $\pi_\theta(z_t,u_t|x_t,g)$：输入当前图像、长时程目标 $g$ 和交互历史 $x_t$，输出推理轨迹 $z_t$ 和短时程指令 $u_t$。
  - 低层预训练策略 $\pi_{lo}(a_t|s_t,u_t)$：接收指令并输出底层动作 $a_t$，执行固定长度动作块。
- 训练目标：让高层 VLM 先推理场景、进度和动作后果，再发出指令引导低层策略。

### 2.2 数据收集
- **Language Table 环境**：
  - 设计 14 种长时程积木排列任务，要求组合物体移动、空间关系推理和几何难度递进。
  - 使用 Gemini 3 Flash 作为“人类专家”推理器，在 64 个场景中收集多轮交互轨迹，记录推理和指令。
  - 数据分为两个子集：
    - **带专家推理轨迹的子集**：用于 Stage I 中期训练。
    - **仅专家指令的子集**：用于 Stage II 强化学习，模拟“推理标注昂贵、指令标注易得”的实际约束。
  - 发现加入历史上下文能提升专家性能，因此历史采用上一步完整响应。
- **双手杂货打包环境**：
  - 使用人类遥操作数据，无推理标注，仅按片段标注短时程指令。
  - 从片段中采样帧，过采样子任务开始和即将完成阶段，略过过渡尾部。

### 2.3 Stage I：中期训练（Mid-Training）
- **目标**：初始化 VLM 的推理风格，使其具备分解、约束跟踪、自我纠正等能力。
- **做法**：在带专家推理的轨迹上用标准 next-token prediction 训练。
- **损失函数**：
  $$\mathcal{L}_{SFT}(\theta) = -\mathbb{E}_{(x_t,y_t)\sim\mathcal{D}_{SFT},i\sim\text{Unif}}\left[\log p_\theta(y_{t,i}|x_t,y_{t,<i})\right]$$
  其中 $y_t=(z_t,u_t)$ 为推理和指令拼接序列。
- 同时使用成功和不成功轨迹，以学习部分进度、错误与恢复行为。

### 2.4 Stage II：基于评分准则的单步强化学习（Rubric-Based Single-Step RL）
- **动机**：中期训练只初始化行为，不能保证推理在测试时有效；在线多轮 RL 面临长时程信用分配困难和低层策略噪声。
- **数据形式**：仅包含交互历史 $x_t$ 和专家指令 $u_t^\star$，无专家推理。
- **采样与奖励**：
  - 从策略 $\pi_\theta$ 采样 $K$ 个候选响应 $(z_t,u_t)$。
  - 奖励包含两部分：
    - 指令准确性奖励 $R_{acc}$：
      - Language Table 使用 VLM-as-a-judge，按语义匹配程度给 1.0（完全语言匹配）、0.5（副词不匹配）、0.25（语义匹配）、0.0（不匹配）。
      - 杂货打包使用字符串精确匹配：1.0（指令完全一致）或 0.0。
    - 长度惩罚 $R_{len}\le 0$：防止过短退化响应。
  - 总奖励 $R=R_{acc}+R_{len}$。
- **优化算法**：使用 Dr.GRPO 进行策略梯度更新。
- **关键设计**：
  - 推理上下文插补：缺失上一步推理时，从中期训练模型采样多个响应，若某响应指令与专家一致则用作历史。
  - 过滤重复步骤：移除重复上一步指令的数据，防止奖励捷径。
  - 杂货打包直接用上一指令作为历史，无需插补。

  - 两个不同模拟域、多种任务、多种消融和诊断，实验设计较为系统。
  - 结果报告 95% 置信区间，并在多个维度进行因果分析（推理预算、训练方式、数据分割），加强了结论可信度。
  - 但仍有局限：实验全部在模拟器中，缺少真实机器人；未进行在线多轮 RL；超参数搜索未系统展示；部分任务成功率很低，统计噪声可能较大；VLM judge 验证样本仅 100 条，规模较小。

## 6. 论文的主要结论与发现

- **RL 后训练单独即有效**：$\mathcal{R}^3$（RL only）在训练任务上显著优于基础模型，并在多数 OOD 任务上提升。
- **中期训练提升 RL**：完整 $\mathcal{R}^3$ 优于 RL only，且 1/4 中期数据即可恢复大部分收益；中期训练为 RL 提供了行为先验。
- **OOD 泛化显著优于指令模仿**：在全部 5 个 held-out 任务上，$\mathcal{R}^3$ 超过 IL；IL 在部分 OOD 任务上甚至退化。
- **推理的测试时收益不仅来自表示学习**：
  - VQA 感知提升无法完全解释操作增益。
  - 推理作为训练时监督的 IL 变体不能匹配 $\mathcal{R}^3$。
  - 增加推理 token 预算可单调提升成功率，证明推理本身是有效的测试时计算。
- **学习到的推理行为**：$\mathcal{R}^3$ 学会比较多个候选、自我纠正、重新检查遮挡场景与历史、增量选择下一步。
- **与结构化 CoT 比较**：ECoT 风格的结构化注释没有带来额外收益，说明长时程进度跟踪、错误恢复和闭环重规划比显式视觉接地更重要。
- **跨域验证**：在双手杂货打包中，$\mathcal{R}^3$（RL only）同样显著超越指令模仿基线。

## 7. 优点

- **方法简洁实用**：不修改低层策略，只通过后训练高层 VLM 实现自由形式语言推理引导，易于与现有机器人系统结合。
- **数据效率高**：用少量专家推理轨迹 + 大量仅指令数据，避免昂贵的在线 rollout 和人工推理标注。
- **消除了昂贵的在线交互**：单步 RL 基于离线动作数据，避免长时程信用分配问题。
- **因果分析充分**：通过截断推理预算、IL 预训练/共训练、VQA 诊断三重证据，明确区分了推理的表示学习收益与测试时计算收益。
- **跨域验证**：在单臂桌面推块和双臂杂货打包两个不同域上都验证了有效性。
- **奖励设计可靠**：验证 VLM judge 与人类标注一致性高，且不同 judge 之间不敏感。

## 8. 不足与局限

- **仅模拟环境**：未在真实机器人上验证，真实噪声、感知误差和物理恢复可能提出更大挑战。
- **低层策略固定**：当前架构分离高层推理与低层执行，可能引入高层意图与低层执行之间的不匹配。
- **Stage I 仍依赖专家生成推理**：获取专家推理轨迹可能昂贵或受限于专家质量；在杂货打包中跳过了该阶段，说明领域适应性仍需人工判断。
- **Stage II 优化替代目标**：单步 RL 奖励基于指令语义匹配，而非最终任务成功，可能无法发现长时程更优策略。
- **某些任务退化**：如 diag_line 上 IL 和 $\mathcal{R}^3$ 均低于基础模型，表明行为先验可能有害。
- **RL 导致行为模式坍缩**：稀有指令（Separate、Touch、ArmMoveAbs）在 RL 后消失，可能降低策略多样性和鲁棒性。
- **杂货打包仅用 RL only**：未在该域探索中期训练与 RL 的组合，可能低估完整方案潜力。
- **算力与超参数信息不完整**：未说明 GPU 型号和总训练时长；超参数和 checkpoint 选择策略虽给出，但缺乏系统搜索和敏感性分析。
- **VLM judge 验证规模有限**：仅 100 对人工标注，覆盖的任务和场景有限。
- **专家数据偏差**：Language Table 的专家为 Gemini，其策略分布可能影响所学推理行为；post-hoc 与在线推理在相同专家下差异较小，真实

机器人部署中的硬件与感知分布差异可能进一步放大该偏差，需谨慎外推。
