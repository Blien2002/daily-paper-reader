## 摘要
视觉-语言-动作（VLA）模型已在机器人操作中展现出有效性，然而诸如 pi0.5 等最先进模型采用单帧范式，限制了其保留过去观测和形成精确空间感知的能力。本文提出 StreamPI，一种流式多模态时序建模框架，在不引入任何额外参数的情况下为单帧 VLA 赋予时序推理能力。其核心设计之一是“指令锚定的时序建模”。它将每个（视觉观测，语言指令）对视为原子时序单元：单元内部的双向注意力实现跨模态融合，而单元之间的因果注意力保持自回归流式推理。这确保语言指令在整个任务执行过程中作为持久的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入随机间隔流式训练策略：适当的帧间间隔（例如每 3 帧）可实现更快、更平滑的动作执行。此外，随机化间隔进一步提高对帧时序扰动的鲁棒性，支持实际中的异步部署。进一步地，通过利用大语言模型骨干的长度外推能力，StreamPI 无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖记忆依赖和精细感知场景的真实机器人任务以及仿真基准 LIBERO 上的实验表明，StreamPI 在多种任务中均优于 pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

## 1. 论文的核心问题与整体含义

- **背景与动机**：当前先进的视觉-语言-动作（VLA）模型如 π0.5 通常采用**单帧推理范式**，即每个动作只依赖当前图像观测，无法保留历史上下文。
- **核心问题**：单帧设计导致两类能力缺失：
  - **时序记忆能力**：无法处理需要跨帧记忆的任务，例如判断哪个杯子藏有物体、跟踪滚动目标。
  - **精确空间感知能力**：难以从单帧获得足够几何信息来完成精细操作。
- **多帧方法的挑战**：已有窗口式多帧 VLA 存在计算开销大、语言指令被视觉 token 稀释导致遗忘、训练与部署帧率不匹配、引入新编码器可能破坏预训练表示等问题。
- **整体含义**：StreamPI 旨在**不增加任何参数**的前提下，将单帧 VLA 升级为具有流式时序建模能力的模型，从而提升记忆依赖和精确感知任务的性能，并支持异步真实机器人部署。

## 2. 论文提出的方法论

- **核心思想：指令锚定的时序建模**
  - 将每个时间步的输入定义为原子时序单元：  
    `u_t = (V_t, l_t)`  
    其中 `V_t` 为当前多视角视觉观测，`l_t` 为语言指令。
  - 每个单元内部使用**双向注意力**实现视觉与语言的跨模态融合。
  - 单元之间使用**因果注意力**实现自回归时序推理，保证流式推理时未来信息不泄漏。

- **注意力结构**
  - **Intra-pair bidirectional attention**：  
    `h_τ = Attn_bi(V_τ, l_τ)`  
    在每个时序单元内，所有视觉和文本 token 互相双向关注，得到融合表示 `h_τ`。
  - **Inter-pair causal attention**：  
    `o_t = Attn_causal(h_{t-T+1}, ..., h_t)`  
    当前步的融合表示只关注过去单元，聚合历史时序信息。
  - 最终基于 `o_t` 预测动作：`a_t ~ π_θ(· | o_t)`。

- **参数无关的时序扩展**
  - 不新增任何参数，仅通过**重构注意力掩码**实现分层注意力。
  - 利用大语言模型骨干的**长度外推能力**处理扩展后的多帧 token 序列。
  - 直接继承 π0.5 全部预训练权重，支持单帧与多帧推理。

- **随机间隔流式训练策略**
  - 训练时在基础帧间隔 `δ̄` 上添加随机扰动：`δ = δ̄ + ε`，其中 `ε ~ U(-Δ, +Δ)`，并裁剪到 `[δ_min, δ_max]`。
  - 从缓冲区按随机间隔采样 T 个流式帧，使模型适应不同帧率。
  - **Temporal Masking**：随机掩码最早的 k 帧（`k ∈ {0, ..., T-1}`），仅保留最近 `T-k` 帧，模拟流式推理中的增量观测模式。

- **流式推理**
  - 初始时刻编码当前帧并缓存 KV。
  - 后续每个时间步只编码新观测，其表示通过 cross-attention 关注历史缓存，避免重复计算。
  - 推理开销随上下文长度近似恒定，适合长程任务。

## 7. 优点

- **零新增参数**：通过注意力掩码和长度外推继承预训练权重，不破坏原有视觉-语言表示，部署简单。
- **流式推理高效**：KV-Cache 使得推理延迟随帧数增长缓慢，5 帧仅比单帧多约 9 ms，适合实时控制。
- **指令锚定设计**：将语言指令与每个视觉观测绑定，有效缓解长时序中的指令遗忘问题。
- **随机间隔训练**：提升对真实机器人异步观测和可变帧率的鲁棒性。
- **实验设计较全面**：同时覆盖真实机器人和仿真基准，消融实验能支撑主要设计选择。
- **跨流泛化能力**：训练好的多帧模型可降级到少帧甚至单帧推理，灵活性高。
