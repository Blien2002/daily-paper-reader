## 摘要
虽然在大规模机器人数据集上预训练的视觉-语言-动作（VLA）模型为机器人操作提供了坚实基础，但当用有限的任务特定演示适配新任务时，其性能可能会下降。检索为数据高效适配提供了一种重用现有演示的实用方法，但现有方法通常依赖视觉相似性、状态-动作表示或任务级语言匹配。这些方法可能忽视长程操作任务的层次结构：完整任务匹配很少，但可重用技能往往很丰富。为应对这一挑战，我们提出了分层技能检索（HSR），一种用于数据高效VLA适配的检索框架。具体而言，HSR首先将目标任务分解为候选技能序列。它根据语义合理性和从先前数据集估计的技能可靠性评估每个计划。所选分解随后用于混合检索。该检索将子任务级语言检索与行为特征重排序相结合，以识别在语义上相关且与目标任务兼容的演示。最后，我们通过两阶段预训练和微调流水线适配策略，将通用技能获取与任务特定适配分离。在LIBERO基准和多个真实世界机器人操作任务上的实验表明，HSR相较最强基线的平均成功率分别提高了10.3%和21.3%。这些结果证明了结构化技能级检索在数据高效VLA适配中的有效性。视频和代码见 https://hoar012.github.io/HSR-Project。

## Abstract
While Vision-Language-Action (VLA) models pretrained on large-scale robot datasets provide a strong foundation for robot manipulation, their performance can degrade when adapted to new tasks with limited task-specific demonstrations. Retrieval offers a practical way to reuse existing demonstrations for data-efficient adaptation, but existing methods often rely on visual similarity, state-action representations, or task-level language matching. These approaches may overlook the hierarchical structure of long-horizon manipulation tasks, where complete task matches are rare but reusable skills are often abundant. To address this challenge, we propose Hierarchical Skill Retrieval (HSR), a retrieval framework for data-efficient VLA adaptation. Specifically, HSR first decomposes a target task into candidate skill sequences. It evaluates each plan based on both semantic plausibility and skill reliability estimated from the prior dataset. The selected decomposition is then used for hybrid retrieval. This combines subtask-level language retrieval with behavior-feature reranking to identify demonstrations that are both semantically relevant and compatible with the target task. Finally, we adapt the policy through a two-stage pretraining and finetuning pipeline, which separates general skill acquisition from task-specific adaptation. Experiments on the LIBERO benchmark and several real-world robot manipulation tasks show that HSR improves the average success rate by 10.3% and 21.3% over the strongest baseline, respectively. These results demonstrate the effectiveness of structured skill-level retrieval for data-efficient VLA adaptation. Videos and code are available at https://hoar012.github.io/HSR-Project.

## 1. 核心问题与整体含义

- **研究背景**：VLA（Vision-Language-Action）模型在大规模机器人数据上预训练后具备较强泛化能力，但在下游任务中通常需要微调；而高质量机器人演示数据收集昂贵，目标任务数据往往很少。
- **核心问题**：现有检索式适配方法主要依赖视觉相似性、状态-动作表示或任务级语言匹配，忽略了长时程操作任务的**层次结构**。对于“泡一杯茶”这类复合任务，完整任务演示在先前数据集中很少，但“拿杯子”“倒水”等可复用技能却大量存在。
- **整体含义**：提出**分层技能检索（HSR）**，在技能粒度上检索可复用演示，从而用少量目标数据高效适配 VLA 策略，提高长时程任务的成功率。

## 2. 方法论

HSR 整体分三步：**任务分解与计划评估 → 混合技能检索 → 两阶段策略适应**。

### 2.1 分层任务分解

- 对先验数据集 \(D_{\text{prior}}\) 的任务指令提取文本嵌入，用 **K-means 聚类**得到技能集 \(S=\{s_1,\dots,s_K\}\)，论文中设定 \(K=10\)。
- 用 LLM（Qwen3-VL-4B）根据目标任务指令和可用技能集生成多个候选计划 \(p=(u_1,\dots,u_n)\)。
- 每个子任务 \(u_j\) 通过文本嵌入相似度匹配到最近技能簇 \(s(u_j)\)。
- LLM 对每个计划给出语义合理性与逻辑一致性得分 \(S_{\text{sem}}(p)\)。

### 2.2 技能可靠性估计

- 为避免昂贵的 rollout 评估，论文将先验数据划分训练/验证集，微调 VLA 得到 \(\pi_{\theta'}\)，并用验证集上的**行为克隆损失**作为技能可靠性的轻量代理。
- 对技能簇 \(s_i\)，计算验证轨迹平均 BC 损失 \(L_{\text{val}}(s_i)\) 和平均轨迹长度 \(H(s_i)\)，归一化后定义技能置信度：
  \[
  C(s_i)=\exp(-\alpha \tilde{L}_{\text{val}}(s_i)-\beta \tilde{H}(s_i))
  \]
  其中 \(\alpha=0.6\)、\(\beta=0.8\)。
- 计划总评分为：
  \[
  \text{Score}(p)=S_{\text{sem}}(p)\cdot\prod_{j=1}^{n}C(s(u_j))
  \]
  选择最高分计划作为最终分解。

### 2.3 混合技能检索

- **语言检索**：对每个子任务，按指令语言相似度从 \(D_{\text{prior}}\) 中取 top \(M\%\) 的 episode，例如 LIBERO 中为 10%。
- **行为特征重排**：训练 VAE 编码器提取先验数据行为特征；候选帧特征 \(z_f\) 与目标演示帧特征 \(\{z_{t_j}\}\) 的相似度定义为：
  \[
  s(f)=\max_{1\le j\le N_t}\left(-\|z_f-z_{t_j}\|^2\right)
  \]
  即候选帧到最近目标帧的负距离。
- 保留语言检索结果中相似度最高的 top \(F\%\) 帧作为最终检索数据，LIBERO 中约为先验数据的 3%。

### 2.4 两阶段策略适应

- 第一阶段：用语言检索数据 \(D_{\text{lang}}\) 预训练策略，获取通用技能。
- 第二阶段：用目标数据 \(D_t\) 与重排数据 \(D_{\text{rerank}}\) 微调策略，进行任务特定适应。
- 真实世界中，由于 DROID 数据与本实验 xArm 平台存在较大跨 embodiment 差异，第二阶段仅用目标数据微调。

## 3. 实验设计

- **仿真环境**：
  - 使用 **LIBERO** 基准的 long-horizon 子集，共 10 个复合操作任务。
  - 目标数据集每个任务仅 **5 条演示**；先验数据集为 **LIBERO-90**。
  - 评估：每个任务 50 个 episode，3 个随机种子，报告平均成功率与标准差。
- **真实机器人环境**：
  - 使用 7 自由度 **xArm** 机器人，设计 4 个任务：Drawer、Trashcan、Cup-Drawer、Cup-Tea。
  - 每个任务收集 **20 条演示**；先验数据来自 DROID，随机抽样 10k 条轨迹。
  - 每个任务评估 **20 次**，所有模型使用相同初始状态集合以保证公平。
- **基线与对比方法**：
  - 目标数据微调：BC。
  - 随机/全量数据混合：Random、All Data。
  - 语言相似检索：Language。
  - 视觉/行为检索：Flow Retrieval（FR）、STRAP、Behavior Retrieval（BR）、Importance Weighted Retrieval（IWR）。

## 6. 主要结论与发现

- HSR 在 LIBERO 上的平均成功率为 **43.5%**，比最强检索基线 BR（33.2%）提高 **10.3 个百分点**。
- 在真实机器人任务上，HSR 总成功率为 **48/80**，明显优于 BC（27/80）、BR（27/80）和 IWR（31/80），相对最强基线 IWR 提高 **21.3 个百分点**。

- 消融表明：任务分解、特征重排、两阶段训练三部分均对性能有贡献；两阶段训练优于单阶段 co-training。
- 仅用 LLM 分解即可获得接近人工设计计划的性能；加入技能集与计划评估后进一步接近人工选择水平。

## 7. 方法亮点

- **充分利用任务层次结构**：在技能级而非整体任务级进行检索，更符合长时程任务的组合性质。
- **技能可靠性代理**：用 BC 损失代替 rollout 评估，避免高成本在线评估，同时仍能区分技能易学性。
- **混合检索**：将语言语义检索与 VAE 行为特征重排结合，兼顾语义相关性和低层行为兼容性。
- **两阶段训练**：分离通用技能获取与任务特定适应，降低检索数据噪声对优化的负面影响。
- **参数高效**：仅更新 VLA 的 action expert（约 100M 参数），计算成本相对较低。
- **仿真+真实联合验证**：在 LIBERO 和真实 xArm 平台上均取得显著提升，验证结果有一定实用性。
