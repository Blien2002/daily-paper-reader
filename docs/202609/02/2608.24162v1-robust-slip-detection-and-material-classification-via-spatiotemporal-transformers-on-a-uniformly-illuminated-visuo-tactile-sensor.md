## 摘要
触觉感知是机器人操作的核心，其中滑动检测是一项典型且关键的任务。然而，现有的滑动数据集主要局限于二分类，缺乏细粒度的方向感知。为了解决这一局限性，我们提出了一种具有定制均匀RGB照明的视觉-触觉传感器，以及一个统一的感知框架。在硬件层面，该传感器实现了高精度、亚毫米级的深度重建。基于这一能力，我们收集了一个包含15个物体的多任务视觉-触觉数据集，并为每个数据样本同步生成深度信息。在算法上，我们设计了一个双头TimeSformer网络来处理动态时空滑动。在未见过的物体上，该网络在3类接触状态预测和细粒度8类滑动方向分类上分别实现了95.5%和91.5%的鲁棒准确率。此外，利用ResNet-50骨干网络的静态触觉目标类别识别在15个类别上取得了98.8%的出色准确率。所提出的软硬件框架为复杂的机器人操作提供了高保真反馈和强大的多模态感知基线。

## Abstract
Tactile sensing is central to robotic manipulation, among which slip detection stands out as a quintessential and critical task. However, existing slip datasets are predominantly limited to binary classification, lacking fine-grained directional perception. To address this limitation, we propose a visuo-tactile sensor featuring customized uniform RGB illumination, alongside a unified perception framework. At the hardware level, the sensor achieves high-precision, sub-millimeter depth reconstruction. Based on this capability, we collect a multi-task visuo-tactile dataset encompassing 15 objects, synchronously generating depth information for each data sample. Algorithmically, we design a dual-head TimeSformer network to process dynamic spatiotemporal slip. On unseen objects, this network achieves robust accuracies of 95.5% and 91.5% for 3-class contact state prediction and fine-grained 8-class slip direction classification, respectively. Furthermore, static tactile-based object class recognition utilizing a ResNet-50 backbone yields an outstanding accuracy of 98.8% across 15 categories. The proposed hardware-software framework provides high-fidelity feedback and a powerful multi-modal perception baseline for complex robotic manipulation.

## 2. 方法论

### 2.1 硬件设计：均匀RGB照明的无标记视觉-触觉传感器

- **传感器结构**：整体尺寸为37 mm × 34 mm × 34 mm，包含弹性体接触模块、照明模块（集成三色RGB LED的PCB）和信号接收模块（微型摄像头）。
- **模块化设计**：弹性体接触模块独立可拆卸，便于长期使用后更换磨损的接触层，同时保持照明条件一致。
- **均匀照明设计**：
  - PCB上的光源被有效隔离为不同照明区域，并在其上放置光扩散滤光片，实现接触层上高度均匀的光照分布。
  - 优化接触模块与相机的相对位置，将来自丙烯酸支撑板的镜面反射“鬼影”移出相机焦区，避免照明伪影影响成像质量。
  - 通过标准平面照明实验验证了RGB三通道强度分布一致，说明均匀照明有效抑制镜面高光，为光度立体和微纹理提取提供物理先验。
- **优点**：无标记设计使微纹理不被遮挡；均匀照明保证了RGB序列在时空上的严格一致性，有利于后续自注意力机制聚焦于真实物理位移而非光照噪声。

### 2.2 弹性体制造工艺

- 使用3D打印制造结构件和硫化模具。
- 弹性体材料：铂催化光学透明硅胶（Smooth-On Solaris），按1:1混合浇筑、真空脱泡、室温固化。
- 反射涂层：将白色硅胶颜料、硅胶涂料基料（Smooth-On Psycho Paint）和硅胶溶剂（Smooth-On NOVOCS Thinner）按0.3:1:1:2体积比混合，均匀喷涂形成薄哑光白色涂层，作为漫反射层。

### 2.3 深度重建：经验光度立体法

- **标定**：使用已知物理半径 $r = 3$ mm 的标准球体压入传感器弹性体，通过三轴线性位移台控制压入深度。
- **几何模型**：对于球面压痕，像素 $(x, y)$ 处的深度 $z(x, y)$ 满足 $z(x, y) = \sqrt{R^2 - r^2}$，其中 $r$ 为像素到接触中心的投影径向距离；通过偏导数可得水平与垂直方向的真实表面梯度 $p_{\text{ref}}$、$q_{\text{ref}}$。
- **映射学习**：训练连续映射函数 $f$，输入为每个像素的RGB强度 $I_R, I_G, I_B$ 及其空间坐标 $(x, y)$，输出表面梯度 $[p, q]$；标定阶段用上述真实梯度监督拟合 $f$。
- **深度积分**：实际感知时，将RGB图像经映射函数转换为致密梯度场 $p(x,y)$、$q(x,y)$，通过Poisson求解器（$\nabla^2 z = \partial p/\partial x + \partial q/\partial y$）重建连续深度图。
- **结果**：平面对齐RMSE为0.072 mm（约72 μm），达到亚毫米级精度。

### 2.4 数据集构建

- **静态材料分类数据集**：包含15个日常物体（标准几何压头、五金工具、精密电子连接器、天然有机纹理等），采集时覆盖不同接触位置、姿态和压入深度，共约19,336张高分辨率触觉图像。
- **动态滑动数据集**：同样基于15个物体，共7,925段高保真滑动序列（约63,400张图像），每段序列为8帧连续图像。
- **标签体系**：核心物理状态分为3类（Pressing、Static、Slip）；其中“Slip”状态按45°间隔细分为8个方向类别，形成更细粒度的方向感知。
- **深度模态**：利用传感器的高精度深度重建能力，为数据集中每个样本同步生成一一对应的致密深度图，构建RGB-D多模态触觉数据集。

### 2.5 统一感知框架：双头TimeSformer + ResNet-50

- **动态滑动检测——双头TimeSformer**：
  - 输入：原始8帧序列（尺寸缩放到224×224），切分为非重叠空间patch，线性投影并加入空间与时间位置编码。
  - 核心结构：堆叠的Divided Space-Time Attention模块，交替计算时间自注意力（跨帧）和空间自注意力（同帧内）。
  - 双头输出：提取全局token后，送入两个全连接头——状态头（3类：Static、Press、Slip）和方向头（8类滑动方向）。
  - **掩码联合损失函数**：
    $$
    L_{\text{total}} = L_{\text{state}} + \lambda \cdot \mathbb{I}(\text{state} = \text{slip}) L_{\text{dir}}
    $$
    即方向损失仅在真实状态为“Slip”时才会反向传播，防止静态或按压样本对方向头产生噪声干扰。
  - 模型初始化：使用预训练权重 `facebook/timesformer-base-finetuned-ssv2`。

- **静态材料分类——ResNet-50**：
  - 输入：单帧触觉图像（缩放到224×224）。
  - 骨干网络：ImageNet预训练的ResNet-50，修改全连接层为15类输出。
  - 数据增强：训练时使用颜色抖动和几何增强，提高对轻微光学波动的鲁棒性。
  - 可解释性：集成Grad-CAM可视化网络关注的高频微特征（如尖锐边界、有机孔隙）。

## 6. 主要结论与发现

- **硬件层面**：所提出的均匀RGB照明无标记视觉-触觉传感器有效抑制了镜面高光，实现了亚毫米级深度重建（RMSE = 0.072 mm），为高保真触觉感知提供了可靠基础。

  - 在RGB模态下，双头TimeSformer在完整测试集上达到99.68%（3类状态）和96.95%（8类方向）的准确率。

- **总体结论**：统一的软硬件框架能同时提供高精度的细粒度滑动检测和静态材料识别，为复杂机器人操作（特别是需闭环力控与抓取适应）建立了有潜力的多模态感知基线。

- **消融实验缺失**：未验证帧数T（8帧）、损失函数掩码策略、TimeSformer结构配置（层数、patch大小等）等关键设计因素的影响。
- **训练细节不完整**：未报告优化器、学习率、调度策略、批量大小、训练时长等超参数，复现性受到影响。
- **应用场景限制**：实验集中在受控桌面抓取/按压场景，未在更复杂的多变负载、长时间连续滑动、动态抓取调整闭环任务中验证；传感器与感知框架在多指灵巧手或移动操作场景下的有效性仍属未来工作。
- **数据集对比的局限性**：论文虽在表I中对现有数据集进行了对比，但并未基于这些公共数据集做跨数据集的迁移或基准测试，限制了数据与方法的通用性证明。
